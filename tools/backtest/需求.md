# 回测层 backtest · 开发包(需求与接口)

> 层:聚合层同级(读历史数据+调策略,不产中心记录)· 状态:**✅ 可开工**(依赖已就绪)· 分支建议:`feat/backtest-bt1`
> 依赖:`tools/strategy`(被测策略,已建)+ `tools/store`(历史 raw,已建)· 详细设计:[docs/计划/回测层.md](../../docs/计划/回测层.md)

## 职责(做什么 / 边界)
- 用**历史原始数据回放策略** → 算绩效 → 与基准对比。验证策略行不行。
- **边界**:只读历史数据(经 store)+ 调策略(经 strategy);**不触网、不产中心记录、不重算指标**。
- **命门**:walk-forward,第 t 日只用 `≤t` 的数据;**严禁未来函数**。

## 接口契约
```python
# engine.py
def backtest(strategy_name: str, codes: list[str], start: str, end: str, *,
             rebalance_days: int = 5, cost_bps: float = ..., price: str = "close",
             benchmark: str = "equal") -> dict:
    """回放策略 → 绩效。返回 {策略,类型,区间,绩效{...},基准{...},超额,明细ref}。"""

# metrics.py(纯函数,可单测)
def cum_return(returns) -> float          # 累计收益
def annualized(returns) -> float          # 年化
def max_drawdown(equity) -> float         # 最大回撤
def sharpe(returns) -> float              # 夏普
def win_rate(trades) -> float             # 胜率
```
- 数据经 `store.get_raw("kline", code)`;策略经 `strategy.run(name, ...)`(按 kind 走选股/信号回放)。
- 参数入 `config/strategy.py['回测']`;产出落 `data/analysis/backtest/{strategy}_{date}.json`。

## 验收标准
- [ ] **防未来函数测试(必)**:注入未来异常值不改变历史回测结果。
- [ ] 绩效指标数值:构造已知收益序列验证 收益/回撤/夏普。
- [ ] 基准对比(等权持有)生效;成交假设(费用/滑点/调仓)生效。
- [ ] 跑现有选股策略(超跌反弹/主力吸筹)拿到基线。
- [ ] 全站标"历史回测≠未来保证,非投资建议"。
