# 股票分析 · A 股自选池分析系统

对一个 32 只硬科技成长股自选池(半导体主线,见 [docs/股票清单.md](docs/股票清单.md))做
**技术指标分析** + **情绪影响分析**(政策 / 公司内部行为 / 舆情 三层)。

分析方向:**方案 2 —— 先抓组合/行业层面共性主线,再挑重点票深挖**。

## 当前状态

**里程碑:不依赖 LLM 的结构化数据层全部打通(P0 / P1 / P2-A / P2-B 已落地)。**
一条命令即可产出组合概览 + 重点票深挖两级报告。开发前请先读 `docs/开发规范.md`。

| 阶段 | 内容 | 状态 |
|---|---|---|
| P0 | 框架 + 开发规范 + LLM 调用设计 | ✅ |
| P1 | 技术面:行情采集 + MACD/KDJ/RSI/均线/量价 + 综合评级 + 报告 | ✅ |
| P2-A | 基本面:营收/净利/ROE/毛利/负债 + PE/PB/市值 | ✅ |
| P2-B | 公司行为:巨潮公告采集 + 15 类规则打标 + 方向粗判 | ✅ |
| P2-C | 新闻关键信息提取(L1)+ 事件三层分类 | 🔒 待 LLM API(见问题台账 Q7) |
| P3 | 组合聚合:主线识别 / 情绪温度 / 重点票筛选 | ⏳ |
| P4 | 舆情(UGC/政策)+ 情感打分(L2) | 🔒 待 LLM API |
| P5 | 编排 / 定时调度 / 测试收尾 | ⏳ |

数据源(避开被 TLS 指纹墙的东财):行情=腾讯/新浪,基本面=同花顺+百度,公告=巨潮 cninfo。
测试:27 单测全过。详见 [开发日志](docs/日志/开发日志.md)。

## 快速开始

```bash
pip install -r requirements.txt
python -m tools.run all        # 采集(行情+基本面+公告)→ 分析 → 出报告到 docs/报告/
```

也可分步:`python -m tools.run collect | analyze | report`。
