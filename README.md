# 股票分析 · A 股自选池分析系统

对一个 32 只硬科技成长股自选池(半导体主线,见 [docs/股票清单.md](docs/股票清单.md))做
**技术指标分析** + **情绪影响分析**(政策 / 公司内部行为 / 舆情 三层)。

分析方向:**方案 2 —— 先抓组合/行业层面共性主线,再挑重点票深挖**。

## 目录

| 路径 | 内容 |
|---|---|
| `docs/开发规范.md` | ⭐⭐ 开发规则 + 文档体系(计划/问题/日志)总纲(**接手先读这份**) |
| `docs/架构设计.md` | ⭐ 系统架构、模块 I/O 契约、落地路线 |
| `docs/数据源调研.md` | 数据源评估(akshare 基座 + 浏览器抓取 + WebSearch) |
| `docs/股票清单.md` | 32 只票池 + 行业归类(数据来源:东财自选截图) |
| `docs/计划/` | 前瞻:分 Phase 的实施计划 |
| `docs/问题/` | 专题:待决问题 + bug 踩坑台账 |
| `docs/日志/` | 回溯:开发日志(时间倒序) |
| `docs/报告/` | 分析报告产出(gitignore) |
| `tools/config/` | 股票池 `stock_pool.py` + 全局参数 `settings.py` |
| `tools/collectors/` | 采集层:行情/基本面/公告/新闻/UGC/政策 |
| `tools/analysis/` | 分析层:技术指标/情感打分/事件三层分类/组合聚合 |
| `tools/report/` | 报告渲染 |
| `tools/run.py` | 编排入口 |
| `data/` | 原始截图 + `raw/` 采集缓存(gitignore) |
