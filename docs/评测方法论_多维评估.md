# 评测方法论:多维评估(不只看 alpha 一刀切)

> 本文确立策略评测的**判定原则**——多维、分档、不再"超额不显著=直接否定"。
> 配套代码:`tools/backtest/eval_v3/`(打分/聚合/报告),多维综合判定见 `report.py::multidim_verdict`。
> 语义由 `tests/test_eval_v3.py` 锁死。**非投资建议。**

## 一、为什么要改:alpha 一刀切的问题

早期评测把"**超额收益(alpha)显著性**"当唯一裁判:超额不显著就把策略判成"非 alpha / 参考"
并倾向下线。这漏掉了一类真有实盘价值的策略:

- **绝对收益 vs 超额收益是两个视角。** 超额回答"跑没跑赢同期大盘"(相对);绝对收益回答
  "真金白银赚没赚"(绝对)。牛市普涨里,一个只跟大盘的垃圾策略绝对收益也为正——所以
  **需要 alpha 防运气**(区分"运气/beta"和"本事/alpha")。
- **但 alpha 不该是唯一裁判。** 一个**命中率高、能稳定选出上涨票、盈亏比健康**的策略,即便
  超额不突出,配合**择时 / 风控 / 仓位**在实盘仍能赚钱、仍有价值。只因"超额不显著"就否定它,
  等于把能选涨票的本事和纯跟大盘的 beta 混为一谈、一起埋没。

**核心修正:** alpha **有必要但非唯一**。评测要多维、分档,区分两种"超额不突出":
1. **纯跟大盘(beta),且不赚** → 该淘汰;
2. **有绝对价值(能选涨票 + 真金白银赚),只是超额不突出** → 可配合择时保留,不该被一票否决。

## 二、多维指标(评测输出的六个视角)

评测对每个策略在每个滚动窗 × 每个 horizon 已并列输出下列维度(口径见
`docs/策略成绩报告.md` 列名说明,均为 T+1 入场、防未来函数):

| 维度 | 指标 | 回答什么 | 作用 |
|---|---|---|---|
| **① alpha / 超额** | 超额收益%_vs全市场、超额聚类CI/p、优于随机p | 跑没跑赢同期大盘 | **防运气**:普涨里别把 beta 当本事 |
| **② 命中率 / 胜率** | 命中%(期末/期内触及)、胜率% | 能否稳定选出方向对/上涨的票 | 择时/风控的选股地基 |
| **③ 绝对收益 + 盈亏比** | 均收益%、中位数%、盈亏比、P10/P90 | 实盘真金白银赚不赚、赢面盈亏结构 | 绝对价值 |
| **④ 稳定性 / 一致性** | 按日聚类 CI 宽度、样本数、预测日数、P10 尾部 | 结论稳不稳、是不是少数日撑起来的 | 可信度 |
| **⑤ 排序选择性**(可排序型) | Top-N(5/10/20)精度、rank-IC/ICIR | 分数越高是否越准/越赚 | 排序信息有没有用 |
| **⑥ 可执行性** | 隔夜跳空占比、每日出票数(容量/流动性)、用close入场占比 | 实盘能不能照做 | 落地约束 |

> 单看任一维度都会误判:高命中可能赢小亏大(须并看盈亏比);高超额可能样本薄不稳(须看 CI/p);
> 绝对收益正可能只是普涨 beta(须看超额)。**多维并看,才能把"运气"和"本事"、"相对"和"绝对"分开。**

## 三、综合判定原则(分档,不一刀切)

判据默认取 **5 日 horizon · 全史窗**(样本厚、有显著性);不可回放策略(含 LLM/新闻/筹码,如
策略0/9)退回 **live 全史**。阈值为命名常量(`report.py`,便于调参、测试锁死):

- `SIG_P = 0.10`——超额显著性阈值(与差生名单一致);
- `MIN_N = 30`——样本充足下限;
- `HIT_BAR = 50.0`——命中率(期末)基线,≥视作"能稳定选出方向对的票"(优于抛硬币);
- `PF_BAR = 1.0`——盈亏比下限,≥视作"没有赢小亏大"。

**分档逻辑(按优先级):**

| 档位 | 判据 | 含义 / 处置取向 |
|---|---|---|
| **观察·样本不足** | 样本 < `MIN_N` | 证据不足,不下强/淘汰任何结论 |
| **淘汰·显著负** | 超额<0 且 聚类p<`SIG_P` | 坐实做反了(方向反向坐实),下线 |
| **强·alpha显著** | 超额>0 且 聚类p<`SIG_P` | 有本事、普涨里也跑赢——核心保留 |
| **可保留·配合择时** | 超额不显著,但 绝对收益>0 且 盈亏比≥`PF_BAR` 且 命中率≥`HIT_BAR` | **能选涨票 + 真金白银赚,只是超额不突出**;配合择时/风控/仓位保留,非独立 alpha |
| **淘汰·纯beta无绝对价值** | 无正超额(≤0/缺)且 绝对收益≤0 | 纯跟大盘还不赚——该淘汰 |
| **观察·证据不足** | 信号互相矛盾/未达任一档 | 留观察,补样本 |

**关键分野**(用户洞察的落地):对"超额不突出"的策略,**不再一律否定**——

- **有绝对价值但超额不突出** → `可保留·配合择时`(不被单一指标一票否决);
- **纯跟大盘且不赚** → `淘汰·纯beta`。

> **可排序型补充:** 全量等权可能稀释排序信息。若 Top-N(尤其 Top5)超额/命中显著高于全量,
> 说明打分有选择性,即使全量等权口径超额不突出,该策略仍可能有"取头部"的用法(附注佐证,
> 不单独改档,供人工共评)。

> **参考·非alpha(伪排序,如策略11):** 打分为离散状态格、个股间无真实区分、代码自认非 alpha;
> 不下强/淘汰判定,只列全量指标 + 参考收益分布,作条件指标输入。

## 四、边界与纪律

- **多维判定是"辅助共评视图",不是自动处置。** 报告并列输出六维 + 综合档位,最终 删/降级/保留
  由策略提供者/合作者共评拍板(见 `docs/策略成绩报告.md` 处置建议节)。
- **防未来函数不放松。** 评测本就无未来函数(as-of 筛选 + T+1 口径 + 只算已到期),多维汇总只读
  既有单元格、不引入任何新的用未来价的计算。
- **样本薄不硬判。** 真正判据是 CI 宽度 / p 值 / 样本量,不靠单点估计。历史观测≠未来保证。
- **阈值可调、语义须锁。** 阈值(`SIG_P/MIN_N/HIT_BAR/PF_BAR`)是工程约定、可随认知更新调整;
  但"超额不突出≠直接否定""区分纯beta vs 有绝对价值"这条原则由测试锁死,不因未来重写而丢。
