# 数据结构说明(结构化产出 schema)

> 状态:v1.0 · 2026-08-05
> 说明每票结构化 JSON(`data/analysis/{code}.json`)与策略配置(`config/strategy.json`)的字段。
> 目的:让程序/数据库/Web 直接消费,不依赖散文文档。区分**当前快照**与**持续/时间序列**。

---

## 1. 每票结构化记录 `data/analysis/{code}.json`

由 `tools/analysis/serialize.py::build_record` 组装。缺失数据块降级为 null,不报错。

| 顶层字段 | 类型 | 时效 | 说明 |
|---|---|---|---|
| `schema_version` | str | — | schema 版本(当前 1.0) |
| `meta` | obj | 静态 | code / name / sector / industry / as_of(数据基准日) |
| `snapshot` | obj | **当前快照(最新1日)** | 见 §1.1 |
| `valuation` | obj | 当前 | pe_ttm / pb / mktcap_yi / 报告期 / **pe_valid / mode / basis**(PE开关判定) |
| `fundamental` | obj | 最近报告期 | 营收 / 净利 / 营收增速 / 净利增速 / ROE / 毛利率 / 净利率 / 负债率 |
| `signals` | obj | **派生判定** | trend(趋势评级)/ reversal(拐点)/ ob_os(超买超卖) 见 §1.2 |
| `fundflow` | obj/null | 派生自时间序列 | 今日主力净流入 / 占比 / 5日合计 / 连续净流入天数 |
| `events` | list | **持续追加流** | 近 20 条公告 {date,type,impact,title} |
| `timeseries_refs` | obj | 指针 | 指向 K线/资金流/公告的时间序列文件路径(大数组不塞进本 JSON) |
| `provenance` | obj | — | 各数据块是否就位(可信度追踪) |

### 1.1 snapshot(当前快照)
`close, pct_chg, ma{ma5,ma10,ma20,ma60,排列}, macd{dif,dea,macd,状态}, kdj{k,d,j,状态}, rsi{rsi6,rsi12,rsi24}, bias20, vol_ratio, vol_state`

### 1.2 signals(派生判定,均由 technical.compute 产出)
- `trend`: {评级(偏多/中性/偏空), 得分(−100~100), 依据[]}
- `reversal`: {拐点标签(反弹启动/超跌待反弹/无), 拐点评分(0~100), 超跌/放量反包/低位金叉/底背离(bool), 依据[]}
- `ob_os`: {verdict(超买/超卖/中性), resonance(共振指标数), per_indicator{kdj,rsi,bias}}

### 时效性总结(用户关注点:持续 vs 当前)
- **当前快照/派生信号**:snapshot / valuation / signals / fundflow —— 每次 serialize 覆盖为最新。
- **持续/时间序列**:K线、资金流历史(parquet)、公告流(json)—— 不塞进本记录,用 `timeseries_refs` 指针 + `events` 增量。

## 2. 策略配置 `config/strategy.json`

由 `tools/config/strategy.py` 导出(单一真源,测试保证 py↔json 一致)。两部分:
- `thresholds`:所有可调阈值(超买超卖 / 拐点 / 趋势评级 / 量价 / PE开关)。
- `formulas`:各判定的文字公式(BIAS / 超买超卖 / 拐点评分 / 趋势评级 / PE适用性开关)。

### 关键阈值速查
| 判定 | 阈值 |
|---|---|
| 超买超卖共振 | ≥2 指标同向才下结论 |
| KDJ | 超买 K>80/J>100;超卖 K<20/J<0;次级超卖 J<10(仅提示,不计共振) |
| RSI12 | 超买>70(极端>80);超卖<30(极端<20) |
| BIAS20 | 超买>+10;超卖<−10;极端<−20 |
| 拐点标签 | ≥50 反弹启动;≥25 超跌待反弹 |
| 趋势评级 | ≥30 偏多;≤−30 偏空 |
| PE开关 | PE≤0/净利<0 失效;PE<5+净利暴增>100% 疑一次性;PE>100+负增长/低毛利 折旧扰动 |

> 改策略只改 `tools/config/strategy.py` 再 `dump_json()`;代码从 THRESHOLDS 读,不散落硬编。

## 3. 消费方式
```python
from tools.analysis import serialize
rec = serialize.load_record("000021")        # 单票结构化记录
rec["signals"]["ob_os"]["verdict"]            # 超买超卖结论
rec["valuation"]["pe_valid"]                  # PE 是否适用
```
后续 Web/DB 可直接读 `data/analysis/*.json` 建表或渲染。
