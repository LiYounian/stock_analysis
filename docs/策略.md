> **权威口径**:所有阈值/公式的**单一真源**是 [`tools/config/strategy.py`](../tools/config/strategy.py)(`THRESHOLDS` + `FORMULAS`);本文是它的人读版,若有出入以代码为准。

## 0. 名词 / 指标速查(先看这个)

| 名词 | 含义 | 一句话作用 |
|---|---|---|
| **K线 / OHLC** | 每日开(open)/高(high)/低(low)/收(close)盘价 + 成交量 | 一切计算的原始输入 |
| **MA(均线)** | N 日收盘均值,如 MA5/MA20/MA60 | 判趋势方向与多空排列 |
| **均线排列** | 多头(MA5>MA20>MA60)/空头(反之)/纠缠 | 趋势强弱的骨架 |
| **MACD** | 快慢 EMA 之差(DIF)与其均线(DEA);金叉=DIF上穿DEA | 中期动能与拐点 |
| **KDJ** | 随机指标,K/D/J 三线(通达信口径,SMA 递推);J=3K−2D | 短期超买超卖 |
| **RSI** | 相对强弱,0~100;>70 偏热、<30 偏冷(RSI6/12/24) | 超买超卖 |
| **BIAS20** | 乖离率 =(收盘−MA20)/MA20×100 | 价格偏离均线多远 |
| **量比** | 当日成交量 / 过去5日均量;>1.5 放量、<0.7 缩量 | 量能是否配合 |
| **ATR** | 真实波幅均值(14日),衡量"这只票每天大约波动多少钱" | **止盈止损的标尺** |
| **ATR%** | ATR / 现价 ×100,把波动换成百分比 | 跨票可比的波动幅度 |
| **Swing pivot(摆动高低点)** | 前后各 window 根内的局部最高/最低点 | **支撑位/压力位**来源 |
| **分位数(percentile)** | 一组数里第 X% 小的值,q10/q50/q90=悲观/中位/乐观 | **情景预测**的涨跌幅 |
| **净情绪分** | 新闻/舆情/政策三层加权后的情绪值,范围 −1~1 | 消息面并入决策 |

## 2. ⭐ 预期涨跌价位怎么判定(核心方法)

对每只票、每个**持有期 N**(默认 N = 1 / 5 / 10 个交易日),我们从**两条独立路径**给"预期涨跌":

- **路径一(波动率法)→ 操作用的止盈/止损价**:基于 ATR 算"合理的止损位、止盈位"。
- **路径二(历史频率法)→ 概率化的收益区间**:统计这只票历史上持有 N 天的真实收益分布,给悲观/中位/乐观三档收益 + 上涨概率。
- **辅助(结构法)→ 支撑/压力价**:用摆动高低点标出上方压力、下方支撑。

三者角度不同、互相印证:**波动率法给"该在哪止损/止盈"**,**历史频率法给"大概能涨/跌多少、概率多大"**,**结构法给"关键价位在哪"**。

### 2.1 支撑位 / 压力位(结构法)

**方法**:在历史 K 线里找 **swing pivot**——某根 K 线的最高价是其前后各 `window`(默认 5)根里的最高 → 记为压力枢纽;最低价是前后最低 → 支撑枢纽。再取**现价下方最近 2 个**作支撑、**上方最近 2 个**作压力。

```
压力枢纽:high[i] == max(high[i-window : i+window])
支撑枢纽:low[i]  == min(low[i-window : i+window])
支撑位 = {枢纽低点 | 低点 < 现价} 取最近 2 个(从高到低)
压力位 = {枢纽高点 | 高点 > 现价} 取最近 2 个(从低到高)
```
> 直觉:价格历史上多次触碰后反转的位置,往往再次形成阻力/支撑。

### 2.2 止盈位 / 止损位(波动率法)⭐ —— "跌到多少止损、涨到多少止盈"

**思路**:一只票能涨多少、跌多少,取决于它**自身的波动幅度(ATR%)**,并且持有越久、波动越大(按 √N 放大——统计学上 N 日累计波动≈单日波动×√N)。

**公式**:
```
ATR%      = ATR(14日真实波幅均值) / 现价 × 100
band_N    = ATR% × √N                       # 持有 N 日的预期波动幅度(%)
最大亏损%  = 止损倍数(1.0) × band_N
目标盈利%  = 止盈倍数(1.6) × band_N
止损位     = 现价 × (1 − 最大亏损%/100)      # ← 跌到这个价就止损
止盈位     = 现价 × (1 + 目标盈利%/100)      # ← 涨到这个价就止盈
风险收益比 = 止盈倍数 / 止损倍数 = 1.6        # 赚的空间是亏的 1.6 倍
```

- **止损倍数 1.0 / 止盈倍数 1.6**:止损设得比止盈近,是为了"亏损截断、让利润奔跑",盈亏比 1.6 表示这套设定的期望赔率。
- 全程**百分比**表达,与买几手、投多少钱无关(买 1 手和 100 手的盈亏百分比相同),所以**不需要总资金**。

### 2.3 情景预测(历史频率法)⭐ —— "大概能涨/跌多少、概率多大"

**思路**:不靠拍脑袋,直接看这只票**历史上**每次持有 N 天,实际收益是多少,汇成一个分布,再报三个代表值 + 上涨概率。

**公式**:
```
对历史每个交易日 t:  r = close[t+N] / close[t] − 1     (N 日前瞻收益)
上涨概率 = P(r > 0) = (r>0 的天数 / 总天数) × 100%
悲观收益 = r 的第 10 分位(q10)   ← 只有 10% 的历史情形比这更差
中位收益 = r 的第 50 分位(q50)   ← 一半好一半差的中间值
乐观收益 = r 的第 90 分位(q90)   ← 只有 10% 的历史情形比这更好
```
样本 < 20 时判为数据不足、不给分位(诚实拒绝)。

> **和 2.2 的区别**:2.2 是"该在哪止损止盈"(操作纪律);2.3 是"历史上持有 N 天大概涨跌多少、上涨概率多大"(期望判断)。两者一起看:止盈目标是否落在历史乐观区间内?胜率是否过半?

### 2.4 一个完整实例(真实数据:芯原股份 688521,2026-08-06)

现价 **217.17**,ATR% = **10.38**(这票波动很大)。

**① 止盈止损位(波动率法)**:

| 持有期 N | band=ATR%×√N | 止损位(最大亏损%) | 止盈位(目标盈利%) | 盈亏比 |
|---|---|---|---|---|
| 1 日 | 10.38 | **194.63**(−10.38%) | **253.22**(+16.60%) | 1.6 |
| 5 日 | 23.21 | **166.79**(−23.20%) | **297.78**(+37.12%) | 1.6 |
| 10 日 | 32.81 | **145.92**(−32.81%) | **331.18**(+52.50%) | 1.6 |

验算(5日):band = 10.38×√5 = 23.2 → 止损位 = 217.17×(1−0.232)=166.79,止盈位 = 217.17×(1+0.371)=297.78。✅

**② 情景预测(历史频率法)**:

| 持有期 | 上涨概率 | 悲观(q10) | 中位(q50) | 乐观(q90) | 样本 |
|---|---|---|---|---|---|
| 1 日 | 49.4% | −6.11% | −0.02% | +6.38% | 324 |
| 5 日 | 50.0% | −10.61% | +0.07% | +15.74% | 320 |
| 10 日 | 52.7% | −15.30% | +0.90% | +27.19% | 315 |

**③ 支撑/压力(结构法)**:支撑 [208.0, 203.67],压力 [237.79, 258.65]。

**怎么读**:持有 5 日,操作上"跌到 166.79 止损、涨到 297.78 止盈";而历史频率看,5 日上涨概率 50%,乐观也就 +15.74%——**说明 2.2 的止盈目标(+37%)偏激进、历史上很少达到**,这正是两条路径互相印证的价值:**波动率给纪律,历史频率给现实预期**。

## 3. 判定类策略(A 组:读盘面下结论)

这三项在 `technical.py` 计算,是"给这只票当前状态贴标签",也是买卖倾向(第 4 节)的输入。

### 3.1 趋势评级 → 偏多 / 偏空 / 中性
按四项加权打分(clamp 到 −100~100):
```
均线排列:多头 +30 / 空头 −30
MACD:   金叉 +25 / 死叉 −25;DIF 在 0 轴上方 +10 / 下方 −10
价对 MA20:收盘 > MA20 +10 / < MA20 −10
RSI12 档位:偏强 +10 / 偏弱 −10
合计 ≥ +30 → 偏多;≤ −30 → 偏空;其间中性
```

### 3.2 拐点识别 → 反弹启动 / 超跌待反弹 / 无(超跌反弹专用)
四个触发项按权重加总(clamp 0~100):
```
超跌       +25:KDJ超卖 或 RSI6<20 或 距20日低点≤3% 其一
放量反包   +30:量比>1.5 且 当日涨 且 站上 MA5
低位金叉   +25:KDJ 的 K 上穿 D 且 K<50
底背离     +20:价创新低但 MACD 未创新低
合计 ≥50 → 反弹启动;≥25 → 超跌待反弹;否则 无
```

### 3.3 超买超卖(共振制,防假信号)→ 超买 / 超卖 / 中性
对 **KDJ / RSI12 / BIAS20** 三个指标各自判超买或超卖,统计**同向命中个数(共振数)**:
```
共振数 ≥ 2 才下"超买"/"超卖"结论,否则中性
(单指标不单独定论——尤其 KDJ 的 J=3K−2D 易假信号)
```
超买/超卖阈值:KDJ(超买 K>80/J>100,超卖 K<20/J<0)、RSI12(>70 / <30)、BIAS20(>10% / <−10%)。

## 4. 买卖倾向(C 组:多因子打分决策)

把上面的判定 + 资金流 + 情绪**打分求和**,给一个可追溯的倾向。**每个因子只是一维输入,不单独决定结果**。

| 因子 | 加/减分 |
|---|---|
| 超买超卖 | 超卖 +2 / 超买 −2 |
| 拐点 | 反弹启动 +2 / 超跌待反弹 +1 |
| 趋势评级 | 偏多 +1 / 偏空 −1 |
| 资金流 | 主力净流入 +1;连续≥2天再 +1;净流出 −1 |
| **情绪(第5节)** | 净情绪分 ≥ +0.2 → **+2**;≤ −0.2 → **−2**(样本数为0不计) |

```
总分 ≥ +2 → 偏买入;≤ −2 → 偏卖出;其间 → 观望
```
> **实例**:688521 各技术项中性、资金流缺失,仅**情绪偏多 +2** → 总分 2 → **偏买入**(依据 `["情绪偏多+2"]`)。情绪真正参与了决策,且依据可回溯。

## 5. 情绪三层(C' 组:消息面量化并入)

新闻/舆情/政策三个来源各自用 LLM 判方向与强度,聚合成层净情绪(−1~1),再**按信源可靠性加权**成总净情绪分:

```
总净情绪分 = 0.5×新闻 + 0.3×政策 + 0.2×舆情    （缺某层则丢弃该层、对存在层重新归一）
```
- **权重依据**:新闻(事实)> 政策(方向)> 舆情/股吧(散户噪声)。
- 每层净情绪 = Σ(方向 × 强度) 归一;方向 利好+1/利空−1/中性0。
- 得到的总净情绪分按第 4 节阈值(±0.2、权重 2)并入买卖倾向。

> **实例**:688521 → 新闻 +0.6(偏多)、舆情 −0.5(偏空)、政策 +0.619(偏多)→ 加权净 **+0.386** → 触发"情绪偏多 +2"。

## 6. 选股 & 回测(D 组)

### 6.1 预设选股(`screener/screen.py`,规则为合理默认,待用户 N1 细化)
| 预设名 | 命中条件 |
|---|---|
| 超跌反弹候选 | 有拐点标签 且 拐点评分 ≥ 25 |
| 主力吸筹 | 主力连续净流入 ≥ 2 天 且 今日净流入 > 0 |
| 趋势强势 | 趋势评级得分 ≥ 30 |
| 质地优不高估 | ROE 达标 且 PE 有效 |
| 反弹+资金共振 | 「超跌反弹候选」且「主力吸筹」同时满足(AND) |

### 6.2 可注册策略(`strategy/registry.py`,`@strategy` 装饰器,三类)
- **信号 Signal**:如「均线金叉」——短均线(5)上穿长均线(20)→ 买,下穿 → 卖,其余 持;逐日输出,喂回测。
- **评分 Score**:如「买卖倾向评分」——只读汇总记录里已算好的买卖倾向。
- **选股 Screen**:上面 5 个预设自动注册进来。

### 6.3 回测(`backtest/`,BT.1 信号回测已实现)
walk-forward 逐日切片、**t+1 成交**(信号次日生效)、单边成本 5bp、对比买入持有基准;**严禁未来函数**(有专门测试锁死)。选股回测 BT.2 待历史快照工程。

## 7. 端到端流程(从数据到"预期涨跌")

```
① 采集   K线/基本面/公告/资金流(数值面) + 新闻/股吧/政策(消息面),按日期落盘
                    │
② 技术分析 technical.py:算 MA/MACD/KDJ/RSI/BIAS/量比 → 趋势评级 / 拐点 / 超买超卖(A组)
                    │
③ 情绪    event.py:三层 LLM 打分 → 加权净情绪分(C'组)
                    │
④ 预测    predict.py:
            ├─ 支撑/压力位(swing pivot)……………………… 关键价位
            ├─ 止盈止损位 = 现价 × (1 ± k·ATR%·√N)……… 该跌到哪止损/涨到哪止盈(B组)
            ├─ 情景预测 = 历史 N 日收益 q10/q50/q90 + 上涨概率… 大概涨跌多少、概率多大(B组)
            └─ 买卖倾向 = 多因子打分(含情绪)……………… 偏买入/偏卖出/观望(C组)
                    │
⑤ 组装    serialize.py:汇成中心记录(过契约校验)→ 按日期存储
                    │
⑥ 聚合    portfolio/screener:组合共性 + 预设选股(D组)
                    │
⑦ 展示    Web 个股页动态呈现:K线+止盈止损线 / 情景表 / 三层情绪 / 买卖倾向
```

## 9. 诚实性与局限(务必知悉)

- **概率 ≠ 保证**:情景预测是**历史频率**,止盈止损是**波动率外推**,都不预测未来。市场变了、历史不重演,数字就会失真。
- **选股规则是默认值**:第 6.1 的预设阈值为自主开发的合理默认,**待用户按实际口径细化(N1)**;股票池目前是固定自选池(开发期用随机 10 只样本)。
- **情绪依赖 LLM**:三层情绪需 LLM 打分,缺层会降级重归一(不崩但信息变少);舆情来自股吧,信噪比低,故权重最低。
- **数据可得性**:资金流数据受东财限流影响可能缺失(缺则该因子不计分)。
- **这不是投资建议**:本工具仅做信息整合与统计辅助,一切决策与风险由使用者自负。
