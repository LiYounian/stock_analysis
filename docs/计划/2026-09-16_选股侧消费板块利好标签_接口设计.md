> 统筹窗口维护。对接板块线《2026-09-16_消息驱动板块选股_一入一出_设计.md》(暗号 回声-0914) §3/§8.3。

> 定位：本文只定义**选股侧怎么消费板块线产出的标签+候选**，不重造上游（一入一出在板块线）。

## 0. 立靶：与被证伪的接法划清界线

| | 已证伪·弃（P3 粗暴自动接） | 本接口（消息驱动催化候选） |
|---|---|---|
| 候选来源 | 量价榜 + 板块加分**机械重排** / roster 补涨**覆盖式 ADD** | **消息催化**锁定利好板块 → 板块内龙头+跟涨候选（催化=用户认的 α 源）|
| 进池方式 | 自动改打分、无脑补入全部补涨 | 候选**进候选池**、仍走逐票催化×量价研判 + 回踩限价入场 |
| 纪律 | 板块信号直接改选股结论 | 板块标签**只提供候选来源**，不改你的逐票否决/入场纪律 |

**核心区别**：候选来自**消息催化**（一个 α 来源），不是来自**板块量价重排**（证伪的非 α）。这是能接的根据。

## 1. 接口契约（板块线产出 → 选股侧读取）

**定案（2026-09-16·板块线 M2 定稿·用户三轮细化+真跑验证过）**：板块线把 `消息驱动` 块**扩进 `data/analysis/<date>/sector_focus.json`**（认同选股单一源，不另起文件）。**v2 描述性 schema：强弱走文字分级、不打数值分；关键事件做分级 dict**：

```
消息驱动:
  as_of: "<ISO8601 产出时刻>"        # 防未来：选股只认 as_of ≤ 决策时刻的信号
  利好板块:
    - board: "申万一级板块名"
      tag: "利好"                     # 本块只列利好；利空另走规避（§3.3）
      强弱: "强" | "中" | "弱"         # 文字分级(非数值 strength)
      关键事件: [{时间, 事件, 方向, 可信度, 影响程度, 执行度, 来源}]  # 分级 dict、一手来源+执行度
      持续性: "近2周持续利好/一次性…"   # 催化持续性
      时效: "…"                       # 消息新鲜度
      可靠性综述: "…"                 # 一手性/研报需核 等综述
      依据: "触发的政策/新闻/龙头催化摘要"   # 人工可核、留痕
      龙头候选: [{code, name, 已动: true/false}]        # 已动=当日涨幅≥3%(预注册)
      跟涨候选: [{code, name, 联动依据: "同板块补涨先锋·龙头已动·后排待接力"}]
```

**硬字段约束**：候选必带 `code`（6位）；`关键事件` 每条必带 `来源`（一手性可核）；`已动` 按**当日涨幅≥3% 预注册**判（供跟涨联动触发）。

**用户补充口径（关键·2026-09-16）**：选股用法 = **支撑路径、非直接触发**——利好板块 → **筛形态好的 + 反选剔除利空/年报差 → 深度分析 → 仍走整体策略**。即：板块利好标签是**候选来源 + 过滤器 + 研判上下文**，不是"利好就自动选"。这比"直接触发"更稳，与 §3 进池口径（进候选池仍走逐票研判、不改打分）一致。

## 2. 消费时点（两条选股线，各自 as-of）

- **晚间线（18:36）**：读**当日 17:30 sector_daily 产出**的 `消息驱动` 块（as_of≈17:30 ≤ 18:36 ✓）。这是主消费点——同日板块研判喂当晚选股。
- **午盘线（11:35 noon_fullA）**：当日板块信号未出（17:30 才产），读**上一交易日**的 `消息驱动` 块，标注"隔夜信号、需当日盘中消息二次确认"；不把隔夜利好当盘中新催化。
- **缺失守卫**：`消息驱动` 块缺失/为空 → 整段忽略、按常规选股（同 P-a 既有守卫）。

## 3. 候选如何进池（不改否决/入场纪律）

1. **利好板块 → 龙头候选进候选池**：tag=利好 且 strength>阈值 且 该龙头有个股级催化 → 龙头**进候选池**（带"消息催化"标签）。仍走：逐票基本面 veto 研判（催化强时不因超买/winner_rate 一刀切否，承接"普跌日不反动量"锚）+ **回踩限价入场、不追高开**。
2. **跟涨候选进"联动观察"档**：龙头**已动**（`已动=true`）时，同板块跟涨候选进**联动观察档**（不与主候选抢名额、优先级低于有自身催化的票）；入场更严（龙头确认续强 + 回踩限价）。**联动假设未验证前只作观察补充、非主线**。
3. **利空板块 → 规避提示**：tag=利空 → 该板块候选打规避提示（叠加 C 线宏观板块规避），非硬删、由逐票研判定。

## 4. 防未来 / 防偷看（硬要求）

- **as-of**：选股只消费 `as_of ≤ 决策时刻` 的信号（午盘读隔夜、晚间读当日 17:30）；绝不用未来信号。
- **预注册**：龙头进池阈值（strength 阈 + 需个股催化确认）、跟涨触发条件（龙头已动+续强+回踩）**先写死再上**，不对既往赢家（通鼎/双星/奥士康）调参。
- **non-gating 先行**：接口先记 forward（消息触发候选 vs 基线，次日/T+5 绝对收益，按"消息利好确认日/龙头催化强度/是否联动"分层），**不 gate 生产选股**；攒够跨 regime 样本 + 显著再由统筹 surface 用户拍 gated 上线。
- **联动单独验**：跟涨档 forward 单列，验"条件在消息利好而非低位"（防把防守低β补涨混进来——那是已证伪的非 α）。

## 5. 复用 vs 新建（选股侧）

- **复用**：P-a 既有 sector_focus 读取通道（§2C 指引段）、催化优先锚（§2B）、回踩限价入场纪律、position_ledger（持仓/联动跟踪）。
- **新建（选股侧·待接口定稿后）**：① `消息驱动` 块解析 + as-of 守卫；② 龙头候选进池 + "消息催化"标签；③ 跟涨"联动观察"档；④ forward 记分器（消息触发候选分层跟踪）。
- **不新建**：一入一出（新闻采集+影响分析+标签生成）全在板块线，选股侧只读标签。

## 6. 分期（与板块线 M1–M4 对齐）

| 板块线 | 选股侧对接 |
|---|---|
| M1 定向龙头新闻+影响分析 | —（等标签产出）|
