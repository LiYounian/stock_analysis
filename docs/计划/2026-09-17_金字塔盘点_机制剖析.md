### 1.2 思维逻辑 / SOP（选股怎么从全A收敛到 5 只）

三层漏斗（经验沉淀 + SKILL 明确）：

1. **候选召回**（用 B 线程序产物）：读**全部策略视图**，按 ①多策略命中 ②单策略极值 ③多样化 三准则拉 shortlist。今日 shortlist 由"三命中集 + wr>99 集 + 有 per-stock json 的深度 6 只"取并。
2. **权重微调（2B 已验证证据，非硬门控）**：
   - **普跌日不反动量**（最高优先纠偏）：绝不因超买/高 wr/高获利盘系统性否决动量票；
   - **半导体多因子命中降权**（selection-α 证实拖累次日 α −1.26%）；
   - **winner_rate 分档**：wr 80–95 中段**降权**（今日 001326 wr93.18 落此段→规避）；**wr>99 不降权**、照常入选但走 **gap-fade 回踩限价**入场、D+1 了结不持 D+2（H2 回测坐实）。
3. **逐票深度研判（SOP 六步）**：定性 → 数据层（per-stock json 或 technical.compute + 合议专家分）→ **强制消息面**（baidu_news + 必要 WebSearch）→ 数据×消息面交叉 → 深度结论（①买入表态②明日情景③1日/5日方向置信④分 α/β⑤我vs系统⑥盯点）→ **判对之后三条必填**（⑦退出纪律 ⑧方向前提=触发信号 ⑨盯点单问化 + 固定一问可转债/定增/解禁）。

## 二、程序选股（B 线）

> **重要澄清**：B 线不是"一个固化打分器"，而是**两层**：
> - **B1 · 固化策略打分层**（`tools/pipeline/screen_*.py` + `tools/strategy/`）：一批**写死阈值**的确定性筛选器，每天各出一张榜单/打分视图。**这是真正"固化/死规则"的部分**。
> - **B2 · selection_synth（S5·双路并集）合成器**（`tools/analysis/selection_synth.py`）：注意它**不是固化打分**——它是一个 **DeepSeek-LLM 程序化合成器**，把 B1 的策略线候选 **∪** 板块消息线候选喂给 LLM，程序化产出《今日选股》。定位见其文件头 docstring（`selection_synth.py:1-32`）。
>
> 换言之：金字塔里 **B1=塔基固化召回层**，**B2=一个"轻量 LLM 决断层"**（与 A 线的重量级 Claude 分析师并行的另一条 LLM 路径，但 B2 更程序化、给 DeepSeek 喂结构化槽位、KPI=绝对收益 Model A→D+1 回踩限价→D+2 卖出）。

### 2.2 谁在编排？三个独立入口，别混为一条流水线

|---|---|---|---|
| **`tools/run.py::run_screen_all`**（`screenall` 命令，`run.py:1123-1366`）| **真正每天批量跑全部 screen_*.py 的主编排** | `data/analysis/<日>/*.json` 各策略 view（10+ 在产 screener：council/s02/momentum/semi_factor/max_range/volume/strong/reversal_turnover/conditional_rank/deduct_quality）| `tools/scheduler.py`(apscheduler) + launchd |
| **`tools/analysis/selection_synth.py`**（S5·双路并集）| **DeepSeek LLM 程序化合成器**——不读上面落盘的 view，而是**自己二次重跑** council+momentum+strong+trend_template（`selection_synth.py:280-332`），∪ 板块消息线，交 LLM 打分 | `data/analysis/<日>/今日选股_<日>.md/.json`（程序双路并集选股，即复盘里的"程序双路并集72票"）| `selection_synth_run.py` CLI 单独触发（**未进 scheduler 定时**）|
| **`tools/analysis/write_picks.py`**| **A 线专用**结构化落盘/校验器，输入是 **Claude 分析师逐票研判**（不吃 selection_synth 产物）| `data/analysis/<日>/每日选股.json` | 由 A 线 SKILL 末尾调用 |

⇒ 每天其实并行产出**三套东西**：A 线 `每日选股.json`（Claude 研判）、B0 各策略 view、B2 `今日选股.json`（DeepSeek 合成）。**A 线与 B2 是两条平行的"LLM 决断线"**，会被复盘横评（主样本 vs 程序并集）。

### 2.3 B2 · selection_synth（S5·双路并集）合成机制

版本 `s5-dualpath-2026-09-17`，主编排 `synthesize()`（`selection_synth.py:775-897`）。

- **合成机制 = 集合并集（union）+ 逐票喂 LLM 打分，不是加权/投票/ML 模型**。`_merge_candidate`（`:746-772`）按 code 去重，`来源` 用 **set** 累加（策略直选/板块催化/两者兼有，`:53-55/:589-595`）。
  - **(a) 策略线**（主体·全A·不被板块闸门）：`run_council_universe` 全A council top-12（`STRATEGY_TOP_N=12`）+ 可选 momentum/strong/trend top-K。
  - **(b) 板块消息线**：读 `sector_focus.消息驱动.利好板块` → 板块内龙头/中军/跟涨（`gather_candidates`），规避板块池票打降级。
- **排序分是 LLM 给的、不是程序算的**：`synthesize_group`（`:693-742`）把每票多维 payload（策略面 council 综合分[-1,1]/方向/财报红旗/龙虎 + 板块面 + 形态）交 `client.extract(DeepSeek, SELECTION_SCHEMA)`，LLM 返回每票 `档∈{推荐,观察,剔除}`+`建议分0-10`+双依据理由+`入场方式`枚举，按建议分降序。
- **价位回填=程序算、LLM 只选类型（关键防线，堵 LLM 抄数字）**：`fill_entry_exit`（`:355-425`）——LLM 只从 `ENTRY_METHODS(回踩MA5/回踩MA20/回踩前低/突破确认/缩量企稳/突破新高确认)` 选类型，程序据 form 的 ma5/ma20/前低算出 挂单价/止损价/不追高上限；**单调性夹逼铁律**（`:409-420`）：回踩 `entry≤现价`（不追高）、`stop<entry`、`cap≥entry`；LLM 文字里的数字一律忽略。
- **硬纪律/硬门控（程序保证，覆盖 LLM）**：
  - `hard_veto_reason`（`:628-650`）：财报高危红旗≥1 / 龙虎榜否决 / 涨停不可买 / 极高位高抛压(获利盘·pos60≥0.95贴高) → 强制剔除；
  - `apply_hard_discipline`（`:653-673`）：反选命中→强制档=剔除、建议分≤2；跟涨角色封顶"观察"；
  - `apply_avoid_downgrade`：规避板块票降级；
  - **强势不回踩旁路**（`bypass_*`）：8 条 AND 死判据，**默认关闭 `enable_bypass=False`**（须过回测才放行）；
  - 防未来：量价/财报 `_asof_slice` 只用 ≤date，消息块 as_of 晚于决策则忽略。

### 2.4 write_picks.py（A 线的结构化落盘/校验器）

职责=**只固化可程序化的三件事**（客观回填 / 结构化落盘 / 校验），"一切研判仍是 Agent 的活"（`write_picks.py:5-12`）。

- **客观回填**（`_backfill_pick :152-181`）：名称/行业/close/pct_chg 从 `data/analysis/<日>/<code>.json` record 回填；**策略 join**（`_join_strategies :123-149`）据 Agent 的 `strategies_hint` 到当日各策略 view 榜单用 code 反查 **1-based rank + score**（榜单位次权威、Agent 不手打分值）。
- **校验闸门**（`picks_schema.validate_picks`）：
  - 枚举：`type{买入候选/检验样本/规避}`、`stance{买入/可参与/观望/规避}`、`dir/conf/sentiment_quality` 全枚举；
  - 必填非空：name/close/pct_chg 回填后仍缺即报错（防"远端只有代码"）；
  - **情绪质量闸门**：`sentiment_quality∈{unknown,missing}` 盲区票**不得给 stance=买入、不得含"首选"**；
  - **防未来**：`meta.as_of > pick_date` 报错 + record.as_of 晚于 pick_date 软告警；
  - **PICKS 一致性**：md 锚点 code 全集 == picks[].code 全集，同源渲染；
  - 其它：code 6 位正则去重、skipped 态 picks 必空、buy_rank 1..N 连续、不给方向时置信须"-"。
  - **校验不过非零退出、绝不带错落盘**（`write_picks:368-372`）。
- **字段语义**：`entry_type∈{a具体价/b集合竞价/c盘中条件/open开盘价}`；`P_entry/P_dip` 数值；`expected_close_positive_prob∈[0,1]`；`entry_rule/target_line/stop_line` 文本透传。

### 2.5 B 线优点 / 缺点（代码证据）

**优点**
- 全 A 覆盖、不被板块绑架（`selection_synth.py:280-295` 全A票池 top-N，双路并集设计）。
- 客观字段/价位**程序回填**，根治手打错 + 堵 LLM 抄数字（write_picks `_join_strategies`；synth `fill_entry_exit:369` + 单调夹逼 `:409-420`）。
- 硬纪律 defense-in-depth 覆盖 LLM（`hard_veto_reason` + `apply_hard_discipline`，语义锁进 tests 防 prompt 重写误删）。
- 强 schema 校验 + as-of 防未来贯穿（picks_schema；`_asof_slice`）。**高度可复现、可回测、可移交中小模型**。

**缺点（固化 / 死规则——"非常固化"具体在这）**
- **阈值大量硬编码、predict-registered 不对既往赢家调参**：旁路量比 1.0/2.5、pos60 0.50/0.85、极高位 0.95、TOP_N=12/K=8（`:344-348/:623-625/:57-58`）——**一刀切、不随市况自适应**。
- **入场方式→价位是死映射表**（`fill_entry_exit:384-408`）：固定 ma5/ma20/前低，无个股波动率/流动性自适应。
- **旁路整条默认关闭**（`enable_bypass=False`）：强势追高能力被冻结待回测。
- **B2 合成完全押单次 LLM 打分、无集成/加权兜底**：`建议分` 全来自 `client.extract`，LLM 失败即整组降级"观察·建议分None"，程序侧无独立排序分 fallback；且 **council 综合分与 LLM 建议分口径割裂**（council 分只作文本喂 LLM，最终序不直接用它）。
- **跟涨角色被死规则封顶"观察"**（`:670-672`），形态再强不进主选。
- **B1 固化 screener 是纯量价/财报因子布尔或 z 打分**：多数无自适应、下线策略(box/s01/D)靠人工判负存档，不是数据驱动动态淘汰。

### 3.3 给金字塔框架的三点提炼

1. **塔基（B1 固化 screener）**：全A、确定性、可回测的候选召回，是两条 LLM 线的共同"票池来源"。缺口=资金流/户数/消息面/自适应。
2. **塔身（B2 selection_synth）**：程序化把"策略线∪板块消息线"喂 DeepSeek，价位与硬纪律由程序锁死、LLM 只做选档打分——**是"可复现的轻决断"**，但缺个股原始新闻 + 经验 + β，且押单次 LLM。
3. **塔尖（A 线 Claude 分析师）**：唯一接入**原始消息面 + 经验沉淀 + market_forecast/capitulation + 供给面 + 逐票退出纪律**的重研判层。金字塔若要合一，A 的"消息面/经验/β"维度与 B 的"固化召回/程序回填/强校验"骨架互补——**A 提供 B 缺的软信息与自适应，B 提供 A 缺的复现性与纪律锁**。

## 四、一句话总结

- 项目现有**三套每日选股产物**并行：A 线 `每日选股.json`（Claude 重研判）、B0 各策略 view（`run_screen_all` 固化）、B2 `今日选股.json`（DeepSeek 双路并集）。
- **A 线数据消费最广**（策略+per-stock全字段+**强制原始消息面**+板块+市场预测+**经验沉淀**+供给面+退出纪律），但难复现、依赖 LLM 会话。
- **B 线高度可复现/可回测/可移交**，但**非常固化**（阈值一刀切、无个股新闻/经验/β、B2 押单次 LLM 无兜底）。
- 金字塔合一的关键互补：**A 的软信息(消息/经验/β/自适应) × B 的骨架(固化召回/程序回填/强校验/价位锁)**。

## 附录：per-stock 深度 json 数据字段全貌（两线共享的数据层）

top-level keys（以 601061 为例）：`meta / snapshot / valuation / fundamental / financial / signals / prediction / sentiment / fundflow / chip / consensus / holder / tick / lhb_veto / financing / events / council(合议) / 合议对账 / provenance`。

- **snapshot**：close/pct_chg/ma/macd/kdj/rsi/bias20/vol_ratio/vol_state + 口径日期/新鲜度
- **sentiment**：利好数/利空数/样本数/失败数/净情绪分/**质量(ok/partial/unknown/missing)**/覆盖率/三层/持续性研判 —— 质量盲区(unknown/missing)时净情绪=null 非 0.0，硬纪律：盲区票表态封顶降一级
- **council(合议专家分)**：experts/default/情绪质量/config + `合议对账`(分歧/程度/council方向/per_stock倾向)
- **financing(固定一问)**：可转债/定增/解禁/约束提示 —— 供给面中期变量
- **fundflow/chip/holder/tick**：主力净流入/获利比例/股东户数环比/主买占比 —— 多为陈旧口径(09-09~09-14)，盯点标"可得时核"
- **provenance**：每个维度的取数来源与口径（防未来函数）
