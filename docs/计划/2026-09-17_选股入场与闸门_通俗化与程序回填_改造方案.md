## 0. 一句话
把选股结果里的**入场价/止损价从"大模型写文字"改成"程序回填数值"**，输出统一成**通俗金额格式**（XX元挂单 / XX元止损 / 高于XX元不追），并把入场闸门**明确拆成"价位层(程序·静态)+时机层(实时·盘中)"两层**——大模型只做文字判断、绝不碰数字。

---

## 1. 背景（用户 2026-09-17 五点诉求 → 收敛）
用户对选股输出提了 5 点，收敛成一条主线：**数值/纪律/时机都交给程序（可复现），大模型只做文字判断、不生成任何数字**。具体：
- (#3) 入场/闸门要**通俗易懂、给金额买点**，别写"回踩站稳5日线"这种黑话。
- (#4) MA5 等**已是程序算的**（`selection_synth.py:204 np.mean(c[-5:])`，大模型只读不生成）——现状正确；**但输出里的入场价是大模型抄写 payload 数字**（schema 自由文字），有抄错风险，需堵。
- (#5) MA5 做闸门**当"价位"用不滞后（开盘前已知、当日可用）、当"趋势信号"用有滞后**；"当日买入时机"需实时盘中信号，MA5 给不了 → 闸门要分两层。

## 2. 现状问题（3 个）
| # | 问题 | 位置 |

## 3. 改造设计

### 3.1 入场/止损 **程序回填**（堵 P1·核心）
**schema 变更**：LLM 不再输出价位数字，改为输出**入场方式枚举 + 文字理由**，价位由程序填。
- `SELECTION_SCHEMA.个股[]` 改：
  - 删 `入场`(自由文字) / `止损`(自由文字) 的"写价位"职责；
  - 新增 `入场方式 ∈ {回踩MA5, 回踩MA20, 回踩前低, 突破确认, 缩量企稳}`（LLM 只选类型，据形态判）；
  - 保留 `理由/风险/档/建议分`（纯文字判断，LLM 擅长的）。
- **程序回填函数** `fill_entry_exit(stock, form)`（新增于 `selection_synth.py`）：
  - 据 `入场方式` + 程序已算好的 `form.ma5/ma20/前低/现价` → 计算**挂单价/止损价/不追高上限**三个数值；
  - 规则（初版）：
    - 回踩MA5 → 挂单价=ma5；止损=ma20；不追高上限=D收盘价；
    - 回踩MA20 → 挂单价=ma20；止损=前低(min low 近20日)；不追高上限=D收盘价；
    - 回踩前低 → 挂单价=前低；止损=前低×0.98；不追高上限=D收盘价；
    - 突破确认/缩量企稳 → 挂单价=D收盘价(回踩确认位)；止损=ma20；不追高上限=D收盘价×1.02；
  - **LLM 若仍在文字里写了数字 → 程序忽略、以回填为准**（defense-in-depth，同 `hard_veto_reason` 思路）。
- 形态数据不足（`form.数据不足`）→ 价位置 None + 标"数据不足、人工确认"，不编。

### 3.2 **通俗化金额**输出格式（堵 P2）
所有选股产物（`今日选股_*.md` 主选深度表 + 统筹精选）统一成**操作卡**格式：
```
东芯股份 688110 ｜ 推荐 7.0
  买点：112–115 元 挂限价买（回踩MA5，不追高）
  止损：跌破 112 元 走
  红线：高于 115.8 元 = 追高，别买
  信号：昨 +4.8% 放量·量比0.99·距20高-6%·获利37%
  理由：四专家共振+低位放量启动（策略依据+板块依据）
```
- 价位一律带"元"单位、给区间（挂单价 ~ 挂单价×1.005）便于挂单；
- 必带"红线：高于 X 元别买"（= 不追高上限，操作最防坑的一句）。

### 3.3 入场闸门 **两层**（堵 P3）
产物里明确标注，两层各司其职：
- **(a) 价位层 — 程序·开盘前定死·当日可用**：ma5/ma20/前低 → 静态挂单价/止损价/不追高上限。**MA5 做价位不滞后**（昨收及之前算的固定数，今日照挂即可）。← 本轮落地。
- **(b) 时机层 — 实时·盘中·归日内线**：现价站上均线 + 量比>1 + 不追涨停/封单确认 → 回答"此刻扣不扣扳机"。**需实时分时数据**，是 `tools/pipeline/intraday_*` 日内线的职责。← 本轮**只定义接口/在产物里点明"时机层看盘中、见日内线"**，实际实时接入随日内线整改（那条线正待"锁一版连跑"）。

> 结论写进产物脚注：**"均线价位=开盘前可用的静态挂单闸门；当日盘中时机需配实时信号，见日内线（暂未接入，先按价位层挂单+不追高操作）。"**
