# 行业财报分析:扩行业覆盖 + 行业归属消歧(方案)

> 2026-08-30 · 统筹 · 用户认可"先地基线+试点1族"。归位:财报=可回测的**基本面正交信号**,服务 WI-6 消息面/基本面融合;诚实预期其价值可能更偏**避暴雷(风险侧)**而非纯 alpha(承 PEAD 粗超预期 flag 叠技术候选池不达标的教训——但深度行业财报是不同的、更细的轴,值得严谨试)。

## 一、现有家底(已核验)
- `tools/analysis/financial/industry/`:7 个行业专家(银行/汽车/电子/计算机/通信/传媒/交通运输),`__init__.py` 的 `_discover/get_expert` 按申万一级 KEY **自动发现**。
- `analyzer.py`:路由 `meta.industry→industry_map.to_sw→申万一级→get_expert`,支持 `as_of`。
- `industry_map.py`(行业名→申万一级 31)、`industry_history.py`(`industry_at` 按 as_of 取当时行业)。
- 缺口:① 申万一级 31 个仅 7 个有专家、24 个走通用兜底;② **行业归属会时变/模糊/市场定义≠正式分类**(蔚蓝锂芯锂电池被当"新能源/锂矿"交易随锂价波动;宇树机器人硬件vs软件定性不清)——现路由只取单一行业、不看市场怎么定义。

## 二、方案三部分
- **A 扩行业**:31 申万一级按自选池覆盖+权重排优先补,每行业专用分析器+专属财报重点(银行看NIM/不良;汽车看销量/毛利/产能;科技看研发/增长;消费看周转/品牌;医药看管线/集采;地产看预收/杠杆;周期看产能/价差)。
- **B 行业归属消歧(新·核心)**:①时变正式行业(industry_history as_of)②市场定义/概念标注(市场当它什么概念/板块交易)③多行业模糊→标记+候选行业列表(多视角分析留后续)。路由支持一或多行业。
- **C 执行**:地基线(消歧+路由+复用模板)与试点族分析器**并行**(文件不相交,靠 get_expert 自动发现组合);验证后按族铺开其余。
