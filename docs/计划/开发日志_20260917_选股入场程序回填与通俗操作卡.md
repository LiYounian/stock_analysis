## 本轮做了什么（为什么）

堵"大模型写价位数字"漏洞：入场价/止损价/不追高上限从 **LLM 自由文字** 改成 **程序回填数值**，
大模型只据形态选**入场方式枚举**、绝不产任何数字（消除抄写 payload 数字的转写风险）。
选股产物从量化黑话表改成**通俗操作卡**（金额买点/止损/不追高红线/信号/理由），并把入场闸门
**明确拆成价位层（程序·静态·开盘前可用不滞后）+ 时机层（实时·盘中·归日内线·本轮暂未接入）**两层。

改动集中在单文件 `tools/analysis/selection_synth.py` + 测试 `tests/test_selection_synth.py`。

## 回填映射（初版规则·方案 §3.1；判据固定不对既往赢家调参）

- 回踩MA5 → 挂单=ma5；止损=ma20；不追高=现价
- 回踩MA20 → 挂单=ma20；止损=前低；不追高=现价
- 回踩前低 → 挂单=前低；止损=前低×0.98；不追高=现价
- 突破确认/缩量企稳 → 挂单=现价；止损=ma20；不追高=现价×1.02
- 入场方式缺/非法 → 兜底回踩MA5（最保守）并回写留痕

## 测试（22 passed·断言锁语义·守则6）

- `test_fill_entry_exit_各入场方式精确值`：各方式回填三价位=程序精确值。
- `test_fill_entry_exit_LLM文字数字被忽略以回填为准`：LLM 文字塞 999/888 被忽略，以 ma5/ma20 为准（**大模型不产数字**语义锁死）。

- `test_render_operatecard`：md 操作卡含"元"+"红线：高于X元别买"+两层闸门脚注。
- 回归：既有硬纪律/冒烟/双路并集 13 项全绿（`hard_veto_reason` 不受影响）。
