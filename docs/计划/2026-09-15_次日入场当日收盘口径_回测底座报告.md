## 0. 一句话结论（gate）

**有条件可行。** "不默认开盘价、改用**估量的限价回踩入场**"这套口径**方向正确、且稳定优于"随便买开盘"**（样本内 + OOS、跨候选流一致）；但**口径本身的无条件净期望很薄（扣成本后 ~+0.05%/单量级）、且逐年衰减**，"随便买开盘"近年已是**净亏**。故该口径是**必要的入场质量改进，但不能单独当盈利来源**——必须与真正的**选股 α** 叠加（动量代理×限价回踩组合达 ~+0.16% 净/单、α+0.33%、OOS 稳）。**弱市避高 β 这条在"次日当日收盘"这个横期上不成立**（数据反而略反向），建议 β/α 只做归因、**不要**做成选股硬否决。

## 1. 口径与样本

| 项 | 取值 |
|---|---|
| 价格 | 主仓 `data/master/kline/*.parquet` 只读，5173 有效票（排北交所），2018-01-02→2026-09-14 |
| 采样 | 按票内 index `stride=2` 抽样 → **全A 448.6 万 (票,信号日) 观测** |
| 持有窗 | 信号日 D → **D+1 入场 → D+1 收盘了结**（当日双出） |
| 市场基准 | 全A**等权** `open→close`（`mkt_ir`，对齐持有窗算 α）；`close→close`（算 β） |
| 成本 | 默认 **10bps 往返**（含滑点近似）；另标 0/20bps 敏感性 |
| OOS | 早段 2018-01~2022-12 / 晚段 2023-01~2026-09，分开汇报看稳定性 |
| 防未来 | 入场价/成交/β/regime 只用 ≤D（β、regime as-of）或 ≤D+1 已确定 K 线；`close[D+1]` 仅作标签，绝不回喂 |

**成交模型**：`marketable`（挂买入限价 P：`open≤P` 立即成交于 open〔价更优〕；否则 `low≤P` 成交于 P；否则未触发）为**主口径**（这才是真实限价单行为）。`doc`（设计 §3.1：`low≤P≤high` 判成交、价取 P）作对照——见 §6，**doc 口径在 P≥open 时系统性偏悲观**。

**诚实边界（务必连同结论一起读）**
- **历史 live 选股不可回测**：canonical `每日选股.json` 仅 2026-09-14 起 1 天。故本底座用**全A基准 + 可复现 as-of 策略代理**（动量 / 反转，**非** live 选股）；"分策略看"是代理口径。
- **T_obs（早盘 vs 全天）历史不可回测**：分钟数据仅 8 天（2026-09-03~09-14）。日线 K **无法区分**"9:30–10:00 触及"与"全天触及"。主回测按**全天触及**成交——这是**触发率的上界**；真实早盘窗只会更难触发 → 实盘触发率更低、薄边际更脆（详见 §5）。
- **未建模涨跌停不可成交 / ST / 退市幸存**：一字跌停里挂 P 实际买不到、一字涨停买不进——当前按 `low≤P` 乐观计。会**高估**深回踩档与开盘基准档的可成交性。

> `dip_pc_0.03` ≡ `limit_pc_0.03`（同公式），略。

**读表**
1. **"买开盘"没有 edge**：胜率 48.5%（<50%），毛收益近零，扣成本后**晚段转负**。→ 数据**支持设计"不默认开盘价买"**的主张。
2. **限价回踩是正确方向且最优**：`limit_pc`（挂在昨收～昨收−1%）净期望最高、样本内胜率抬 1.3–2.2pt、α 由 0 抬到 +0.1~0.3%。**limit_pc_0.0 / 0.01** 是帕累托最优（触发率 92%/62% 尚可执行）。
3. **深回踩（−2%/−3%/−5%）不是更好**：条件 α 抬升是**机械的**（见 §4 警告），但**净均收益不再提高、晚段 OOS 转负、触发率坍塌**（36%→7%）。深回踩只宜作**可选次级 `P_dip` 加档**，不作主入场。
4. **`limit_open`（挂开盘×(1−k)）净期望为负**——挂在开盘下方一个固定折扣，触发即机械便宜 k，但把"没跌下来的强势日"（往往是上涨日）过滤掉了，净反而差。**不建议**。
5. **薄且衰减**：最优档净期望 ~+0.05~0.07%/单（样本内），晚段（2023+）逼近 0。**口径本身不足以独立盈利**。

## 3. β 脆弱性验证（回应用户第 1 点 / 设计 §4）——**核心 honest finding**

按 **regime_asof**（信号日 ≤D 已知的市场趋势，全A等权 5 日累计三分位分 普跌/震荡/普涨）× β 桶（≤D as-of 60 日 β，<0.8 低 / >1.2 高）分层：

**open 入场：**

| 分层 | n | 绝对胜率 | 净µ | β拖累占亏损 |
|---|--:|--:|--:|--:|
| 弱市·低β | 45.9万 | 48.8% | −0.011% | 23.0% |
| **弱市·高β** | 45.6万 | **51.4%** | +0.057% | **46.2%** |
| 强市·低β | 46.4万 | 45.7% | −0.044% | 18.0% |
| 强市·高β | 46.0万 | 47.3% | +0.030% | 34.7% |
| **弱市 高β−低β 胜率差** | | **+2.5%（z=24.4）** | | |

**结论（与设计假设相反，需据此修正设计 §4）**：
- **"弱市里高 β 票绝对胜率更差"在"入场→当日收盘"这个横期上 NOT SUPPORTED**——**恰恰相反**：弱市（=已下跌/超卖态）里高 β 票次日当日胜率**更高**（+2.5pt, z=24.4），因为**跌透后反抽，高 β 弹得更猛**。limit_pc_0.01 下该差缩到 −1.2%、limit_pc_0.0 下 +1.4%——**符号不稳、幅度极小**，不构成可用规则。
- **β 拖累是真的、但只体现在"亏损单的成因"上**：高 β 亏损单里 β 拖累占比 46%（低 β 仅 23%）——即高 β 票**一旦亏，主要怪大盘**。但它**赢的次数更多**，两头相抵，胜率不吃亏。
- **可操作含义**：**不要**把"弱市避高 β"写成选股硬否决——在这个次日当日横期上过滤高 β **不会**提升（甚至略降）绝对胜率。**β/α 保留为归因手段**（如设计所言"α/β 是达成绝对为正的手段"），但**不升格为 veto**。（多日持有横期上 β 过滤或另有价值——超出本底座范围。）

> 注意区分：**当日 contemporaneous 下跌日**（m<0）高 β 当然亏更多（β·m<0，机械），βdrag 分解已证；但**信号时点已知的"弱市 as-of"**（趋势性超卖）对**次日**反而利多高 β。选股拿到的是后者（as-of），故过滤无益。

## 4. ⚠️ 关于"配对 vs open"巨额 t 值 = 机械假象（防误读）

配对表里 `limit_pc_0.03 vs open` mean_diff +2.34%、`limit_open_0.02 vs open` win_diff 100%、t 值 800~70000——**这些不是可交易 α**，是**条件成交的机械偏差**：只在"当天跌到了 P"的子集里成交，`close/P−1` 当然天然更高；`limit_open` 挂开盘下方 k 则成交价机械便宜 k。**真正可信的指标是各档的边际净均收益 + 胜率 + OOS 同号**（§2），不是配对 t 值。本报告结论一律以边际净 + OOS 一致性 + 经济幅度为准，不采信配对/单侧 z 的名义显著性（同日横截面相关会把 t/z 灌爆）。

## 5. 观测窗 T_obs 敏感性 —— 数据受限，方向性给论

- 分钟级 intraday 仅 8 天，历史不可做早盘/全天对比。**日线只知"当天是否触及 P"，不知何时触及**。
- **方向性可断言**：把 T_obs 从"全天"收紧到"早盘（9:30–10:00）"，触发集是全天触发集的**子集** → **触发率单调下降**、"未触发率"上升。本报告的全天口径触发率（limit_pc_0.01=62%）是**上界**；实盘早盘窗只会更低。
- **含义**：§2 已薄的净边际，在真实早盘窗下**更薄、更易被"未触发"吃掉**。建议 SOP 里 `T_obs` 给**全天或至少到午盘**、并把"未触发率"当护栏监控（未触发过高=入场价定太苛、失去次日可执行性，呼应设计 §4）。
- **后续**：待分钟数据积累 ~数月，另起小 chip 做真·T_obs（早盘触发率 vs 全天、及早盘触发单的胜率）——本底座留接口（`nextday_entry.py` 的成交判定可换分钟路径）。

## 6. 成交模型对照（marketable vs doc-literal）——实现口径建议

| 档（全A, stride4） | marketable 净µ | doc-literal 净µ |
|---|--:|--:|
| open | +0.009% | −0.015% |
| limit_pc_0.0 | +0.051% | −0.031% |
| limit_pc_0.01 | +0.068% | +0.017% |
| dip_pc_0.05 | +0.071% | +0.038% |

- 两口径**定性一致**：limit_pc_0.0~0.01 最优、深回踩不改善净、open 近零/负。
- 但 **doc-literal（设计 §3.1）系统性偏悲观**：当 P≥open（挂价高于开盘）时它仍按 P 成交，而真实限价单会以更优的 open 成交。**建议 SOP/复盘/回测统一采用 marketable 口径**（`fill=open if open≤P else (P if low≤P else 未触发)`），别用 `low≤P≤high 取 P`——后者会低估限价入场、误导择档。

## 7. 策略代理（可复现 as-of，**非** live 选股）

| screen | 档 | 触发率 | 绝对胜率 | 净µ | α | 早胜率 | 晚胜率 |
|---|---|--:|--:|--:|--:|--:|--:|
| **动量**(close>MA20>MA60 且近20日正) | open | 100% | 47.1% | +0.021% | 0.03% | 47.1% | 47.0% |
| | **limit_pc_0.01** | 69.8% | **50.9%** | **+0.155%** | **0.33%** | 51.4% | 50.5% |
| | limit_pc_0.02 | 44.7% | 50.6% | +0.144% | 0.49% | 51.3% | 49.8% |
| **反转**(近10日跌>3%且换手<20日均) | open | 100% | 49.9% | −0.039% | −0.04% | 50.4% | 49.3% |
| | limit_pc_0.01 | 61.9% | 50.0% | −0.024% | 0.30% | 50.8% | 49.2% |
| | dip_pc_0.05 | 6.6% | 48.0% | −0.003% | 1.51% | 49.7% | 46.1% |

- **口径的价值随选股类型放大**：**动量票 × 限价回踩**是最佳可执行组合——胜率 50.9%、净 +0.16%/单、α +0.33%、**OOS 稳**（早51.4/晚50.5）、触发率 70%。动量票开盘常冲高回落，回踩限价既降成本又择时，契合最好。
- **反转/超跌低换手票**：次日当日**净期望为负**，限价回踩也救不回。→ 这类候选流不适配"次日当日收盘为正"目标（至少不叠加更强催化时）。
- 印证 §0：**口径是乘数不是源头**——乘在有 α 的候选（动量）上才转正，乘在无 α 候选（反转）上仍负。

## 8. gate 判定（对照预注册判据）

| 预注册判据 | 结果 |
|---|---|
| ① 至少一档净期望>0 且 OOS 同号 | **部分满足**：limit_pc_0.0/0.01 全A净>0 且两段同号（早+0.086/+0.122%、晚+0.016/+0.013%），但晚段逼近 0 |
| ② 该档胜率>无条件基线(open)且 OOS 同向 | **满足**：limit_pc_0.01 胜率 50.7% > open 48.5%，早晚两段均 >open |
| ③ 报出档排序 + 触发率护栏 | **满足**：见 §2；帕累托最优 = limit_pc_0.0/0.01；深回踩触发率坍塌不推荐 |
| ④ 弱市高β胜率显著更差 → 避高β成立 | **不满足（反向）**：弱市高β胜率更**高**（§3）；不建议做 β veto |
| ⑤ 无任一档满足①② → 不可行 | 不适用（①②部分/满足） |

### 结论：**有条件可行（口径方向对、须叠加选股 α，勿单吃口径；勿做 β veto）**

**建议给后续 selection / 复盘 SOP 的口径（本 gate 的产物）**：
1. **入场档**：每票主入场用 **`P_entry = 昨收 ~ 昨收×(0.99)`（limit_pc 0~1%）的限价回踩**，`T_obs` 给全天或至少到午盘，未触发则放弃（并统计未触发率作护栏）。**不默认买开盘**（开盘无 edge、近年净亏）。深回踩 −2%~−5% 只作**可选 `P_dip` 次级加档**，不作主入场（净不改善、OOS 差、触发率低）。
2. **成交/回测口径统一用 marketable**（`open≤P→open；否则 low≤P→P；否则未触发`），**弃用** doc §3.1 的 `low≤P≤high 取 P`（系统性低估限价入场）。
3. **β 过滤**：**不要**把"弱市避高 β"写成选股硬否决——在次日当日横期上不成立。**β/α 仅作复盘归因**（判亏损是选错票 α<0 还是大盘拖累 β），指导经验沉淀，不做 veto。
4. **绝对期望薄 → 选股 α 是胜负手**：口径把"随便买开盘的净亏"救成"薄正"，真正决定盈亏的是候选票本身的 α（动量代理×回踩=净+0.16%/α+0.33%，反转代理仍负）。SOP 的重心应放在**挑出次日绝对为正概率高的少数票 + 用回踩限价把入场做好**，而非依赖口径本身。
5. **诚实预期管理**：即便最优组合，单笔净期望也只 ~+0.1~0.2%、胜率 ~51%——**是"薄优势 + 需纪律执行"，不是"稳赚"**。复盘胜率牌要如实兑现，达不到就收缩（呼应设计 §8）。

## 10. 局限与后续
- 未建模涨跌停不可成交 / ST / 幸存偏差 → 高估可成交性（尤其深回踩、开盘基准）。
- 同日横截面相关使名义 t/z 偏乐观；结论已改以**边际净 + OOS 两段同号 + 经济幅度**为准，不采信巨额配对 t。
- T_obs 需分钟数据（现 8 天）→ 待积累另做。
- 策略代理≠live 选股；live 选股史(canonical)仅 1 天，不可回测——真·"分 live 策略胜率"需灰度积累后补。
- 本底座只测**次日当日收盘**单横期；D+2 卖出线 / 多日持有 β 效应另议。
