## 0. 与 spike 的一处订正（已复测，必须先讲）

spike §1.4 说「`push2.eastmoney.com/api/qt/stock/get` 普通 requests 直连可用」。**今日复测证伪**：

| 端点 / 客户端 | 结果 |
|---|---|
| `np-weblist.../getFastNewsList`（快讯流）· 普通 requests | ✅ 可用（与 spike 一致，不吃墙） |
| `push2.eastmoney.com/.../stock/get`（BK 解析）· 普通 requests | ❌ RemoteDisconnected |
| `push2.eastmoney.com/.../stock/get` · curl_cffi(chrome) | ❌ curl(56) Connection closed abruptly |
| **`push2delay.eastmoney.com/.../stock/get` · curl_cffi(chrome)** | ✅ **返回 `{"f57":"BK1137","f58":"存储芯片"}`** |
| `qt.gtimg.cn/q=bk_BK1137`（腾讯） | ❌ `v_pv_none_match`（腾讯无东财板块名） |

**结论**：BK→板块名解析改走**延时行情主机 `push2delay` + curl_cffi 伪装 chrome**（与 `fundflow.py` 绕 JA3 墙同一手法，单一真源复用）。实时 `push2` 主机被墙，不用。BK 名解析对时效不敏感（板块名不变），用延时主机零损失。

## 1. 目标与非目标

**目标**：把东财 7x24 全量快讯流按日拉全，用东财预打标（stockList）归到申万一级，并入现有 policy 池（同契约、`keyword="7x24流"`），as-of 归档保证回测可复现，源失败不中断流水线。

**非目标**（本轮不做）：
- 不默认每条过 LLM（LLM 兜底做成**默认关闭**的开关，见 §4.4）
- 不改 `event.py:_stock_policy_items` 的 `s.sector in industries` 直比 bug（spike §7 遗留项 1，另开一轮）
- 不动 sector_universe / roster 等共享产物；不做 L1/L3

## 2. 模块结构（先框架后填充·约法5）

新增 `tools/collectors/policy_stream.py`（logger 命名空间 `collectors.policy_stream`·约法7），复用 `policy.py` 的契约/归一/落盘，不把 724 逻辑塞进已经内聚的 `policy.py`。

```
policy_stream.py
├─ _fetch_page(sort_end) -> dict            # 单页取数(np-weblist),抽出便于 mock
├─ _iter_stream(target_date, max_days) -> list[dict]
│                                            # 游标翻页拉到 target_date 00:00(或回溯上限)
├─ _resolve_bk(bk_code) -> str|None          # BK码->板块名, push2delay+curl_cffi, 带缓存
├─ _tag_one(item) -> list[str]               # stockList/规则 -> 申万一级列表
├─ _normalize_stream(item, industries) -> dict   # -> policy 契约, keyword="7x24流"
├─ collect_stream(date=None, max_days=1, pool_only=True, use_llm=False) -> list[dict]
│                                            # 主入口:取数+打标+过滤+归一, 返回契约list(不落盘)
└─ archive_raw_stream(date, raw_items)       # as-of 原始流归档
```

集成点：`policy.fetch_policy()` 末尾（落盘前）合并 `policy_stream.collect_stream()` 的结果，**一次 `tag_and_dump` 写同一个 `policy_{date}` 文件**（见 §5 合并语义）。

### BK 名解析缓存（避免每条一请求·spike §1.4 要求）
- 磁盘缓存：`data/raw/<date>/policy/bk_cache.json`？→ **不入 store kind**（避免动 repo.py `_JSON_KINDS`）。改为**进程级 dict + 一个扁平 json 缓存文件** `settings.DATA_RAW/bk_name_cache.json`（跨天复用，BK 码稳定；类似 llm_cache 的「内容 hash 跨天复用」精神）。
- 命中缓存不请求；未命中才 push2delay 解析，成功写回缓存。解析失败（None）不写缓存、不重试打断整批。

## 3. 取数与 as-of（防未来红线）

### 3.1 游标翻页
- 首页 `sortEnd=""`，之后回传上页 `data.sortEnd` 续拉；`pageSize=200`（服务端封顶）。
- **终止条件**（任一即停）：
  1. 本页最早一条 `showTime` 的日期 < `target_date`（已翻过目标日 00:00）；
  2. `sortEnd` 不再前进 / 为空 / `fastNewsList` 空页；
  3. 累计翻页数 > 上限（`max_pages`，冷启动回溯 `max_days` 天时按 ~600 条/天 × 天数 / 200 估，硬上限兜底防死循环，超限 `log` 明确报「截断，覆盖到 X」——不静默截断）。
- 每页 `time.sleep(settings.FETCH_SLEEP_SEC)`（沿用既有节流惯例）。

### 3.2 as-of 语义（绝不破坏防未来）
- `collect_stream(date=D)`：只保留 `showTime` 的**日期部分 == D** 的条目（当日全天流）。冷启动 `max_days>1` 时保留 `D-max_days+1 ≤ showTime.date ≤ D`。
- **绝不纳入 `showTime.date > D` 的未来条目**（测试锁死：给一批含明天时间戳的 mock，断言被剔除）。
- 落盘沿用 store 按日期分区：写 `policy_{D}` 到 `D/` 分区。原始流归档同分区（§3.3）。

### 3.3 原始流归档（回测可复现）
- `archive_raw_stream`：把**当日拉到的原始 fastNewsList**（未打标、含 stockList）落 `put_raw("policy", f"policy724raw_{D}", raw_list, meta={"source":"eastmoney_724"})`。
- 复用现有 `policy` kind（不同 code 前缀），**不改 repo.py `_JSON_KINDS`**（零 blast radius）。回测重算打标时读此原始流。

## 4. 打标（stockList → 申万一级）

### 4.1 契约与 industries 口径（**设计决策**，见 §7 已报统筹）
- 契约完全并入现有 `{date,title,source,url,region,summary,industries,keyword}`；`keyword="7x24流"`，`source="东财7x24"`。
- **`industries` 存申万一级名**（"电子"/"通信"…），依 §6「统一过 to_sw 归申万一级」。
  - 现有关键词检索路径的 `industries` 存的是概念名（"半导体"/"光通信"，即 `_INDUSTRY_TERMS` key），二者格式不同 → policy 池**混格式**。
  - **为什么安全**：唯一按 industries 做行业 rollup 的下游 `sector_macro_avoid.aggregate_macro` 已对每个 industry 过 `to_sw`（申万名过 to_sw 幂等原样返回，概念名映射到申万）——两种格式都吃得下。`event.py` 的直比本就是 §7 遗留 bug，不因本轮变好变坏。
  - 申万一级是全库 rollup 的规范形（sector_macro_avoid docstring 明写「行业口径=to_sw 单一真源」），724 用规范形是对的。

### 4.2 stockList 分派（实测前缀分布：90 板块占多数，0/1 A股，其余美港基金）
```
for secid in item.stockList:
    market, raw = secid.split(".", 1)
    if market == "90" and raw.startswith("BK"):        # 东财板块
        name = _resolve_bk(raw)          # push2delay+curl_cffi, 缓存
        sw = to_sw(name) if name else None
    elif market in ("0","1") and raw.isdigit() and len(raw)==6:   # A股个股
        sw = board_of(raw)               # 现有离线 code_industry(5206 覆盖),已是申万一级
    else:
        sw = None                        # 美股105/106 / 港股116 / 基金(0.16xxxx,150.x) → 跳过
    收集去重 sw
```
- A 股 secid 里混有基金（`0.161027` LOF、`150.562500`）——靠 `board_of` 命中与否天然过滤（基金不在 code_industry），无需额外判定。

### 4.3 无 stockList 的 ~33%：规则兜底
- 复用 `policy._match_industries(title+summary)` 得概念名命中 → 过 `to_sw` 归申万一级。
- 仍无命中 → industries=[]。

### 4.4 LLM 兜底：默认关闭
- `collect_stream(use_llm=False)` 默认不调 LLM（成本可控关键·§6/§1.5）。
- 预留开关：`use_llm=True` 时，仅对「无 stockList 且规则未命中」的条目走一次 LLM 归行业（复用 `event._cached_extract` 同款缓存）。本轮**不接线到编排默认路径**，只留接口 + 测试，避免默认烧钱。

### 4.5 池过滤（**设计决策**，见 §7 已报统筹）：bound 下游 LLM 成本
- `collect_stream(pool_only=True)` 默认**只保留 industries 与当前票池申万一级有交集的条目**（与 `default_keywords` 同口径：`{to_sw(s.sector) for s in pool} - {None}`）。
- **为什么必须过滤**：`event.score_policy` 对 policy 池**逐条调 LLM 打分**。若把全市场 587 条/天全量入库，下游即 587 次 LLM/天，成本爆炸。池过滤把 724 流收敛到「碰到我票池行业」的子集，与关键词路径同粒度，直接落地 doc「不默认每条过 LLM」。
- 无 industries（打标全空）的条目：等同关键词路径 `require_industry_hit=True` 丢弃。

## 5. 合并语义（与 fetch_policy 集成）

现状 `tag_and_dump` 用 `store.put_raw` **覆盖**写 `policy_{today}`。关键词流 + 724 流必须并进**同一个文件**，不能互相覆盖。

方案：给 `tag_and_dump` 增补一个已归一入参：
```
tag_and_dump(raw_items, days=None, require_industry_hit=True,
             source="eastmoney", pretagged=None)
```
- `pretagged`：724 流已归一 + 已打标的契约 dict 列表，**跳过 `_normalize`/`_match_industries`**（industries 已是申万一级,不能再被文本重打标覆盖）。
- 合并后统一走同一套**去重（url 优先, 退化 title）+ 时间窗 + 排序 + 落盘**。724 与关键词条目若指同一事件（同 url/title）自然去重。
- `meta.source` 记多源：`"eastmoney+724"`（有 724）或原值。

`fetch_policy` 末尾：
```
stream = policy_stream.collect_stream(date=today) if enable_stream else []
return tag_and_dump(raw_items, days=days, source=source, pretagged=stream)
```
- `enable_stream` 开关（默认 True），源失败时 `collect_stream` 内部吞异常返回 `[]`（§6 降级）。

## 6. 降级（约法5 传统，不构成单点）
- 724 取数/解析任一步失败：`collect_stream` 记 logger.error、返回已拿到的部分（或空），**绝不 raise**。
- 724 全挂 → `pretagged=[]`，`fetch_policy` 仍走原关键词/联播两源 fallback，流水线不断。
- push2delay 解析失败：该条 BK 不贡献 industries，退化到规则兜底/其它 stockList 项；不影响别条。
