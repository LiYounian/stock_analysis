## 三、D3 闭环记分引擎设计

### 目标
量化"三方选股 + 四模式召回"的 forward 表现，产出可回测的命中/收益表，
为 §一 的权重(量价0.30/板块0.25/共识0.20/排雷0.15/宏观0.10)与召回阈值提供**证据**，
而不是拍脑袋调参（守则：权重复盘时按回测调，现不定死）。

### 输入契约（已确认可解析）
- **三方选股**：`docs/每日分析/选股/<date>_金字塔_{ClaudeCode,DeepSeek,千问}.md`
  首部标记 `<!-- PICKS_BUY: c1,c2,c3 -->` / `<!-- PICKS_AVOID: c1,c2,c3 -->` + 正文 entry_price 价位。
- **四模式召回**：D2 原型 tools/experimental/pyramid_select_v1.py 的四路(多策略并集/council/板块roster/agent主线) top-N。
- **实际行情**：data/master/kline/<code>.parquet 的 D+0..D+N close（防未来：只读 ≤ 记分执行日）。

### 记分口径（初版·写死档位·可复盘调）
- **窗口**：D+1 / D+3 / D+5 收益（相对 D+0 收盘 = 选股日收盘）。
- **买入票命中**：D+K 收益 > 0（或跑赢基准，基准初版取 hs300 同期）。
- **规避票命中**：D+K 收益 < 0 或跑输基准（避对了）。
- **止损判定**：区间内最低价是否击穿 md 里的止损价（纪律有效性）。
- **汇总**：每方/每模式的命中率、平均收益、中位收益、最大回撤票。

### 引擎结构（守则5 先框架）
`tools/pyramid/d3_score.py`：
- `parse_picks(md_path) -> {buy:[code], avoid:[code], entry:{code:{挂单,止损,红线}}}`（纯函数）
- `forward_return(code, d0, k, root) -> {ret, low, 击穿止损}`（读 K线纯函数）
- `score_source(picks, d0, windows, root) -> 记分dict`
- `build_scorecard(as_of, windows, root) -> {三方, 四模式, 汇总}` + CLI
- 语义锁测试 `tests/pyramid/test_d3_score.py`：锁 parse 标记、收益符号、命中判定、防未来。
