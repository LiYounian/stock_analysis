## 2. 次日执行实盘口径（复用 nextday_entry 底座，锁等价）
决策日 D 只用 ≤D 收盘信息 → **D+1（次交易日）入场 → D+1 收盘 离场**（当日双出）。
- **入场价（主口径）**：限价回踩 `P = 昨收×(1−k)`，k∈{0.00, 0.01}（limit_pc_0 / 0.01，
  预注册 Pareto 最优档）。**成交模型 marketable**：`fill = open if open≤P else (P if low≤P
  else 未触发)`。同时并列报 **买开盘**（Doc3 口径，`fill=open`）作对照。
- **离场**：D+1 收盘。绝对收益 `r = close_{D+1}/fill − 1`。
- **成本**：round-trip **10 bps** 默认（`(1+r)*(1−cost)−1`），0/20 bps 敏感性。
- **α 基准**：`α = r − 全A等权同口径均值`（oc 口径 = 全A open→close 截面等权均值，
  对齐持有窗）。β 作归因不作否决（弱市避高β不成立，见底座报告）。
- **涨停不可买**（Doc3 §7.2）：`open_{D+1} ≥ close_D×(1+limit−0.005)` 判不可买，移出可
  交易集（其负α为纸面）。limit：300/688 板 20%，主板 10%，排北交所；ST(5%) 按板近似并标注。
- **防未来**：入场/基准/β 全部只用 ≤D+1 已定 OHLC；胜率 append-only，不回改不挑日子。

## 3. 机械 baseline（超额检验对照）
预注册：**动量代理 × limit_pc_0.01**。每个决策日 D，在全A（排北交所、历史充足）里取
`close>MA20>MA60 且 ret20>0` 的动量票，按 ret20 降序取 Top-N（N 对齐当日我们该策略入选数，
做同规模对照），过同一口径得 baseline α 分布。**超额 = 我们选股 α − 同日 baseline α**（按日
配对，规避同日横截面相关）。同时报 "全A当日全体" 作第二基准（α 的定义基准）。

## 4. 分析维度
1. **总量**：每策略 & 合并（union of date×code）的 触发率 / 净胜率 / 均值净收益 / 均值α /
   收益分布 / 按日聚类的稳健区间。分 limit_pc_0 / 0.01 / 买开盘 三口径。
2. **超额检验**：我们 vs 机械 baseline（配对，按日）；vs 全A全体。
3. **分维贡献**：按策略拆（合议/动量/放量回踩/最强/反转/半导体/量价/最大范围/…）；
   在 S05 内复用 backtest_strong 的 C1→C4 边际；winner_rate 分档（>99/95-99/80-95/≤80）
   的次日 oc α（预期 wr>99 gap-fade 负尾，扣涨停不可买后收敛）；催化/消息面维度若可得。
   **拆维度贡献，不因整体薄就一句全否，也不掩盖某段拖累。**
4. **OOS / walk-forward**：按日期切早/晚段（样本仅约 20 日 → 诚实标注这是"短持有窗小样本、
   近似 in-sample"，OOS 强度主要来自 ①机械 baseline 对照 ②按日聚类推断 ③逐策略一致性）。
5. **提升杠杆（预注册后验证）**：候选规则——(a) 只在动量共振（close>MA20>MA60&ret20>0）时选；
   (b) 剔 gap-fade 型 wr>99 高开回落票；(c) 弱市结构过滤。**先写判据再看结果**，walk-forward
   验증增益，判据不过就不建议。

## 5. 预注册判据（先于结果）
一条规则/结论"成立"需同时：① 边际净 α 为正且经济量级不可忽略（≳+0.05%/笔）；
② 早晚两段同号（不挑日子）；③ 相对机械 baseline 的配对超额>0 且非单点驱动；
④ 逐策略/逐段一致性（不靠个别日或个别票）。**任一不满足→报"未过判据，不建议落地"。**
诚实底线：**没有真 α 就明说没有**；薄/衰减也如实报，不粉饰。
