## 2. 工具注册表设计（公理 G1/G2/G3）

**注册项 schema**（每个工具必填）：
```
name / 塔层 / inputs(as_of, code|board|market) / outputs(结构字段 + 每个数值的【口径】【档位文字】【一句解释】)
freshness(口径日期 + 新鲜度三态 fresh/stale/missing，来自 provenance) / source(底层维度·生产者) / 防未来声明 / tests(档位语义锁)
```
**两种调用方式并存**：Python API（`tools/pyramid/registry.get(name).run(as_of, code)`）与 CLI（`python -m tools.pyramid tool <name> --as-of D --code X`）——满足"直接调用 vs CLI 只是 Agent 用工具方式不同"。
**产出统一为"浓缩块"**：每工具每票 ≤ 8 行文字 + 结构字段；Agent 一次读完；**禁止裸 json.dumps 进 prompt**（A4 §8(a)#17 反例）。
**注册文件**：`tools/pyramid/registry.py` + `tools/config/tool_registry.yaml`（工具清单 SSOT，Agent 开工先读它知道"有哪些工具"）。
