# REVS 四因子模型 — 设计与价值论证（预注册）

> 状态：**方案待审阅**（先文档后实现）｜创建 2026-09-09
> 目标：先复现 + 回测验证 alpha；不达标不授"策略N"编号、不上线。
> 本文档回答三件事：**(1) 怎么做**（设计口径）｜**(2) 相对现有策略强在哪弱在哪**（对比论证）｜**(3) 值不值得做、增益量级多大**（决策结论）。

---

## 0. 一句话结论（先给判断，论证在下面）

**值得做，但要"拆两轨、分阶段、守证据"。** REVS 的四个维度（宏观 R / 盈利 E / 估值 V / 情绪 S）**正好落在现有策略覆盖矩阵的四个空白或薄弱格**——尤其【估值 V】几乎空白、【宏观 regime 择时 R】有轮子但从未接进选股。项目自己的策略总览已明确点名下一步是"补基本面/资金/情绪维度 + 走出纯量价日频"，REVS 就是这个方向的正面落子。

但增益**不是无条件的**：项目历史反复验证了三条教训（A股短期动量弱/反转强、短样本 regime 择时不显著、幸存者偏差高估净超额）。因此本方案把 REVS **拆成两条独立可验证的轨**，分阶段实施，每一步都用回测数字兜住，达标才推进。

## 1. 模型来源与定义

来源：B站「Kara说量化」REVS 四因子模型。REVS 是四个英文单词首字母缩写（**不是**反转因子 REVS5/10/20）：

| 字母 | 因子 | 中文 | 原始指标 | 维度性质 |
|---|---|---|---|---|
| **R** | Regime | 宏观环境 | PMI · CPI · 信用利差 | **全市场共享**（同一天所有票同值） |
| **E** | Earnings | 盈利动能 | 利润增速 · 营收 · ROE | 个股横截面（季频） |
| **V** | Valuation | 估值水平 | PE · PB · 市值分位 | 个股横截面（日频） |
| **S** | Sentiment | 市场情绪 | 动量 · 成交量 · 波动率 | 个股横截面（日频） |

原视频合成式：`综合得分 = 25%·R + 30%·E + 25%·V + 20%·S`，每因子 MAD 鲁棒标准化到 `[−1,+1]`。

## 2. 核心架构决策：为什么拆成"两轨"，而不是照原式线性加权

**问题**：R（PMI/CPI/信用利差）对同一天所有股票是**同一个值**。把它直接加进个股横截面打分，等于给所有票加同一个常数——**不改变排序、不影响"选谁"**。原视频的 `25%R` 在横截面选股里其实是空转。而且我们验证 alpha 靠 `backtest_rank` 的横截面 IC，R 作为截面常数**根本进不了这个检验**。

**决策**（已与用户对齐）：拆成两条独立轨道，各干各的活、各自可验证。

```
                    ┌─────────────────────────────────────┐
   轨道二（Overlay）  │  R = Regime 择时闸门（全市场）        │
                    │  PMI/CPI/信用利差 → regime 分档       │
                    │  → 控制"整体出不出票 / TopK 大小 / 仓位"│
                    └──────────────┬──────────────────────┘
                                   │ 施加于
                    ┌──────────────▼──────────────────────┐
   轨道一（选股核心） │  E·V·S 横截面多因子合成 → 排序 TopK   │
                    │  权重按原式相对比例归一：             │
                    │  E:V:S = 30:25:20 → E 40% / V 33% / S 27% │
                    └─────────────────────────────────────┘
```

- **轨道一 = 选股**：E/V/S 做横截面 winsor+zscore 加权合成，排序取 TopK。进 `backtest_rank` 测 IC/ICIR/分层单调/TopK净超额。
- **轨道二 = 择时**：R 合成 regime 分，分档控制整体仓位/出票开关，**单独用组合净值曲线验证**（好 regime 满仓 vs 坏 regime 空仓，能否降最大回撤 / 提夏普）。

**与原式的关系**：四个因子全部用上，忠于视频精神；但让每个因子干它数学上真正能干的活——E/V/S 决定"选谁"，R 决定"要不要选/选多少"。原式那种把 R 塞进截面的写法，我们**明确不采用**并在此留痕原因。

**为什么 R 不做成个股级择时闸**：现有 roster 已有三道个股级过热/风控闸（动量高位超买抑制 `strategy.py:868`、多策略命中闸门 `:897`、反转否决层 `:806`）。R 若做个股级会和它们重叠。R 唯一干净的空位是**组合层/regime 层的总仓位控制——项目现在完全没有**（`grep 总仓位/仓位控制` 只命中单票回测的 0/1 目标仓位，无组合级 regime 控仓）。

## 3. 因子计算口径（防未来函数 point-in-time）

所有因子标准化统一复用 `tools/strategy/_factor_util.py` 的 `winsorize_med(scale=3.0)` + `zscore`，与策略10/回测器口径一致，IC 可比。

### E — 盈利动能（季频，个股）
数据现成（`tools/collectors/financial.py` + `tools/analysis/financial/metrics.py`）：
- `归母净利增速`（累计同比，`metrics.py:145`）
- `营收增速`（`metrics.py:144`）
- `ROE`（`fundamental.py` 同花顺摘要 或 `metrics.py` 自算，季报未年化需注意）
- 合成：三子指标各自截面 winsor+zscore → 等权均值 → E 分。
- **防未来**：只取 `disclosure_date <= as_of` 的最近报告期，绝不用未披露财报。

### V — 估值水平（日频，个股）
数据现成（`tools/collectors/fundamental.py`，百度源）：
- `PE_TTM`、`PB`：**方向为负**（低估值得高分），截面 winsor+zscore 后取负。
- `市值分位`：复用 `_percentile`（`fundamental.py:63`，PE分位就是这么算的），**按当日股票池横截面**算市值分位。方向可配（默认偏小市值，A股小市值长期有效但需警惕风格切换）。
- 合成：三子指标截面标准化 → 等权 → V 分。
- **防未来**：估值取 `as_of` 当日值；市值分位用当日截面，不用未来数据。

### S — 市场情绪（日频，个股，自算）
数据现成（`tools/collectors/market.py` 日线 OHLCV+turnover）：
- `动量`：N 日收益率 `close/close.shift(N)-1`（N 待定，建议 20，A股短窗易踩反转，见 §7 风险）。
- `换手/成交额`：`turnover`（已统一百分数口径 `market.py:60`）。
- `波动率`：N 日收益 rolling std（复用 `conditional_predict.py:223` 口径）。
- 合成：截面标准化 → 权重待回测定（动量方向在 A 股需实测，见风险）。
- **防未来**：纯因子只读序列尾部窗口，回测按 `series[:t+1]` 切片天然不泄露。

### R — 宏观 regime（月频，全市场，**唯一新接数据**）
现有数据管线**完全没有**宏观序列，是本方案唯一新数据接入：
- 新建 collector（推荐 AkShare 免费接口，避开 Tushare 积分门槛）：
  - `macro_china_pmi`（制造业 PMI，月频）
  - `macro_china_cpi_monthly`（CPI，月频）
  - `bond_china_yield`（中债国债收益率）→ 自算信用利差（企业债-国债，或用 AA 级利差）
- 新建 `kind="macro"` 存储（全市场单序列，不按个股落盘）。
- regime 合成：三宏观指标各自打分（PMI>荣枯线偏多、CPI 温和偏多过热偏空、信用利差走阔偏空）→ 加权 regime 分 → 分档（如 3~5 档）。
- **复用现有轮子**：`tools/analysis/pattern_screener/regime.py`（五因子 regime 骨架）、`market_forecast`（四维预测器），别重造。
- **防未来硬红线**：PMI/CPI 是月频且**滞后发布**（月初发上月数），必须按**实际发布日**对齐，绝不用"当月值当月用"。信用利差可日频。

## 4. 选股规则（轨道一）

- **选股域**：全 A，剔除 ST / 科创 / 北交（与反转低换手同口径）。
- **调仓频率**：月频（贴合基本面季频更新节奏；回测 horizon 取 5/10/20 日）。
- **流动性过滤**：最小成交额门槛 + 次新剔除（仿 `反转低换手` 的 `流动性_最小成交额_万元` / `次新_上市最少天数`）。
- **合成**：`score = 0.40·E_z + 0.33·V_z + 0.27·S_z`（初始权重，回测后可调）。
- **输出**：排序取 `top_k`（默认 20）。
- **R 施加方式（阶段2）**：坏 regime 档缩小 top_k / 降仓 / 极端档暂停出票。

## 5. 对比现有策略：优势 / 劣势 / 增量在哪

### 5.1 现有 roster 的维度覆盖矩阵（数据来自实盘代码盘点）

| 维度 | 现有覆盖情况 | 结论 |
|---|---|---|
| 技术/量价 | 策略1/2/3/4/7/8/9/10/11、SEPA、趋势模板 —— **挖到底** | 拥挤 |
| 基本面/盈利 E | 仅半导体多因子（限178只池）+ 扣非质量（**待回测未达标**）+ 合议财报专家（常弃权） | **薄** |
| 估值 V | **几乎空白** —— 唯一用 PE/PB 的是合议内"多因子专家"（8专家之一、常降级）；PE 别处只作护栏剔除 | **空白** |
| 资金/情绪 S | 换手/成交额/筹码/北向散见于策略8/9/10、合议情绪三层，但**只作单维弱输入** | 分散、弱 |
| 宏观/regime 择时 R | 有 `regime.py` 分类器 + `大盘预测` 预测器，但**没有任何 screen 消费它们做选股门或控仓** | **有轮子没接线** |

**关键空白**：现有**没有任何一个合成同时正交地把【R宏观 + E盈利 + V估值 + S情绪】四大维融合**——要么单维深挖，要么在合议里被弃权稀释。REVS 的四维正交合成填的正是这个空。

### 5.2 现有策略的已知表现（诚实数字，决定"值不值得"的底色）

项目策略总览（自称权威表）的核心结论：**"纯量价·日频这口井挖到底：没有一个策略跑出统计显著的正 alpha。"**

- 策略4 动量：IC 5/10/20 日 **−0.048/−0.067/−0.069（t 全 <−2.9 显著为负）** → A股是短期反转市，追强动量反跑输。
- 策略1(S01)：胜率 12.6%、均 −0.34%，"救不活"。
- 策略10 反转低换手：composite 5日 net **+13.9%**、增量 +13.6pp，是**目前唯一像样的正结果**，但⚠️**明确标注净绝对水平存幸存者偏差**（主档100%幸存者、漏退市输家），可信的只是"相对单因子 rev5 的增量"。
- 扣非质量 / 半导体：**无回测数字**，待验证。
- 合议：IC≈0 无 edge（能带 alpha 的维度全弃权）。

**项目自己指的下一步**（策略总览 §8）：①补数据维度历史快照（资金流/情绪/基本面）让合成有料；②**非纯量价日频**。→ **REVS 精确命中这两条。**

### 5.3 REVS 的优势（增量来源）

1. **填维度空白**：V 估值（几乎空白）+ R 宏观择时（有轮子没接线）是最干净的增量；E 盈利补薄弱格。
2. **走出纯量价井**：现有显著 alpha 缺失的根因是"纯量价挖到底"，REVS 是横跨基本面+估值+情绪+宏观的**非纯量价**合成，方向对。
3. **组合分散化**：REVS 选票逻辑（基本面+估值主导）与现有纯量价策略**相关性应低**，混入候选池降低持仓同质化。
4. **R 的外溢基础设施价值**：regime 择时闸一旦做出来，**不止服务 REVS**——它是项目缺失已久的"组合级总仓位/择时开关"，理论上可给现有所有策略当回撤保护。这是一份可复用资产，价值超出 REVS 本身。

### 5.4 REVS 的劣势 / 风险（如实列，不藏）

1. **A股动量方向陷阱**：S 的动量维在 A 股短窗是反转市（策略4 已坐实动量 IC 显著为负）。S 的动量子因子方向/窗口**必须实测**，可能要做成反转而非动量。
2. **估值择时性差**：V 在 A 股长期有效但择时性弱，价值陷阱 / 风格切换年份（如成长占优年）会大幅跑输。单靠 V 不稳。
3. **过拟合风险**：因子多→参数多（窗口、权重、方向、分档）。回测必须守净成本 + 样本外 + 相对单因子的增量（不能只看 composite 绝对值）。
4. **R 择时的历史警示**：项目"大盘预测"的资金流维已被自家 A/B 判定"弱正不显著、n≈210 样本短"，权重压到 0。**R 若做成硬择时门，需拿出比"55%命中/n≈210"更强的样本外证据**，否则撞上同一堵墙。宏观月频数据点更少（每月1个），regime 判断噪声天然大。
5. **幸存者偏差**：和反转低换手同样的坑——主档 100% 幸存者会高估净超额。回测结论只认"相对单因子的增量"，绝对可交易性需含退市宇宙复核。
6. **信号慢**：E 季频 + 月频调仓 → 换手低、对快行情钝（这是特性也是代价）。

## 6. 预期增益量级（诚实的区间估计，不是承诺）

> 以下是**基于维度论证的先验预期**，最终以回测数字为准。给区间而非点估计。

| 维度 | 乐观情形 | 中性情形（我的主观概率最高） | 悲观情形 |
|---|---|---|---|
| **轨道一 E/V/S 选股** | composite 20日 rank-IC 稳定 >0.03、ICIR>0.3、D9-D0 单调、TopK net 年化超额为正且相对单因子有增量 | **IC 弱正但不总显著；V 贡献正、E 贡献正、S 需改反转**；net 超额小但为正 | composite IC≈0 或被幸存者偏差吃掉，与合议同命 |
| **轨道二 R 择时** | regime 分档能显著降最大回撤（如 -30%→-20%）、夏普提升，且样本外成立 | **降回撤有效但牺牲部分收益；样本短不够显著，只能当"软降仓"参考** | regime 择时无 edge（撞大盘预测同墙），仅留作展示 |
| **组合层价值** | REVS 与现有策略低相关，进候选池提升组合分散度；R 闸复用到全策略 | **分散化成立，R 闸作为基础设施留存复用** | 相关性没那么低，增量有限 |

**我的综合判断**：轨道一（E/V/S 选股）**中性偏乐观**——因为它填的是 V/E 空白格，而项目现有失败集中在拥挤的量价维，换维度本身就是最大的先验优势。轨道二（R 择时）**中性偏保守**——宏观月频 + 项目历史 regime 不显著的教训，我预期它更可能是"有用但不惊艳的软降仓工具 + 一份可复用基础设施"，而非收益放大器。

**最可能的真实增益**：拿到一个**与现有策略低相关、在估值/盈利维度有正贡献的选股腿** + 一个**可复用的组合级 regime 降仓开关**。这两样现有 roster 都没有，即使各自增量不大，**填空白 + 基础设施**的价值也成立。

## 7. 值不值得做 — 决策结论

**结论：值得做，推荐分阶段实施，先做轨道一。**

理由：
1. **靶心正**：命中项目自己指的下一步（补维度 + 非纯量价），填 V/R 空白格，不是在拥挤的量价维再挤一个。
2. **成本可控**：轨道一 E/V/S 数据全现成，照 `反转低换手` 模板链换因子即可，无新数据接入。R 才需要新接一个 AkShare 宏观 collector。
3. **风险有围栏**：拆两轨让 alpha 归因清晰、各自可证伪；预注册验收闸门（下 §8）挡住过拟合和幸存者偏差自欺。
4. **有退路**：即使轨道一 IC 平平，V/E 因子和 R 闸也能作为**合议专家的输入增强 / 组合级降仓基础设施**留存复用，不是全损。

**不值得做的情形**（提前说清）：如果你要的是"立刻能跑赢的高收益策略"，REVS 大概率给不了——项目历史证明 A 股这些标准因子很难跑出惊艳 alpha。REVS 的价值是**填空白 + 基础设施 + 分散化**，是长期地基而非短期爆发。

## 8. 分阶段实施 + 回测验收标准（预注册闸门）

**阶段0（本文档）**：方案审阅。← 当前在这

**阶段1：轨道一 E/V/S 横截面选股（无新数据，最快出结果）**
- 实现 `tools/strategy/revs.py`（纯因子 + `@strategy` 选股）、`tools/pipeline/screen_revs.py`、config 参数块、`tools/backtest/backtest_revs.py`（仿 `backtest_reversal_turnover`）。
- **验收闸门（达标才推进 & 才授编号）**：
  - composite 20日 rank-IC 显著为正（p<0.10）；
  - 分层 D9−D0 单调（高分组前瞻收益 ≥ 低分组）；
  - TopK **net 年化超额 > 0**（扣真实往返成本）；
  - **相对单因子（E-only/V-only/S-only）有正增量**（不能只是某单因子的马甲）；
  - S 动量方向经实测确定（大概率要改反转）。
- 不达标 → 不上线，记录为何失败（哪个维度拖后腿）。

**阶段2：轨道二 R regime 择时闸（需新接宏观数据）**
- 新建宏观 collector + `kind="macro"` 存储；复用 `regime.py` 骨架合成 regime 分。
- **验收闸门**：叠加 R 闸后，组合净值曲线**最大回撤下降**且**夏普不降**（在多个 regime 区间样本外成立）；若只是牺牲收益换回撤，需明确权衡后由用户拍板是否上线。
- 不达标 → R 只作展示/软降仓参考，不做硬门（对标大盘预测资金流维被压权重0的先例）。

**阶段3（可选）**：接每日编排（`run.py` + `candidate_message.py`），并入候选池；文档如实标注状态（参考策略10"前向观测中，非已验证可用"的诚实措辞）。

## 10. 未决问题（需用户/回测拍板）

1. **S 动量方向/窗口**：A股短窗是反转市，动量子因子大概率要改成反转或拉长窗口——**以阶段1回测单因子 IC 符号为准**。
