# 2026-09-17 选股整改：S5「板块唯一闸门」→ 策略线 ∪ 板块消息线 双路并集

> ⚠️ 测试环境研究模拟，非投资建议。KPI = 绝对收益（Model A）。
> 分支 `feat/selection-dualpath`。

## 一、病根

旧 `tools/analysis/selection_synth.py`(S5) 只做「消息面判利好板块 → 只在利好板块内选票」，
导致**策略选出的强票，若其所属板块没被判利好，就整条被旁路**——策略线被板块绑架，
选股过度极端。用户要拉回平衡。

## 二、整改：双路并集

### (a) 策略线（主体 · 全A · 不被板块闸门）
- `run_council_universe`：全A（离线缓存票池 `_offline_universe_codes`）跑 `screen_council`
  策略0多专家合议 → top-N（默认 12）。**原策略直选强票，不管板块是否利好都保留**。
- `run_extra_strategies`（best-effort，默认关）：动量/强势/趋势模板各取 top-K，
  只并「策略命中」名，council 仍是主排序面。

### (b) 板块消息线（催化/规避维，不再是唯一闸门）
- 利好板块：沿用 `gather_candidates`（龙头/中军/跟涨）作催化候选。
- 规避板块池 `规避板块池`：`load_avoid_boards` → 隶属票 `apply_avoid_downgrade`
  （推荐→观察 + 留痕），按 board 或 council 行业→申万一级匹配。

### (c) 综合并集 + 来源标注
- `_merge_candidate` 按 code 去重合并两路 → `来源∈{策略直选, 板块催化, 两者兼有}`。
- 分组：隶属利好板块→该板块组；隶属规避→规避组；否则→「策略直选」组。逐组 DeepSeek 合成。

### 提示词双依据（`SELECTION_SYNTH_INSTRUCTION`）
- 每票喂 ①策略面(命中策略/council综合分+方向/财报红旗/龙虎) ②板块面(利好/利空/催化/强弱) ③形态。
- 要求 LLM 理由**分别写「策略依据」与「板块依据」**。
- 用户 3 项精修已并入：① 建议分 0-10 每档文字定义；② 入场去 few-shot「回踩」偏向
  （据个股形态给合适入场，保留不追涨停/高开）；③ 策略分值口径解释块
  （council综合分∈[-1,1] 阈值 / 财报红旗 / 获利盘 / 位置pos60 / 距高 / 量比，
  均程序算出，描述口径供模型正确解读）。

## 三、硬约束（保留不变）
硬纪律程序兜底 `hard_veto_reason` / `apply_hard_discipline`：财报红旗/龙虎否决/涨停不可买/
极高位高抛压 → 强制剔除；跟涨只观察；判据固定、绝不对既往赢家调参。量价/财报 as-of≤date。

## 四、S3 新闻时效放开（防未来红线：可切换参数，不删严格分支）
`board_news_collect.py` 加 `allow_future`（默认 False=严格 as-of，保留 `t>date` 剔除，
回测/forward 复盘走默认）；`=True`（live 口径=最大可得新闻）跳过未来上限。
S3 每日 runner `board_news_collect_run.py` 默认放开（`--strict` 回退，`--lookback-days` 放宽下限）。
量价/财报仍严格 as-of。
