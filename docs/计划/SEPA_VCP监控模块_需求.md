## 一、原始需求（终稿原话，忠实记录）

来源：策略提供者《SEPA+VCP 监控模块 · 最终需求文档（终稿）》，2026-08-18。
取代 08-16《SEPA量化系统需求说明书 V1.0》及我方当时的评估拆分（见 [旧评估](SEPA策略_评估与反馈与方案.md)，本文为新权威）。

### 1.1 运行设定

- 执行时间：每日 2 次——午间休市后 / 收盘结束后。
- 是否实时：❌ 无盘中 tick / 分钟级。
- 监控范围：仅当日通过 SEPA 硬条件的个股（≈200~400 只），不是全市场盯盘。
- 是否交易：❌ 不自动下单、不给精确买点。

### 1.2 SEPA 入池（原书标准 · 不调整）

必须同时满足：

1. 股价 > MA50 > MA150 > MA200
2. MA200 向上（当前 > 20 日前）
3. 股价在 MA50、MA200 上方

满足即进入「技术合格池」，记录入池日。

### 1.3 星标（辅助标签 · 不参与过滤）

- ⭐ 基本面星（财报 / 客观数据）
- ⭐ 板块星（主线 / 共振）
- 仅展示，不打分排序

### 1.4 VCP 监控逻辑（核心）

**一轮**：从一个波段高点回撤到一个波段低点；单轮 ≥3 个交易日；单日 K 线 ≠ 一轮。

**收缩判定（只比「当前轮 vs 上一轮」）**：对该轮

`回撤% = (本轮起点高点 − 本轮最低点) / 本轮起点高点`

相邻两轮满足即可，不要求全局单调：

1. 当前轮回撤% < 上一轮回撤%（振幅缩小）
2. 当前轮低点 > 上一轮低点（higher low）
3. 当前轮持续天数 ≤ 上一轮（时间压缩，可选加分）
4. 当前段成交量 < 上一段成交量（量缩，标记即可）

- ❌ 不预设末轮阈值；先跑结果，肉眼看，再回头定阈值。
- 只要「这一轮比上一轮小」就继续观察，不卡死绝对数字。
- ≥2 轮收缩即进重点观察池；2 轮 = 可显示；3 轮+ = 结构更健康（仅展示权重区分）。

**盘中破位 = 洗盘（算活）**：

- 允许：盘中刺破前一轮低点 → 收盘拉回。判定：算活，不判 VCP 失效。
- 失效仅当：收盘确认跌破前一轮低点（>1.5% 且收不回）。

### 1.5 输出（午间 + 收盘）

**表1 技术合格池（全量）**：代码、名称、入池天数、星标数。

**表2 重点观察池（过滤后）**，满足任一即入表：

| 分类 | 条件 |
|---|---|
| 🌱 新候选 | 今日首进 SEPA 池 + 有星 |
| 🔄 VCP 进行中 | ≥2 轮收缩，相邻两轮满足「振幅↓ + 低点↑」 |
| ⏳ 接近枢纽 | 末轮收缩中 + 量枯 + 距前高近 |
| ❌ 结构破坏 | 收盘有效跌破前低 |

**文本摘要**示例：

```
【收盘雷达】
重点：5只
VCP进行中：300xxx（25%→15%→8%，第3轮）
新入池+星：002xxx（板块⭐）
失效移出：无
```

### 1.6 辅助工具：VCP 收缩分段主图（不自动命名）

在 K 线上标注：每轮「高点→低点」线段、该轮回撤%、持续天数、该段均量 vs 50 日均量。
不叫「VCP 完成」，只叫「收缩结构参考」。目的：一眼数出「这是第几轮、缩到多少了」。

## 二、要实现哪些功能（可验收）

- [x] **F1 SEPA 入池扫描**：全 A（排除北交所）用日 K 硬过滤 1.2 三条；产出技术合格池 + 入池日 / 入池天数。验收：给定 K 线夹具，三条全满足才入、缺一根不入；跨日快照能算出入池天数。
- [x] **F2 星标（展示专用）**：对合格池打基本面星 / 板块星；表1 出星标数。验收：星标不参与入池过滤（无星仍在表1）；无星的「新候选」不进表2 的 🌱。
- [x] **F3 VCP 波段分段**：对合格池每只票切「高点→低点」轮次（≥3 日）；算出每轮回撤%、天数、段均量。验收：单日 K ≠ 一轮；不足 3 日的摆动丢弃。
- [x] **F4 相邻轮收缩判定**：只比当前轮 vs 上一轮（振幅↓ + higher low 为硬条件；时间压缩可选加分；量缩只标记）。验收：全局不单调但相邻两轮收缩仍算进行中；无末轮绝对阈值。
- [x] **F5 洗盘 vs 失效**：日 K 的 low 刺破前低但 close 收回 = 洗盘算活；close 较前低跌破 >1.5% 且收不回 = 结构破坏。验收：夹具覆盖这两种；不依赖分钟线。
- [x] **F6 两表 + 雷达摘要**：落 view；表2 四分类可并存（一只可多标签）。验收：摘要能列出重点只数 / 进行中回撤链 / 新入池+星 / 失效移出。
- [x] **F7 收缩分段主图**：个股页（或监控详情）K 线叠加轮次线段 + 回撤%/天数 + 段均量 vs MA50 量。验收：标题为「收缩结构参考」，文案不出现「VCP 完成」。
- [x] **F8 午间 + 收盘两趟**：CLI + 定时（约 11:35 / 15:30）；午间用当日未完成 bar。验收：产物带 `session=午间|收盘`；Web 可按日期+场次看。
- [x] **F9 不交易**：页面 / 摘要无买点、无下单、全站非投资建议。

### 3.4 接口 / 契约（拟定，审阅后实现）

```
# 入池（无未来函数：MA 只用 t 及之前）
sepa_pass(kline, t) -> bool
# 波段轮次：已确认 pivot 高/低交替成对；末段可以是「进行中」（从最后高点到迄今最低）
segment_rounds(kline, t, min_bars=3) -> list[Round]
# Round: {start_date, end_date, high, low, 回撤%, 天数, 段均量, 进行中:bool}
# 相邻收缩
contraction(curr, prev) -> {振幅缩小, higher_low, 时间压缩, 量缩}
# 失效：close < prev_low * (1 - 0.015) 且 close 未收回 prev_low
structure_broken(kline, t, prev_low, fail_pct=0.015) -> {失效, 洗盘刺破}
# 编排
run_sepa_vcp(as_of, session) -> {合格池, 观察池, 雷达, 图表}
```

中心记录 **不改 schema**（本模块是独立 view，不塞进每只 `record.json`，避免污染全池契约）。

### 3.5 工程默认口径（终稿未写死、实现用占位，标「待肉眼标定」）

| 缺口 | 推荐默认 | 理由 |
|---|---|---|
| 波段高/低怎么认 | 左右各 **N=3** 根的确认 pivot；**当前轮允许未确认**（最后高点 → 迄今最低价） | 单轮≥3 日；进行中必须能画「缩到哪了」。窗口 8 对 VCP 太钝，会并掉短轮。 |
| ST / 次新 | 代码层剔 ST 名称；上市不足 200 日自然算不出 MA200 → 不入池 | 终稿没写，属数据卫生，不是新过滤条件 |
| 入池日重置 | 连续在池；**缺席 1 个交易日即重置** | 简单可测 |
| 基本面星 | 近 2 季营收同比或归母净利同比 ≥0（至少 1 个）；缺数据不打星 | 沿用旧需求书客观口径；**不挡入表1** |
| 板块星 | 同申万一级当日合格池 ≥2 | 「主线/共振」可计算的最小定义 |
| ⏳ 量枯 | 末轮段均量 < 50 日均量 | 终稿图上已要求 vs 50 日均量 |
| ⏳ 距前高近 | 收盘距本轮起点高点 ≤ **8%**（占位） | 终稿无数字；先跑再标 |
| 一只多标签 | 允许（新候选 ∩ VCP 进行中） | 表2「满足任一」 |

**洗盘实现（日 K 即可，不必分钟）**：当日 `low < 前轮低点` 且 `close ≥ 前轮低点` → 洗盘算活。这就是终稿「盘中刺破、收盘拉回」。

### 3.6 工作量估

- 预估 token：input ~80–120K / output ~20–40K（含全 A 编排 + 图 + 测试）
- 预估 agent 工时：~4–6 小时（分步：计算核 → 编排 → Web/图 → 定时）

分期：

1. 计算核 + 单测（F1–F5），用夹具不碰全 A
2. 编排 + view（F6、F8 CLI）
3. Web 两表+雷达 + 收缩结构图（F7、F9）
4. 午间 launchd；收盘挂到现有 15:30 之后
