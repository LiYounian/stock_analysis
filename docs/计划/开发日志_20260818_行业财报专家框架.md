### 四、M4 银行增强(本轮提交 `f84048c`,用户拍板)

**诊断**:银行「健康」维 4 个子键全 None → 整维空转被丢弃。分两类:
- 本可从三大表算却没加进 metrics:总资产增速 / 贷款增速 / 减值占PPOP / PPOP覆盖减值倍数
- 三大表根本没有、需监管附注源:不良率 / 拨备覆盖率 / 资本充足率 / 净息差

**决策(用户选"先补可算的 4 键再提交")**:metrics 补前一类 4 键(PPOP≤0 时 减值占PPOP 置 None 防污染反向打分)。健康维 `None → 95.24` 复活。监管附注比率仍列在 specs、标注待补采,`five_dims` 缺项降级不影响当前打分。
