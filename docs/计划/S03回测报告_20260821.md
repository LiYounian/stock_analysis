# S03「最大范围选股」A/B 历史回测报告 · 2026-08-21

> ⚠️ **非投资建议**;历史统计非未来保证。
> ⚠️ **样本级方向性 sanity,非全A alpha**:本回测基于 **250 只分层样本**(沪/深主板 + 中小 + 创业 + 科创,baostock qfq)+ **27 个测试日**(2025-04-02 ~ 2026-07-16,跨多行情段),用于验证**方向性是否符合设计意图**(看多型→入池前瞻应偏涨),**不是全A alpha 结论**。定位=过滤器/研究工具。

## 一、方法(无未来函数)
- 对每个 (股票, 测试日 d):用 `screen_max_range.signal_at(kdf, i)` 在 d 的索引处判定(**只用 ≤d 的数据**),命中则记 **T+1 / T+5 / T+10 / T+20** 前瞻收益 `close[d+k]/close[d]−1`。
- 对照组:①**baseline** = 同期全样本(所有被评估 (股票,日) 的前瞻均值);②**HS300** 同窗收益(市场基准)。
- 方向判据:S03 为**看多型**,命中组前瞻均值应高于 baseline / HS300 才算有方向 edge。
- A/B 消融:去掉 C3「32 日内大阳(单日涨>6%)≥1」门槛,看该门槛的边际作用。
- 测试日取法:HS300 交易日轴 [300, 末-21) 每 12 日一采(留足 20 日前瞻窗)。

## 二、结果(命中 789 样本)

| 组 | T+1 均值/胜率 | T+5 | T+10 | T+20 |
|---|---|---|---|---|
| **S03 命中** (n=789) | +0.22% / 46.9% | +0.03% / 43.6% | **+1.13% / 44.7%** | +1.01% / 45.1% |
| baseline 全样本 (n=6750) | +0.16% / 51.3% | −0.05% / 47.4% | +0.36% / 47.9% | +1.29% / 51.7% |
| HS300 基准 (n=27) | +0.18% / 59.3% | +0.46% / 55.6% | +0.50% / 55.6% | +1.33% / 59.3% |

**A/B 消融(去 C3 32日大阳)**:命中样本 789 → **1600**(门槛使入选收紧一半);前瞻 T+10 +0.93% / T+20 **+1.74%**(不低于、甚至高于完整版 T+20 +1.01%)。

## 三、诚实结论
- **方向对、edge 弱**:命中组 **T+10 均值 +1.13% 明显高于 baseline +0.36%、HS300 +0.50%**(方向性符合"看多"设计);但 **胜率 44.7% 低于 baseline 47.9%**,且 T+20 均值 (+1.01%) 反而略低于 baseline (+1.29%)。
- **典型右偏/动量特征**:低胜率 + 高均值 = 少数大涨拉动(高位强势股的动量延续),而非"多数上涨"。作**机械买入信号不合格**(胜率偏低)。
- **C3(32日大阳)门槛主要收紧选择性、不增收益**:去掉后样本翻倍、前瞻收益不降反微升 → 该门槛更像"限定强势形态"的画像条件,不是 alpha 来源。**建议保留**(用于画像一致性),但不宜宣称其提升收益。
- **定位**:**过滤器 / 观察池**——把"高位 + 均线多头 + 近期有过大阳"的强势股筛出来供人工复核或喂合议,不作单独买入依据。
