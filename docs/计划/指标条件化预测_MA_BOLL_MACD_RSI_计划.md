# 指标条件化预测(MA / BOLL / MACD / RSI)— 增强 predict.py

> 状态：**待审** · 日期：2026-08-23 · 分支：`feat/strategy-discuss-2`
> 一句话：用 MA/BOLL/MACD/RSI 的**当前状态**给前瞻收益分布"开条件",把现有 predict.py 里**无区分力的无条件上涨概率/区间**升级为**指标条件化**的方向判断 + 区间(含期望值),覆盖 1/5/10 交易日。非投资建议。

## 〇、背景与关键诊断(为什么是"增强"而不是"新建")

用户诉求:调研 MA/BOLL/MACD/RSI 四个指标,评估能否**综合起来做短期预测**——输出**预期涨/跌方向**、周期 **1/5/10 交易日**、并进一步给**涨跌幅度**(接受形态:**区间 + 期望值**)。

调研后(带证据):

1. **项目已有预测引擎** `tools/analysis/predict.py`,已产出:方向 + 上涨概率%、1/5/10 日、幅度区间(悲观 q7 / 中位 / 乐观 q93)、止损止盈两条线、买卖倾向;且有**严格无未来函数**的回测验证 `tools/backtest/backtest_predict.py`(区间覆盖校准 / Brier / 上涨概率校准曲线)。
2. **它有一个自己记录在案的致命缺陷**(`predict.py:95-98`):`scenarios()` 的「上涨概率%」是**无条件**历史频率(只数这只票历史上 N 日涨跌比例),**未条件化到当前形态/位置**,回测(2026-08-12,随机全A 29 万观测)显示各预测分箱实际上涨率都塌到基础率 ~50%、**Brier≈0.25(≈掷硬币)**。区间 [悲观,乐观] 经分位调参后覆盖 ~80% 可信,但**中心/方向无区分力**。
3. **四指标现状**(证据见 `技术面调研`):
   - **MA / MACD / RSI** 已在 `tools/analysis/technical.py` 计算(通达信口径:MA 5/10/20/60;MACD 12/26/9;RSI 6/12/24),并已合成「趋势评级」分数(`technical._score`,均线30 + MACD 25/10 + 价MA20 10 + RSI 10),再喂给 `predict.bias_recommendation` 产出粗粒度"偏买入/偏卖出/观望"标签。
   - **BOLL(布林带)完全没落地**:全代码库零计算、零 THRESHOLDS 键、零策略引用,仅在参考文档提及。
4. **结论**:用户要的"用四指标状态做条件判断",**恰好就是修好 predict.py 那个无条件缺陷的钥匙**。故本需求定位为**增强现有 predict.py**(用户 2026-08-23 拍板),而非并排新建工具。四指标中 MA/MACD/RSI 复用现成计算,**唯一需从零实现的是 BOLL**。

## 二、要实现哪些功能(可验收的功能点)

- [ ] **F1 · BOLL 指标落地**:在 `technical.py` 新增布林带计算(中轨=20日MA,上/下轨=中轨±2σ),输出上轨/中轨/下轨/带宽(bandwidth)/%B(价格在带内相对位置 0~1)/挤压标志。参数进 `THRESHOLDS`。
  - 验收:`technical.compute` 输出新增 `boll` 块;单测断言 %B∈[价破上轨>1、破下轨<0]、带宽=（上-下)/中轨、挤压=带宽处于近 N 日低分位。
- [ ] **F1b · BOLL 形态识别(开口/缩口)+ 带宽动态调区间宽度**(用户 2026-08-23 强调):BOLL 最有预测价值的部分是**波动率/幅度**(而非方向)。
  - **形态识别**:判定当前 BOLL 是**开口**(带宽扩张)/**缩口**(带宽收窄至近 N 日低分位=挤压)/**沿轨行走**(riding the band,连续贴上/下轨),给出形态标签。验收:构造样本形态标签正确;缩口=带宽近 N 日低分位、开口=带宽较前 M 日显著扩张。
  - **带宽 → 幅度**:用带宽/挤压**动态调整 §F3 输出的预测区间宽度**——缩口时区间收窄(预示变盘前的低波动)、开口时区间放宽(波动放大)。这比现在纯 ATR 构造的区间更贴形态。验收:回测显示带宽调宽后区间覆盖仍 ~80% 且信息量(区间宽度)随波动率状态自适应。
  - **触轨的 regime 依赖**(写入 §F2 状态定义):触上轨在**震荡市**=超买回落(看跌)、在**趋势市**=强势延续(riding)——故 %B 越轨信号必须与趋势状态(均线/MACD)联合判读,不单独定方向。
- [ ] **F2 · 四指标状态向量(离散特征)**:把 MA(排列/价位)、BOLL(%B/挤压/开口)、MACD(金叉死叉/零轴/柱变化/背离)、RSI(超买超卖/50 中枢/背离)归约为一组**离散状态特征**(如"均线多头+MACD零上金叉+RSI偏强+触上轨"),作为条件化的自变量。纯函数、防未来。
  - 验收:给定构造样本,状态标签符合定义(表见 §3.3);单测锁 12/26/9、20/2σ、70/30 等口径不被改写。
- [ ] **F2b · 高级形态状态(用户 2026-08-23 追加,定为二级维度)**:补齐几个现在缺失/半套的高级用法,**作二级状态维度**——不进 A2 的主相似度量(防维度爆炸),用作**条件过滤 / 断点佐证(见文档2)/ 展示**:
  - **KDJ 钝化**:连续 N 日 K>80(高位钝化=强趋势,超买失效不该卖)或 K<20(低位钝化=极弱)。现状 `technical.py:100-105` 只有单日超买超卖,无连续判定。验收:构造连续超买样本→钝化标志=真;N 进 THRESHOLDS。
  - **KDJ 交叉扩展**:现仅"低位金叉"(`technical.py:258-259`)。补一般金叉/死叉 + **高位死叉**(顶部警报)+ **交叉点逐波抬高/降低**(动能增强/衰减)。验收:构造样本交叉标签正确。

> **二级维度说明(遵 A2)**:上表中标 **(F2b)** 的钝化/交叉扩展/顶底背离/止跌锚 = **二级状态维度**,**不进 A2 的 2-3 主相似度量**(趋势方向×动量×BOLL位置),仅作条件过滤 / 断点佐证(文档2)/ 展示,避免主相似度量维度爆炸→稀疏。

#### 相似日筛选口径(统筹 2026-08-23 定死,F3 成败关键)

- **A1【主口径·必定】全A横截面池化**:条件分布用**全A 所有票 × 所有历史日**的状态向量**共池**计算——即"历史上所有股票、所有日子里,处于和今天相似状态的那些样本,后来 N 日怎么走"。**不用单票自身历史**(单票 × 多维离散状态必然稀疏,样本量根本不够)。设 `min相似样本数`,不足再优雅退回无条件 `scenarios()`。可保留"二级 per-stock 微调"作为增强项,但**主口径 = 全A 池化**。防未来函数:池只纳入"截至 t 已发生"的 (票, 日) 样本。
- **A2【相似度量·预先收敛,不全开放】**:主维度先降到 **2–3 个**——建议 **趋势方向(均线排列)× 动量状态(MACD/RSI)× BOLL 位置(%B 分档)**;用**加权 Hamming / 离散距离 + max 阈值匹配**(距离 ≤ 阈值即算相似),用降维控制"维度爆炸→稀疏"。维度权重、"相近"容差、`min相似样本数` → 进 THRESHOLDS,由回测标定。其余维度(背离、挤压等)先作二级过滤或留待后续,不进主相似度量。

### 3.5 工作量估(按 agent 视角,约法第 11 条)

- **预估 token**:input ~ 200–320K / output ~ 40–70K 量级(核心在条件化逻辑设计 + 回测多轮 A/B 跑数与调参迭代)。

### 预期效果(做完后应看到的现象)

### 成功 / 失败判据(诚实,允许"无提升"结论)

- 🟢 **成功**:条件化后上涨概率**恢复区分力**——校准曲线出现单调斜率、**Brier 明显 < 0.25**(无条件基线);或区间在**保持 ~80% 覆盖**的同时**显著收窄**(信息量提升);且条件期望的实测偏差可接受。可能是**分 regime/周期成立**(如趋势市 5/10 日有效、震荡市无效)——照实分层回填,参照趋势模板/SEPA 报告的诚实口径。
- 🔴 **失败也照实写**:若条件化相对无条件**无统计显著提升**(Brier 不降、覆盖/收窄无改善),报告明确写"四指标条件化在本口径下无聚合 alpha",并给出是否某 regime/周期例外。**不为了交付而美化。**

### 测试(锁"为什么改"的语义)

- `test_boll.py`:锁 20/2σ 口径;%B 破轨边界;带宽/挤压定义。
- `test_indicator_state.py`:锁 MACD 12/26/9、RSI 70/30、MA 排列判定;构造样本状态标签正确。
- `test_advanced_patterns.py`(F2b):锁 **KDJ 钝化=连续 N 日超买/超卖**(单日不算)、**RSI/MACD 顶底背离**判定、**背离标为"警告"不进主相似度量/不当买卖点**、**MA20 止跌锚**并入 structure_anchor 后无未来函数;全部纯函数只用 ≤t。
- `test_conditional_predict.py`:锁**无未来函数**(条件筛选只用 ≤t)、样本不足**退回无条件**并标注、1/5/10 日结构完整。

## 八、回测设计与预期(预注册假设,遵 A3)

**回测方式(复用现成)**:
- 引擎:扩展 `backtest_predict.py`(五指标)+ walk-forward 复用 `screen_forward_common`(WINDOWS=1/5/10/20、双基准=全A等权 baseline + HS300、regime 打标、`pick_test_days` stride 抽样)。

- A/B:先跑现有 `backtest_predict` 得**无条件基线**,再比条件化。

**我的预注册假设(诚实,先说死,不事后挑赢的报)**:

| 对象 | 我的预期 |
|---|---|
| 方向(上涨概率) | **1日≈噪声;5/10日仅在趋势 regime 有弱改善**(Brier 从 ~0.25 基线降到 ~0.22-0.24 量级);**聚合大概率弱 / 无显著 alpha**(类比趋势模板聚合无 edge) |

| 主格 vs 探索格 | 预注册主状态格(如"趋势多头×动量强×BOLL中性")**必报**(无论输赢);背离/钝化仅二级佐证、归探索格 |

> **诚实预判**:这套很可能结论=**分 regime 弱正 / 聚合无 alpha**,与趋势模板/SEPA 一贯口径一致。价值在于把条件化框架搭好 + 诚实标定"什么条件下有一点用",不承诺能赚钱的预测器。
