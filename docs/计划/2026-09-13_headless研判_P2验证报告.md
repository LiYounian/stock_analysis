## 0. 一句话结论

headless 生成器**可端到端跑通、产出符合 picks_schema 的逐票研判,叙事质量接近 Claude、且会主动引用经验库教训**;
在 2026-09-11 的 5 只 Claude 终选票上,与 Claude 的分歧**全部是 ±1 档谨慎度的微差**(观望↔规避、买入候选↔检验样本),
**无一例"Claude 看多、程序化看空"的严重反向**。近端方向姿态一致率 80%。**质量差距不大但未到可无人值守切主**,
主要短板在 type 分类口径与个别边界票的谨慎度校准 —— 建议再补 1~2 个历史日 + 前瞻收益闸门后由用户拍板。

## 2. 生成器工作流

`data/analysis/<date>/` 原料 →
`deep_analysis_inputs.assemble`(record/news_ai/sentiment/market_forecast β,**防未来裁剪**)→
`experience_recall`(选 ≤date 最新经验版本 → 按 行业/策略/定性形态 关键词召回 + 常驻高频纪律 #1~#4)→
`prompts.deep_analysis_instruction`(SOP 硬红线 + 逐票 9 必填结构化 + 经验片段)→
`get_client("deep_analysis")` / `get_client_for(provider)` 的 `.extract` →
枚举兜底 + 一致性修正(不给方向→conf'-'、情绪盲区不买入/首选)→
write_picks 可吃的 analysis unit(客观字段仍由 write_picks 回填)。

**防未来函数**(硬红线,已测):经验版本 ≤ pick_date;news_ai / sentiment.events 剔除 time 晚于 pick_date 条目;
record.as_of 晚于 pick_date 标 future_leak(prompt 里显式告警,研判转保守)。

## 3. 历史日 dry-run:生成器 vs Claude(2026-09-11)

**方法**:候选集 = Claude 09-11 报告 PICKS 锚点(601872,002913,300124,688262,002064);
生成器(DeepSeek,think 关)跑同一候选 → 与 Claude`选股/2026-09-11.md`「买入建议排序」表对比。
表态归一到 picks_schema 4 枚举后精确比;方向为姿态级粗比(Claude 自由文本 vs 枚举,已在报告标注)。

| 指标 | 结果 |
|---|---|
| 覆盖度 | **5/5**(全部出研判,schema 全过) |
| type 一致率 | 60%(3/5) |
| stance 一致率(4 枚举) | 60%(3/5) |
| 方向姿态一致率(是否承诺方向) | 80%(4/5) |
| 明显退化(生成器过保守 ≥2 档) | **无** |
| 过冒进(≥2 档) | **无** |

**逐票**:

| 代码 | 名称 | type(C/生) | stance(C/生) | 方向姿态5日 |
|---|---|---|---|---|
| 601872 | 招商轮船 | 买入候选/检验样本✗ | 可参与/可参与✓ | 承诺/承诺✓ |
| 002913 | 奥士康 | 检验样本/规避✗ | 观望/规避✗ | 不承诺/不承诺✓ |
| 002064 | 华峰化学 | 检验样本/检验样本✓ | 观望/观望✓ | 不承诺/不承诺✓ |
| 300124 | 汇川技术 | 检验样本/检验样本✓ | 观望/观望✓ | 不承诺/承诺✗ |
| 688262 | 国芯科技 | 检验样本/检验样本✓ | 规避/观望✗ | 不承诺/不承诺✓ |

**质量诚实评估(直接决定第三波敢不敢切)**:

- **达标面**:① 覆盖度、schema 合规 100%;② 无严重反向(最危险的"Claude 买、程序化避"或反之,一例都没有);
  ③ SOP 纪律落地——情绪票(002913)正确给"规避 + 不给方向",超卖票(002064)给出"次日缩量止跌"的方向前提;
  ④ **主动引用经验库**:002913 命中 #2(主力 vs 融资盘)、300124 命中 #5(孤立破位 vs 全市场恐慌),
  证明关键词检索确实把既往教训注入了研判。
- **差距面(未达可无人值守切主)**:
  1. **type 分类口径**:601872 Claude 判"买入候选",生成器判"检验样本"(但 stance 同为"可参与")——
     type 与 stance 的耦合口径生成器未对齐(可参与 ≈ 买入候选)。属可 prompt 校准的口径问题,非研判错误。
  2. **边界票谨慎度 ±1 档**:002913(观望 vs 规避)、688262(规避 vs 观望)差一档;300124 5 日 Claude"弱"、
     生成器"偏空"(生成器更敢承诺方向)。均属谨慎度校准,非方向反向。
  3. **前瞻收益闸门未能落地**:09-11 之后交易日 record 尚未落地(T+1/T+5 不可算),本轮无法用"事后收益"验哪一路更对。

## 5. 我定的默认口径(便于后续拍板调整)

| 项 | 取值 | 理由 |
|---|---|---|
| 输出形态 | extract 结构化(叙事字段一并 extract) | 机读强、对齐 picks_schema、下游 write_picks 零改动 |
| 经验检索 | 关键词/2-gram + 常驻高频纪律(#1~#4) | 轻、可解释;embedding 留后。实测能召回行业相关 + 命中既往教训 |
| 双跑裁决 | 只出报告 + 建议,不自动切 | 分歧人工复核;P2 是闸门工具不是生产开关 |
| think | 先关,作双跑一臂 A/B | 近端不改结论,5 日边界票才分歧;不确定是否值日更耗时 |
| 候选来源 | dry-run 用 Claude PICKS 锚点(同集对比) | 隔离"选股"与"研判"质量,专测研判 |
| 枚举越界 | 兜底保守默认 + 记 coercion | 宁保守待人工,不冒进给最强表态 |
