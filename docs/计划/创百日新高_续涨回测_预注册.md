# 创百日新高 · 后续涨幅回测 · 预注册与执行

> 日期:2026-08-13 · ⚠️ 非投资建议 · 纪律:测前钉死假设 → 执行 → 诚实回填 §4。
> 缘起(策略提供者):"牛市常有创百日新高的股票,想回测创百日新高后续涨得怎么样。比如前几天的百普赛斯、创新药、CXO。"→ 若有 edge 则转策略。

## 0. 与已有结论的关系(为什么值得单测)
我们测过**纯动量(加权对数)在 A 股短期显著为负(IC t=−2.9~−4.0,反转市)**;但:
- "创百日新高"是**离散突破事件**,不是连续动量排序——行为可能不同(极端强势档 D9 当时反而不差)。
- 提供者样例(百普赛斯/创新药/CXO)是**特定强势板块行情**,含**板块 beta + 幸存者偏差**——必须用**全 A 横截面**去偏,不能只看几个样例。
- 可能**强 regime 依赖**(牛市续涨 / 震荡熊市追高即套)。

## 1. 口径(钉死)
- **事件定义**:第 t 日 **收盘价 = 最近 100 交易日最高收盘**(`close[t] == max(close[t-99:t+1])`);另做一版 **当日创 100 日新高(high)**对照。取"**首次/新突破**"(前一日不是新高),避免连续新高重复计数。
- **进场**:t+1 收盘(机械基线,标注非最终买法);另报**当日收盘→t+1 开盘**捕捉隔夜。
- **前瞻**:5/10/20 日收益 + **相对沪深300 Alpha**(同持有期)。
- **样本**:全 A(随机抽样或全量,复用 `backtest_predict._sample_universe`),破板块偏差;窗口约 1.5 年(偏多,声明)。
- **分层**(关键,找 edge 藏在哪):①放量新高 vs 缩量新高(当日量比≥1.5?);②板 20cm(创300/301·科688) vs 主板;③市场状态 regime(若有 view);④叠加均线多头 vs 否。

## 2. ⭐ 预注册假设
| 假设 | 成功判据 | 若不成立·最可能原因 |
|---|---|---|
| **无条件"创新高即买"续涨弱**(与 A 股反转一致) | 新高组前瞻 Alpha 显著>0 且净成本后正 | 追高短期见顶回落(A 股)/ 样例是板块 beta 非 alpha |
| edge(若有)藏在细分:**放量新高 + 趋势/牛市 regime + 20cm 板** | 该细分 Alpha 显著>基准且>无条件组 | 细分后样本太小不显著 |
| 提供者样例的"续涨"是**板块行情 + 幸存者偏差** | 全 A 横截面新高组 ≈ 基准(样例不可外推) | — |

**总预期**:无条件版大概率**弱/不显著**(呼应反转结论);真要有可交易 edge,更可能是"**放量创新高 + 趋势确认**"的细分,而非"创新高"本身。诚实优先——出方向性 + 显著性 + 数据可信度,不硬凑正结论。

## 3. 执行
- 新建 `tools/backtest/backtest_newhigh.py`(信号型事件研究,复用 `backtest_predict`/`backtest_rank` 的无未来函数切片 + 前瞻收益 + 分层写法)。全 A 跑,分层出数。
- 无未来函数红线:新高判定只用 ≤t;前瞻收益 t+1 及之后作标签。
