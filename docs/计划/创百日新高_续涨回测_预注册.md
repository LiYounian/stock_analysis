# 创百日新高 · 后续涨幅回测 · 预注册与执行

> 日期:2026-08-13 · ⚠️ 非投资建议 · 纪律:测前钉死假设 → 执行 → 诚实回填 §4。
> 缘起(策略提供者):"牛市常有创百日新高的股票,想回测创百日新高后续涨得怎么样。比如前几天的百普赛斯、创新药、CXO。"→ 若有 edge 则转策略。

## 0. 与已有结论的关系(为什么值得单测)
我们测过**纯动量(加权对数)在 A 股短期显著为负(IC t=−2.9~−4.0,反转市)**;但:
- "创百日新高"是**离散突破事件**,不是连续动量排序——行为可能不同(极端强势档 D9 当时反而不差)。
- 提供者样例(百普赛斯/创新药/CXO)是**特定强势板块行情**,含**板块 beta + 幸存者偏差**——必须用**全 A 横截面**去偏,不能只看几个样例。
- 可能**强 regime 依赖**(牛市续涨 / 震荡熊市追高即套)。

## 1. 口径(钉死)
- **事件定义**:第 t 日 **收盘价 = 最近 100 交易日最高收盘**(`close[t] == max(close[t-99:t+1])`);另做一版 **当日创 100 日新高(high)**对照。取"**首次/新突破**"(前一日不是新高),避免连续新高重复计数。
- **进场**:t+1 收盘(机械基线,标注非最终买法);另报**当日收盘→t+1 开盘**捕捉隔夜。
- **前瞻**:5/10/20 日收益 + **相对沪深300 Alpha**(同持有期)。
- **样本**:全 A(随机抽样或全量,复用 `backtest_predict._sample_universe`),破板块偏差;窗口约 1.5 年(偏多,声明)。
- **分层**(关键,找 edge 藏在哪):①放量新高 vs 缩量新高(当日量比≥1.5?);②板 20cm(创300/301·科688) vs 主板;③市场状态 regime(若有 view);④叠加均线多头 vs 否。

## 2. ⭐ 预注册假设
| 假设 | 成功判据 | 若不成立·最可能原因 |
|---|---|---|
| **无条件"创新高即买"续涨弱**(与 A 股反转一致) | 新高组前瞻 Alpha 显著>0 且净成本后正 | 追高短期见顶回落(A 股)/ 样例是板块 beta 非 alpha |
| edge(若有)藏在细分:**放量新高 + 趋势/牛市 regime + 20cm 板** | 该细分 Alpha 显著>基准且>无条件组 | 细分后样本太小不显著 |
| 提供者样例的"续涨"是**板块行情 + 幸存者偏差** | 全 A 横截面新高组 ≈ 基准(样例不可外推) | — |

**总预期**:无条件版大概率**弱/不显著**(呼应反转结论);真要有可交易 edge,更可能是"**放量创新高 + 趋势确认**"的细分,而非"创新高"本身。诚实优先——出方向性 + 显著性 + 数据可信度,不硬凑正结论。

## 3. 执行
- 新建 `tools/backtest/backtest_newhigh.py`(信号型事件研究,复用 `backtest_predict`/`backtest_rank` 的无未来函数切片 + 前瞻收益 + 分层写法)。全 A 跑,分层出数。
- 无未来函数红线:新高判定只用 ≤t;前瞻收益 t+1 及之后作标签。

## 4. 执行结果与分析(2026-08-13 回填)

> harness:`tools/backtest/backtest_newhigh.py`。全 A 5166 只、首次创100日新高(收盘)事件 **28,011 个**,但仅落在 **215 个交易日**→ 事件强聚集,**朴素 t 被高估 20~30 倍**,全程以**按进场日聚类 t** 为显著性下界(基准20日收益 朴素t=152 vs 聚类t=5.9)。窗口 2025-03~2026-08(≈314日,偏多)。无未来函数已核实。

### 4.1 无条件"创新高即买" —— ❌ 无 edge(假设①成立)
- 前瞻 Alpha:5日 −0.01% / 10日 +0.12% / 20日 −0.12%,**没有一个 horizon 聚类 t 显著**(≈0)。且新高组**胜率 40~43% 低于基准 49~51%**(追高后中位偏负、右偏)。

### 4.2 分层 —— ❌ 假设② REJECT,且方向相反
| 分层 | 20日 Alpha(聚类t) | 结论 |
|---|---|---|
| 放量(量比≥1.5) | +0.05%(−0.9) | 无 |
| 20cm 板(创/科) | +0.14%(0.5) | 不稳 |
| 主板 | −0.30%(−1.9) | 偏负 |
| **均线多头(>MA200 且 MA5>10>20)** | **−1.06%(−2.67)** | **显著负** |
| **放量+均线多头**(预注册最看好) | **−0.70%(−2.71)** | **显著负** |
| **regime 上行(HS300>MA20)** | +0.42%(20日);**5/10日 +2.6/+2.8 显著正** | 唯一正向 |
| regime 下行 | −1.84%(−3.0) | 显著负 |

- **放量没用;"趋势确认(均线多头)"不但没帮助反而显著为负** → 经济含义:在已走出 MA200 多头+均线发散的**延伸段**再追新高 = **追在后期、均值回归**。与预注册预期**相反**。
- **真正分水岭是市场 regime,不是个股特征**:牛市追新高短期正、熊市显著负。但这是**择时叠加层(=吃市场 beta),不是选股 alpha**。

### 4.3 假设③成立 + 一个有意思的连接
- **提供者样例(百普赛斯/CXO/创新药)的续涨 = regime + 板块行情 + 幸存者偏差**,全 A 横截面下新高组 ≈ 基准,**不可外推**。
- ⭐ **一个小而稳的正效应**:新高组**隔夜(当日收→次日开)+0.22%,聚类t +2.74**——动量以**隔夜跳空**体现、随后日内消退。**这恰好落在"突破当天竞价/开盘"进场那一下**,t+1 收盘进场吃不到。→ **与箱体提供者说的"买点=突破当天竞价"呼应**:那点微弱动量真在开盘跳空里,但计成本后能否为正存疑。

### 4.4 结论:是否转策略 —— 不建议做成独立选股策略
- 无条件创新高无 edge;"趋势确认版"显著为负;唯一正向是 **regime 择时(买牛市新高)= 市场 beta,非选股 alpha**。
- 与全局主线一致:**A 股短期"见光死/追高回落"**,追突破/追新高族反复失灵。
- **唯一残留、值得单独深挖的线索**:创新高的**隔夜跳空动量**(+0.22%,t=2.74)——需**竞价/开盘进场**才吃得到,且要验净成本后是否为正。这跟箱体那条"竞价买入"是同一个东西,建议合并到箱体那条线一起验(见 `箱体重构_交接与需求.md`)。
- **数据可信度**:窗口仅 1.5 年、regime 分层 138/77 日偏薄、MA200 分层覆盖缩水、新高股中小盘 vs 沪深300 大盘有残余 size 因子——结论对本窗口敏感,非长期定论。
