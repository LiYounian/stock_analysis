## 2. P2-A 基本面采集(本轮实施)

### 数据源(已实测本机可用)
| 数据 | 源 | akshare 函数 |
|---|---|---|
| 营收/净利/增速/ROE/毛利率/净利率/负债率 | 同花顺 | `stock_financial_abstract(symbol)` |
| PE(TTM)/PB/总市值 | 百度 | `stock_zh_valuation_baidu(symbol, indicator, period)` |
> 东财系(`stock_individual_info_em`/`stock_value_em`)不稳/被指纹墙,不用。

### 拆解
| 函数(`collectors/fundamental.py`) | 输入 → 输出 |
|---|---|
| `fetch_fundamental(codes)` | 拉两源合并 → 落 `data/raw/fundamental/{code}.json`,返回 `{code: dict}` |
| `load_fundamental(code)` | 读缓存 |

单票输出契约:
```
{
  "报告期": "20260331",
  "营收": float, "净利": float, "营收增速": float, "净利增速": float,
  "ROE": float, "毛利率": float, "净利率": float, "负债率": float,
  "PE_TTM": float, "PB": float, "总市值": float,
}
```
- 指标名映射(同花顺):营业总收入 / 归母净利润 / 营业总收入增长率 / 归属母公司净利润增长率 / 净资产收益率(ROE) / 毛利率 / 销售净利率 / 资产负债率。
- 取最新报告期列(df 第 3 列);百度估值取时间序列最后一个值。
- 某源失败 → 对应字段 None,不中断整批(与 market 一致)。

### 报告(扩 `report/builder.py`)
- 组合层新增"基本面对比":按板块聚合 PE/ROE/净利增速中位数;估值分位。
- 单票卡新增"基本面"章节(接在技术面后)。

### 测试(`tests/test_fundamental.py`)
- mock 两源,验证:指标名映射正确、最新期选取、缺字段容错、落盘/读盘往返、某源失败降级。

## 4. 验收标准
- [ ] 关键指标数值抽查与外部一致(容差)。
- [ ] 某源失败时字段降级为 None 不崩。
- [ ] 指标名映射用测试钉死(防 akshare 改版静默错位)。

## 5. 风险
- 同花顺/百度接口改版(登记 R1)→ 指标名/参数容错,不硬编下标。
- 百度估值 indicator 中文名(总市值/市盈率(TTM)/市净率)可能变 → 命中失败则该字段 None + 日志。
