# 策略1 修正理解 与 回测重设计 · 2026-08-10

> 源:与策略提供者对话后,发现此前理解偏差,回测口径需改。本文档留痕修正后的理解 + 重设计方案。
> ⚠️ 非投资建议。

## 一、提供者原话(修正后的真实意图)
> "这是一个**识别哪个股票在被庄家做低吸**的策略,而不是单纯的买入策略。这个只是选出来**暴力洗盘**的股票。后面的选择有两个:
> 1. 如果继续洗盘,那就是**不跌破策略一的最低点**的话,**低吸**。
> 2. 如果**直接反包策略一高点**,就**追**。
> (这两个操作和判断都很主观,也有实时性)。回测可以测一下**午休选股然后下午开盘买入**的买点效果。"

## 二、我们此前理解偏差 → 旧回测作废
- 旧口径:把策略1当"买入策略",**信号日收盘 P0 建仓 + 5 条离场状态机**撮合。
- 实际:策略1 **只是筛选器**(识别"被暴力洗盘/庄家做低吸"的候选);**买点是后续两条条件化、主观、实时**的决策,不在筛选内。
- 所以旧回测"胜率12.6%/即死86.5%/救不活"是**测错了对象**(测的是"信号日收盘买"这个提供者从没说过的买法)——**该结论对策略1本意不成立、作废**。筛选器本身(选出暴力洗盘强势股)未被证伪。

## 三、定位重述
- **策略1 = 「筛选低吸股票」**:识别被资金暴力洗盘/做低吸的候选(现有 C1–C4 大体刻画:均线多头+贴近52周高+近10日偏强+当日暴跌收阳=强势股当日被暴力砸)。
- **买点(不在筛选内,后续决策)**:
  - **低吸**:信号后继续洗盘、**不跌破策略1信号日最低点** → 低位吸。
  - **追**:价**反包/突破策略1信号日最高点** → 追入。
  - **买点时机(提供者建议测)**:**午休(11:30)选股 → 下午开盘(13:00)买入**。

## 四、回测重设计(客观化 低吸/追,可回测)
把主观买点客观化成可回测规则(每条独立测):
- **追(突破)**:信号后 N 交易日内,若价突破信号日 HIGH → 在突破点买入 → 测后续收益。
- **低吸(不破低)**:信号后价回踩但**未跌破信号日 LOW** → 在回踩日买入 → 测后续收益。
- **买点时机**:提供者要的是"午休选股→下午开盘买"——**需盘中/分钟数据**(午休快照价 + 下午开盘价)。**我们当前只有日线 OHLC**,是本次的数据缺口。

## 五、数据缺口 + 方案(待用户定,见对话)
- **只有日线** → "午休选股+下午开盘买"精确买点做不了;低吸/追的"是否触发"可用日线近似(是否破高/破低),但买入价用日级近似(开盘/收盘),与"下午开盘"有偏差。
- 方案 A(快):日线近似先跑 低吸/追 两条路径,看方向有没有 edge(不用新数据)。
- 方案 B(精确):接分钟行情源(akshare/baostock 分钟线),精确测"午休选股→下午开盘买"。
- 方案 C(暂缓回测):策略1 先纯当筛选器展示"低吸候选",买点主观/实时、回测意义有限,等定了客观买点再测。

## 六、离场/风控
提供者这次没改离场;但买点变了(不是信号日收盘进),离场状态机的锚点(P0)也要跟着改成"实际买入价/日",重设计时一并调整。
