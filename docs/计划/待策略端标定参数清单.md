# 待策略端标定参数清单（形态选股 V1 + 市场状态 + 多因子）

> 用途：把当前所有"占位/待策略端定"的参数汇成一张可交付清单，策略同事照着填。
> 单一真源：全部在 `tools/config/strategy.py` 的 `THRESHOLDS`（改这里即生效，程序不散写硬编码）。
> 日期：2026-08-08 · 分支：`docs/strategy-calibration-checklist` · 仅文档、不改代码。
> 现状口径：本文所列**均为占位默认，系统已能跑通**；"不定则现在怎样"列诚实标注每项不标定时的降级/偏差。

## 一、结论先行

### A. 必须先定（不定则该功能不可用或严重失真，占位跑出的结论**不能当决策依据**）
1. **核心龙头池**（`市场状态.核心龙头池`，现 `[]`）——空则"科技共振"因子**直接降级缺失**，市场状态只剩 4/5 因子。
2. **形态几何参数**（箱体/杯柄/楔形/旗形各阈值）——杯柄/箱体等**无业界唯一定义**，占位阈值会导致**检出漂移**（漏真形态或纳假形态），达标池形态质量未校准。这是模块二选股的核心。

### B. 可先用占位跑通，待数据/回测标定（不定则用占位，流程完整但刻度/边界未校，结论有偏差）
- **市场状态五档边界**（`市场状态.五档`）——现等分占位，分档能出但不代表真实市场分布。
- **宽度参考占比**（`市场状态.宽度参考占比`，0.05）——达标占比→[0,1] 归一的刻度，占位。
- **护栏三阈值 + 正向确认阈值/关键词**——通用默认已合理，可直接用；标定是"调优"非"启用前提"。
- **多因子权重/标准化/窗口**——等权 + 分位是稳健起步；待回测 IR 调权。
- **RS 达标阈值 / 板块最小样本**——0.0=跑赢即达标（合理默认），一般无需改。

### C. 数据缺口（需决策是否补数据源，见 §四）
- **股息率、北向个股明细** 本机拿不到 → 多因子的"股息""资金流"两维**现降级缺失**（多因子实得 4/6）。要转正需上 Tushare 或换源。

> 一句话给策略端：**先定 A 组两项**（龙头池 + 形态参数），系统就能产出"可参考"的选股/择时；B 组待攒够回测数据再闭环调；C 组决定要不要花 Tushare 积分补两维因子。

## 三、必须先定 vs 可占位（速览）

| 组 | 参数 | 不定的后果 |
|---|---|---|
| **必须先定** | 核心龙头池 | 科技共振因子**缺失**（市场状态少一维） |
| **必须先定** | 形态几何参数（4 形态） | 达标池形态质量未校，**选股结论不可当决策依据** |
| 可占位·待回测 | 五档边界 / 宽度参考占比 / 多因子权重 / 护栏与正向阈值 | 用占位跑通，刻度/边界未校、结论有偏差 |
| 数据缺口 | 股息率 / 北向个股 | 多因子两维降级，实得 4/6 因子 |

## 四、数据缺口与补齐建议

现两项因子数据本机拿不到（已在多因子里降级"缺失"，其余 4 因子照算）：

| 缺口 | 现状 | akshare 现状 | Tushare 补齐接口 | 成本（积分门槛，约） | 建议 |
|---|---|---|---|---|---|
| **股息率**（多因子·股息） | 中心记录无此字段 → 该因子缺失 | 百度估值/同花顺摘要均不含；东财相关口径被墙 | `daily_basic`（字段 `dv_ratio`/`dv_ttm`） | 需 token + 约 2000 积分 | 若要股息因子转正，上 `daily_basic`；否则接受 5/6 因子 |
| **北向个股明细**（多因子·资金流 D8） | 东财个股北向接口本机签名/返回不稳定 → 缺失 | `stock_hsgt_individual_em` 本机不可用（见 `collectors/northbound.py` 已留接口） | `hk_hold`（陆股通个股持股）/ `moneyflow_hsgt`（市场级） | 个股 `hk_hold` 需 token + 约 5000 积分 | 个股北向价值有限且积分高，**建议暂缓**；市场级北向可先做大盘情绪辅助 |

> 说明：Tushare 需注册 token + 积分（积分靠充值或社区贡献累积）。上不上由策略端按"因子边际价值 vs 积分成本"决定；不上则多因子长期运行在 4/6 因子（质量/价值/低波/成长），系统不受影响、只是少两维。

## 五、如何验证标定效果（闭环）

1. 填入 A 组（龙头池 + 形态参数）→ 跑 `screen_pattern` 出达标池、`regime` 出市场状态。
2. 让 scheduler 每交易日盘后落 达标池/市场状态 view，积累 ≥1–2 月快照。
3. 跑 `pattern_forward`（批次C）看达标池前瞻 5/10/20 日 **胜率 / Alpha / regime 择时增益**。
4. 据回测结果反标 B 组（五档边界按情绪分分布、多因子权重按 IR、护栏/正向阈值按剔除效果）→ 闭环调参。
