# SEPA + VCP 监控 前瞻回测报告 · 2026-08-22

> ⚠️ **非投资建议。** 本文是对 A 股全市场公开行情做的历史统计,仅用于验证监控工具的方向性设计意图,不构成任何买卖建议。
>
> ⚠️ **口径先说清:方向性 sanity + 标签分层验证,非全 A alpha。** SEPA+VCP 是**看多型盘后监控工具**,定位为**过滤器 + 人工翻图**(缩小翻图面,不含精确买点/自动交易)。本回测验证两件事:(1) 各标签层入池后前瞻是否偏正、是否相对基准有方向性;(2) **「越靠近枢纽方向性越强」的设计直觉是否成立**(技术合格池 → VCP进行中 → 接近枢纽 的梯度)。**不以绝对 alpha 为验收**(需求预注册:趋势/收缩类 A 股 alpha 多不显著,价值在缩小翻图面)。

---

## 一、方法(walk-forward,无未来函数)

- **数据**:全 A 前复权日线主档,5,131 只(排北交所;历史 <220 根剔除),跨度 2018-01-02 → 2026-08-21(约 8 年,多行情段)。
- **测试日**:全跨度 stride=60(约一季)抽样 + regime 覆盖,取距样本末 ≥20 交易日者(留足 T+20)。相邻测试日前瞻窗不重叠 → 近似独立。
- **喂数口径**:每测试日 t 喂近史尾部 500 根(与线上 `load_kline_recent` 一致),策略函数只读 ≤t(纯函数,无未来函数)。
- **标签定义**(逐票在 t 重算):
  - **技术合格池**:SEPA 三均线门(收盘 > MA50 > MA150 > MA200、MA200 向上、站上 MA50/MA200)。
  - **VCP进行中**:末对轮次硬收缩(振幅缩小 + higher-low)且结构未破坏。
  - **接近枢纽**:进行中 + 量枯 + 距前高近(≤距高%)+ 未破坏。
  - **结构破坏**:收盘跌破前轮低点 >失效%(作为**反向对照**,预期最弱)。
  - 注:**「新候选」** 需「首日入池 + 星标」的连日 pipeline 状态,稀疏测试日无法廉价复原,**本回测不单列**(不影响梯度验证)。
- **前瞻窗口**:T+1 / T+5 / T+10 / T+20,进场锚定测试日后首个交易日,复用 `event_study`。
- **双基准**:全 A 等权 baseline(同宇宙无条件对照)+ HS300;Alpha = 命中前瞻 − HS300 前瞻。
- **A/B 标定(占位阈值)**:pivot 窗口 ∈ {2,3,4} × 距前高% ∈ {6,8,10} × 失效% ∈ {1.0,1.5,2.0},聚焦「接近枢纽」层的样本量-方向性权衡,给人工标定依据。
- **口径澄清**:任务书曾把 `min_rps 70/80/90` 列于本工具,但代码中 SEPA+VCP **无任何 RPS/相对强度项**(min_rps 属趋势模板);经统筹确认,本工具 A/B 用其真实占位阈值 pivot/距高/失效,不加 RPS(加 RPS = 改策略语义,超出补回测范围)。

## 三、诚实结论

1. **短窗枢纽梯度成立(设计意图得到支持)**:T+5(≈1 周)方向性单调梯度 **接近枢纽 +0.60% > VCP进行中 +0.25% > 技术合格池 +0.04%**,接近枢纽 T+5 且跑赢全 A baseline(+0.09%);T+1 亦为 接近枢纽>VCP>技术 的正梯度。→ 作**短线枢纽临近排序 / 缩小翻图面**的监控信号,设计成立。
2. **无中期超额**:T+10/T+20 各标签层与 baseline 同步转负(接近枢纽 T+20 -1.82% 未跑赢 baseline -0.41%),与预注册"不以入池 alpha 为验收"一致。作中期 alpha 源不成立。
3. **regime 条件性**:牛市正、震荡显著负(技术合格池震荡 T+10 -2.88%);聚合负值主因样本震荡日占多。
4. **阈值标定建议**:**pivot 窗口是唯一有意义的主控**——建议 **pivot=3–4**(默认 3 合理,4 对中期回撤更稳,代价样本更少);**距前高% / 失效% 无需精调**(影响 <0.1%),失效% 保守留 1.5% 即可。「接近枢纽」样本随窗口收紧显著变薄(pivot4 距高6 仅 2,443),标定须兼顾样本量。
5. **定位(独立工具)**:合格的**盘后监控 / 缩面 + 短线枢纽排序**工具;**不合格**作自动交易或中期 alpha 信号。价值 = 把 400+ 只压到几十只值得人工翻图的票,并按枢纽临近度排序。

---

## 四、局限与后续

- **梯度是核心产出**:本工具价值不在绝对超额,而在「按标签把 400+ 只压到几十只值得翻图的票」。若「接近枢纽」层方向性显著强于技术合格池,即支持监控设计。
- **接近枢纽样本偏薄**:越靠枢纽样本越少(见 A/B 表 N),熊段更薄,估计噪声大,阈值标定须结合样本量看,别只看均值。
- **结构破坏层为反向对照**:样本少且含「破位后反抽」噪声,不宜单独解读。
- **新候选未回测**:连日状态依赖,留待线上 pipeline 观察或后续带状态的回放专项。
- **右偏/动量**:胜率多低于 50% 而均值为正,收益靠右尾,须配风控。
