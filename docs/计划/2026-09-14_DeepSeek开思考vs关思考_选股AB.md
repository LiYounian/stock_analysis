# DeepSeek 开思考 vs 关思考 · 选股 A/B 报告（v2 候选池 · 16 日）

> 日期：2026-09-14　分支：`feat/deepseek-thinking-ab`（基于 `feat/shadow-pool-v2 @ 38b986f`）
> 铁律：测试环境研究模拟，**非投资建议**；本轮只建 + 验证，**不切生产 / 不动 live SKILL / 定时任务 / registry / settings**。
> artifacts（脚本 / units / 打分 / reasoning 样例）：`2026-09-14_DeepSeek开思考vs关思考_选股AB_artifacts/`

## 一、结论先行（TL;DR）

- **开思考≠更好的选股。** 在同一 v2 候选池、同 16 日、同经验库下，把 deep_analysis 的模型端点换成
  compatible-mode（真思考激活）后：**买入侧 α 在统计上与关思考无法区分**（T+1 日均 α +0.027 vs +0.009，
  SE≈0.3，两者都≈0），**命中率略降**（0.40 vs 0.42），**T+5 反而更差**（α −1.24 vs −0.02，小样本，见局限）。
- **开思考更"敢动"但不是单纯变松。** 它双向重排表态：32 例 观望→可参与（转买入侧）、20 例 可参与→观望/规避
  （退出买入侧，含 4 例直接 →规避）；净多 12 票买入（65 vs 53）。字段一致率低（stance 49%、方向 44~51%、
  置信 37~39%），说明思考确实改变了大量个股表态——但**改动没有换来可测的 α 收益**。
- **09-02 的"过保守"不是研判层能修的。** 开思考在 09-02 的 15 只 v2 候选上**同样给 0 买入**。当日 Claude
  live 漏掉的 002811(+7.8%)/603270(+10.0%)**根本不在机械 v2 候选池里**——这是**候选池覆盖问题，不是研判
  保守问题**。换开思考对此无能为力。
- **成本/时延日更用得起，但不值当。** 开思考 ~41s/票、~4486 tok/票（关思考 ~2s/票）；日更收盘后
  8~15 只候选，5 并发 ~2~10 分钟即可跑完，token 走网关不烧 Bedrock。**时间上可行**，但**既然 α 无实质
  提升、T+5 更差，不建议为它切生产**。
- **开思考真正的价值在"可审计的多因子推理链"**，适合**边界票 / 关键日的人工复核辅助**，不适合无人值守的
  headless α 引擎。**建议：不切生产常开思考；如需，仅在关键日 / 边界票做 human-in-the-loop 混合调用。**

## 二、实验设置

| 项 | 关思考臂（基线，复用） | 开思考臂（本轮真跑） |
|---|---|---|
| 端点 | `LLM_BASE_URL`（`.../qwen/v1`） | `QWEN_BASE_URL`（`.../qwen/compatible-mode/v1`） |
| 模型 | deepseek-v4-pro | deepseek-v4-pro（**同模型**，非 qwen） |
| 思考 | 未激活（秒回、无 reasoning_content） | 真激活（~40s、reasoning_content ~1500 tok） |
| 候选池 | v2 三段式（强度排序+质量闸门+交叉确认） | **同一 pool_v2_<date>.json**（逐票完全一致） |
| 研判 | `deep_analysis.generate`（经验检索+SOP prompt+schema） | 同 pipeline，**仅注入 ThinkingClient** |
| 样本 | 16 日 · 204 票 · 0 错误 | 16 日 · 204 票 · 0 错误 |

两 base 用同一把 key（`LLM_API_KEY == QWEN_API_KEY`）。开思考臂**只注入客户端**，未改 registry/settings/
生产 client（`ThinkingClient` 为 `OpenAICompatClient` 子类，`chat()` 发 `extra_body={"enable_thinking":True}`
并把 `max_tokens` 调到 4096——思考 token 计入输出，默认 2048 会截断最终 JSON）。

**Smoke 验证（先 2 票）**：extract 吐出的 schema JSON **合规、0 coercion、content 无 `<think>` 污染、无截空**。
原因：OpenAI SDK 对 compatible-mode 端点把思考链放 `message.reasoning_content`、最终答案放 `message.content`，
父类 `chat()` 只取 `content`，故 `_extract_json` 正常解析。**踩坑护栏**：`ThinkingClient` 仍加了 `<think>` 剥离
兜底 + `content_empty` 监控（全程 0 命中），并把 `max_tokens` 提到 4096 防思考挤断 JSON。

## 三、五维对比

### 维度 1 · 字段一致率与表态迁移（共同票 n=204）

| 字段 | 一致率 |
|---|---|
| type | 70.1% |
| dir_5d | 51.0% |
| stance | 49.0% |
| dir_1d | 44.1% |
| dir_1d_conf | 38.7% |
| dir_5d_conf | 36.8% |

思考显著改变个股表态（近半 stance、过半方向/置信被改）。**买入侧迁移 52 例**：32 转买入侧（多为 观望→可参与）、
20 退出买入侧（可参与→观望/规避，含 08-24 300945、08-26 300122/300107/000720 共 4 例直接→规避）。**净 +12 票买入**。
→ 结论：思考不是单纯放松，而是**双向重排**；净效果略偏敢买。

### 维度 2 · 选股质量 / α（买入侧 = stance∈{买入,可参与}，基准=当日全A等权 forward_scorecard）

| 指标 | 关思考 | 开思考 |
|---|---|---|
| ≥1 买入日 | 14/16 | **15/16** |
| 总买入票 | 53 | **65** |
| 买入侧 T+1 日均 α（pp）±SE | +0.009 ± 0.406 | +0.027 ± 0.280 |
| 买入侧 T+1 pooled 命中 | **0.42** | 0.40 |
| 买入侧 T+5 日均 α（pp） | **−0.016** | −1.242 |
| 买入侧 T+5 pooled 命中 | **0.44** | 0.33 |
| 看多方向侧 T+1 日均 α | −0.172 | −0.144 |

- **T+1**：开思考 α 略高但**两臂都在 0 附近、SE≈0.3**，差异**不显著**；命中率反而略低。
- **T+5**：开思考明显更差（α −1.24、命中 0.33）。**但 T+5 只覆盖 ≤2026-09-04 的日子**（`T5_CUTOFF`），
  买入最密集的 09-08/09-10 未计入，pooled_n 仅 46/48，**小样本，勿过度解读**；方向上不利于开思考。
- **看多方向侧**（dir 偏多，含观望）两臂都是负 α——程序化池上"看多方向"本身不带正 α，思考未改变这点。

### 维度 3 · 能否修"过保守"（重点：09-02）

- 关思考 09-02：0 买入（9 观望 + 6 规避）。**开思考 09-02：同样 0 买入。**
- 当日 Claude live 漏掉的 002811(+7.8%)/603270(+10.0%)**不在 15 只机械 v2 候选池内**。
- → **09-02 的过保守是候选池覆盖问题，不是研判层保守**。开思考在"池子里没有赢家"时，再深的推理也变不出赢家。
  要修 09-02 这类日，应从**候选池召回**下手，而非研判开思考。

### 维度 4 · 质量抽检（3 只边界票 · 观望→可参与）

| 日期 | 代码 | 名称 | 关→开 | T+1 | T+5 |
|---|---|---|---|---|---|
| 08-14 | 300515 | 三德科技 | 观望→可参与 | +0.12 | −0.42 |
| 09-09 | 301345 | 涛涛车业 | 观望→可参与 | −1.57 | — |
| 09-10 | 605098 | 行动教育 | 观望→可参与 | −0.27 | — |

读 300515 的 reasoning_content（2647 字）：**确是真多因子权衡**——技术（多头/超买 KDJ J90/BIAS 远离）、
估值（PE 17.27、ROE 3.5%）、消息面（减持届满未实施=利好、中标传闻未达披露=中性偏空、质押风险=利空）、
情绪质量（partial）、系统合议（技术看多 vs 情绪/事件看空→冲突中性），**甚至主动指出原料自相矛盾**
（"超跌=False 但拐点标签=超跌待反弹，取系统合议"）。**推理链质量真实、可审计**——但它在明知冲突的情况下
仍把 观望 升为 可参与，3 只里 2 只 T+1 收跌。→ **深思考带来更好的"解释"，未带来更好的"决策"**；反而倾向为
更激进的表态找理由。

| 指标 | 值 |
|---|---|
| 时延 均值 / 中位 / P90 / 最大 | 41.0s / 39.9s / 56.5s / 75.1s |
| completion tok 均值（含 reasoning 1527） | 1866 |

- **日更可行性**：收盘后单日候选 8~15 只，5 并发下 ~2~10 分钟跑完，无超时风险（最大 75s < timeout 180）。
  **时间/成本上日更用得起。**
- 关思考 ~2s/票，开思考 ~41s/票（约 20× 时延、~5~10× token）。**代价明确，但因 α 无实质提升，性价比不成立。**

## 四、结论与建议

1. **不建议把生产日更选股切到常开思考端点。** 依据：买入侧 T+1 α 与关思考无统计差异、命中略降、T+5 更差
   （小样本）；额外成本（~20× 时延、~5~10× token）换不到可测收益。
2. **09-02 类"过保守"要从候选池召回修，不是研判开思考。** 赢家不在池里，研判再深也无用。
3. **开思考的价值定位 = 可审计的多因子推理链**，宜用于**关键日 / 边界票的人工复核辅助**（human-in-the-loop），
   帮人做判断；**不宜**作无人值守 headless α 引擎。
4. **可选混合策略（待拍板）**：日更主链仍关思考（快/省）；仅对**边界票**（如系统合议冲突、stance 处于
   观望/可参与临界）或**关键日**触发开思考做二次复核，产出 reasoning 供人工看——但需先证明"边界票开思考"能
   提 α，本轮 3 只边界抽检 2 跌 1 平，**暂无正证据**，建议先扩样再定。

## 五、局限与诚实标注

- **样本小**：16 日 · 买入侧 pooled 53/65 票；日均 α 的 SE≈0.3pp 远大于 α 本身，**任何 α 优劣结论都不显著**，
  本报告只作方向性判断，不足以支撑切生产。
- **T+5 覆盖不全**：仅 ≤09-04 的日子已结算，买入最密集日未计入，T+5 结论尤其脆弱。
- **temperature=0 但思考模型有内生随机性**：同 prompt 重跑表态可能微变；本轮每票单跑，未做重复性估计。
- **reasoning_content 未随 units 落盘**（仅存 4 字段研判结果 + call_stats）；维度 4 的推理链系事后对 3 只
  重新捕获（`reasoning_cases.json`），与全量跑非同一次调用，仅作定性佐证。
- **基准**为全A等权 forward_scorecard，非行业/风格中性化；α 含 beta/风格暴露噪声。
- 非投资建议；测试环境研究模拟。
