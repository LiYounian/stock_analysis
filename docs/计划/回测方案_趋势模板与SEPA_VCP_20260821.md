## 一、目标与定位（先说清口径，避免误读）

两策略都是**看多 / 趋势型筛选器**，定位是**过滤器 / 研究工具 / 缩小人工翻图面**，**不追绝对 alpha**。

- 已知先验（两个需求文档都预注册了）：趋势模板类信号在 A 股 **Alpha p=0.87 不显著**。本回测**不以入池 alpha 为验收门槛**，只做**方向性 sanity**：验证「入池后前瞻收益是否偏正、是否相对全样本/HS300 有方向性倾斜」，符合设计意图即通过。诚实呈现，弱 edge 就说弱。
- 验收判据（方向感知，看多型）：命中组 T+N 前瞻均值 **≥ 全样本 baseline** 且 **≥ HS300 同窗**，胜率与右偏特征如实报告；不足以定论的样本量明确标注。

## 三、方法：walk-forward 测试日回放（无未来函数）

复用 `tools/backtest/event_study.py` 的 `forward_returns` + `summarize`（不造轮子）。设计与既有 S03 报告同构（测试日抽样 + 命中/baseline/HS300 三组对照）。

### 3.1 测试日抽样（覆盖多行情段）
- 在 2018–2026 全跨度按**固定步长抽样测试日**（约每 15 个交易日一档），并**保证每个主要 regime 段 ≥3 个测试日**：2018 熊 / 2019 修复 / 2020 V 型 / 2021 结构牛 / 2022 熊 / 2023 震荡 / 2024 底部+9 月急涨 / 2025–2026。目标 **~30–40 个测试日**（对齐 S03 的 27 日量级，控算力与前瞻窗口重叠）。
- regime 标签：用 `tools/pipeline/regime.py`（若可分类）或 HS300 均线状态给每个测试日打 牛/熊/震荡 标，分层报告。

### 3.2 前瞻窗口与方向感知
- 窗口：**T+1 / T+5(≈1 周) / T+10(≈2 周) / T+20(≈1 月)**（票可能第二周才动，故到 T+20）。
- 进场锚定：事件日（测试日）后**首个交易日**（含执行滞后），`event_study` 已内建；越界窗口记 `None` 不补。
- 三组对照（每窗口给 均值 / 胜率 / 相对 HS300 超额）：
  1. **命中组**：该测试日入池的票。
  2. **全样本 baseline**：同测试日全 A 有效票的同窗前瞻均值（无条件对照，几乎零额外成本）。
  3. **HS300 基准**：同测试日同窗指数前瞻。
- 方向判据：命中组均值 > baseline 且 > HS300 → 方向对；否则如实报不显著/无 edge。

### 3.3 无未来函数保证
两策略入池函数均为**纯函数、只读 ≤t**：趋势模板 `conditions.evaluate(kline, t, rps250)`；SEPA `sepa_pass(kline, t)` + `analyze_vcp(kline, t)`。测试日 t 只喂 `iloc[:t+1]`，前瞻收益取 t 之后价格，天然隔离。

### 3.4 近期肉眼验收
取**最近一个交易日（2026-08-21）**入池票，逐票列出各可得窗口表现（T+20 因距今不足会缺，缺就标注可得窗口）。对齐 S03 报告的「近期肉眼验收」小表 `代码 | T+1 | T+5 | T+10 | T+20`。

## 四、趋势模板（Minervini 8 条）具体口径

- 入池 = **完整模式**（A1–A8 全真；RPS250 = 全 A 横截面 Return250 百分位）。基础模式（A1–A7，无 RPS）作为对照顺带出。
- **A/B 标定（本策略的占位阈值就是 RPS 门）**：`min_rps ∈ {70, 80, 90}`（`THRESHOLDS["趋势模板"].min_rps`，传 `cfg` 覆盖）。另可选对 A7 `max_distance_from_52w_high ∈ {0.75, 0.85}`（距 52 周高 25%/15%）做一档敏感性。
- RPS 计算：每测试日对全 A 算 Return250 → `rps.rps_from_returns` 百分位 → 喂 `evaluate` 的 A8。
- 最小历史 250 根（硬门）。

## 五、SEPA+VCP 具体口径（按标签分层）

- **技术合格池**：`sepa_pass` 三均线门（收盘>MA50>MA150>MA200、MA200 向上、站上 MA50/MA200）。
- **重点观察池分层**（各自单独算前瞻分布，验证「越靠近枢纽越该偏正」的设计直觉）：
  - `技术合格池`（SEPA 全体）
  - `VCP进行中`（硬收缩：振幅缩小 + higher-low）
  - `接近枢纽`（进行中 + 量枯 + 距前高近 + 未破坏）
  - `结构破坏`（跌破前轮低点，作为**反向对照**，预期应偏弱/转负）
  - 说明：`新候选` 需「首日入池 + 星标」的连日状态（pipeline 从前日视图取），测试日稀疏抽样下无法廉价复原，**本回测不单列新候选**，在报告注明。
- **A/B 标定（占位阈值）**：`pivot窗口 ∈ {2,3,4}` × `距前高近% ∈ {6,8,10}` × `失效跌破% ∈ {1.0,1.5,2.0}`（传 `cfg` 覆盖 `THRESHOLDS["SEPA_VCP"]`）。给「肉眼标定」依据（各阈值组合下 接近枢纽 组的前瞻/样本量权衡）。
- **⚠️ 口径澄清（需统筹知悉）**：任务书把 `min_rps 70/80/90` 列在 SEPA+VCP 下，但**代码里 SEPA+VCP 无任何 RPS/相对强度项**——`min_rps` 只存在于趋势模板。故本方案把 `min_rps 70/80/90` 的 A/B **归到趋势模板**（第四节），SEPA+VCP 的 A/B 用其真实占位阈值 pivot窗/距前高%/失效%。若统筹本意是「给 SEPA 也加一道 RPS 前置过滤」，那是**改策略语义**，超出「补回测」范围，需另立需求——先按现状口径回测。

## 六、脚本结构（先框架后实现，复用 harness）

```
tools/backtest/backtest_trend_template.py   # 趋势模板 walk-forward 驱动
tools/backtest/backtest_sepa_vcp.py         # SEPA+VCP 分层 walk-forward 驱动
```
两脚本共用骨架（仿 `backtest_s02.py` 的「全 A 循环 + 离线 load_kline + _load_bench」），但把出场状态机换成 `event_study.forward_returns/summarize`：
1. `list_test_days(master_span, stride, regime_tag)` → 测试日列表 + regime。
2. 预加载全 A `load_kline`（一次，仿 `scan_s01.load_all`），按测试日切片。
3. 每测试日：算 RPS（趋势）/ 跑入池函数 → 命中组事件日集合（按标签分桶）。
4. `forward_returns(events, kdf, windows=(1,5,10,20), benchmark_df=bench)` → `summarize` → 聚合到 组×窗口×regime。
5. A/B：外层遍历阈值网格，复跑步骤 3–4。
6. 产物 JSON 落 worktree（scratchpad / `data/analysis` 本地），报告落 `docs/计划/`。
- CLI：`python -m tools.backtest.backtest_trend_template [--test-days N] [--stride K] [--min-rps 70,80,90] [--out PATH]`（SEPA 同构，A/B 参数换成 pivot/距高/失效）。
- 开发后配轻量断言测试（锁「无未来函数」「BJ 已排」「命中组样本 N>0」「阈值网格全跑到」语义）。

## 八、诚实预期（预注册）

- 大概率：两策略方向性偏正但 edge 弱、右偏/动量特征、Alpha 不显著（与 p=0.87 先验一致）。
- SEPA 分层预期：`接近枢纽` ≥ `VCP进行中` ≥ `技术合格池` 的方向性梯度（若成立，支持「越靠枢纽越值得看」）；`结构破坏` 应最弱/转负（反向对照）。
- 若结果与预期不符（如毫无方向性甚至转负），如实报告并给可能解释（样本期 regime 偏置 / 阈值过松）。
