## 2. 采集(数据源 + 健壮性)

**数据源(per-stock、自带披露日,避开需扫全市场的 by-date 接口):**
- `stock_profit_sheet_by_report_em` / `stock_balance_sheet_by_report_em` / `stock_cash_flow_sheet_by_report_em`
- 每张表按报告期给全科目,并带 `REPORT_DATE`(报告期)+ `NOTICE_DATE`(**披露日**)+ `REPORT_TYPE`(一季报/中报→半年报/三季报/年报)+ `OPINION_TYPE`(审计意见,仅年报有值 → 落到 raw 供后续审计闸门,本轮不判)。

**健壮降级(约法2):**

**落盘:** `store.put_raw("financial_report", code, payload)`,payload 内层按 period 索引(`{code, name, periods:{period: {disclosure_date, report_type, is_forecast, audit_opinion, 利润表{}, 资产负债表{}, 现金流量表{}}}}`)。仅存分析必需的关键科目(EM 原表 200+ 列不全落)。

## 3. 衍生指标(`metrics.py`,代码算)

累计同比增速(营收/归母/扣非)、毛利率、净利率、扣非占归母、**现金含量 CFO/归母净利**、资产负债率、有息负债、**短债覆盖**(货币资金/短期有息负债)、商誉占净资产、应收/存货周转天数(当期口径)、应收/存货增速、ROE(当期口径)、**自由现金流**(CFO−capex)、研发费用率、**单季拆分**(相邻累计相减)+ 单季营收环比。

口径注:季报为累计口径,增速用累计同比(稳健);去年为负、今年改善时用 `|prev|` 作分母使方向正确(亏损收窄=正增长);ROE/周转天数为当期口径未年化,仅作趋势/相对比较。除零/缺值一律 → None(不用 0 冒充)。

## 4. 数值红旗(`flags.py`,阈值集中可配)

已实现 9 条:增收不增利、现金含量不足(CFO/净利<0.8)、应收存货激增((应收 或 存货)增速−营收增速>20pct)、商誉高企(>30%)、高负债(资产负债率>70%)、扣非占比低(<0.6)、短债覆盖不足(<1.0)、扣非为负、毛利率异常跳升(同比>10pct)。每条输出 `{code, 命中, 严重度, 值}`。阈值全在 `THRESHOLDS["财报"]["红旗"]`。缺数据 → 不命中(不误杀)。

## 5. 存储 + 无未来函数 + 评分 + 浅度输出

- **存储键 `(code, 报告期)`**:raw kind `financial_report` 内层按 period;分析视图走 `put_code_view("financial_report", code, ...)`。
- **无未来函数红线**:`analyze(code, as_of)` / `query(codes, as_of, ...)` 强制按 `disclosure_date <= as_of` 过滤——报告期结束 ≠ 披露,披露日前该期不可见(测试 `test_no_future_function_analyze/query`;`query` 强制传 as_of,空则 `ValueError`)。
- **质地评分(数值部分)**:五维(成长/质量/健康/运营/回报)→ 0~100 等权 − 红旗扣分,**高危红旗封顶**(降至"风险");LLM 的"好坏画像"层(`verdict`/`qualitative`)置 **null 留口**。评级映射 优/良/中/差/风险。
- **浅度输出**:每期 `利润表摘要`(营收/归母/扣非 + 增速 + 毛利/净利率)做成显眼字段(服务情绪/短期)。
- **record 挂钩**:`build_financial_block(code, as_of)` 产最新已披露期轻量摘要 → 中心记录新增可空顶层块 `financial`(不塞多期大数组;多期在 code_view)。
