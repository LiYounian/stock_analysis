## 两个关键数据发现（阻塞/影响闸门，已上报统筹待拍板）

### 发现1：防前视行业归属源不可用（阻塞，待拍板成分源 A/B/C）
- 规格指定的 PIT 源 `industry_history.industry_at(code,T)` 实测**申万一级覆盖仅 ~6%**。根因：
  ①它返回**证监会门类大类**（制造业/工业/金融业…），`to_sw` 对跨多申万一级的粗桶**故意返 None**；
  ②`industry_history` store 只采了约半数股票、按运行日零散分区。→ 结构上给不了申万一级 rollup。
- 唯一可用源 `code_industry`（baostock 当前快照）→ **覆盖 93.6%**（29/31行业，0行业成分<5），
  但是**当前快照、回填历史有前视**。`board_membership` 未采集。
- **待拍板**：【A·推荐】用 snapshot 建探针 + 写透前视 caveat（聚合到行业中位稀释个股错配、
  forward return 用官方指数不受影响 → 残余前视二阶）+ 近端子样本稳健性；达标转全量一期时再升级
  真正 PIT 申万成分。【B】先采 PIT 申万历史成分（严谨但拖慢、源未验证）。【C】死守 industry_at→毙探针。
  **snapshot 触碰简报防前视红线，未获批不擅跑。**

### 发现2：回测窗口硬顶 ~286 交易日（影响闸门口径）
- `board_kline`（申万行业指数）与沪深300 index **均只回溯 2025-04-28**，RS-Momentum 预热后
  **2025-07-09 才有值** → 温度序列整体卡在 2025-07 ~ 2026-09、约 286 日。
- 影响：只有 ~1.2 年 → "分年份"子样本不可行，**改用规格§7并列选项"多随机划分"**。
  286截面 + k仅4档（重并列）→ IC 功效有限，报告须写清样本/功效 caveat。

## 成分源拍板 + 探针结论（2026-09-10 收尾）
- 用户拍板 **A（当前快照建面板）** + 四硬条件（caveat写透/近端短窗必做/达标转全量须升级真PIT/其余红线不放松）。
- **增强**：发现 industry_history 含「申银万国」PIT 记录（覆盖~25%），作**防前视子样本交叉验证**。
- **探针结论（详见 [行业层IC报告](2026-09-10_IET探针_行业层IC报告.md)）**：
  - **预注册闸门未达标**（k_full h20 IC=0.031, t=1.78<2.0 @ 锁定 cut0.5）。
  - **核心问题答负**：估值+换手（k_nonmom）h20 IC≈0/负（快照-0.013 / PIT-0.004），无增量；
    k_full 边缘信号全来自动量（RRG 已有）。
  - **regime 不稳**：近端4个月符号显著翻转（h20 IC=-0.088, t=-2.68）。
  - **前视稳健**：PIT 子样本 k_full 略强（t=2.12），快照弱前视未驱动结论。
  - → **三态判定**：论题①(val+turn增量)=**(b)无可检出增量**（三锚CI全跨0/点估≈0，非样本不足）→不投；
    论题②(k_full动量层)=**(c)弱正欠功效**（IC0.031 CI[-0.003,0.065]跨0、近端翻转、且是动量非新增）→
    本窗无法定论，是否为"补长历史+真PIT"买单探动量regime择时，球交用户。温度降级纯报告 `IET_启用=False` no-op。
