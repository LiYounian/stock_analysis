# 强势不回踩旁路 · 设计与回测方案（先审后建）

- 立项日期：2026-09-17

## 0. 一句话结论

给**够格的、低位起步的强势主线龙头**开一条**不需要等回踩**的平行入场通道（"突破 D 日高点确认"取代"死等回踩"），
**所有现有硬风控（极高位 veto / 涨停不可买 / 单调性铁律）继续生效**，并用**同口径 Model A 回测**验证
它相对"回踩基线"是否真能多赚钱；**只有跑赢才采用，否则明确否掉**。

## 1. 病根与立项动机

### 1.1 现状：入场框架"全是等回踩/等确认"

`selection_synth.py` 的 5 种入场方式（`ENTRY_METHODS`，line 334）全部是"等回踩/等确认"，
且被一条铁律夹死（`fill_entry_exit`，line 382–384）：

```
ENTRY_METHODS = ("回踩MA5", "回踩MA20", "回踩前低", "突破确认", "缩量企稳")
entry = min(entry, 现价)   # 回踩限价绝不挂到现价之上（绝不追）
```

- 「回踩MA5/MA20/前低」：挂单价锚在均线/前低，且被 `min(entry, 现价)` 夹到现价之下 → **必须等价格跌回来才成交**。
- 「突破确认/缩量企稳」：挂单价=现价、cap=现价×1.02 → 顶多容忍开盘上探 2%，仍是"确认后小步跟"，不是"主动追突破"。
- 兜底默认 `回踩MA5`（line 335，最保守）。

回测口径 Model A 里，这条铁律的代价被放大：**"D+1 不回踩到限价 → 不成交 → 不进分母"**
（`reselection/portfolio.py` 的 `n_skipped_untriggered`；`nextday_kernel.fill_and_return` 未触发即 `filled=False`）。

### 1.2 后果：系统性漏掉强势主线龙头

强势主线龙头（如 2026-09-17 光模块 **300308 中际旭创 / 300502 新易盛**）的典型走法是
**一路涨、不回踩**——它们要么当天涨停（被涨停闸挡）、要么次日高开高走从不回落到限价：

- 回踩型限价 → **系统性 untriggered**，一路踏空；
- 程序版当天**完全没选到这两只**（板块催化线即使命中，落到入场也是"等回踩"，最终不成交或被漏）。

**核心矛盾**：现有框架是"低吸/防追高"哲学，对**趋势加速段的主线龙头**天然不友好。
但趋势主线龙头恰恰是超额收益的主要来源之一。缺一条"够格才追、追得有纪律"的旁路。

### 1.3 但不能变成"高位追涨"（反例约束）

旁路的危险面是滑向**高位追涨**：现价 425 去追新易盛，若它已处 60 日区间顶部（pos60≈1）=
**接盘站岗**。因此旁路的立身之本是一句话：

> **只吃"低位起步的强势主线"，绝不吃"高位加速的末端"。**

这句话必须落成**写死、可复现的判据**（§2）和**不可绕过的硬风控**（§3）。

## 2. 触发条件：什么样的票"够格"走旁路

旁路是**平行通道**，不替换现有回踩通道。一票进入旁路，须**同时**满足下列**全部**门槛（全部写死、可复现，
字段均来自 `pattern_metrics`（line 191）已算好的形态指标 + 板块消息线上下文）。

### 2.1 够格判据（AND，逐条写死）

| # | 维度 | 判据（写死） | 依据字段 / 来源 | 立意 |
|---|---|---|---|---|
| G1 | 趋势 | `均线多头 == True`（ma5>ma10>ma20 且 close≥ma5） | `form["均线多头"]`（line 237） | 只做多头排列的趋势票，不接下跌途中 |
| G2 | 主线/风口 | 属于当日 `sector_focus` **消息驱动利好板块** 且 `board_ctx["强弱"]=="强"` | 板块催化线（`load_message_boards`，line 99） | **必须挂在当日主线上**，不是任意个股强势 |
| G3 | 角色 | 角色 ∈ {龙头, 中军, 策略}；**跟涨不走旁路** | `cand["role"]`（跟涨仍只"联动观察"，line 464） | 只追主线主升，不追补涨先锋 |
| G4 | 温和放量 | `量比 ∈ [1.0, 2.5]` | `form["量比"]`（line 240） | 放量确认，但排除"爆量"（爆量常见于一日游/见顶） |
| G5 | 未到高位 | `位置pos60 ∈ [0.50, 0.85]` | `form["位置pos60"]`（line 230） | **低位起步**：下限保证确是启动、上限保证离顶尚有空间 |
| G6 | 离顶有空间 | `距60高 ≤ -0.08`（现价距 60 日高点还有 ≥8%） | `form["距60高"]`（line 239） | 与 G5 双保险，防"贴着 60 日高点追" |
| G7 | 当日不过热 | `当日涨跌 ∈ (0, limit-0.02)`（当日红盘、但未接近涨停/未暴涨） | `form["当日涨跌"]`、`limit_pct`（line 181） | 不在已经暴涨/连板的当天追 |
| G8 | 非涨停 | `涨停不可买 == False` | `form["涨停不可买"]`（line 243） | 涨停无法次日限价/开盘买入 |

> **默认值与假设（信息不全时的处理）**：
> - G2 的"强弱=强"取自 `board_ctx["强弱"]`；若历史 `sector_focus` 缺该字段，旁路**退化为形态维近似**
>   （见 §4.4），并在产物/回测标注"板块维近似"。
> - G4/G5/G6 阈值为**初版预注册值**，来自"温和放量 + 低位起步"的一般性约束，**不对既往赢家调参**。
>   调参只允许在**预注册的粗网格**（§4.5）里做一次性 OOS 选择，且写入文档留痕。

### 2.2 入场方式：用"突破确认"取代"死等回踩"

旁路新增**一种入场方式**（并入 `ENTRY_METHODS` 枚举，判据写死）：

- **`突破新高确认`**：挂单锚 = **D 日 high（前高突破位）**，D+1 盘中**突破 D 日高点**即成交。
  - 与现有"突破确认"的关键区别：现有"突破确认" entry=现价、被 cap=现价×1.02 夹住（几乎不追）；
    旁路 `突破新高确认` **允许挂单价高于 D 收盘价（现价）**，即**受控地"追"**。
  - 但"追"有**硬顶**（§3.2 的 cap）：不是无限追。

> 备选入场方式 `强势不破均线`（现价站上 ma5 且盘中不破 ma5 即持）属**时机层/日内线**，
> 需实时分时信号，**本轮不接入**（与现有"两层闸门"脚注一致，line 804–809）；旁路先只落**价位层**的
> `突破新高确认`。

## 3. 硬风控（必须·不可绕过）

旁路是"受控放松追高纪律"，**放松的只有"必须等回踩"这一条**；其余硬纪律**全部继续生效**，
且旁路**额外**叠加更严的位置闸。实现上：旁路票**先过 §3.1 的通用硬闸，再过 §3.2 的旁路专属闸，
最后过 §3.3 的单调性铁律**，任一不过即踢出旁路（可回落到普通回踩通道或直接剔除）。

### 3.1 通用硬闸（复用 `hard_veto_reason`，line 512，一字不改）

旁路票**必须照跑** `hard_veto_reason`，命中任一即"剔除"：

1. 财报高危红旗 ≥ 1；
2. 龙虎榜净买否决；
3. 涨停不可买（无法次日入场）；
4. **极高位高抛压**：获利盘 / pos60 ≥ 0.95 **且**贴近高点（距 20/60 高 ≥ -2%）。

> 铁律：**旁路绝不改动 `hard_veto_reason` 与 `apply_hard_discipline`（line 537）**。旁路是"入场方式"层的扩展，
> 不是"选不选"层的放水。极高位 veto 是防站岗的最后一道墙。

### 3.2 旁路专属闸（比通用闸更严）

| 闸 | 判据 | 立意 |
|---|---|---|
| 位置更严 | `pos60 < 0.90`（严于通用闸的 0.95） | 旁路只做低位起步，留足与"极高位"的安全垫 |
| 追高硬顶 cap | `不追高上限(cap) = min( D日high × 1.03 , 现价 × (1 + limit − 0.02) )` | 突破位之上最多追 3%，且不越"次日近涨停"线 |
| 挂单不越顶 | `挂单价(entry) = clip( D日high×(1+ε) , 下界=现价 , 上界=cap )`，ε=0（触及前高即买） | 允许 entry > 现价，但**恒 ≤ cap**（受控追，不裸追） |

> **与现有铁律的关系**：现有 `entry = min(entry, 现价)`（line 384）**只作用于三种回踩方式**
> （见 line 382–383 的 `method in ("回踩MA5","回踩MA20","回踩前低")`）。旁路的 `突破新高确认`
> **不进这个分支**，改用 §3.2 的 `clip(现价 ≤ entry ≤ cap)`——**这是对铁律的定向、有上限的放松，
> 而非删除**。回踩通道的铁律原样保留。

### 3.3 单调性铁律（继续生效，line 385–391）

不论旁路还是回踩，最终三价位**必须满足**：

```
止损价 < 挂单价 ≤ 不追高上限（红线）
```

旁路的止损锚：`止损 = max(ma5, D日low)` 的下方一档（跌破 ma5 或跌破启动日低点即止损），
仍走现有 line 386–391 的夹逼保证 `止损 < 挂单 ≤ cap`。

## 4. 回测设计：旁路 vs 回踩基线，同口径量绝对收益

### 4.1 复用而非重造：直接落在 `reselection` 谐器上

关键发现：**现成回测谐器 `tools/backtest/reselection/portfolio.py` 的 `simulate()` 已同时支持
旁路与回踩两种入场**，无需造新引擎：

- `entry_rule="open"` = **D+1 开盘价成交**（marketable）= **旁路"追"的最保守可回测代理**（追 D+1 开盘）；
- `entry_rule="limit_pc_k"` = **挂 close_D×(1−k) 限价** = **回踩基线**（等回踩 k%）；
- 两臂共用同一 Model A 退出（`arm="baseline"`：D+1 入场 → D+2 无条件了结）、
  同一涨停不可买闸（`limit_up_unbuyable`）、同一 10bps 成本、同一全 A 等权基准 α。

> **旁路入场的回测口径选择**：`突破新高确认`（挂 D 日 high、D+1 触及成交）在回测里对应
> `fill_and_return(model="marketable")` 挂价 `P = high_D`（D+1 若 high≥P 则以 P 成交，若开盘已过 P 则以 open 成交）。
> 这需要在 `_limit_price`（portfolio.py line 71）新增一档 `breakout`（`P = high_D`）。
> **本轮先用现成的 `entry_rule="open"` 做旁路的下界代理**（追 D+1 开盘，最激进），
> 实现窗再补 `breakout` 精确档做上界对照——两者夹出旁路真实收益区间。

### 4.2 两臂对比 + 三个必看维度

在**同一"够格旁路子集"**（§2 判据筛出的票）上，对比：

| 臂 | entry_rule | 语义 |
|---|---|---|
| **旁路臂** | `open`（本轮）/ `breakout`（实现窗补） | 不等回踩，D+1 直接追入 |
| **回踩基线臂** | `limit_pc_0.01` / `limit_pc_0.02` | 现有框架：等回踩 1%/2% |

**三个必看维度（缺一不可）**：

1. **成交率（覆盖率）**：`filled / signals`。回踩基线的核心弱点是大量 `untriggered`——
   旁路的**首要价值是把"不回踩被漏掉"的强势票捞回分母**。若旁路成交率显著更高，说明"漏票"是真的。
2. **成交票绝对收益**：胜率（D+1 收盘为正占比）、平均净收益、中位数。
3. **α（减全 A 等权）**：`alpha_net`（portfolio 已算，line 118）。防"只是 β/大盘涨"。

> 单看收益不够：旁路可能"多成交但每笔更差"（追高的代价）。必须**成交率 × 每笔收益 × α 三者一起看**，
> 综合判断"多捞的票是否真多赚"。

### 4.3 防未来铁律（硬）

- **信号 + 够格判据只用 ≤date 数据**：`pattern_metrics` 已 `_asof_slice`（line 185）；
  `sector_focus` 消息驱动带 `as_of` 守卫（`load_message_boards`，line 103）。
- **成交/收益只用 date 之后的 master kline**：D+1 OHLC 定成交、D+1 收盘/D+2 定收益，
  取自事后主档全历史 K 线（与 `nextday_kernel` / `screen_forward_common` 同口径）。
- **判据固定、绝不对既往赢家调参**：§2 阈值预注册；不允许"看见 300308/300502 赚了就回去调 pos60 上限凑中"。
  任何阈值选择只允许在 §4.5 预注册粗网格里做一次性 OOS 选择并留痕。
- **分层稳健性**：全样本 + 分年 walk-forward + OOS 早/晚段（谐器 `run_h1.run()` 已内置，line 63–92）。

### 4.4 数据依赖与退化路径（信息不全时）

旁路够格判据 G2（主线/风口板块）依赖**历史每日 `sector_focus` 消息驱动利好板块 as-of**。风险：
历史 `sector_focus` 可能不完整（消息面重建成本高）。**退化策略（写明、不反问）**：

- **首选**：有历史 `sector_focus` 的交易日，用真板块维（G2 全约束）。
- **退化 A（形态近似）**：无 `sector_focus` 的日子，G2 用**申万一级板块强度代理**
  （板块内当日涨幅分位 / 板块动量），标注"板块维近似·非消息面"。
- **退化 B（纯个股）**：连板块强度都缺，则**去掉 G2**、只用形态维 G1/G4–G8 跑"个股强势不回踩"，
  作为**旁路收益的下界参照**（缺主线约束，预计更弱；若连这个都跑不赢基线，旁路直接否）。

三条路径的结果**分开报**，不混算。采用判定以"首选"口径为准，退化口径作旁证。

### 4.5 预注册粗网格（唯一允许的调参自由度）

只在下列**粗网格**里做一次性 OOS 选择（早段选参 → 晚段验证），选中值写入文档：

- G5 `pos60` 上限 ∈ {0.80, 0.85, 0.90}
- G4 `量比` 上限 ∈ {2.0, 2.5, 3.0}
- 回踩基线 k ∈ {0.01, 0.02}（对照臂各跑）
- 旁路 cap 追高上限 ∈ {D日high×1.02, ×1.03}

## 5. 采用门槛（只有跑赢才采用）

用户原则：**有正向收益才采用**。旁路采用须**同时**满足（否则明确建议否掉）：

1. **正收益**：旁路臂成交票**平均净收益 > 0** 且**平均 α > 0**（首选口径，全样本）；
2. **跑赢基线**：旁路臂**净收益 ≥ 回踩基线臂** 且 **α ≥ 回踩基线臂**（同一够格子集）；
3. **覆盖是真增量（成交率门槛·事前锁死·2026-09-17 统筹给定）**：旁路臂成交率须
   **同时**满足 ①绝对：`旁路成交率 ≥ 回踩基线成交率 + 15 个百分点`；②相对：`旁路成交率 ≥ 1.3 × 回踩基线成交率`。
   两条件同时满足才算"覆盖是真增量"（多捞的票靠"不等回踩"、不是靠放松收益门槛）。
   > 门槛立意：回踩基线在主线龙头子集上成交率天然偏低（大量 untriggered），旁路追 D+1 open 成交率天然高；
   > "+15pp 且 ≥1.3×" 双条件确保"旁路确实把回踩漏掉的票捞回分母"是量级级增量，而非几个百分点的噪声。
   > **此数字事前锁定，回测中绝不因既往结果回调**（防"事后凑门槛"）。
4. **稳健**：分年 walk-forward **至少 ⌈N×0.6⌉ 年**旁路臂不为负 α，OOS 晚段不崩（无未来偏移的旁证）；
5. **无硬风控倒退**：旁路子集内**极高位/涨停/财报/龙虎**四类硬闸命中率与全框架一致（旁路没偷偷放水）。

**任一不满足 → 建议否掉旁路**，维持现有全回踩框架，并在小结里写明"哪条没过、差多少"。
