# 第一部分 · 体检卡（个股分析）需求规范（归纳）

## 1. 维度划分
- **卡头（元信息）**：股票名+code+as_of、骨架分/五基石子分、召回来源标签。
- **四面**：一·基本面 / 二·技术面 / 三·资金面 / 四·消息情绪面。
- **经验纪律**（跨面·尾块）。
- 归面原则：**自主治理行为→基本面**（如大股东减持=治理信号）；**机械筹码事件→资金面**（如限售解禁）；
  量价/择时→技术面；个股情绪/公告/预期→消息面。多出来的工具（闸门/入场价/假利好等）也各归其面。

## 2. 数值要求
- 每个数值来自工具**真实产出**：〔源〕=数据源直取；〔算〕=系统计算（附口径）。
- **口径不许拼装层编**——档位定义来自各工具自己的档位表常量，一路贯通上传。
- **缺数据诚实标注、绝不编造**，且区分三种"没有"：
  · **无数据/样本太少**（如情绪样本少→中性，不是缺失）；
  · **待补落盘**（数据已算/已采、未入库，补齐即接入）；
  · **维度未接/该票无覆盖**（能力已上线但此票无底料，如冷门股无研报覆盖）。

## 3. 内容排版
- **共性概念（指标是什么）抽到「统一指标词表」**——喂大提示词开头一次，个股卡**不逐条重复**。
- **个股卡每条 = 数值 + 档位 + 一句针对本股本值的「含义/影响」**（因股因值不同才写这里）。
- 分四面、有格式 Markdown（**非表格**）、逐条给评价/指向。
- 概念解释与个股判断**分开写**（共性进词表、个性进卡）——避免每票重复、又保证 LLM 拿到定义。

## 4. 评价标准
- 每条给**档位**（按全A横截面分位标定，低/中/高=相对全市场位置，非绝对好坏）。
- 每条给**影响**：对最终选股的指向（加分/减分/需结合X看），有指导意义、供 LLM 权衡，**不是买卖指令**。
- 卡尾给 **LLM 综合一句指向**（示例：不追高、回踩不破支撑再评估）。

## 5. 数值区间（各指标档位分界·均在统一词表列明·代表相对全市场位置）
- 市盈率 PE：亏损≤0 / 低≤15 / 中≤30 / 偏高≤60 / 高>60（pe_valid=False 不套档）
- PB：破净≤1 / 低≤2 / 中≤4 / 偏高≤8 / 高>8
- PEG：低估≤0.8 / 合理≤1.2 / 偏高≤2 / 高估>2（增速≤0 失效）
- 增速：衰退≤-20 / 下滑≤0 / 平稳≤15 / 增长≤30 / 高增长>30
- 负债率：低≤30 / 中≤50 / 偏高≤70 / 高>70
- 财报五维 & quality：各 0–100；quality 优>80 / 良>65 / 中>50 / 弱>35 / 差
- 量比：缩量≤0.7 / 平量≤1.2 / 放量≤2.5 / 爆量>2.5
- 60日位置 pos60：低≤0.3 / 中≤0.7 / 高>0.7
- RSI12：超卖极端≤20 / 超卖≤30 / 中性≤70 / 超买≤80 / 超买极端>80
- 筹码获利盘：普遍套牢≤0.2 / 套牢为主≤0.5 / 获利为主≤0.8 / 普遍获利>0.8
- 主力净占比：强流出≤-5 / 流出≤-1 / 中性≤1 / 流入≤5 / 强流入>5
- 主买占比：弱≤0.45 / 均衡≤0.52 / 偏强≤0.56 / 强>0.56
- 股东户数环比：明显集中≤-10 / 集中≤-3 / 平稳≤3 / 分散≤10 / 明显分散>10（负=集中=利好）
- 换手率：过低≤1 / 正常≤3 / 活跃≤7 / 过热炒作>7
- 竞品·板块内相对：龙头级≤20% / 前排≤40% / 中游≤70% / 尾部>70%
- 个股净情绪（-1~+1）：强负≤-0.3 / 负≤-0.05 / 中性≤0.05 / 正≤0.3 / 强正>0.3
- 研报覆盖机构数：无0 / 冷门≤2 / 一般≤9 / 高关注≥10

# 第二部分 · 市场 / 国际新闻 / 板块消息面 · 样例格式（同套：数值/研判 + 含义 + 影响）

> 现状：14:00 sector_news_catalyst 已采「新闻+政策+**国际**+龙虎榜」→ DeepSeek 按 rubric 文字分级研判
> → 落 sector_focus「消息驱动」块（板块级·关键事件带 方向/强弱/可信度/影响程度/执行度/来源）。
> 本样例把它按体检卡同套格式显性化，供 HTML 展示 + 喂选股大提示词。数据取自 2026-09-18 真实产出。

## 统一词表（消息面·喂大提示词开头一次）
- 方向：利好/利空/中性——事件对相关板块个股的影响方向。
- 强弱：强/中/弱——催化力度。
- 可信度：可信/存疑——信源与逻辑可靠度。
- 影响程度：大/中/小——对基本面或情绪的冲击量级。
- 执行度：高/中/低——事件落地兑现的确定性（政策"研究中"vs"已出台"）。
- 来源：一手（公告/官方）/ 二手（媒体转述）——越一手越可信。
- 风险偏好/广度/宏观净方向：全市场情绪与多空环境定调（决定当日整体进攻/防守）。

## 市场定调（2026-09-18）
- **风险偏好：中性**。依据（上游研判原句）：广度档中性（沪深300震荡、净广度-0.044、涨停58/跌停6、
  权重搭台中小盘偏弱）；宏观净方向中性 → 最终中性。
  影响：全市场无明显多空占优，宜均衡、不宜追高，选股靠个股与板块阿尔法。

## 板块消息面（重点板块深挖·全板块覆盖，此处示例"交通运输·利好·强"）
**交通运输 —— 利好 · 强**
- 事件1｜招商轮船 26Q2 归母净利同比+233%，油散盈利弹性延续；BDI 创新高；**欧线集运主力合约飙升超3%**〔一手·可信·影响大·执行高·方向利好·**国际**〕
  含义：全球干散货/集运运价走强（BDI、欧线），航运业绩弹性释放。影响：利好航运板块龙头（招商轮船/中远海能等），资金面/基本面双正向。
- 事件2｜中远海能 26Q2 归母净利同比+104%，主力连续7日净流入；**中东航线运费大幅跳涨**〔一手·可信·影响大·执行高·方向利好·**国际**〕
  含义：油运景气+地缘推升中东航线运价。影响：直接利好油运标的，叠加资金面主力净流入，强催化。
- 事件3（反向）｜上港集团/宁波港公告 8月吞吐量同比下降（-14.7%/-17.2%）〔一手·可信·影响大·执行高·方向利空〕
  含义：港口吞吐走弱，与航运运价背离。影响：利空港口子板块（上港/宁波港），板块内需区分航运 vs 港口。
- 事件4｜七大快递上半年合计盈利215亿、圆通31.8亿〔二手·可信·影响中·执行高·方向利好〕
  含义：快递盈利改善。影响：温和利好快递子板块。
- **板块小结**：交运整体利好·强，但**结构分化**——航运/油运（国际运价+业绩）强正向、港口（吞吐下滑）走弱、快递温和向好。选股指向：优先航运油运龙头，规避港口吞吐承压股。

（其余板块同格式逐一给：利好/利空板块的关键事件+含义+影响+小结；规避板块池单列。）

## 国际/宏观事件汇总（从各板块关键事件里抽"国际/宏观"标签汇总一屏）
- 航运：BDI创新高、欧线集运+3%、中东航线运费跳涨 → 利好航运油运。
- （加息/汇率/关税/地缘 等宏观事件若当日有 → 汇总于此 + 影响哪些板块）
影响：让 LLM 一眼看到当日国际/宏观面对哪些板块构成系统性利好/利空。
