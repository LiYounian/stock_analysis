# 外围宏观影响分析 · Agent 化固化方案

> 日期：2026-09-17 ｜ 作者：宏观影响分析 chip（受统筹派发）
> 上游：本方案是《外围宏观影响分析_美联储加息_2026-09-17.md》（已合入 main 6e06775）的**流程化固化**——把一次性文字报告升级成**可复用、可结构化、Agent 自主取数**的流程。
> ⚠️ 研究模拟、非投资建议。

---

## 0. 目标与结论速览

**目标**：把"外围/国际宏观新闻 → A股大盘与板块影响"从一次性人工文字报告，固化为
① 覆盖 **US / 日本 / 香港 + 跨境** 的**新闻采集范围**；
② **机读结构化 schema**（影响说明=自由文字，评级=**文字档anchored、绝不产 raw 数字**）；
③ **Agent 自主取数+分析+结构化输出**的可运行脚手架，并实测 DeepSeek / 千问3.8-max 效果。

**核心结论（实测后·2026-09-17 真跑公司网关）**：
- **Agent 化可行、且明显优于固定提示词流水线**——两模型都能**自主多轮联网**、按范围清单铺开搜 US/日/HK，指令遵循（搜什么、覆盖哪些地区）好；**但"能不能落地"完全取决于 harness 三件套**（见下）。
- **deepseek-v4-pro**：加足超时后**一次跑通**（132.5s / 25 工具调用 / prompt 73.6K / 6 事件 / 全区域）；结构化质量优、评级零裸分。**短板：把已落地加息幅度写错（5.50–5.75% vs 实际 3.75–4.00%）——事实核实弱，需一手源加固。** 本网关下大 payload 首 token 延迟极高，**90s 超时会全废**，须放宽到 ≥300s。
- **qwen3.8-max**：研究面最广，但**天然不收敛**（首轮 48 次工具调用仍不交卷、prompt 爆到 575K）。**加"迭代预算 + 收敛 nudge + 末轮强制 submit + 上下文压缩"后一次跑通**（279.6s / 11 调用 / prompt **32.3K**（压缩后 18× 降本）/ 5 事件），评级零裸分。
- **决定成败的 harness 三件套**：① 足够超时；② 收敛控制（预算+nudge+末轮强制交卷）；③ **上下文压缩**（旧工具结果用完压桩）。缺一，勤奋模型就烧 token 不产出。
- **评级档 anchored 设计有效**：两模型都在五档里选档、**无一裸吐数字**，与选股 `selection_synth.py`「先定档再给分」同源，产出可比、可程序兜底。**结论：优先 Agent 化（用户判断正确），但必须配套 harness 三件套 + 一手源事实校验。**

## 1. 新闻采集范围清单（US / 日本 / 香港 + 跨境）

|---|---|---|

| **JP 日本** | BOJ 利率决议/YCC；日元 USDJPY 汇率/**套息交易 carry trade**；日经 225 | 日元套息逆转是全球波动放大器 |
| **HK 香港** | HKMA/联系汇率、港元流动性；恒生/恒生科技；**南向资金/港股通**；IPO 与流动性 | 港股是外资看中国的前哨；南向映射内资情绪 |
| **CROSS 跨境** | 北向资金流向；人民币在岸/离岸汇率；中美利差；全球风险偏好 VIX | 外围→A股的直接传导变量 |

### 采集来源与方式（分层，与项目 `tools/collectors/` 同风格）
1. **通用网络检索（本方案实测所用）**：百度资讯 `baidu.com/s?tn=news`（免登录、宏观覆盖好）+ curl_cffi 伪装 chrome 抓正文。已验证可用；360 `so.com/s` 作备份源。
   - 反爬注意：百度**网页搜索** `wd=` 直取会被拦（返回极短占位页），**须走资讯 tab `tn=news`**；Bing 可返回但需另写解析。
2. **一手官方口径（建议后续补）**：美联储/BOJ/HKMA 官网决议声明、点阵图 PDF（数字权威，抗谣言）。
3. **财经快讯 API（可选增量）**：财联社/金十快讯、东方财富，做实时事件流。
4. **复用项目现有 curl_cffi 基建**：`tools/collectors/news.py`、`baidu_news.py` 已是 chrome 伪装取数，可抽出公共 fetch 层给宏观 agent 复用（避免重复造轮子）。

> 采集哲学：Agent **自主决定搜什么**（不写死关键词），范围清单只作"必须覆盖"的下限提示；每条事件强制**≥1 真实来源 URL**，禁编造。

## 2. 结构化 Schema（机读，像"板块分析"那样出机读结构）

代码常量见 `tools/experimental/agent_macro.py` 的 `REPORT_SCHEMA`。顶层结构：

```jsonc
{
  "as_of": "2026-09-17",
  "region_scope": ["US","JP","HK","CROSS"],
  "events": [
    {
      "id": "fed-0916",
      "date": "2026-09-16",
      "region": "US",                       // US|JP|HK|EU|CN|GLOBAL
      "category": "货币政策",                // 货币政策|利率债市|汇率|贸易关税|资金流|地缘|其他
      "headline": "美联储加息25bp至3.75-4.00%",
      "summary_free": "影响说明——自由文字，不强求量化",
      "sources": [{"title":"...","url":"https://...","date":"2026-09-16"}],   // ≥1，禁编造
      "transmission_free": "传导到A股的路径——自由文字",
      "affected_sectors": [{"sector":"光模块","direction":"利多","note":"..."}],  // direction∈利多|利空|中性
      "rating": "利空",                      // ★五档之一，anchored，禁数字
      "rating_reason": "为何给这一档（点明判据）",
      "confidence": "高",                    // 高|中|低
      "half_life_days": 20                   // 影响半衰期，不确定可 null
    }
  ],
  "aggregate": {
    "net_direction": "利空",                 // ★五档之一（全局净方向）
    "regime_note": "整体外围环境定性——自由文字",
    "sector_watchlist": [{"sector":"AI算力","stance":"超配","reason":"..."}]  // stance∈超配|标配|低配|回避
  },
  "meta": {"provider","model","mechanism","elapsed_sec","tool_calls","usage","as_of"}
}
```

**两条硬约束的落地**：
- **影响说明 = 自由文字**：`summary_free` / `transmission_free` / 各 `note` / `reason` 全为自由文本，不强求量化——宏观影响本就难精确量化，强行造数字反而失真。
- **评级 = 文字档，绝不产 raw 分**：`rating` / `net_direction` 只能取五档枚举之一，`affected_sectors.direction` 三态、`stance` 四态、`confidence` 三档——**全部枚举、无裸数字**。

## 3. 评级档定义（文字 anchored，与选股「建议分档位」同源）

> 设计原则**对齐 `tools/analysis/selection_synth.py`**：那里要求 LLM「**先按【建议分档位定义】定档，别裸给分**」，并有程序硬纪律兜底（反选命中强制剔除）。宏观评级照搬此思路——**只给档、给判据，不给数字**，避免"raw LLM 数字"的不可比与幻觉。

### 3.1 影响评级五档（对 A股 大盘/风险偏好的方向×力度）
| 档 | 判据 |
|---|---|
| **强利多** | 重大宽松/流动性显著改善/明确利好A股主线（超预期降息、重大稳增长、外资大幅回流），方向明确且力度大，历史类比普遍上涨。 |
| **利多** | 边际偏正面，利好部分板块或小幅改善风险偏好，但力度有限或有对冲项。 |
| **中性** | 方向不明或多空基本对冲，对A股整体无显著净影响（可能仅局部结构性）。 |
| **利空** | 边际偏负面，压制估值/资金面/风险偏好，但非系统性（可结构性规避）。 |
| **强利空** | 重大紧缩/流动性冲击/系统性风险（超预期加息+鹰派、套息逆转、关税急升），方向明确力度大，普遍下跌压力。 |

### 3.2 证据充分度三档
| 档 | 判据 |
|---|---|
| **高** | 多源一致、有一手数据/官方口径。 |
| **中** | 有来源但单一或口径有差异。 |
| **低** | 传闻或推断为主。 |

### 3.3 为什么坚持"档而非分"
1. **可比**：不同事件/不同模型/不同天，档位语义一致；raw 数字（一个模型的 7.3 vs 另一个的 7.3）不可比。
2. **抗幻觉**：LLM 裸吐数字倾向编造精度；先定档强制它对齐**明文判据**。
3. **可程序兜底**：如需排序，程序按 `档→有序值` 映射（仿 `_档_ORDER`），而不是信任模型数字。
4. **与全项目一致**：选股建议分、板块 verdict 都是"档位 anchored"，宏观模块不破例。

## 4. Agent 化脚手架（实测所用）

文件：`tools/experimental/agent_macro.py`（复用 `agent_select_ds.py` / `agent_select_qwen.py` 的
function-calling 思路，单脚本 `--provider ds|qwen` 参数化，省去两份重复代码）。

- **工具（function-calling）**：`web_search(query, region_hint)`（百度资讯）、`web_fetch(url)`（curl_cffi 抓正文）、`submit_report(report)`（交卷即终止）。
- **loop**：OpenAI 兼容 client（公司网关，不烧 Bedrock）→ 多轮 auto tool_choice → 交卷。
- **收敛控制（关键改进）**：迭代预算 `--max-iters` + 过半未交卷注入 nudge + **末轮强制 `tool_choice=submit_report`**。
- **上下文压缩（关键改进）**：`_trim_history` 只保留最近 6 条工具结果全文，更早的压成短桩——实测把 qwen prompt token 从 575K 降到 32K（~18×），是让 qwen 能收敛/不超时的决定性一环。
- **留痕**：`{tag}_agent_宏观_{date}.json`（report+meta）、`..._trace_{date}.md`（逐轮工具调用+usage+mechanism）。
- **失败降级**：function-calling 重试 2 次；仍失败标 mechanism、产空 report 但不崩。
- **运行**（真跑走 `zsh -ic` 才有网关 env；conda 环境）：
  ```bash
  zsh -ic 'cd <worktree> && ~/.conda/envs/stock_analysis/bin/python tools/experimental/agent_macro.py --provider qwen'
  zsh -ic 'cd <worktree> && ~/.conda/envs/stock_analysis/bin/python tools/experimental/agent_macro.py --provider ds --timeout 300'
  ```

## 5. Agent 固化验证：实测 vs 预测

<!-- FILL: 最终实测数值在 reruns 完成后回填 -->

### 5.1 预测（跑之前的假设）
| 维度 | 预测 |
|---|---|
| 能否跑通 | 两模型都支持 function-calling，应能自主搜+抓+交卷 |
| 指令遵循 | 中上——能按范围搜，但可能漏地区或不交卷 |
| 结构化质量 | 中——schema 较复杂，可能字段缺失/评级偶尔裸给数字 |
| 成本 | 单次几十万 prompt token 量级（工具结果累积重发） |

### 5.2 实际实测数值（2026-09-17，走公司网关，非投资建议）

**A. deepseek-v4-pro（成功）**
| 轮次 | 参数 | 结果 |
|---|---|---|
| 首轮 | timeout=90s | ❌ **全废**——首个 create() 就超 90s（大 payload 首 token 延迟高），重试2次均超时，tool_calls=0，724s 空转。 |
| 改进轮 | timeout=300s, max_iters=14, +上下文压缩 | ✅ **成功交卷**：elapsed **132.5s**，tool_calls **25**，usage prompt **73.6K**/completion **6.3K**，产 **6 条事件**，覆盖 US/JP/HK/CROSS，net_direction=利空。 |

- **结构化质量高**：6 条事件全部 `rating` 落在五档（利空×4/中性×1/利多×1）、**无一裸给数字**；`confidence` 三档齐用；每条带 2–4 个**真实抓取到的来源 URL**（10jqka/baijiahao/cngold）；`sector_watchlist` 用 超配/低配/回避 档 + 判据（超配红利·石油·光伏，低配科技·AI，回避航空）。**评级 anchored 设计完全生效。**
- **⚠️ 事实准确性偏弱（关键短板）**：DS 把已落地的**加息幅度写错**——报告写"加息25bp至 **5.50%–5.75%**、市场定价95%"，实际为 **3.75%–4.00% 已决议**（DS 疑似混入 2023 旧数据/预测稿，且把"已决议"当"预期"）。说明**结构/指令遵循强，但对时效数字的事实核实弱**——需一手官方源加固（§6.4）。

**B. qwen3.8-max（研究强，但收敛/成本是硬伤）**
| 轮次 | 参数 | 结果 |
|---|---|---|
| 首轮 | max_iters=24, 无收敛控制 | ❌ **不收敛**：疯狂搜 **48 次工具调用 / 18+ 轮**，US/日/HK/关税/油价/套息全覆盖（研究面极广），但**从不主动 submit_report**，耗尽预算无产出；prompt token **575.6K**（工具结果累积重发）。 |
| 二轮 | max_iters=16, +收敛nudge+末轮强制submit | ❌ **上下文膨胀拖垮**：后段单次 create() 因累积 ~50万+ token 上下文**超 200s 超时**，attempt 失败重试，未产报告。 |
| 三轮 | max_iters=12, timeout=240, **+上下文压缩**（只留最近6条工具全文，旧的压桩） | ✅ **成功交卷**：elapsed **279.6s**，tool_calls **11**，usage prompt **32.3K**/completion **12.4K**，产 **5 条事件**（US/JP/HK/GLOBAL），net=利空。**压缩把 prompt token 从 575.6K → 32.3K，约 18× 降本**，并让它按时收敛。结构化质量好：评级全五档（利空×4/中性×1）零裸分，每条 3–5 个来源。 |

- **共性**：qwen 是**很勤奋的研究者**（搜得比 DS 全、覆盖面广、query 会自我改写换词重搜），指令遵循"搜什么/覆盖哪些地区"很好；**但天生不收敛、不主动交卷**，且**每轮重发全部工具结果导致 prompt token 爆炸**（是 DS 的 ~8 倍）。这正是"固定提示词流水线之外，Agent 化必须解决的两个工程问题：收敛 + 上下文成本"。

### 5.3 预测 vs 实际 差异与教训
| 维度 | 预测 | 实际 | 教训 |
|---|---|---|---|
| 能否跑通 | 都能自主搜+抓+交卷 | **两者最终都跑通**：DS 需足够 timeout；qwen 需收敛+压缩三件套 | **超时/收敛/压缩是 Agent 化能否落地的先决条件**，不是调优细节 |
| 指令遵循 | 中上 | **搜集范围遵循好**；但 qwen 不交卷、DS 事实核实弱 | "搜什么"好办，"何时停+核实数字"才是难点 |
| 结构化质量 | 中，可能裸给数字 | **DS 结构优、评级零裸分** | **档位 anchored（先定档）有效压住了裸数字幻觉** |
| 成本 | 几十万 prompt token | DS 73.6K；qwen 575.6K（未压缩） | **上下文累积是主成本项**；压缩后可数量级下降 |
| 事实准确 | 未特别预期 | **DS 加息幅度写错**；qwen 也把"已决议"当"预期"表述 | 时效数字必须有**一手官方源**兜底，不能只信网络二手稿 |

### 5.4 选型建议（head-to-head）
| | deepseek-v4-pro | qwen3.8-max |
|---|---|---|
| 收敛（是否主动交卷） | ✅ 天然会交卷 | ⚠️ 必须强制收敛 |
| prompt token 成本 | 低（73.6K） | 高（压缩后 32.3K，未压缩 575K） |
| 首 token 延迟 | 高（须 ≥300s 超时） | 中（单轮慢但可控） |
| 研究覆盖面 | 好（6 事件） | 最广（query 自改写重搜） |
| 结构化/评级 anchored | 优·零裸分 | 优·零裸分 |
| 事实准确 | 加息幅度写错 | 表述含糊但未硬编错数 |

**建议**：两者**都可用**，**优先 deepseek-v4-pro**（天然收敛、成本低），把 qwen 作为"要更广覆盖时"的备选；**无论用哪个，都必须**：① 配 harness 三件套；② 对关键时效数字（利率/汇率/收益率）用**美联储/BOJ/HKMA 官网一手源做程序化校验或复核闸门**，防二手稿把"预期/旧值"当"已落地"。

## 6. 落地建议与后续
1. **优先 Agent、弃固定流水线**：实测证实 Agent 自主取数覆盖面/时效优于写死关键词的流水线（与用户判断一致）。
2. **收敛是 Agent 化第一工程问题**：必须显式给迭代预算 + 收敛信号 + 末轮强制交卷，否则勤奋模型烧 token 不产出。
3. **成本治理（已实现并验证）**：工具结果累积重发是 prompt token 膨胀主因——已在 `_trim_history` 做"旧工具结果用完压桩"，实测 qwen 降本 ~18×（575K→32K）。后续可进一步换 Responses API 服务端状态、或对 web_fetch 正文先做要点抽取再入上下文。
4. **一手源加固**：谣言/数字口径差异风险高，建议补美联储/BOJ/HKMA 官网决议原文作高置信锚。
5. **接入选股主链**：宏观 `aggregate.net_direction` + `sector_watchlist` 可作为 regime 输入喂给 `selection_synth` 的盘面 regime（宏观净方向/宏观情景字段已存在），形成"外围宏观→选股修正"的闭环。
6. **定时化**：稳定后挂定时任务（决议日/每日盘前跑一次），与项目"选股要快要增量当天出"的节奏对齐。
