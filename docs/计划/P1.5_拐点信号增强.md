# P1.5 · 超跌反弹拐点信号增强(计划)

> 状态:**执行中** · 编写 2026-08-05
> 触发:实盘分析发现技术评级(纯趋势回看)把 8/5 存储链主升打成 -60,踏空超跌反弹(见 [实盘分析](../实盘分析_20260805.md) 第 6 节)。
> 依赖:无(纯 OHLCV 计算,不依赖 LLM)。

---

## 1. 目标

在 `technical.compute` 里**新增一个与趋势评级并列的「拐点信号」维度**,专门捕捉超跌反弹/启动。
**关键原则:拐点信号独立呈现,不并进趋势得分**——避免"一个分数掩盖异动"(这正是这次踏空的根因)。

---

## 2. 拐点信号定义(4 个子信号,全部 OHLCV 可算)

| 子信号 | 定义 | 分值 |
|---|---|---|
| **超跌** | KDJ 超卖(K<20 或 J<0) 或 RSI6<20 或 收盘距近 20 日最低 ≤3% | +25 |
| **放量反包** | 量比>1.5 且 当日收阳(close>open) 且 收盘站上 MA5 | +30 |
| **低位金叉** | KDJ 的 K 上穿 D 且 K<50(低位金叉) | +25 |
| **MACD 底背离** | 价创近低但 MACD 柱未创新低(简化版:近两个波谷比较) | +20 |

- **拐点评分** = 子信号加总,clamp 0~100。
- **拐点标签**:≥50 → `反弹启动`;25~49 → `超跌待反弹`;<25 → `无`。
- 阈值均为透明可调默认值,先跑起来再按实盘微调。

## 3. 输出契约(compute 新增 key)

```
"reversal": {
  "超跌": bool, "放量反包": bool, "低位金叉": bool, "底背离": bool,
  "拐点评分": 0~100, "拐点标签": "反弹启动/超跌待反弹/无",
  "依据": [ ... ],
}
```
趋势维度 `signal` 保持不变;两者并列。

## 4. 报告接入

- **组合报告新增「超跌反弹拐点榜」**:按拐点评分排序,列出 `反弹启动`/`超跌待反弹` 的票——直接堵 8/5 盲区(存储链应在此榜置顶)。
- **单票卡**:技术面章节加"拐点信号"行。

## 5. 测试(扩 test_technical)

- 构造"深跌后放量反包"序列 → 拐点标签=反弹启动、评分高。
- 稳定上涨序列 → 拐点标签=无(不误报)。
- 低位 KDJ 金叉识别正确。
- 数据不足优雅降级。

## 6. 预期效果

- 对当前缓存数据跑 report:存储链(江波龙/晶合/澜起/东芯等 8/5 大涨且 KDJ 超卖的)进入"拐点榜"靠前,即便趋势评级仍偏空。
- 全套单测通过。
