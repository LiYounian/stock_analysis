## 四、为什么这么做（设计决策留痕）
1. **停"合成他人票池"的过渡版**：用户明确不要各渠道合成糊弄，要真·金字塔。独立全A召回(575)证明四模式漏掉量价前20名的19个 → 必须独立召回。
2. **骨架偏好放量突破**：把缩量回踩票(300308#489/600995#534)排后面，纠正了历史"总是等回踩"的偏(源于 selection_synth 默认回踩MA5)。
3. **打分+浓缩块结合**：打分做可审计骨架、浓缩块喂 LLM 做受限调整，两条都留痕，守"LLM 不产数字"。
4. **全板块分析·重点3~5·浓缩不遗漏**：决策包扫全29板块，避免只看重点池漏信息。
5. **权重不定死**：留 D3 复盘按 forward 回测调。
