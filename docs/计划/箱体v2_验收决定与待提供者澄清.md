## 待提供者确认(请转达;前三条卡着能否往下走)
1. **⭐ 到底是"箱体"还是"抛物线突破"?** 近期 300209 是 6 根窄幅→抛物线加速(振幅>30%),与"20~60 天箱体"对不上——要的是**长横盘箱体突破**,还是**短窄幅整理后的加速突破**?(决定整个检测逻辑 + 是否需缩短最小窗)

4. 均线多头是否要**全序到 MA200**(默认只 close>MA200 且 MA5>10>20)?
5–7. 站稳容差 0.5% / 触碰容差 1% / 回落反弹 3% / 缩量比 0.8 / 横盘斜率 0.15 / 结构分下限 0.34(默认值,可先用,提供者有经验值再调)。
