# 选股·复盘 贯穿"次日实盘口径"整改设计

> 日期 2026-09-15 ｜ 状态：**待用户审阅**（审完再动 live SKILL）｜ ⚠️ 测试环境研究模拟，非投资建议。
> 维护：stock_analysis 统筹窗口。本文只写设计与口径，不改代码/不换线；用户拍板后另行执行。

---

## 0. 一句话

把"选股 → 入场 → 见效 → 复盘"四步统一到**次日实盘口径**：**D 晚选股给出次日(D+1)可执行的入场点 + 预期当日收盘为正 + 后日(D+2)卖出线**；**隔日复盘精确检验"若按该入场点买、到 D+1 收盘赚没赚"**，累积成一条**绝对收益胜率**曲线。让选股与复盘互相咬合、复盘变得有意义。

---

## 1. 背景：现状的两处不一致（要修的根因）

### 1.1 入场模型冲突（Model A vs Model B）
- **系统本意（Model A）**：选股→次日直接买→次日收盘见效→隔日复盘。生产的"选股(18:36) + 隔日盘尾复盘(15:05 复上一交易日)"闭环本来就是这个节奏。
- **后来叠加的 Model B（触发闸门·尾盘等信号）**：`⑧方向前提` + `① 超跌反抽放量收阳首入场` 要求"等哪天放量收阳、尾盘才买"，可能等多日。
- **冲突**：Model B 一旦"要等"，隔日复盘就是在给一个**尚未买入的票**记分 = 空转；且入场不落在次日、与"次日见效"目标脱节。**用户明确要求回到 Model A 并把链条贯穿。**

### 1.2 记分口径与操作目标脱节
- 现复盘 α = 个股 `昨收→今收` 涨跌 − 全A等权同期（**相对**市场的超额）。
- 但用户的操作目标是**绝对赚钱**（入场→当日收盘为正，次日直接卖也赚），且入场点是**次日开盘/盘中某点**、不是"昨收"。
- 故复盘必须改成：**按次日实际入场点计、既看绝对收益（是否为正）也看 α（是否跑赢市场）**。绝对收益胜率是用户第一位关心的指标，α 作能力诊断。

## 2. 目标模型（贯穿链条）

| 时点 | 产出/动作 | 口径 |
|---|---|---|
| **D 晚·选股** | 每只买入候选必给：① **D+1 入场点/条件**；② 预期**入场→D+1 收盘为正**（方向+置信+胜率区间）；③ **D+2 卖出线**（目标价/条件）；④ **止损线**（入场当日/次日破位即走） | 只用 ≤D 收盘信息（防未来） |
| **D+1·买入日** | 按入场点买入，目标当日收盘为正 | 入场点见 §3 |
| **D+1 收盘·复盘** | 复 D 选出的票：按入场点算**入场→D+1 收盘**的绝对收益 + α + 是否达"收盘为正" | 见 §4 |
| **D+2·卖出日** | 按 D+2 卖出线卖出（或直接卖） | 卖出线见 §3 |
| **D+2 收盘·跟踪** | 记录 D+2 卖出线是否达成、隔夜(D+1收→D+2)收益 | 见 §4 |

**诚实约束（必须写进 SOP，不删）**：没有策略能"保证"每一单入场→收盘为正。选股的职责是**最大化 P(入场→D+1收盘>0)**；复盘的职责是**如实统计实际胜率**；两者迭代把胜率往上推。"一定赚"是**目标与被持续检验的硬指标**，不是承诺。弱市宁可少选/不选，绝不为凑数硬塞（沿用 #10⑥）。

---

## 3. 入场点 / 卖出线 / 止损 的定义（可执行 + 可回测）

### 3.1 入场点（D+1，全天任意阶段，**必须是估量出来的，不许默认"开盘价买"**）
买入是**算出来的**，不能一股脑挂开盘价。每只买入候选**必须**给出下列三要素（缺一不可）：
- **(a) 具体入场价 `P_entry`（硬要求）**：给一个**明确的买入价位**（含依据：支撑位/成本密集区/回踩位/前低等）。用户可拿它去挂**集合竞价限价**或盘中限价。宁给"到 X 价才买"，不给"开盘随便买"。
- **(b) 观测时间窗 `T_obs`**：说明**观测到什么时点为止**——如"早盘 9:30–10:00 内触及 P_entry 则买""到 14:30 仍未触及则放弃"。给出**未触发的处理**（放弃 / 或退而求其次的次优价，写死一种）。
- **(c) 震荡低点买入位 `P_dip`（如适用）**：若判断当日会震荡，给出**回踩到什么程度可入手**的低点价位（可与 P_entry 分档：P_entry 为主买、P_dip 为震荡回踩加档或更优主买）。
> 复盘要能记分：入场规则必须**单一可判定**（价位 + 时间窗 + 触发/未触发口径清楚）。**不设"默认开盘价"**——开盘价买只是特例，需明确写"以开盘价为 P_entry"并给理由。
> 回测里 (a) 的"限价是否被触及"用当日 `low ≤ P_entry ≤ high` 判成交、成交价取 P_entry（保守可加滑点），(c) 同理。

### 3.2 D+2 卖出线（买入后给退出）
每只必给 D+2 卖出方案（至少其一，可组合）：
- **目标价止盈**：到 P_target 卖（给具体价位/幅度）。
- **时间止盈**：D+2 收盘无条件了结（短线不恋战）。
- **条件持有**：若 D+1 收盘强势(如放量收阳/站上关键位)可持到 D+2 看更高目标，并给 D+2 的移动止盈线。
> 涨停封板卖不出的预案沿用现 SOP ⑦（次日集合竞价挂跌停价优先出）。

### 3.3 止损线
入场后跌破 S_stop（具体价位）即离场；给"当日盘中破位"和"次日低开破位"两种情形的处理。

## 4. 复盘口径重构（让复盘咬合选股承诺）

盘尾复盘（D+1 15:05，复 D 选出的票）改为：

**逐票记分表新增列**（供 web 解析，列名一经定稿即冻结）：
- `入场点`（引 D 选股给的 D+1 入场规则）
- `入场价`（按规则取 D+1 实际成交口径：(a)=开盘价；(b)/(c)=触发价或"未触发"）
- `D+1 收盘`
- `入场→收盘 绝对收益%`（= D+1收盘/入场价 − 1）→ **主指标**
- `是否收盘为正`（是/否/未触发）→ **胜率计数**
- `α vs 全A等权`（= 绝对收益% − 全A等权同期口径）→ **归因 + 选股反馈**（见下，保留且重要）
- `β归因`（当日大盘/板块方向；该票下跌是否主要由 β 拖累）
- `D+2 卖出线达成`（次日跟踪补记）

**α/β 在复盘里的角色（回应用户第 1 点）**：**绝对收益是 KPI（要真赚钱），但 α/β 分解不丢**，两个用途：
1. **归因/学习**：这单亏损是**选错票(α<0)**还是**大盘拖累(β)**？两者教训不同、改法不同。
2. **反哺选股（关键）**：若一只票的下跌能归到 β（大盘弱它就跟跌），说明**当初在弱市就不该选这种 β 脆弱的票**——复盘要把"该票在弱市高 β 敞口、跟跌"这条**回灌给选股**（经验/负样本），让选股下次避开。
> 即：**绝对为正是目标，α/β 是达成它的手段**——靠 α/β 归因反过来管住"别在弱市选会跟跌的票"，绝对胜率才提得上去。

**累积胜率牌**：复盘任务维护滚动统计（如 `data/analysis/backtest/nextday_scorecard.csv`）：近 N 日"入场→收盘为正"的**绝对胜率**、平均绝对收益、平均 α、**β 拖累致亏占比**、卖出线达成率。这是这套策略对用户的**核心 KPI**，也是复盘存在的意义。

**"未触发"处理**：(b)/(c) 条件入场未触发的票，记"未触发、不计入胜率分母"（诚实，不拿没买的票充数）；但要统计"未触发率"，太高说明入场条件设太苛、失去次日可执行性。

**防未来/防偷看**：复盘只用 ≤D+1 已确定数据；胜率是 append-only 事后统计，绝不回改历史、绝不挑日子。

## 5. 三个 live SKILL 的具体改动（审后执行）

### 5.1 `daily-stock-selection`（盘后选股，18:36）
- **⑧方向前提 重构**：不再要求"等尚未出现的触发信号才给方向 / 只给低波动待动"。改为：**给次日(D+1)入场点 + 预期收盘为正的方向与胜率 + D+2卖出线 + 止损**（§3）。方向依据不足时降级为"不选此票"，而非"选了但让你等信号"。
- **① 放量收阳换线回退**：删去"超跌反抽首入场=等放量收阳（多日尾盘等待）"这一段。放量收阳可保留为**(c) 类盘中入场条件之一**（次日盘中当场判、非多日等待），或直接不作硬闸。
- **绝对收益优先 + β 脆弱性过滤**：市场环境判断仍读 market_forecast 作 β 背景；选票以"次日绝对为正的概率"为纲。**大盘偏空/弱市时，主动避开"高 β 敞口、会跟跌"的票**（回应用户第 1 点：会因大盘下跌的票当初就不该选），优先"低 β 抗跌 + 有独立 α 催化"的票。普跌/弱市**宁缺毋滥**（#10⑥）。
- **入场价必给**：每票按 §3 给 `P_entry`/`T_obs`/`P_dip`（估量出的价位，非默认开盘）。
- **保留**：capitulation β 背景(#10⑤)、防未来、结构化 write_picks Tool（需扩字段：入场点/卖出线/止损，见 §6）。

### 5.2 `daily-stock-eod-review`（盘尾复盘，15:05）
- 复盘口径改为 §4：按入场点算**绝对收益 + 是否收盘为正 + α**，逐票记分表加列，维护累积胜率牌。
- 保留经验沉淀并版 + 状态字段(④)。

### 5.3 `daily-stock-noon-analysis`（午盘研判）
- 角色重定位：午盘正好是 **D+1 盘中入场点的"当场确认"节点**——对昨日(D)选出、且用 (c) 类盘中条件入场的票，午盘判断触发没触发、给尾盘前的执行提示。与 §3.1(c) 咬合。
- 去掉与 Model B 绑定的措辞。

## 6. 配套代码/数据（审后由实现线做）
- `tools/analysis/write_picks.py` canonical JSON **扩字段**：`entry_rule`/`entry_type(a/b/c)`/`target_line`/`stop_line`/`expected_close_positive_prob`。带校验。
- 复盘 web 解析：`parse_review_close_pct` 增补"绝对收益/是否为正/入场价"列解析（列名冻结）。
- 累积胜率牌：`data/analysis/backtest/nextday_scorecard.csv` 写入逻辑（复盘任务 append）。
- **回测支撑（本整改的证据底座，另起 chip 做，见 §7.2）**：不止"开盘价入场"，要按 §3 的**估量入场价口径**回测：
  - **限价成交模型**：入场 `P_entry`（及震荡低点 `P_dip`）在 D+1 是否被触及（`low ≤ P ≤ high` 判成交、成交价取 P、可加滑点），触及才算买入、否则"未触发"。对比"开盘价买"作基准，看**限价入场是否真的改善绝对胜率/期望**。
  - **绝对收益 + α/β 双口径**：每单同时出"入场→当日收盘绝对收益（是否为正=胜率）"和"α（−全A等权）/β 归因"，验证 §4 的"β 脆弱票该被过滤"是否成立（弱市里高 β 票的绝对胜率是否显著更差）。
  - **观测窗敏感性**：不同 `T_obs`（早盘/全天）对触发率与胜率的影响。
  - 最强选股 chip 正在补的 `open[t+1]→close[t+1]` 是这个底座的第一块（开盘价基准档），本 chip 在其上加限价/α-β/观测窗维度。

## 8. 风险与诚实边界
- **胜率非保证**：目标是高胜率+正期望，复盘如实兑现率；达不到就迭代或收缩策略，绝不粉饰。
- **"次日收盘为正"对单只不可保证**：分析师历史教训（#8/#14/#31）是"静态理由预测不了次日上涨"。本整改的赌注是"**用更强的方向+催化+资金证据挑出次日绝对为正概率高的少数票**"——是否成立，靠 §7.2 回测底座**先证再上**，不预设成立。
- **入场条件不能太苛**：否则"未触发率"高、失去次日可执行性；用未触发率作护栏。
- **防未来/防偷看**：全链只用 as-of 数据；胜率牌 append-only、不回改、不挑日。
