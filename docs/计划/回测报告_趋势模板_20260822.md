# 趋势模板(Minervini 8 条)前瞻回测报告 · 2026-08-22

> ⚠️ **非投资建议。** 本文是对 A 股全市场公开行情做的历史统计,仅用于验证筛选器的方向性设计意图,不构成任何买卖建议。
>
> ⚠️ **口径先说清:方向性 sanity,非全 A alpha。** 趋势模板是**看多/趋势型筛选器**,定位为**过滤器 / 研究工具**(第一层趋势门,不含买点/放量/枢纽确认)。本回测只验证「入池后前瞻收益是否偏正、是否相对全 A / HS300 有方向性倾斜」,**不以绝对超额(alpha)为验收门槛**。已知先验:趋势模板类信号在 A 股 alpha 不显著(需求文档预注册 p=0.87),本文诚实呈现,弱 edge 就说弱。

---

## 一、方法(walk-forward,无未来函数)

- **数据**:全 A 前复权日线主档,5,131 只(排北交所 8/4 头;历史 <250 根者剔除),跨度 2018-01-02 → 2026-08-21(约 8 年,覆盖多轮行情段)。
- **测试日**:全跨度按固定步长(交易日 stride=60,约一季)抽样,并保证每个 regime 段有覆盖;仅取距样本末 ≥20 交易日者(留足 T+20 前瞻)。步长 60 使相邻测试日的前瞻窗(≤T+20)不重叠 → 事件近似独立。
- **入池口径**:**完整模式 A1–A8**。A8 = 当日**全 A 横截面** Return250 百分位 RPS250 ≥ min_rps(默认 70)。逐票在测试日 t 判定,指标只用 ≤t 的 K 线(纯函数,天然无未来函数)。
- **前瞻窗口**:进场锚定测试日后首个交易日,测 **T+1 / T+5(≈1 周)/ T+10(≈2 周)/ T+20(≈1 月)** 的收益(含执行滞后;窗口越界记缺失,不回看、不编造)。
- **方向感知(看多型)三组对照**:
  1. **命中组**——测试日入池票的前瞻收益;
  2. **全 A 等权 baseline**——同测试日全体有效票的同窗前瞻均值(同宇宙无条件对照,对全 A 筛选器比 HS300 更同口径);
  3. **HS300 基准**——同测试日指数同窗前瞻。
  判据:命中组均值 **≥ baseline 且 ≥ HS300** → 方向对;Alpha = 命中前瞻 − HS300 前瞻。
- **A/B 标定**:min_rps ∈ {70,80,90} × A7 距 52 周高 ∈ {0.75(25%内), 0.85(15%内)},给阈值收紧/放松的样本量-方向性权衡。
- **复用**:前瞻测量复用 `tools/backtest/event_study.py`(`forward_returns` + `summarize`),不另造轮子。

## 三、诚实结论

1. **无独立正向 edge(与先验一致,甚至更弱)**:全 A 全跨度(2018–2026,35 测试日)聚合看,命中组前瞻各窗均值**低于全 A baseline 且低于 HS300**,相对 HS300 负超额 T+10 -1.33% / T+20 -2.11%,胜率 38–45% < 50%。这与需求预注册的「趋势门 A 股 alpha p=0.87 不显著」一致,方向甚至偏负。
2. **本质是顺势放大器,效果由 regime 决定**:牛市显著跑赢(T+10 +3.72%),震荡/熊市显著跑输(震荡 T+10 -3.07%)。聚合为负,主因是本抽样窗震荡日占多(20/35),而非策略"坏"——它在无趋势环境放大了高动量名的回撤。
3. **调阈值改不了方向**:min_rps 90 + A7 距高 0.85 只把负超额从 -1.33% 收窄到 -1.13%(T+10)、样本减半;收紧提升的是"少而略好",仍为负。
4. **右偏/动量分布**:收益靠极少数大涨名贡献,须配仓位/止损,不能当高胜率信号。
5. **定位与标定建议(独立工具)**:**不可作独立看多 alpha 源**;宜作**趋势/regime 过滤器或前置门**——建议叠加市场状态门(仅牛/强趋势启用,震荡/熊关闭或收敞口)+ 买点确认(如 SEPA+VCP 枢纽收缩)+ 止损。单独入池不构成完整策略。

## 四、局限与后续

- **样本期 regime 偏置**:2018–2026 含多轮牛熊,但 A 股结构性行情切换快,分层样本在熊段偏薄(见 regime 表 N),熊段结论仅供参考。
- **非全 A alpha 保证**:与预注册先验一致,趋势门单独使用的超额多不显著;本文定位为方向性 sanity + 阈值标定,不追绝对 alpha。
- **右偏/动量特征**:胜率常低于 50% 但均值为正 → 收益由少数大涨样本贡献(右偏),属趋势/动量策略的典型分布,须配合仓位/风控使用,不能当高胜率信号。
- **未含买点**:趋势模板只是第一层门;要落地需叠加买点确认(如 VCP 枢纽/放量突破)与止损,单独入池不构成完整策略。
- **后续**:可与 SEPA+VCP「接近枢纽」层叠加(趋势门 ∩ 枢纽收缩)观察方向性是否增强;可引入换手/流动性二次过滤降右尾噪声。
