# 选股规避能力整改 · 诊断与回测设计（2026-09-16）

> 状态：**待用户审阅** → 审后按数据可验性分线执行。⚠️ 测试环境研究模拟，非投资建议。
> 维护：统筹窗口。KPI = **绝对收益**（Model A 口径：D 选 → D+1 估量价入场 → D+1 收盘绝对为正 → D+2 卖出线）。
> 起因：用户指出近日选股亏损、且**漏掉了在涨的票**（通鼎/双星/奥士康），并要求从**板块级 + 大环境级（宏观，如美联储加息）**做规避。

## 0. 诊断结论（先厘清事实，不甩锅）

**"普跌"不是理由——收回。** 同日有票在涨（双星三连板 +33%、奥士康续强），没选出来是选股侧的问题。三只票是**三种不同的失败模式**，不是同一个盲点（两路只读取证，2026-09-16）：

| 票 | 近日实际 | 系统里发生了什么 | 定性 |
|---|---|---|---|
| 通鼎互联 600289 | 5 日 −5.77%、20 日 −8.93%、换手 0.2%（死量） | 零策略命中、从未进候选池 | **前提不成立**——在跌不是在涨，未选是对的 |
| 双星新材 002585 | 三连板 +33% | 个股层被「量价放量」抓到，但被①单命中②基本面红旗 veto→tier0③候选排名#16 三重挡掉；+ ④板块拐点走申万一级、MLCC 概念被一级粒度漏掉 | **真赢家被基本面 veto + 概念粒度盲点挡掉** |
| 奥士康 002913 | 09-14 +5.59%、题材续强 | 09-11 选过；09-14 标"规避"；09-15 因普跌日整体降级 + winner_rate≈98%(获利盘~100%高抛压) + 业绩预告 −54.5% 主动规避 | **系统主动规避强动量+弱基本面+超买票**（其涨是 PCB/AI 题材 β，非基本面催化） |

**宏观（美联储加息）现状**：系统**在采**（`policy.py` 关键词含 美联储/加息/CPI/非农/关税/白宫；`sentiment_policy.json` 每条消息带 `region`+`industries`+`影响方向`+`影响强度`），但**只汇成大盘级日度净利好度标量**喂大盘预测（~55% 命中、作 β 背景、非硬规避）。**每条消息已标的"影响行业+方向"没有落到选股的板块规避**——"美联储加息→利率敏感/高估值成长板块系统性降权规避"这条链**没接**。原料已在库、缺的是接线。

**三个真问题**（都关系绝对收益 KPI）：
- **A｜续选缺口 + gap-fade 误伤**：选股是无状态每日重筛、入选多靠单日触发信号、`position_ledger` 有多日持有能力但没接进选股；加上 2B(a) 我引入的 gap-fade 把续涨强势票当降权挤出（本意是"怎么买"的入场纪律，被误用成"要不要选"）。抓不住持续赢家 = 实打实漏利。
- **B｜基本面 veto / 超买规避在题材行情误杀强动量票**：双星/奥士康都是"价量强但被判基本面弱"被 veto。弱市防爆雷有理，但游资/题材行情里系统性错过还在炒的强票。
- **C｜宏观 / 板块级消息规避缺失（用户重点）**：宏观海外消息已采、已标行业+方向，但没接成板块级规避信号。

## 2. 三维方案（复用已有基建·不重造）

> 复用：regime 板块环境层（`thermometer` 拥挤度/动量冷热 + `sentiment_judge` 情绪）、`sentiment_policy.json` 每条消息的 `industries`+`影响方向`+`影响强度`、`position_ledger`（持仓账本）。全部 forward-shadow 期间 **non-gating**、不进生产选股，validated 才上线。

### A · 续选缺口 + gap-fade 误伤（真回测线）
1. **回测**（预注册见 §3）：在持续型排名视图（动量/合议/S05/趋势模板）上，对比"**已选强势票续选/继续持有到 D+2** vs 无状态重挑新票"的绝对收益；并测 wr>99 票**用回踩限价买入并持有** vs 被 gap-fade 降权丢弃 的绝对收益差。
2. **达标后改线**：接通 `position_ledger` → 选股产物加"**继续持有/继续跟踪**"档（不与新票抢 3–5 名额、不被 gap-fade 降权）；把 gap-fade 从"降权（要不要选）"改回"入场提示（怎么买·回踩限价）"。

### B · 基本面 veto 是否误杀强动量题材票（forward-shadow 线）
1. **forward-shadow**：每日记录"价量强(命中量价放量/最强选股)但被基本面 veto/业绩预告负/超买规避"的票 → 跟踪其 D+1/D+2 绝对收益，攒样本判 **veto 是净避损还是净漏利**。**不动 live veto**。
2. 现有例子（双星/奥士康 + 6 天标签内）做描述性，只作方向参考、不作结论。

### C · 宏观 / 板块级消息规避（复用板块层·forward-shadow 线）
1. **接线（复用不重造）**：把 `sentiment_policy.json` 每条消息按 `industries` rollup 到申万一级 → 聚合成**板块级宏观/消息净方向 + 强度**；叠加 regime `thermometer` 的拥挤度/动量冷热作确认 → 产"**板块规避标记**"（如"美联储加息命中 → 利率敏感/高估值成长板块打规避"）。
2. **31 天窗口 sanity**：检验"宏观利空命中板块"在该窗口是否真跑输（方向性，不作 validate）。
3. **forward-shadow**：每日落板块规避标记 + 跟踪该板块候选票后续绝对收益，攒 ≥120 天。**不动 live 选股**直到 validated。

## 3. 预注册（防偷看·防未来·硬要求）

- **A 回测**：先写死"续选规则"（已选票次日仍在持续型视图 TopN 且未破 D+2 卖出线 → 续选/续持）与"成功判据"（绝对收益 net 提升 且 不显著抬高回撤），**再**跑；walk-forward、时间序 OOS 切分、参数高原检查；**绝不对通鼎/双星/奥士康这几个例子调参**（它们是诊断线索、不是拟合目标）。
- **B/C forward-shadow**：预注册"veto 命中口径"/"板块规避判据（净方向+强度阈值）"，落盘后**只读不改**，append-only；样本 <120 只报 N、不下结论。
- **防未来**：A 回测严格 ≤D 数据（限价成交用当日 low/open、基准用当日全A等权）；C 消息按 as-of、板块 rollup 因果。

## 4. 上线门槛
- **A**：OOS 绝对收益净正 + 多年一致 + 不抬高回撤 → 换线（selection SKILL + position_ledger 接线）。不达标 → 只改 gap-fade 语义（入场提示，低风险纯正确性）。
- **B/C**：≥120 天 forward 样本 + 命中显著 → 才由统筹 surface 用户拍是否真 gate。此前纯记录。
