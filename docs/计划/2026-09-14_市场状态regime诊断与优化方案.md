# 市场状态 regime（大盘冷热）· 诊断与优化方案

> 日期 2026-09-14 · 对象 = **市场状态 Market Regime** `tools/analysis/pattern_screener/regime.py`
> （5 因子平权 → 情绪分 0–100 → 五档：冰点/熊市共振/震荡/分化/牛市共振）。
> 编排层 `tools/pipeline/regime.py`；参数 `THRESHOLDS["市场状态"]`。
> **本文=诊断 + 优化方案（守则#4：先出方案审阅，再动生产代码）。只读诊断，未改任何模型/配置/生产。**
> 非投资建议。防未来函数：情绪分只用 ≤T 信息，前瞻收益为标签。可复现脚本见同名 `_artifacts/`。

## 0. 这是哪个模型（避免与"四维预测器"混淆）

regime 是**无监督情绪温度打分**——描述"当下市场多热"，**不是**预测涨跌方向的模型（那是另一个
`market_forecast` 四维预测器，见 `docs/计划/2026-09-14_大盘预测四维分维度诊断.md`）。
本次目标是把这个**温度计**做扎实：验证它有没有预测/择时价值、标定占位参数、重构因子与权重。

---

## 结论速览（TL;DR）

1. **"五因子平权"名不副实——生产里只有 2 个因子可靠存活**：
   - **科技共振** = 死（`核心龙头池` 配置为**空** → 恒降级，avail 0%）。
   - **涨跌停** = 死（`pipeline/regime.py:71` **硬编码 `涨跌停=None`** → 恒降级）——但数据其实现成（breadth 有
     `limit_up/limit_down` 家数），是**没接线**，非没数据。
   - **宽度** = 名存实亡（真输入=形态选股「达标占比」view，**历史仅 1 个文件、值还是 0.0** → 几乎从不填充；
     `宽度参考占比=0.05` 是**未标定占位**）。
   - 真正可靠存活的只有 **指数多头 + 量能**。→ 现状情绪分 ≈ **指数MA + 成交量**两因子平权，其余三维形同虚设。
2. **五档标定坏，温度计"读不出冷"**：重建的情绪分区间 **41–96、均值 75**，落档全在 分化/牛市共振/震荡，
   **冰点 与 熊市共振 两个看空档从未触发**（现边界 20/40/60/80 是等分占位，与真实分布严重错配）。
   一个报不出"冰点/熊市"的市场温度计，在真正该避险时是哑的。
3. **情绪分几乎无方向预测力，但存在轻微"反向/过热"结构**：hs300 上 IC(情绪分, 前瞻)≈ **−0.04~0**（T+1/T+5），
   方向命中≈49%（不及掷硬币）。但**五档前瞻收益单调"反着来"**：震荡 > 牛市共振 > 分化（T+20：+2.4% / +1.5% / +0.66%），
   且 **量能因子 IC 稳定为负**（T+20 达 −0.11）——高温≈过热透支，未来收益反而低。
   现口径把"高温"当利好（分数越高越偏牛），**方向恰恰用反了**。
4. **优化路径清晰**：接线复活涨跌停、按分布标定五档边界（让看空档可达）、重估因子朝向与权重
   （量能/宽度是**过热反向**信号而非顺势），并明确温度计定位（描述过热度 vs 预测方向，二选一或分层）。

## 1. 诊断详情

### 1.1 因子存活体检（hs300 真指数窗口 2025-03→2026-09，n=359）

| 因子 | 生产可用率 | 子分 std | 唯一值数 | 状态 |
|---|---|---|---|---|
| 指数多头 | 94.7% | 0.40 | 3 | ✅ 活（0/0.5/1 三态） |
| 量能 | 99.4% | 0.12 | 247 | ✅ 活（连续） |
| **科技共振** | **0%** | — | 0 | ❌ 死：龙头池空 |
| **涨跌停** | 生产 0%（重建后活，std 0.21/258值） | — | — | ❌ 死：`regime.py:71` 硬编码 None；**数据现成、仅未接线** |
| **宽度** | 真输入历史仅 1 天 | — | — | ⚠️ 名存实亡：达标占比 view 几乎不产出；ref=0.05 未标定 |

> 注：上表"涨跌停/宽度"的重建用 breadth 家数 / `above_ma20_ratio` 代理，用于**评估其潜在价值**；
> 生产真实状态是"死/名存实亡"。重建显示**涨跌停一旦接线会是最活跃的因子**（std 0.21）。

### 1.2 五档标定（分布 vs 现占位边界）

- 情绪分实际分布（hs300）：min **41.05** / 均值 75 / max 95.9；分位 10%=58、50%=76、90%=90。
- 现五档边界（等分占位）：冰点≤20 / 熊市共振≤40 / 震荡≤60 / 分化≤80 / 牛市共振≤100。
- 落档计数：**牛市共振 146 + 分化 168 + 震荡 45，冰点 0 + 熊市共振 0**。
- **诊断**：因 宽度(代理)与量能长期把分抬高、且看空事件在平权里被稀释，情绪分**下不去 40**，两个看空档
  永远空置。边界是"数轴等分"而非"数据分位"，与真实分布错配。长样本 proxy(2018+，含 2018/2022 熊市)同样从未触发看空档
  （min 40.3）——说明**即便经历过真实熊市，这套口径也报不出"冷"**。

### 1.3 预测力验证（情绪分/因子/五档 → hs300 前瞻收益）

| 视野 | IC(情绪分) | 方向命中 | 量能 IC | 指数多头 IC | 涨跌停 IC(重建) | 五档前瞻(震荡/牛共/分化) |
|---|---|---|---|---|---|---|
| T+1 | −0.038 | 48.9%±2.6 | −0.049 | −0.001 | −0.058 | +0.25% / +0.07% / −0.03% |
| T+5 | −0.036 | 48.0%±2.7 | −0.072 | +0.015 | −0.047 | +0.91% / +0.36% / −0.04% |
| T+20 | +0.006 | 53.4%±2.7 | **−0.114** | +0.037 | +0.010 | +2.45% / +1.47% / +0.66% |

- **情绪分本身无正向择时价值**（IC≈0 甚至微负，命中≤50%）。
- **五档前瞻收益系统性"倒挂"**：温度越高，未来收益越低（各视野一致）——温度计是**轻微反向/过热指标**。
- **量能是最稳定的（反向）信号**：高量能→未来收益低（透支/blow-off），IC 随视野拉长增强（T+20 −0.11）。
  现口径却把高量能计为"高温=偏牛"，**符号用反**。
- 诚实标注：hs300 N=359、每档 n=37–168、命中 SE≈2.7pp、IC_SE≈0.05——**弱信号、探索性**，跨档 0.x% 差异含噪声。
  proxy 长样本(2018+, n=2111)佐证方向：宽度(above_ma20)IC 稳定为负(−0.05~−0.10)、震荡档前瞻始终最高（反向结构稳健），
  但 proxy 幸存者偏差 + 指数多头/量能在 proxy 失真，其绝对值不解读。

## 2. 优化方案（分层，按投入/收益排序）

> 原则：先**修管道让 5 因子真活**（低成本、纯接线/标定），再**验证并重定语义/权重**（有数据支撑再动），
> 最后决定它**是纯温度计还是择时信号**。每步都走 walk-forward + holdout，不在测试集调参（守则贯穿）。

### P0 复活死因子（纯工程，无建模风险）
1. **涨跌停接线**：`pipeline/regime.py` 把 breadth 的 `limit_up/limit_down` 家数喂给 `factor_涨跌停`
   （数据现成，删掉硬编码 `涨跌停=None`）。预期：+1 个活跃因子。
2. **科技共振**：要么**填 `核心龙头池`**名单（并定市值门槛），要么**移除该因子**（诚实降为 4 因子），
   避免长期挂着一个恒降级维。建议先移除、待龙头池口径定了再加回。
3. **宽度**：真输入「达标占比」几乎不产出 → 要么保证形态选股每日先跑并落 view（运行时耦合），
   要么**改用 breadth 的 `above_ma20_ratio` 直接做宽度**（每日可得、语义相近）。二选一，别留空转。

### P1 标定占位参数（用数据，防未来函数）
4. **五档边界改数据分位**：用**因果扩窗分位**（只用 ≤T 历史，不偷看）把 20/40/60/80 换成情绪分自身分布分位
   （如 10/30/50/70/90 分位切点），保证**五档都可达、看空档能触发**。当前等分占位必须废弃。
5. **宽度参考占比 ref**：若保留达标占比口径，ref 按其真实历史分布（因果分位）标定，而非固定 0.05；
   若改 above_ma20_ratio，直接用其因果分位映射到 [0,1]，取消 ref。

### P2 重估因子朝向与权重（需先做完 P0/P1 攒出有方差的历史序列）
6. **明确温度计语义**（关键分叉，需用户拍板）：
   - **路线 A：纯描述性过热计**——保留"高分=热"，但**语义与"看多"解耦**（高温=过热≈风险，不是买入信号）。
     下游按"过热→减仓/收紧、冰点→放宽"使用（利用其反向结构）。改动小、诚实。
   - **路线 B：预测性择时信号**——把它当有监督模型：按 IC 定**因子朝向与权重**（量能/宽度取负号、指数多头取正），
     walk-forward 拟合，holdout 显著才上线。风险：现有效因子少、信号弱，可能拟合噪声。
7. **平权 → 数据驱动权重**（仅路线 B）：IC 加权或轻正则回归，按 walk-forward 出样本外权重；
   接**架构⑤权重自适应**框架统一治理（与四维预测器共用方法学）。

### 验证与测试（守则#6）
- 为 regime 加**预测力回测脚本**（本 `_artifacts/regime_diag.py` 可作基础），断言锁住：
  五档必须都可触发、情绪分 IC 报告、因子朝向符号。防未来重写时无声改坏标定/朝向。

## 3. 总结论 & 待拍板点

**总结论**：现 regime 是个"**2 因子平权、读不出冷、且把过热当利好**"的温度计——既没做到"五因子"，
五档标定也失效，方向语义还用反了。好在问题都可修：死因子是没接线/空配置（非没数据），标定是占位（非无法标），
反向结构反而是它**唯一被数据支持的价值**（过热预警）。

**待你拍板**：
1. **温度计定位选路线 A（纯过热预警，改动小、诚实）还是路线 B（预测择时信号，需建模、样本弱有过拟合险）？**
   —— 我的推荐：**先 A 后 B**。P0/P1 先把它修成一个可信的描述性过热计（并把"高温=风险"讲清楚），
   同时攒有方差的历史；待样本够、路线 B 的 holdout 显著性达标再升级为择时信号。
2. **科技共振**：填龙头池 还是 先移除降为 4 因子？
3. **宽度**：保达标占比口径（要保证每日先跑形态选股）还是 改 above_ma20_ratio（每日可得，我倾向这个）？
4. P0/P1 属改生产（`pipeline/regime.py` + `config/strategy.py`）——确认后我开实现窗口/分支，分步 commit + 测试。

### 诚实标注（N/SE/幸存者偏差/小样本）
- 预测力结论主证据 hs300 n=359、每档 n=37–168、命中 SE≈2.7pp、IC_SE≈0.05 → **弱信号、探索性**。
- proxy 长样本仅作方向佐证：**幸存者偏差** + 指数多头/量能在等权代理上失真，绝对值不可解读。
- 宽度用 `above_ma20_ratio` 代理真「达标占比」（后者历史几乎无数据）→ 宽度相关结论标注为代理、非生产实测。
- 科技共振无法重建（龙头池空），其价值本诊断**未评估**。
