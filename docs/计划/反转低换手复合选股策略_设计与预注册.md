# 反转 + 低换手 复合选股策略（设计与预注册）

> 状态：**待审** · 日期：2026-08-23 · 分支：`feat/strategy-new`
> 一句话：用 A 股实证最强的两个 alpha —— **短期反转** 与 **低换手率** —— 做一个纯量价、低相关叠加的多因子选股策略，落成一个新 `@strategy` + 全 A 扫描管线 + 回测验收。

---

## 一、原始需求（负责人诉求 + 调研来源）

- 负责人诉求：分析开源项目 [VernonOY/alpha-skills](https://github.com/VernonOY/alpha-skills)，从中挑一个策略思路，落成本项目的一个新策略。
- 调研结论（见本文附录 A / 会话记录）：alpha-skills 本质是"给 AI 助手用的量化方法论技能包"，其 `knowledge/factor-taxonomy.md` 给出 A 股因子有效性实证排序：
  - **短期反转（5 日）= A 股最强 alpha**（"the dominant alpha source in Chinese equities"，IC 0.04–0.08）。
  - **低换手率 = 第二强 alpha**（"the #2 alpha source after reversal"，ICIR>0.5）。
  - 二者**相关性低**（一看价格、一看成交），符合其核心原则："两个 IC=0.03、corr=0.2 的因子叠加 >> 单个 IC=0.05 的因子"。
  - 传统**动量在 A 股弱甚至反向**（本项目现有策略 A/B 是动量系，正好互补而非重复）。
- 选定方向：**反转 + 低换手 复合选股**。理由：全新（现有 5 个策略无纯反转、无换手因子）、纯量价好落地（数据已备）、是实证最强方向、与现有策略互补。

## 二、为什么可行（前置事实核验）

动手前已核验的关键事实（避免拍脑袋）：

1. **换手率数据已备**：主仓 `master/kline/*.parquet` 的 `turnover` 列非空覆盖 ~99%，全 A 共 5.2 万个 kline 文件。低换手因子有**真实换手率**支撑，无需用成交额/流通股本凑代理。
2. **标准化手法项目已有**：`tools/strategy/semi_factor.py` 的 `_winsorize_med`（中位数 ±3×MAD 去极值）+ `_zscore`（截面标准化）与 alpha-skills 的 `standardize()` 口径一致，可直接复用/抽提为共享工具。
3. **多因子选股 + 调仓回测机制项目已趟通**：策略 E（半导体多因子）已实现"winsor+zscore 加权 + 每 20 交易日调仓"；`tools/backtest/` 下已有 `engine.py` / `backtest_rank.py`（排名类因子回测）/ `metrics.py`；`THRESHOLDS["回测"]` 已定义 `cost_bps=5`、`rebalance_days=5`、`execution_lag=1`（T+1 成交）、`年化交易日=244`。新策略可直接接入。
4. **业务过滤器已有先例**：涨跌停（`|pct_chg|≥9.7`）、停牌（snapshot 缺失）、板块头剥离（30/68/8/4/9）在策略 C/D/E 中均有实现，可沿用。

## 三、要实现哪些功能（可验收的功能点）

- [ ] **F1 反转因子**：`rev_N = -(close[t]/close[t-N] - 1)`，默认 N=5。截面去极值 + zscore。（验收：给定构造序列，跌得多的票 z 值更高。）
- [ ] **F2 低换手因子**：`turn_N = -(过去 N 日平均 turnover)`，默认 N=20。截面去极值 + zscore。（验收：换手越冷的票 z 值更高；turnover 缺失票按规则剔除并计跳过数。）
- [ ] **F3（可选第三腿）量价背离因子**：`pvd = -corr(日收益率, 成交量变化率, 窗口=20)`。默认**先不纳入主策略**，作为对照/扩展开关。（验收：价涨量缩的构造序列得高分。）
- [ ] **F4 复合打分**：`score = w_rev·z(rev) + w_turn·z(turn)`，默认等权 `w_rev=w_turn=0.5`。权重进 `THRESHOLDS`。（验收：单票依据里能看到两因子各自 z 值与权重。）
- [ ] **F5 选股策略注册**：`@strategy("反转低换手组合", "选股")`，签名 `fn(records) -> dict`（对齐策略 C/D/E 返回结构：候选 + 依据 + 跳过统计）。输出 `top_k`（默认 20）。
- [ ] **F6 股票池与业务过滤**：全 A；剔除 ST/退（9 头）、科创/创业/北交（可配开关，默认**纳入**全 A，仅提供剥离开关）、次新（上市 < M 日，默认 M=60）、当日涨跌停、停牌；**流动性下限**（过去 N 日平均成交额 < 阈值剔除，防选出买不进的僵尸票）。
- [ ] **F7 全 A 扫描管线**：`tools/pipeline/screen_reversal_turnover.py`，仿 `screen_momentum.py`（**纯量价、不触发全 A serialize**，只按需加载 kline 收盘 + turnover 序列）。产出落 `store.put_view`。
- [ ] **F8 阈值集中**：所有参数（N、权重、top_k、过滤阈值）进 `tools/config/strategy.py` 的 `THRESHOLDS["反转低换手"]`，不散写硬编码。
- [ ] **F9 回测**：见第五节。至少跑通 **①组合调仓净值回测** + **②因子有效性（IC/ICIR）回测**，与基准对比，出诚实报告。
- [ ] **F10 测试**：见第六节，断言锁住"防未来函数""因子方向""过滤语义"。

### 4.3 接口 / 契约

因子与策略函数签名（对齐 registry 三类标准签名 + 策略 C/D/E 返回结构）：

```
# 因子（纯函数，输入按票的时序，输出该票的原始因子值；标准化在 screen 里跨截面做）
reversal_factor(closes: list[float], n: int = 5) -> float | None      # -(涨幅)；不足 n+1 根 → None
low_turnover_factor(turnovers: list[float], n: int = 20) -> float | None  # -(均换手)；缺值不足 → None
pv_diverge_factor(closes, volumes, window: int = 20) -> float | None  # -corr(ret, vol_ret)；可选

# 选股策略（注册进 registry；返回结构对齐策略E）
combo_reversal_turnover_screen(records, top_k=20, as_of=None, kline_loader=None) -> dict
#   -> {"候选": [code...], "明细": [{code, score, z_rev, z_turn, 依据:[...]}...], "跳过": {原因: n}}
```

**防未来函数契约（命门）**：因子只用 `close.iloc[:t+1]` / `turnover.iloc[:t+1]`（截至信号日 t 的已见数据）；回测建仓在 **t+1**（`THRESHOLDS["回测"]["execution_lag"]=1`），成交价 `close`（可配）。不读任何 t 之后的数据。

### 4.4 THRESHOLDS 草案

```python
"反转低换手": {

    "权重": {"反转": 0.5, "低换手": 0.5},   # 等权；可调

    "流动性_最小成交额_万元": 5000,  # 过去换手窗口内均成交额下限（防买不进）

    "剥离创业科创北交": False, # True=只留主板；默认纳入全 A，仅提供开关
    # —— 可选第三腿 ——
    "启用量价背离": False,

```

## 五、回测方案（能不能验证）

**能，两种口径都搭，互为印证：**

### 5.1 组合调仓净值回测（模拟"能赚多少"）
- 复用 `tools/backtest/engine.py` + `backtest_rank.py`：walk-forward，每 `rebalance_days`（默认 5）用**当时可见数据**给全 A 打分 → 取 top_k 等权持有到下期 → 扣 `cost_bps` 双边成本 → 算组合收益。
- 产出：累计/年化收益、最大回撤、夏普、月胜率、**相对基准超额**。
- 基准：等权全 A（默认）+ 沪深 300（可选）。

### 5.2 因子有效性回测（模拟"因子到底有没有用"，防自欺）
- 借鉴 alpha-skills 评估口径，新增（或接入现有）**IC/ICIR** 评估：
  - **Rank IC**：逐期算"因子分排名"与"未来 N 日收益排名"的 Spearman 相关，取时序均值。
  - **ICIR** = IC 均值 / IC 标准差（alpha-skills 称"the single most important metric"）。
  - **五分位单调性**：按因子分五档，看各档未来收益是否单调（Spearman(组序, 组收益) 应显著为正）。
  - **多空组合**：top 档做多、bottom 档做空的收益/夏普。
- 这套比净值曲线更快、更能识别过拟合（一条好看的曲线可能只是运气或未来函数）。

### 5.3 诚实性验收标准（达标才算"策略成立"，参考 alpha-skills 门控）
- ICIR ≥ 0.3（Moderate）为门槛，≥ 0.5（Strong）为优秀；
- 五分位**单调**（top 档 > bottom 档，且大体递增）；
- 组合净值回测**超额为正**且最大回撤可接受；
- **防未来函数测试通过**（见第六节）。
- 未达标 → 如实记录"该方向在本项目数据上未复现 alpha-skills 结论"，不美化（诚实性优先，与项目 §5.4 一致）。

## 六、测试设计（约法第 6 条，断言锁语义）

`tests/test_reversal_turnover.py`：
- **T1 因子方向**：构造两票，一票近 5 日大跌、一票大涨 → 反转因子前者 > 后者；一票低换手、一票高换手 → 低换手因子前者 > 后者。
- **T2 标准化**：全同值输入 → zscore 全 0；含极端离群值 → winsor 后不主导排名。
- **T3 过滤语义**：涨跌停票被剔、停牌票被剔、次新票被剔、低流动性票被剔，且各计入"跳过"统计。
- **T4 防未来函数（命门）**：在信号日之后的某天注入异常值，回测结果**不应改变**（若变了说明用了未来数据）。
- **T5 缺数据降级**：turnover 缺失票不抛错、按规则剔除并计数（守诚实性，不静默）。
