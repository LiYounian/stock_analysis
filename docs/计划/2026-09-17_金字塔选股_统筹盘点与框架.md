## 4. 金字塔框架定义（骨架已用户认可 2026-09-17）

**塔尖融合公式**：
```
塔尖买入候选 = 程序广度打底(B1+B2 的 72 候选池)
             + agent 补主线(DeepSeek/千问 自主挖 程序漏掉的强势主线,如光模块联动)
             + 财报排雷(剔除"假利好"/业绩红旗 → 直接进规避)
             + 宏观定 beta(外围偏空→整体降 beta/偏防御;但国内主线科技可逆势→哑铃)
             + 经验纪律闸(H2放量收阳首入场 · gap-fade回踩限价不追高开 · 普跌日不反动量)
```
**输出**：5~6 只 = **2~3 买入**（主看绝对盈利，配退出纪律）+ **2~3 规避**（调模型/防踏空/验策略稳健；来源=板块/市场/国际局势风险 + 财报雷 + 高位）。

## 5. 现状优劣总评 + 缺口

**优**：三层齐全（召回广→合成→重研判）、数据面最全、经验沉淀 34 条、可回测可移交。
**劣 / 缺口**（按优先级）：
1. **α 源缺失（market_ew 未建）= 评测第一优先**——没它只能看绝对收益、看不了超额。
2. **外围国际宏观完全未接**——今天新做的分析还在 repo 里躺着。
3. **三线分裂**：A线 与 B2 是两条平行 LLM 各选各的，没在塔尖收敛。
4. 数据缺 fundflow/tick/chip/margin 4 目录；薄样本（定时牌2天/精选各3票）；阈值硬编码不自适应。
