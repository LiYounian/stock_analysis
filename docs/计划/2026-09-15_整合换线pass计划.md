## 0. 目标与诚实背景（必读）

一整轮六条线的结论收敛成一句话：**现有数据/方法里没有圣杯**——深度选股跑不赢纯动量、量价换手无新增量、金叉形态证伪、动量+回踩组合级降级、逆向行业只截面成立。

**所以本 pass 不是"上线一个赚钱策略"，而是把已坐实的成果落地 + 把流程从"自欺"改成"诚实"**：
1. **流程正确性**（最高价值·低风险）：复盘改**绝对收益记分 + 胜率牌**（终结"α 相对记分掩盖绝对亏损"的错觉）；入场改**限价回踩、不默认开盘**（回测证实开盘无 edge）。
2. **已验证的边际微调**：S05 分档+gap-fade 标记落生产；半导体多因子降权、winner_rate≤80 降权（selection-α 诊断）。
3. **org 级地基入库**：regime 板块环境层（拥挤度截面过滤·已验证）合 main、做成可复用层。
4. **forward 实验起跑**：情绪 shadow-runner 接调度攒样本（≥120 天才谈 validate）。

> ⚠️ **不承诺 alpha**：换线让操作"诚实且执行更优"，不创造 alpha。绝对胜率牌会**如实**显示选股到底赚不赚钱（很可能≈动量、边际）。真增量在数据层（另案）。

## 5. 风险与回滚
- **换线动 live 选股/复盘=高影响**：每个 SKILL 改动**保留旧版备份**（`SKILL.md.bak-0915`）；换线后**首个交易日盯产出**（选股/复盘格式、PICKS 锚点、write_picks 校验、胜率牌落盘），异常即回滚旧版。
- **代码合 main**：全走临时 worktree、合前测试全绿、脱敏；每步独立 commit 便于二分回滚。
- **拥挤度过滤误用风险**：严守"截面辅助过滤、非组合择时"边界（regime §1b），配置默认**只降权不硬否决**。
- **胜率牌 append-only**：绝不回改历史、不挑日。
- **launchd**：agent 只备 plist，`load`/`unload` 全由用户本人（约法）。
- **自动 commit 覆盖**：#10⑤/经验沉淀类改动要辨明是否会被 eod 每日重写；改在正确的层。
