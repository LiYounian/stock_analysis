## 1. 目标

对 32 只自选票:
1. 拉日 K线并落盘缓存;
2. 算全套技术指标(均线 / MACD / KDJ / RSI / 量价);
3. 出两级技术报告:**组合技术概览**(方案2 第一层)+ **单票技术卡**。

做完即拥有:一键从零到"32 只票的技术面全景 + 单票深度技术分析"。

## 2. 拆解(脚本 / 函数 / 输入输出)

### Step 1 · `collectors/market.py` 行情采集
| 函数 | 输入 → 输出 |
|---|---|
| `fetch_kline(codes, start=None, end=None, adjust="qfq")` | 用 akshare `stock_zh_a_hist` 拉日K → 落 `data/raw/kline/{code}.parquet`,返回 `{code: DataFrame}` |
| `load_kline(code)` | 读缓存 parquet → DataFrame[date,open,high,low,close,volume,amount] |
- 全量拉取(默认近 `settings.KLINE_DAYS=250` 交易日);前复权;单次请求间隔 `FETCH_SLEEP_SEC`。
- **代码→带市场前缀**的映射(6/60/68→sh,0/3→sz)封装成内部 helper。
- 拉取失败**抛错**(不静默返回空 df),错误票记录到返回值的失败列表。

### Step 2 · `analysis/technical.py` 技术指标(纯本地,无网络)
| 函数 | 说明 |
|---|---|
| `ma(close, window)` | 简单均线 |
| `macd(close, fast=12, slow=26, signal=9)` | 返回 DIF/DEA/MACD 柱 |
| `kdj(kline, n=9, m1=3, m2=3)` | 返回 K/D/J |
| `rsi(close, window)` | 相对强弱 |
| `compute(kline) -> dict` | 汇总单票技术画像(见下) |

`compute` 输出契约:
```
{
  "last": {收盘, 涨跌幅},
  "ma":   {ma5, ma10, ma20, ma60, 排列: 多头/空头/纠缠},
  "macd": {dif, dea, macd, 状态: 金叉/死叉/-},
  "kdj":  {k, d, j, 状态: 超买(>80)/超卖(<20)/-},
  "rsi":  {rsi6, rsi12, rsi24},
  "vol":  {量比, 状态: 放量/缩量/平量},
  "signal": {评级: 偏多/中性/偏空, 得分: -100~100, 依据: [...]},
}
```
- 指标参数:MA(5/10/20/60)、MACD(12/26/9)、KDJ(9/3/3)、RSI(6/12/24)、量比(当日量 / 过去5日均量)。
- **综合评级**:对上述子信号规则打分求和 → 映射偏多/中性/偏空(规则透明、可测,不用玄学权重)。
- 数据不足(新股/停牌 K线太短)→ 对应指标标 `数据不足`,不报错。

### Step 3 · `report/builder.py` 技术报告(本期只做技术章节)
| 函数 | 输出 |
|---|---|
| `build_portfolio_tech_report(results) -> path` | `docs/报告/组合技术_{date}.md`:32 票技术评级排行 + 板块强弱(按 sector 聚合评级) + 金叉/超卖等异动清单 |
| `build_stock_tech_report(code, result) -> path` | `docs/报告/个股_{code}_{date}.md`:单票技术卡(均线/MACD/KDJ/RSI/量价 + 评级依据) |
- 情绪面章节留占位标题("P2 补"),不空造内容。

### Step 4 · `run.py` 串联(技术面最小闭环)
- `collect` → 拉全池 K线;`analyze` → 全池 technical.compute;`report` → 出组合概览 + 单票(默认对评级最强/最弱各若干只出单票,或全池)。
- 先跑通**一只票**最小闭环,再放开全池。

### Step 5 · 测试 `tests/`
- `test_technical.py`:构造已知序列,验证 MA/RSI/MACD/KDJ 数值(容差)+ 金叉/超买超卖/放缩量判定(**断言锁语义**)。
- `test_market.py`:mock akshare,验证代码前缀映射、拉取失败抛错不返空、落盘/读盘往返一致。
