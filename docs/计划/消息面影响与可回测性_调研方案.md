# 消息面影响与可回测性 · 调研方案 + 执行与分析

> 日期:2026-08-13 · 状态:方案 + 执行(用户"写方案后直接执行,连同效果一起评估")· ⚠️ 非投资建议
> 纪律:先探查用途 → 定口径 → **测前预注册假设** → 执行 → 诚实回填(§5)。方法学同预测两条线/策略回测那轮。

## 0. 缘起与核心命题

**已知**:五个选股策略(0合议/1 S01/2 S02/3箱体/4动量)+ 预测两条线,全部历史回测——**无一有统计显著正 alpha**(见 [策略总览](../策略/策略总览_定义计算与回测.md))。纯量价·日频这个信息集**见顶**。

**命题(用户提出)**:我们的策略全是**数值(价量)**的,天生**看不见消息**。那么——
1. 失败的信号里,有多少是**消息面(新闻/公告)驱动**的?(数值模型的"盲区")
2. 这些造成影响的消息,**能否提前捕获**?
3. 我们现有的**消息分析(净情绪分/LLM)到底准不准**?(从没回测过)

这三问指向同一件事:**消息面是唯一没系统验证过的维度**,而事件驱动(PEAD 等)在文献里是少数有记录 edge 的方向。值得查清。

## 1. 拆成三项可测研究(口径钉死)

### 研究 A · 归因:失败信号 ∩ 重大消息
- **样本**:历史信号日(S01/S02/箱体入选日,或"买卖倾向偏多"日)。"失败"定义:进场后前瞻 N 日(5/10)收益 < 0 或被硬止损。
- **测什么**:失败样本中,信号日**前后 ±M 日**有无实质新闻/公告(`news.fetch_news` / `announcement`)。失败∩有消息的占比 = 消息对"数值信号失灵"的**解释力**。
- **口径**:归因是**回溯解释**(允许看信号后消息),但须把命中的消息分"**信号前已可见**"vs"**信号后才突发**"(喂给研究 B)。

### 研究 B · 可提前捕获:事件类型 + 领先时间
- 把 A 命中的消息分两类:**预定型**(业绩预告 `yjyg` / 快报 `yjkb` / 财报 / 解禁 / 分红——有日历、可提前)vs **突发型**(重组 / 监管 / 突发公告 / 龙虎榜——无预告)。
- **测**:每类"消息时间 vs 股价异动时间"的领先/滞后分布。**可提前捕获比例** = 预定型 + 突发型里消息明显早于异动的部分。
- **产出**:哪类事件值得接入"前瞻捕获"(vs 只能事后解释)。

### 研究 C · 消息信号回测:净情绪分 / LLM 判断准不准
- **信号** = `record.sentiment.净情绪分`(点位存储,-1~1)。**测**:横截面 IC(净情绪分 vs 前瞻 5/10 日收益)+ ICIR/t + 分层十档 + 上涨命中校准。方法同 `backtest_rank`(但打分改用**存储的点位情绪**,不是从 K 线算)。
- **事件型**:业绩预告超预期(PEAD)→ 前瞻收益(复用 F7 事件→前瞻框架)。
- 这是"从没做过的消息面回测",直接回答第三问。

## 2. ⚠️ 数据约束(诚实前置,决定能做到什么程度)

- `record.sentiment.净情绪分` **只存了 08-06~08-13 共 7 个交易日,且仅子集**(每日选出∪自选 ~124 只),**不是全A、样本极短** → **研究 C 现在跑,统计力几乎为零**,只能出方向性 + 标"待累积"。
- 新闻 API(东财/新浪/财联社)**历史窗口很短**(天~周),回补历史消息补不了多久 → 研究 A/B 的回溯也受限于近窗口。

**因此两条腿并行**:
- **治本 · 前向累积**:每日闭环已存 sentiment;加一个"**picks + 预测 + 净情绪分 配前瞻收益**"的滚存评估,几周后自然攒出可回测样本(研究 C + "昨日选股 vs 今日实际"记分卡)。
- **治标 · 小规模回溯**:用手头 7 天子集 + 能补的短历史,先做研究 A(归因)+ B(事件分类),出**方向性结论**,标注"样本小·待累积复验"。

## 3. ⭐ 预注册假设(执行前钉死,防事后找理由)

| 研究 | 假设 | 成功判据 | 若不成立·最可能原因 |
|---|---|---|---|
| A 归因 | 相当比例(>1/3)的失败信号伴随重大消息(尤其异动/涨停类) | 失败∩有消息 显著高于 基准日有消息率 | 消息采不全(API 短窗)/ 失败多是纯技术性回撤 |
| B 捕获 | 预定型可提前(占比有限);**突发型多数不可**(新闻滞后于或即为异动那根) | 预定型领先时间>0 占多;突发型≈0/负 | 新闻时间戳不准 / 分类粗 |
| C 情绪信号 | 无条件**净情绪分弱预测力**(\|IC\|<0.05,可能不显著);**PEAD 事件更可能有真且可提前的 edge** | 情绪 IC 显著>0 或 PEAD 前瞻收益显著>0 | 情绪是滞后/同步反应(异动后才有新闻情绪),非领先 |
| 总 | **消息面"解释力" > "预测力"**;可交易 edge 更可能在**预定型事件(业绩预告)**而非泛情绪 | — | — |

## 4. 执行计划

1. `tools/backtest/backtest_sentiment.py`:读**存储的点位情绪面板**(逐日 records.sentiment.净情绪分)→ IC/分层/校准(研究 C)。
2. 前向累积:每日闭环加"前瞻收益回填"(picks/预测/情绪 配 t+N 实际)——滚存,治本。
3. 归因脚本(研究 A):信号失败样本 ∩ 新闻/公告命中率;命中消息按预定/突发分类(研究 B)。
4. 跑 + 分析 + 回填 §5。数据太薄的部分**如实标"方向性·待累积"**,绝不编。

## 5. 执行结果与分析(2026-08-13 回填)

> harness(均新建、未改现有代码):`tools/backtest/backtest_sentiment.py`(C)、`attribution_news.py`(A+B)、`forward_scorecard.py`(治本)。无未来函数已核实(spot-check:000539 信号日08-06,r_5=+7.09% 与手算一致,t+5=08-13 严格晚于信号日)。

### 5.0 数据现实(决定可信度)
点位情绪存了 08-06~08-13 共 7 天,但**能配上前瞻收益的有效观测**急剧衰减:r_1=308(5天)、r_2=139、r_3=31、**r_5=9(仅1天)、r_10=0**。→ **只有 r_1 勉强有信号,且=5 个交易日,本质是噪声。** 所有数字都是"方向性·待累积"。

### 5.1 研究 C · 情绪信号(净情绪分能否预测收益)—— 可信度:极低
- r_1:IC 均值 **−0.118**,**t=−0.64 不显著**;校准**非单调甚至反向**(正情绪票次日涨 44.7%,负情绪票涨 53.0%)——"情绪越正≠越涨"。
- r_5/r_10 有效日 <5,无法算 IC;PEAD 事件线**样本为零,未能测**。
- **对预注册假设 C**:方向一致(净情绪分**未见显著正预测力**),但样本太薄不能下死结论。倾向判断:**净情绪分更像对异动的滞后/同步反应,不是领先信号**——这与预测两条线里"上涨概率是噪声"同源。

### 5.2 研究 A · 失败∩消息 —— 有一个**结构性硬发现(即使数据薄也成立)**
- **管线给几乎每只票都抓了舆情 → events 饱和到 84.2%**。于是"有没有消息"**几乎零区分度**:失败样本有消息 87.0% vs 全样本基准 85.4%(仅 +1.6pp),成功样本 83.7%。
- **→ 预注册假设 A 在"任意消息"口径下不成立**——不是因为消息不重要,是因为**"有无消息"这个粒度被舆情采集稀释成了噪声**。**"给数值策略加上新闻就能变好"这个朴素想法,在这个粒度上是错的。**

### 5.3 研究 B · 事件类型 —— 可信度:低(关键词粗分类)
- 失败命中的消息:**泛舆情噪声 66.1% / 突发型 22.4% / 预定型 11.5%**。突发型(重组/监管/龙虎榜/传闻)≈ 预定型(业绩预告/快报/解禁/分红)的 **2 倍**。
- **领先时间无法可靠测**(events 时间戳是"信号日当日采集"快照,报出的"早3.3天"其实是存储回看深度,非真实预测领先)——已诚实标注"待累积"。
- **对预注册假设 B**:方向一致——**能提前捕获的预定型只占 ~12%**,大头是"事后才知"的突发型。

### 5.4 治本 · forward_scorecard —— 已建成、幂等、能滚存
- 525 行,方向命中率 r_1 **43.6%(298行)**、r_5 44.4%(9行)、r_10 全 pending。每天重跑自动把"新到期"的前瞻收益补进,**这是研究 C 未来攒样本的长期数据源**。部署到每日闭环时传持久 `--out data/analysis/backtest/`。

### 5.5 综合分析:回答用户五问(诚实版)
1. **多少策略好用**:0 个统计显著正 edge(纯量价见顶,已知)。
2. **选出的票符合前一天预测吗**:forward_scorecard 方向命中 r_1 **43.6% < 50%**——**次日方向兑现度不如掷硬币**(薄样本,与"无 edge"一致)。
3. **失败里多少是消息驱动**:**问不出来**——因为舆情采集把"有消息率"顶到 85%,"有无消息"沦为噪声。**真正该问的是事件的"类型/质量",不是"有无"**。
4. **消息能否提前捕获**:**大头不能**。市场真正在意的多是**突发型(占失败命中 22%,是预定型 2 倍),而突发型基本是"异动同时或之后才知"**;能提前的**预定型只 ~12%**(业绩预告/PEAD 这类有日历的)。
5. **我们的消息分析准不准**:**没有证据表明它有预测力**(净情绪分 IC 不显著、校准反向)——它更像**对已发生异动的滞后描述**,而非领先信号。但样本薄,定论待累积。

### 5.6 结论 + 下一步(数据指向)
**核心洞察**:"给数值策略补消息面"没有想象中直接——① 泛舆情/"有无消息"是噪声(85%饱和);② 真正驱动的突发型多数**不可提前**;③ 我们的净情绪分暂无领先预测力。**消息面的"解释力" > "预测力",与预注册总假设一致。**

**唯一收窄出的、值得追的正向方向**:**预定型事件(业绩预告/快报 PEAD)**——有日历、可提前、文献有 edge,且不被舆情噪声稀释。建议下一轮**单独预注册测 PEAD**(超预期→前瞻收益),而非泛情绪。
**治本**:forward_scorecard 接入每日闭环,攒 4~6 周再复验研究 C(那时才有统计力下"能不能赚"的结论)。
