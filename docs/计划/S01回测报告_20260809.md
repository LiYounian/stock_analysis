- 收益**极右偏**:>75% 的交易一进场就打到 −3% 硬止损;靠极少数大赢家(59 笔 >+20%,最大 +95%)撑起 6.04 盈亏比。
- 分板块:沪主板/科创微正打平(+0.19%/+0.06%),创业板/深主板偏负(−0.84%/−0.79%),**无一板块有说服力的正 edge**。

## 统计显著性 + 置信度
- 平均收益 **t=−1.42, p=0.15 → 不显著**,无法拒绝"期望=0";整体≈打平偏微负,Alpha 基本贴地。
- 信号仅落在 **2026-04~08 的约 80 个交易日**,进场高度聚簇、不独立 → **有效样本远小于 1405,置信度偏低**。
- 汇总里的"最大回撤 99.99%"是**串行满仓复利口径的产物**,非实盘分仓组合回撤,**勿据此下结论**(报告已标注)。

## 结论(诚实)
**当前数据不支持"S01 准 / 有正超额";也不足以判它一定亏。不建议现在单凭 S01 下单。**
最大问题:**86.5% 一进场就被 −3% 硬止损扫掉**——"深跌收阳"进场常是接下跌中继,次日续跌打止损。

## 下一步(改进方向,验证驱动)
1. **扩历史样本**:现只~1.5 年、信号聚簇;攒更长历史再复验,提升置信度。
2. **参数敏感性**:对硬止损系数(0.97)、深跌阈值(−0.04)做扫描,压低"即死率"(86.5% 太高)。
3. **回撤口径**:改成分仓组合口径,别用串行满仓复利。
4. **入场加确认**:深跌收阳后或需再等一根确认(次日不破低),减少接飞刀。
5. 这些改动都用同一回测器 A/B 对照,以数据反调,别拍脑袋。
