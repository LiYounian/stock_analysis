# 行业冷热钟摆表 · P-B LLM 情绪判官 · 现状(诚实)

> 日期：2026-09-15 ｜ ⚠️ 测试环境研究模拟，非投资建议。
> 范围：Marks 表15-1 **情绪面4维**(投资者情绪/经济展望/流行风格/景气)的 LLM 判官。
> 代码 `tools/analysis/industry_temp/sentiment_judge.py`;接层 `thermometer.py` 情绪 slot。

## 1. 结论先行
- **历史回测不可行**(feasibility 已核实):全A PIT 行业文本只从 **2026-08-06** 起(~6周/~30交易日),
  远低于 120 天 walk-forward 底线 → **无法历史 validate**。本档只能是 **going-forward live 信号 +
  forward-shadow 观察**,攒够 **≥120 独立样本**才谈 validate。
- **pipeline 已跑通**(真 LLM 冒烟):判官端到端可用,输出**只 A/B、不打分**,依据有据(引原文)。
- **两个诚实限制**(非"没用",是"待改进"):见 §3。

## 2. 做了什么
- **判官** `judge(industry, date)`:采集截至 date 的 policy 行业文本(tag→申万一级)→ 固定提示词 →
  LLM(deepseek,走 zsh -ic 网关)→ 4维各 **A/B/中性**(中性=弃权);综合=多数 A/B、平局/全弃权=None。
- **防偷看6条全落地**:①只喂 ≤date 文本(落盘日≤T + 条目 date≤T);②固定提示词(`PROMPT_VERSION`);
  ③`run_shadow` 落输入文本+判定供**人工核验**;④**只输出 A/B、不打分**;⑤真 LLM 走 zsh -ic 网关;
  ⑥分支不合 main。**无文本→弃权,绝不臆造**(测试锁:无文本时 0 次 LLM 调用)。
- **forward-shadow** `run_shadow(date)`:全行业判定**纯记录**到 `<out>/<date>.json`,标 `非validated`/
  `forward_shadow`,**不 gate 任何决策**;`read_sentiment_shadow` 供板块层 情绪 slot 选读(缺→None)。
- **7 语义测试**(mock LLM,不真调网关)。

## 3. 诚实限制(人工核验发现)
1. **利好偏斜 → 综合偏 A**:policy 文本源天然利好重(冒烟:电子 229 条政策 → 判官如实读出"乐观/正面/
   激进/生机"=全A)。判官忠实反映文本,但文本本身偏多 → 综合系统性偏"过热(A)"。**需去均值/regime
   相对归一**才能当真实"冷热"信号,现阶段原始综合不可直接当过冷/过热档。
2. **覆盖偏科技**:policy 的 `industries` tag 多是主题/概念名(半导体/AI算力→电子),映射到申万一级时
   **偏科技**;冒烟里汽车/银行 tag 无映射文本 → 弃权。→ 多数传统行业当前无情绪信号(弃权),
   覆盖稀疏。**需补个股 news 按 code→行业 rollup** 才能覆盖全行业。

## 4. 下一步(候选,待用户/统筹定;都不改变"非validated"性质)
- **(增强A)补 news rollup**:个股 news(code→申万一级)并入文本源 → 覆盖全行业、稀释单一 policy 偏斜。
- **(增强B)去偏**:综合做 regime 相对/去均值(相对全市场情绪的偏离),缓解利好skew。
- **(生产化)接调度 forward-shadow**:每日盘后 run_shadow 落盘(统筹换线),开始积累 ≥120 样本。
- 以上都**先不 gate 任何选股/组合决策**;情绪维只作观察,直到样本够 + 去偏后才评估其增量。

## 4b. 增强已落地(2026-09-15,用户选 park+调度+rollup+去偏)
- **增强A·news rollup(补覆盖)**:成分个股 news(code→申万一级,截 max_codes/max_items 控 IO)并入文本源。
  实测:汽车/银行/医药生物/食品饮料 从"弃权"→均可判(各 25 条文本)。覆盖偏科技已修。
- **增强B·跨行业去偏(缓解利好skew)**:judge 出**净A度**=(#A−#B)/n;`run_shadow` 以跨行业净A度**中位数**
  为基线 → **情绪_相对**(相对全市场偏离)。实测:基线净A度=1.0(市场普多)下,判出**汽车/医药生物相对冷=B**
  (LLM 读出"蔚来保毛利/车贷不良甩卖""医美盈利下滑/违规清退"的审慎)——去偏后信号能分辨,不再一味偏A。
- 板块层 情绪 slot 现读**去偏后的情绪_相对**(缺回退综合)。仍标**非validated**、仍不 gate 决策。
- **待生产化**:`run_shadow` CLI 就绪(`python -m tools.analysis.industry_temp.sentiment_judge --date --out-dir`);
  每日盘后调度落盘=**统筹换线活**,装载后开始积累 ≥120 独立样本。

## 5. 与板块层的关系
- 情绪只是板块层第③信号,**当前 slot 默认 None**;给 `sentiment_shadow_dir` 且有落盘才填(标非validated)。
- 板块层已可用的是 **①拥挤度(截面前瞻IC有预测力,组合级只作过滤)** 与 **②动量冷热(描述性,双口径)**;
  情绪(③)是 additive、短期不可validate、**不在关键路径**。
