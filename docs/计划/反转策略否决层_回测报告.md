# 反转否决层 · A/B 回测报告(诚实结论)

> 脚本:`tools/backtest/backtest_reversal_veto.py`;产物:`data/analysis/backtest/reversal_veto_ab_finuniverse.json`。
> A=纯量价反转 TopK;B=A+否决层。⚠️ 非投资建议;历史回测≠未来保证。防未来函数=硬红线。

## 1. 数据可用性(决定回测边界,先说清)

- **全A kline 历史齐全**(5552 票)→ 前瞻收益/踩雷标签纯价可长历史算。
- **财报/龙虎榜/公告 raw 快照仅约 2026-08-06 起**(~24 采集日）。其中财报 raw 单快照内含 ~12 个报告期
  (带 disclosure_date)→ **基本面轴可按 as_of 回溯 ~3 年**,但**仅约 401 只有财报快照**(有偏子池)。
- **ST**:用当前 `code_name.json` 名称近似(状态粘性,无 as-of 精确;诚实标注)。
- **事件博弈 / 龙虎榜 / 重组未完成轴**:数据仅近月快照,**不足长历史严格回测 → 本回测默认关**。
  → 本回测只覆盖**基本面空心 + ST 治理**两轴;event 轴(正是抓住 002445 停复牌重组的那轴)**未纳入 A/B 数字**,
    故回测**低估**了否决层对"壳股停复牌重组博弈"这一核心失败模式的价值。

## 2. A/B 结果(fin-universe 401 只 · 2950 个高分票观测 · 1768 交易日 · 踩雷=T+10 内 maxDD≤-15%)

| 指标 | A(纯量价) | B(加否决层·基本面+ST) | 被否决高分票 |
|---|---|---|---|
| 高分票数 n | 2950 | 2470 | 480 |
| **踩雷率** | **6.51%** | **5.55%**(−0.96pp,相对 −15%) | **11.46%** |
| 胜率 5日 | 46.07% | 46.15% | 45.62% |
| 胜率 10日 | 47.29% | 47.09% | 48.33% |
| 均收益 5日 | 0.095% | 0.105% | 0.045% |
| 均收益 10日 | 0.43% | **0.328%** | 0.957% |

全样本踩雷基率 8.09%(反转高分票 6.51% < 基率,低换手腿本身已避开部分踩雷)。

## 3. 诚实结论(混合,非无条件达标)

1. **踩雷率:降**。A 6.51% → B 5.55%(相对 −15%)。被否决票踩雷率 11.46% ≈ 保留票(5.55%)的 **2 倍**——
   否决层**确有筛出高崩盘风险票的判别力**(否决的不是随机票)。
2. **胜率:不劣化**。5/10 日基本持平(46.07→46.15 / 47.29→47.09)。
3. **均收益:轻微劣化(10日)**。0.43% → 0.328%。根因:被否决票是**高方差**票——崩盘更频(踩雷 11.46%)
   但**均值反弹也更猛**(被否决票 10日均收益 0.957% > 保留票)。否决层用**削峰去尾**换**左尾风险下降**:
   剔掉的是"高波动壳股/基本面空心票",它们均值为正但肥左尾。对"反转买入候选"(要躲 002445 这类爆雷)
   这笔权衡可接受,但**不是无条件"收益不劣化"**,如实标注。
4. **严格「误杀率」88.5%**(被否决里非踩雷占比):**这是稀有事件指标的天然假象**——踩雷本就只 ~5-11%,
   任何风控过滤"命中非崩盘票"的比例都会很高。**更该看收益对比**:被否决票 5日均收益(0.045%)低于保留票
   (0.105%),说明否决剔的方向是差票,不是系统性错杀优质超跌票。

## 4. 是否达标 / 建议

- 严格口径(踩雷率**显著**降 + 收益**不劣化**):**部分达标**——踩雷率降、胜率不劣化,但 10 日均收益轻微降。
- **但回测低估**:最能证明否决层价值的**事件博弈轴(停复牌重组/龙虎榜/异常波动)因数据仅近月未纳入**;
  样本外案例 002445 正是被 event 轴(重组公告)+ 基本面轴(扣非-87%)双否——这类"技术超跌壳股博弈"是
  否决层的靶心,却不在上面数字里。
- **建议**:①默认**降级(软)**而非硬否决/剔除(保留展示+⚠,把爆雷候选挤出买入区即可,误伤最小);
  ②生产随每日闭环滚存**前向记分卡**(event 轴数据逐日累积),攒够样本后再对 event 轴做严格 A/B;
  ③kill-switch 默认可回退。
- **样本外**:002445 中南文化 as_of=2026-09-01 触发 3 轴(扣非-87% + 重组公告 + 重组未完成)→ 降级沉底;
  002155 湖南黄金触发 0 轴 → 不误杀。符合预期。
