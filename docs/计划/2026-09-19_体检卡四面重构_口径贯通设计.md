# 体检卡四面重构 · 口径贯通设计

> 日期：2026-09-19 ｜ 统筹：金字塔统筹窗口 ｜ 状态：**草案（待流程图窗口盘点补全 + 用户审）**
> 关联：流程图窗口（内容/产品侧盘点）、金字塔 D2 决策链
> 研究模拟，非投资建议。

## 0. 一句话目标
把金字塔"逐票浓缩块/体检卡"（喂第五层选股 LLM 的个股分析）**重构为四面结构**，每个字段
**口径从各浓缩模块真实传上来、不许编**，让个股分析真正覆盖 基本面 / 技术面 / 资金面 /
消息情绪面，并修掉"缺数据=排雷满分"的虚高。

## 1. 硬原则（【用户明说】）
1. **现状痛点**：当前体检卡"太散碎"。
2. **四面组织**：基本面 / 技术面 / 资金面 / 消息情绪面。结构=先"什么面"再该面细节。
3. **每条字段 = 数值 +【真实口径/档位定义】+「这意味着什么」解读**。解读要"数值说明了什么 +
   这意味着什么"，尤其"这意味着什么"要对**最终选股**有帮助。
4. **口径一律贯通、绝不新编**：分数/档位（层级、好中差、有无）的定义都在各浓缩模块里已定好，
   **一路原样从模块传上来**——拼装层零加工。一路传上来 = 详尽个股分析。
5. **财报保留字段级明细**：别过度凝练成几个字；"财报分析产出是字段的，把字段放上来"。
6. **卡片带股票名称 + code + as_of**（现状只有 code 无名）。
7. **10 块全展开**（用户要看全部）。
8. **决策包"市场定调"输入侧要更描述性**：现状喂 LLM 的是干字段（如"净广度-0.04"），用户要
   **输入侧就更可读**（描述性文字，而非等 LLM 去解释干字段）。
9. **展示 HTML = 实际传输内容**：流程图窗口展示的卡片结构 = 真正投喂 LLM 的内容，二者同源。

## 1b. 用户四面清单全文（【用户明说】·并集目标，除已识别 5 缺口外这些都要覆盖）
> 流程图窗口两路盘点回来后给"每项①已进卡/②有数据未读/③不存在 + 证据 + 真实口径"三态映射，
> 逐项落到 §2 矩阵。以下为用户原始清单。

- **基本面**：财务指标(营收/净利/毛利率/净利率/ROE/资产负债率/经营现金流)；盈利能力质量(盈利增长
  趋势/扣非是否真实/是否主业赚钱)；成长性(营收增速/利润增速/市占变化/扩张空间)；估值(PE/PB/PEG/PS
  + 与行业均值&自身历史区间对比)；公司治理(管理层/股权结构/大股东减持/质押)；行业地位(市占率/护城河)；
  分红回报(股息率/分红持续性/回购)
- **技术面**：趋势(MA5/10/20/60/趋势线/通道)；量价(量价配合/放缩量/量比)；指标(MACD/KDJ/RSI/BOLL/CCI)；
  形态(头肩/双顶底/三角/旗形/W底M顶)；支撑压力(关键价位/筹码密集区/前高前低/黄金分割)；K线组合
- **资金面**：主力大单超大单净流入/机构席位；北向(**已改披露持股量、非实时净买**)；两融余额；
  股东户数(减少=筹码集中)；龙虎榜(游资/机构席位)；换手率(过高炒作/过低关注不足)
- **消息情绪面**：政策(产业利好利空/监管/规划)；行业动态(上下游景气/拐点/技术变革)；公司公告(业绩
  预告快报/重大合同/并购重组/股权激励/增减持)；事件驱动(突发/地缘/国际)；市场情绪(信心/风险偏好/
  板块轮动)；舆情关注度(研报覆盖数/搜索热度/社媒讨论度)

## 2c. 三态映射（流程图窗口盘点·权威版 2026-09-19）
> 结论：**绝大多数是「有数据未读」②，接进来即可、不用重采。** 少数需补落盘或不存在。

### ② 有数据未读·接进来即可（附 json 路径）
- **基本面**：营收/净利=`fundamental.营收/净利`；毛利率/净利率/ROE/负债率=`fundamental.{毛利率,净利率,ROE,负债率}`(原始值)+`financial.derived`；现金流=`financial.现金流.{CFO,自由现金流,造血模式}`；营收/净利增速=`fundamental.{营收增速,净利增速}`；PE=`valuation.pe_ttm`；PB=`valuation.pb`；每股股利=`fundamental.每股股利`；管理层语气=`financial.qualitative`；质押/回购/业绩预告快报/重大合同/激励=`events`(按 type)
- **技术面**：MA10/60/排列=`snapshot.ma`；MACD=`snapshot.macd`；KDJ=`snapshot.kdj`；RSI=`snapshot.rsi`；结构支撑压力=`prediction`；筹码=`chip`
- **资金面**：主力资金=`fundflow.{今日主力净流入,净占比,近5日,连续天数}`+`tick.{主买占比,大单笔数}`；龙虎榜/机构席位=`lhb_veto`/`smart_money`；股东户数=`holder.{最新股东户数,户数环比,连续减少期数}`；换手率=主档 turnover 列
- **消息面**：个股情绪=`sentiment`(三层)；一致预期/研报覆盖数=`consensus.{覆盖机构数,预期EPS,预期增速}`；社媒热度=`ugc`

### 已有工具 → 归面（用户要求多出来的也归面）·归面决策 2026-09-19（以用户 §1b 清单为准）

## 2d. 关键口径（贯通上传源·原样，完整全表见流程图窗口底稿 §3）
- 量比档：缩量≤0.7 / 平量(0.7,1.2] / 放量(1.2,2.5] / 爆量>2.5
- pos60：低≤0.3 / 中(0.3,0.7] / 高>0.7
- gate：T1 量比≥1.5 / T2≥1.2 / T3≥1.0；极高位 pos60≥0.95
- 净催化：强负≤−50 / 负 / 中性0 / 正 / 强正>49.99
- quality：差≤35 / 弱 / 中 / 良 / 优>80
- 解禁：占比线 3% / 10%；临近 30 日
- 减持：清仓 或 控股+大额 = 高
- 骨架权重：0.30 / 0.25 / 0.20 / 0.15 / 0.10

## 4. 代码集成设计（统筹侧，待细化）
### 4.1 拼装层
- 体检卡在 `tools/pyramid/d2_package.py` 拼装（决策包 top~15 每票全工具浓缩块）。
- **重构为四面分组**：每个工具的 ToolResult 增加"归属面"标签；d2_package 按面分组渲染。
- **口径贯通机制**：每工具输出携带 (数值, 档位定义, 解读) 三元组，拼装层零加工、只排版。
### 4.2 新增/扩展工具（A 期·卡片补全，各解耦可并行）
1. **估值+成长工具**（新）：读 valuation + fundamental，输出 PE/PB/PEG 提示 + 增速明细 + 档位 + 解读。
2. **资金面工具**（新）：读 fundflow + holder + financing + lhb + chip，输出主力/北向(若有)/两融/户数/龙虎榜 + 档位 + 解读。
3. **消息情绪面工具**（新）：读 sentiment + events，输出净情绪/利好利空/覆盖率/三层 + 档位 + 解读。
4. **竞品/龙头对比**（新，最重）：consensus 缺 → 需定方案（新采一致预期 or 用板块 roster 做龙头相对位）。
5. 扩 price_volume / financial_redflag：把已有但未上全的指标明细补进卡（技术指标/财报明细）。
### 4.3 #6 缺数据→排雷满分 修复（已定 2026-09-19 · #6 chip 实测）
- `tools/pyramid/d2_compose.py::子分_排雷`：三张扣表 `_财报档_扣/_解禁档_扣/_减持档_扣` 里 "missing"→0，
  与"无嫌疑(查净)"→0 同分 → 缺数据票排雷满分虚高。生产实测：2026-09-17 全池 509/553 排雷=100，
  全部≥1 维 missing，0 票三维全查净。
- **修法（已定）**：missing 惩罚=各维"半个低档"，per-dimension，严格落在 无嫌疑(0) < missing < 低：
  **财报 8（低15）/ 解禁 5（低10）/ 减持 6（低12）**。s 起点(假利好)、经验硬命中、veto 全不动。
  None-guard 保持：缺参(fin=None) 不扣，只有工具显式档="missing" 才触发（缺参≠缺数据）。
- **效果**：all-missing+假利好无嫌疑 100→81(-19，总分-2.85)；查净票相对上移(000725 rank 142→61)；
  **top30 与 D2 fixture 零变化 → 无需 re-bless**（语义/前瞻正确性修，非今日重排）。
- **前瞻待办（backlog）**：8/5/6 量级待 forward 数据够了用 rank IC 复验重调（当前 forward n=0 算不了）。
