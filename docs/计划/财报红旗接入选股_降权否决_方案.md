# 财报高危红旗接入选股逻辑（降权 / 否决）方案

分支：`feat/redflag-veto`　状态：实现中　非投资建议

## 一、诊断（问题在哪、数据在哪产生）

- **合议真源**：`tools/analysis/council.py::convene` 逐票加权求和产出 `综合分`。默认专家组已含
  **财报专家**（`experts.expert_财报`，权重 1.0）：按财报评级投方向，并对**审计双闸门**
  失败做「一票否决→强制看空 -1.0」。但**没有基于「高危红旗严重度」的显式风险覆盖层**。
- **两条 council 分来源**：
  1. 离线 `pipeline/screen_council.py` 产出 view「策略0合议」——用**最小记录**（只有技术信号，
     无 financial 块）→ 财报专家恒弃权。故全A 策略0 的综合分**不含财报**。
  2. `run.py` 全量记录（约 71~81 只带财报，= 自选池 ∪ 各策略前5）→ `record.council.default.综合分`
     **含**财报专家。web `selection_page` 的「自选股」区块用它排序。
- **最终排序/入选在哪**：面向用户的选股页排序在 `web/data_access.py::selection_page` 组装：
  - 「自选股」`pool_rows` 按 `council_score` 降序；
  - 「综合选股」`combined` = 各策略入选**并集**，仅按并集插入顺序（无打分）；
  - 「策略0」rows 按 view 内 `综合分` 顺序。
- **实测暴雷票入选证据**（本机 data/analysis）：
  - 2026-08-28：**002129（评级=风险，红旗=扣非为负）在自选股排第 3**，council_score 为正 0.0535，
    排在多只正常票前面。
  - 高危红旗票（严重度=高：扣非为负 / 非标审计意见 / 审计机构未备案）约 19~24 只/日；
    其中约 **17 只落进 combined 综合选股并集**。
- **财报高危口径**（复用 `financial_risk`，与 finval `has_high_severity` 一致）：
  `flags_detail` 严重度=高 ∪ 轻量 flags 里 config 严重度=高（审计闸门补挂）。

## 二、方案比较与推荐

| 维度 | 降权（候选分扣分，dose 单调） | 硬否决（踢出/绝对沉底） |
|---|---|---|
| 力度 | 软，保留展示 + ⚠，仍可被强势基本面/技术盖过 | 决绝，彻底避开暴雷 |
| 误伤 | 低：扣非为负常见于周期底/一次性，良/中票只降不删 | 高：一条常见红旗即整只剔除，误杀成长股 |
| 可解释/可调 | 高：罚分×高危红旗数、封顶，透明可追溯 | 低：非黑即白 |
| 前后端一致 | 不改 council 综合分本身（另存排序分），前端重合成不漂移 | 同左 |

**推荐：默认「降权」（dose 单调罚分），保留「否决」为可配模式。**

### 关键实现取舍：为什么用「扣分」而非「乘系数」

council 综合分 ∈ [-1,1] **有正有负**。若按字面「乘 <1 系数」，负分风险票会被
**抬高**（-0.3×0.5 = -0.15，反而上升），方向错。改为从**排序分**里减去正罚分
`rank = 综合分 − 罚分`，对任意符号都单调下沉，语义正确。综合分本身不改（前端重合成不漂移）。

### 接入点（只改 council/web，config additive）

1. `THRESHOLDS['财报']['红旗接入']`（additive）：`{启用, 模式, 每面罚分, 罚分上限, 否决沉底保留展示}`。
2. `council.py`：纯函数 `redflag_penalty(高危数)`、`redflag_adjust(base, 高危数)` → 排序分/否决标记。
   纯变换，不 import web/store，可离线/web 共用。
3. `web/data_access.py`：
   - 有分区块（自选股 / 策略0）：按「否决优先沉底 → 排序分」重排；
   - 无分区块（combined / 各策略入选清单）：高危票**稳定沉底**（dose 大者更靠后），保留展示 + ⚠。

## 三、预期效果

- 002129 类「风险+高危红旗」票从自选股前排下沉到高危票段（正常票上浮）。
- combined 并集里 17 只高危票整体沉到列表尾部，前排是无红旗票。
- 降权模式**不剔除**任何票（保留展示 + 风险标注），只改**顺序**；否决模式才剔除/绝对沉底。
- 正常票（无高危红旗）排序**完全不变**（disabled 时全链路 no-op，additive 保证不回归）。
