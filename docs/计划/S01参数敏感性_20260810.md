# S01「趋势深跌反包」参数敏感性 + 入场确认 · 结论表 · 2026-08-10

> 承接 `docs/计划/S01回测报告_20260809.md`(基线:胜12.6%、均-0.34%、即死86.5%、p=0.15 不显著)。
> 本轮:参数网格 + 入场确认,看能否压低即死率并得到正期望。**结论:救不活。** 数字全真。⚠️ 非投资建议。

## 方法
- 全A 前复权 raw(分区 2026-08-08,有效票 5124,基准沪深300)。
- 新增 `tools/backtest/scan_s01.py`:预加载全A kdf,每组参数**显式转发 cfg 到入场判定**(原 `find_signals` 不转发,是关键坑),复用 `simulate_position`(离场状态机原样)+ `summarize_trades`。
- 入场确认新增 `screen_s01.confirm_entry(kdf,t,mode)`(默认关闭、向后兼容);`t1_nobreak`=T+1 不跌破信号日最低价才在 T+1 建仓。
- 即死率=硬止损离场数/已离场数;p=正态近似双尾(仅看显著性量级)。

## 推荐(待主窗/用户拍板,本轮不落 strategy.json)
1. **不采用 S01 单独下单。** 全网格平均收益无一为正;显著的都是显著为负;最不烂的 深跌=-0.03 与 0 无异、计入成本净负。
2. **不改 THRESHOLDS 默认。** 若要"最不烂"参考只有 深跌=-0.03(样本更多、Alpha +0.1%),但非正 edge。
3. 根因是入场前提"深跌收阳=抄底"在全A不成立(要求越深越差),需重构入场逻辑再验,而非继续调参。

## 置信度
- "救不活"方向性:中高(深跌恶化、确认无效均跨网格单调一致)。
- 绝对数值:低(信号聚簇于 ~80 交易日,有效独立样本远小于交易数;p 为正态近似)。攒更长历史可复验,不改当前结论。
