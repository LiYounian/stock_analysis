## 0. 理解:这策略是什么 / 做什么 / 目的
**Mark Minervini 的 SEPA(第二阶段趋势)+ VCP(波动收缩形态)监控系统**。精髓:**不自动交易,只做信号+标记,人工最后拍板**。五模块:
- 模块一 **SEPA 选股**(盘后):趋势模板硬过滤(MA50/150/200 多头+向上、价在均线上、距52周高≥65%/距52周低≥25%)+ VCP 前置(近5日振幅<近15日 且 <4.5%)+ 量能(非死水)+ 基本面门槛(净利/营收同比≥0)→ 观察池。
- 模块二 **板块共振标星**:同行业入池≥2 → 打 ⭐hot_sector。
- 模块三 **VCP 突破预警**(盘中实时):突破 N 日箱顶 + 放量 + 不远离 MA50 + 非消息秒板 → 弹窗/推送。
- 模块四 **趋势保护线 TSL**:max(近10日低, MA50),只上移(棘轮)——展示/复盘用。
- 模块五 **人工干预**:加星/移出池/屏蔽行业/参数面板。
**目的**:在**强势趋势股**的**波动收缩后放量突破点**给人工介入信号 + 板块主题加权,人负责看基本面+下单。**与我们项目"策略辅助·非投资建议"定位完全一致。**

- **TSL 保护线**:max(近10日低, MA50) 棘轮上移,简单,作展示字段(接入 predict/serialize)。
### ⚠️ 与我们项目的出入 / 需提供者确认
1. **⭐ 我们已实测过"趋势模板过滤",A股深历史 8.4 年下 Alpha 不显著(p=0.87;加样本后更弱)**——这是最关键的数据反馈:**Minervini 趋势模板在 A 股不一定有正 Alpha**。是否仍坚持?还是把 SEPA 定位为"**选强势股给人工看的过滤器**"(不追求策略自身 Alpha,只做辅助标记)?(我倾向后者:与"信号+人工拍板"精髓一致。)
2. **MA 口径**:SEPA 用 MA50/150/200;我们 S01 用 MA5-200 全序。用哪套?

2. **人工干预**:池增删我们有;**屏蔽行业 / 参数面板** 是新 UI,可做但需排期。
3. **验收标准**(2023-2024 回测 中际旭创/剑桥科技/万丰奥威/正丹股份 启动前3-5天入池):可回测,需拉那几只历史数据核对。

## 3. 方案(步骤3 · 可实现的「策略5·SEPA选股」)
### 实现(盘后 screener,落 `tools/pipeline/screen_sepa.py`)
- **趋势模板硬过滤**(8条,SEPA 原版):非ST/上市>240、价>MA200、MA150>MA200、MA200 20日前向上(用相对变化>0.5%口径,踩坑④)、MA50>MA150>MA200、价>MA50、价/250日高≥0.65、价/250日低≥1.25。复用 `technical` 的 MA + 无未来函数逐日切片。
- **VCP 前置**:新增振幅收缩算子(近5日均振幅<近15日 且 <4.5%)。
- **量能**:当日量≥20日均量×0.9。
- **基本面门槛**(可配置):近2季 净利/营收同比≥0(至少1个;财报数值层,披露日锚定)。
- **板块共振**:池按 `industry_map` 聚合,同行业≥2 → `hot_sector`。
- **TSL 字段**:max(近10日低, MA50) 棘轮上移,存记录供展示。
- 阈值全进 `config/strategy.py['SEPA']`(可配),踩坑①②③④⑤ 全遵守(前复权/剔一字板/收盘后重算板块/200线相对变化/规则命中即输出、不打分)。
### 回测(实现后)
- **SEPA 观察池前瞻 Alpha**:同口径(相对沪深300、按个股聚类 t、深历史)——看池的前瞻收益/即死率。
- **验收股核查**:中际旭创等 4 只在 2023-2024 启动前是否进池 + 突破日是否命中。
- **预注册预期(诚实)**:我们已知趋势模板过滤 A股 Alpha 不显著 → SEPA 池自身 Alpha 可能弱;**价值更可能在"给人工缩小到强势+主题共振的候选面"**,而非策略自身超额。回测重点验证:①池是否确实是强趋势股②板块共振是否真的富集大赢家。
