## 0. 一句话

搭一条**可复现、脚本化**的"统一大复盘"生成路径（KPI=**绝对收益**）：把过去 N 个交易日、两条选股线（策略线 + 板块消息线）+ 塔尖金字塔逐票选出的票，逐票 **join「当时依据」×「事后收益」→ 判对错 → 归因**，产出**每日复盘 + 跨线汇总大复盘**。本轮**只搭路径（脚本+测试跑通）**，全量复盘运行等用户发令。

## 1. 背景与定位

### 1.1 为什么现在做
近期做了大量整改（双路并集、洗输入 P1+P2、新闻加深、描述凝练、P4 防误挂、塔尖金字塔信息凝聚）。整改后**口径分散在各线各自的记分器**里，缺一次**跨线统一校准**——同一天两条线各选了票、事后谁对谁错、选对靠什么、选错错在哪，目前无法一张表看清。

### 1.2 定位（关键·避免重造）
系统已有丰富的**分线分档 forward 记分器**（见 §6）。本路径**不重造收益口径**，而是在其上做**跨两条线 JOIN + 归因**的"大复盘层"：
- **复用**现有事后收益引擎（`event_study.forward_returns`、`sector_news_forward` 回踩限价撮合、`KlineBook` kline 缓存、master kline 天然防未来护栏）。
- **新增**的只有三件：① 跨线统一的 **Model-A 收益列**（跨版/跨线唯一可比）；② **规则归因引擎**（选对/选错分桶）；③ **跨线汇总渲染**（每日 MD + 汇总 CSV/MD）。

## 4. 口径（防未来硬红线 + Model-A 完整定义）

### 4.1 双列报告架构
- **(a) 各线原生口径列**：复用现有 `nextday_scorecard`（次日实盘入场口径）/ `sector_news_forward`（回踩限价 prev_close D+1/D+2）——**各线自身归因用，不破坏现有产物**。大复盘对这些**只读 join**，不重算。
- **(b) 统一 Model-A 列**：跨版/跨线收益榜**只用此列**（否则"次日开盘入场 vs 回踩限价"不可比）。
- 两列共守**严格 as-of 防未来**。

### 4.2 Model-A 完整定义（统筹拍板·锁定）
| 环节 | 定义 |
|---|---|
| **限价** | = **信号日 D 收盘价**（取 master kline `close[idx_D]`；产物 `形态.现价` 仅作交叉校验）。全线/全版可算，与 `sector_news_forward` 的 `prev_close` 天然一致 |
| **成交判定** | D+1 `low ≤ 限价` → 成交；否则 **未触发** |
| **成交价** | = **`min(限价, D+1 open)`**（跳空低开破限价则真实成交在开盘价、更优、保守中性；不跳空则=限价） |
| **未触发** | **不计入胜率分母**；单列 **"未成交率"**，不混进胜率 |
| **主胜率指标** | 入场→**D+1 收盘**绝对收益 `r_d1 = (D+1收盘/成交价 − 1)×100`，`>0` 计胜率 |
| **实际了结收益 `r_exit`** | D+1 收盘为正 → 持到 **D+2 卖出线**（D+2 收盘计收益）；D+1 收盘为负 或 盘中破 MA5/止损 → 当日(D+1)离场 |
| **α** | `r − 全A等权同期`（只归因不否决） |
| **P_entry 自报** | 各票自报回踩支撑价（MA5/MA20，手工版部分给）→ **次列敏感性**；规则算不到 → null 有声缺失；**跨版排名只认主列** |

### 4.3 防未来红线（两列共守·全项目统一范式）
- 收益 canonical：`close[idx+N]/close[idx]−1`；**越界 `idx+N≥len` → pending 留 None**（master kline 无未来 bar = 天然护栏）。
- 信号侧只喂 `df.iloc[:idx+1]`（≤D）算方向/技术。
- as-of 守卫：消费块 `as_of ≤ D`，缺则**保守拒**（复用 `sector_news_forward.asof_ok` 范式）。
- 进场 execution_lag：信号日 D 盘后产生 → D+1 成交，绝不用 D 当日偷看。
- 落盘三件套：未到期留 None + backfill 只填 None + 同 date upsert。

## 5. 归因分类法（规则先行 + LLM 可选层 + null 有声缺失）

对每只**已成交**票，先用**规则**归因；规则判不了留 `null`（有声缺失，不猜）；LLM 归因作**可选层**（默认关，`--llm-attr` 开）。

### 5.1 选对归因（r_exit > 0 时，答"靠什么选对"）
| 桶 | 规则判据（字段） |
|---|---|
| 板块-龙头催化 | `来源=板块催化` 且 该 code 在 `sector_focus.消息驱动.利好板块[].龙头候选`（emit=`{code,name,已动}`，**候选不自带催化**）；催化证据按 **board join 取板块级 `关键事件`**（`利好板块[].关键事件` 或 `catalyst.板块研判[sw].关键事件`，逐条带 时间/方向/可信度/影响程度/执行度/来源）；板块 `强弱` 作信念权重 |
| 板块-联动跟涨 | `来源=板块催化` 且 该 code 在 `跟涨候选`（补涨先锋·二阶信号·**归因权重低于龙头**） |
| 策略 | `来源=策略直选` 且 `策略命中` 非空（如 council合议） |
| 财报 | `council.财报风险` 正面 / 财报红旗数=0 且策略命中含财报专家 |
| 形态 | `形态.均线多头` 且 `来源=策略直选`（量价形态驱动） |

### 5.2 选错归因（r_exit ≤ 0 或未触发时，答"错在哪"）
| 桶 | 规则判据（板块半来自板块线·**是否触发来自执行侧 Model-A**） |
|---|---|
| **踏空** | 板块 `强弱=强` + 关键事件真强（`影响=大` 且 `来源=一手` 且 `执行度=高`）**且** Model-A **未触发**（D+1 未回踩到限价）**且**事后 `r_d1_shadow>0`（若按开盘买本会赚）。板块线只给"信号确为强"这半，未触发由 Model-A 撮合 join |
| **假利好** | `来源=板块催化`，有 `关键事件` 但**质量弱**——`可信度∈{存疑,不可信}` 或 `来源=二手` 或 `执行度=低` 或 板块 `强弱∈{中,弱}`——且成交后 `r_d1<0`。**关键事件的 可信度/来源/执行度 三档 = 假利好探测器** |
| **追高** | `已动=True`（当日涨幅≥3%·MOVED_PCT，追高必要信号位）且入场在已动后追（违"回踩不追高"）或 `形态.涨停不可买=true`/`pos60`高位，成交后 `r_d1<0` |
| **财报红旗漏判** | `council.财报红旗数>0` 仍入推荐档，成交后 `r_d1<0` |
| **踏错板块基调** | 从 `sector_regime.冷热标签∈{过热,拐点}`（或拥挤分位高/动量转弱）的板块选出、催化 `时效`偏旧/`持续性`近日转弱 → 选对催化但踏错板块节奏 |
| **踏错大盘基调** | 弱市（`market_forecast` 净方向偏空）里选高 β 票随大盘跟跌（β 拖累致亏）。**大盘基调属统筹市场线**，板块线只到板块 regime 层 |

### 5.3 板块归因映射（**已确认·wizardly-swirles·回声-0914**）
板块线窗口已给全映射，权威文档：`docs/计划/2026-09-17_板块线依据到归因桶_映射.md`（**已由统筹合入 main**·merge 5c2efe3·可稳定引用）。上表 §5.1/§5.2 板块相关桶已按其定稿。
**诚实边界（其文档 §5）**：事后涨跌来自 kline、**是否成交来自执行侧（Model-A 撮合）**、板块线不含后者——踏空判据须 join 两侧。

## 7. 脚本架构（先框架后填充·守则5）

新模块 `tools/review/`，按"输入 → Model-A → 归因 → 渲染"单向数据流分层，函数低耦合：

```
tools/review/
  __init__.py
  loaders.py          # 读 7 类产物 → 统一 Pick 记录列表
  model_a.py          # Model-A 撮合+收益（复用 sector_news_forward 撮合逻辑）
  native.py           # 各线原生口径列：join 现有 csv（nextday_scorecard.csv / shadow_forward/sector_news/），不重算
  attribution.py      # 规则归因引擎（选对/选错分桶）+ LLM 可选层接口
  render.py           # 每日复盘 MD + 汇总 CSV/MD 渲染
  build_grand_review.py  # CLI 编排（--date / --range / --data-root / --out / --llm-attr），幂等
```

**各模块 I/O 契约（定死输入输出再填实现）：**

| 模块 | 输入 | 输出 |
|---|---|---|
| `loaders.load_picks(date, data_root)` | date + 产物目录 | `list[Pick]`，`Pick{date,code,name,version_tag,来源,角色,建议分,档,council,形态,板块消息面,自报入场/止损文本}` |
| `model_a.compute_labels(pick, book, ew)` | 单 Pick + KlineBook + 等权基准 | `{filled:bool, entry_price, r_d1, r_exit, alpha_d1, sell_line_hit, untriggered, p_entry_self_sens}`（未到期 None） |
| `native.join_native(pick)` | 单 Pick | `{nextday_native, sector_news_native}`（读现有 csv，无则 None） |
| `attribution.classify(pick, labels)` | Pick + Model-A labels | `{correct_bucket\|null, wrong_bucket\|null, evidence_text}`（规则判；`--llm-attr` 时补 LLM） |
| `render.daily_md(date, rows)` / `render.grand_csv(rows)` | 逐票行 | 每日复盘 MD（docs/）+ 汇总 CSV（data/analysis/backtest/grand_review_scorecard.csv） |
| `build_grand_review.main()` | CLI | 编排上述，逐日+汇总，幂等 upsert |
