# P5 · 角色-催化对齐 · 小设计(先论证再决定动不动)

> 2026-09-17 · 板块预测窗口(回声-0914)。⚠️ 测试环境研究模拟,非投资建议。
> 统筹要求:P5 会把"新闻催化"加进 S2 角色识别,先讲清 **①为什么要动角色口径 ②会不会破防未来 ③是否真必要**,对齐后再决定建不建。

## 1. 起因(要解决的现象)
DeepSeek-vs-Opus 对比里观察到:电子板块 S2 选出的**龙头**是威尔高/致尚科技/有研硅等——
它们当日**量价强**(异动/停牌/解禁波动),但**新闻是噪音**(解禁跌停、终止收购、停牌);
真正的**新闻催化主体**(长飞光缆集采、生益 PCB+130%、源杰 CPO)却在**中军**。
→ 直觉:"龙头选错了,该把新闻催化纳入角色打分,让龙头更贴近真催化主体"。

## 2. 诊断:这真是"角色选错"吗?——**不是,是 news 噪音问题,P1 已解决**
- S2 角色口径 = **纯可计算量价**(涨幅/成交额/市值/位置/放量/β/市值),定义的是
  **"谁量价强/谁是大市值主力/谁低位补涨"**——这本身**没选错**:威尔高当日确实量价异动,
  它就是"当日量价龙头"。角色刻画的是**结构位置**,不是"谁有好消息"。
- "龙头新闻是噪音"的**真因**是**采集/研判层的噪音**(解禁×6/终止×7 淹没),
  **P1 榜单过滤 + P2 事件去重已洗掉**——洗后电子从"分歧"→"利好·强",**问题已消失**。
- 即:**症状(误判分歧)的根因是 news 脏,不是角色选谁**。P1 修的是根因;P5 想修的是"角色"这个**非根因**。

## 3. 若强行做 P5(把新闻催化掺进 S2 角色)的代价
| 维度 | 现状(S2 纯量价) | 掺新闻后 |
|---|---|---|
| **防未来函数** | 硬保证:只用 ≤date 量价/市值(PIT·可离线因果算) | **风险**:新闻催化需 LLM 判 + live 口径(allow_future),把**不可复现的 LLM 判断 / 放开未来的新闻**灌进角色 → 角色不再 PIT、回测口径污染 |
| **可复现/可审** | 纯规则打分,测试可锁、可离线重算 | LLM 判催化每次可能不同,角色表**不可复现**、难审计、难留痕 |
| **周度稳定性** | 量价周维护稳定 | 新闻催化天天变 → 角色天天抖,违背"周度定表·变更留痕"初衷 |
| **解耦** | S2(角色)/S3(采集)/S4(研判)三层清晰单一职责 | S2 里塞 S3/S4 的活 → 层耦合、职责混乱 |

**结论:P5 原样会破坏 S2 的"纯量价·PIT·防未来·可复现"干净口径,收益(修一个已被 P1 修好的非根因)远小于代价。**

## 4. 建议:**不做侵入式 P5**;如确有需要,走两个安全替代
1. **保持 S2 纯量价不动**(角色=结构位置的客观刻画,别掺主观消息)。
2. 若担心"新闻很热的股没进角色、被漏采"——**这是采集覆盖问题,在 S3 解**:
   S3 除了按 S2 角色表采,**额外把"当日板块内新闻热度高的成分"纳入采集范围**(增量补采,
   不改角色表)。这样真催化主体的新闻一定被 S4 看到,而 S2 角色口径保持干净。
3. 若塔尖想知道"哪个角色股此刻有真催化"——这在 **S4 研判 / board_desc 描述**里已体现
   (关键事件按角色标注、描述里点名催化主体),**无需回改 S2**。

## 5. 结论(待统筹拍)
- **推荐:P5 标记为「不做/关闭」**——根因(news 噪音)已由 P1+P2 解决,角色口径应保持纯量价。
- 若统筹/用户仍想要"角色贴近催化",走 §4.2 的 **S3 增量补采板块新闻热股**(可另立小任务·不碰 S2·不破防未来)。
- 我不动 S2,等你拍:①认可"P5 不做"→关闭;②或要 §4.2 补采→我另开小任务设计。
