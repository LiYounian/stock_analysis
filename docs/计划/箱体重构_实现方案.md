## 1. 歧义默认取值(§3 七条,可配)
| # | 歧义 | 默认取值(可配) | 理由 |
|---|---|---|---|
| 1 | 进场时序 | **回测同时出两口径**:①`次日开盘`(T+1 open,无未来函数,**头条数**)②`当日收盘`(=旧基线,可比)。提供者"突破当天竞价买"作为盘中预判,回测无法无偏复现→用 T+1 开盘做最诚实近似 | 收盘才确认突破,当日开盘买=未来函数;T+1 开盘是可无偏成交的最近似"突破日买入" |
| 2 | "站稳" | 收盘 > 箱顶 ×(1+`站稳容差%`),默认 0.5% | 比旧"突破幅度3%"更贴"刚站稳";可调 |
| 3 | 触碰容差 | 触轨带 `触碰容差%`=1.0;回落/反弹幅度门槛 `回落反弹%`=3.0;各 ≥`触碰次数`=2 次 | 1% 容差贴合日内噪声;回落3%确认是"真震荡"非贴边 |
| 4 | 缩量 | 后 `缩量后段占比`=1/3 窗口均量 ≤ 前段均量 ×`缩量比`(0.8) | "后期持续缩量"=后段量能下台阶≥20%;可调 |
| 5 | 均线多头 | `close>MA200`(站上年线,硬)AND `MA5>MA10>MA20`(短多头);<200 根历史→趋势门不过(剔除,保守) | 提供者明确"200日线上方+均线多头";次新不够200根→诚实剔除 |
| 6 | 振幅 | (箱顶−箱底)/箱底×100 ∈ [`振幅下界%`8, `振幅上界%`30] | 提供者原文 8%~30% |
| 7 | 标的范围 | 检测**不硬限**板块(全A 通用);回测**按板块拆分报告**(含 20cm 创业板300/301·科创688 子集);配 `限20cm板` 开关默认关 | 规格是形态+趋势,不是板块;20cm 是收益特征,拆分看即可,不写死 |

## 2. 配置新增(`['形态选股']['箱体']`,默认值)
```
窗口区间: [20, 60]        # 替代固定30,自适应选最优箱体窗
振幅下界%: 8.0            # 新增下界
振幅上界%: 30.0           # 由旧"高度上限12"放宽(旧键保留给 v1)
突破放量倍数: 1.8         # 由1.5→1.8(v2 用;v1 仍1.5)
站稳容差%: 0.5           # 收盘站稳箱顶的余量
触碰容差%: 1.0           # 触轨带
触碰次数: 2              # 上下轨各≥2次
回落反弹%: 3.0           # 触轨后回落/反弹确认幅度
缩量比: 0.8              # 后段均量/前段均量 上限
缩量后段占比: 0.3333     # 后1/3窗口为"后期"
趋势门: {启用:true, MA200:true, 短均线多头:true}
进场时序: "次日开盘"      # 回测头条口径;另跑"当日收盘"对照
```
旧键(窗口30/高度上限12/突破幅度3/突破放量1.5)**保留**,`detect_box`(v1)不受影响。

## 3. 函数框架(先框架、定 IO,后填实现——约法5)
### 3.1 `pattern.py`(纯几何,只用 K线)
- `detect_box_v2(df, cfg) -> {达标:bool, 命中:"箱体v2", 特征:{窗口, 箱顶, 箱底, 振幅%, 触上次数, 触下次数, 缩量:bool, 横盘:bool, 站稳:bool, 放量:bool, 量比}}`
  - `_pick_box_window(df, cfg) -> (lo, hi, win)|None`:在窗口区间内选振幅落 [下界,上界] 且触碰达标的最优窗(不含末根)
  - `_count_touches(seg, rail, tol, 回落反弹%, 上轨?) -> int`:带容差触轨 + 回落/反弹确认的次数
  - `_shrinking_volume(seg, 占比, 缩量比) -> bool`:后段均量 ≤ 前段 ×缩量比
  - `_sideways(seg) -> bool`:箱体内收盘对时间回归斜率≈0(单边涨跌剔除)
  - 突破/放量/站稳沿用 `_vol_confirm` 思路 + 站稳容差
- 兼容:v2 特征保留 `箱顶/箱底` 供结构化输出与止损。

### 3.2 `screen_box.py`(接趋势门 + 结构化输出)
- `_trend_gate(kdf, t, cfg) -> (pass:bool, {ma200_ok, 短多头_ok, 历史不足})`:复用 `technical.ma`,只用 [0,t]
- `signal_at(kdf, t, cfg, use_v2=True)`:v2 = `detect_box_v2` AND `_trend_gate`;输出并入 `箱顶/箱底/止损`
- `_box_stop(箱底, price, kdf, cfg) -> {止损价, 依据}`:止损=箱体下轨(或 `predict.atr` 兜底),取更近者
- `run_box_screen` 入选项补 `{code, 箱顶, 箱底, 止损, 振幅%, 触碰, 特征}`;`use_v2` 开关(默认 v2)

### 3.3 `backtest_box.py`(进场口径参数化 + A/B)
- `summarize(..., entry="次日开盘"|"当日收盘", use_v2=True)`:进场价注入 `position_backtest`
- 若 `simulate_position` 只支持信号日收盘 → 加薄封装:T+1 开盘进场 = 从 t 取 open(t+1) 作 P0(仍防未来函数)
- 出 4 组:{v1,v2} ×{当日收盘, T+1开盘},重点看 v2 是否降即死61%、提 Alpha
