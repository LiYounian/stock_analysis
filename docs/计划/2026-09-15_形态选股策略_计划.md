## 0. 一句话

把"KDJ/均线金叉"这个**冲高当天才亮的同步信号**，改造成**冲高前 3~4 天就埋伏的领先信号**：D 晚扫出刚发生金叉的票 → D+1 在回踩/支撑位限价埋伏 → 5 日内冲高触及固定止盈线即卖，吃"金叉→冲高"这段 3~4 日跑道。核心研究问题从"识别冲高"变为"**预测冲高的前兆**"。

---

## 1. 缘起（为什么这么改）

### 1.1 用户构想
形态口述：股票**接近支撑位、初步向上、要开始反弹**；趋势**必须向上、不能持续下跌**。并给了朋友按 2026-09-14 行情选出的 8 只票（博迁新材 300285 / 洁美科技 002859 / 胜蓝股份 300843 / 德福科技 301511 / 金安国纪 002636 / 金禄电子 301282 / 蓝盾光电 300862 / 中石科技 300684），要求反推形态、盘点"交叉"类指标、画均线辅助线判趋势。

### 1.2 反推 8 只票的实证发现（本轮调研，样本仅 8，属**假设生成**非结论）
- **共性触发**：8 只里 7 只 **KDJ 金叉发生在 ≤5 日内、J 值 7/8 在上行**，6/8 收盘站上 MA20。朋友的筛选核心大概率是"KDJ 拐头金叉 + 站上短均线"。
- **趋势阶段不统一**：8 只分三档——A 底部刚反转（洁美/博迁，中期均线仍下行）、B 上升回踩（胜蓝/金安/中石）、C 已强势涨高（德福/金禄/蓝盾，金禄分位95已近高点）。用户两条约束（"接近支撑非高点" vs "趋势必须向上"）本身有张力，B 档是两者交集。
- **⭐关键：金叉是"领先信号"**。定位每只最近的"冲高回落"日 T（盘中较昨收 ≥+5% 且收盘回吐 ≥3%、收在下半区），倒推发现：能"提前埋伏"的那几只（博迁/德福/胜蓝/中石），**金叉都出现在冲高前 T-3~T-4**，冲高当天 **J 已在 90~110（超买）**。买在金叉有 3~4 天跑道；等冲高当天信号才买（洁美/金禄）就是"晚一步"。
- **与已有栈印证**：SEPA/VCP 回测（`回测报告_SEPA_VCP_20260822.md`）证"接近枢纽 **T+5 +0.60%**、T+10/T+20 转负"——**edge 就在 5 日内**，与本策略"5 日兑现"吻合；趋势模板裸用被证伪（顺势放大器，震荡市杀跌）→ 本策略须叠加市场状态门 + 不裸用。

### 1.3 用户的核心重构（本文据此立项）
> 朋友那套精准找到了"要冲高"的时点（成功一半），但 A股 T+1 使"当天亮信号→次日买"买在回落（失败一半）。**正确用法 = 提前埋伏**：抓冲高前兆、低位埋伏、冲高触线即卖。

## 2. 策略环（次日实盘口径贯穿）

| 时点 | 动作 | 口径 |
|---|---|---|
| **D 晚·选股(埋伏)** | 扫全A，选**当日/近1日发生金叉**（触发件见 §3）的票入候选池；叠加趋势阶段门 + 市场状态门（见 §3.3） | 只用 ≤D 收盘信息（防未来） |
| **D+1·入场** | 在支撑/回踩位挂**限价** `P_entry`；`marketable` 成交口径 | `P_entry` 主档=昨收~昨收−1% 回踩（底座已证最优、触发率高）；未触发处理写死 |
| **D+1..D+5·持有** | 盘中/收盘监控，触及止盈线 `P_target` 即卖 | 冲高主测口径=**固定目标 +X%**（X 扫参）；对照 J≥阈值 / 长上影冲高回落K |
| **止损** | 跌破支撑 `S_stop` 即离场 | 支撑下方一档，ATR 自适应 |
| **时间了结** | 第 5 交易日未触发止盈 → 收盘无条件了结 | 持有窗**最长 5 交易日** |

- 涨停封板卖不出预案沿用现 SOP（次日集合竞价挂跌停价优先出）。
- 主指标 = **入场→卖出 绝对收益**（是否为正 = 胜率）；α vs 全A等权作归因。

## 3. 形态定义（可判定 + 可回测 + 防偷看）

### 3.1 触发件（金叉，回测作维度**全交叉扫**，不预定哪个最优）
每种"金叉"= 前一根未成立、当前根成立（`sign` 由 ≤0 转 >0），只用已收盘 K，无未来函数：
- **T1 KDJ 金叉**：K 上穿 D 且 J 上行（复用 `indicator_state._kdj_cross` 的低位/新近/交叉点抬高语义）。
- **T2 MA5×MA10 金叉**：短均线金叉（仓无现成函数，照搬 `_kdj_cross` 扫描逻辑泛化到均线）。
- **T3 MACD 金叉**：DIF 上穿 DEA（经典两线交叉，非仓里"柱穿零轴"口径；原料 `technical.macd()` 已给 dif/dea）。
- **T4 多信号共振**：T1/T2/T3 中任 2 个在近 ≤2 日内同时成立。

### 3.2 趋势阶段门（回测作维度扫；含"不加门"）
用"均线辅助线的生长/下降"量化（对应用户"画均线辅助线判趋势"）：
- **MA20 斜率** = MA20(t) / MA20(t−5) − 1；**MA60 斜率**同理（照搬 SEPA `ma > ma_ago` 模式）。
- **档 A 底部反转**：MA20/MA60 斜率可为负，但价格站上 MA20、近60日低位分位 ≤35%。
- **档 B 上升回踩**：MA20 & MA60 斜率 > 0（趋势向上）+ 价格回踩到 MA20 附近（|收/MA20−1| ≤ 阈值，"接近支撑非高点"）。
- **档 C 强势**：多头排列（MA5≥MA10≥MA20≥MA60，复用 `technical._ma_arrangement`）。
- **档 N 不加门**：仅触发件。

### 3.3 市场状态门（护栏，防震荡市杀跌）
叠加 `THRESHOLDS["市场状态"]` 四因子五档 regime（`pattern_screener/regime.py`）；回测分 regime 汇报，验证是否只在"牛/强趋势"档有效（趋势模板教训）。

### 3.4 入场点 / 止盈 / 止损（§2 已列，回测参数化）
- `P_entry`：主档 昨收~昨收−1% 回踩限价；未触发→放弃（写死）。深回踩 −2~−5% 作可选 `P_dip`（底座已证不更优）。
- `P_target`（止盈/冲高）：主测 **成本 +X%**，X ∈ {5,8,12}% 扫；对照 J≥{90,100} / 长上影K。
- `S_stop`：入场支撑下方一档（如 P_entry×(1−止损%)，止损% ∈ {5,8}% 扫）。
- 持有窗 = 5 交易日（时间止盈）。

## 4. 预注册回测判据（**判据先于结果，防事后看图说话**）

### 4.1 回测框架
- 复用 `tools/backtest/screen_forward_common.py`（walk-forward，`window_at`/`build_forward_cache`/`summarize_records`/regime 分层），范式照 `backtest_sepa_vcp.py`。
- 全A（排北交所、剔 ST），2018–2026，stride≈60，对照全A等权 + HS300。
- **成交**：`marketable` 口径；**扣成本**（双边佣金+印花+滑点，沿用底座口径）；**涨停约束**：入场日/止盈日若涨停封板不可买/不可卖，按 SOP 处理并单列。
- **OOS**：留出最近 N（如 2025-01 起）为样本外，参数只在样本内选。

### 4.2 组合矩阵（用户要求"列出可能、全交叉、看是否有影响"）
触发件(4) × 趋势阶段门(4) × 止盈口径(3) × 持有窗(固定5) × 止损%(2) → 主跑触发件×趋势门(4×4=16)网格，止盈/止损作二级敏感性。每格报：绝对胜率、均值绝对收益、α、Sharpe/回撤代理、样本量、分 regime。

### 4.3 预注册判据（回测前写死，达标才建议采用草案）
1. **净正**：主组合（样本内选优）**扣成本后均值绝对收益 > 0 且绝对胜率 > 50%**，OOS 不反号。
2. **有增量**：相对现有栈（接近枢纽 T+5 +0.60% 底座 / 次日入场底座）**α 或净收益有正增量**，或在现有栈失效的 regime 补位。
3. **稳健**：跨 regime 不是仅靠单一牛市窗口；参数高原（相邻参数不塌）；预注册显著性（如 bootstrap p）达标。
4. **"领先"证据**：验证"金叉→冲高"跑道确实存在——买在金叉的组显著优于买在冲高当天的组（证伪 T+1 滞后陷阱）。

**任一不达标 → 如实证伪、不建议采用**（诚实证伪优先，不为立项硬凑）。不自换线；有增益也只出**草案**交统筹。

## 5. 防未来 / 防过拟合红线
- **防未来（硬红线）**：所有指标只用 ≤t 收盘；入场/止盈用 D+1 及之后的实际 K，选股日不许偷看未来。
- **防过拟合**：形态策略极易"事后看图说话"——① 判据 §4.3 先于结果；② walk-forward + OOS；③ 8 只票仅作假设生成、绝不作证据；④ 参数扫看"高原"非"孤峰"；⑤ 组合数受控，多重比较用 OOS 兜底。
- **配置单一真源**：所有阈值进 `tools/config/strategy.py` 的 `THRESHOLDS` 新键（如 `["形态金叉前兆"]`），零硬编码。
- **不裸用**（A股动量弱/反转强）：可叠加基本面（净利增速≥0）或事件确认作二级过滤，回测对比加/不加。
