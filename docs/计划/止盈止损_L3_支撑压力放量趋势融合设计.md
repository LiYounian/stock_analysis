> ⚠️ 非投资建议;所有输出为基于历史与波动率的统计构造。
> 目标:把现在"纯 ATR 波动率括号"的止盈/止损,升级成**以结构点位(支撑/压力)+ 放量确认 + 趋势方向**为核心的、页面上看得见判断逻辑的模型。

## 一、现状零件(已实现,口径精确)

三块已在 `tools/analysis/predict.py` + `technical.py` 算出,但**尚未融进止盈/止损**(现止损/止盈只用 ATR)。

### 1.1 支撑位 / 压力位([predict.py:53](tools/analysis/predict.py:53))
- **Swing Pivot 法**:某根 K 线的 high 若是其**左右各 5 根(共 11 根窗口)内最高** → 压力候选点(pivot high);low 若是窗口内最低 → 支撑候选点。参数 `swing窗口=5`。
- 取**现价下方最近 2 档**为支撑 `[S1, S2]`(S1 最近)、**上方最近 2 档**为压力 `[R1, R2]`(R1 最近)。参数 `支撑压力_取几档=2`。
- 输出:**绝对价格**。局限:未按成交量密集度加权(强/弱支撑不分)。

### 1.2 放量([predict.py:35](tools/analysis/predict.py:35) / [technical.py:112](tools/analysis/technical.py:112))
- **量比 = 当日成交量 / 前 5 日平均成交量**(前 5 日**不含当日**,`shift(1)`)。
- **量化阈值:量比 > 1.5 判为放量**(参数 `放量_量比=1.5`)。
- `recent_volume_spikes` 回溯最近 3 次(`近N次放量=3`)放量日。

### 1.3 趋势([technical.py:145 `_score`](tools/analysis/technical.py:145))
多信号打分(−100~100):

| 信号 | 口径 | 分 |
|---|---|---|
| 均线排列 | ma5≥ma10≥ma20≥ma60=多头;全反向=空头;否则纠缠 | +30/−30/0 |
| MACD | 金叉/死叉(EMA) | +25/−25 |
| 价 vs MA20 | 收盘在 MA20 上/下 | +10/−10 |
| RSI12/KDJ | 强弱区/金叉死叉 | 若干 |

- 合成:**≥+30 偏多(上升)· ≤−30 偏空(下降)· 中间 中性(震荡)**。
- 位置量:`BIAS20 = (收盘−MA20)/MA20×100`(**百分比**,离 20 日线多远)。

## 二、L3 新增逻辑(要做的)

### 2.1 突破判定(has broken?)
判定"当前有没有突破以前的压力/支撑",**必须放量确认**(A 股假突破多):

```
向上突破压力 R1 = 收盘 ≥ R1 × (1 + τ_break)  且  当日量比 ≥ 放量阈值
向下跌破支撑 S1 = 收盘 ≤ S1 × (1 − τ_break)  且  当日量比 ≥ 放量阈值
```
- `τ_break`(突破容差)= **0.75%**(占位,待数据验证;候选区间 0.5%~1.5%)。
- 放量阈值 = **1.5**(占位,复用 §1.2)。
- 只碰价未放量 = "**假突破嫌疑 / 待确认**",不算有效突破。

### 2.2 距离与位置(数据口径:以百分比为主,绝对值辅助)
- **距压力% = (R1 − 收盘)/收盘 × 100**;**距支撑% = (收盘 − S1)/收盘 × 100**。
  - 为什么用百分比:10 元股和 100 元股"差 3 毛"意义天差地别,百分比才可跨股比较。绝对价差同时展示便于下单。
- **区间位置% = (收盘 − S1) / (R1 − S1) × 100**:
  - 0% 贴支撑 · 100% 贴压力 · >100% 已向上突破 · <0% 已向下跌破。一个 0~100 的直观刻度。

### 2.3 趋势方向(上升/下降,详述)
沿用 §1.3 的 `_score` 三分(偏多/中性/偏空)+ BIAS20,**再叠加**:
- **趋势强度** = |score|(0~100),用于调节止盈力度(强趋势给远目标)。
- **趋势一致性**:MA 多头排列 + 价在 MA20 上 + MACD 金叉 = 强上升(三者齐);缺项则降级。

### 2.4 放量预估(先日频)
- **当日放量判定**:今日量比、是否 ≥1.5(实时回答"今天放量没")。
- **量能趋势(日频)**:近 5/10 交易日放量频率、量能是否逐日抬升(温和放量 vs 爆量)。
- **盘中放量预估**:需分钟级数据外推当日预计量——**当前只有日频,暂不做**(用户同意先日频),留作数据源扩展后的增强位。

### 2.5 新的止盈/止损锚定(核心:融合上述)
把 ATR 从"唯一决定项"降级为"缓冲宽度来源",按**趋势 + 突破 + 位置**分情景锚定:

| 情景 | 判定 | 止损锚 | 止盈锚 |
|---|---|---|---|
| **放量突破上行** | 上升趋势 + 放量突破 R1 | 突破位 R1 × (1 − buffer)(回踩不破才有效) | 下一档压力 R2;或量度目标 = R1 +(R1−S1) |
| **箱体震荡** | 中性 + 价在 [S1,R1] 内 | S1 × (1 − buffer) | R1 × (1 − 小缓冲)(压力前止盈) |
| **趋势回踩** | 上升趋势 + 价回踩近 S1 未破 | S1 × (1 − buffer) | 前高 R1 |
| **跌破/下降** | 下降趋势 或 放量跌破 S1 | 观望,不给多头目标(或提示离场) | — |

- `buffer`(止损缓冲)= **max(1.0%, 0.5 × ATR%)**(占位):强波动票给宽缓冲防扫损,弱波动票给窄缓冲。
- 盈亏比不再恒定 1.6,而是 **(止盈锚−现价)/(现价−止损锚)** 由真实点位算出——**这才是有信息量的盈亏比**。
- 全部同时给**绝对价 + 百分比**。

## 三、阈值清单(留痕,占位值 → 待 §四 数据验证后定稿)

| 参数 | 含义 | 占位值 | 验证方式 |
|---|---|---|---|
| swing窗口 | pivot 左右各 N 根 | 5 | 扫 3/5/8/10 看点位稳定性 |
| 支撑压力_取几档 | 取最近几档 | 2 | 固定 2 |
| 放量_量比 | 放量阈值(倍) | 1.5 | 扫 1.2~2.0 看突破区分度 |
| τ_break | 突破容差(%) | 0.75 | 扫 0.5~1.5 看假突破率 |
| buffer | 止损缓冲 | max(1%,0.5×ATR%) | 看被扫损率 vs 目标达成率 |
| 趋势分档 | 偏多/偏空阈 | ≥30 / ≤−30 | 沿用,回测校 |

> 这些是**我们思考过的经验起点**,不是定论。策略提供者若有经验值可给,但**最终以历史数据验证为准**(用户口径②③)。

## 四、用历史数据自验阈值(数据说话,方法)

对 47 只自选股(尤其新加的验证池),用本地历史 K线(已缓存),复用 `tools/backtest`(单③)框架:

1. **支撑/压力有效性**:历史上价格触及 S1 后 N 日内反弹的比例(支撑有效率)、触及 R1 后回落比例(压力有效率)。有效率显著 >50% 才说明 swing 点位有意义。
2. **放量阈值区分度**:比较"放量突破 R1"(量比≥阈值)vs"缩量突破"后未来 5/10 日胜率与收益。若放量组显著更好,阈值合理;扫 1.2~2.0 找拐点。
3. **突破容差 τ_break**:统计不同 τ 下"突破后回落跌回箱内(假突破)"的比例,选假突破率明显下降的最小 τ。
4. **止损 buffer**:统计"止损锚被 N 日内扫破但随后创新高"(误扫)比例 vs buffer,取误扫可接受的最小 buffer。
5. **趋势门**:分"上升/中性/下降"三态下,同一套止盈/止损的胜率与盈亏比,验证"只在上升趋势用多头括号"的增益。

产出:每个阈值一个**数据支持的推荐值** + 页面「**策略体检**」卡(每指标带样本量,数据不足标"待观察")。

### 4.1 首轮验证结果(2026-08-08,`tools/backtest/validate_l3_thresholds.py`)

样本:自选池 46 只 · 各~334 根日 K(2025-03 至 2026-08)· 防未来函数。**结论要带样本偏差看**(见末尾)。

**基准**(无条件前瞻上涨概率):5 日 52.9% / 10 日 55.6%,均值 +1.39% / +2.79%——**样本本身处于偏多窗口、基数高**。

**A. 放量阈值区分度 —— ⚠️ 常识被部分证伪。** 突破日(创前 20 日新高)按量比分组,**放量突破的未来收益并不优于缩量,多数区间反而略低**:
| 量比阈值 | 5日 放量均值 vs 缩量 | 10日 |
|---|---|---|
| 1.5 | +1.81% vs **+2.64%**(放量差 −0.83%) | +5.19% vs +5.44% |
| 2.0 | +2.21% vs +2.30% | +5.59% vs +5.27%(放量略优 +0.32%) |
→ **"放量突破=收益更高"在本样本不成立**。放量**不宜**当收益 alpha 用。

**B. 突破容差 τ —— ✅ 站得住。** τ 越大假突破率单调下降:5 日 τ=0%→53%、0.75%→48%、1.5%→42%;10 日 62%→52%。且**放量确实降低假突破率**(5 日 放量 51% vs 缩量 55%;10 日 59% vs 63%,约 −4pp)。→ **放量的价值在"降假突破",不在"提收益";τ 取 0.75%~1.0% 合理**(平衡假突破率与信号量)。

**C. 支撑/压力有效性 —— 边际很弱。** 贴支撑(2%内)5 日上涨 53.6%、贴压力 55.1%,基准 52.9%——**只比基准高 0.7~2pp,且贴压力并未明显受阻**(偏多市里贴压力更多是突破)。→ **swing 点位预测力弱,更适合当"锚点/风控刻度",不宜当方向信号**。

**数据支持的阈值修订(替换 §三 占位)**:
- τ_break:**0.75%~1.0%**(数据支持,降假突破)。
- 放量_量比:**1.5 保留,但角色改为"突破确认/降假突破",不作收益预测**;置信度低。
- 支撑压力:**仅用于止盈止损锚定与位置刻度**,不进方向打分。

**样本偏差(必须声明,数据说话也要说清局限)**:① 仅 46 只自选(偏成长/科技),非全 A 截面;② 窗口偏多、基数高,压制了各条件的相对区分度;③ 突破用"前 20 日新高"近似 R1。**结论是"在本篮子本窗口"的,攒够更长/更宽样本后需复验**(每次跑该脚本即可复现)。

## 五、A 股交易日历 / 休市处理(用户口径③)

- **所有"N 日"= 交易日,不是自然日**:K线本身只含交易日(无周末/节假日 bar),故 ATR×√N、前瞻 5/10/20 日、swing 窗口、量能均**已按交易日计**。文档/页面须标注"5 交易日 ≈ 1 周",避免用户误读成自然日。
- **调度只在交易日跑**:盘后闭环(autopush)在**周末 / 法定节假日不应触发**(无新数据,跑了浪费)。需接入 **A 股交易日历**(akshare `tool_trade_date_hist_sina` 或交易所公告),launchd/定时器加"当日是否交易日"守卫;非交易日直接跳过。
- **回测锚点**:前瞻收益 t+1 锚已按交易日序列(单③),休市自然跳过,无未来函数风险。
- **"当日放量/突破"仅在交易日有意义**:非交易日不产生新判定。

## 六、落地拆解(建议顺序,每步可见+可验)

1. **L3-a 计算层**:在 predict 产出里新增 `突破状态 / 距压力% / 距支撑% / 区间位置% / 趋势方向+强度`(纯计算,复用现有 S/R、量比、_score)。归 predict/analysis owner。
2. **L3-b 锚定层**:按 §2.5 情景表重写止盈/止损锚定(ATR 降级为 buffer)。盈亏比改真实点位算。
3. **L3-c 展示层**:选股页/个股页显示"趋势方向 + 是否突破 + 区间位置 + 新止盈止损锚 + 真实盈亏比",一句话判断逻辑(如"上升趋势·放量突破 R1(+1.2%)→止损上移突破位、止盈看 R2")。归 web owner。
3. **L3-d 交易日历**:接入 A 股交易日历,调度加交易日守卫。归 sync/ops owner。
4. **L3-e 数据验证**:按 §四跑历史验证 → 定稿 §三阈值 → 页面「策略体检」卡。归 backtest owner。

> 顺序保证:先算(a)、再锚(b)、边展示(c)让你看得见,验证(e)用数据定阈值,交易日历(d)可并行。**不先做验证(e)就不锁死阈值**——先用占位跑起来、看得见,再用数据收敛。
