# 计划:按日期存储 + 10 只开发样本 + 全链路流水线 + Web 动态展示

> 状态:执行中 · 2026-08-06 · 用户开发阶段诉求。
> 一句话:开发期固定随机 10 只;每次跑的 raw+分析结果按**日期分目录**存;Web 从最新日期数据动态加载(原始数值+分析结果+消息/情绪三层)。

## 用户诉求(逐条)
1. 不用每次跑 32 只 → **随机挑 10 只,固定用**(开发期可复现)。
2. 每次抽取的数据 → **按日期存储**(布局:按日期分目录,已拍板)。
3. Web 展示内容 → **程序从存储数据动态加载**(原始数值 + 分析结果 + 消息整合)。
4. 做完 → 跑一遍流水线 → Web 展示。

## 存储布局(已拍板:按日期分目录)
```
data/raw/<日期>/<kind>/{code}.{parquet|json}   + {code}.meta.json
data/raw/llm_cache/{code}.json                 # 例外:不按日期(内容 hash,跨天复用)
data/analysis/<日期>/{code}.json               # 中心记录
data/analysis/<日期>/{name}.json               # 视图 panel/screen
data/analysis/<日期>/chart/{code}.json         # 按票视图 chart
data/analysis/<日期>/sentiment/{code}.json     # 按票情绪
```
Web 读**最新日期**目录。天然留历史快照(未来 BT.2 回测直接用)。
