## ① 预注册（规则 + 判据，先于跑写死 · 防偷看）

**票池 / 样本**：全A主档 K 线 **5563 只**（排北交所 8/4 头），2018-01 ~ 2026-09（每票约 2113 根）。
决策日区间 **2019-01-01 ~ 2026-09-15**（前留 ≥250 根做 MA/动量暖机）。持续型排名视图每日横截面
再加**流动性门**：近 20 日均成交额 ≥ **2 亿元**（as-of，防微盘幻觉、保可交易性）。

**持续型排名视图（recomputable，只用 ≤D 数据）**：
- **主视图 = 加权对数动量**（`weighted_log_momentum`，lookback 25，向量化复刻，等价性由单测锁）——
  对应「动量组合」。每日按 score 降序取 TopN。
- **稳健性视图 = 策略0合议**（`council.综合分`）——在流动性 Top 票池的子样本上做确认（算力所限，见 ③.4）。
- 说明：S05「最强选股」与「趋势模板」是**信号/过滤型引擎**（非干净的横截面打分），不适合直接做
  "TopN 续选"排名视图；故 H1 用两个可重算的横截面**打分**视图（动量 + 合议）作证据，S05 的强势票
  另在 H2 单独处理。

**入场（Model A · D+1）**：限价回踩 marketable 成交。主口径 **P_entry = 昨收 close_D×0.99**
（`limit_pc_0.01`，底座报告预注册 Pareto 最优）；敏感性另测 `limit_pc_0.0`（挂昨收）与 `open`（买开盘）。
成交模型 `marketable`：`open≤P→open; 否则 low≤P→P; 否则未触发不建仓`。**涨停不可买**过滤
（`open_{D+1} ≥ close_D×(1+涨停−0.005)` 剔除）。成本 **10bps** round-trip。

**两臂（唯一差异 = 到期退出规则；N 槽等权、口径、成本全一致）**：
- **baseline（无状态重挑）**：每日从 TopN(D) 重挑，D→D+1 入场→**D+2 收盘无条件了结**（每日再挑）。
- **treatment（续选/继续持有）**：持仓到期（D+2）时，若**仍在最新决策日 TopN** 且**收盘≥入场价
  （未破卖出线）**→ **续持**（不为换新票而丢），否则收盘卖出；续持者逐日复用同一判据。
  - **卖出线定义（预注册）**：`未破卖出线 = 当日收盘 ≥ 入场价`（盈亏平衡止损）+ 续持须仍在 TopN。
  - **稳健性对照**：另测 `topn_only`（仅要求仍在 TopN、去掉止损）以判「卖出线」是否为主因。

**成功判据（H1，预注册）**：treatment 绝对收益（组合 cum/annualized net）**显著 ≥ baseline** 且
**最大回撤不显著抬高**；佐证 = walk-forward 分年一致 + OOS 早/晚段同向 + 逐笔按 exec_date 聚类 t。

**H2（gap-fade）**：对 winner_rate>99 的强势票（S05 `C1∧C2∧C3` 通过 + 筹码获利比例 as-of D，
复用 `backtest_strong`），比 (a) 被 gap-fade 当降权丢弃（proxy = 追高开 `open` 买入）vs
(b) 用回踩限价（`limit_pc_0.01`）买入，持有到 D+1 收盘（Model A 检查点）与 D+2。
**判据**：若 (b) 绝对净收益显著优于 (a)（且 (b) 在 D+1 检查点为正），证明 gap-fade 应回退为
「入场提示（怎么买·回踩限价）」、不该降权（怎么选）。

**防未来 / 防偷看**：排名/入场/基准全部只用 ≤D（及 D+1 OHLC）数据；限价成交用当日 low/open 判触及；
基准 = 当日全A等权。规则先于跑写死；**绝不对通鼎互联/双星新材/奥士康这三只例子调参**；
walk-forward + 时间序 OOS + 参数高原（TopN∈{5,10,20}、入场三口径、续持两模式）。

## ② 数据与口径

- 样本区间：决策日 2019-01-01 ~ 2026-09-15，全A **5563** 只，流动性门后每日横截面 TopN 从
  近20日均额≥2亿元的票中取。全A执行日历约 **2076** 个决策日。
- 成交口径：完全沿用 `2026-09-15 次日α诊断` 的 nextday 内核（`marketable` 成交、涨停不可买、
  10bps、全A等权 open→close 基准），代码复用 `tools/research/selection_alpha/nextday_kernel.py`。
- 组合口径：**N 槽等权**（空槽记现金 0 收益），逐日 mark-to-close 组合净值 → 回撤；逐笔 round-trip
  记胜率与 net；换手 = 日均新建仓数 / N。期末仍持有的仓按最后收盘清算入逐笔。
- α（辅）：逐笔 net − 持有期全A等权累计（近似）；KPI 仍以**绝对净收益**为纲。

## ⑥ 诚实边界

- **幸存者偏差（重）**：票池 = **当前**主档 5563 只（活到 2026 的幸存者），历史 TopN 天然偏向"后来
  没退市/没爆的"票 → **绝对收益量级被系统性高估**（baseline 年化看着很高不可尽信）。**H1 的相对
  结论（treatment vs baseline）在同票池同区间内对冲了大部分幸存者偏差，比绝对量级稳健得多。**
- **涨停不可买**：已按板 10/20% 近似剔除次日一字/接近涨停开盘；ST(5%) 无法由 code 判、按板近似。
- **成本敏感性**：10bps round-trip 为近似；treatment 换手更低（这点对它有利），但仍不改结论方向。
- **持续型视图的代表性**：主证据是动量视图（可全A重算）；合议视图受算力限制只在子样本确认；
  S05/趋势模板为信号型未纳入 TopN 续选测试（H2 单独覆盖 S05 强势票）。
- **卖出线是机械定义**（盈亏平衡+仍在TopN），非 live 逐票目标价；已用 `topn_only` 稳健性对照排除
  "是止损设定不当导致"的可能。
