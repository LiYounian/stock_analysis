## 逐条质证(按你请审的 5 个点 + 我补的)

### ① Novelty:是否真不撞车 —— ✅ 认可,但补一个"隐性撞车"警告
数据维度确实新,机制与 0–9 不重叠,这点我认。**但要警惕与项目已证伪结论的"隐性同源"**:本策略的收益来源本质是"涨停后情绪溢价的次日均值回归"= **反转**。项目 C-2(反转照妖镜)已证:反转账面 IC 显著正,但**净成本后≈0,且 edge 在流动性前 50% 直接归零——全部集中在垃圾小盘**。首板回调票**天生就是小盘/高换手/游资票**,结构上正落在反转 edge 所在、且已被证"不可交易"的那块区域。→ novelty 不撞,但**经济来源可能撞在已知的不可交易陷阱上**。这不是否定,是把 ② 的举证责任顶到最前面。

### ② 理论是否自洽 —— 🟡 部分自洽,但借用了"不完全适用"的证据
- "买回调=在反转市里做反转"的框架**方向上**成立,叙事漂亮。
- **但项目验证过的反转是"横截面 5–20 日反转"**(策略4 IC、rev_mom),而本策略是**单只票、单日事件(T+1开盘→T+2开盘)**。两者时间尺度和机制并不等价——你不能拿"5–20日横截面反转成立"直接推出"首板次日1日回调有edge"。**这条 edge 必须自己独立证,不能搭反转的便车。** 请在草案里把这句挑明,别让理论显得比证据强。
- 浮筹真空/情绪溢价的机制描述合理,属"可能有 edge",接受进回测检验。

### ③ §2.3 可交易性是否真堵死"买不进" —— 🟡 买入侧堵住了,**卖出侧有对称漏洞**
- 买入侧(排一字/续板/高开秒板 + 成交概率折算):**堵住了,认可。**
- **漏洞:卖出侧未对称处理。** E-base"T+2 开盘无条件卖出"——若 T+2 一字跌停 / 停牌,**卖不出**,和"一字买不进"是同一类不可成交,但草案只折算了买入侧。**要求:卖出侧同样做成交概率折算**(T+2 开盘若跌停/停牌则顺延到可成交日,并如实计入这段额外损益)。否则会系统性高估(专挑最坏的次日,恰恰卖不掉)。

### ④ §5.1 预注册判定是否够硬 —— 🔴 有两处软肋,必须收紧
- **[硬] H1 判定太软**:"均收益 > 0 且 t 显著"——**牛市里买啥都>0**,绝对正收益 ≠ edge。必须改成**相对同期基准的超额收益 > 0 且显著**。对照基准建议二选一并预注册死:①全A 同持有期等权;②"符合 S1–S5 但**不看 r、机械 T+1 开盘买**"的首板全集(这样测的才是"回调择时"本身的增量,而非"首板"本身的beta)。**强烈建议用②**,能干净分离"回调择时"的贡献。
- **[硬] 多重检验没锁死**:E-base/E-cont × 4 档滑点 × 3 regime × 板块 × 市值 = 十几个切片,总有一个好看。**预注册必须写死:成立判定只认主口径(E-base + 0.20%滑点 + 全A),其余切片一律"仅描述、不作成立依据"。** 否则 §5.1 再硬也留了事后挑说法的后门。
- H2/H4/H5 判据本身够硬,认可。H3"退潮段≤强/中段"几乎机械成立、偏软,真正的检验是"加门 vs 不加门同一样本 Sharpe 提升",请把后者设为 H3 的主判据。

### ⑤ 过拟合陷阱是否遗漏 —— 补 3 条
- **[硬/数据] 双重幸存者偏差**:涨停家数 / 连板高度 / 晋级率 / 票池**必须 point-in-time 含当日已退市/已ST股**。若票池只有"当前仍上市"的股,情绪周期指标和信号样本会双重高估(退潮期爆雷退市的票被抹掉)。请与回测工程师确认历史票池是否含退市股;不含则此偏差需显式声明并评估方向。
- **[澄清] OOS 不是真盲样本外**:华安研报**已经**报过 2024–2025 样本外成功,你是"看着这段 work 才选的这个策略"。所以 H5 的 2024–2026 OOS **说服力要打折**——它检验的是"我能否复现研报",不是"盲测未知未来"。请在草案诚实标注这一点(不影响做,影响解读权重)。真·未来样本只能靠上线后跟踪。
- **[提示] 晋级率/连板高度计算复杂,易引入未来函数**:regime 用 T 日收盘数据门控 T+1 入场,时序上 OK;但"晋级"要跨日追踪每只票的连板计数,实现时注意别用到 t 之后。请单测锁死(和主信号同标准)。

### ⑥ 我额外的核心担忧:换手/容量/成本三角(和 H4 强绑定)
持仓 1 日 ⇒ **年换手 ~250x**。单边 0.20%滑点 + 双边佣金0.05% + 卖出印花0.05%,**单笔 round-trip 成本 ~0.5%**。若单笔均收益本就在 0.5–1% 量级,成本吃掉一半以上;再叠加 5000 万成交额上限(容量本就小),**即使统计显著,可部署净 alpha 也可能所剩无几**。
- **要求回测额外给两张图**:①**扣费后单笔净收益分布**(不只均值/t,要看分布和尾部);②**容量–收益曲线**(把成交额门槛从 5000万 抬到 1亿/2亿,看 edge 是否随可交易性上升而消失——这正是复刻 C-2 照妖镜"流动性前50% edge归零"的关键检验)。
- 5000 万门槛我认为**偏低**,建议主口径同时报一个"流通市值/成交额前 50%"的子样本(对齐照妖镜口径),这是判 H4 生死的关键切面。
