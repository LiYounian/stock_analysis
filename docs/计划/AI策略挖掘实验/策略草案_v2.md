## 0. 一句话与"为什么新"(v1 保留,补隐性同源警告)

**一句话**:对 T 日首次涨停(首板)、且为**换手板(非一字)**的强势股,**不追涨**,在 **T+1 开盘回调到 r∈[−5%,+3%] 时低吸**,默认持仓 1 日(上限 5 日);用**全市场情绪周期(涨停家数/连板高度/晋级率)当总开关**,退潮期空仓。

**新在哪(机制/维度/哲学,详见 v1 §0 对比表,结论不变)**:用「涨停结构+情绪周期」两个 0–9 与 roadmap 全未触碰的维度;入场哲学(回调不追)与策略4/7/8(追强)相反。

**⚠️ 隐性同源警告(审判者①,写进明处)**:本策略收益的**经济来源本质是"涨停后情绪溢价的次日均值回归"= 一种反转**。项目 C-2(反转照妖镜)已证:反转账面 IC 显著,但**净成本后≈0、且 edge 全集中在流动性前 50% 以外的垃圾小盘**。首板回调票**天生小盘/高换手**,结构上正落在那块"不可交易"区域。→ novelty 不撞,但**经济来源可能撞进已知的不可交易陷阱**。这不是否定,是把"可交易性举证"顶到最前(§5.2 H6 就是为回答这个而设)。

## 1. 理论逻辑(补:独立自证声明,不搭反转便车)

1. **浮筹真空 + 情绪溢价**:首板锁仓当日获利盘被锁在板上、可流通浮筹骤减;次日情绪买盘常以高开表达,缺承接时高开回吐——这段回吐是低吸窗口。
2. **方向直觉(仅直觉,非证据)**:A股短期是反转市(项目已证策略4 动量 IC 显著负),故追涨(动量)在反转市里必亏;买涨停后的次日回调=方向上与反转一致,解释"为何不追涨"。
3. **情绪周期调制**:打板类收益强依赖 regime,退潮期亏钱,用连板梯队/晋级率量化 regime 当开关切掉退潮段。

**独立自证声明(审判者⑤)**:项目验证过的反转是**横截面 5–20 日反转**(策略4 IC、rev_mom);本策略是**单只票、单日事件(T+1开盘→T+2开盘)**。两者时间尺度与机制**不等价**,**不能用"横截面反转成立"推出"首板次日 1 日回调有 edge"**。本策略的 edge **必须由本次回测独立证明**,理论只给"可能有 edge + 为何不追涨"的方向直觉,不作 edge 存在的证据。

## 2. 信号定义(精确、防未来函数)

记 T 日=触发日,整数索引 t;只用 `kdf.iloc[:t+1]`,入场锚 T+1,严禁引入 t 之后数据。全部前复权(qfq)。阈值全进 `THRESHOLDS["首板回调"]`。

### 2.1 涨停判定(board-aware,自算)

```
主板(60/00):                pct_chg ≥ +9.8%
创业板(30):  date≥2020-08-24 → ≥+19.8%;否则 → ≥+9.8%
科创板(688): ≥+19.8%(2019-07-22 起 20%)
ST/*ST(名称含 ST):         v1/v2 直接排除(±5% 制度特殊,样本脏)
北交所(8/4):               已被 universe 排除
```

### 2.2 SELECT(T 日入池)

```
S1 首板:      T 日涨停 且 T-1 日非涨停
S2 换手板:    T 日 low < 涨停价  且  T 日换手率 ≥ 1%      # 排一字板 + 流动性下限
S3 非高位末端:T 日前 20 交易日累计涨幅 ≤ 20%
S4 流动性:    T 日成交额 ≥ 5000 万元(硬下限;主口径另报"成交额前50%"子样本,见 §5.2)
S5 非次新:    上市交易日 ≥ 60
SELECT = S1 ∧ S2 ∧ S3 ∧ S4 ∧ S5
```

### 2.3 T+1 开盘条件入场(可交易性核心 · 买入侧)

`P0 = T 日收盘`,`r = (T+1 开盘 − P0)/P0`:

```
入场 ⟺ r ∈ [−5%, +3%]   → T+1 开盘价买入(叠加滑点,§5)
r > +3%  → 放弃(高开/一字续板/秒板 = 追涨且买不进,自动排除)
r < −5%  → 放弃(次日破位,情绪崩)
```

### 2.4 离场(两口径 · 卖出侧对称成交概率折算)(审判者③)

- **E-base(主口径)**:买入后 **T+2 开盘卖出**(持仓 1 日)。
- **E-cont(次口径,仅描述)**:当日收涨停则持有,否则次日开盘卖;上限 5 交易日强平;任意日收盘 ≤ 买价×0.92 次日开盘止损。

**卖出侧成交概率折算(两口径通用,硬要求)**:计划卖出日若 **一字跌停(open==high==low==跌停价)或停牌(无 bar)→ 当日卖不出**,顺延至下一"可成交日"(非一字跌停且有 bar)的开盘卖出,**如实计入这段被迫持有的额外损益**。买入侧同理(r>+3% 已在 §2.3 排除,属不可成交样本,不计入可下单集)。**买卖两侧都要报成交概率折算比例。**

## 3. 情绪周期门(regime 总开关)

全市场横截面,逐日从 pct_chg 自算(零外部依赖):

```
N_lu   = 当日涨停家数(全A,§2.1 口径,point-in-time 含当日在市股,见 §5.4)
H_max  = 当日最高连板高度
晋级率 = 昨日 k 板中今日晋级 (k+1) 板的比例
```

**三态(粗粒度,只做二/三值开关,不精细调参)**:

```
强(放开):   N_lu ≥ 60 且 晋级率 ≥ 其 60 日中位
中性(放开): 30 ≤ N_lu < 60
弱/退潮(空仓): N_lu < 30 或 H_max 较昨日下降 ≥ 2(断板回落)
```

**用法**:仅 regime∈{强,中性} 时允许 §2 开仓。**未来函数红线(审判者⑤补)**:晋级率/连板高度需跨日追踪每票连板计数,实现只用 t 及之前;用 T 日收盘 regime 门控 T+1 入场(时序 OK);**单测锁死**"构造 t 之后极端数据不改变 T 时刻 regime 与信号"(与主信号同标准)。

## 5. 回测方案(预注册 · 交回测工程师)

**类型**:信号型+事件驱动,自定义 T+1 开盘条件入场(§2.3)+§2.4 状态机;建议改 `backtest_s02.py`/`event_study.py` 骨架的入场锚。基准与票池见下。

### 5.0 多重检验锁死(审判者② · 硬)

**成立判定只认【主口径】**:`E-base + 单边 0.20% 滑点 + 全A(排ST/次新)+ regime门开 + 相对"首板全集基线"超额`。
其余一切切片(E-cont、其他滑点档、分 regime、分板块、分市值、容量曲线)**一律仅描述、不作成立依据**。**唯一例外**:H6 的"可交易流动性层"是**预注册的独立主问题**(见 §5.2),与主口径并列,不算事后挑切片。

### 5.1 预注册假设与判定(结论前写死)

**两个对照基线(都预注册)**:
- **基线A(核心,分离回调择时)**:符合 S1–S5、**同样开 regime门、但忽略 r 条件、机械 T+1 开盘买入**的首板全集。DB01 与基线A **只差 r 过滤**,故其差=**回调择时的净增量**。
- **基线B(beta 参照)**:沪深300 同持有期等权。

| 编号 | 假设 | 判定"成立" | 判定"否定" |
|---|---|---|---|
| H1 | 回调择时有增量 | 主口径 **相对基线A 的超额 > 0 且 t 显著(p<0.05)** | 超额 ≤ 0 或 p≥0.05 |
| H2 | 是 alpha 不是 beta | 与沪深300 相关系数 < 0.3 | ≥ 0.3 |
| H3 | 情绪周期门有用 | **加门 vs 不加门 同样本 Sharpe 提升**(主判据) | 门不改善或反向 |
| H4 | 成本存活(全A) | 主口径 0.20%/side 下扣费净均超额 > 0 | 仅 0 滑点为正、0.20% 转负 |
| H5 | 样本外方向一致 | OOS(2024–2026)超额>0 且方向与样本内一致(**权重打折,见 §5.3**) | OOS 转负 |
| **H6** | **可交易层存活(命门)** | **成交额前 50%(或≥1亿)子样本,扣费后净超额仍显著>0** | edge 只存在于成交额后 50% 尾部 → 判"账面真·不可交易" |

**成立门槛(新且经回测检验)= H1 ∧ H4 ∧ H5 ∧ H6 同时成立。** H2 佐证、H3 加分(影响部署形态,非成立必需)。
**诚实前置**:若 H1 成立但 **H6 否定**(edge 只在不可交易尾部)→ 与项目 C-2 反转结论同类,**判"账面真·不可交易",诚实记录**(挡下一个上线会亏的策略,有价值)。若 H1/H5 直接否定→草案不成立,迭代或换向。

### 5.2 照妖镜分层 + 容量曲线(审判者④⑥ · 硬)

除主口径外**必须**产出:
1. **扣费后单笔净收益分布**:直方图 + 尾部分位(不只均值/t),看是否少数极端标的主导。
2. **容量–收益曲线**:成交额门槛 5000万→1亿→2亿→按成交额/流通市值分 5 层,报每层扣费后净超额,**看 edge 是否随可交易性上升而消失**(复刻 C-2"流动性前 50% edge 归零"检验)。
3. **换手/容量/成本三角**:持仓 1 日 ⇒ 年换手 ~250x,单笔 round-trip 成本 ~0.5%(0.2%×2 滑点+0.05%佣金+0.05%印花);报**净超额 / 成本 的倍数**,量化可部署空间。

### 5.3 OOS 诚实标注(审判者⑥)

2024–2026 已被华安研报报过样本外成功,**本策略是"看着这段 work 才选的"→ 2024–2026 是"复现研报"的准样本外,不是盲测未知未来**,H5 说服力打折。缓解:**保留最近可得段(如 2026 年至今)作更盲 holdout 单独报**;真·盲测只能靠上线后跟踪。样本内建议 2018–2023。

### 5.4 数据要求(审判者⑦ · 待回测工程师确认)

- 票池 / 涨停家数 / 连板高度 / 晋级率 **须 point-in-time 含当日已退市/已 ST 股**;否则退潮期爆雷退市票被抹→情绪指标与信号样本**双重高估**。**请回测工程师确认历史票池是否含退市股**;不含则显式声明该偏差(方向=高估 edge),并评估量级。
- 成本按日期精确:印花税 2023-08 起 0.05%、之前 0.10%。

**指标**:笔数 N、胜率、均超额、中位、盈亏比、相对基线A/沪深300 超额、与大盘相关系数、等权组合日频 Sharpe/最大回撤、t/p;买卖两侧成交概率折算比例;全 slippage sweep 表;§5.2 三张分层图。
