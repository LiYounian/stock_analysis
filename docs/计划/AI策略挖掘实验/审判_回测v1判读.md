### A. 口径核验(我 sign-off 过的 3 项,逐条对)
- **注记1 同口径扣费**:✓ DB01 与基线A 完全同成本模型;报告"毛超额≈净超额(+0.037%)"正是同成本抵消的佐证 → H1 的超额是干净的"回调择时净增量",不掺成本噪声。
- **H6 照妖镜分层**:✓ 成交额分层 + 容量曲线,口径对齐 C-2。
- **退市股幸存者偏差**:✓ 诚实前置声明到位,方向=高估,且按我写死的不对称规则处理(负结论稳健、方向不因偏差反转)。
- **ST 边界(小瑕疵,不影响结论)**:报告写了制度阈值+动态护栏,但未显式点"创业板/科创板 ±20% ST 少量残漏"。因该残漏与幸存者偏差同向(上偏)、且主结论为否定,不影响裁决。记为诚实完整性的小改进项,不返工。

### B. Sign-flip / bug 排查(负结果是真信号还是实现错误?)
- **双向一致**:DB01(−0.85%)与基线A(−0.88%)都净亏,首板次日毛均 −0.27% 亦为负 → 若是做多/做空写反的 sign-flip,首板应显著为正;实际两条腿一致为负,排除 sign-flip。
- **经济可解释**:买 T+1 开盘、卖 T+2 开盘,首板次日情绪溢价向下回归、做多恰好吃到下行;胜率 35.9%(彩票式打板,右尾 p99+15.8% 撑均值,主体亏)——与 A股"追涨杀跌"现实、与项目 C-2 反转结论同向,非反常。
- **数值自洽**:净 −0.85%/std~4.8%/N=27,745 → t≈−29 量级对得上;容量曲线随可交易性上升单调转负(大盘票打板溢价更小、可回归的更少)经济可解释;maxdd −100% 与逐笔期望为负的复利归零一致。
- **纪律到位**:11 断言测试含防未来函数/成本/成交折算/ST护栏/判定门槛,全过。
- **结论**:内部一致、经济可解释、无 bug 迹象。不对称规则下(偏差=高估),**负结论稳健**——真实只会更差。

### C. 与我预注册担忧的对账
我在审判 v1/v2 反复标注的"**隐性同源 = 反转不可交易陷阱(C-2)**"被数据**以更强形式证实**:不是"edge 只活在不可交易尾部",而是**全流动性层皆无 edge**,且**可交易区间(≥2亿)是负增量**。命门 H6 检验结构有效——正是它把"看着能做的打板回调"钉死为"根本没有正 edge"。这是一次有价值的诚实否定(挡下上线必亏策略)。

## 对后续方向的判读(重要:DB01 否定如何影响 v3)

1. **DB01 结案,不在现结构上调参救**。与回测工程师一致:换持有期/离场/滑点档都救不了"根本没有正 edge + 情绪门有害 + 非 beta 独立"的三重否定。E-cont 次口径不必补跑(核心经济来源已否定,大概率同类;若挖掘者坚持可补,仅描述不改结论)。DB01 的 H6 结论存入技术基座知识库,单独回答了项目一直想知道的"纯技术首板回调可交易性"。

2. **这个否定其实强化了我们已定的 v3 pivot**。v3 已改基座 = **S01 深跌/破位弱势点 + 消息面修正层**(命中用户点1"挖弱势"+点3"解老难题")。DB01(强势首板打板)恰是照妖镜杀死的那类纯技术事件策略;pivot 到"攻弱势/破位侧 + 叠加量价捕捉不到的消息面维度"是对的方向响应。

3. **★关键预期管理★:不要期待 v3 的破位技术基座单独有历史 alpha。** DB01 否定 + S01 已知弱(12.6%),两者合起来说明:**纯量价的破位反包基座单独几乎肯定也弱**。这是**预期之内、可接受**的——v3 的整个赌注不在"技术基座有 alpha",而在"**消息面修正能否可测地把弱基座救起来**(真破位规避 / 假破位低吸)"。因此 v3 判据必须据此结构化:
   - 技术基座:诚实报其(弱)base-rate + 照妖镜可交易性,**作对照锚**,不当 alpha 源;
   - 消息面修正层:判据 = "**加消息面修正 vs 不加**,方向性/前向验证上是否可测改善",而非"基座是否历史显著为正"。
   - 这与不对称尺子一致:技术侧可回测(哪怕弱)、消息侧诚实前向。
