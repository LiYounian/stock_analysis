## 逐条质证(挖掘者请审的 5 点 + 我补的关键要点)

### ① Novelty / 与 roadmap PEAD 正交性 —— ✅ 讲清了,认可
PEAD trade 的是超预期**漂移**(可 trade 的信号本身);本策略把"结构性实质利空是否存在"当作**技术破位真假的判别器**(filter/classifier),不 trade 业绩事件本身,方向相反(避真崩/买洗盘)。机制正交,不撞车。**补一句提醒**:v3 的 Layer1 SELECT 就是策略1/S01 本身,所以**全部新意集中在 Layer2 消息面修正**——这意味着"命中北极星且有证据"完全押在 Tier A 的 H-A1 上。若 Tier A 否定且 Tier B 样本≈0,v3 就没有已验证的新意(只是 S01+一个未验证想法)。诚实否定路径已覆盖此情形,但要清楚:**H-A1 是这版命中北极星的全部赌注**。

### ② 业绩预告作"结构性利空代理"是否 economically 站得住 —— 🟡 站得住,但有两个我补的要点必须处理
- **站得住**:业绩预告实质利空(预亏/首亏/续亏/净利同比大幅下滑)是**基本面结构性负面**,不是情绪噪声。用它区分"这个深跌是真基本面恶化(避)还是无实质利空(可能洗盘,买)"——正是量价看不见、消息面天生能补的变量。
- **★补1:下界性质其实是设计优点(保守偏向)★**:草案诚实标了 Tier A 是判别力**下界**(违规/减持/商誉/诉讼等非业绩结构性利空抓不到)。**关键推论**:这些漏网的真破位会混进"无利空组"、**拖低**其收益 → 使 H-A1 **更难通过**。所以偏向是**保守**的:**H-A1 若通过 = 可信(真信号强到扛住污染);若不过 = 含糊(可能真无效,也可能被污染冲淡)**。这点要写进判读预案。
- **★补2:业绩利空的时间聚集混杂★**:业绩预告集中在报告期公告季(1月年报预告等),所以"有利空组"破位**时间上高度聚集**在特定窗口。若这些窗口的市场 regime 系统性不同(如公告季破位更多/更弱),有/无利空组的差异可能**混入时间效应而非利空效应**。**要求**:报两组的时间分布;稳健性做"同日历窗口内 有利空 vs 无利空"对比,确认 H-A1 效应不是伪装的时间效应。

### ③ H-A1 / H-A2 够硬吗、有无事后找说法 —— 🟡 大体硬,但要加 2 个锁 + 明确 H-A2 量级天生受限
- **★补3:H-A2 增量在构造上就小★**:多数破位无业绩利空 → 利空组稀疏 → "无利空组 ≈ 全集",剔除一小撮坏样本对 baseline 的提升**天生很小**(利空组占比 × 其拖累)。即便修正真有效,H-A2 增量也可能 economically 微小、难显著。**推论**:**命中北极星的科学证据主要在 H-A1(能否显著区分真假),不在 H-A2 的大小**;H-A2 是可部署性 reality check。判读时别因"H-A2 增量小"就否定命中北极星——见结果树。
- **锁1:冻结利空类型清单**。草案清单混了严重(预亏/首亏/续亏)与轻微(略减/预减)。**开跑前冻结**这份清单 + 净利同比阈值(−50%);severity 分组(如只看预亏)只能**描述性**看,不得用来挑最好看的切法。否则留"H-A1 若剔除略减就成立"的事后后门。
- **锁2:预注册结果树(防挪门柱)**。三种结局出结果前写死:
  - **H-A1 否定** → 消息面连真假都分不出 → 概念失败,诚实否定。
  - **H-A1 成立 ∧ H-A2 否定** → 消息面**能显著区分**真假(**北极星命中!概念被回测证明**),但无利空组扣费后仍不可交易(反转不可交易,同 C-2)→ **概念成立但不可部署,仍是有价值的真发现**(证明了技术×消息融合的判别机制),明确区别于双否定。
  - **H-A1 成立 ∧ H-A2 成立** → 概念 + 可部署双成立,最佳。
  草案现"成立=H-A1∧H-A2"我认可(保守),但上面结果树的中间态必须预注册为"命中北极星",不许事后贬为失败。

### ④ point-in-time(公告日)红线是否堵死前视 —— 🟡 红线找对了,但有个数据命门必须先验证
- 草案正确抓住命门:用**公告日 notice_date ≤ T**、不用报告期、单测锁死。方向对。
- **★补4:notice_date 可得性是 Tier A 生死门,须回测工程师开跑前先验证★**:
  - akshare `stock_yjyg_em` 是否**真返回可靠的公告日**?若它只给报告期、公告日靠推断 → point-in-time 完整性崩塌 → Tier A 不可信,**降级为前向**(同 Tier B)。这是开跑第一步的确认门。
  - **必须用首次公告版本,不用修正后版本**(业绩预告会修正,用最新版=前视)。
  - 预告/快报/正式财报各有各的公告日,分别对齐到各自 notice_date。
  → **确认 notice_date 干净可得,Tier A 才算"可历史回测";否则老实说 Tier A 也只能前向。**

### ⑤ 基座 S01破位 vs DB01首板 —— ✅ 确认 S01破位(逻辑闭合,比之前更强)
之前我已让步采 S01;草案给了更强的收敛论证:**"结构性利空区分真假破位"这个修正机制只在弱势/破位 setup 下才有意义——强势股首板(DB01)根本没有"破位真假"可言**。数据现实 + 机制双重强制基座=S01破位。完全认可。DB01 继续作纯量价并行候选,不代表北极星方向(与 DB01 判读一致)。
