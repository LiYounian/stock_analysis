## 0. 一句话与为什么"新"

**一句话**:对 T 日首次涨停(首板)、且为**换手板(非一字)**的强势股,**不追涨**,而是在 **T+1 开盘回调到平开附近时低吸**,吃"涨停后情绪溢价的次日均值回归",默认持仓 1 日(上限 5 日);并用**全市场情绪周期(涨停家数/连板高度/晋级率)当总开关**,只在情绪启动/主升期开仓、退潮期空仓。

**为什么这是"新"的(与现有策略 0–9 + 独立工具的机制区分,预先堵审判者的"撞车"质疑):**

| 现有 | 它做什么 | 本策略如何不同 |
|---|---|---|
| 策略4 动量组合 | 横截面**追**最强动量,已验证 A股短期反转→IC 显著为负、上线会亏 | 本策略**反其道**:不追涨,买 T+1 **回调**。把"A股短期反转"这个杀死动量的事实**从负债变成 edge**——涨停是离散强度事件,次日高开溢价倾向回吐,买回调=顺着反转方向做,理论自洽 |
| 策略7/8 放量/最大范围看多 | 量能算子并集看多;策略8 已证"低位放量无 edge" | 本策略核心**不是放量信号**,是"**价格触及涨跌停这一离散制度事件** + 次日回调择时 + 情绪周期门";入场哲学(回调不追)与 7/8(追强)相反 |
| 策略3 箱体突破 | 横盘后**突破追买** | 本策略是涨停后**回调低吸**,方向相反 |
| SEPA / 趋势模板 | 中期趋势过滤门 | 本策略是 1 日级事件短线,时间尺度不同 |
| roadmap 已占 | PEAD 事件驱动 / 增持回购 / RRG / 北向(并入多因子) | 本策略**不碰**财报/一致预期/行业轮动/北向,走的是**涨停结构 + 情绪周期**这条现有策略与 roadmap 全未触碰的维度 |

**数据维度也是新的**:现有 0–9 没有任何一个用"涨停/连板结构"或"全市场情绪周期"作信号,本策略两者都用,且**当前免费数据即可回测**(见 §6)。

## 1. 理论逻辑(为什么可能有 edge)

1. **浮筹真空 + 情绪溢价**:首板锁仓当日,获利盘被"锁"在板上,可流通浮筹骤减;次日情绪买盘常以高开表达,但缺乏承接时高开会回吐——这段回吐正是低吸窗口。
2. **反转市顺势而为**:项目已用数据证明 A股短期是反转市(策略4 动量 IC 显著负、纯反转账面真)。追涨(动量)在反转市里必亏;**买涨停后的次日回调 = 在反转市里做反转**,方向一致。这解释了为何"打板追涨"多数散户亏、而"回调低吸"可能有结构性 edge。
3. **情绪周期调制**:打板类收益强依赖市场情绪 regime(启动/主升期赚钱、退潮期亏钱)。用连板梯队与晋级率量化 regime 当开关,把最亏钱的退潮段切出去。

**外部证据(仅供参考,需自证,勿直接采信)**:华安证券金融工程 2026-03 专题「涨停板背后的 Alpha·首板回调」(样本 32,615 首板)口径:样本内 2021–2023 年化 18.21%/Sharpe 1.09、**样本外 2024–2025 年化 20.72%/Sharpe 1.13(样本外未衰减)**、**与大盘相关系数仅 0.14(收益来自选股非 beta)**。**但成本极敏感:零滑点总收益 151.6%,单边 0.30% 滑点后骤降到 18.4%**——这是本类策略的生死线,回测口径必须悲观。来源:新浪财经转载华安证券研报。

## 2. 信号定义(精确、可复现、防未来函数)

记 T 日 = 触发日,整数索引 t;所有量只用 `kdf.iloc[:t+1]`(闭区间 [0,t]),入场锚 T+1,严禁引入 t 之后数据。全部前复权(qfq)。

### 2.1 涨停判定(board-aware,自算,无需外部涨停池)

用 `pct_chg`(或 `close/pre_close-1`)配合板块阈值,留 rounding 容差:

```
主板(代码 60/00 开头):        涨停 ⟺ pct_chg ≥ +9.8%
创业板(30 开头):
    date ≥ 2020-08-24:         涨停 ⟺ pct_chg ≥ +19.8%
    date <  2020-08-24:        涨停 ⟺ pct_chg ≥ +9.8%
科创板(688 开头):             涨停 ⟺ pct_chg ≥ +19.8%   (2019-07-22 起 20%)
ST/*ST(名称含 ST):            本 v1 直接排除(±5% 制度特殊,样本脏,单列不做)
北交所(8/4 开头):             已被 universe 排除
```

### 2.2 首板 + 换手板 + 高位过滤(SELECT 条件)

```
S1 首板:      T 日涨停(§2.1) 且 T-1 日非涨停          # 首次触板,非连板途中
S2 换手板:    T 日 low < 涨停价                          # 盘中曾跌破板 = 有换手,排除一字板
              且 T 日 换手率 ≥ 1%                         # 流动性/浮筹下限(容量诚实)
S3 非高位末端:T 日前 20 个交易日累计涨幅 ≤ 20%           # 排除接力末端的高位首板(研报口径)
S4 流动性:    T 日成交额 ≥ 5000 万元                     # 可交易 + 容量约束(小市值诚实)
S5 非次新:    上市交易日 ≥ 60                            # 排除上市初期无涨跌停/极端波动
SELECT(T 日入池) = S1 ∧ S2 ∧ S3 ∧ S4 ∧ S5
```

阈值全部进 `THRESHOLDS["首板回调"]`,不散写硬编码;上表数字为**预注册初值**,回测做敏感性但不精细调参(防过拟合)。

### 2.3 T+1 开盘条件入场(可交易性的核心)

令 `P0 = T 日收盘价`(≈涨停价),`r = (T+1 开盘 − P0)/P0`:

```
入场 ⟺ r ∈ [−5%, +3%]     → 以 T+1 开盘价买入(集合竞价可成交的真实价)
r > +3%   → 放弃(高开/一字续板,追涨=回到动量,已知会亏;且续板买不进)
r < −5%   → 放弃(次日直接破位,情绪已崩)
```

**为什么这样就把"不可交易"堵死了**:一字续板 / 高开秒板的次日开盘 r 必然 > +3%,被自动排除——**本策略天然只买"买得进"的回调票**,不会像很多打板回测那样把"其实封死买不进"的涨停算进收益。

### 2.4 离场(两个预注册变体,机械基线)

- **E-base(主口径,最简)**:T+1 开盘买入后,**T+2 开盘无条件卖出**(持仓 1 日,对应研报"91% 只持 1 日")。
- **E-cont(次口径,吃续板)**:买入后若当日收涨停则持有,否则次日开盘卖;**上限 5 个交易日强制平仓**;任意日收盘 ≤ 买入价 × 0.92 则次日开盘止损。

两口径都逐日机械执行、无盘中数据依赖(纯日线可复现)。E-base 为主口径下结论,E-cont 作对照。

## 3. 情绪周期门(方向三 · regime 总开关)

全市场横截面,逐日从 pct_chg 自算(零外部依赖):

```
N_lu   = 当日涨停家数(全A,§2.1 口径)
H_max  = 当日最高连板高度
晋级率 = 昨日 k 板中今日成功晋级 (k+1) 板的比例(资金接力意愿的核心动量)
```

**三态 regime(粗粒度,防过拟合;只做二/三值开关,不精细调参)**:

```
强(放开满仓):  N_lu ≥ 60  且  晋级率 ≥ 其 60 日中位
中性(放开):    30 ≤ N_lu < 60
弱/退潮(空仓):  N_lu < 30  或  H_max 断板回落(最高板较昨日下降 ≥ 2)
```

**用法**:仅当 regime ∈ {强, 中性} 时才允许 §2 的开仓;退潮期空仓。回测须**分 regime 拆开报收益**(验证退潮期确实拖累、门确实有用)。

## 5. 回测方案(交回测工程师 · 预注册)

**类型**:信号型 + 事件驱动。不能直接套 `position_backtest`(它是信号日**收盘**建仓),需**自定义 T+1 开盘条件入场**(§2.3),离场用 §2.4 状态机。建议复用 `backtest_s02.py` / `event_study.py` 骨架改入场锚。

**票池**:全A(已排北交所),排 ST、排上市<60 日、按 §2.2 S4 成交额门槛过滤。
**样本 / walk-forward**:样本内 2018–2023、**样本外 2024–2026** 分开报(对齐研报的样本外检验思路)。基准沪深300。
**成交概率折算**:统计"出信号且 r∈band 可成交"的比例,用可成交子集算收益(不可成交的不计入,诚实反映真实可下单集)。

**成本模型(生死线,必须显式且悲观)**:

```
佣金:双边各 0.025%(万2.5)
印花税:卖出 0.05%(2023-08 起;2023-08 前 0.10%,按日期精确)
过户费:双边各 0.001%(可忽略)
滑点:做 sweep —— 单边 0 / 0.10% / 0.20% / 0.30%
主口径:单边 0.20% 滑点(保守现实)
```

**指标(信号型口径)**:笔数 N、胜率、均收益、中位、盈亏比、相对沪深300 同持有期 Alpha、**与大盘相关系数**、等权组合日频 Sharpe 与最大回撤、t 值 / p 值;**并给全 slippage sweep 表**(展示 break-even 在哪)。分 regime、分板块、分市值再拆一版。

### 5.1 预注册假设与判定(结论前先写死,防事后找说法)

| 编号 | 假设 | 判定"成立" | 判定"否定" |
|---|---|---|---|
| H1 | 首板回调有正 edge | 主口径(0.20%滑点/E-base)均收益 > 0 **且** t 显著(p<0.05) | 均收益 ≤ 0 或 p≥0.05 |
| H2 | 是 alpha 不是 beta | 与沪深300 相关系数 < 0.3 | ≥ 0.3(疑似 beta) |
| H3 | 情绪周期门有用 | 退潮 regime 段均收益 ≤ 强/中段;加门后组合 Sharpe 提升 | 门不改善或反向 |
| H4 | 可交易(成本存活) | 0.20%/side 滑点下净均收益仍 > 0 | 仅 0 滑点为正、0.20% 转负 → **判"账面真·不可交易"** |
| H5 | 样本外不塌 | OOS(2024–2026)均收益 > 0 且方向与样本内一致 | OOS 转负 → 过拟合 |

**诚实前置声明**:若 H4 落到"账面真·不可交易",与项目已有的"短期反转不可交易"同类——**这也是有价值的诚实否定**(挡下一个上线会亏的策略),照实记录,不粉饰。若 H1/H5 直接否定,则本草案不成立,迭代或换向。

## 7. 已知风险与过拟合陷阱(诚实清单)

1. **成本/滑点是生死线**:研报口径 0.30%/side 即近乎归零。已用「T+1 开盘可成交价 + r≤+3% 只买买得进的 + slippage sweep + 成交概率折算」正面应对,但仍可能 H4 否定。
2. **容量小**:小市值首板流动性差,有效容量有限(研报口径 500 万–2000 万)。已加 5000 万成交额下限诚实约束,大资金不适用。
3. **regime 阈值漂移**:60/30 家、晋级率中位随年份漂移。已只做粗粒度三态、不精细调参;回测报敏感性但阈值不 fit。
4. **制度依赖**:涨停板制度一改(如全市场改 20%、注册制扩容)历史规律可能失效。
5. **一字/续板不可成交**:已用 r>+3% 排除 + 成交概率折算处理,防"账面买入实则买不进"虚高。
6. **前视/幸存者**:严格 [0,t]、用上市当时可交易票池、ST/次新排除;单测锁死"构造未来极端数据不改变 T 时刻信号"。
