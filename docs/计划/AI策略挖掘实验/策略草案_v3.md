## 0. 一句话与命中北极星

**一句话**:项目策略1(S01 深跌反包)曾以 **胜率仅 12.6%** 失败——根因是**纯量价分不清"强势股深跌破位"到底是"洗盘假破位(该低吸)"还是"消息驱动真破位(该规避)"**。本策略保留 S01 的技术破位点作**可回测技术基座**,叠加一层**消息面结构性实质利空修正层**来甄别真假破位:**无结构性实质利空的破位→判洗盘→低吸反包;有结构性实质利空的破位→判真崩→规避**。

**命中用户 4 条思路**:①挖掘弱势(破位=technical breakdown 点)✓;②融合消息面(评估该破位受消息面影响)✓;③**用消息面数值修正技术指标、解决以前没解决的问题(S01 老难题)** ✓✓(重点);④突破纯技术局限(补"缺真实世界动态"=消息)✓。

**为什么"新"**:0–9 与 roadmap 没有任何一个用"消息面数值去修正/甄别一个技术信号的真假"。这不是并列贴新闻标签,是**用消息面可测地改变技术信号的方向判定**。与 roadmap 的 PEAD(独立事件驱动、trade 超预期漂移,项目已证无稳定漂移)**机制不同**:本策略**不 trade 业绩超预期本身**,只把"结构性实质利空是否存在"当作**技术破位真假的判别器**——正交用法,不撞车。

## 2. 技术基座(Layer 1 · 可全历史回测 · 全套硬标准)

**破位点定义**(主口径直接复用项目策略1/S01 的 SELECT,使 baseline 可直接对标已知的 12.6% 失败):

```
C1 均线完整多头:MA5>MA10>MA20>MA30>MA60>MA200 且 收盘≥MA5      # 前期强势
C2 贴近52周高:  0.9×H52 ≤ 收盘 ≤ 1.2×H52
C3 近10日偏强:  近10根 收阳数 > 收阴数
C4 当日深跌收阳:(最低−前收)/前收 ≤ −4% 且 收盘>开盘           # 破位/深跌弱势点
破位点(T) = C1 ∧ C2 ∧ C3 ∧ C4
```

**基线前瞻收益**(event-study,复用 `forward_scorecard.py`/`event_study.py`):对每个破位点 T,算 T+1 开盘入场后 T+1..T+10 前瞻收益分布,相对沪深300 同持有期超额。严格 [0,t] 无未来函数;成本模型同 DB01(佣金双边0.025%、印花2023-08起0.05%、滑点sweep,主口径0.2%/side)。

**照妖镜纪律(技术侧不因消息面是主角就跳过诚实回测)**:破位=深跌/超跌,经济上是反转,**天然落在项目 C-2 反转照妖镜"流动性前50%外 edge 归零"的区域**(深跌票多是垃圾小盘)。故 Layer 1 的 base-rate **必须按 C-2 口径报**:扣费后净超额 + 按成交额/流通市值分层,明示技术基座本身的可交易性边界。这不是走过场——它决定了后面 Tier A 修正出来的"无利空组"是否也只活在不可交易尾部。

**Layer 1 预注册假设**:
- **T1(确认老问题存在)**:破位点全集前瞻超额 ≈0 或负、不显著(=纯量价无 edge,复现 S01 失败)。**这是"问题陈述"而非策略成败**——若基座本身就有 edge,反而说明破位点选得好;若无(预期如此),正说明"需要消息面来甄别"。
- 报 S01 状态机口径(胜率/盈亏比/即死率)作与旧结论的连续性对照。

## 3. 消息面结构性利空修正层(Layer 2 · 可插拔 · 判据分开写)

**修正机制(可测地改变信号,非贴标签)**:对每个技术破位点 T,判定"信号时点前是否存在结构性实质利空";据此把破位分成两组,**改变方向判定与是否入场**:

```
真破位(规避/不做多,可选看空研究)  ⟺  破位 ∧ 存在结构性实质利空
假破位(洗盘,低吸反包做多)          ⟺  破位 ∧ 无结构性实质利空(或仅短暂情绪扰动)
```

### 3.1 Tier A · 业绩预告结构性利空(✅ 可历史回测 · 机械 · 无需 LLM)

**结构性实质利空代理(point-in-time 机械口径 · 🔒锁2:开跑前冻结,看结果前锁定)**:破位点 T 时,**近 K=30 个交易日内**存在业绩预告/快报,公告日 ≤ T,且满足下列**任一**即判"有结构性实质利空":

```
公告日 ≤ T                                          # 严格 point-in-time:只用T日前已公告的
且 (  预告类型 ∈ {预亏, 首亏, 续亏}                  # (a) 亏损类 = 实质
   OR 净利润同比变动幅度 ≤ −50%  )                  # (b) 大幅下滑类(不论类型标签)
```

**🔒 锁2 冻结规则(防"剔除某类就成立"的事后后门)**:
- 上述 (a)∪(b) 是**唯一主口径定义**,连同 K=30、−50% 阈值**开跑前冻结**,看结果前不改。
- **明确排除主口径**:仅"略减/预减"且同比 > −50% 的轻微下滑 → **不算结构性实质利空**,归入"无利空组"(经济上"实质"=需足够量级,略减/预减不够)。
- **severity 敏感性(仅描述,不作成立依据)**:①更严(只看预亏)②更宽(把略减/预减也计入利空)—— 只报方向一致性,**严禁用来挑最好看的切法**。成立判据永远只认冻结的主口径。

> ⚠️ **point-in-time 命门**:必须用**公告日(notice_date)**对齐,**不是报告期**。信号日 T 只能"看见"在 T 日收盘前已公告的预告。破位常与利空公告near-simultaneous(市场对差业绩以破位反应),只要公告日≤T即合规;入场锚 T+1。单测锁死"构造 T 之后公告的预告不得改变 T 时刻的修正标签"。
>
> ⚠️ **"筛选码正确"≠"被筛数据 point-in-time"(审判者补,回测工程师须验证 akshare 3 事实)**:单测只锁过滤逻辑(notice_date≤T 筛选码),锁不住字段语义。真 point-in-time 还需工程师核实:(a) `notice_date` = **首次公告日**、非最后修正日(否则 D1 首发/D2 修正显示 D2,过滤被未来污染);(b) 用的预告类型/数值 = **该公告日当时公开值**、非后续修正值(源若只存报告期最终值,"略减→后修正预亏"会用未来信息误判,★单测抓不到★);(c) **无真实 notice_date 的记录必须丢弃**,不许从报告期推断(推断=前视或误排)。三验证 + 单测共同才堵死前视;任一不满足且绕不开 → Tier A 历史完整性受损,**如实向 forward 降级**。

**Tier A 预注册假设(扣费口径,p<0.05)**:
| 编号 | 假设 | 成立 | 否定 |
|---|---|---|---|
| H-A1 | 结构性利空能区分真假破位 | "无利空组"前瞻超额 **> "有利空组",且差异显著** | 两组无显著差异 |
| H-A2 | 修正带来真实增量(解老问题) | "无利空组(预测洗盘)"前瞻超额 **> 破位全集baseline 且扣费后 > 0** | 无利空组不优于baseline 或 扣费后≤0 |

**成立判据以 §4.1 预注册三态结果树为权威**(H-A1=①研究发现级成立=核心;H-A2=②可部署级,更高目标)。**H-A1 单独成立即命中北极星(S-2 态)**,不要求 H-A2 同时成立——详见 §4.1,此处不再重复定义避免歧义/挪门柱。
**样本护栏**:"有利空组"样本可能偏少(多数破位无 earnings 利空)→ 必报两组样本量;`有利空组` N<30 则该组仅描述、H-A1 标"待观察",但 H-A2(无利空组 vs baseline)仍可判。

### 3.2 Tier B · 泛新闻持续性修正(🟡 仅前向验证 · 预注册)

**用法**:从起记日起,对每个破位点 T 跑 `news_persistence.classify()`,按"结构性实质利空 vs (短暂事件/无)"二分修正;净情绪分仅作辅助特征(不作主判据)。

**Tier B 预注册前向协议**:
- **起记日**:v3 落地并接入 `forward_scorecard.py` 每日滚存之日(记为 D0,写死具体日期)。
- **样本阈值**:累计"可配 T+10 前瞻收益的有效破位观测 ≥ 100"才做统计判定(当前 r_10 有效观测=0,统计力≈0,诚实标注)。
- **判据**:达阈值时检验"无实质利空组前瞻超额 > 结构性利空组",方向与 Tier A 一致则互证。
- **早期(未达阈值)**:只给**逻辑级验证**(修正规则是否 economically 合理:该 fire 时是否正确 fire)+ 少数可得事件人工核对,给**方向性**结论,**明确标"待样本、暂无统计定论"**。
- **红线(判者)**:严格 point-in-time 只用信号日前已发布新闻;**禁补采历史新闻/用事后新闻**;净情绪分只作辅助。

### 3.3 可跑通性 / 优雅降级(判者第4点)

- 融合层**可插拔**:某破位点无业绩预告(Tier A 空)且无新闻(Tier B 空)→ 该点**回落为纯技术基座**处理(默认按"无结构性利空→洗盘→做多",因结构性利空是稀疏事件,缺失即视为无),**不报错不阻塞**。
- Tier A 立即可历史回测给数字;Tier B 前向累积;两层独立、互不阻塞。

## 4. 回测方案(交回测工程师 · 预注册 · 双层判据分开)

**类型**:信号型 + 事件研究。技术基座用 event-study 前瞻收益(`forward_scorecard.py`/`event_study.py`);Tier A 修正 = 破位点样本按"结构性利空标签"分组比较。

**票池**:全A(排北交所/ST/次新);成本按日期精确;滑点 sweep(主0.2%/side)。
**数据要求(待回测工程师确认)**:
- 业绩预告历史:`event_driven.py::fetch_earnings_forecast(period, kind)` 按报告期回补;**必须取到公告日 notice_date** 做 point-in-time 对齐(非报告期)。确认历史覆盖多少报告期/多少条。
- 破位点票池 point-in-time 含退市/ST 股(同 DB01 §5.4;不含则声明"高估edge"偏差方向)。
- **不对称幸存者偏差规则**(沿用 DB01 与审判者约定):结论为负→稳健直接认;为正→须先清幸存者偏差量级上界才敢定性。
- **🔒 时间聚集混杂控制(审判者补,必报)**:业绩利空聚集在报告期公告季,"有利空组/无利空组"的差异可能混入**时间效应**(如利空季恰逢弱市)。故必须:①报两组的**时间分布**;②做**同窗对比**(同一公告季内、甚至同一 regime 段内比"有利空 vs 无利空破位"),排除 H-A1 差异只是时间抽样假象。

**多重检验锁死**:Tier A 成立判据只认**主口径**(破位点=S01 SELECT + K=30 + 结构性利空机械口径 + E=T+1开盘入场/T+5前瞻 + 0.2%滑点 + 全A);其余(K其他值、其他前瞻窗、板块/市值分层、Tier B)一律仅描述、不作成立依据。

**交付**:
1. **Layer 1 基线**(T1):破位点全集前瞻超额分布 + S01状态机口径 → 确认老问题(纯量价无edge)。
2. **Tier A 修正**(H-A1/H-A2):无利空组 vs 有利空组 vs 全集baseline,前瞻超额(扣费)+ 样本量 + 显著性;分层(成交额/市值)描述性看是否落不可交易尾部。
3. **Tier B 前向协议**:起记日+样本进度,当前诚实标"样本≈0待积累"+逻辑级方向判断。

### 4.1 v3 预注册结果树(🔒锁3:出结果前写死三态 · 防挪门柱)

**前提(非成败判据)**:技术基座弱/无独立 alpha 是**预期之内**——DB01 全层否定 + S01 已知 12.6% 已印证"纯量价破位反包基座单独几乎肯定也弱"。**基座作对照锚,不当 alpha 源,绝不调参救它**(基座弱是前提,不是 bug)。**v3 整个赌注 = H-A1(消息面修正能否可测救起弱基座)**,而非"基座是否历史显著正"。

**🔒 三态结果树(看结果前锁定,不许事后挪门柱)**:

| 状态 | 条件 | 定性(写死) |
|---|---|---|
| **S-1 概念失败** | **H-A1 否定**(无利空组 vs 有利空组无显著差异) | 消息面结构性利空**无法**区分真假破位 → **诚实否定**,v3 历史层无证据,降级为纯前向协议待样本 |
| **S-2 概念成立·不可部署** | **H-A1 成立 ∧ H-A2 否定** | 消息面**能显著区分真假破位=北极星命中、概念被回测证明**;但无利空组扣费后仍不可交易(同 C-2)→ **概念成立但不可部署,仍是有价值真发现**。**明确区别于 S-1 双否定**,不得混为一谈 |
| **S-3 概念+可部署双成立** | **H-A1 成立 ∧ H-A2 成立** | 无利空组扣费后 > 0 且 > baseline 且照妖镜可交易层存活 → 最佳,弱基座被修正救到可独立部署 |

- H-A1 = "无利空组"前瞻超额 **> "有利空组"**,扣费、过不对称幸存者偏差关,p<0.05。
- H-A2 = "无利空组(洗盘)"扣费后 **> 0 且 > baseline 且在照妖镜可交易流动性层存活**。
- **命中北极星的科学证据在 H-A1(能否区分),不在 H-A2 的大小**(见下"H-A2 量级天生小")。**S-2 就是命中北极星的成立态**,不要因不可部署而自我否定成 S-1。
- **加分/未来**:Tier B 前向(样本≈0,允许"暂无定论"诚实结论)。

**两条设计性质(审判者补,写明使论证更强)**:
- **★下界性质 = 优点**:非业绩类结构性利空(违规/诉讼/商誉减值)Tier A 抓不到、会漏进"无利空组"**拖低**它 → 使 H-A1 **更难通过** → 这是**保守偏向**;故 **H-A1 若仍通过,结论更可信**(真实判别力只会比测出的更强)。
- **★H-A2 量级天生小**:利空组稀疏(多数破位无业绩利空)→ "无利空组 ≈ 全集" → 剔除一小撮对 baseline 的构造性提升本就小。**因此 H-A2 小不等于概念失败**,别用 H-A2 的小去反噬 H-A1 的成立。

## 5. 已知风险与陷阱(诚实清单)

1. **Tier A 样本不平衡**:多数破位无 earnings 利空,"有利空组"可能薄 → 已设 N<30 护栏(该组仅描述)。
2. **结构性利空 ≠ 只有业绩**:违规/减持/商誉/诉讼等结构性利空 Tier A 抓不到(历史补不回)→ Tier A 是"结构性利空判别力"的**下界**;完整判别靠 Tier B 前向。诚实标注。
3. **净情绪分诱惑**:项目已证其滞后无效,严禁滑回当主因子。
4. **point-in-time 业绩预告**:必须用公告日,不用报告期,防前视(单测锁死)。
5. **反转不可交易陷阱(继承 DB01 命门)**:破位反包做多的经济来源仍是反转,可能落在不可交易小盘尾部 → Tier A 修正后的"无利空组"必须报**扣费后 + 成交额/市值分层**,看 edge 是否只在不可交易尾部(否则同 C-2)。
6. **样本外/前向**:Tier B 当前统计力≈0,不得夸大;真检验靠上线后累积。
7. **双重幸存者偏差**:同 DB01,不对称规则判读。
