# 审判基线笔记（策略审判者 · 独立建立）

> 用途：在挖掘者提交 `策略草案_vN.md` 之前，独立建立我的判断基线——现有策略全景、项目已验证结论、已知的坑、回测口径规范、数据可得性。审判每一版草案时以此为锚，逐条对照。
> 建立时间：实验启动首日（AI策略挖掘实验-0823）。来源：独立通读 `docs/策略/` 与 `docs/计划/` 下回测/结论类文档。

## 0. 核心底色（必须先内化）

**纯量价·日频这口井已挖到底：无一策略跑出统计显著的正 alpha。** 弱正的不显著，显著的要么平庸要么为负。所有"有效"信号本质是**过滤器 / 排序器 / 风控刻度**，不是可独立部署的 alpha 源。

→ 审判推论：任何新草案若仍停留在**纯量价·日频**且声称有 alpha，默认高度怀疑，举证责任在挖掘者。真正的新意更可能来自：**新数据维度**（资金流/情绪/基本面历史快照）、**新组合方式**、或**明确承认自己只是过滤器/择时门而非 alpha 源**。

命名权威：用户可见一律「策略N」（面板 0-9）；`S01-S05` 是历史内部代号（**S03=策略7、S04=策略8、S05=策略9，S03≠策略3**）；SEPA+VCP / 趋势模板是不占面板号的独立工具。参数唯一真源 `tools/config/strategy.py['THRESHOLDS']`。

## B. 已被验证"有效"（弱/条件性，可作过滤器/择时门，非独立alpha）
1. **SEPA+VCP 短窗枢纽梯度成立**（核心正面发现）：全A 8年/35测试日，T+5 单调梯度 **接近枢纽+0.60% > VCP进行中+0.25% > 技术合格池+0.04%**，接近枢纽 T+5 跑赢baseline。**T+10/T+20 各层转负，无中期超额**。主控参数=pivot 3~4。
2. **趋势模板/SEPA 是"顺势放大器"，效果由 regime 决定**：牛市 T+10 +3.72%/+2.55%，震荡为负、熊市为负。→ 仅牛/强趋势启用的门控。**调阈值改不了方向**。
3. **单日/连续放量（策略8子信号）方向性较好**：样本级 T+10 +2.64%/+1.88%，作强势过滤有意义（样本级）。
4. **预测两条线经调参可作风控刻度**：区间覆盖80%、L3止损误扫降到24%。

## C. 已知的坑 / 已被证伪（新草案撞上任一 = 高危，需强举证）
1. **动量反向**：A股短期是反转市，选最强动量反跑输（策略4 IC显著负）。
2. **反转"账面异象、不可交易"（照妖镜）**：rev_mom IC 显著正（t≈3~4）看着能赚，但**多空净成本后≈0**，且**在流动性前50%里 edge 直接归零**（反转全在垃圾小盘）。→ 反转/超跌类默认不可交易，除非给出**净成本后+流动性前50%**的结果。
3. **上涨概率预测是纯噪声**：全A Brier≈0.25，各分箱塌到基础率。任何"胜率/上涨概率"要求 Brier/校准。
4. **策略1旧回测画错靶**：机械买入口径是提供者从没说过的买法，结论对本意作废。→ **用途先探查再定回测口径**。
5. **低位放量子信号样本内无edge**：疑似弱势环境假突破。
6. **过拟合/数据窥探防线**：所有回测**测前预注册**钉死预期+判据+失败原因+预设调参；意外为正先查泄漏（反转就是这么被证伪的）；新线索必须**独立重新预注册**再测。
7. **样本偏差**：自选池偏成长偏多不可外推，必须**随机全A抽样**。
8. **右偏/低胜率普遍**：趋势类胜率常<50%但均值靠极少数大涨名，须配仓位/止损，不能当高胜率信号。
9. **工程坑**：store 读写日期不对称（写active_date/读latest）曾致全A入选0，数据层健壮性红线。

## D. 回测口径规范（审判草案的"可回测性"时对照）
- **无未来函数（命门/单测锁死）**：逐日 t 只用 `kdf.iloc[:t+1]`，进场锚定 t+1，前瞻收益取 t+1 之后；一字板不可成交顺延。
- **三类口径不可混用**：信号型（状态机 simulate_position，看胜率/盈亏比/Alpha/即死率）；排序型（backtest_rank，看 IC/ICIR/分层/TopK）；前瞻型（event_study，T+1/5/10/20 vs 双基准）。
- **样本与窗口**：全A前复权日线约5131只；SEPA/趋势模板跨 2018-01→2026-08（~8年多regime），stride=60抽样、相邻前瞻窗不重叠近似独立；样本级须标注"非全A"。
- **双基准**：全A等权 baseline + HS300；Alpha=命中前瞻−HS300。
- **成本/流动性**：cost_bps；反转类专门做多空净成本年化+流动性过滤（照妖镜）。
- **防窥探纪律**：测前预注册；意外为正先查泄漏；诚实回填带样本量与显著性，不足标"待观察"，不编准确率。

## E. 数据可得性（审判"数据可得性"时对照）
- **量价**：baostock 全历史前复权日线OHLCV+turnover（主力）；akshare/腾讯/新浪回退当日增量；**只有日线，无分钟级**（策略1精确买点做不了，明确缺口）。
- **Tushare（可选）**：全市场批量+**筹码获利 cyq_perf**（免费源拿不到，策略9硬依赖），需 token。
- **财报**：akshare 财务指标+年报PDF管线（LLM）。
- **新闻/情绪**：采集+LLM三层，**仅对每策略入选前5∪自选池做**（控token）。
- **指数**：HS300 全史。
- **关键限制**：**无资金流/情绪/基本面的历史快照**（正是策略0 IC≈0 的原因，也是最有价值的补数方向）；日筛只读近~500根；北向个股口径待实测。

## 审判红线速查（每版草案逐条过）
1. **是否真"新"**：与策略0-9 + 三个独立工具有无实质差异？还是换皮？
2. **动量/趋势/放量类**：regime 依赖（牛市才正）？右偏低胜率？全A还是样本级？
3. **反转/超跌类**：有没有净成本后+流动性前50%的结果？没有=默认不可交易。
4. **任何"胜率/上涨概率"**：要 Brier/校准，警惕噪声。
5. **IC为正**：查未来函数泄漏 + 可交易性（成本+流动性）。
6. **声称有alpha**：要预注册记录 + 随机全A样本 + 双基准 + 无未来函数单测，否则视为未验证。
7. **数据可得性**：依赖的数据（尤其分钟级/资金流/情绪历史快照）项目到底有没有？
8. **回测口径是否自欺**：口径与用途是否匹配（画错靶教训）？机械基线是否冒充最终买法？
