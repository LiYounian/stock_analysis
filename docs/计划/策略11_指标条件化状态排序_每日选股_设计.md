# 策略11 · 指标条件化状态排序(每日选股)· 设计

> 状态:**设计待审(用户 + 统筹)**。把"指标条件化预测"从个股页升级成每日选股面板里的一个**排序型策略**:每天全市场按上涨概率排 Top~10,出 1/5/10 日三维度。非投资建议。

## 0. 用户需求

- 逻辑:找上涨概率 > 50% 的票 / 或按上涨概率排序,再看置信度高的靠前。
- 维度:主看 1 日,或列 1/5/10 日三个维度排行。
- 产出:一个排序型选股策略,每天 Top~10,进"每日选股"面板。

## 1. 诚实前提(必须先说)

该预测**自身回测=聚合无显著超额**(Brier≈无条件基线、聚类t不显著);建池后全A概率**几乎全挤在 45–52%**,方向阈值(看涨58/看跌42)几乎不触发。分维度:**1 日弱单调(略有区分力),5/10 日校准塌陷甚至反向(近噪声)**。
→ 定位:**"当日指标状态相似日的历史上涨概率排序参考",不是已验证 alpha**。面板须沿用个股页那句 ⚠️ 诚实标注 + "状态参考"徽标,不作胜率/涨跌承诺。**这也决定了排序键取基线、不吹 5/10 日。**

## 2. 设计(照 策略10·反转低换手 同构)

编号 **策略11**,注册名/视图名 `指标条件化状态排序`。

- **排序键**:基线 `上涨概率%` 降序;`置信度`(高>中>低)作 tiebreak。**用基线不用"修正"**(激进版倾斜未经回测标定、且全A多数票无 sentiment→不倾斜)。
- **过滤**:剔除 `是否退回=True` 与 `方向=数据不足`;`上涨概率>50%` 作**标记/软筛**(纯排序永远能凑满 Top10,>50% 只作展示标注,避免 5/10 日筛空)。
- **三维度**:1/5/10 日各出 Top10;**1 日为主**,5/10 日并列展示但标"区分力弱/近噪声"。
- **票池**:全A(universe_codes,排除北交所),非自选池。

## 4. 关键数据前提(⚠️ 需统筹数据线,是能否上线的命门)

- **state_pool 每日构建**:`conditional_scenarios` 依赖 `data/backtest_local/state_pool.parquet`(gitignore、worktree 本地)。**当前日流水线从不建池**,且本 worktree/开发机无全A主档行情。→ 要让策略11 每天有意义,**必须在每日闭环加一步 `build_state_pool(全A主档, save=True)`(~80s)**,且需全A主档 K线(统筹数据线正在铺的"每日全量")。**池缺失→全退回→排行=噪声。**
