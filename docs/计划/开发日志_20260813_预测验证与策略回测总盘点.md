- 新建 `tools/backtest/backtest_predict.py`:逐日切片喂**真** `predict()`(连 technical.compute 也在切片上重算),**严格无未来函数**(`tests/test_backtest_predict.py` 锁死:改未来不改 t 时刻预测字段)。

- 样本:先自选池(11 只)快跑出方法,再**随机全A ~700 只 / 29 万观测**(破"偏成长"偏差,`--sample/--seed/--step` 抽稀提速)。
- **关键发现**:①上涨概率在全A是**纯噪声**(Brier≈0.25、各预测分箱都塌到 50% 基础率)——自选池那点信号是样本偏差;②区间覆盖偏窄(72%);③L3 远止损被大量扫(10日 32%);④偏买入择时全A 无 edge。
- **OFAT 调参**(自选池调、换种子全A验):情景分位 [10,90]→**[7,93]**(覆盖→80%)、swing窗口 5→**8**、止损缓冲 0.5→**1.0**、止损ATR倍数 1.0→**1.2**;止盈保持 1.6。写回 `strategy.py['预测']`(注释带 provenance),`scenarios` docstring 标注上涨概率无效。

### 2. 策略 0/3/4 回测(先写预注册方案)
- 先读码确认用途:**3 箱体=信号型**、**0 合议 / 4 动量=排序型**(用途不同口径不同,防再犯 S01 错前提)。
- 方案文档 `docs/计划/策略0_3_4_回测方案与预注册预期.md`,**测前钉死每个策略的预测 + 成败判据 + 若失败原因 + 预设调参**。
- `backtest_box.py`(克隆 `backtest_s02`,信号源换 `screen_box`)、`backtest_rank.py`(排序型:IC 横截面 / 分层十档 / TopK 超额,打分可插拔=动量/合议)。
- **结果(预注册全命中)**:箱体 N=1415 胜率31%/Alpha+0.32%/即死61%(弱正不显著);动量 IC 显著为负(t −2.9~−4.0,A股反转);合议(技术面)IC≈0 不显著。

### 3. 反转因子探索(追唯一正向线索)
- 动量显著为负 → 反过来反转可能有 edge。加 rev5/rev10/rev_mom 打分 + **流动性列/过滤** + **多空净成本年化**(反转命门=换手成本)。
- **结论:账面异象、不可交易**。rev_mom IC 显著正(负动量镜像),但多空**净成本后≈0**;rev5/10 净后为负;**流动性前50%里 edge 直接归零**(反转全在垃圾小盘)。命中预注册命门"看着能赚、交易就没了"。

## 三、关键决策 / 教训
- **用途先探查再回测**:0/4 是排序型(IC/分层),3 是信号型(持仓状态机)——口径混了就是错靶。
- **预注册**:测前写死预期与判据,让"平/负"结果不意外、不硬凑;"意外为正"要先查泄漏(反向自证)。
- **随机全A 破偏差**:自选池偏成长偏多,结论不可推广;随机抽样天然以传统股为主,才是部署目标。
- **净成本 + 流动性是照妖镜**:账面 IC 正 ≠ 能交易;反转就死在这两关。
- **AI 先行**:方案审过后执行阶段放手做,git 分步 commit 兜底(本轮 7+ commit)。
