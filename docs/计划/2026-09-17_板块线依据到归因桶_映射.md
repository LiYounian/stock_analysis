# 板块/消息线 依据 → 复盘归因桶 · 字段映射(供统一大复盘路径引用)

> 2026-09-17 · 板块预测窗口(回声-0914)提供给「统一大复盘生成路径」建设窗。
> ⚠️ 测试环境研究模拟,非投资建议。**防未来硬红线**:复盘打分只用 t≤date 的依据 + 事后 master kline 涨跌,严格 as-of。

## 0. 两个产物文件(板块线的"当时依据")
- `data/analysis/<date>/sector_focus.json` →「消息驱动」块:**选股实际消费的候选**(只出利好板块)。
- `data/sector_news/catalyst_<date>.json` →「板块研判」块:**逐板块完整研判**(候选背后的依据全量)。
- (辅助)`data/analysis/<date>/sector_regime.json`:板块冷热/拥挤/动量(判"踏错板块节奏")。

## 1. 哪些字段="该票靠板块消息选出" + 龙头 vs 跟涨 归因分桶

`sector_focus.json.消息驱动.利好板块[]`(每个 tag=利好 的板块)下:
- `龙头候选: [{code, name, 已动}]` → **归因桶 = 「板块-龙头催化」**。语义:该票**本身是催化承载者**(该板块龙头/中军,有直接消息催化)。选对 → 板块龙头催化命中。
- `跟涨候选: [{code, name, 联动依据}]` → **归因桶 = 「板块-联动跟涨」**。语义:补涨先锋,**非自身催化、靠板块龙头已动的联动**接力。选对 → 联动补涨命中;选错权重应低于龙头桶(联动本就是二阶信号)。

**判定"是否板块线选出"**:该票 code 出现在某利好板块的 龙头候选∪跟涨候选 即是;分桶按它在哪个 list。
**板块把握度**:该板块 `强弱`(强/中/弱)= 板块级信念强度(归因时作权重)。

## 2. 已动 / 强弱 / 关键事件 → 判 选错的三类(假利好 / 踏空 / 追高)

| 归因结论 | 判据(用板块线字段 + 事后涨跌) |
|---|---|
| **追高** | `龙头候选.已动=True`(当日涨幅≥3%·MOVED_PCT)**且**入场是在已动之后追(非回踩)**且**事后跌。板块线口径本是"回踩限价·不追高",已动=True 仍追=违纪律。**已动=True 是追高的必要信号位**。 |
| **假利好** | 有 `关键事件` 但事件质量弱:`可信度∈{存疑,不可信}` 或 `来源=二手` 或 `执行度=低` 或 板块 `强弱∈{中,弱}`,**且**事后跌。=催化不实/噪音驱动(不是真催化失效)。**关键事件的 可信度/来源/执行度 三档是假利好探测器**。 |
| **踏空** | 板块 `强弱=强` 且 `关键事件` 有`影响程度=大`+`来源=一手`+`执行度=高`(真强催化),**且**事后涨,**但该票未被买入/未触发**(回踩限价没到)。=真信号漏吃。⚠️**"是否买入/触发"在选股执行侧、不在板块线文件**——需 join 选股执行/成交记录判"未触发";板块线只提供"信号确为强"这一半。 |

补充信号位:
- `持续性`("持续利好·多条同向" vs "零星单条" vs "近日转弱")、`时效`("本周新" vs "偏旧") → 判**时点**:强弱=强但 时效=偏旧/持续性=近日转弱 = 信号在衰减,选错偏"踏错时点"。
- `资金流`(主力净买/卖) → 与消息背离时(利好但主力净卖)= 分歧,选对/错都要标"消息与资金背离"。

## 3. 判"踏错大盘/板块基调"的字段

- **板块级**:`sector_regime.json.板块[].冷热标签` ∈ {过热, 拐点, 正常活跃, 过冷}。从`过热/拐点`板块选出的票 → 即使消息利好,也标**"选对催化但踏错板块节奏(板块过热见顶)"**。辅以 `拥挤分位`(高=拥挤)、`动量_时序分位`。
- **催化自带时点**:catalyst 的 `时效`/`持续性`(见 §2 补充)。
- **大盘级**:市场 regime / 宏观净方向在 `market_daily.md` / market_forecast(**统筹的市场层**,非板块线)——"踏错大盘基调"的大盘部分请由统筹市场线提供;板块线只覆盖到**板块 regime**这一层。

## 4. catalyst「板块研判」逐板块可取的完整依据字段(候选背后的全量)
`catalyst_<date>.json.板块研判[sw]`:`消息标签`(利好/利空/中性/分歧)、`强弱`、`关键事件[{时间,事件,方向,可信度,影响程度,执行度,来源}]`、`持续性`、`时效`、`可靠性综述`、`理由`、`龙头/中军/主力`(名单)、`资金流`、`描述`(凝练整段·可直接引用)。

## 5. 诚实边界(复盘归因要标)
- 板块线文件给的是**"当时的消息依据"**;**事后涨跌**来自 master kline、**是否买入/触发/成交价**来自选股执行侧——两者需 join,板块线不含后者。
- 板块线 forward 严格 as-of 数值口径:`sector_news_forward_shadow`(默认严格·干净),可作板块线归因的现成基础设施。
- 概念级细分缺(仅申万一级);资金流=龙虎榜proxy(覆盖度见 catalyst 资金流条数)。
