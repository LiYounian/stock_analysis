# 午盘/日内选股复盘（隔夜口径）· 设计（待统筹审）

> ⚠️ 测试环境研究模拟，**非投资建议**。窗口：午盘/日内复盘线（competent-hermann-8e9b06）。
> 与尾盘大复盘（epic-ellis 的 `tools/review/` D选→D+1回踩入场→D+2卖）**彻底解耦**：本线只加
> 一个「当天买→次日早卖」的隔夜 cadence 变体，**复用不重写**尾盘基建、不动它的口径与测试。

---

## 一、复盘口径（本线独有：隔夜绝对收益）

| 环节 | 定义 | 价源（as-of 防未来） |
|---|---|---|
| 信号日 D | 午盘/下午选出票的日期 | 选股产物 ≤D |
| **买入** | 当天**下午收盘前买入** → 买入价 = **D 日收盘价** | master 日线 `close`（date==D 当日行，天然 ≤D） |
| **卖出** | **次日午盘前(约11:00)卖出** → 卖出价 = **D+1 早盘快照价** | 见 §二价源分级 |
| **持有** | 隔夜单段（无条件持有到次日早盘，不设 D+2） | 单一 horizon，比尾盘简单 |
| **绝对收益** | `r_overnight = (卖出价 − 买入价) / 买入价 × 100%` | 绝对口径，不做择时假设 |
| **α（超额）** | `个股 r_overnight − 全A等权同期 r_overnight` | 同口径同源（§二基准） |

**与尾盘口径的本质区别**：尾盘是「限价=D收盘 → D+1 回踩 low≤限价才成交 → D+1/D+2 卖」（限价单撮合、
可能未触发、分母剔除）；本线是「D 收盘**市价买入必成交** → 次日早盘卖」——**无回踩条件、无未触发、
无 D+2 条件持有**，是干净的隔夜单段。因此**不复用 model_a 的 r_exit/hold_to_d2/stop_flag 逻辑**，
另写隔夜撮合。

## 二、价源分级（防未来 as-of 是红线）

### 卖出价（D+1 早盘 ~11:00）—— 关键差异点，用真实盘中快照
项目**每日都采集** `data/intraday/<date>/` 快照。分级取 D+1 卖出价：

1. **首选 `data/intraday/<D+1>/noon_screen_snapshot.json`** → `quotes[code].price`
   （全A 11:30 午休冻结快照，实测 5564 只**全市场覆盖**，09-11 起每日有）——真实早盘价，最贴口径。
2. **次选 `data/intraday/<D+1>/T1145.json`** → `codes[code].price`（11:45 定向快照，仅 ~18 只
   watchlist，覆盖窄）——命中则用。
3. **降级 master 日线 `open`@D+1**（次日开盘价，早盘近似）——全覆盖兜底，快照缺失时用，**标注降级**、
   口径由「早盘 11:00」漂移为「次日开盘」，解读时降权。
4. 都缺 → `r_overnight=None`（有声缺失 pending，绝不用 D+1 收盘顶替——那会破坏"早盘卖"语义）。

### 买入价（D 下午收盘前）
- **master 日线 `close`@D**（全覆盖、天然 ≤D，最稳）。单一价源，不分级。

### α 基准（全A等权同期隔夜）
- **首选**：全A等权 `r_overnight` = 全A每只 `(D+1 noon_screen price − D close)/D close` 的等权均值，
  复用 `market_forecast.breadth.equal_weight_mean_pct`（唯一真源）。个股与基准**同口径同源**。
- **降级**：D+1 全A早盘快照缺失 → 回退 `market_ew.parquet` 的 close→close 日频 α（复用尾盘
  `sector_news_forward._load_ew`/`excess_*`），**标注为近似**（口径漂移：隔夜→收收）。
- 基准不可得 → α=null 有声缺失（绝不顶替/编）。

**防未来红线**：卖出价只取 D+1 已落盘快照/日线行；买入价只取 D 当日行；任何 >卖出时刻的 bar 不进计算。

## 四、脚本划分（先框架后填充·守则5）

```
tools/review/intraday_cadence.py         # 本线核心（隔夜撮合+收益+基准）
  ├─ OvernightLabels (dataclass)          # 隔夜收益标签（buy_price/sell_price/sell_src/r_overnight/alpha_overnight/status）
  ├─ buy_price(code, D, cache)            # = D close（master 日线）
  ├─ sell_price(code, D1, snap_cache)     # 分级：noon_screen → T1145 → open降级 →(缺)None，带 src 标记
  ├─ overnight_return(buy, sell)          # 绝对收益%，任一缺→None
  ├─ market_overnight_ew(D, D1, ...)      # 全A等权同期隔夜基准（复用 breadth）
  ├─ compute_labels(pick, ...)            # 单票 → OvernightLabels
  └─ compute_all(picks, ...)              # 批量共享 kline/snapshot 缓存

tools/review/intraday_loaders.py         # 午盘专用 loader（Agent版/千问版/午盘Q线买入组 → Pick）
                                          #（明早 Agent 产物落地后定 adapter；今晚先留接口+今日选股复用）

tools/review/build_intraday_review.py    # 编排 CLI：load → compute_all → classify(复用) → render
                                          #  --date/--dates/--data-root/--dry-run，幂等 upsert

tests/test_intraday_cadence.py           # 锁语义（见 §五）
```

**编排链**：`intraday_loaders.load → compute_all(隔夜) → attribution.classify(复用) → render(本线MD+CSV)`。

## 五、测试锁语义（守则6：断言锁"为什么"）

`tests/test_intraday_cadence.py` 用桩数据（不依赖生产 data）锁死：
1. **买卖点时序**：买=D close、卖=D+1 早盘，且 D < D+1（撮合方向不可反）。
2. **防未来 as-of**：卖出价绝不取 >D+1 早盘时刻的 bar；喂入未来行时结果不变（护栏）。
3. **绝对收益公式**：`r=(sell−buy)/buy×100`，正负号、量级正确。
4. **价源分级**：noon_screen 命中优先；缺则 T1145；再缺 open 降级并标 `sell_src='open_degraded'`；全缺→
   `r_overnight=None` 且 status=pending（**绝不用 D+1 收盘顶替**）。
5. **基准同口径**：α 基准与个股同口径（隔夜），基准缺→α=null 有声缺失。
6. **未到期 pending**：D+1 快照未出（如今天选的票明早才有）→ None、status=pending，可回填幂等覆盖。
