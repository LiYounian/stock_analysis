## 0. 目标（v2 四条）
1. 共性指标解释（"是什么" + 全档位区间）抽到**统一指标词表**，喂决策包 prompt 开头一次，个股卡不再逐条重复。
2. 个股卡每条 = **数值 + 档位 + 一句针对本股本值的「含义/影响」**（加分/减分/需结合X）。
3. 财报五维（成长/质量/健康/运营/回报）**逐维给一句描述**；"财报质量"→"财报质量汇总"给综合句。
4. 消息面重写清楚：个股净情绪 0 分三态（样本太少/真中性/未覆盖）；"情绪样本质量"→"消息覆盖与可信度"讲人话。

**边界**：只改呈现文案结构（值+档+影响）+ 共性搬词表；**不改档位阈值、不改打分逻辑**。

## 1. 统一指标词表（tools/pyramid/指标词表.py·新增）
- `render_区间(档位表, fmt, 单位)`：从各工具**档位表常量**程序化渲染区间串——**区间单一真源**，
  档位表改则词表自动跟随、绝不手抄漂移。末档=顶档渲成 `档>上一档上界`（兼容 inf/1e9/1.01 有限哨兵）。
- 各指标"是什么"一句手写（取自 v2 规范 §一，编辑性文案）；非 banded（均线/MACD/KDJ 状态、龙虎榜、
  排雷、ROE 未年化）手写无区间。`render_词表()` 按四面（基本面/技术面/资金面/消息情绪面）分节。
- 拼接：d2_package.render_package 开头（决策包标题后、`## 市场定调`前）`out.append(render_词表())`，全 prompt 一次。

## 2. 各工具意味段改法
统一原则：**口径段**只留档名 + 真实 provenance（现算公式/未年化/金融业口径/报告期/折算/口径日期），
剔除与词表重复的区间/共性定义；**意味段**改为 `影响：<本股本值 加分/减分/需结合X>`。

### 2a. 5 个 字段() 工具（结构化口径三段）
- **valuation**：PE/PB/PEG/PE历史分位 按档给影响；PEG 保现算公式 provenance；市值口径滞后提示保留。
- **growth_quality**：营收/净利/盈利能力/负债率/股利影响化；"财报质量"→"**财报质量汇总**"综合句（最强/最弱维）；
  **财报五维逐维**（成长/质量/健康/运营/回报 各 值+档+一句·按 _QUALITY档 分强/中/弱三档取句）+ 财报增速明细。
- **technical_detail**：均线/MACD/KDJ/RSI/筹码/支撑压力/BOLL——口径剔区间枚举、意味影响化（状态类意味表重写）。
- **fund_flow**：主力/主买/户数/换手/龙虎榜/竞品/两融——口径剔区间、意味按档给影响，保 provenance（折算/陈旧/rank/roster）。
- **stock_sentiment**：净情绪三态（样本≤`样本太少阈值`=5 且≈中性 → "消息太少非缺数据"；样本足→真中性；
  未覆盖→缺数据待补）；"情绪样本质量"→"**消息覆盖与可信度**"（抓N条·约X%成功打分→可信度档）。

### 2b. 6 个 plain 浓缩块工具（方案 b·剥词表重复共性）
- **price_volume**（量比/pos60 定义移词表）、**financial_redflag**（quality 档解移词表）、
  **sector_context**（RS分位剥 pos60 定义、冷热/净催化影响化）：剥共性 + 影响化。
- **insider_reduction / unlock_risk / fake_good_news**：本已"值+档+证据"（减持/解禁/假利好定义在词表），
  各档补一句选股影响。
- **gate / entry_price / experience_rules 本轮不动**：纯纪律/价位/命中，无词表重复共性。
  gate 的 T1/T2/T3 阈值保留 inline（搬词表反造重复、判定不值）。
