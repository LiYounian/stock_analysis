## 2. Store schema：`kind=industry_panel`（持久，仿 valuation 序列）

主键：`(industry, date)`。**只存原始聚合值，分位在读取时因果 rolling 算**（防未来函数）。

| 字段 | 类型 | 口径 | 备注 |
|---|---|---|---|
| `date` | str `YYYY-MM-DD` | 交易日 | |
| `industry` | str | 申万一级规范名（31 类，`to_sw` 归一后） | |
| `n_members` | int | 当日该行业成分股数 | 用 `industry_at(code,date)` 逐票还原**历史时点归属**统计；`< IET_MIN_MEMBERS` 该行业当日弃权 |
| `pe_median` | float\|null | 成分股 `PE_TTM` 中位数 | 剔除 ≤0 / null；PE_TTM 用已披露盈利（PIT，不前视） |
| `pb_median` | float\|null | 成分股 `PB` 中位数 | 剔除 ≤0 / null |
| `turnover_mean` | float\|null | 成分股当日换手率(%)均值 | 来源主档 K 线 `turnover` 列 |

> **探针只建这 3 个聚合字段**（估值 2 + 换手 1）。波动/涨跌家数/资金流留全量一期。
> 动量维**不入 panel**——打分时直接从 `rrg` 现取。

### 2.1 构建流程（`panel.py`）

```
for date in 交易日区间:
  members = { code : industry_at(code, date) for code in 全A票池 }   # 历史时点归属，禁用当前回填
  for industry in 31申万一级:
    codes = [c for c,ind in members if ind==industry]
    if len(codes) < IET_MIN_MEMBERS: 记 n_members，其余置 null（弃权）; continue
    pe_median  = median(PE_TTM[c] for c in codes if PE_TTM 有效)
    pb_median  = median(PB[c]     for c in codes if PB 有效)
    turnover_mean = mean(turnover[c] for c in codes)
    upsert industry_panel(date, industry, n_members, pe_median, pb_median, turnover_mean)
```

（探针可写到独立命名空间 / 独立目录，或明确标注 probe 版本）。

## 3. 维度 → A/B 二分类口径（3 维）

打分时对每 (行业,date) 算：

### 3.1 动量维（复用 RRG，零新建）
- 取 `rrg.industry_row(industry)` 的 **RS-Momentum**（RRG 纵轴，中心=100）。
- **A 面（过热）= RS-Momentum ≥ 100**（对应象限 领先/改善，动量向上）；
  **B 面（过冷）= RS-Momentum < 100**（走弱/落后）。
- 敏感性备选（不做主口径，仅报告附注）：按 RS-Ratio 横轴切、或 2D 四象限映射。

### 3.2 估值维（行业自身历史 rolling 分位）
- `val_pctile` = 该行业 `pe_median`（主）在其**自身历史滚动窗 `IET_PCTILE_WIN`** 的分位（因果，只用 ≤date）。
  PB 作为并行参考（可取 `mean(pe_pctile, pb_pctile)` 或仅 PE，主口径用 PE，PB 敏感性）。
- **A 面（贵/过热）= `val_pctile ≥ IET_VAL_CUT`**；否则 B 面。

### 3.3 换手维（行业自身历史 rolling 分位）
- `turn_pctile` = `turnover_mean` 在自身历史滚动窗 `IET_PCTILE_WIN` 的因果分位。
- **A 面（拥挤/过热）= `turn_pctile ≥ IET_TURN_CUT`**；否则 B 面。

### 3.4 聚合（等权多数票，用户已定）
- `k` = 3 维中 A 面的个数 `∈ {0,1,2,3}`。作**序数温度**用（k 越大越"热"）。
- 温度档（探针 4 档，非 5 档）：`k=3` 强A｜`k=2` 偏A｜`k=1` 偏B｜`k=0` 强B。
- 任一维缺失（弃权/null）→ 该行业当日温度置**弃权**，不进回测样本（不硬填）。

## 4. 回测口径（只做行业层）

### 4.1 收益口径
- 信号日 **T**（只用 ≤T 信息）→ **T+1 入场**（行业指数 `board_kline`）→ 持有 `h∈{1,5,20}` 日 → forward return。
- 收益标的 = 申万一级**行业指数**收盘价 close→close；记录用 close 入场占比（沿用 eval_v3 可执行性口径）。

### 4.2 rank-IC
- 每个横截面日：对当日**所有有效行业（≤31）**的 `k` 值 与 forward return 求 **Spearman rank-IC**。
- 汇总：IC 均值、`ICIR = mean/std`、`t = ICIR × √N_days`。分 `h=1/5/20` 各出一列。
- ⚠️ **已知局限**：横截面只有 ≤31 行业，单日 IC 噪声大 → 靠时序 `N_days` 累积显著性；报告须显式写明。

### 4.3 分层单调 + 多空
- 按 `k=0/1/2/3` 分 4 档，各档行业 forward return 均值，看单调性。
- **不预设方向**（探针是探"有无预测力"，方向让数据说）：
  - 若"过热→未来弱"则应**单调递减**（k 大收益低）；若"动量延续"则**递增**。两向都在报告并列，不预判。
- 多空 spread：按数据显示的 IC 方向构造（如递减则做空 k=3、做多 k=0），net 年化，扣成本（行业指数层成本口径）。

### 4.4 基准
- **全A等权**（`equal_weight_index`）+ **行业等权**（31 行业等权），双基准并列。

## 5. 正交性检验（回答"除动量外有无增量"）

- 把行业温度**广播到个股**（该行业所有成分股取其行业的 `k` / 分维信号），
  与现有 **9 因子 + 合议综合分** 做横截面 **Spearman**，时序均值。→ 回答"IET 是否与现有因子冗余"。
- **重点子项**：只用**非动量部分**（`val_pctile`＋`turn_pctile` 的合成，剔除 RRG 维）vs **RRG 动量**的相关，
  以及非动量部分 vs 行业 forward return 的独立 IC。→ 正面回答"除了动量，估值+换手还带没带新信息"（统筹关切）。

## 6. 防未来函数 checklist（逐条须过单测）

- [ ] 行业归属用 `industry_at(code, T)`，**禁用**当前 `code_industry.json` 回填历史。
- [ ] rolling 历史分位窗只含 `≤date` 数据（因果，`min_periods` 达标才出分位，否则弃权）。
- [ ] PE_TTM/PB 用已披露 point-in-time 值，价格用当日、盈利用最近已披露。
- [ ] **T+1 入场**，只算已到期 horizon（未到期不纳入）。
- [ ] panel 构建按 as-of，不引用未来价。

## 7. 预注册闸门 + 判定（评测前锁定，不看结果再改）

命名常量（进 `config/strategy.json` / `strategy.py` `THRESHOLDS`，**只追加不重排**）：

| 常量 | 值 | 含义 |
|---|---|---|
| `IET_IC_BAR` | 0.03 | 行业层 rank-IC 均值 |IC| 下限 |
| `IET_T_BAR` | 2.0 | IC 的 t 统计下限 |
| `IET_VAL_CUT` | 0.5 | 估值分位 A/B 切点 |
| `IET_TURN_CUT` | 0.5 | 换手分位 A/B 切点 |
| `IET_PCTILE_WIN` | 250 | 历史分位回看窗（敏感性 {120,250}） |
| `IET_MIN_MEMBERS` | 5 | 成分股数下限，不足弃权 |

**达标判定**：某 horizon 上 `|IC| ≥ IET_IC_BAR` 且 `|t| ≥ IET_T_BAR` 且**跨子样本（分年份/多随机划分）符号稳定**
→ 判**"有信号"**，建议投全量一期（补选股层 M0~M3 赛马 + 展示 + LLM 维）。
否则 → **停在探针**，温度保留作纯分析报告（可回退，默认 `IET_启用=False` no-op）。

**参数稳健性**：对 `IET_PCTILE_WIN∈{120,250}`、切点 `∈{0.5,0.6,0.7}` 做敏感性网格，报告附表；
结论不得依赖单一阈值。

## 8. 测试锁点（守则6，语义须锁）

- `test_industry_at_no_lookahead`：给定日期，归属不返回该日之后才生效的行业变更。
- `test_rolling_pctile_causal`：分位序列右移一位不改变历史值（无未来泄漏）。
- `test_ab_classify`：估值/换手分位在切点两侧、RS-Momentum 在 100 两侧的 A/B 判定语义。
- `test_k_aggregate`：3 维 A/B → k 计数正确；任一维弃权 → 行业弃权。
- `test_gate_constants`：闸门常量从 `THRESHOLDS` 读取、探针判定分档语义。
