# WI-6 消息面融合设计(融合北极星)

> 2026-08-30 · 统筹 · 用户已认可。承评测大线定论:**纯技术面在 A股扣成本后≈市场、离场只管风险不创收 → 净收益唯一出路 = 把消息面/资金面/事件面作为正交增量层,叠加到"技术面小而精 5–10 股候选池"之上。** 本文是北极星的落地设计。

## 一、核心破局:按"能不能历史回测"分两层
家底调研核心发现:**"接口就绪 ≠ 数据落地"**(很多非技术信号代码接了 factor/experts,但生产从未采集填充,存档 0 文件)。且回测难度天差地别 → **不是所有消息面都难回测,把能回测的先做严谨、难回测的诚实前向。**

### 🟢 Phase 1 · 可历史回测的正交增量层(先做,能严谨盖章)
| 信号 | 成色 | 状态 | 断点 |
|---|---|---|---|
| **PEAD / 业绩预告实质利空** | 最好(真实公告日、防未来函数红线全、已有干净回测 backtest_pead) | 仅回测脚本,未接生产 | ⚠️ 公告日只在回测脚本;生产 event_driven.py 采集把公告日丢了 → 需**贯通公告日到生产** |
| 筹码分布 | 好(本地K线推演,可任意 as-of 重算,PR#19 已 point-in-time) | 已接 factor | — |
| 龙虎榜 / 大宗交易 | 好(游资/机构席位,解释力强) | **采而未用**(采了零消费) | 直接激活 |
| 资金流(主力净流入) | 中(API 返全历史日序列) | 已采,未进多因子 score | 接入 score |

### 🟡 Phase 2 · 只能前向验证的 LLM 情绪层(后做,诚实前向)
- 净情绪分/政策层/消息持续性:LLM 情绪历史无快照(存档仅 ~7-13 交易日、外部 API 只回溯 ~7天,补不回)。
- **复用现成 `forward_scorecard 倾斜A/B`**(专门做"纯技术基线 vs 叠消息面倾斜"的前向增量验证,含聚类 t 放行闸,开箱即用)→ 滚存累积。舆情/北向(源已停更)/一致预期(只当前快照)→ 降权/剔除。

## 二、架构 + 用法
**技术面选出小而精 5–10 候选 → 消息面正交增量层 → 终选/tilt。** 用法按策略11 的两种:
- **断点(veto)**:有实质利空/大额减持的候选剔除;
- **评价参数(tilt)**:正超预期/游资净买/筹码集中的候选加权或提前。

## 三、达标判据(预注册)
消息面层要能给"技术面≈市场的候选池"带来**扣成本后正交的净增量** —— Phase 1 用历史回测(event_study/backtest_pead 口径 + eval_v3 聚类显著性)严谨盖章;Phase 2 用前向累积验证。**达标才上线,不达标诚实止步**(同前纪律)。

## 四、分步实现
1. **Phase 1-a(头号·进行中)**:PEAD/业绩预告公告日贯通生产 + 历史回测"叠加到技术候选池的净增量"(断点+tilt 两用法)。分支 `feat/wi6-pead-fusion`。达标才接生产。
2. **Phase 1-b**:激活龙虎榜/大宗 + 资金流接 score,同口径回测。
3. **Phase 2**:LLM 情绪层挂进 forward_scorecard 倾斜A/B,前向滚存。

## 五、诚实边界
消息面增量在 A股同样可能薄/不显著(前向样本尤其极薄,机制正确但统计力现≈0,需滚存)。两阶段+预注册判据就是防"为融合而融合"。DB01/DB02 曾被诚实枪毙,本轮以"可历史回测的 PEAD"为最高确信起点,达标才推进。
