## 3. 对 D2 设计的四条结论
1. **T 层阈值明显过宽**：T1 = 165 只，无法直接取 2~3；T3 从未启用。→ T 层需**重标定**（目标 T1 ≈ 10~20 只），或把 T1 定义为"量价分 top-N"而非绝对阈值，T2/T3 作保底。
2. **纯量价闸门选出的是另一个宇宙**：四模式（定时任务 / 程序 / DS / 千问）9-17 推荐票**无一进 T1 前列**（多为收阴 / 缩量 / 极高位 / 供给面票）。→ 说明 D 当日量价自证与其他四模式的逻辑几乎正交；**孰优孰劣未知，只能靠 forward 记分裁决**。
3. **排序公式偏好"单日放量反包小盘票"**（原型自陈）。这是只用量价一维的必然结果——**五基石中 策略命中 / 板块角色 / 催化 / 宏观 regime 均未进排序**。→ D2 的排序必须是**多基石合成**（量价只是一维），闸门是"入池资格"而非"选票依据"。
4. 排雷层与价位回填层可用：慢变字段排雷有效（5 只全为财报红旗）；单调性回填（挂单 / 红线 / 止损）正常。

## 4. 原型能力清单（可复用进 D1 工具）
- `shared_pool`：全A K 线扫描 + 条件池（→ `shared_pool_tool` 起点）
- `gate`：T1/T2/T3 分层（→ `gate_tool`，阈值待重标定）
- `score`：量价自证分（→ `price_volume_tool` 的一维输入，非最终排序）
- `veto`：慢变字段排雷（→ `financial_redflag_tool` / `money_chip_tool`）
- `entry_price`：D+1 开盘附近限价 + 单调夹逼（→ `entry_price_tool`）
- `market_ew`：kline 全A等权自算（→ H4 方案）

## 5. 缺的（原型自报 + 统筹补）
- 策略命中 / 板块角色 / 催化 / 宏观 regime 四维未进排序；经验规则库未接；假利好排雷仅靠 LLM 网络核验（应程序化：兑现日高开走弱 + D-1 回看）；per-stock 排雷字段覆盖不全（三只 T1 头部均无档）。
