# 弱策略三合一诊断:S02 / S03 / S04(优化 or 删减)

> 日期:2026-08-28 · 线D(feat/weak-strategy-triage) · ⚠️ 非投资建议 · **诊断+建议,供合作者共评;不直接删策略、不改 strategy.json**。
> 触发:成绩记分卡(base-rate 超额)坐实这三个近端跑输市场(S02 近一月5日超额 −10.5、S03 近一周1日 −5.1、S04 近一周1日 −9.7,全场最差)。
> **命名对照**:S02=策略2;**S03=策略7**、**S04=策略8**(S03≠策略3,历史代号错位,见策略总览)。

## 0. 方法与口径(先说清)
- **变体实验脚手架**:`scratchpad/triage_harness.py`(本分支已 commit)。walk-forward,逐 (票, 测试日 t) 用各 screener 的 `signal_at(kdf, t)`(只用 ≤t)判命中,记 T+1/5/10/20 前瞻收益 `close[t+k]/close[t]−1`(纯标签)。
- **样本**:全 master 随机 **277 只**(排北交所)× 深历史(2018-01~2026-08,长上市票 ~2100 根/票)× 测试日步长 12。baseline 前瞻样本 **n=35512**。
- **基准(baseline)**:同测试日全体抽样票前瞻均值(等权,市场方向/水平代理)——与既有报告"baseline 全样本"同精神;**本分支无 HS300 index**,故未用沪深300,用等权代理。
- **超额**:hit 组均值/胜率 − baseline;>0 才叫方向跑赢同期市场面。
- **regime 门测试**:等权指数 vs 其滚动 MA60(只用 ≤t)打牛/熊标,测"只在牛市发信号能否救活"。
- **防未来函数自审**:signal_at 只用 ≤t;前瞻收益、MFE、baseline、regime 全部只用 ≤t 或作结果标签,无泄漏。
- **成本假设**:A股单边约 0.07~0.15%(佣金+印花税卖出+滑点),**往返 ~0.2~0.3%**。超额 mean 须显著高于此才有净 edge。

## 一、S02 放量后缩量回踩(策略2)——【结论:优化/救(窄门,且救点在离场不在入场)】

### 真因诊断(带数字)
- **入场有真·短周期 edge,但很薄**:深历史 277 票、命中 **n=322**,超额 mean 全周期为正:T1 **+0.21%**、T5 **+0.54%**、T10 **+0.26%**、T20 **+1.47%**(T20 靠右尾,胜率 47.8% < 基准);胜率 ~48–52% 贴近基准。与既有深历史持仓回测(S01 离场)Alpha **+0.09~+0.40%** 同向。
- **记分卡近端 −10.5 主要是"口径 + 低吸本性"造的假弱,不是入场没信号**:S02 是**收阴收跌+地量+贴MA10 的逆势低吸**;记分卡量的是"信号日→T+5 **收盘**方向",**不套 S02 的离场**。故 5日**期末** 30%(方向对但回落没守住)、而 5日**期内触及** 91.8%。
- **MFE 铁证**:S02 命中后 5 日内**盘中最高价**相对信号日收盘:**均 +5.77%、中位 +3.62%、96.3% 的票触及正 MFE**。→ 入场确实抓到了一次反弹,edge 在**早段/盘中**兑现,**持有到收盘就还回去**。
- **入场过滤救不了(已被前人坐实,勿重蹈)**:Minervini 趋势过滤深历史 A/B 从 sample800 的 +1.26%(p=0.042)**加样本到 1500 打回 +0.45%、p=0.33 不显著**(见 `两策略优化总结_箱体v2与S02趋势过滤.md`)。本轮我加的 **close>MA50 变体**同样只是脆弱抬升(超额 T10 +0.42%,牛市门内更弱 +0.08%)——**同一个随样本衰减的假象,不作为救活依据**。

### 结论:优化/救——但救点=**离场器**,不是再堆入场过滤
数据一致指向:入场有薄 edge + 兑现在早段 + 收盘回吐 → **换一套吃到 MFE 的离场**最可能把薄 edge 转成净正。

### 若救 · 下一步(预注册判据)
1. **实现**:S02 专属离场变体——止盈优先(触及 +X% MFE 即止盈,X∈{3,5,8} 扫描)/ 更短时间止损 / 追踪止盈;复用 `position_backtest` 状态机,新增止盈规则,默认关、零回归。
2. **回测**:`backtest_s02 --ab`,A=现 S01 离场 / B=新止盈离场;深历史全A;相对基准 Alpha + **Welch t 检验** + **样本稳健性(800→1500→3000,专防前人那种 800→1500 衰减)** + **扣往返 0.2~0.3% 成本**。
3. **预注册成功判据(全中才算"救活"、才建议合并)**:
   - 扣成本后 Alpha **显著 >0**(p<0.05)**且随样本增大不衰减**(1500、3000 仍显著同号);
   - 即死率不升(≤现 ~34.8%);
   - B 相对 A 的提升主要来自"少还回吐"而非新增右尾。
   - **任一不满足**(尤其扣成本后转负或随样本衰减)→ 判**删/降级为观察池**。
- **扣成本后是否仍正的合理预期**:边际正、但不稳。裸超额 T5 +0.54% 高于往返成本,但持仓回测 Alpha 仅 +0.09~0.40%(已含成本),**净空间很窄**;能否显著为正取决于止盈能锁住多少 MFE。**诚实**:这是"值得再试一轮离场 A/B、但门槛没过就该删"的窄门,不是稳赢。

## 二、S03 最大范围选股(策略7)——【结论:删减】

### 真因诊断(带数字)
- **深历史无 edge(全周期超额为负)**:命中 **n=3692**,超额 mean:T1 **−0.17%**、T5 **−0.55%**、T10 **−0.29%**、T20 **−0.86%**;超额胜率 T1~T20 **−3.2 ~ −5.9pp**(处处低于基准)。
- **既有"正 edge"是牛市窗口假象**:2026-08-21 报告的 T+10 +1.13% 是 **250 只 / 27 日 / 2025-04~2026-07 单一偏多窗口**的样本级 sanity(报告自己标注"非全A alpha");拉到 2018-2026 深历史后**反号为负**。
- **regime 门也救不活**:只在牛市发信号,超额仍全为负(T10 −0.08%、T20 −0.50%、胜率 −2.5~−4.6pp)。
- **根因=追高/动量画像**:S03=250日高位比+均线多头+近期大阳,本质**追强势**;A股短期反转惩罚追高(与 策略4 动量 IC 显著为负、S01 追高 −1.06% 同根)。**无"入场有 edge 被离场拖累"那类可修错配**——是**根本无 edge**(像被否的 DB01)。

### 结论:删减
建议**从计分/选股展示中下线 S03(策略7)作独立信号**。若合作者仍想保留其"强势画像"过滤价值,最多降级为**不计分的观察池标签**(且须标注"深历史超额为负、非买点")——但作独立选股信号无依据。
### 门槛对照
"救"的门槛=具体可修根因 + 扣成本后有正 edge 预期。S03 **两者都给不出**(无 edge、regime 门无效、根因是策略类型本身)→ 判删。

## 三、S04 量价放量(策略8,3 子信号)——【结论:删减(三个子信号均判删)】

### 真因诊断(带数字,按子信号)
- **整体无 edge**:命中任一 **n=1307**,超额 mean T1 −0.09%、T5 **−0.98%**、T10 −0.76%、T20 −0.85%;胜率超额 −4.9~−7.1pp。牛市门内仍负(T10 −0.48%、T20 −0.47%)。
- **单日放量(n=651)**:超额 mean 全负(T5 −1.11%、T10 **−1.42%**、T20 −1.34%)。2026-08-21 报告的 T+10 +2.64% 是牛市窗口假象,深历史反号。
- **连续放量(n=823)**:全负(T5 −1.28%、T10 −0.67%、T20 −1.14%),胜率超额 −5.9~−8.9pp。同上,牛市窗口正、深历史负。
- **低位放量(n=156)**:最不差但仍不合格——mean 超额 T1 +0.46%、T20 +1.13%(右尾),但 **T5/T10 mean 超额为负、且胜率超额处处为负(−0.7~−5.4pp)**;既有报告本就标"样本内无 edge"。**不是可靠买点**。
- **根因=追放量突破/上涨=见光死**:与 S02 互补方向(买放量本身),正落在项目反复坐实的"追突破即死"上。**无可修错配,属根本无 edge**。

### 结论:删减
建议**下线 S04(策略8)三个子信号作独立买点**。若合作者坚持保留 **低位放量** 作观察项,须标注"深历史胜率低于市场、mean 靠右尾、非买点";单日/连续放量无保留价值。
### 门槛对照
无具体可修根因、扣成本后无正 edge 预期(裸超额已负,遑论扣 0.2~0.3% 成本)→ 判删。

## 四、自审
1. **防未来函数**:signal_at/indicators 只用 ≤t;前瞻收益 close[t+k]、MFE high[t+1:t+6]、baseline、regime(指数 vs 滚动 MA60)全部只用 ≤t 或作结果标签,无泄漏。变体(MA50 门、regime 门)同样只用 ≤t。
2. **每结论有数据支撑**:均带 n 与超额数字(S02 n=322、S03 n=3692、S04 n=1307),非拍脑袋。
3. **救的下一步可验证且预注册**:S02 离场 A/B 判据(显著 + 样本稳健 + 扣成本 + 即死不升)已钉死;明确"任一不过就删"。
4. **三策略不混口径**:各自独立 collector、各自命中样本;S04 三子信号分桶;baseline 同测试日全体、对三者一致。
