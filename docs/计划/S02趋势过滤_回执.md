## 4. 是否改善?——**否(本数据上未改善,且统计力/外部效度双弱,不定论)**

- 过滤后**胜率反降**(22.4% vs 26.1%)、**Alpha 基本持平略差**(−0.35% vs −0.31%);唯一变好的**盈亏比**
  (3.04 vs 2.25)是「胜率降 + 单笔赢更大」的再分配,**净期望未抬升**。PASS/FAIL 两组 Alpha 不可区分(p=0.87)。
- **命中预注册的「失败最可能」**:A 股趋势股缩量回踩后**仍均值回归**,趋势门筛出的强势子样本并未更优
  (呼应本项目「均线多头 + 追高显著为负」的铁律)。
- **不定论的原因**:趋势门需 252 根 → 本地 335 根只剩**尾部单一 ~4 个月行情段**;此窗内**连原版 A 都比历史基线差**
  (窗内 26.1%/−0.31% vs 历史 31.6%/+0.14%),改善/变差被 regime 混淆。**要定论须更长历史 + 跨多个行情段复验**。
