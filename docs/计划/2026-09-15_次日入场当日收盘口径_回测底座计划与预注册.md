## 0. 要回答的 gate 问题

**"D 晚选股 → D+1 按估量入场价买 → 目标 D+1 收盘绝对为正" 这套口径，在真实历史上有没有可用的正胜率与正期望？**
- 哪种入场档最优：开盘价 vs 限价（回踩昨收/开盘×(1−k)）vs 震荡低点？
- 弱市避开高 β 票能提升多少绝对胜率？（验证 §4 "β 脆弱票该被过滤"）
- 观测窗 T_obs（早盘 vs 全天）对触发率/胜率的影响？

## 1. 数据与样本（诚实边界）

- **价格**：主仓 `data/master/kline/<code>.parquet`（`--data-root` 只读），5563 票，2018-01-02→2026-09-14。排北交所(8/4 头)。
- **市场基准**：全 A 等权。两口径——`mkt_ir[d]`=当日 open→close 等权均值（日内基准，对齐"入场→收盘"持有窗）；`mkt_ret_cc[d]`=昨收→今收等权均值（算 β 用）。
- **T_obs 硬限制**：分钟级 intraday 仅 8 天(2026-09-03~09-14)历史。**日线 K 无法区分"9:30–10:00 触及"与"全天触及"**——真·T_obs 早/全天敏感性历史不可回测。处理：主回测用"全天触及"(low≤P)口径；T_obs 早/全天差异用现有 8 天分钟数据做小样本 side-check + 在报告里标为**数据受限、需分钟数据补**。
- **历史 live 选股**：canonical `每日选股.json` 仅 1 天(2026-09-14 新 schema 起)。**无历史 live 选股流可回测**。替代：
  - **全 A 基准**（每票每采样日=一个候选）→ 无条件基线 + 入场档对比 + β/regime 分层的**主证据**（样本量大、统计有力）。
  - **可复现 as-of 策略代理**（非 live 选股，明确标注）：①强势动量(close>MA20>MA60, 近月为正)代理"最强选股"；②超跌低换手(近 N 日跌+换手低分位)代理"反转低换手"。看入场档结论在"被选样"子集上是否稳健。

## 2. 入场成交模型（核心）

信号日 t（用 ≤t 信息），入场发生在 D+1=t+1。
- **基准档 `open`**：P=open[t+1]，必成交，ret=close[t+1]/open[t+1]−1。
- **限价档 `limit_pc_k`**：P=close[t]·(1−k)，k∈{0,0.01,0.02,0.03}（预注册网格）。
- **限价档 `limit_open_k`**：P=open[t+1]·(1−k)，k∈{0.005,0.01,0.02}。
- **震荡低点档 `dip_pc_k2`**：P=close[t]·(1−k2)，k2∈{0.03,0.05}。
- **成交模型（realistic marketable buy-limit，主口径）**：挂买入限价 P →
  `open[t+1]≤P` 立即以 open 成交（限价高于开盘=马上买到，价更优）；否则 `low[t+1]≤P` 则以 P 成交；否则**未触发**。
  ret=close[t+1]/fill_price−1。
- **doc-literal 成交（敏感性对照，设计 §3.1 口径）**：`low≤P≤high` 判成交、价取 P，否则未触发。跑一遍看定性结论是否一致。
- **成本敏感性**：对每档标注 −0.05%/−0.1% 单边滑点+手续费后的胜率/期望。

## 3. 收益 / α / β 口径（每单）

- **绝对收益** = close[t+1]/fill_price − 1（>0 记胜；未触发不计入胜率分母，单列"未触发率"）。→ **主指标/KPI**。
- **α** = 绝对收益 − mkt_ir[t+1]（全A等权同期，日内口径，对齐持有窗）。
- **β**：个股 60 日(min40)滚动 β = cov(ret_cc_stock, mkt_ret_cc)/var(mkt_ret_cc)，**as-of ≤t**（不含 t+1，防未来）。分桶：低(<0.8)/中/高(>1.2)。
- **β 归因（拖累判定）**：市场同期 m=mkt_ir[t+1]，β 贡献≈β·m。亏损单若 `m<0 且 β·m<0 且 |β·m|≥0.5·|绝对收益|` → 记 "β 拖累致亏"。
- **regime**：两种——
  - `regime_asof`（**可操作版**，选股时已知）：用 ≤t 的市场趋势（等权 5 日累计 + breadth=收盘>MA20 占比）分 普跌/震荡/普涨。
  - `regime_contemp`（描述版）：sign/分位 of mkt_ir[t+1]，确认机制。

## 4. 防未来 / 稳健性（硬红线）

- 入场价、成交判定、β、regime 只用 ≤t（regime_asof）或 ≤t+1 已确定 K 线（成交/收益）；close[t+1] 只作结果标签，**绝不回喂**入选/入场判定。
- k 网格**预注册**（本文写死），不 tune 到某几天。
- **walk-forward/OOS**：样本按日期切两段(2018–2022 / 2023–2026)分别汇报，看结论稳定性。
- 采样：`--stride`（默认 2）按日抽样；结论看各档**相对**优劣（配对同候选）而非绝对水平的过拟合。

## 5. 预注册 gate 判据（跑之前写死）

判"可行 / 有条件可行 / 不可行"，依据下列**先验阈值**：
1. **正期望**：至少一个入场档，其**净额（扣 0.1% 成本后）平均绝对收益 > 0** 且两段 OOS 同号。
2. **正胜率有意义**：该档绝对胜率 > 对应"未触发已剔除后的无条件基线胜率"（即入场规则要跑赢"随便买开盘"的基线），差值在两段 OOS 同向。
3. **入场档排序**：报出 开盘 vs 限价 vs 震荡低点 的胜率/期望/触发率三维，指出帕累托最优档（高期望但触发率过低=不可执行，用触发率作护栏，触发率<~50% 视为可执行性差）。
4. **β 脆弱性**：弱市(regime_asof=普跌)内，高 β 桶绝对胜率显著低于低 β 桶（差值 + 简单 z 检验），则"弱市避高 β"成立，量化其对绝对胜率的提升。
5. 若无任何档满足 1&2 → **不可行**，如实报，不迎合。
