## 本轮做了什么(为什么)

用户要迭代午盘全A选股两处短板:①没有复盘闭环(选了不验证 → 无法评估迭代);②输出侧重点不对(85 只全序、不聚焦「今日可买入」)。

### 1. 输出侧重点重构(短板 B)——`tools/pipeline/intraday_screen.py`
- 新增共享切分函数 `split_buy_avoid(重排, n_buy, n_avoid)`:**买入 5 只**(完整分 Top∩排除看空,**主评价对象**)+ **规避 3 只**(看空优先、补最低分,**纠偏参照**),买入/规避保证不相交。这是**输出侧与复盘侧的单一真源**,避免两处切分漂移。
- `render_intraday_md` 从「85 只全序」重构为【今日可买入】+【今日规避】两栏 + 行动/时效标注(`action_tag`:尾盘可买/次日观察/仅规避)+ **折叠的完整候选台账**(全序不丢,供复盘取数与审计留痕)。
- 为什么 5/3:用户拍板(D5)——午盘价值就看「买入选得准」,规避少量只为暴露/纠正模型系统性偏差。

### 2. 11:30 快照落盘(D1)——`intraday_screen.persist_noon_snapshot`
- 午盘节点已在内存持有全A 11:30 gtimg 快照,顺手落盘 `data/intraday/<date>/noon_screen_snapshot.json`(gitignored,不入库、不碰主档),供当日复盘算「下午」口径。防未来:只存 ≤11:30 冻结价。

### 3. 复盘闭环(短板 A)——新增 `tools/pipeline/intraday_review.py` + `tools.run intraday_review`
- **D-0 当日闭环**:午盘票 11:30 选出、当日收盘可得 → 当天就能记「下午 α」。这是盘后 eod-review(复盘 D-1)拿不到的时段,是午盘选股的差异化价值。
- 记分:**下午涨跌% = (当日收盘 − 11:30 冻结价)/11:30 冻结价**;**下午 α = 个股下午涨跌% − 全A下午等权基准**。基准复用唯一真源 `market_forecast.breadth.equal_weight_mean_pct`(不自算)。
- 切分复用 `intraday_screen.split_buy_avoid`(单一真源)。买入组=主评价、规避组=纠偏。
- 产 `docs/每日分析/复盘/午盘_<date>.md`(两组逐票记分表,α 列名 `α vs 全A等权` 兼容 web `_alpha_col`,**节标题避开「逐票收盘记分」不与盘后复盘表竞争选表**)+ 追加一行结论到经验 inbox `_待并入.md`(D8:由盘尾 eod-review 统一并版)。
- 防未来:收盘只取主档 `date == as_of` 的当日行(主档含未来脏行时绝不使用),已锁单测。

### 4. 阈值集中到配置真源(与 IET 窗的共享约定)——`tools/config/strategy.py`
- 买入 5/规避 3 + 复盘预注册闸门(分离度下限 0.30pp / 买入命中率下限 0.55 / 稳健窗口 10 交易日 / 下午基准取样率下限 0.60 / 强α判定线 1.0pp)集中追加到 `THRESHOLDS['午盘选股']`,**只在 THRESHOLDS 收尾前追加一个键、不重排**(避免与 IET 探针窗在同文件的合并冲突)。节点读配置带硬默认兜底。

## 预注册验证闸门(§4,先定达标线再评判)
- 主闸门(买入组):滚动 ≥10 交易日池化,买入组均值下午 α > 0 且「α>0」命中率 ≥ 55%。
- 辅助(纠偏):买入-规避分离度 > 0.30pp;塌陷则回查模型偏差,非一票否决。
- 硬红线:防未来 / 基准一致(下午口径) / 样本诚实。单日不判定。
