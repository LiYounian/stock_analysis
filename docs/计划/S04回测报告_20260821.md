# S04「量价放量」A/B 历史回测报告 · 2026-08-21

> ⚠️ **非投资建议**;历史统计非未来保证。
> ⚠️ **样本级方向性 sanity,非全A alpha**:250 只分层样本 + 27 个测试日(2025-04-02 ~ 2026-07-16,跨多行情段)。定位=过滤器/研究工具。

## 一、方法(无未来函数)
同 S03(见 [S03回测报告_20260821.md](S03回测报告_20260821.md) §一):`screen_volume.signal_at` 在测试日索引处判定,记 T+1/5/10/20 前瞻收益;对照 baseline 全样本 + HS300。**A/B = 按 3 个子信号(单日/低位/连续放量)分桶**,分别看各子算子的方向性。S04 为**看多型**。

## 三、诚实结论(按子信号)
- **整体方向对、edge 弱**:S04 命中组 **T+10 均值 +1.40% > baseline +0.36% / HS300 +0.50%**(符合看多设计),但胜率 45.4% 低于 baseline 47.9% → 同 S03 的**右偏/动量**特征,非机械买点。
- **单日放量**:方向最明显——**T+10 +2.64% / T+20 +1.92%**,显著高于 baseline;但 T+1 略负、胜率仅 ~37-48%(放量当日常冲高回落,收益延后到 1-2 周)。**作 1-2 周持有期的强势过滤有意义**。
- **连续放量**:温和正向(T+5 +0.90% / T+10 +1.88%),较稳,胜率 44-47%。可用。
- **低位放量**:**样本内无 edge**(T+5 −0.67% / T+10 −0.14%,n=43),胜率偏低。**如实标注:该子信号在本样本未验出方向性**——可能是"上穿 30 周线"在弱势/低位环境假突破多。**建议**:面板默认可勾但提示"未验出 edge",后续调参(周线周期 / 加量能确认)或缩小适用域,拿全A样本复验再定。
- **定位**:3 个可勾选子算子作**过滤器/观察池**;单日放量、连续放量方向性较好,低位放量待复验。命中≠必涨,需持有期。

## 四、近期肉眼验收
