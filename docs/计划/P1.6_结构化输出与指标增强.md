## 3. 每票结构化 JSON schema(data/analysis/{code}.json)

```
{
  "meta": {code,name,sector,industry,as_of},          # 静态
  "snapshot": {                                        # 当前快照(最新1日)
     "close,pct_chg, ma5/10/20/60, ma_arrange,
      macd{dif,dea,hist,state}, kdj{k,d,j}, rsi{6,12,24},
      vol_ratio, vol_state, bias20"
  },
  "valuation": {pe_ttm,pb,mktcap,pe_valid,mode,basis,报告期},  # 当前
  "fundamental": {营收,净利,营收增速,净利增速,roe,毛利率,净利率,负债率},  # 最近报告期
  "signals": {                                         # 派生判定
     "trend": {rating,score,reasons},
     "reversal": {label,score,flags,reasons},
     "ob_os": {verdict, resonance, per_indicator}
  },
  "fundflow": {today主力净流入,占比,5日合计,连续净流入天数},  # 派生自时间序列
  "events": [ {date,type,impact,title} ],              # 持续更新(公告流)
  "timeseries_refs": {kline:"data/raw/kline/{code}.parquet",
                      fundflow:"data/raw/fundflow/{code}.parquet"},  # 时间序列指针
  "provenance": {data_date, sources}
}
```
- **当前快照 vs 持续**:snapshot/valuation/signals 是当前值;kline/fundflow 时间序列不塞进 JSON,用 `timeseries_refs` 指针;events 是持续追加流。
