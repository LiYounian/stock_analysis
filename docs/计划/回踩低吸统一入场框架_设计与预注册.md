# 回踩低吸 · 统一入场框架 · 设计与预注册

> 日期:2026-08-14 · ⚠️ 非投资建议 · 源自策略提供者对箱体 6 问的回答(尤其第 4 条转折)。
> 纪律:先设计+预注册假设 → 实现 → 回测 → 诚实回填。

## 0. 缘起(策略提供者 4 条回答)
1. **箱体定义**:必须**真横盘矩形箱体**(上沿回落/下沿反弹),突破需放量+破上沿、最好当天涨停;**否定"抛物线加速"**(近期 300209 那种)。
2. **即死率**:**不接受高即死**;封死 v2"赢少赢大/右尾撑 Alpha"那条路。
3. **优化方向**:继续堆**入场过滤**(不转离场/消息面)。
4. ⭐ **关键转折**:**突破 = 只加关注、不操作**;等**股价回踩支撑 + 同时缩量**再进场、设止损。= 把 **S02 缩量回踩逻辑升格为所有突破类策略的统一入场方式**。

## 1. 与本项目数据的呼应(为什么这个方向对)
整轮回测反复证明 **"追突破/追新高 = 即死/见光死"**:动量 IC 显著负、创百日新高追高负(均线多头+追高 −1.06%)、箱体 v2 突破日进场即死 67%、PEAD 见光死。**提供者的解法(不买突破、买回踩低吸)正是数据指向**——这是第一个**数据预测"会真的降即死"**的设计。

## 2. 框架设计:两段式(观察 → 回踩缩量进场)
**Stage 1 · 突破 → 加观察池(不进场)**
- 触发源(可插拔,任何"突破类"形态):**严格箱体放量突破**(收紧后的 detect_box)/ 创 N 日新高 / 其它突破。
- 记录:突破日、**突破位/箱顶(= 后续支撑参考)**、观察窗(如突破后 M 个交易日内有效)。

**Stage 2 · 回踩缩量 → 进场信号(统一买点 = S02 逻辑)**
- 观察池内的票,在观察窗内,当日同时满足:
  - **回踩到支撑**:收盘回踩到 突破位/箱顶/关键均线(MA10/MA20)附近(带容差),未有效跌破;
  - **缩量**:当日量 ≤ 前 N 日均量 × 缩量系数(复用 S02 地量口径);
  - (可选)**趋势仍在**:未跌破 MA/箱体下沿,均线多头未破。
- **进场** t+1;**止损** = 支撑(箱顶/突破位)下方一个 buffer。
- **离场**:沿用 S01/S02 状态机 或 支撑破位。

**复用**:Stage-1 箱体检测 = 收紧到严格横盘的 `detect_box`(revert v2 的振幅带放宽/软化,回到硬横盘);Stage-2 = S02 `screen_s02` 的缩量回踩算子,泛化为"对任意观察池票"判回踩缩量。

## 3. 箱体收紧(据答①②)
- 严格横盘矩形:**振幅带回窄**(如 [8,20]%,不放到 30)、**触碰≥2/横盘/缩量由软改硬**(不再"结构分≥下限"放行)、突破需放量+破上沿(可要求当天涨停作强确认)。
- 目的:配合答②**降即死**——严格箱体 + 回踩低吸双管齐下。

## 4. ⭐ 预注册假设(实现前钉死)
| 假设 | 成功判据 | 若不成立·最可能原因 |
|---|---|---|
| **回踩缩量进场 即死率 << 突破日进场** | 新框架即死率显著低于箱体 v2 的 67%(目标 <40%) | 回踩后继续下跌(接下跌中继)、支撑无效 |
| **回踩缩量进场 Alpha ≥ 突破日进场,且为正** | 相对沪深300 Alpha 显著 >0、且优于"突破日追高" | A 股回踩也不反弹 / 缩量回踩信号少、样本不足 |
| 严格箱体(收紧)比 v2 均衡口径 即死更低 | 收紧后即死明显下降 | — |

**总预期(诚实)**:降即死这条,数据强烈支持(低吸 vs 追高);**能否转成显著正 Alpha 仍需回测**——A 股回踩后是否反弹是未知数(反转市对低吸有利,但"接下跌中继"也常见)。这是**第一个方向和数据都对、值得认真做**的入场框架。

## 5. 执行计划
- 新分支实现两段式框架(Stage1 观察池 + Stage2 回踩缩量进场),复用 detect_box(收紧)+ screen_s02 回踩算子。
- 回测:**新框架 vs 箱体v2突破日进场 vs S02原版**,同口径(离场/基准/深历史 8.4 年多 regime),重点看**即死率 + Alpha + 显著性**;无未来函数(观察/回踩只用 ≤t)。
- 回填结果 + 对照预注册。

## 6. 结果与分析(实现后回填)

实现见 `feat/pullback-entry-framework`;三组同口径 A/B/C 回测(N=1200 抽样,深历史 2018→2026,
相对 HS300,信号 t+1 开盘进场、S01 离场)。完整回执见 `docs/计划/回踩低吸框架_回执.md`。

| 组 | 即死率 | 中位收益 | 胜率 | 平均Alpha(聚类t/p) |
|---|---|---|---|---|
| A 回踩缩量进场 | **36.8%** | **−1.31%** | 32.5% | +0.24%(t=1.61 / p=0.107 不显著) |
| B 箱体v2突破日进场 | 67.7% | −3.00% | 25.5% | +0.78%(t=7.60 显著) |
| C S02 原版 | 34.8% | −1.15% | 32.9% | +0.40%(t=9.01 显著) |

- **§4 假设一(降即死):达成** —— A 36.8% << B 67.7%(< 40% 目标;B 与预注册 67% 吻合)。中位/胜率亦明显改善。
- **§4 假设二(Alpha ≥ 突破日 且显著为正):未达成** —— A Alpha 正但 **低于** B 且不显著。
  与本文 §4「总预期(诚实)」一致:A 股回踩后均值层面不更反弹,且回踩低吸砍掉了突破日进场的右尾大赢家。
- 定性:本框架是**"守"的入场法**(即死腰斩、坏情况变好),不是均值 Alpha 放大器;用均值 Alpha 换低即死+稳中位。
