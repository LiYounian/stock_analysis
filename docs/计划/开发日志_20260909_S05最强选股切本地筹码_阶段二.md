## local vs tushare 行为差异
- `local`(默认):不看 `is_configured()`,不触网;每票本地推演 ④;换手缺失/数据不足 → 该票无筹码 →
  ④False 不选(计入 `筹码不可用数`),不写「需 Tushare」占位;present 恒 True。
- `tushare`(回退):与切换前逐字节等价——未配 token / cyq_perf 取不到 → present=False + 「需 Tushare」占位;
  配 token 但取不到 → WARNING(三分法告警不变)。

## 量纲坑(重点)
本地 `获利比例` 是 0~1 小数,直接喂 `wr > 95.0` 会恒 False。适配层统一 ×100 转百分数,复用现有阈值 95.0。
测试 `test_local_dimension_lock` 锁死:0.98→98%>95 入选、0.90→90%<95 不选,防未来重写写反。
