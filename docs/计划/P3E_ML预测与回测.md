# P3.E · ML 预测 + 回测(计划,第二阶段)

> 状态:**已设计,待启动**(建议在统计版有一段真实表现基线后再上)· 编写 2026-08-05
> 目标:在统计版预测之上,用机器学习预测 n 日收益,并以**严谨回测**证明是否优于统计基线;
> 不优于则不上线(诚实性:宁可不做,不做自欺的过拟合模型)。

---

## 0. 为什么先设计后做(决策留痕)

- A 股信噪比低、样本少(单票约 1 年日线),ML 极易**过拟合**,回测不严会自欺。
- 必须先有**回测框架**(样本外验证)+ **统计版基线**,ML 只有显著超越基线才有价值。
- 故本阶段**独立成期**,不与前面赶工混做;建议前面统计版跑一段、积累真实数据后启动。

---

## 1. 拆解

### P3E.1 回测框架(先行)`analysis/backtest.py`
- 时间序列切分:滚动窗口 / walk-forward,严格**样本外**。
- 评估指标:方向准确率、n 日收益 IC/RankIC、分层回测收益、最大回撤。
- **基线**:统计版(predict.scenarios 的上涨概率)作为对照基准。

### P3E.2 特征工程 `analysis/features.py`
- 技术:MA 斜率、MACD/KDJ/RSI/BIAS、量比、拐点分、距高低点位置。
- 资金:主力净流入(近1/5日)、连续净流入天数、主力占比。
- 基本面/事件:PE 有效性、ROE、近期公告方向计数。
- 标签:未来 n 日收益(回归)或涨跌(分类),n∈{1,5,10}。

### P3E.3 模型 `analysis/ml_model.py`
- 从简单稳健起步:Logistic / GBDT(LightGBM/XGBoost)。
- 交叉验证用时间序列 split;正则 + 早停防过拟合。
- 输出:n 日上涨概率(校准后),与统计版并列展示。

### P3E.4 集成
- 若回测显著优于基线 → serialize 的 prediction 增 `ml` 子块;Web 个股页并列"统计 vs ML"。
- 否则:保留统计版,记录 ML 未达标结论(同样是有价值的结论)。

## 2. 依赖 / 环境
- 新增:scikit-learn、可选 lightgbm、scipy。装入 conda `stock_analysis`。
- 需要更长历史(多拉几年日线)以扩样本;跨票 pooled 训练缓解小样本。

## 3. 验收标准
- [ ] 回测框架样本外、无未来函数(用测试钉死"不泄露未来")。
- [ ] ML vs 统计基线有明确对比结论(方向准确率/IC)。
- [ ] 仅在显著优于基线时上线;否则保留统计版并记录。
- [ ] 全站仍标注非投资建议。

## 4. 风险
- 过拟合(核心风险)→ 样本外 + 简单模型 + 跨票池化。
- 数据泄露(未来函数)→ 特征只用 t 时刻及以前;测试专门校验。
- 小样本 → 扩历史 + pooled;不行就诚实收敛到统计版。
