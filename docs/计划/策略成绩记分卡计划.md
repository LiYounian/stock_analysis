# 全策略上线以来成绩记分卡 · 计划

> 分支 feat/strategy-scorecard。内容窗口·线A。产物只落 worktree,不 push、不碰 main。

## 目标

用**上线以来的观测数据**(`data/analysis/<日期>/<策略>.json`),校验每个**已上线**策略当天给出的
**1日 / 5日**预测方向准不准,出一份**分策略成绩报告**,标出"回测差 ∧ 真实观测也差"的差生候选。

## 数据源与口径

- **预测来源**:每日各策略 view JSON。字段 `as_of` = 预测日 T;选股清单里每个 `code` = 当日预测标的。
  - 多数策略是**纯多头选股**(选出=看多)→ 预测方向 `+1`。
  - `策略0合议` 每票带 `综合方向`(看多/看空/中性);`指标条件化状态排序` 的 `排行` 按 `1日/5日/10日`
    分组、每票带 `方向`(多为中性)。方向映射 `{看多/看涨:+1, 看空/看跌:-1, 中性:0}`;方向 0 不计命中。
- **实现收益**:`tools.collectors.market.load_kline(code)` 的前复权收盘/最高/最低。
  预测日 T 定位为 kline 里 `date==T` 的下标 `idx`;horizon h 的实现收益 `close[idx+h]/close[idx]-1`。

## 三条硬规则(编码进校验 + 单测锁死)

1. **每个 (预测日, 期限) 独立评判 + 防未来函数**:horizon h 仅当 `idx+h < len(kline)` 才算**已到期**;
   否则 pending,**排除出统计**。kline 最大日期 = 最近交易日 ≤ 今天 → 天然无未来函数。
2. **中途翻转不反算**:逐 (日期) 独立评估,T 日预测只对 `T→T+h` 窗口打分;T+2 的另一次预测
   不回溯影响 T。按日迭代天然满足;单测构造 T 与 T+2 反向预测锁死。
3. **5日"涨"命中双口径**:
   - (a) **期末**:`close[idx+h]/close[idx]-1`,方向感知命中(+1 看收益>0,-1 看收益<0)。
   - (b) **期内(触及)**:5日内 `max(high) > close[idx]`(看多)/ `min(low) < close[idx]`(看空)触及即算。
     对占绝对多数的多头选股,(b) 即用户所说"期内涨过"。1日只报期末(无期内歧义)。

## 产物

- 结构化 `data/analysis/backtest/strategy_scorecard.json`:每策略 样本量(1d/5d)、1日命中率、
  5日命中率(期末/期内两栏)、薄样本(<30)标注、差生候选。
- Markdown 摘要 `docs/策略成绩报告.md`。

## 差生判据

**同时**"已有回测结论偏弱 ∧ 观测命中也低(且样本不薄)"才列差生候选;单一维度差只提示、不判死。

## 模块划分

- `tools/backtest/strategy_scorecard.py`:
  - `_DIR` 方向映射常量;`extract_picks(view)`→[{code,dir,horizons?}];
  - `forward_returns(code, date, horizons)`→{h:{r, hit_end, hit_intra, matured}};
  - `build_rows(analysis_dir, dates, horizons)`→DataFrame(逐 pick 一行);
  - `aggregate(rows)`→每策略成绩;`write_report(...)`。
- `tests/test_strategy_scorecard.py`:锁"中途翻转不反算""双口径""防未来函数(pending 排除)"。
