## 0. 先钉死:这次回测的到底是什么(防重蹈 S01 前提错误)

`predict.py` 对某只票、在某个交易日 t(只用 ≤t 的数据)产出三样:

| 产物 | 字段 | 我们要验证它的什么 |
|---|---|---|
| **波动率括号** | `持有期建议[N].止损位/止盈位` | 这个 ATR×√N 括号画得合不合理(触发率、区间校准) |
| **情景分布** | `情景预测[N].上涨概率%/q10/q50/q90` | 这个历史频率预测校不校准 |
| **L3 结构锚定** | `结构位.锚定.止损位/止盈位/盈亏比/情景` | 你最关心的两条线:止盈先于止损命中没有、盈亏比是不是真的正期望 |

**明确不验证的**(避免又画错靶):
- 不验证"这两条线能预测涨跌方向"——设计上它们**本来就不预测方向**(见 [止盈止损预测_现状与深做方案.md](止盈止损预测_现状与深做方案.md) §三)。方向 edge 在合议/形态里,不在括号里。
- 因此"能不能赚钱"这个问题,**只在第 5 项(叠加方向信号后期望)里回答**,不苛求括号本身产生 alpha。

> 一句话:前 4 项测"这套统计构造**自不自洽/校不校准**",第 5 项测"叠加方向信号后**能不能赚钱**"。两者分开报,不混。

## 1. 五个指标的精确定义(事件研究法)

对每只票、每个可回测日 t(要求 ≤t 有 ≥60 根 K 防冷启动)、每个持有期 N∈{1,5,10}:
用 `df.iloc[:t+1]` 喂 `predict()` 得到当日的两条线与分布(**严格无未来函数**),再看 t+1..t+N 的真实 OHLC 路径。

1. **止损触发率** = P(min(low[t+1..t+N]) ≤ 止损位)。对照组:同幅度随机止损。要**显著低于**随机,才说明止损位挑得有信息。
2. **止盈先于止损命中率** = 沿 t+1→t+N 逐日判定先摸到哪条:
   - 先摸止盈(high≥tp)记 TP-first;先摸止损(low≤sl)记 SL-first;同日两条都触及记 AMBIG(保守按 SL-first 计,A股跌得快);到期都没碰记 NEITHER。
   - 报 P(TP-first)/P(SL-first)/P(NEITHER),并结合真实盈亏比算**期望** E = P(TP)×(+目标%) − P(SL)×(−止损%)。E>0 才算这套括号在本样本正期望。
3. **区间覆盖校准** = P(q10 ≤ 实际 r_N ≤ q90),应 ≈80%;附 [q25,q75]≈50%。偏离越大说明分布估偏窄/偏宽。
4. **上涨概率校准** = 把预测"上涨概率%"分箱(十档),每箱实际 P(r_N>0) 对比预测值 → 可靠性曲线 + Brier 分。**必须扣掉样本期基础漂移**(偏多窗口基数虚高),报"相对基准的校准"而非绝对命中。
5. **叠加方向信号后的期望** = 只在 `买卖倾向.结论=偏买入`(或合议看多)的 t 上,测第 2 项的 E、平均前瞻收益、胜率,对照"全样本无择时"基准。这是唯一回答"能不能靠它赚钱"的指标。

**两条线各测一遍**:波动率括号 vs L3 锚定,横向对比哪套更好(为后续取舍提供数据)。

## 2. 工程实现(先框架后填充,约法5)

新增 `tools/backtest/backtest_predict.py`,复用 `tools/backtest/engine.py` 的前瞻路径工具与无未来函数纪律(参考现成 `validate_l3_thresholds.py` / `pattern_forward.py`)。

- `build_panel(codes, lookback_min=60, horizons=(1,5,10))` → 逐票逐日无未来函数跑 `predict`,落一张长表:每行 = (code, t, N, 现价, 括号sl/tp, 锚定sl/tp, 上涨概率, q10/q50/q90, 前瞻实际路径的 min_low/max_high/r_N/先命中标签, 买卖倾向结论)。
- `metrics_from_panel(panel)` → 上面 5 个指标 + 分组(按 N、按情景标签、按趋势态)。
- `sweep_params(codes, grid)` → 对 ATR止损倍数(0.8~1.5)/止盈倍数(1.2~2.5)/τ_break(0.5~1.5%)/buffer/swing窗口(3/5/8/10)/放量阈值 网格扫,按"第2项E + 第1项误扫率 + 第3项校准"择优,**留出全A做样本外验证防过拟合**。
- 性能:自选池快跑用诚实的逐日 recompute(11只×~300日,秒级);全A(~5000×300)把热路径(ATR/pivot/分位)向量化,或抽样+分批。

**测试**(约法6):`tests/test_backtest_predict.py` 锁死①无未来函数(t 的预测只依赖 ≤t)②区间覆盖在构造数据上等于理论值③先命中判定的同日 tie 规则。断言锁住语义,防未来重写误删。

## 6. 第一轮结果(2026-08-12,自选池 11 只 · 9369 观测 · `tools/backtest/backtest_predict.py`)

> 实现:未拆多 agent,直接一个文件建全(逐日切片喂真 `predict()`+`technical.compute`,严格无未来函数,`tests/test_backtest_predict.py` 锁死)。样本 = 11 只自选、各~334 根日 K,**偏成长/科技 + 窗口偏多**,结论仅"本篮子本窗口",全A 复验前不定论。

**核心数字(N=5 日为例):**

| 指标 | 波动率括号 | L3 锚定 |
|---|---|---|
| 止盈先命中 % | 10.5% | 52.2% |
| 止损先命中 % | 7.7% | 11.0% |
| 到期都没碰 % | 81.8% | 36.7% |
| 均目标% / 均止损% | +18.4 / −11.5 | +7.0 / **−16.8** |
| 名义期望 E% | +1.1 | +1.8 |
| 实测均值% | +1.6 | +1.1 |

**四条结论(诚实版):**
1. **波动率括号太宽**:各持有期 ~80% 到期都没摸到任一条线 → 它在持有期内几乎不构成可操作触发,只能当"外层风控包络",不能当"会不会到"的预测。
2. **L3 锚定是"捡钢镚"形态**:止盈线贴压力(均目标仅 7%)→ 命中率高(52~64%);但止损放在支撑下方、平均远达 −16.8% → **盈亏比名义 <1、偶尔踩深坑**。高胜率不等于高期望。
3. **情景区间偏窄(肥尾没吃住)**:实际收益落在 [q10,q90] 只 64~69%(应≈80%),即 31~36% 落在区间外 → √N + 无条件分位**低估了尾部波动**(印证 L3 文档对波动率聚集/肥尾的担忧)。中位无偏(偏差≈0)。
4. **上涨概率几乎没校准**:Brier≈0.25(≈掷硬币),且**高分箱系统性高估**(预测 75~80% → 实际仅 65%)→ 无条件历史频率**信息量弱**,不宜当"胜率"呈现。
5. **方向信号(偏买入)在本样本无可测增益**:仅 7.1% 交易日偏买入,其上实测收益不优于全样本(N=10 括号 3.0% vs 3.5%)→ 本篮子本窗口**这套择时没跑出 edge**(n=221,样本小,待全A/更长窗口复验)。

**→ 指向的下一步(调参/升级候选):**
- 括号 ATR 倍数按持有期收窄(短周期尤其),让线在持有期内真正可触;
- L3 盈亏比 <1 的不对称需正视(要么止损上移、要么止盈放远,用数据择优);
- 情景分位改经验尾部/波动率聚集(EWMA)缓解低估,或直接放宽区间到校准 80%;
- 上涨概率需条件化(当前形态/位置)才有信息量,无条件版建议页面**弱化呈现或标注"校准差"**。

**尚未做(下一轮,需你拍板范围/成本):**

- 页面「策略体检」卡 + 更新 [预期价位预测.md](../策略/预期价位预测.md) 补验证结论。
