## 本轮做了什么（为什么）

搭一条**可复现、脚本化**的"统一大复盘"生成路径（KPI=**绝对收益**）：跨两条选股线（策略线 + 板块消息线）
+ 塔尖金字塔逐票，**join「当时依据」×「事后收益」→ 判对错 → 归因**。定位：在现有分线 forward 记分器
之上做**跨线 JOIN + 归因**，**不重造收益口径**（Model-A 撮合直接复用 `sector_news_forward`）。

**本轮性质 = 搭路径（筹备）**：脚本 + 测试跑通 + 冒烟即止；**全量 N 日大复盘运行等用户发令**。

## 怎么跑（CLI）

```bash
# worktree 内跑，--data-root 指主仓 data/（历史产物+master kline 在主仓）
python -m tools.review.build_grand_review \
  --dates 2026-09-11,2026-09-14 \
  --data-root /Users/yqg/Documents/projects/stock_analysis/data
# 单日 dry-run（只算不落盘、打印每日汇总）：
python -m tools.review.build_grand_review --date 2026-09-16 --data-root <data> --dry-run
```
- 落盘：每日复盘 MD→`docs/预测复盘/大复盘_<date>.md`；汇总 CSV→`data/analysis/backtest/grand_review_scorecard.csv`（gitignored）。
- 幂等：同 date 重跑覆盖当日全部行（D+1/D+2 到期后重跑=回填真实数字）。
- 选项：`--no-curated`（不含精选对照）｜`--build-ew`（α 源缺时尝试构建，否则 α=null）。

## 口径（统筹拍板·落定）

- **双列**：各线原生口径列（native）+ 统一 **Model-A 列**（跨版/跨线收益榜唯一可比）。
- **Model-A**：限价=D 收盘；D+1 `low≤限价`→成交@`min(限价, D+1 open)`，否则**未触发（不进胜率分母）**；
  `r_d1`=成交价→D+1 收盘；`r_exit`=D+1 收盘为正且未破 MA5→持到 D+2（r_d2），否则当日 D+1 离场（r_d1）。
- **主榜=r_exit**（含 D+2 了结）；**胜率=r_d1**（close_positive）。
- **α**=全A等权 `market_ew.parquet` 超额；**源缺→α=null 有声缺失**（绝不顶替/编）。
- **防未来硬红线**：只用 t≤date 数据 + 事后 master kline（无未来 bar=天然护栏）；未到期 pending 留 None；
  MA5 取信号日 `形态.ma5`（PIT）；as-of 守卫复用 sector_news_forward。
