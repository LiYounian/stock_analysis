# 策略计划 · 消息驱动板块拐点（"选热板块 → 龙头/成员拐点进场"）

> 日期 2026-09-15 ｜ 分支 `feat/pattern-strategy` ｜ 状态：**待统筹审 + 待与过冷过热chip协调接口**
> ⚠️ 测试环境研究模拟，**非投资建议**。不合 main、不换线（换线交统筹）。
> 来源：反推某成功投资者 16 只买点 + 朋友 MLCC 活样本（村田退出）。是"形态选股"chip 的方向演进——技术形态单独证伪后，锁定"消息驱动板块择时"为核心 edge。

---

## 0. 一句话

**消息催化（供给侧退出/涨价/禁令反转小作文）→ 识别板块正拐点（过冷转热 / 结构性利好）→ 在该板块的龙头/成员上、用"缩量回踩+高开反包"进场埋伏。** 消息层是核心 edge，技术形态是进场外壳（单独为负）。

---

## 1. 证据脉络（为什么这么定）

1. **反推 16 只赢家（校验后 14 有效）**：共性**不在技术形态**（双峰：有抄底有追强势），**在"押对当期热产业主线"**——消息面 13/14 落在 AI算力硬件+电子材料涨价周期，催化 71% 是板块题材联动。
2. **技术骨架单独证伪**：全A历史回测"缩量回踩+高开反包·买开盘" **α −0.9% 显著负**（追高开、均值回归）。→ 技术形态是外壳、单独亏钱。
3. **消息催化把亏钱动作变赢钱**：朋友 MLCC 活样本（2026-09-11）全流程验证成功——村田退出低端MLCC（利好·强4·结构性）→ 龙头 9-10 缩量回踩 → 9-11 高开+1.2%反包 → 风华涨停+10%。**是消息催化让"追高开"这个generically亏的动作赢了。**
4. **纯价量冷行业组合层失败**（前轮严验：热优先223% > 冷优先163%/回撤−30%）→ 印证"**光价量过冷不够，要消息催化确认拐点**"。

## 2. 策略三层结构

### 2.1 板块环境层（价量过冷过热）— **复用过冷过热chip，不重造**
- 消费 regime/行业温度计的**因果价量温度**（RS-动量/估值分位/换手分位 → 遇冷/遇热档）。
- 接口：`industry_heat(code|板块, date) -> 温度档/分位`（因果 PIT）。**确切签名待与过冷过热chip协调后填**（见 §7 待办）。
- 角色：给"这个板块此刻价量上是过冷还是过热"的底。

### 2.2 消息催化层（**本计划唯一新增模块 `sector_sentiment.py`**）
- **输入**：预置板块→龙头映射；各龙头当日 `sentiment/<code>.json`（`event.analyze_stock` 产物，含净情绪分/质量三态/持续性研判）；`sentiment_policy.json` 命中该板块的政策条目（含 region 国内/国外）。
- **聚合**（复用现成件，先定输入输出再填实现，约法#5）：
  - `板块净情绪 = Σ龙头(净情绪分×质量权重)/Σ质量权重`（只计 ok/partial，剔 unknown/missing——复用 `event._weighted_net` 三态，别让打分失败冒充中性）。
  - `板块结构性利好/利空数 = Σ龙头 persist_summary`（复用 `news_persistence`，判"真结构改善 vs 一次性催化"）。
  - `国际叙事分 = region==国外 且 industries命中该板块的政策条目聚合`（对应美股港股/禁令小作文）。
- **拐点信号**：板块净情绪的**因果 rolling 分位突破**（复用 `industry_temp.causal_rolling_pctile`，无未来函数）+ 符号翻转 + 当日有"印证强度=强/结构性持续"的根源消息。
- **角色**：这是核心 edge——判板块"由冷转热的正拐点 / 遇冷预警"。

### 2.3 成员进场层（技术外壳，只在消息-正催化板块内用）
- 龙头/成员出现"缩量回踩支撑"（量比<0.8、贴 MA20、上升趋势中）后，次日"高开反包"（开盘价买入）。
- 或退而用已验证的"回踩限价埋伏"（买低不追高，α 更好）——**入场口径回测对比 §5**。

## 5. 验证方案与统计口径（正视用户三点难点）

### 5.1 消息实时性 → 不做历史回测（硬约束）
消息数据只近端~1个月、时点不可复原。**消息层不假装 2018-2026 历史回测**；验证=**近端事件研究（MLCC 9-11 ✓ + 16赢家 + 往后新样本）+ 每日实盘前瞻跟踪**。历史回测仅用于技术外壳（已知单独负）。这是**事件驱动 + 实盘验证**范式，非"历史回测定生死"。

### 5.2 提前埋伏风险 → 显式统计
埋伏=限价挂单+明确止损。中途震荡损失用**持有窗内最大逆行 MAE** 显式报告 + 止损兜底；给"埋伏期回撤分布"，不藏震荡代价。

### 5.3 统计口径 1/5/10 日 → 当参数扫
持有窗 ∈ {1,5,10} 交易日全扫；**"有效"定义 = 窗内触及 +X% 明显盈利**（目标达成率），分窗报 目标达成率/收益/胜率/MAE。让数据说哪个窗口口径合理，不预设。

## 6. 防未来 / 防过拟合
- **消息 as-of 切片**：`baidu_news.news_asof(code, as_of)` 带真实 publish_ts，回测按 as-of 切、无前视；`event` 的新鲜度三态 date-pin。
- **因果分位**：板块情绪/价量温度分位一律 `causal_rolling_pctile`（≤t）。
- **样本诚实**：16赢家/MLCC 是活样本佐证、非证据；无反例（用户无），故消息层结论标"近端验证+实盘待累积"，不夸大。
- **不裸用技术外壳**（单独负）。
