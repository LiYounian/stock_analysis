## 五、集成流水线(统筹每次合并照做)
`git fetch` → `merge-base --is-ancestor` 判基 → `diff --name-only` 核范围(只碰本线目录、不碰中央文件/别线)→ 独立临时 worktree `--no-ff` 合 → push origin main → `remove --force` **仅**临时集成 worktree、内容线 worktree 收尾前先 `git status --ignored` 扫归档再**不带 --force** remove → 更新本表 + 开发日志。回归用 `revert -m 1`,绝不 force-push。
