## 2. k 的诚实处置(关键)

**现在无法可信标定 k**,原因(调研实测):
- 本 worktree **几乎无行情数据**(仅 000001、无 state_pool)→ 连技术上涨概率 p 都算不出、0 条前瞻收益;
- 即便在有数据的环境,消息面只覆盖 **近月约 3 个不同交易日、主要自选池**,收窄到"根源"后 **root_sig 非零仅约 1/4 记录、两根源同时非零仅 33 条**;按日聚类 t 的 `n_days≈3` → 统计功效≈0;
- 政策层 89% 为 0 且**行业共享**(同业同日近乎常数)→ 横截面区分度低、与日期效应混淆;
- 已有薄回测甚至提示**根源情绪 IC 偏反向**(见研究草案 §1.5)。

**处置**:`k=8.0` 是**实验默认值、非回测标定**(config 注释已写明);上线即为**收集前向验证证据**(需 k≠0 才有 p_adj≠p 可测),非表示已验证有效。**放行闸**:前向累积样本经按日聚类 t **显著为正**才上调 k;**反向/无增量则收敛到 0(可为负)**,并如实写 `回测报告_激进版消息面倾斜_YYYYMMDD.md`(退出判据不美化)。k=0 一键回滚纯技术。

## 3. 数据需求清单(交统筹 · 为把 k 标定/验证做实)

1. **回测环境要有行情**:k 标定/前向记分卡都需 kline(主档 + state_pool)与 sentiment **共处一个环境**;本 worktree 无行情 → 任何回测跑不出非空。→ 请指明/搭一个"行情+消息面齐全"的回测环境。
2. **根源消息的历史 + 广度**:要有统计功效,需 根源(政策+公司公告)信号覆盖**更多交易日 + 更多票**(不止自选池)。你正在修的"每日全量带消息面"正是此项;能否**前向每天全量落根源信号**,让样本自然累积。
3. **持续性(结构性)落进 record**:`news_persistence.py`(结构性/短暂分类)已实现但**未接入 serialize/记录**,现只能用"强度≥3"近似结构性。建议一个小任务把 `持续性/印证强度` 写进 sentiment 块 → 倾斜可用真结构性。
4. **`forward_scorecard` 加 `p_adj/hit_adj` 列**:用于前向累积"倾斜 vs 纯技术"的命中/Brier(方案见研究草案 §2①)。此脚本依赖行情,应在数据线环境跑;代码我可提供,你那边有数据可测/落地。
