# 反转策略「基本面/消息面否决层」· 实现方案

> 分支 `worktree-agent-a227baf26b97e0993`(基于 main）。承接 `docs/每日分析/策略建议/反转策略否决层.md`（诊断+§3提议+§4回测口径）。
> ⚠️ 非投资建议；历史回测≠未来保证。防未来函数=硬红线。

## 1. 命题

反转低换手策略（策略10）为**纯量价**打分（`combo_reversal_turnover_screen`），无基本面/消息面否决。
高分假阳性典型：技术超跌形态与「壳股/停复牌重组/游资博弈/基本面空心」重叠时无法区分
（样本外靶子：中南文化 002445 反转 0.83 假阳性）。给它叠加**否决/降级层**。

## 2. 四轴风险特征（命中任一→否决或降级）

1. **基本面空心**：最近可见报告期扣非净利为负 / 大幅下滑、主业萎缩。
   复用 `financial.analyzer.build_financial_block(code, as_of)` + `flags.high_flag_count(block)`（高危红旗剂量）
   + `利润表摘要.扣非净利增速`（大幅下滑门槛）。
2. **事件博弈**：近期停复牌重组 / 龙虎榜 / 交易异常波动。
   龙虎榜复用 `analysis.risk_veto.lhb_verdict_asof(code, as_of)`（as-of 严格 <）；
   停复牌/重组/异常波动从 `announcement.load_announcements(code)` 标题关键词命中（**自行按 date<as_of 过滤**，
   因 load_announcements 无 as-of 参数）。
3. **治理风险**：ST/*ST。名称标签 `config/code_name.json` + `"ST" in name.upper()`。
   ⚠️ 名称为当前快照、无 as-of（ST 状态粘性，回测里作近似，诚实标注）。
4. **重组未完成**：重组预期驱动但方案未过会/未完成（存终止风险）。公告关键词命中「重组/发行股份购买资产/
   预案/未过会/停牌核查」且无「完成/过会/实施完毕」。

## 3. 分层设计（与 codebase 纯因子→record→薄管线一致）

- **`tools/strategy/reversal_veto.py`**（新）：
  - `veto_verdict(features, cfg=None) -> dict`：**纯函数**，吃预抽取的四轴特征 dict，
    出 `{triggered, action(否决/降级/None), penalty, reasons, axes}`。config kill-switch + 分轴开关 + 模式 + 罚分。
    脱 IO 可单测（壳股命中 / 优质超跌不误杀 / 开关兼容）。
  - `extract_features(code, as_of, ann=None) -> dict`：as-of 安全 IO 层，复用上述数据源，缺数据保守降级（不误否决）。
  - `veto_asof(code, as_of) -> dict`：extract + verdict 便捷入口。
- **`tools/strategy/reversal_turnover.py`**：`combo_reversal_turnover_screen` 打分后按 record 挂的
  `rec['风险特征']` + config 应用否决层——降级=综合分减罚分（沉底、标「高风险博弈」）、否决=剔除/强制沉底。
  无特征 / 开关关 → no-op（向后兼容，纯量价现状不回归）。
- **`tools/pipeline/screen_reversal_turnover.py`**：开关开时对候选逐票 `extract_features` 挂 `rec['风险特征']`，
  view 里报否决命中数与归因。
- **config** `THRESHOLDS['反转否决层']`：`启用`(kill-switch) + `模式` + 分轴开关 + `每轴罚分`/`罚分上限`
  + 关键词表 + `否决沉底保留展示`。

> 为何不动共享的 `risk_veto_adjust`：它被 council/web/多回测共用且已重测，扩轴有回归风险；
> 反转否决层是策略专属，独立模块 + 复用底层数据源，符合「不改无关代码」。

## 4. 回测口径（A/B）· 数据可用性诚实说明

- **数据现实**：全A kline 历史齐全（5552 票），但**财报/龙虎榜/公告 raw 快照仅约 2026-08-06 起**（~24 采集日）。
  → 事件/龙虎榜轴无法长历史严格回测；财报 raw 单快照含 12 期（disclosure_date），故**基本面轴可按 as_of 回溯 ~3 年**；
  ST 名称当前快照作近似。
- **可行 A/B**（`tools/backtest/backtest_reversal_veto.py`）：复用 `backtest_reversal_turnover.build_rt_panel`
  取历史反转高分票 + T+5/T+10 前瞻收益。
  - A=纯量价反转 TopK；B=A+否决层（基本面+ST 轴，长历史可跑）。
  - 指标：① 反转高分票 T+5/T+10 胜率/前瞻收益（B vs A 不劣化）；
    ② **踩雷率**=高分票 T+10 内最大回撤 < -15%（纯价、可长历史算）；B 是否显著降；
    ③ **误杀率**=非踩雷高分票被否决占比。
  - 达标：踩雷率显著降 + 胜率/收益不劣化。
- **样本外**：002445 中南文化——B 下应被否决/降级（用现存快照全轴）。
- 事件/龙虎榜轴不足以长历史回测的部分**如实说明**，仅在近窗 + 案例验证。
