# 大盘预测策略 · 计划文档

> 建档 2026-09-02。需求来自用户：制定针对**整体大盘 + 主要板块**的涨跌预测，由**技术指标 + 消息面 + 资金流向**共同参与，用于选股时**剥离β、算个股α**。
> ⚠️ 非投资建议：测试环境研究模拟。状态=**规划（待审）**，审阅后走实现窗+回测，达标才接生产。

---

## 1. 为什么做（动机）

2026-09-02 普跌日：昨晚选的 5 只在大盘-1.05%/创业板-2.70%里全绿，暴露选股**完全没有市场β维度**——把β当成了选股胜负。有了大盘预测，选股时就能：预判次日大盘/板块环境 → 设定β基准 → 把个股预测拆成 **α(个股能力) + β(大盘水涨船高)**，买入表态更准。

## 2. 数据家底（勘察结论，2026-09-02）

**现成可用（金矿）**：
- **全A个股日K** `data/master/kline`（5552只，回溯**2022**）→ **市场广度可完全重算**（涨跌家数/涨停跌停/新高新低/破位广度），且**可历史回测**。当前最大资产。
- **指数日K** `index.py`（沪深300现成；创业板/科创50/中证1000等扩采一行配置即得）。
- **技术指标库** `technical.py` 直接吃指数K线算 MA/MACD/RSI/KDJ/BOLL/量能，零开发。
- **市场级消息面** `sentiment_policy.json`（每日~50条政策/宏观，LLM已判**方向+强度1-5+受影响行业**，~22-26天历史）。
- **市场状态雏形** `regime.py`（五因子平权→情绪分0-100→五档冰点/熊/震荡/分化/牛）——**已是市场级、可复用作骨架**。
- **资金流代理**：全市场龙虎榜净买合计、大宗溢价情绪、成交额总量/环比。

**缺口**：
1. **市场级资金流采集器缺位**（现 fundflow 只24只自选+陈旧）。需接 akshare `stock_market_fund_flow`（大盘资金流）+ 市场级北向 `stock_hsgt_north_net_flow_in`（个股北向2024-08已停，但**市场级净买仍披露**）+ 两融余额。均免费未接入。
2. **市场广度聚合器缺位**（底料在，缺"每日涨跌/涨停/新高家数"的落盘模块；regime里该因子当前恒降级）。纯本地计算。
3. **指数覆盖窄**（仅落盘沪深300）。
4. **消息面/资金流历史浅**（~1月/需从接入日累积）→ 监督学习长历史样本前期只能靠**技术+广度(可回溯2022)**两维；消息面/资金流短期更适合做**实时增量因子**。
5. **无预测标签/回测骨架**（regime是分类器非预测器）。

## 3. v1 设计

**目标**：预测**沪深300(主) + 主要板块指数**的 **未来1日/5日 涨跌方向+幅度档**（如大涨/小涨/震荡/小跌/大跌），输出一个可解释的"市场环境判断"。

**四维特征**：
| 维度 | 特征 | 数据来源 | 状态 |
|---|---|---|---|
| 技术 | 指数MA排列/MACD/RSI/KDJ/BOLL/量能环比/动量(1/5/10/20日)/ATR | technical.compute(指数K) | ✅现成 |
| 市场广度 | 涨跌家数比/涨停跌停家数/创N日新高新低/破位广度/中位涨幅/成交集中度/板块红绿分布 | 新写聚合器扫 master/kline | 🔨需开发(纯本地) |
| 消息面 | 日度净利好度(Σ强度×方向)/利好利空条数比/管制类快讯计数/受影响行业广度 | sentiment_policy.json | ✅现成(接入即用) |
| 资金流 | 起步:成交额环比/龙虎榜净买合计/大宗溢价；补采:大盘主力净流入/市场级北向净买/两融变化 | 龙虎榜(现成)+akshare补采 | 🟡代理现成/真资金流需补采 |

**骨架**：复用 `pattern_screener/regime.py` 的五因子平权框架（已市场级、已有降级机制、已接指数K+量能），**从"贴标签的分类器"改造成"预测器"**——加真标签（沪深300 T+1/T+5 收益/涨跌档），四维因子加权打分→输出涨跌概率+档位。v1 先用**可解释的因子加权/逻辑回归**（不上黑箱），后续再考虑ML。

**标签(y)**：沪深300（及各板块指数）T+1、T+5 收益率→分档。防未来函数：因子只用 ≤T 信息。

**回测**：复用 `tools/backtest/forward_scorecard` 前向验证。技术+广度可回溯2022做长历史回测；消息面/资金流因增量短，先作实时因子、随数据累积再纳入长回测。达标标准：预测方向命中率显著>基线(如50%/惯性基线)，且分档收益单调；带 kill-switch。

## 4. 分阶段实施（省力优先）

- **v0.5（零/低网络依赖，先出）**：①写市场广度聚合器(扫 master/kline，激活regime恒降级因子+得历史广度序列)；②接入 sentiment_policy 日度净利好度因子；③扩 index 采集补主要板块指数；④regime骨架加沪深300标签+前向回测 → 出一个"技术+广度+消息面"三维 v0.5 预测器，**可回测2022**。
- **v1（补真资金流）**：接 akshare 大盘资金流 + 市场级北向 + 两融采集器 → 资金流维从"代理"升级为"真流"，纳入预测器（增量因子）。
- **接入选股**：预测器每日产出"市场/板块环境(偏多/偏空/震荡)+涨跌概率" → 写 data/analysis/<日>/market_forecast.json → 选股任务读它做β基准、算个股α（三个定时任务的"市场环境判断"步骤已预留接口）。

## 5. 工作量（agent视角）
- v0.5（广度聚合+消息面接入+指数扩采+regime改预测器+回测）≈ 20-50K token / agent执行 2-4h（含回测来回）。
- v1（市场资金流/北向/两融采集器补全）≈ 30-60K token / 2-4h。
- 可先 v0.5 出可回测原型，验证"技术+广度+消息面"三维判别力，再决定是否补资金流采集。

## 6. 风险/待决
- 消息面/资金流历史浅：前期长回测只能靠技术+广度两维，另两维作实时因子——**这点要接受**。
- 预测粒度：先只做沪深300(大盘)还是同时做主要板块？建议 v0.5 先大盘，v1 扩板块。
- 是否与"题材事件驱动候选池"提议协同（板块层面）？
- 待统筹/用户决策：批准 v0.5 先行？粒度(仅大盘 vs +板块)？
