## 0. 一句话结论

**近端(长样本视角)市场预测效力没有明显在掉。** 主 β 基准 `proxy`(全A等权)T+1 长样本命中
稳定在 **54.7%**(2018–2026,n≈1969),滚动命中仅微幅走弱(后半段较前半段 −0.8pp),而滚动
IC 与 Brier 近端反而略有改善——维持既有"**弱方向边际、无经济 alpha**"的画像,**未见崩坏**。
唯一亮红灯的是 `hs300/T+5`:滚动命中跌破 50%、Brier 较气候基线差 ~10% → 触发报警;但 hs300
历史仅 ~210 样本、T+5 噪声更大,判为"**数据短**"而非"效力崩",建议观察不建议立即再标定。

**真·线上产物事后验证(source=production)样本太小**(每组仅 3–5 条已到期记录),统计上
不可结论,仅作机制占位;随每日产物累积,该来源会逐步接管为权威事后验证口径(见 §4 局限)。

## 1. 探针在测什么(设计要点)

固化点在哪:`market_forecast` 的维间**组权重是手工常量**(`tools/config/strategy.py:370`
`因子权重={技术:1.0,广度:1.0,消息面:1.0,资金流:0.0}`),每日只重训标准化/定向/校准,**组权重
永不重训**——这是"会固化"的点。要"实时进化",第一步不是改权重,而是先让**效力漂移可测**。

探针(`tools/analysis/market_forecast/drift_monitor.py`)对齐"预测 p_up"与"事后已实现方向/收益",
算**滚动**命中率、校准(Brier + 可靠性表)、IC(p_up~fwd_ret 相关)与趋势,并按阈值报警。

**两种预测记录来源,共用同一评分栈**(复用 `market_forecast_backtest.score`/`_spearman` 与
`features.build_panel`,不另造口径):

| source | 记录来自 | 样本 | 用途 |
|---|---|---|---|
| `production` | 历史 `data/analysis/<date>/market_forecast.json` 里**真实产出**的 p_up ⋈ as_of 之后**已实现** fwd_ret | 受历史产物数量限制(当前极少) | 真·线上模型的事后验证(权威口径) |
| `backtest` | 复用 `walk_forward` 滚动重训样本外记录(同一模型离线重跑) | 历史长(proxy 回溯 2018) | 看**滚动趋势**、效力有没有掉 |

**防未来函数(硬红线,已单测锁)**:
- 每个预测日 d 只用当天 p_up + 其**之后**才实现的收益 `fwd_ret[d]=close[d+h]/close[d]-1`
  (close[d+h] 全部 ≥ d,合法事后标签);T+h 尚未到期 → NaN → **该日不评分**(不编造)。
- 滚动指标严格 **trailing**(只用截至当日历史),绝不用更晚信息回改早先评分。
- 单测 `tests/test_market_forecast_drift_monitor.py`:配对口径/未到期丢弃/追加未来不改早先记录/
  滚动 trailing/Brier 方向语义/报警触发与静默,共 **10 用例全过**。

## 2. 现状漂移画像(source=backtest,长样本,权威趋势)

滚动窗口 60、min_periods 20。"hit/IC 走弱=效力掉;Brier 走弱=误差升(越小越好,已按效力语义标注)"。

| 标的/horizon | n | 覆盖 | 命中率 | 相对惯性 | IC | Brier/气候基线 | 滚动命中趋势 | 滚动IC趋势 | 报警 |
|---|---|---|---|---|---|---|---|---|---|
| proxy / T+1 | 1969 | 2018–2026 | **0.547** | +4.77pp | +0.012 | 0.2481 / 0.2469 | 走弱(Δ−0.008) | 走强 | 否 |
| proxy / T+5 | 1961 | 2018–2026 | 0.535 | +3.11pp | −0.012 | 0.2501 / 0.2458 | 走弱(Δ−0.030) | 走强 | 否 |
| hs300 / T+1 | 217 | 2025-10~2026-09 | 0.535 | +16.6pp | +0.107 | 0.2517 / 0.250 | 走弱(Δ−0.022) | 走强 | 否 |
| hs300 / T+5 | 209 | 2025-10~2026-09 | **0.498** | +4.78pp | +0.083 | 0.274 / 0.250 | 走弱(Δ−0.039) | 走强 | **是** |

读法:
- **proxy T+1(主口径)**:命中 54.7%、相对惯性 +4.8pp,与基线清单记录的"~54.3%、+4.8pp"吻合;
  滚动命中几乎持平(−0.8pp,窗口噪声内),IC/Brier 近端略优 → **效力未掉**。
- **Brier 全线 ≈ 气候基线**(比值 1.00~1.10):这是"**无经济 alpha**"的直接体现——模型的概率校准
  几乎不比"永远报历史上涨率"更好。这是**既有诚实结论**,不是新出现的漂移。
- **hs300/T+5 报警**:命中 0.498 跌破 50%、Brier 比气候基线差 ~10%。但 hs300 仅 ~210 样本、T+5
  重叠标签自相关强、噪声大 → 归因"**样本短**"更合理,**建议纳入观察名单,暂不触发再标定**。

## 2b. 生产产物事后验证(source=production,样本极小,仅占位)

当前仅 6 个历史 `market_forecast.json`(2026-09-01/02/03/07/09/11),已到期可评分记录每组仅 3–5 条。
各组命中 0.20~0.33、报警全触发——**但样本量 3–5 条,统计上等同噪声,不可据此下结论**。它反映的是
9 月初模型清一色偏多(p_up 多 >0.5)而该窗口指数偏弱的**偶发**错配,不代表结构性效力下降(见 §2
长样本才是权威)。此来源的价值是**口径正确、随产物累积自动变权威**,现阶段仅作机制占位。

## 3. 探针怎么跑

```bash
# 长样本趋势(权威,看效力有没有掉)——复用 walk_forward,首跑约数十秒
python -m tools.analysis.market_forecast.drift_monitor --source backtest \
  --targets hs300,proxy --horizons 1,5 --window 60 --min-periods 20 \
  --out data/analysis/<date>/market_forecast_drift.json
```

```bash
# 真·线上产物事后验证(样本随日积累;小样本可临时调小 min-periods)
python -m tools.analysis.market_forecast.drift_monitor --source production \
  --window 60 --min-periods 3
```

- 只读:`--data-root` 缺省自动探测主仓数据根(worktree 兼容);不写生产 `data/`,`--out` 落派生文件。
- 程序接口:`drift_monitor.drift_scan(source=..., targets=..., horizons=..., window=..., thresholds=...)`
  返回 `{blocks:{"<tgt>/T+h":{overall, brier, climatology_brier, calibration, rolling_trend, alarms}}}`。
- **日更接线建议(第三波再落地,本波不接)**:`ops/launchd/pull_refresh.sh` 日更 forecast 之后追加
  一步 `--source production` 巡检,报警接 §6 统一告警;不改现有产出链路。

## 4. 局限(诚实标注)

1. **生产产物样本极小**:仅 6 份、可评分 3–5 条/组 → production 口径暂不可结论;需 ≥ 数十个交易日
   产物累积后才有统计意义。当前权威趋势只能靠 backtest(同模型离线重跑)近似。
2. **backtest ≠ 完全等同线上**:walk_forward 用的是"当日可得的同一模型滚动重训",与线上每日 fit
   口径一致,但不含线上偶发的数据缺口/降级;是效力趋势的**良好代理**,非逐日字节复刻线上产物。
3. **proxy 含幸存者偏差**(master 只含在市个股),绝对收益别当真;方向研究可用(与既有结论一致)。
4. **hs300 历史短**(~2025-10 起),T+5 重叠标签自相关强,单点指标不稳 → 报警需结合样本量看。
5. **Brier≈气候基线是模型固有特性(无 alpha),非漂移**;阈值已按"实质劣化"而非"未跑赢基线"设。

## 5. 报警阈值建议(为再标定触发铺垫)

默认阈值(`drift_monitor.DEFAULT_THRESHOLDS`,可 CLI/参数覆盖),取值理由锚定"本模型是弱边际、
无经济 alpha"的诚实基线——报警应对"**跌破既有弱基线**",而非苛求"跑赢强基线":

| 指标 | 默认阈值 | 语义 / 理由 |
|---|---|---|
| 滚动窗口 | 60 记录 | 约一季度交易日;够平滑又不过度滞后。样本不足自动退化全样本 |
| min_periods | 20 | 滚动最小样本,防近端追噪声 |
| 命中率地板 | < 0.50 | 跌破抛硬币即报警(方向判别彻底失效) |
| 相对惯性边际 | < 0 | 跌破"顺昨日方向"基线即报警(模型的既有卖点=相对惯性 +4.8pp) |
| Brier / 气候基线 | > **1.10** | 比"永远报基础上涨率"实质差 10%+ 才报警;**不取 1.0**——本模型 Brier 常≈基线(比值≈1),取 1.0 会几乎恒报、无判别力 |
| IC | < 0 | p_up 与 fwd_ret 转为负相关(预测反着来)即报警 |

**再标定触发建议(第三波用)**:任一报警**连续 N 期(建议 2–3 个滚动窗口刷新)持续触发**才触发
组权重再标定信号,单期报警仅记录观察,避免噪声抖动误触发。champion(冻结先验权重)始终保留、
kill-switch 一键回退——challenger 连续优于 champion 才提拔(§5.3-C/§7.3)。
