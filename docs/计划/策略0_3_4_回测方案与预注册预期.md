## 0. 三个策略的用途(已读代码确认,不是猜)

| 策略 | 代码 | 本质用途 | 回测类型 |
|---|---|---|---|
| **3 箱体形态** | `screen_box` | 窄幅箱体 **AND 放量突破箱顶** → **单日触发的买入信号** | **信号型**(同 S01/S02:进场→离场/前瞻) |
| **4 动量组合(A腿)** | `screen_momentum` | 加权对数动量打分 → R²闸门 + 低通信号 → **按分排序取 TopK** | **排序型**(分层/IC/TopK 组合) |

> 关键区分:**3 是"买不买"的信号,0/4 是"谁更强"的排序**。信号型看胜率/盈亏比/Alpha;排序型看 IC(预测力)和头尾分位收益差,两者回测口径不能混(混了就是又画错靶)。

## 1. 统一方法(三者共用,防未来函数)

- **样本**:随机全A ~700 只(主档随机抽样,破"偏成长"偏差;复用本轮 `backtest_predict._sample_universe`)。要更硬时扩样本或 literally 全A。
- **基准**:沪深300(同 S01/S02,`collectors.index`),算相对 Alpha。
- **无未来函数**:逐历史日 t **只用 kdf.iloc[:t+1] 重放筛选**(三个 screener 均已声明截至当日判定);进场锚 **t+1**,前瞻收益只取 t+1 及之后。**红线**:构造未来极端数据不得改变 t 时刻信号(单测锁死,同 `backtest_predict` / engine)。
- **持有期**:前瞻 5 / 10 / 20 交易日(交易日非自然日)。
- **口径诚实**:信号型先做"信号日收盘机械基线"(无择时无调仓,衡量信号原始质量),明确标注**非最终买法**(S01/S02 已立此规矩)。

## 2. 各策略回测口径

### 2.1 策略 3 箱体(信号型)—— 直接克隆 `backtest_s02.py` 骨架
- 信号日 = `screen_box` 判 SELECT 的 t;进场 t+1 收盘。
- **两套离场并报**:①固定持有期前瞻收益(5/10/20 日,纯信号质量);②`position_backtest.simulate_position` 状态机(沿用趋势深跌反包离场,**与 S01/S02 同口径便于横比**)。
- 指标:胜率 / 中位·平均收益/笔 / 盈亏比 / 相对沪深300 Alpha / 即死率(硬止损占比)/ 平均持有 / 样本数 + 统计显著性(t/p)。

### 2.2 策略 4 动量 A 腿(排序型)
- 每个 rebalance 日(每 5 / 10 日)按动量分排序 → **TopK 等权组合**持有到下次调仓;算组合日收益 → 年化 / Alpha / 夏普 / 最大回撤 / 换手。
- 并报 **IC**:每日全A 动量分 vs 前瞻 N 日收益的 Spearman 相关(时序均值 + ICIR),看动量分**有没有预测力**。
- 并报**分层**:按动量分十分位,每层前瞻 N 日均收益,看是否单调(动量有效则 top>bottom)。

### 2.3 策略 0 合议(排序型)
- **IC 为主**:每日全A 合议综合分 vs 前瞻 5/10/20 日收益的 Spearman 相关(时序均值 + ICIR + t 检验)。
- **分层多空 spread**:合议分十分位,Top decile − Bottom decile 的前瞻收益差(合议有效则显著 >0)。
- **TopN 组合**:每日 Top20 等权前瞻收益 vs 沪深300 Alpha(贴近实际用法)。
- 边界:合议里资金流/情绪/多因子/事件维度在全A最小记录下**弃权**(无历史快照),故测的是"**技术面为主的合议**",与 web 全维度合议**不等价**,须标注。

## 3. ⭐ 预注册预期(结果出来前写死)

> 依据:① 本轮实证(放量突破不提收益、上涨概率/买卖倾向在全A无 edge、区间肥尾);② A股已知特性(短期反转>动量、假突破多);③ S01/S02 前车(信号型机械基线普遍贴地/微负)。

| 策略 | 我的预测 | 判"有效"的判据 | 判"无效"的判据 | 若无效·最可能原因 | 预设调参方向 |
|---|---|---|---|---|---|
| **3 箱体** | **弱/负超额**(放量突破在A股假突破多,类 S01 即死) | Alpha 显著>0 且即死率明显低于 S01(<50%) | Alpha≈0 或负、即死率高、p 不显著 | 箱体突破=接下跌中继/假突破;放量不提收益(本轮已证) | 提突破放量倍数、加"回踩不破再进"确认、只在趋势 regime 用 |
| **4 动量A腿** | **短周期(5-10日)弱/负,20日或趋势市才可能正**(A股短期反转) | IC 显著>0(如 5日 IC>0.03 且 ICIR>0.3)、分层单调、TopK Alpha>0 | IC≈0/负、分层不单调 | A股短期动量弱、反转占优;R²闸门没滤掉伪趋势 | 拉长动量回看/持有期、强化 R²质量门、叠反转过滤 |
| **0 合议** | **IC 小(\|IC\|<0.05)、TopN Alpha 微弱**(买卖倾向本轮已显示无 edge;合议维度更多但同源技术信号) | IC 显著>0、Top−Bottom spread 显著>0 | IC≈0、spread 不显著 | 纯技术面合议信息量弱;弃权维度(资金流/情绪/基本面)恰是 alpha 来源却缺席 | 补历史快照让资金流/情绪/多因子维度上场;调专家权重;换排序目标 |

**总预期(诚实)**:三个大概率**都跑不出强正 alpha**——与本轮"没有任何策略/预测项有统计显著正超额"一致。这不是唱衰,是让"若结果确实平/负"时**不意外、不硬凑**;若某个**意外地正**,则要先查是不是样本偏差/未来函数泄漏(反向自证)。

**成功的真正定义**:不是"逼出正 alpha",而是**给每个策略一个带样本量、带显著性的诚实数字 + 一个数据支持的下一步**(要么可调、要么该弃、要么缺数据待补)。

## 4. 实施拆解(先框架后填充,能并行则并行)

1. **箱体回测**(最干净,现成模板):克隆 `backtest_s02.py` → `backtest_box.py`,换信号源为 `screen_box`,离场沿用。**先做,立即能出数。**
2. **排序型回测器**(动量+合议共用):新建 `backtest_rank.py`——输入"每日全A 打分函数",产出 IC / 分层 / TopK 组合绩效。动量分=`weighted_log_momentum`;合议分=`council` 综合分。两策略共用一套,只换打分函数。
3. **单测**(约法6):无未来函数(构造未来不改信号/打分)、IC 口径、分层单调性构造校验。
4. **文档回填**:各出结论表 + 对照本预注册"预测 vs 实际",更新本文件 §5。

**工作量估(agent 视角,约法11)**:
- 箱体回测:token ~30-50K,agent ~1h(克隆+跑+单测)。
- 排序型回测器:token ~60-90K,agent ~2-3h(新 harness + IC/分层 + 单测 + 两策略各跑)。
- 可并行:箱体(信号型)与排序型 harness **互不依赖、不同文件** → 可并行起 subagent。合议与动量共用排序器,串行(先器后两次跑)。
