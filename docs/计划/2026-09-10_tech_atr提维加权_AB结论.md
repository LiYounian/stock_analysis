## 0. 一句话结论

**判据不达标 → 不建议接生产。** 把 tech_atr（波动率，全表最强单特征）从技术维等权里提出来（提独立维 / 维内 |IC| 加权），
**命中率没升、多空收益价差没有明显、稳定、显著地转正**：proxy 长样本 h1 最多把 long_short 从 ≈0 拱到 +0.0009/天（t≈0.8，**不显著**），
proxy h5 与 hs300 各格不一致甚至翻负；naive 把 ATR 单独提为一整维（B1）反而**拖累命中**。
这确认了研究报告的判断——**"~55% 命中无经济 alpha"是结构性的**：重新配权放不出收益，不是维内稀释造成的可修问题。

## 1. 实验设计

**现象（研究 §3.4）**：技术维内对 10 列做**等权 `.mean()`**，把 tech_atr（h1 IC 0.083 / h5 0.095，全表最强）
稀释到 1/10；其余 9 列（动量/均线/RSI）IC 多在 ±0.02 内、符号不稳。广度里 br_limit_up 同理被 7 列等权稀释。

**四个变体**（只改"维内/维间怎么配权"，不引入新数据、不碰生产 `predictor.py`）：

| 变体 | 说明 |
|---|---|
| `B0_baseline` | 现状：技术维 10 列等权含 atr —— 生产口径 |
| `B1_atr_dim` | tech_atr 提为独立"波动"维（权重=1，等同一整维），技术维剩 9 列 |
| `B3_atr_br_dim` | tech_atr→"波动"维 + br_limit_up→"涨停"维，各权重=1（研究 §6 候选 ii 扩展） |
| `B2_ic_weighted` | 技术维内按训练集 \|rank-IC\| 加权（**数据驱动、无手调参**；IC 只用训练集→防未来） |

**口径**：walk-forward 样本外，复用 `market_forecast_backtest.walk_forward`（min_train=120，stride=5）；
proxy（全A等权代理，n≈1960-1968）+ hs300（真沪深300，n≈207-215，短）× h1/h5 四格。
**判据焦点 = 多空收益价差 `long_short`**（预测涨的日子平均 fwd − 预测跌的日子平均 fwd），带 Welch t 检验（正态近似 p）。
研究强调：命中提升若换不出多空收益就意义有限；只有 long_short **明显转正 + 样本外稳 + 不是单参碰运气** 才建议接生产。

## 3. 读法与判据核对

**逐条对判据（明显转正 + 样本外稳 + 非单参碰运气）**：

1. **命中率没提**：B3 proxy h1 持平（0.5473）、hs300 略升；B1/B2 在 proxy 上反而**降命中**。没有一个变体在四格上一致提命中。
   naive 提维（B1）把 ATR 单独放大成一整维，等于让"技术其余 9 列 + 波动 + 广度"重新等权，**明显拖累命中**（proxy h1 −0.6pp、h5 −1.7pp、hs300 h1 −3.3pp）——是负面教材，明确不做。

2. **long_short 没有明显、显著转正**：全表最好的正向格是 B3/B2 在 proxy h1 的 **+0.0008~0.0009/天**，但
   **t≈0.7-0.8、p≈0.4-0.5，落在噪声内**；hs300 h5 的 +0.0056（B3）也只有 p≈0.12。**没有任何变体在任何格达到 |t|≥2 的显著转正。**

3. **样本外不稳**：proxy **h5 全部变体仍为负**，且前后半段翻号剧烈（B3 前半 +0.0029 → 后半 −0.0140）——h5 是 regime 依赖，谁都稳不住。
   唯一"两个半段都正"的是 B3 proxy **h1**（+0.0012 / +0.0010），但幅度极小（~+0.001/天）且整体 t 不显著；换到 h5 立刻翻负 → **跨 horizon 不稳**。
   hs300 h1 基线本就是最正的（+0.0029），而**每个变体都把它削弱**。

**综合**：改后既没换出命中，也没换出**显著、跨格稳定**的多空价差。B3（ATR+涨停广度提维）是四个里"最不坏"的——
proxy h1 上方向一致地微正、且不伤命中——但**幅度落在噪声内、跨 horizon 不成立**，达不到"明显转正"。
B2（|IC| 加权，最有原理的数据驱动版）同样放不出收益 → 说明**问题不在"权重没配好"，而在信号本身是弱方向边际、不是收益价差**。

## 4. 建议

- **不接生产。** 维持生产口径 `B0_baseline`（`因子权重={技术:1,广度:1,消息面:1,资金流:0}`、技术维内等权、tech_atr 留在技术维内）。
  已在 `predictor.py._dim_scores`、`README.md`、`forecast.py` notes 注明"ATR 被维内等权稀释是已知现象，A/B 试提权无显著收益、未接生产"。
- **若未来仍想接**（需统筹/用户审过再动）：
  - 唯一有一丝方向的是 **B3 在 proxy h1**，但必须先拿到**显著性**（当前 t≈0.8 不够）——建议等 hs300 真实历史累积更长后重跑，看短样本里 B3 的 +0.005~0.006（h5）能否收敛到显著。
  - 接法（若达标）：不改配置数值，而是给 `CompositeModel` 加一个 **默认关闭的 kill-switch 开关**（如 config `技术维_ATR独立=False`），
    生产默认走等权、开关打开才提维，可一键 config 回退。**绝不**直接改 `因子权重` 或维内 `.mean()`（那样无法回退、且会静默改变所有历史产出口径）。
- **明确不做**：naive 把 ATR 提为整维（B1，拖累命中）；把合成换成全特征 logistic（研究 §3.5 命中 0.506 更差）。
