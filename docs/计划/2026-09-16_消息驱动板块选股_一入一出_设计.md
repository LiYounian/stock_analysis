# 消息驱动板块选股 · "一入一出" · 设计(2026-09-16 · 待审)

> 专窗「板块预测系统」(暗号 回声-0914)。⚠️ 测试环境研究模拟,非投资建议。
> **本文是方向修正**:用户 2026-09-16 指出板块线重心错了——**消息(新闻/政策)才是主力信号,
> 不能以量价数据为主**。P3 的量价机械回测"测错了对象",结论收回,按消息驱动重做。

## 0. 修正点(一句话)

**从"数据驱动的量价重排"掉头为"消息驱动的板块标签 → 板块内选股(龙头+跟涨)"。**
新闻的**获取与影响分析是核心**;量价退为辅助确认。

| | P3 之前(错的重心) | 本设计(对的重心) |
|---|---|---|
| 主信号 | 量价动量,消息小配角(板块加分) | **消息/催化为主**,量价辅助 |
| 选股 | 全A量价榜 + 板块加分重排 | **消息锁定利好板块 → 板块内选龙头 + 跟涨/联动** |
| 验证 | 量价候选 forward(测错) | **消息触发的板块选股 forward(实盘累积,非回测)** |

## 1. 一入 —— 定向收集 + 影响分析(消息为主)

**采集三源(定向)**:
1. **板块新闻/政策**:各申万一级/概念板块的消息(复用 `sentiment_policy` + 定向关键词强化)。
2. **板块龙头股新闻/公告**:对每个板块 roster 的**龙头**,定向抓其新闻+公告
   (复用 `news.fetch_news(codes)` + `announcement.fetch_announcements(codes)`,codes=当日龙头名单)。
3. **国际新闻**:海外龙头(英伟达/台积电/ASML…)+ 宏观(美联储/关税/汇率,已有 news_store)。
   **诚实缺口**:海外龙头专用源当前缺,需新接(baidu_news 定向词 / 新增源);先接得到的,标注覆盖度。

**影响分析(核心)**:对采集到的每条消息用 **LLM 判影响**(复用 `event.score_policy` →
利好/利空/强度/受影响行业),按板块 rollup → **每板块净催化 + 龙头个股催化**。

## 2. 一出 —— 板块报告 + 消息驱动选股

**板块报告 + 标签**(每日):每板块出"消息影响分析 + **标签**"(利好/利空/中性 + 强度 + 依据)。
复用/强化 P2 的 sector_daily.md、market_daily.md,把**消息影响判定**做成明确的板块级 tag。

**消息驱动选股(标签触发)**:
- **触发**:板块被判**利好**(消息净催化 > 阈值,且有龙头催化确认)→ 该板块进"重点选股池"。
- **选票**:在利好板块内选 ①**龙头**(消息主受益、已启动)②**跟涨/联动候选**
  (同板块、龙头已动、后排待接力——**用户联动假设:龙头涨→后排跟涨**)。
- **口径**:消息触发为主;量价作**入场确认**(不追高、回踩限价),不作主筛。

## 3. 与选股流程的接口(跨线 · 需统筹对齐)

本线产出 **消息驱动的板块利好标签 + 板块内龙头/跟涨候选**(落 `sector_focus` 的消息驱动版);
**选股侧(统筹午盘/晚间线)消费该标签**:利好板块 → 在该板块补入龙头+跟涨候选。
(区别于 P3 证伪的"量价榜+板块加分"——那是数据驱动机械接,已弃。)

## 4. 验证(这次用对的方法)

- **不再用量价回测**(P3 教训)。新闻历史仅 ~1 个月,小样本证不了因果。
- **实盘 forward 累积**:每日"消息触发的板块选股" vs 基线,记 forward(次日/T+5),按
  **消息利好确认日 / 龙头催化强度**分层看。攒够跨 regime 样本再谈显著。
- **联动假设单独验**:龙头利好且已动的板块,后排跟涨候选 forward 是否正(条件在"消息利好"而非"低位")。

## 5. 复用 vs 新建

- **复用(P2 已有)**:sector_focus 的新闻催化维(已是最高权重 0.40)、独立新闻库(宏观真采)、
  四角色表(龙头名单)、每日研判文档、event LLM 影响打分、个股 news/公告采集器。
- **新建/强化**:① 定向龙头股新闻采集(接 news.fetch_news(龙头 codes));② 国际龙头新闻源
  (缺口,新接);③ 消息→板块利好**标签**(明确 tag + 阈值,驱动选股);④ **跟涨/联动候选**识别
  (同板块、龙头已动、后排待接力);⑤ 消息触发选股接口(供选股侧消费)。

## 6. 分期(建议)

- **M1 一入·定向龙头+影响分析**:对当日各板块龙头定向抓新闻/公告 → LLM 判影响 → 板块级+龙头级净催化。
- **M2 一出·板块利好标签 + 报告**:消息驱动的板块 tag(利好/利空+强度)写进每日板块报告 + sector_focus。
- **M3 消息触发选股 + 联动**:利好板块内龙头+跟涨候选,落"消息驱动重点池",接口给选股侧。
- **M4 国际龙头源 + forward 验证**:补海外龙头新闻;实盘 forward 记分(消息触发 vs 基线,分层)。

## 7. 诚实边界

- 国际龙头专用源缺(先宏观+国内财媒间接覆盖,逐步补)。
- 概念级板块成分缺(仅申万一级),龙头/跟涨识别在申万一级口径,概念级延后。
- 新闻→选股因果无法历史回测(样本少)→ 走实盘 forward,诚实标"累积中、未显著"。
- LLM 判影响有噪声/主观,固定提示词 + 留痕人工可核。
