## 1. 背景与命题

线3 已证:龙虎榜净买上榜票 T+1 开盘入、持有 5 日,按沪深300去市场后**显著跑输**
(见光死 / 追高),net_buy_ratio 前向 rank-IC 显著为负 → **多头 alpha 是负的**。
与本 repo「显著负诊断=删」方法论(S01 / 箱体3)一致:方向反过来用才有价值。

本线把龙虎榜正式做成 **否决 / 反转风控信号**,回答三问:
① 否决价值有多大(净买上榜票的净跑输 = 否决/离场所避免的损失);
② 反转价值有没有(净卖上榜票 H1 短反弹扣成本后是否还剩正);
③ 是否稳定 + 显著(按年分层、净买占比分档、按日聚类 bootstrap、rank-IC)。

## 3. 否决信号设计(`lhb_veto.py`)

三种用法,一套裁决核心 `verdict_from_events(events, as_of, mode, ...)`:

| mode | 触发条件 | 用途 |
|---|---|---|
| `entry_veto` | 近日**净买**上榜(dir=+1 且占比≥门槛) | 多头选股时**否决入选**(追高见光死) |
| `exit` | 同上 | 持仓票触发**减仓/离场** |
| `reversal` | 近日**净卖**上榜(dir=−1) | 短期**弱反弹**候选(H1,谨慎) |

- **防未来函数**:裁决只用 `list_date` **严格小于 as_of** 的上榜(盘后披露→上榜日当天不可用),
  复用 `lhb.lhb_asof` 语义;`veto_asof(code, as_of)` 从落盘快照读切片。
- **近日窗口**:仅 as_of 前 `window_days`(默认 7 自然日 ≈ 5 交易日)内的活跃上榜才计。
- **门槛**:`min_net_buy_ratio` 可只否决"强追高";无快照 → 保守放行(由上层其它风控兜底)。
- 输出 `Verdict`(triggered/reason/list_date/direction/net_buy_ratio/days_since/n_recent),
  可序列化进审计轨迹。

## 4. 评测结论(2024-2025,485 交易日,38005 上榜事件)

> 数字为按日聚类净超额(去沪深300、扣往返0.2%),p 为按交易日聚类 bootstrap 双边 p。

### 4.1 否决腿(净买上榜 dir=+1)—— 稳定显著负(见光死)

| 视界 | 净超额 | p | 结论 |
|---|---|---|---|
| H1 | **−0.26%** | 0.003 | 追高即跌,即时否决有效 |
| H5 | **−1.68%** | 0.000 | 见光死最稳 → **否决/离场避免 +1.68%** 跑输 |
| H10 | **−2.53%** | 0.000 | 越持越差 |

- **按年一致**:2024 H5 −2.53%、2025 H5 −0.83%,两年均显著负(2024 更狠,2025 收敛)。
- **rank-IC**:net_buy_ratio 对 **H1** 前向超额 rank-IC = **−0.037(p=0.0001)**、全体 H1 = −0.062(p=0)——
  净买占比越高、H1 越差。
- **净买占比分档(H1 单调!)**:占比 [0,1.8]→+0.07%(不显著);[1.8,4.4]→−0.08%;[4.4,9.2]→−0.22%(p=0.08);
  **[9.2,89]→−0.76%(p=0)**。追高越猛、H1 见光死越狠 = 干净单调。H5/H10 则是"上榜即滞后"的
  普遍效应(各档均负,与占比强度关系弱)。

### 4.2 反转腿(净卖上榜 dir=−1)—— H1 微正、H5 后反转

| 视界 | 净超额 | p | 结论 |
|---|---|---|---|
| H1 | **+0.40%** | 0.000 | 净卖后短反弹,**扣成本后仍正**(两年均显著:2024 +0.41%、2025 +0.40%) |
| H5 | −1.73% | 0.000 | 反弹全数回吐,净卖到 H5 也见光死 |
| H10 | −2.69% | 0.000 | 越持越差 |

反转腿 H1 净超额 +0.40% 边际偏薄(单腿、等权),仅可小仓试探,不宜作主力多头。

### 4.3 模块自校验

生产 `lhb_veto` 模块对每条事件在 T+1 裁决,**否决集恰等于净买腿**(n=16260,aligned=True),
否决集 H5 净超额 −1.68%(p=0)——证明"模块所否决的正是那批见光死票",生产口径 ↔ 诊断口径对齐。

## 5. 适用用法与合成建议

- **首选:入选否决 / 持仓离场**(净买上榜)。H1 即已跑输、H5 最稳(−1.68%),多头选股应把
  "近日净买上榜"作为**硬否决层**;持仓触发则减仓/离场。这是本线最确定、最稳健的价值。
- **次选:H1 强追高即时否决**。net_buy_ratio 高档 H1 −0.76% 单调最强,可作即时否决的加权。
- **谨慎:净卖 H1 弱反转**。扣成本后 +0.40% 微正且两年稳定,但边际薄,仅小仓试探,不推。
- **能否与红旗 veto 合成统一风控线:能,且正交**。龙虎榜 = **市场行为/微结构事件**(游资追高),
  红旗 = **财报质量事件**(基本面排雷),两者作用轴不同,可 **OR 合成**否决:任一触发即否决/降权。
  `lhb_veto.Verdict` 已是标准裁决结构(triggered + reason + 强度),便于与红旗 veto 的高危度并线。
  建议后续在风控侧(线1 红旗 veto 所在层)加一个 veto 汇聚器,把龙虎榜否决作为一路输入。
