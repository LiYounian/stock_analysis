## 0. 一句话结论(先说最重要的)

1. **扩到 16 日后,headless 端到端选股相对全A等权没有稳定正 α,统计上不显著。** DeepSeek 自选买入侧 T+1 日均 α = **−0.43 ± 2.05 pp**(n=6 日),T+5 = **+2.08 ± 3.98 pp**(n=6 日)——两个横期的标准误都**远大于**点估计,置信区间大幅跨越 0;且 T+5 的正值几乎完全由**单只票(600479 +17.6%)**扛起,是典型的小样本个例主导。
2. **更根本的问题:headless 从机械策略池"几乎选不出票"。** DeepSeek 在 16 日 × 12 候选里**总共只自选出 6 只买入**(0.375 只/日),**10/16 日给出 0 买入**。即若今天把生产选股切成"策略池 → DeepSeek 自选"的无人值守,系统绝大多数交易日会**什么都不推荐**。
3. **这与上一篇"DeepSeek 复核 Claude 选票时高度一致(~81%)、α 非负"并不矛盾,反而互补定位了瓶颈**:DeepSeek 的**研判/复核能力**跟得上 Claude;但**候选池构造(选股流水线的前半段)**才是短板——喂给 DeepSeek 一个噪声大的机械池,它(正确地)几乎全部否掉。**headless 化的关键缺口不在判研模型,而在候选池质量**。
4. **第三波"无人值守切主"仍不够格,且比 5 日版给出的信号更审慎。** 详见 §5 更新版拍板建议。

## 1. 方法(只补与上一篇的差异)

### 1.1 候选池构造规则(可复现·防未来·逐日一致)——本篇的核心新增

代码:`tools/analysis/shadow_pool.py`(复用 `write_picks._load_strategy_views` / `_extract_ranklist` 加载器,单一真源)。规则**固定、逐日一致、不按日调参**(防 cherry-pick):

1. **选择性策略集** = 当日 `data/analysis/<date>/` 下全部含 code 榜单的策略视图(顶层非 6 位 json),**排除两个"全域/宽网聚合层"**:
   - `策略0合议`(council,对全域打分的元聚合,常达千级——把它计入会让"命中≥2"对几乎所有票平凡成立);
   - `最大范围选股`(显式"最大范围"宽网,常 100~300+ 只)。
   其余(动量组合 / 放量后缩量回踩 / 量价放量 / 反转低换手组合 / 箱体形态 / 趋势深跌反包 / 半导体多因子 / 最强选股 / 扣非质量 等)各计为一个独立选择性策略。**按名字稳定排除,跨日一致**(不按当日榜长临时决定)。
2. **命中** = code 出现在某策略榜单中即"命中"该策略(**只认成员资格,不认榜内名次**——经核验,多数宽网榜按 **code 升序**而非强度排序,榜内名次不可靠,见 §6 局限)。
3. `hit_count(code)` = 命中的选择性策略数;候选 = **{hit_count ≥ 2 的票}**(多策略交叉确认,核心稳健信号)。
4. 若不足 12 只:按策略"选择性由强到弱(榜由短到长)"轮流补入各策略成员,补到 12。
5. 排序键 = (hit_count desc, 最短命中榜长 asc, code asc);取前 **14** 只(实测各日均落在 12 只)。

> **为什么排除聚合层 + 只认成员资格**:目标是给 DeepSeek 一个"当天量化筛出的较强票"的**可复现、无 cherry-pick** 的池子,再让 DeepSeek 自选。α 只在 **DeepSeek 的买入侧**上算——所以池子里混入弱票不影响结论的诚实性:那正是在考 DeepSeek 的**甄别力**(它该把弱票否掉)。

### 1.2 α 打分(同上一篇口径)

代码:`tools/analysis/shadow_score.py`。买入侧 = `stance ∈ {买入, 可参与}`;基准"全A等权" = 当日 `forward_scorecard.csv` 全样本 r 均值;**α(pp) = mean(买入侧 r) − mean(全样本 r)**;命中率 = 买入侧 r>0 占比。`r_1` 恒算,`r_5` 仅当日 ≤ 2026-09-04(已结算)才算。汇总给**日均 α ± 标准误(SE)** 与 **pooled 命中率**,诚实标注 N。

### 1.3 选日(16 日,跨市况)

08-11, 08-13, 08-14, 08-18, 08-20, 08-24, 08-26, 08-28, 08-31, 09-01, 09-02, 09-03, 09-04, 09-08, 09-09, 09-10。覆盖普涨日(全A等权 r_1>+1%:08-11/08-14/08-26/09-04)、普跌日(<−1%:08-18/08-20/09-01/09-09/09-10)、分化日(其余)。T+5 已结算子样本 = ≤09-04 的日。

## 3. 汇总 · α(诚实标注 N 与 SE)

### 3.1 DeepSeek 自选买入侧(canonical)

| 横期 | 日均 α(pp) | SE | N(日) | pooled 买入票数 | pooled 命中率 | pooled 买入侧均 r |
|---|---|---|---|---|---|---|
| **T+1** | **−0.43** | ±2.05 | 6 | 6 | 33%(2/6) | +0.27% |
| **T+5**(≤09-04) | **+2.08** | ±3.98 | 6 | 6 | 33%(2/6) | +1.51% |

- **两个横期 α 都统计不显著**(|α| < SE,甚至 T+1 SE≈5×|α|)。方向上 T+1 微负、T+5 微正。
- T+5 的 +2.08 完全靠 600479(+17.6%)与 300684(+10.4%)两只;去掉 600479 则转负。**单名主导 + n=6,无统计意义**。

### 3.2 看多方向侧(更软口径,样本更大)

因买入侧样本太薄,补一个更宽的口径:DeepSeek 判 `dir_1d 或 dir_5d = 偏多` 的票(即使 stance=观望),看它的**方向 tilt** 是否带 α。

| 横期 | 日均 α(pp) | SE | N(日) | pooled 票数 | pooled 命中率 |
|---|---|---|---|---|---|
| T+1 | **−1.27** | ±0.75 | 11 | 19 | 21%(4/19) |
| T+5 | −0.93 | ±1.72 | 10 | 17 | 24%(4/17) |

- **看多方向侧 T+1 α 为负且 SE < |α|**(t≈−1.7):DeepSeek 在机械池上的"偏多"方向判断,**非但没有正 α,反而略跑输全A等权**。这进一步说明:问题不是"DeepSeek 太保守漏了好票",而是**这个机械池里本就缺乏可被 DeepSeek 转化为正 α 的票**——池子质量是瓶颈(§0.3)。

**回答核心问题**:*扩到 ~16 日后,headless 选股相对全A等权是否有稳定正 α?统计上显著否?* → **没有稳定正 α,统计上不显著(买入侧 α 的 CI 大幅含 0;看多方向侧 α 甚至略负)。且 headless 从机械池几乎选不出票(6 买入/16 日)。**

## 5. 千问被动度体检(max-push 变体)

上一篇结论:baseline 千问(think 关 / 温 0 / 默认 prompt)在 5 日中 4 日给 **0 买入**,过度保守到失能。本轮聚焦"**能不能救**":取 3 日(08-26 普涨 / 09-03 分化 / 09-09 普跌)、同一候选池,试 max-push 变体(代码 `_artifacts/qwen_probe.py`)。

**变体②(think 开关 on)—— 直接不可用**:qwen think 模式单票推理 > 网关 60s 超时(注册表 `qwen_max.params.timeout=60`),3 次重试全 `Request timed out`,**产 0 有效研判**。→ 结论:**当前 60s 超时下千问 think-mode 无法上线**,要评测它得先给 deep_analysis 路由单独放宽超时(涉及配置,本轮未改)。

**变体①+③(强制表态 prompt + 提温 0.5,think off)—— 被动度被治好了**:

| 日 | 市况(bench r_1) | 千问 max-push 买入 | 千问买入 T+1 α | 命中 | 同日 DeepSeek 买入 / T+1 α |
|---|---|---|---|---|---|
| 08-26 | +1.68%(普涨) | **8 只** | −0.72 | 3/8 | 600479 / **+8.30** |
| 09-03 | −0.73% | 2 只(300866,603162) | **+5.27** | 1/2 | 300866 / −0.18 |
| 09-09 | −1.78%(普跌) | **0 只** | — | — | 0 只 |

- **强制表态 prompt 直接解决了"恒 0 买入"**:普涨日千问敢给 8 只可参与、分化日 2 只,普跌日回到 0(该谨慎时也会谨慎)。→ **"过度保守"主要是 prompt/温度配置问题,不是模型能力天花板**(印证上一篇的边界判断)。
- **但被"逼"出来的千问是把散弹枪、选择性极差**:08-26 一口气买 8 只(12 只候选里的 2/3),把当日唯一大赢家 600479(+9.98%)**稀释**在 5 只输家里,α −0.72,**反而跑输**了 DeepSeek 只买 600479 一只的 +8.30;pooled 命中率仅 **40%(4/10)**。偶有亮点:09-03 它多买的 603162 次日 **+9.99%**,是 DeepSeek 更紧的筛选**漏掉**的赢家。
- **结论:经调教千问能被逼出方向,但"给方向"不等于"给对方向"**。当前它要么恒 0(默认)、要么散弹(强制),**缺乏 DeepSeek 那种"敢重仓一只对的"的选择性**。做 primary 会推太多噪声、做可靠 fallback 也不够稳;且 think-mode 未解决超时前连评测都做不了。**当前配置下仍不能挑大梁**,但"被动度"确属可调教的 prompt 层问题。

## 6. 更新版拍板建议(第三波"无人值守切主"够格否?)

**结论:仍不够格,且扩样后的证据比 5 日版更明确地指向"暂不切"。**

扩到 16 日 + 端到端口径后,新增/强化的证据:

1. **无稳定正 α、统计不显著**:买入侧 T+1 α = −0.43 ± 2.05pp、T+5 = +2.08 ± 3.98pp(均 n=6,CI 大幅含 0,T+5 单名主导);更宽的看多方向侧 T+1 α 甚至略负(−1.27 ± 0.75pp,n=19)。**无法拒绝"α=0"**。
2. **headless 从机械池几乎选不出票**:6 买入 / 16 日,10 日 0 买入。无人值守切主 = 绝大多数交易日空推荐。
3. **过度保守有真实机会成本**:喂 Claude 自己的选票时 DS 仍过度否决(09-02 对 Claude 3 只买入 0% 一致 + 1 例严重反向,放弃了 +7.8%/+10% 两个赢家)。这不是"稳",是"漏"。
4. **千问 fallback 腿**:被动度可用 prompt 治好,但治好后是低选择性散弹;think-mode 因 60s 超时连测都测不了。**降级腿仍不可靠**。

**关键再定位(与上一篇合读)**:上一篇证明 **DeepSeek 的判研/复核保真度 OK**(复核 Claude 选票 ~81% 一致、无严重反向);本篇证明**瓶颈在选股流水线的前半段(候选池)+ DeepSeek 的买入阈值校准**,不在判研模型本身。所以 headless 化的正确下一步不是"换更强判研模型",而是:

- **A. 候选池质量**:本篇用的机械池含 code 顺序噪声、且把"多策略命中"当唯一强信号;生产 headless 需要一个**强度排序、经质量过滤**的候选池(接近人工/Claude 当前的挖票逻辑),再喂给判研模型。
- **B. 重标 DeepSeek 买入阈值**:headless 下它明显比 Claude 保守一档(±1 档在有人复核时无害,无人值守下直接变成"空仓/漏赢家")。需按前瞻收益校准"何时该从观望升到可参与"。
- **C. 修千问**:think-mode 超时 + 强制表态后的选择性,二者都解决后才谈得上 fallback。
- **D. 补样本**:A/B 改好后,买入样本才可能从"6/16 日"升到可做统计的量级,再谈 α 显著性。

**建议路径(更新版)**:DeepSeek 保持 primary **影子跑、不切生产** → 先做 A(候选池)+ B(阈值校准)两项工程,而非继续无脑扩天数(当前池子扩到 30/50 日,α 仍会被"选不出票"卡死)→ 千问按 C 修 → 重新扩样评 α → 达标后由**用户拍板**。**本轮不切、不改 live / 定时任务 / model_registry。**

## 7. 局限(诚实标注,勿夸大)

- **买入侧样本致命地小**:16 日仅 6 只自选买入、每日≤1;α 的 SE 远大于点估计,**统计上不能拒绝"α=0"**。所有数字是**方向性观察**,非统计证据。
- **T+5 仅 6 日且单名主导**:600479 一只决定 T+5 正负。
- **候选池的选择偏差**:①"排除 策略0合议/最大范围选股"是主观规则(虽固定、可复现);②**多数宽网榜按 code 升序而非强度排序**,故补池阶段(hit<2 的填充票)含 code 顺序偏差(偏向低码),这会给池子引入噪声——但因 α 只在 DeepSeek 买入侧上算,该偏差主要影响"DeepSeek 面对的票的质量",不直接构造假 α。仍应视为**本篇最大方法学软肋**。
- **record 缺失**:08-24 跳过 3 票、09-08 跳过 4 票(候选码当日无 record json),使这两日 u<12。
- **基准口径**:α 基准用当日 scorecard 全样本 r 均值近似"全A等权",与项目正式 α 记分口径可能有细微差异。
- **口径切换的可比性**:本篇(池→DeepSeek 自选)与上一篇(Claude 选票→DeepSeek 复核)口径不同,不能直接比 α 数字;两者是**互补的两面**(判研 vs 选池),见 §0.3。
