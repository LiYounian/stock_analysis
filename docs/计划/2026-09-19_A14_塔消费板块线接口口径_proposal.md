## 0. 一句话
塔(`tools/pyramid/tools/sector_context_tool.py`)现在把板块线**最富的描述性证据几乎全丢了**:
每票只落一个"净催化档",而板块线实际产出的 **龙头候选/跟涨候选(催化承载者 vs 联动)、关键事件三档(可信度/来源/执行度)、已动** 都没进塔。本 proposal 给出"塔该怎么读板块线才不丢信息"的接口契约。

## 1. 现状:塔现在怎么消费板块线(引 origin/main 真实代码)

`sector_context_tool.py` 每票渲染 6 行 + fields(`sector_context_tool.py:213-289`):
`板块 / 冷热拥挤 / RS分位 / 角色 / 板块内排名 / 净催化`。

板块线信息只进了**第 6 行「净催化」**,来源两条(`:260-272`):
- `focus_entry.新闻净催化`(数值)→ `_净催化档` 用 **±50 阈值**折档(`:42-49`);
- 无数值时旁路读 `消息驱动.利好板块[].(tag,强弱)`(`:204-212` + `_消息驱动档` `:62-67`)——**只取 tag 和 强弱两个标量**。

第 4 行「角色」(`:246-251`)来自 **roster 量价角色**(龙头/中军/主力/补涨,`_find_role`),
**不是**板块线的"消息催化角色"(龙头候选/跟涨候选)。→ 塔无法区分"这票是催化承载者"还是"靠联动"。

板块线实际 emit(`news_focus_block.py:84-95`,`消息驱动.利好板块[]`):
```
{board, tag, 强弱, 关键事件:[{时间,事件,方向,可信度,影响程度,执行度,来源}],
 持续性, 时效, 可靠性综述, 依据, 新闻时间跨度, 新闻条数, 新增条数,
 龙头候选:[{code,name,已动}], 跟涨候选:[{code,name,联动依据}]}
```
**加粗字段(龙头候选/跟涨候选/关键事件/已动/持续性/时效/可靠性)在塔里一个都没用到。**

## 2. 问题:信息损失 4 点(按重要性)

| # | 损失 | 后果 | 严重度 |
|---|---|---|---|
| L1 | **龙头候选 vs 跟涨候选**未进塔(塔"角色"是量价角色) | 塔看不出一票是**一阶催化承载者**还是**二阶联动**;归因桶(板块-龙头催化/板块-联动跟涨)在**选股消费侧无对称信号**——只在事后 attribution 才分,进场时塔不知道 | 高 |
| L2 | **关键事件三档(可信度/来源/执行度)**未进塔 | 塔侧**没有假利好探测能力**;"利好·中/弱 + 来源二手 + 执行度低"这类脏催化,塔只看到"净催化正"就当利好吃 → 追高/假利好风险 | 高 |
| L3 | **净催化用数值 ±50 阈值** | 活跃板块 `新闻净催化` 绝对值天然大,±50 使其**几乎一律"强正"**,档位失去区分度(统筹 A14 已同向记:改分位/占比截断) | 中 |
| L4 | **已动**塔未读、attribution 侧重算 | 板块线已 emit `已动` 布尔(当日涨幅≥MOVED_PCT 3%),塔/归因各自重算 = 口径重复、易漂移 | 低 |

## 3. Proposal:接口契约(塔该怎么读每个字段)

原则:**板块线已转向"描述性文字档"(强弱 + 三档 + 候选角色),塔应直接消费这些文字口径,不要在塔侧用数值阈值再造一套。**

### 3.1 净催化档:弃数值±50,以板块线文字档为主口径
- **主口径**:直接用 `消息驱动.利好板块[].强弱`(强/中/弱,板块线 LLM 已判定的文字档)映射净催化档,不再用 `新闻净催化` 数值过 ±50。
- 数值 `新闻净催化`/`利好条`/`利空条` **降为辅证**(证据串里显示),若仍要用数值,改**分位或占比截断**(对齐统筹 A14),不用绝对阈值。
- 好处:档位区分度回来了;塔与板块线**同一套文字口径**,不再各判各的。

### 3.2 新增「消息催化角色」字段(L1 的核心修复)
在 `sector_context` fields 里**并列**现有量价"角色",新增一个 **`消息催化角色 ∈ {催化承载, 联动跟涨, 无}`**:
- 该票 code ∈ 该板块 `龙头候选` → `催化承载`(一阶,有直接消息催化);
- code ∈ `跟涨候选` → `联动跟涨`(二阶,靠板块龙头已动接力);
- 都不在 → `无`。
- 这与 attribution 的归因桶(板块-龙头催化 / 板块-联动跟涨)**消费侧对称**:进场时塔就知道这票吃的是一阶还是二阶催化,而非等事后归因才分。
- 塔如何用:**联动跟涨票的消息权重应低于催化承载票**(二阶信号本就弱),建议塔在合成时对"联动跟涨"打折(具体折扣归塔侧权重口径,本窗只出信号)。

### 3.3 关键事件三档进塔(L2 的假利好探测)
- 至少把该票所在板块的 `关键事件[]` 的**三档摘要**(可信度/来源/执行度)透传进 `sector_context` 证据串 + 决策包渲染。
- 给塔一个**弱催化标记** `催化质量 ∈ {强, 弱}`:板块 `强弱∈{中,弱}` **或** 关键事件命中 `可信度∈{存疑,不可信}` / `来源=二手` / `执行度=低` → `弱`;否则 `强`。
- 塔如何用:`催化质量=弱` 的利好票,消息驱动的加成应被抑制(防把假利好当真催化吃)。这是把"假利好探测器"从事后 attribution 前移到进场侧。

### 3.4 已动:直接读板块线 emit 的布尔(L4)
- `sector_context` / attribution 统一读 `龙头候选[].已动`,不各自用 K 线重算。板块线是 `已动` 的**单一真相源**(MOVED_PCT=3% 预注册写死)。去重复、防漂移。

### 3.5 接口字段清单(塔应新增消费的 fields)
```
消息催化角色: "催化承载" | "联动跟涨" | "无"        # 3.2
催化质量:     "强" | "弱"                          # 3.3
已动:         true | false | null                  # 3.4(读板块线,不重算)
净催化档来源: "文字档(强弱)" | "数值分位"           # 3.1(口径留痕)
关键事件摘要: [{方向,可信度,影响程度,执行度,来源}]   # 3.3 透传(可截断)
```
板块线**产出侧已具备全部字段**(news_focus_block 已 emit),本 proposal **不需要板块线改产出**,只需塔侧消费口径改写 + 上面 5 个 fields 落地。

## 4. C10 治理输入:non-gating 却占 35% 权重(供统筹汇总进用户决策)

**事实**:板块线 `消息驱动` 块自标 **non-gating**(`news_focus_block.py` 诚实边界:"forward 累积·未达标不 gated");但塔里 sector_focus 占 ~35% 权重(统筹 C10)。→ 一个 forward 未验证的信号事实上在 gating 决策。

**两个选项 + 我的推荐**:
- 选项 A(解除边界):承认板块线已可信,正式解除 non-gating,保留 35% 权重。
  - 前提:**必须先有 forward 达标证据**(`sector_news_forward_shadow` 严格 as-of 累积、命中率/IC 达阈)。现在**没有**这个证据 → **不推荐现在解除**。
- **选项 B(降为上下文)【推荐】**:在 forward 验证达标前,把 `消息驱动` 降为**上下文/软信号**——
  - 不进硬权重合成(或权重从 35% 大幅下调,建议 ≤5–10%);
  - 主要作用改为:①决策包**展示**(给 LLM/人看催化);②**软否决触发**(催化质量=弱 时抑制追高),而非正向加分主力;
  - 待 forward 累积达标 → 再走选项 A 升权。
- **理由**:符合板块线自己的诚实边界与防未来红线——未验证的信号不该 gating。宁可先当上下文,验证达标再升权,避免用未证实的消息面主导选股(踏空的反面是追高,两头都要防)。
