## 0. 一页纸结论（先读这个）

- **目标**：把"热门板块 → 板块内角色个股（龙头/中军/补涨/弹性）"做成**每日滚动、落库、最终定向影响选股**的体系，堵住"利好在板块里、选股却踏空"的洞。**踏空真根已独立证实 = 候选池覆盖不足**（赢家不在机械候选池），本体系正是解药——落点是候选池的板块定向补充，同时喂**午盘全A重筛 + 晚间选股**两个下游。
- **现状一句话**：板块环境层（温度计/情绪判官）**有代码、零每日产出、零落库、零接入选股**；四角色**无任何真定义**；新闻是选股副产、非独立采集。**但底层数据采集器齐全**（价量/市值/换手/资金流/龙虎榜/北向/大宗/板块指数 kline 都日度落库）。
- **可行性判断**：**申万一级板块口径下，四角色识别 + 每日板块冷热文档 + 大盘→板块两步框架 = 现有数据即可做，无需新数据源**。真瓶颈只有两个（**概念级细分成分缺**、**个股资金流新鲜度陈旧 ~5 天**），诚实标注、分期绕过。
- **打法**：三期推进。**P1 板块环境每日落库 + 四角色主表（MVP，纯离线复算，不碰选股）→ P2 独立板块新闻库 + 每日板块定向分析文档（forward-shadow 留痕）→ P3 接入选股（占优板块内定向选先锋/中军/补涨，默认只降权不硬否）**。每期独立可交付、可回滚。

### 1.5 两个真瓶颈（诚实标注，贯穿全设计）

- **B1 概念级细分成分缺**：只有**申万一级 31 板块**成分（`board.py` + `code_industry`）。需求文档里的"算力/低空经济/机器人"这类**概念板块**没有成分名单 → **P1/P2 一律先用申万一级口径**；概念级列为 P2+ 增量（需补概念成分采集，见 §7）。
- **B2 个股资金流新鲜度**：`fundflow` 口径日期常滞后 as_of ~5 天（实测 09-15 标注"陈旧 2026-09-10"）。**板块级 `market_fundflow` 与龙虎榜/北向相对新鲜** → 角色识别的资金维度**优先用板块级 + 龙虎榜 + 北向**，个股 fundflow 作辅助并带新鲜度标签。
- 另注：**无专门涨停/异动采集器** → 涨停由 `pct_chg` + 代码前缀（涨停阈：主板 10%/创业科创 20%/北交 30%）**派生**，不新增数据源。

## 4. 怎么做：分期路线（对应用户问题③）

> 原则：每期独立可交付、离线可复算、forward-shadow 不碰 live 选股；防未来函数硬红线；先框架后填充（约法第 5 条）。

### P1 — 板块环境每日落库 + 四角色主表（MVP）
- **P1.1** `sector_regime` 每日面板：包 `thermometer.build_thermometer_panel` + 补充广度/资金维度 → 每个申万一级出 `{拥挤分位, 动量档, 板块资金净流, 上涨家数占比, 涨停数, 连板高度, 冷热标签∈{过冷,正常,过热,拐点}}` → 落 `data/analysis/<date>/sector_regime.json`。
- **P1.2** 四角色识别脚本（§5 定义）：对每个"入选目标板块"算龙头/中军/补涨/弹性候选（各 2–5 个，主选/备选排序 + 入选理由）→ 落 `data/sector_roster/<板块>.json`。
- **P1.3** 目标板块自动建议：按板块成交占比 + 涨幅榜 + 政策事件命中 → 建议监控板块清单（人工确认版固定，之后动态复核）。
- **交付**：离线脚本 + 单测（断言角色定义语义、防未来），跑历史若干日 sanity。**不接线、不定时**。

### P2 — 独立新闻库 + 每日板块定向分析文档 + 两步预测
- **P2.1** 独立板块/宏观新闻采集器（§7 schema）：宏观（美联储/央行/关税/汇率/美债）+ 海外龙头（英伟达/台积电/ASML…）+ 大宗（油铜铝锂稀土金）→ 独立落 `data/sector_news/<date>.json`，**不依赖选股链**。
- **P2.2** 每日板块定向分析文档生成器（§6 模板）→ `sector_daily.md` + `.json`。
- **P2.3** 大盘→板块两步合成器（§8）→ `sector_focus.json`（重点选股板块池 + 理由 + 置信）。
- **交付**：独立定时任务（草案 plist，**不 load**，交用户）；全程 forward-shadow 留痕、non-gating。

### P3 — 接入选股（gated，统筹拍板）
- 选股在 `sector_focus` 占优板块内**定向加权**先锋/中军/补涨；**默认只降权不硬否决**（`整合换线pass计划.md:75` 口径）。
- 前置条件：≥ 约定样本量 + 前向有效性显著（照 B/C 线 ≥120 样本门槛）。**本设计不落地 P3，只预留接口**。

## 5. 四角色可计算定义（申万一级口径 · P1）

> 全部 PIT 因果（只用 ≤date 数据）。板块内 = 该申万一级成分股集合（`code_industry` 反查）。

### 5.1 龙头（识别度 + 带动性 + 共识）
- **计算特征**（板块内排序，取 top）：
  - 率先性：近 20 日**首次涨停/强势突破日**最早（涨停派生：主板≥9.8%/创科≥19.5%/北交≥29.5%）。
  - 涨幅领先：3/5/10 日涨幅板块内分位 ≥ 0.8。
  - 带动性：个股涨停日，板块指数当日涨幅 & 板块上涨家数占比同步走高（相关度）。
  - 资金/共识：龙虎榜净买上榜次数、成交额板块内 top、舆情提及度（`ugc`/`news` 命中数）。
- **定义**：上述特征**加权分板块内 rank #1~#2**，且"分歧日能承接（回撤小于板块均值）、一致日能领涨"。

### 5.2 中军（容量 + 流动性 + 基本面 + 趋势）
- **计算特征**：市值板块内 top 分位、日成交额 top 分位、`financial.quality_score` ≥ 中、中期趋势（MA 多头排列/20 日趋势上行）、少连板但**抗跌**（板块调整日相对回撤小）。
- **定义**：大市值 + 高成交 + 基本面扎实 + 趋势稳的**主阵地股**，龙头分歧时稳盘。

### 5.3 补涨先锋（低位 + 同逻辑 + 早期异动）
- **前置**：板块已有龙头启动（板块冷热 ∈ {正常活跃, 过热} 且龙头已 rank）。
- **计算特征**：位置低（价 / 近 60 日高点分位低、涨幅落后板块）、同产业链/同概念（申万一级内 + 关键词共现）、**近期首次放量或首板**（`vol_ratio` 突增 + 涨停派生首板）。
- **定义**：龙头有高度后**低位滞涨、率先接力**的个股；标注"补涨空间 / 是否纯跟风 / 会否演化新龙头"。

### 5.4 弹性股（波动 + 赔率放大器）
- **计算特征**：小市值分位、高换手（`chip` 换手 top）、涨跌停板制标签（创业/科创 20cm、北交 30cm，代码前缀派生）、可转债对应正股（`financing.可转债` 字段 / 转债标的映射）、历史 β（个股 vs 板块指数回归，≤date）> 板块均值。
- **定义**：上涨领涨、退潮回撤更大的**风险偏好晴雨表**。

## 7. 独立板块/宏观新闻库 schema（产出 D · P2）

- **独立性**：专用采集器（复用 `policy.py`/`news.py`/`baidu_news.py` 底层抓取，但**独立入口 + 独立落库**），与选股链解耦——不选股也每日采。
- **采集维度**（照需求文档 §5）：
  - 国际宏观：美联储/欧央行利率、非农/CPI/PMI、美元指数、**美债收益率**、汇率。

## 8. 大盘→板块两步预测框架（产出 E · P2）

- **第一步（大盘/整体）**：合成市场风险偏好档 = 大盘广度（涨跌家数）+ 大盘资金（北向/两融 `margin`）+ 宏观新闻净方向（产出 D 国际宏观维）→ 输出 `{风险偏好: 进攻|中性|防守}`。
- **第二步（板块）**：对每个板块合成 `板块得分 = w1·冷热(A) + w2·板块资金净流(market_fundflow) + w3·RRG相对强弱(rrg.py) + w4·新闻催化匹配(D) + w5·广度`。
- **输出** `sector_focus.json`：`{风险偏好, 重点板块池:[{板块, 得分, 冷热, 理由, 置信}], 规避板块池:[...]}`。
- **合成机制诚实**：初期**规则加权**（权重预注册、只读不改）；样本足后再谈学习式权重。权重与阈值写死后 append-only。
