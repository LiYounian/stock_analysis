## 目标(两个 P0)

- **P0-2(核心)· 给午盘买入5补 D-0 交易计划**:让「日内全A」买入票产出可执行的当日进出场纪律
  ——进场触发 / 止损位(ATR·当日振幅锚定,非拍脑袋)/ 止盈参考 / **收盘强制了结**。
- **P0-1 · 加固 11:30 快照 + 复盘降级回退**:堵 09-10 那类「快照缺失→复盘 α=None、丢样本」。

## 输入/输出(框架先行)

### P0-2(`tools/pipeline/intraday_screen.py` + 配置)
- 配置真源:`THRESHOLDS['午盘选股']['交易计划']`(ATR 窗口/止损止盈倍数/止损上下限/进场容忍/缺省锚)。
- `compute_trade_plan(code, quote, as_of, *, load_kline_fn, cfg) -> dict|None`
  - 输入:11:30 快照 quote(price/open/high/low)+ 历史日线(算 ATR)。
  - 波动锚:优先 ATR(N 日真实波幅%),历史不足回退当日半日振幅%,再不行用缺省锚。
  - 输出:现价 / 进场触发(不追高价带)/ 止损位(现价−k·锚,夹在上下限)/ 止盈位(现价+k·锚)/
    了结纪律(当日收盘无条件平仓 + 盘中触及止损止盈即走 + 次日跳空破止损开盘即走)。
- `render_intraday_md` 增 `quotes`/`load_kline_fn` 入参,买入表后加「D-0 交易计划」表 + SOP 说明。
- 沿用经验 v2026-09-11:#12 退出纪律 / #14 单问盯点 / #18 闸门 / #20 跳空保护;针对**当日买卖**。

### P0-1(`intraday_screen.py` 落盘自检 + `intraday_review.py` 降级回退)
- 落盘侧:`snapshot_self_check(as_of, universe_n, ...)` 复读快照核存在性+样本率;`run_intraday_screen`
  拉取覆盖率过低时重试一次,落盘后自检不过则 ERROR 告警(不静默),结果进 report。
- 复盘侧:`load_noon_snapshot` 缺失 → `build_fallback_base`(主档**当日开盘价**近似基价,
  口径由「下午」降级为「全日开→收」),`_fallback_universe` 用 `universe.universe_codes` 重建全A;
  个股与基准**同口径**、标注「降级口径」纳入样本(不丢样本),render 显式打降级横幅。

## 防未来红线
- ATR 只用 `date < as_of` 的历史日线;降级 open/close 只取 `date == as_of` 当日行;快照采集时刻冻结。
