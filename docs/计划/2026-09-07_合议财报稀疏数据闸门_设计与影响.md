# 合议财报「稀疏数据 → 误判优」最小覆盖度闸门(设计 + 影响验证)

分支:`fix/合议财报稀疏数据闸门`  ·  as_of:2026-09-07

## 1. 问题(已诊断根因)

`tools/analysis/financial/scoring.py` 的 `quality_score()`:
- 只对**非空维度**求加权均值(`base = Σ(v·w)/Σw`,None 维跳过、权重同步剔除);
- 利润数据缺失时红旗 `flags=[]` → 零扣分。

后果:当**利润表整块未解析**(成长/质量/回报三维全 None)、但资产负债表正常
(健康维=100)时,该票只凭 `健康=100` 一个维度拿到 base=100 → `_rating()` 判「优」。

实证:001223 欧克科技 H1(2026-06-30)`five_dims={成长:null,质量:null,健康:100,
运营:null,回报:null}` → quality=100.0 / 评级「优」,而其中报实为归母 −74.6%、
Q2 单季转亏。这不是个例——任何「利润表缺失 + 资产负债表正常」的票都会被误判优,
再经财报专家输出「看多 0.9」抬高合议综合分。

## 2. 修复(策略层,可泛化)

### 2.1 scoring 最小覆盖度闸门
`quality_score()` 在算完五维、算加权均值后,加**盈利覆盖闸门**:
- 盈利相关维度(成长 / 质量 / 回报)**全部为 None** → 无法评估盈利质量;
- 此时**不得**据「健康 / 运营」单独给「优 / 良」→ 降级为「不可评」:
  `quality_score=None`、`评级=None`,并透出 `不可评=True` + `不可评原因`。
- 硬语义:**盈利三维全缺 → 不得判优**。

阈值 / 开关走 `config/strategy.py` → `THRESHOLDS["财报"]["评分"]["覆盖闸门"]`
(遵循该块「评分配置=占位待标定」约定,不硬编码魔数):
```python
"覆盖闸门": {"启用": True, "盈利维度": ["成长", "质量", "回报"]}
```
关掉(`启用=False`)即完全回退旧行为(向后兼容、可 kill-switch)。

### 2.2 财报专家置信度反映覆盖度
`tools/analysis/experts.py::expert_财报`:
- 财报块在、但评级为 None(被覆盖闸门判「不可评」)→ **专家弃权**:
  方向=中性、强度=0、数据充分度=缺失、置信度=0(不再据 is_forecast 给 0.6/0.8)。
- **审计否决优先**:非标意见 / 审计机构未备案(硬风险)即便盈利维缺,仍强制看空 −1.0
  (弃权分支置于 audit_veto 之后)。

## 3. 测试(tests/test_financial.py,hermetic,不触网)

- `test_coverage_gate_profit_dims_all_none_not_优`:只有健康维有数(健康=100、盈利三维全 None)
  → 断言评级**不是**「优」、且降级为 None、quality_score None、`不可评=True`。
- `test_coverage_gate_full_dims_still_优`:五维齐全优等票仍判「优」(防误伤)。
- `test_coverage_gate_partial_profit_dim_survives`:盈利三维还有任一维有数(仅 ROE)→ 不触发闸门,正常可评。
- `test_expert_caibao_abstains_on_uncoverable`:不可评的块 → 专家中性 / 强度0 / 数据充分度缺失 / 置信度0(不输出看多)。
- `test_expert_caibao_uncoverable_but_audit_veto_still_bear`:不可评 + 审计不通过 → 仍强制看空 −1.0。

结果:financial/experts/council 相关用例全绿;**全量 pytest 2418 passed / 7 skipped / 0 fail**。

## 4. 影响验证(2026-09-07 合议全量重跑)

方法:离线全A(5558 只)`run_council_screen(as_of=2026-09-07, fetch=False)`,
对**同一现磁盘缓存**做 A/B——闸门 ON(修复后)vs 闸门 OFF(等价旧行为),隔离本次改动的纯因果影响。

- **605007 五洲特纸**:OLD #1(0.7776)→ NEW #1(0.7776),**完全不变**。
  其财报块缺失 → 财报专家本就弃权 → 不受闸门影响。**坐实稳。**
- **001223 欧克科技**:财报评级 优(q=100)→ 不可评(None);
  合议综合分 0.7169 → 0.6437(−0.073),排名 **#6 → #323**,**移出 Top-20**。
- **Top-20 变动**:仅 001223 掉出;#7~#20 各上移一位;#21 的 **603987** 补入 #20。
  **没有别的票**因同一 bug 被误抬进旧 Top-20。
- **全A 同类 bug 扫描**:老口径「优/良」→ 新口径「不可评」共 **8 只**翻转。
  其中仅 001223(#6)在 Top-20 内;002096 在 #58(#58→#1130),其余 6 只本就 >60 名,均非 Top 票。
  即:该 bug 对 09-07 合议 **Top 排名的唯一实质影响就是 001223**。

结论:修复精准命中问题票(001223 大幅下沉),对健康/正常票零副作用(605007 及其余 Top 全稳)。

注:与现存 `data/analysis/2026-09-07/策略0合议.json`(17:10 生产产物)相比,Top-10 及分数完全吻合;
11~20 位有少量重排,系生产快照后磁盘缓存漂移所致(非本次改动);无论以哪个为基线,001223 都从 Top 移出。
