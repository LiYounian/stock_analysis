# 消息持续性分类(结构性 vs 短暂)· 预注册与执行

> 日期:2026-08-13 · ⚠️ 非投资建议 · 承接 [PEAD与根源消息信号](PEAD与根源消息信号_预注册与执行.md) §4.4 的"见光死"主线。
> 纪律:测前钉死假设 → 执行 → 诚实回填 §5。

## 0. 缘起(用户洞察 + 已验证的量化背景)
- **"一切利好皆为利空"**:大家都知道的利好已被 price-in,再追是接盘。我们已量化验证这条古话——PEAD 超预期见光死、正情绪逆向、创新高追高负,A 股短周期"见光死/反转"。
- **现有净情绪分只判极性(好/坏),不判持续性**。用户命题:真正该判的是——这条消息带来**持续稳定增长(结构性)**,还是**短暂催化(事件性/蹭概念)**?**极性告诉你好坏,持续性才告诉你能不能拿住。**
- **假设的机制**:短暂利好当天走完(见光死);**结构性利好(长期订单/产能/政策长期扶持/主营实质改善)市场无法瞬间完全定价,可能有更慢的持续兑现** → 这才是消息面可能藏 edge 处。且结构性消息**多来自政策+公司公告(根源)、可跨源印证**(与已验证的"根源原则"一脉相承)。

## 1. 分类器设计(LLM)
`tools/analysis/news_persistence.py`:输入**根源消息**(公告/政策 + 可选基本面印证),输出:
```
{ 持续性: 结构性持续 | 短暂事件 | 中性,
  方向: 利好 | 利空 | 中性,
  印证强度: 强/中/弱(是否有公告+政策+基本面互相印证),
  依据: 一句话 }
```
- **结构性持续判据**:长期订单/在手订单饱满、产能扩张/新产线投产、政策长期扶持(非一次性补贴)、主营业务实质改善、连续多期高增、护城河/份额提升。
- **短暂事件判据**:单季度业绩波动、非经常性损益/一次性扭亏、蹭概念/热点跟风、纯资金/龙虎榜异动、传闻/未落地重组。
- 关思考(`LLM_DISABLE_THINKING`)、并行+缓存(复用 `event._pmap`/`_cached_extract`);只对**根源消息**(公告/政策,不含舆情)分类。

## 2. 三条腿(哪条现在能做)
1. **live 接入(治本)**:让 `forward_scorecard`(或采集管线)对每日根源消息打持续性标签,随记分卡滚存——攒**持续性×前瞻收益**的样本。
2. **现在可回测的 slice**:**历史业绩预告**(复用 PEAD 的 `pead_forecasts.parquet`,akshare 有历史)——用分类器把每条预告分 **结构性 vs 短暂**,看两组**前瞻收益形态**(5/10/20/60 日):结构性应"持续升",短暂应"spike-then-fade"。**LLM 成本→抽样(几百条,分层)**,标注样本量。
3. **完整验证**:泛消息无长历史,仍需 live 累积几周。

## 3. ⭐ 预注册假设
| 假设 | 成功判据 | 若不成立·最可能原因 |
|---|---|---|
| **结构性利好 中长窗(20/60日)持续正漂移 > 短暂利好** | 结构性−短暂 组的 20/60日 Alpha 差 **显著>0**,且结构性组自身 Alpha 显著>0 | A 股结构性也被快速 price-in(仍见光死)/ 分类噪声大 / 样本期偏多混淆(结构&短暂都涨) |
| 短暂利好见光死(短窗回落) | 短暂组 5/10日 Alpha ≤0 | — |
| 印证强(公告+政策+基本面一致)比印证弱更持续 | 印证强组漂移 > 印证弱 | 印证判定太主观 |

**总预期(诚实)**:这是消息面**第一个我"有希望"而非"预判会失败"的方向**——因为它针对的正是"见光死"的反面(慢兑现的结构性)。但仍要防:①A 股连结构性也快速定价 ②业绩预告的"结构性"标签与超预期高度共线(PEAD 已证超预期无漂移)→ 需看**持续性是否比单纯超预期多分出信息**。

## 4. 执行计划
- 建 `tools/analysis/news_persistence.py`(分类器)+ 单测(构造:典型结构性/短暂各判对)。
- 回测 slice:`tools/backtest/backtest_persistence.py`——对历史业绩预告抽样分类 → 结构性/短暂 两组前瞻收益(含 60 日)+ 相对沪深300 Alpha + 聚类 t;**关键对照**:持续性分组 vs 单纯超预期分组(PEAD)谁更能分出漂移。
- live:`forward_scorecard` 增持续性标签(读 record events → 分类器 → 存),滚存。
- 分析回填 §5。无未来函数红线:分类只用披露日及之前信息,前瞻收益作标签。

### 唯一无需 LLM 的真实对照(可信):超预期 pos vs neg(抽样 364 事件)
| 窗口 | pos Alpha(聚类t) | neg Alpha(聚类t) | pos−neg(Welch p) |
|---|---|---|---|
| 5日 | −0.010(−1.33) | −0.012(−1.13) | ≈0 |
| 20日 | +0.030(3.94) | +0.027(1.46) | ≈0 |
