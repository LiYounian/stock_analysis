# 情绪打分失败不再静默兜底成"中性 0.0" —— A+B+C 重构设计

> 日期：2026-09-04　　分支：`feat/情绪打分失败三态`
> 触发：09-04 复盘发现 300802 矩子科技"买入·首选"是在消息面盲区下给出的。深挖确认：**采集层正常**（24 新闻/50 股吧/180 百度均在 18:36 闭环前落盘），是**情绪打分 LLM 层大面积失败**（09-03 参与选股的 564 只里 43% "全部新闻打分失败"、条目级 66% 失败；舆情层同日 55% `Connection error`），而失败被**静默兜底成 `强度0/中性/评论空` → 净情绪 0.0**，与"真中性"不可区分，`provenance` 也不反映。
> ⚠️ 非投资建议，测试环境研究模拟。

## 一、问题定性（一句话）

**"打分失败"和"真的中性"目前共用同一个 0.0 表示，缺失被冒充成正常值。** 这与近期 fundflow"过期值当当日值 + provenance=true"（commit `07f6469` 想解决的那类问题）是同一个病。后果：消息面完全是盲区的票照样走完打分、拿到全批最强表态，该有的置信度折价没打。

## 二、核心契约：三态（先定死，A/B/C 都建在它上面）

任何"会失败"的打分层，必须区分三态，**绝不允许把失败/缺失塌缩成 0.0/中性**：

| 态 | 语义 | 净情绪取值 | 下游处理 |
|---|---|---|---|
| **ok** | 打分成功，值可信（**可以是真·中性 0.0**，但那是真的中性） | 真实值 | 正常参与 |
| **unknown（未知）** | 打分失败/降级（LLM 超时、Connection error、并发打爆） | **null，不得写 0.0** | 触发置信度折价 + 表态封顶 |
| **missing（无数据）** | 本就没有输入（当天没采到任何新闻） | null | 该层退出加权、其余层重归一 |

### 落点（三个粒度）

1. **条目级**（`news_ai/<code>.json` 每条的 `ai`）
   - 新增显式 `ai.scored: true/false`（C 前向写入）。
   - 历史数据无该字段时，回退启发式：`评论` 与 `原因` **都空** ⇒ 视为 `scored:false`（失败兜底形态）。

2. **层级**（`sentiment.三层.{新闻,舆情,政策}`）
   - 新增 `status ∈ {ok, partial, unknown, missing}` 与 `失败数`；`样本数` 收窄为**成功打分**条数。
   - 新闻层：全失败 ⇒ `unknown`；部分失败 ⇒ `partial`（只用 ok 条目加权）；无新闻 ⇒ `missing`；全成功 ⇒ `ok`。
   - 舆情层：`degraded` 非空（如 `Connection error.`）⇒ `unknown`。

3. **顶层**（`sentiment`）
   - 新增 `质量 ∈ {ok, partial, unknown}` 与 `覆盖率`（成功层加权占比）。
   - `质量==unknown`（有效层覆盖不足阈值，默认 <0.3）⇒ `净情绪分 = null`，**不得为 0.0**。
   - `provenance.sentiment` 从"隐式布尔"改为三态 `{ok|partial|unknown|missing}`。

## 三、三条线的分工与文件边界（避免撞车）

> 依赖：**C 产出失败标记 → B 消费它做聚合与降级 → A 消费聚合后的质量做标注**。契约（第二节）是三者的共同接口，本设计定死后，实现可按文件边界并行。

### C · 打分层可靠性（产出失败标记）
- **改**：情绪 LLM 调用封装（逐条新闻 + 舆情）。
  - 加**重试**（指数退避）+ **超时** + **并发上限**（09-03 66% 失败大概率是并发打爆/限流）。
  - 最终失败**显式写 `ai.scored:false`**（及层级 `degraded` 原因），**不再静默回落到 `中性/0/空`**。
- **测试**：mock LLM 抛连接错误 ⇒ 断言 `scored:false` 且不产生 0.0 净情绪；mock 部分成功 ⇒ partial。

### B · 聚合语义 + provenance 三态 + 表态降级（消费失败标记）
- **改①（聚合）**：净情绪计算只吃 ok 条目/ok 层；`质量` 与 `覆盖率` 写入；unknown ⇒ 净情绪 null。
- **改②（provenance）**：`provenance.sentiment` 写三态。
- **改③（表态/综合分）**：`情绪质量==unknown` 时 —— (a) 情绪维度退出综合分并对其余维度重归一；(b) **打置信度折价**；(c) **表态封顶：不得给最强档（如"买入·首选"）**，强制降一级。
- **测试**：构造"情绪 unknown"的票 ⇒ 断言拿不到最强表态、综合分不被 0.0 情绪拉偏；构造"真中性"的票 ⇒ 断言仍可正常评级（锁住 ok 的 0.0 与 unknown 的 null 语义不同）。

### A · 选股 md 标注（消费聚合质量，纯展示）
- **改**：选股报告每票增列/增注**情绪来源质量**，如 `情绪: 3/24 成功` 或 `情绪: 未知(打分失败)`。判据取 `sentiment.质量`/`覆盖率`。
- **测试**：渲染一只 unknown 票 ⇒ md 里出现"未知/失败"标注，不出现误导性的"净情绪 0.0=中性"。

### 撞车规避
- **B 改②③ 与 C 若同处一个 sentiment 管线文件，则串行**：先合 C（定字段），再合 B（读字段）。具体是否同文件，待 Explore 接缝图确认后据以决定"同文件串行 / 异文件并行"。
- A 只碰选股 md 渲染器，与 B/C 天然解耦，可并行。

## 四、预期效果（改完应看到的现象）

1. 300802 这类"情绪 unknown"的票，在选股环节**拿不到"买入·首选"**（被降级），且 md 上明确标"情绪未知/打分失败"。
2. `sentiment.净情绪分` 不再出现"失败导致的 0.0"——失败一律 null + 质量=unknown。
3. 09-03 那种 66% 条目失败的日子，C 的重试/并发退避应把失败率显著压低；仍失败的部分被如实标记、不污染净情绪。
4. 回归测试锁住：**ok 的真·中性(0.0) 与 unknown(null) 是两种东西**，未来重写不得再把它们合并。
