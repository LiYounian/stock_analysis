# 第二步 · 消息面融合(保守版)计划

> 状态:**待审阅**(第一步图表已验收,交统筹合 main;本步在 main 合并后、ff 到最新 main 起做)
> 前置:统筹已把"消息数据新鲜度"合入 main(`134c3aa`),字段契约见下。
> 分步定位:用户定"保守版 + 激进版都做,先校验保守版反馈;激进版数值观测两天、待更可靠再论证"。**本轮只做保守版**,激进版在文末登记设计与门槛,不实现。

## 1. 目标(一句话)

在个股预测卡片旁**加一句"消息面提示"**(如"近期消息整体偏多、共 8 条,与技术面一致,可留意"),给出**看涨/看跌/中性**的消息面方向判断——**完全不改动任何预测数字/方向**(情景预测、指标条件化预测、持有期止盈止损、买卖倾向全部原样)。零风险、单点。

## 2. 消费契约(来自统筹,已冻结/新增)

- **冻结不动、直接用**:`净情绪分`(−1~1)、`样本数`、`利好数`、`利空数`、`口径`、`events`、三层原字段。
- **新增(main 已落,附加可空,旧记录 null 兼容)**:
  - 顶层 `新鲜度`("新鲜"/"陈旧"/"无数据"|null,最坏优先聚合)、`采集日期`、`锁定日期`。
  - 三层各 `采集日期` / `新鲜度`。
- 口径:当天有料=**新鲜**;当天缺、3 交易日内回退=**陈旧**(降权语气);超窗=**无数据**(不出信号)。

## 3. 设计(先定输入输出,再填实现)

### 3.1 新增纯函数 `tools/analysis/predict.py :: _sentiment_note(sentiment) -> str | None`

- **输入**:record 的 `sentiment` 块(dict);**可选** `tech_dir`(技术方向,用于"一致/背离"判断)。
- **方向分档**(复用现有情绪阈值 `THRESHOLDS`,±0.2,不新造参数):
  - `净情绪分 ≥ +0.2` → **看涨**;`≤ −0.2` → **看跌**;其间 → **中性(消息面平淡)**。
- **新鲜度叠加**(main 合并后可用):
  - `无数据` 或 `样本数 == 0` 或 `sentiment` 缺失 → 返回 `None`(不出提示,向后兼容旧记录)。
  - `陈旧` → 提示末尾加"(消息偏旧,仅参考)",语气降级。
  - `新鲜` → 正常语气。
- **一致/背离**(可选增强):若技术方向已知,附"与技术面一致 / 背离"。
- **输出**:一句中文提示串,或 `None`。例:
  - "近期消息整体偏多(净情绪 +0.35,共 8 条),与技术面一致,可留意。"
  - "近期消息整体偏空(净情绪 −0.41,共 12 条),与技术面(偏多)背离,留意分歧。(消息偏旧,仅参考)"

### 3.2 挂载点 `predict.py :: predict()`

- `predict()` 作用域内已持有 `sentiment` 形参(现只透传给买卖倾向)。在 `out` 组装完后:
  `out["消息面提示"] = _sentiment_note(sentiment, tech_dir=...)`。
- **红线**:不碰 `情景预测` / `指标条件化预测` / `持有期建议` / `买卖倾向` 的任何数值或方向。`_conditional_block` 签名不动。

### 3.3 契约 `tools/contracts/record.py` + `record.schema.json`

- `prediction` 块补可空字段 `消息面提示: str | null`;校验对 null/缺失宽容,不新增必填、不加枚举。

### 3.4 展示 `web/templates/stock.html`

- 在"情景预测 / 指标条件化预测"卡片旁,`{% if p.消息面提示 %}` 时渲染一行提示(带📰小标),纯展示、不参与任何计算。

## 4. 测试(守则 6)

新增 `tests/test_sentiment_note.py`:
- 看涨(净情绪 +0.3、样本足)/看跌(−0.3)/中性(±0.2 内)三档文案断言。
- 样本数=0 / sentiment 缺失 / 新鲜度=无数据 → 返回 `None`(向后兼容锁定)。
- 新鲜度=陈旧 → 文案含"仅参考"降级标注。
- 一致/背离分支(给定 tech_dir)。
- 契约:带/不带 `消息面提示` 的 prediction 均过 `validate_record`。

## 5. 验证

- 本地个股页:构造带 sentiment 的记录,确认提示渲染、且预测数字与之前**逐字不变**(回归:保守版不改数)。
- 远端合并后:挑几只**当日各选股策略选出、近期有消息驱动**的票,人工看提示是否合理。

## 6. 激进版(登记设计 + 门槛,本轮不做)

- 设计:把 `净情绪分` 后验倾斜到"指标条件化预测"的上涨概率(`p_adj = clip(p + k·净情绪分·100, 0, 100)`),再按 `新鲜度` 降权(陈旧→k 减半,无数据→不倾斜);幅度/区间可选平移。增益 `k` 落 `THRESHOLDS`,不硬编码。
- **门槛(为什么先不做)**:① 需回测校准 `k`(证明倾斜真能提升方向命中,而非帮倒忙);② 用户要求"激进版数值先观测两天、待消息面数值更可靠(新鲜度落地后陈旧率下降)再论证"。故先上保守版收集反馈,激进版待数据稳定 + 回测通过再实现。

## 7. 不做什么

- 不改情绪引擎打分(那是采集侧,统筹在做)。
- 不把情绪并入"相似历史日"建池维度(历史消息面无回填,当前不可行,已在总计划标注)。
- 激进版本轮不落代码。
