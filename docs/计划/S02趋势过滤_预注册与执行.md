## 0. 背景与诚实张力(先摆明)

- **S02 现状**(子集回测基线):胜率 31.6% / 平均 +0.33% / Alpha +0.14%(见 `docs/计划/S02回测报告_20260810.md`)——微弱正期望、edge 极薄、未过显著性。
- **反面证据**:本项目已回测「均线多头 + 追高(创新高)在 A 股显著为负」(见 `docs/计划/创百日新高_续涨回测_预注册.md`),即 A 股**动量弱 / 反转强**。
- **但机制不同**:S02 是「趋势中**回踩低吸**(买跌)」,不是「追突破」。Minervini 趋势模板是**趋势成立性**的门槛(个股处于长期上升结构 + 相对强度靠前),叠在 S02 的低吸入场上,理论上是「只在真·强势趋势里做回踩」,过滤掉「下跌中继式假回踩」。
- **结论纪律**:本轮**只给数据 + 诚实标注显著性**,**不下「能不能赚」的终结论**(留统筹窗口)。过滤器**可能改善也可能变差**。

## 1. 预注册假设(执行前写死)

- **H1(主假设)**:S02 叠加趋势模板过滤后,已离场交易的 **Alpha(相对沪深300 同持有期)与胜率**,在**同口径、同候选窗**下**显著优于**未过滤的 S02。
- **H0(零假设)**:过滤后 Alpha / 胜率与原版**无显著差异**(edge 不来自趋势成立性)。
- **失败最可能的样子(预注册)**:A 股趋势股「缩量回踩」后**仍均值回归 / 继续阴跌**(呼应「均线多头 + 追高为负」那条),即趋势门筛掉的是噪声、留下的也没更强 → 过滤后样本骤减但 Alpha / 胜率不升甚至下降。
- **判定口径**:样本足(见 §4 统计力)时看 Alpha 均值差 + 胜率差 + 有条件的聚类 t / 差异显著性;样本不足时**只标注方向 + 明确"统计力不足、不定论"**。

## 2. 过滤器定义(Minervini 趋势模板,全A 横截面,可配参数)

对候选票在信号日 `t`(**只用 ≤ t 的数据,无未来函数**)判 8 条,**全过**才算通过趋势门:

1. `收盘 > MA150` 且 `收盘 > MA200`
2. `MA150 > MA200`
3. `MA200` 上升:`MA200[t] > MA200[t−21]`(≥1 月);另**记录**是否更强 `MA200[t] > MA200[t−100]`(4–5 月)
4. `MA50 > MA150` 且 `MA50 > MA200`
5. `收盘 > MA50`
6. `收盘 ≥ 52周最低(近252日 low.min) × 1.30`
7. `收盘 ≥ 52周最高(近252日 high.max) × 0.75`
8. **RS 排名 ≥ 70**(横截面百分位;理想 80–90):`RS = 个股近126日涨跌幅 − 沪深300近126日涨跌幅`;当日全A 各票算 RS 后取百分位 rank。可选叠加「RS 曲线向上」`RS[t] > RS[t−21]`(默认关)。

**历史门槛**:需 ≥ **252** 根历史(52周 low/high 窗为最紧约束;MA200[t−21] 需 221、RS 需 127)。不足(次新股)→ **不通过趋势门**(记为跳过,not passed)。
> 注:需求原文写「≥200 根(算 MA200)」,那是 MA200 的下限提法;要判**全部 8 条**(含 52 周高低点、MA200 上升回看)实际需 252 根,故取 252 为工程下限,并在此显式标注差异。

## 3. 落地设计(向后兼容红线)

- **过滤函数** `screen_s02._trend_template(kdf, t, rs_rank, rs_up=None, cfg=None)`:返回 8 条逐条 bool + `PASS` + 明细;`rs_rank` 为横截面百分位(0–100,由调用方按当日全A 预计算后传入);历史不足 / 无 RS → `PASS=False` + 原因。**单票函数不做横截面**(RS 必须外部喂)。
- **screener** `signal_at(kdf, t, cfg=None, trend_filter=False, rs_rank=None, rs_up=None)`:默认 `trend_filter=False`,行为**逐字节等价旧版**(不加任何键 → 防未来函数等价测试 `full == truncated` 不破)。`trend_filter=True` 时:base SELECT 且趋势门 PASS 才 SELECT=True,并在结果加 `趋势门` 明细键。
- **配置**:`tools/config/strategy.py` 新增独立键 `"S02趋势过滤"`(**不动** `"放量后缩量回踩"` 原键);改后需 `python -m tools.config.strategy` 重生成 `config/strategy.json`(合并时做,别把无关 drift 塞进提交)。
- **回测 A/B**:扩 `tools/backtest/backtest_s02.py`:
  - 预计算**全A 每日 RS 百分位面板**(按日期对齐各票 126 日涨跌幅 − 沪深300,再逐日横截面 rank)。
  - **同口径对照(核心)**:只在**趋势门可计算窗**(t ≥ 251)内取 S02 信号,分成
    - **A = S02 原版**(该窗内所有 S02 信号)
    - **B = S02 + 趋势过滤**(该窗内 S02 信号 ∩ 趋势门 PASS)
    - 差异只来自过滤器(同窗、同离场器、同基准),避免「窗口不同」混淆。
  - 另给 **A_full = S02 全历史信号**(仅上下文参照,本地历史仅 ~16 个月)。
  - 离场一律复用 S01 持仓回测器 `position_backtest.simulate_position`(读 `THRESHOLDS["趋势深跌反包"]`,**未改一行离场逻辑**),与既有 S02 回测同口径可比。

## 4. 统计力与显著性

- 本地主档仅 **~335 根/票(2025-03-31 → 2026-08-13,≈16 个月)**。趋势门需 252 根历史 → 信号只能落在**最后 ~84 个交易日**,B 组样本**天然稀少**。
- 有条件给**聚类 t / 差异显著性**;样本不足时**明确标注「统计力不足、不定论」**,绝不硬凑结论。
- 最大回撤沿用「串行满仓复利」口径(与 S01/S02 既有报告同坑,仅内部对照,非实盘组合回撤)。

## 5. 无未来函数红线 + 测试

- 趋势模板只用 ≤ t 数据(MA / 52周窗 / RS 的 126 日均在 t 及之前);RS 百分位按**当日**横截面算(不引入未来日)。
- 测试(`tests/test_screen_s02.py` 增补 + `tests/test_backtest_s02.py` 增补):
  - 趋势模板各条命中 / 不命中(逐条构造);RS 百分位阈值边界;
  - 无未来函数(截断不变);
  - **S02 原路径零回归**(`trend_filter=False` 逐字节等价);
  - RS 面板 rank 正确性。

## 7. 执行结果(回填 · 2026-08-14)

**样本**:全部本地滚动主档 **5193 只**(≈335 根/票,2025-03-31 → 2026-08-13);沪深300 基准可用。
趋势门可计算窗 = t+1 ≥ 252 → 信号入场日**全部落在最后 ~84 个交易日**(约 2026-04 → 2026-08 单一行情段)。

**窗内信号**:S02 信号 **2083** 笔;趋势门 **PASS 379(18.2%)** / FAIL 1704;无 RS 0(基准齐全)。

| 组(离场均复用 S01,同口径) | N(已离场) | 胜率 | 中位/笔 | 平均/笔 | 盈亏比 | 平均Alpha vs沪深300 | 平均持有 |
|---|---|---|---|---|---|---|---|
| **A · S02 窗内(原版)** | 1894 | **26.1%** | −1.88% | −0.32% | 2.25 | **−0.31%** | 2.82d |
| **B · S02 + 趋势过滤(PASS)** | 375 | **22.4%** | −3.0% | −0.24% | 3.04 | **−0.35%** | 2.81d |
| 对照 · 窗内 FAIL | 1519 | 27.1% | −1.62% | −0.33% | 2.08 | −0.29% | 2.82d |

**显著性(PASS vs FAIL 的 Alpha,Welch)**:t = **−0.16**,p ≈ **0.87**,均值差 **−0.0005** → **不显著**(无差异)。

**结论(诚实,不下终判,留统筹)**:
- **过滤器在本数据上未改善 S02**:胜率反而略降(22.4% < 26.1%),Alpha 基本持平且略差(−0.35% vs −0.31%),
  唯一变好的是**盈亏比**(3.04 vs 2.25)——但那是「胜率降 + 单笔赢更大」的再分配,净期望仍未抬升。
  PASS 与 FAIL 两组 Alpha 统计上不可区分(p=0.87)。
- **命中了预注册的「失败最可能」**:A 股趋势股「缩量回踩」后**仍均值回归**,趋势门筛出的 18.2% 子样本
  并未成为更强的一档(呼应「均线多头 + 追高在 A 股显著为负」那条铁律)。
- **统计力/外部效度双弱,不定论**:全部入场落在**单一 ~4 个月行情段**(趋势门需 252 根 → 本地 335 根只剩尾部窗);
  且此窗内**连原版 A 都比历史基线差**(窗内 26.1%/−0.31% vs 历史 31.6%/+0.14%)——说明这是弱行情切片,
  任何「改善/变差」都被 regime 混淆。要定论需**更长历史 + 跨多个行情段**复验。

复现:`python -m tools.backtest.backtest_s02 --ab --full --no-view`(单进程串行,只读主档,约 10 分钟)。
