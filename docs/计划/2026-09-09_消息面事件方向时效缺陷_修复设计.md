# 消息面回灌打分 · 事件方向/时效缺陷修复设计（2026-09-09）

> ⚠️ 非投资建议，研究模拟。防未来函数：所有判断只用 ≤ as_of 信息。
> 缺陷双向铁证与复盘见 `docs/每日分析/选股/2026-09-08.md` §2/§6。
> 本文只改「消息面回灌」消费的**事件驱动专家**口径 + 回灌层冲突处理，**不动**全A 主排序、
> 不动回灌权重/base 剔除口径/资金流留 base、不动并行化。全部加 config 可逆开关、默认开。

## 1. 根因诊断（三例复盘 → 五类根因）

| 样本 | 现象 | 根因 |
|---|---|---|
| `000019 深粮控股` | 减持×6 + 净情绪 −0.229 却得消息面 **+0.53** | 情绪方向单方面把真减持拉成正分（方向冲突未处理）；疑同名 000027 张冠李戴 |
| `600356 恒丰纸业` | 数据面全批最高 0.732 被 **−0.71** 压到 #5 | `_load_precise` 增减持**无时效下限**，2018–2020 陈旧减持全被计入；重组「承诺不减持/锁定」文本被当利空 |
| `000035 中国天楹` | 正分方向对但依据是上半年旧减持 | 同样缺时效过滤：旧减持与近期增持混算，依据错配 |

**现状核对（读码确认已有 / 仍缺）**：
- ✅ 事件方向符号本就正确（`judge.py` 公司行为方向 减持=−1、增持/回购=+1）。
- ✅ 防未来已有（`_load_precise` 跳过 `日期 > as_of`）。
- ✅ 协议转让/战略引资/二级减持性质区分已有。
- ❌ **增减持精数值路径无时效下限**（`公司行为窗_天` 仅在公告粗判用，精数值路径漏了）——600356 病根。
- ❌ **无「重组承诺不减持/锁定」文本排除**——把非真实减持文本当利空。
- ❌ 回灌层**无方向冲突处理**——情绪看多可单方面把真减持拉成正分（000019 病根）。
- ⚠️ 代码归属靠精确 `df["code"]==code`，但两侧格式未强制归一，加固为归一化匹配。

## 2. 各修复口径

### 修复1 · 事件方向符号正确（已正确，加断言锁死）
`公司行为方向` = {增持:+1, 回购:+1, 减持:−1}。无需改逻辑，加红线测试「纯减持样本事件驱动方向=看空」。

### 修复2 · 事件时效过滤（新增，核心）
`tools/analysis/event_driven/summary.py:_load_precise` 增减持精数值路径加**时效下限**：
只取 `as_of − 增减持时效_月`（config 默认 6 个月）≤ 变动日期 ≤ as_of 的记录，更早的历史事件不进当日消息面。
- 只用 ≤ as_of 信息（防未来不变），下限只是再砍掉过旧记录。
- **缺日期**记录：保守保留（沿用既有「缺日期不漏」行为，向后兼容）。
- 开关 `事件驱动.增减持时效过滤`（默认 True）关 → 退回旧无下限行为。

### 修复3 · 重组承诺文本排除（新增）
`judge.py:classify_share_change` 增类别「非减持承诺」：文本命中 `减持排除关键词`
（承诺不减持/锁定期/延长锁定/限售/转让限制…）且非二级抛售 → 看空无效、方向中性、强度 0。
`judge_corporate_action` 与 `_coarse_from_announcements` 同步识别该类别 → 中性、不计利空。
优先级：战略引资 > 二级减持（真抛售）> 非减持承诺 > 协议转让待定 > 普通减持。

### 修复4 · 同名代码归属校验（加固）
`_load_precise` 用**归一化代码**（补零 6 位、去非数字）在两侧对齐匹配，杜绝格式差异导致的漏配/错配；
加测试锁「只有本 code 的事件参与，别的 code 事件不串味」。

### 修复5 · 方向冲突处理（新增，回灌层）
`tools/pipeline/candidate_message.py:_score_one`：读消息面合议归因里 事件驱动/情绪三层 方向，
当**事件驱动=看空（真减持）而情绪=看多**冲突时，按 `冲突降权系数`（默认 0.0=中和）
缩放正的消息面分，杜绝情绪单方面把减持拉正。输出加 `方向冲突`/`冲突降权` 标记。
开关 `消息面回灌.方向冲突降权`（默认 True）关 → 退回旧行为。

## 3. config 开关（均默认开，可一键回退）
- `事件驱动.增减持时效过滤` = True，`事件驱动.增减持时效_月` = 6
- `事件驱动.减持排除关键词` = [承诺不减持, 不减持, 锁定期, 锁定承诺, 延长锁定, 限售, 转让限制, 股份锁定]
- `消息面回灌.方向冲突降权` = True，`消息面回灌.冲突降权系数` = 0.0

## 4. 测试覆盖（tests/，锁语义防未来重写误删）
- 纯减持（近期真实）→ 事件驱动=看空 且回灌消息面分 ≤ 0（锁 000019 类）。
- 只有陈旧(>N月)减持、近期无事件 → 事件驱动弃权/中性、不误压（锁 600356 类）。
- 近期增持 + 旧减持 → 事件驱动看多、依据为近期增持（锁 000035 类）。
- 重组「承诺不减持/锁定」文本 → 不计减持利空。
- 代码归属：别的 code 的减持不串味到本 code。
- 防未来：变动日期 > as_of 不参与（已有，回归保留）。
- 各 config 开关关闭 → 退回旧行为（可逆）。

## 5. 回滚方式
四个开关任一置 False 即回退对应修复；全置 False 完全回到旧行为。config 单一真源、`dump_json` 同步 strategy.json。

## 6. 对既有选股的影响预估
- 600356 一类：陈旧减持被过滤 → 事件驱动不再强看空 → 消息面分从 −0.71 回中性，完整分回到数据面高位（纠偏）。
- 000019 一类：方向冲突中和 → 消息面分不再被情绪拉正，回中性/偏空（纠偏）。
- 000035 一类：旧减持过滤后依据为近期增持，方向与依据一致。
- 绝大多数近期真实增减持票不受影响（时效窗内照常计入）；影响范围限于「有陈旧事件 / 事件与情绪方向冲突」的少数票。
- 全A 主排序、回灌权重、base 口径均不变。
