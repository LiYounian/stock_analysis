# 日筛「近史加载」护栏 · 设计与预注册

> 日期:2026-08-14 · ⚠️ 非投资建议
> 缘起:主档回补到 8.4 年(为多 regime 回测)后,**每日全A闭环崩了**——日筛/序列化每票都去读 8.4 年全历史(~2090 根/票 × 5543 票),叠加 mini_racer 在内存吃紧时原生崩溃。用户定调:**显示走近期、采集走近期增量,不必每次跑 8.4 年;8.4 年只留给回测。**

## 1. 根因(已定位)
`collectors/market.py::load_kline(code)` 直接返回 `store.get_master_kline(code)` = **主档全历史**。
- 日筛全部走它:`screen_s01/s02/box/momentum/council/pattern`、`regime`、`serialize`、`chart`、`factor/score`、`run.py` 的 ta.compute。
- **回测也走它**(`backtest_s02/box/predict/rank/pead/newhigh/sentiment`、`forward_scorecard`、`position_backtest` …),且**依赖它返回全历史**做逐日 `iloc[:t+1]` 多年切片。

⇒ 不能直接截断 `load_kline`,否则**静默毁掉 8.4 年多 regime 回测**。必须分叉。

## 2. 方案:分叉加载器(推荐)
- `load_kline(code)` **保持不变** = 全历史(回测继续用)。
- 新增 `load_kline_recent(code, rows=None)`:读主档/raw 后只取 **近 N 根尾部**(默认 `DAILY_KLINE_ROWS`),**保留原索引不 reset**(行为对齐现有 load_kline,避免动到依赖 iloc/rolling 的下游)。
- `settings.DAILY_KLINE_ROWS = 500`(约 2 年交易日)。
- 把**日筛/分析**的 11 处调用切到 `load_kline_recent`;**回测/forward_scorecard/position_backtest 一律不动**。

### 窗口大小依据(已量)
日筛路径最长回看 = **251 根**(s01:MA200=200 + 52周高 H52=250、不含当日 → 下限 251;趋势模板同量级;momentum lookback=25;box 更短)。
取 **500** = 最长回看的 ~2x 冗余 → 不降级任何日筛信号;同时 500/2090 ≈ 内存/IO **降到 ~1/4**。

## 4. 预注册假设 / 测试锁语义
| 断言 | 判据 |
|---|---|
| 近史加载器只返回 ≤N 根 | `len(load_kline_recent(c)) <= DAILY_KLINE_ROWS` 且 == `load_kline(c).tail(N)` |
| 回测加载器仍全历史 | `len(load_kline(c))` 远 > N(多年) |
| 日筛信号不降级 | 同一票 s01/s02/box/momentum 用 recent vs full 产出**完全一致**(因 N > 最长回看 251) |
| 内存下降 | 全A日筛峰值 RSS 明显低于全历史版(定性:闭环不再崩) |

测试:`tests/test_daily_kline_window.py` —— 断言上面 4 条(尤其第 3 条"recent 与 full 日筛结果逐字段相等",防未来有人加了 >500 根的回看却忘了扩窗)。

## 6. 回填(实现后 · 2026-08-14)
**已落地**:`settings.DAILY_KLINE_ROWS=500` + `market.load_kline_recent`;12 处日筛调用切到近史加载器;回测目录零改动(已 grep 确认无 `_recent`)。momentum.py 的 `_load_closes_from_record`(动量组合)也切近史。

**测试**(`tests/test_daily_kline_window.py`,3/3 通过):
- `recent == full.tail(N)` 且 `len ≤ N` ✅
- `full` 仍多年(> N)——回测未被截断 ✅
- ⭐ **日筛信号 parity**:同票 `ta.compute(recent)` 与 `ta.compute(full)` 除行数 n 外**逐字段完全相等**(ma/macd/kdj/rsi/bias/vol/signal/reversal/ob_os/last)✅ —— 证明 N=500 > 最长回看 251,不降级任何信号。

**内存/IO 实测**:真实主档 000001/000002/000006 全历史 **2091 根 → 近史 500 根 = 降 76%**。全A日筛每票加载量降到 ~1/4,直接消除此前"8.4 年主档 × 全A"的内存爆点。
