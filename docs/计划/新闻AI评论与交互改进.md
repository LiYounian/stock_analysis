# 计划:新闻 AI 评论 + 统一新闻存储格式 + 交互改进

> 状态:开发中 · 2026-08-07 · 分支 `feat/news-ai-comments`。
> 一句话:设计一份**统一的"新闻 + AI 分析"存储格式**(一次生产,处处复用),让 /news、个股页、详情页都读它;补 AI 评论列/块、可回退的交互、并跑出今天的数据让日期下拉可选。

## 需求整理(来自负责人)
1. `/news` 每日信息流加一列:**AI 分析结果 + 分析原因**(推断/评论文本)。
2. **交互**:详情页只能点"个股"、点不回来 → 加"返回上一页 / 面包屑"。
3. **日期**:目前磁盘只有 2026-08-06 → 跑今天数据,验证日期下拉可选多天。
4. **个股页新闻消息**也展示 AI 评论,且能进详情页并返回。
5. **新闻详情页**也要有 AI 评论。
6. **设计好新闻保存格式**,实现时复用、不重造轮子。

## 核心设计:统一"新闻+AI"格式(可复用单一来源)⭐
**新增按票视图** `data/analysis/<日期>/news_ai/{code}.json`,一条一新闻,原始字段 + AI 分析合一:
```json
[
  {
    "title": "...", "time": "...", "source": "...", "url": "...",
    "content": "...(原始正文,≤2000)",
    "ai": {
      "方向": "利好|利空|中性",
      "强度": 0,                       // 0~5
      "与本股关系": "直接|间接|无关",
      "评论": "一句话推断/点评(AI)",
      "原因": "为什么这么判断(AI 简述)"
    }
  }
]
```
- **生产**:新增 `analysis` 层一步 `enrich_news(code, date)` = 读原始新闻(`data/raw/<日期>/news/{code}.json`)+ **复用 `event.py` 已有的 LLM 逐条抽取**(方向/强度/关系/摘要,已带缓存,不额外烧钱)→ 按序合并 → `store.put_code_view("news_ai", code)`。评论/原因优先复用抽取的摘要;如需"原因"单列,最小扩展抽取 prompt(能复用就不新增字段)。
- **消费**:`data_access` 只认这一份;`news_list/news_detail` 改读 `news_ai`(缺失回退原始新闻,`ai` 为空不崩)。**/news 列、个股页新闻块、详情页 全部复用同一 reader,零重复逻辑。**
- **复用点**:LLM 抽取复用 event.py;存取复用 store 的 code_view;按日期复用现有分区;web 复用 data_access 单一 reader。

## 分期(用开发模式:后端 subagent + 前端主窗口渲染验证)
- **P1 后端(subagent,worktree)**:定义 news_ai 格式 + `enrich_news` 步骤(接 run.py)+ `data_access.news_list/news_detail` 改读 news_ai + 单测。无需渲染、可测试自证。
- **P2 前端(主窗口,实时渲染验证)**:
  - `/news` 加 **AI 列**(方向徽章 + 评论文本);标题/行可点(已做)。
  - `news_list.html` / `news_detail.html`:展示 AI 评论 + **面包屑**(每日信息流 / 该股新闻 / 本条)+ `← 返回上一页`(history.back 兜底)。
  - `stock.html` 新闻块:列原始新闻 + AI 评论 + 链接到详情(可返回)。
- **P3 数据**:跑今天(2026-08-07)全链路(含 enrich_news),让日期下拉 ≥2 天,截图验证可选日期。
- **P4 文档**:开发日志 + 架构小节。

## 交互设计(点2/4)
- 详情页顶部面包屑:`每日信息流 › {股票}新闻 › 本条`,每级可点;另加 `← 返回上一页`(`onclick=history.back()`)。
- 所有二级页(news_list / news_detail / stock)都带"返回上一页" + 面包屑,不再只有单向"个股"入口。
- 全站链接继续带 `?date=`,历史日期下钻不丢日期。

## 预期效果
- /news 每行看到 AI 方向 + 评论;点进详情看完整正文 + 来源 + **AI 评论/原因** + 原文链接 + 可返回。
- 个股页新闻块有 AI 评论且能进详情并返回。
- 日期下拉出现 2026-08-06 / 2026-08-07 两项,可切换回看。
- 新闻数据"一次生产处处复用",新增页面直接读 news_ai。

## 依赖方向
enrich_news 属分析层(读 raw + 调 llm/event,写 analysis view),合规;web→data_access→store 只读,合规。
