## 〇、一段话背景(大白话,先读)

**保守版**只在预测卡片旁加一句"消息面提示"(偏多/偏空/中性),**不改任何预测数字**——零风险,正在开发。

**激进版**要更进一步:**真的拿消息面去动预测的涨跌方向/幅度**。为什么想做?因为已被诚实回测钉死的一个事实:**纯技术指标的条件化预测在聚合层面没有超额**(方向准确率≈掷硬币、Brier 无显著改善),但**指标状态里其实藏着约 20 个百分点的真实区分力**(如"超卖触下轨"次日反弹率 60.3% vs "超买触上轨"40.3%),只是"历史频率法"没能把它提出来用。我们指望消息面补上技术指标天生看不见的东西——政策/公告驱动的大涨大跌、断点——把那 20pp 潜在区分力 + 消息信号,变成**真实可用**的方向/幅度改善。

**但必须先把丑话说前面**:本项目此前对消息面做过多轮诚实回测,结论几乎全是"消息面的**解释力 > 预测力**"——净情绪分对前瞻收益的 IC 不显著**且方向是反的**(更像对异动的滞后描述,而非领先信号);PEAD"见光死"、无漂移;泛舆情把"有没有消息"稀释成 85% 饱和的噪声。**唯一还有一线希望的是"消息持续性(结构性 vs 短暂)"的区分,且它需要前向累积几周到几个月才测得动。** 所以激进版的**诚实默认预期是:naive 地按顶层净情绪分去倾斜预测,大概率不会有用、甚至帮倒忙;真正可能有用的路径很窄(根源+结构性+前向累积验证过),且当前无数据支撑其有效性。** 本文的作用就是把"设计、指望、差距、怎么补、什么条件下才允许真上线"讲清楚。

## 一、目前激进版的设计 + 预期(回答问题 1)

### 1.1 机制:后验倾斜(登记版,接入指标条件化预测线)

激进版接入点是 `tools/analysis/conditional_predict.py` 的 `conditional_scenarios`(产出每个持有期的 `上涨概率%`/区间/期望)与 `direction_view`(把 `上涨概率%` 按阈值 `看涨≥58 / 看跌≤42` 映射成方向)。登记的机制是**在概率层做后验倾斜**:

```
p_adj = clip( p + k · 净情绪分 · 100 , 0 , 100 )
```

- `p` = 指标条件化预测给出的原始上涨概率%;`净情绪分` ∈ [−1, 1](event.py 三层加权);`k` = 增益系数,**落 `THRESHOLDS['指标条件化']`,不硬编码**。
- 倾斜后的 `p_adj` 重新过 `direction_view` 的 `看涨58/看跌42` 阈值 → 可能把原本"中性"的边界样本翻成"看涨/看跌"。
- **参数量纲提醒**:`净情绪分·100` 落在 [−100, 100],故 `k` 必须很小(k=0.05 → 满情绪时 ±5pp;k=0 → 与纯技术逐字节等价)。建议实现时把公式写成 `p + k·净情绪分`(k 直接是"满情绪时的 pp 位移"),更好标定、更好读。

**新鲜度降权**(按保守版 §6 登记):
- `新鲜度 = 无数据` 或 `样本数 == 0` 或 `sentiment` 缺失 → **k=0,不倾斜**(向后兼容,等价纯技术)。
- `新鲜度 = 陈旧` → **k 减半**(消息偏旧,降权)。
- `新鲜度 = 新鲜` → 正常 k。

**幅度/区间平移(可选,建议早期不做)**:登记设计里提到可把"悲观/中位/乐观"区间按情绪平移。但区间校准当前已 ~87% 可用,而消息面对**幅度**的预测力从未被验证过,平移区间比倾斜方向风险更大。**建议:方向倾斜先行,区间平移留到方向那步被证明有效之后再单独论证。**

**可开关 + 可回归**:k=0 时 `p_adj≡p`,输出与纯技术逐字段等价——这既是 kill-switch,也是回归测试锚点(必须有单测锁"k=0 时激进版与纯技术输出逐字段相等")。

### 1.2 三种机制的取舍(为什么选后验倾斜)

| 机制 | 做法 | 优点 | 致命约束 / 结论 |
|---|---|---|---|
| **A · 后验倾斜**(登记版) | 在 `上涨概率%` 上加 `k·净情绪分` | 最小、局部、可开关、单点、可回归对齐;一个 config 旋钮 | 加性倾斜可能失准;**若情绪信号是滞后/反向的,倾斜方向会错**(见 §1.5)。**→ 选它作首选,但强制回测标定 k、允许 k 收敛到 0 甚至负** |
| **B · 并入建池维度** | 把情绪状态作为 `state_pool` 第 4 个匹配维度,让"相似历史日"也匹配情绪 regime | 理论最干净(和技术状态同源建池) | **历史消息面无法回填**——`state_pool` 是全A×8年 K 线,情绪只有近一个月(见 §2①)。**短期不可行**,只能靠前向累积几个月后才有"带情绪标签的历史池" |
| **C · 事件条件化 / 断点**(独立文档) | 只在"大涨大跌 / 技术-消息背离 + 根源结构性消息"处打断点,叠加独立事件修正层 | 可解释、可单独回测、只碰边界、贴合"消息补技术盲区"的初衷 | 更"对味"但更重;当前**暂缓**(样本≈0,靠前向累积)。**长期更可能是正解**,与激进版 A 不冲突,可并行推进 |

**结论**:激进版第一步走 **A(后验倾斜)**,因为它最小、可开关、可回归。但**必须**把倾斜的"输入信号"从"顶层净情绪分"收窄到更可信的口径(见 §1.5),并接受"k 可能标定为 0"的诚实结果。**B 短期不可行**(无历史);**C 是更有机会的长期路径**,建议作为激进版的"演进方向"而非替代——先用 A 验证"消息能不能改善方向",再用 C 把"结构性事件断点"做成独立修正层。

### 1.3 指望它带来什么(大白话)

- **补技术盲区**:技术指标是纯量价、天生看不见消息。政策/公告驱动的大涨大跌、"违背旧规律"的断点,技术面事后才反应(滞后)。指望消息面在这些点上提前或同步给出方向线索。
- **把 20pp 潜在区分力兑现**:纯技术条件化预测知道"超卖触下轨该反弹"却把概率压在 50%(全历史平均稀释了时变关系)。如果当下有"根源利好 + 结构性"的消息,指望它成为"这次反弹更可信"的加权证据,把边界样本从"中性"推成有方向的判断。
- **让边界样本更准**:实测显示条件化概率大多挤在 45–52%,`看涨58/看跌42` 几乎不触发——激进版最可见的效果就是**在 42/58 边界附近翻转少数样本的方向标签**。这既是它能加最多价值的地方(技术信心低),也是最危险的地方(容易被噪声带偏)。成功与否几乎全看"这些被翻转的样本,实际是不是真的更准了"。

### 1.4 可量化成功判据(沿用回测报告方法学)

**基线**:纯技术的"指标条件化预测"(即 k=0)。激进版要证明的是"倾斜后相对纯技术**有增量**",而不仅仅是"不比掷硬币差"。

- **主判据**:在**已到期**的前向累积样本上,倾斜后 `p_adj` 相对纯技术 `p` 的
  - **方向命中率**(hit = sign(前瞻收益) 与方向一致)显著提升,**或**
  - **Brier 分数**显著下降(ΔBrier > 0,无条件−倾斜);
  - **显著性**:按测试日聚类的 t 统计 **> 2**(与 `回测报告_指标条件化预测_20260823.md` 同口径,防伪显著)。
- **分层看**(缺一不可,防"整体被稀释"重演):
  - 分 **regime**(牛/熊/震荡,用 `screen_forward_common.regime_tag`);
  - 分 **新鲜度**(新鲜 vs 陈旧——只在"新鲜"子集上有资格谈增量);
  - 分 **情绪来源**(根源[政策+公司公告] vs 舆情——根源才是可信信号,见 §1.5);
  - 分 **持续性**(结构性 vs 短暂——结构性才是唯一还有希望的钩子)。
- **及格线(预注册,防事后找理由)**:在"**新鲜 + 根源 + 结构性**"子集上,方向命中率或 Brier 相对纯技术**显著改善**(聚类 t>2),且改善在至少 2 种 regime 上方向一致(不是靠单一 regime 拉起来)。**达不到 → 不上线**(见 §四退出判据)。

### 1.5 诚实预期(基于本项目已有回测,不粉饰)

把已验证的结论摊开(全部来自本项目自测,非外部文献):

- **净情绪分 IC 不显著且反向**:`消息面影响与可回测性` §5.1——r_1 的净情绪分 IC = −0.118(t=−0.64 不显著),校准非单调甚至反向(正情绪票次日反而略跌)。`PEAD` §4.3——根源净情绪 r_1 IC = −0.31(t=−1.89,逆向)。**→ 直接后果:naive 按净情绪分正向倾斜,符号很可能是错的**;k 标定时必须允许出负值或 0。
- **顶层净情绪分常被舆情主导**:实测 08-24 情绪样本中,**政策层约九成为 0**(32/36 样本数=0)、新闻层部分为 0,不少票的顶层净情绪分**完全由舆情(UGC)一层决定**(缺层重归一,舆情权重从 0.2 被归一到 1.0)。而 `PEAD` §4.2 已证舆情是"有无消息 85% 饱和"的噪声放大器。**→ 直接后果:拿顶层净情绪分去倾斜,很多时候等于拿股吧情绪去改预测,这正是回测警告过的坑。** 激进版若做,**倾斜信号应收窄到根源层(政策+公司公告)、并优先只对"结构性"消息生效**。
- **PEAD 见光死**:预定型事件(业绩预告超预期)`PEAD` §4.1 无漂移、beta 伪装——上一轮寄望的"可提前的预定型 edge"被证伪。
- **唯一一线希望**:`消息持续性` ——结构性利好(长期订单/产能/政策长期扶持/主营实质改善)"市场无法瞬间完全定价、可能有更慢的持续兑现",且多来自根源、可跨源印证。但它**需要 forward_scorecard 前向累积几周到几个月才有统计力**。

> **一句话诚实预期**:激进版**很可能证不出聚合增量**,与趋势模板/SEPA/条件化预测"聚合无 alpha"一脉相承;若有,也最可能只落在"新鲜 + 根源 + 结构性"的窄子集,且需累积样本后才测得动。**因此激进版的正确姿态是"先影子跑、攒样本、诚实回测,过了才敢上"**,而不是先上再看。

## 二、现状与预期的差距 + 怎么弥补(回答问题 2)

逐条列差距/风险,每条配弥补办法。

### ① 情绪数据只有近月、无多年历史回填

- **现状(实测)**:`data/analysis/<date>/sentiment/` 仅覆盖 **2026-08-06 → 08-24**(约 18 个交易日,其中 08-16 为 0),每日仅 **10–172 只**(选出∪自选子集,非全A),多数日 30–130 只。新闻 API 历史窗口仅约一周,历史消息补不回。
- **差距**:无法做长历史回测;**无法把情绪并入"相似历史日"建池(机制 B 因此不可行)**;当前统计力≈0。
- **弥补**:
  - 在**近月可用窗口**上做 **walk-forward 诚实回测**(无未来函数:方向标签只用信号日 t 及之前,前瞻收益仅作标签)。
  - **前向累积**:复用 `tools/backtest/forward_scorecard.py`——它已每日滚存 `(date, code, 趋势评级, 净情绪分, pred_dir, persist[持续性], r_1/5/10, hit_1/5/10)`,到期自动回填、幂等无未来函数。**激进版只需给它加一列 `p_adj / hit_adj`**(倾斜后的概率与命中),几周后自然攒出可回测样本。
  - 明确对用户定性:这是**"小样本先验"**,不是长历史验证过的规律;结论一律标"方向性·待累积"。

### ② 陈旧 / 结构性零值(政策层近九成为 0)→ 有效样本稀薄

- **现状(实测)**:08-24 样本政策层 32/36 样本数=0;顶层净情绪分常被舆情单层决定。**且当前真实记录里 `新鲜度/采集日期/锁定日期` 三个字段全为 None**(契约/schema 已落 main,但情绪数据尚未用带新鲜度的新版 `event.py` 重跑回填)。
- **差距**:激进版赖以降权的"新鲜度"信号**现在数据里还没有**;有效(新鲜+有料+根源)的样本非常稀薄。
- **弥补**:
  - **先决条件**:让每日闭环用带新鲜度口径的 `analyze_stock` 跑,把 `新鲜度/采集日期` 真正写进记录(否则 §1.1 的降权逻辑是空转)。这是激进版"可以开始影子跑"的硬门槛。
  - **只在"新鲜且样本足"子集上评估**:回测/上线都按新鲜度分层,`陈旧`降权、`无数据`不倾斜。
  - **倾斜信号收窄到根源层**:用 `sentiment.三层.政策 + 公司行为` 而非顶层净情绪分(舆情不进倾斜),从源头避开噪声放大器。

### ③ 消息可能已被 price-in 或本就是噪声 → 未必有增量

- **现状**:PEAD 见光死、净情绪分 IC 反向、泛舆情 85% 饱和——多轮回测指向"消息面解释力 > 预测力"。
- **差距**:倾斜未必带来增量,甚至可能帮倒忙(符号错)。
- **弥补**:
  - **事件研究法**测"消息强弱 vs 后续超额":复用 `event_study.forward_returns`(锚+漂移+alpha,windows=1/5/10/20)+ `screen_forward_common` 双基准/regime 分层/`pick_test_days`/聚类 t,对比"倾斜 vs 不倾斜"的校准/前瞻收益/alpha。
  - **只测收窄口径**:根源 + 结构性 + 新鲜(而非泛情绪),给假设最有利也最诚实的检验。
  - **预置退出判据**:见 §四——"若无显著增量就不上激进版",写死不美化。

### ④ 增益 k 的过拟合风险

- **差距**:近月样本极薄,直接标一个 k 很容易过拟合到几十个样本上。
- **弥补**:
  - **k 落 config**、不硬编码;**预注册** k 的搜索范围与选择规则(在样本上先验),避免事后挑一个好看的 k。
  - **交叉验证 / walk-forward**:用时间序列 CV(前段标 k、后段验),而非全样本调参。
  - **聚类 t 显著性**:沿用回测报告方法学(按测试日聚类,t>2 才算数),防止把噪声当信号。
  - **允许 k=0 甚至 k<0 作为诚实结果**:如果数据说"倾斜没用"或"反向才对",就如实记录,不强行给正 k。

### ⑤ 断点如何形式化识别与动作(大涨大跌 / 技术-消息背离)

- **现状**:`三面融合与断点` 文档已给出框架但暂缓(样本≈0)。
- **差距**:激进版若要处理"断点"(旧技术规律在此失效),需要可操作的检测规则 + 验证。
- **弥补(检测规则草案)**:
  - **异动(大涨大跌)**:`|pct_chg| > k·ATR` 或 触涨跌停 → 异动 flag{方向, 幅度}(复用 `三面融合` G1 思路,统一散落各 screener 的阈值)。
  - **技术-消息背离**:技术方向(条件化 `direction_view` 或趋势评级)与消息方向相反;**或**技术反常(RSI/MACD 顶底背离、KDJ 高位钝化)与同期**根源结构性**消息共振。
  - **动作(硬约束)**:**只有"结构性持续"消息**才触发断点、才允许重估技术预测;**"短暂事件"→ 见光死 → 只标记不改数**(印证已验证的见光死主线)。技术反常与消息**互为异源佐证**——两路共振才给高置信断点,单有其一仅低置信标记。
  - **验证**:断点日作 event_date,走 `event_study.forward_returns` + 双基准/regime/聚类 t;**严格只用信号日当天已采到的消息**(约束:消息时间戳是采集日快照,历史补不回;绝不事后补采,否则 alpha 是泡沫)。

## 三、成功判据与上线门槛(什么条件下才允许真改预测数字)

**分阶段门槛,逐级放行,任一级不过就停在该级**:

- **阶段 0 · 影子跑(不上线,当前应处的位置)**
  - 前提:①新鲜度字段已在每日记录中真实回填(见 §2②);②`forward_scorecard` 加 `p_adj/hit_adj` 列,与纯技术 `p/hit` 并排滚存。
  - 动作:计算 `p_adj` 但**绝不改任何展示的预测数字/方向**,只落库累积。用户看到的仍是保守版的"消息面提示"。
  - 出口:攒够样本(预注册最小量,如 ≥ 数百条已到期观测、跨 ≥2 个 regime、≥若干测试日)方可进阶段 1。

- **阶段 1 · 回测通过**
  - 在累积样本上跑"倾斜 vs 纯技术"A/B(方法学同 `回测报告_指标条件化预测_20260823.md`):方向命中率或 Brier 显著改善、聚类 t>2、在"新鲜+根源+结构性"子集成立、至少 2 种 regime 方向一致。
  - **不过 → 停,不上线**(走 §四退出)。

- **阶段 2 · 小范围上线**
  - 只在**回测验证成立的窄子集**(如仅"新鲜+根源结构性+特定 regime")真正改预测数字;k 取保守值;**保留 kill-switch(k=0 秒回滚)**;web 明确标注"含消息面修正、非未来保证"。
  - 出口:小范围样本继续累积、持续监控命中率不劣化。

- **阶段 3 · 全量**
  - 仅当小范围在更多样本上稳住,才扩到全量;仍保留开关与分层监控。

> **红线**:任何阶段都必须保证 "k=0 时输出与纯技术逐字段等价" 的回归测试通过(守则 6:锁住"为什么改"的语义)。契约层(`prediction` 块)若新增 `p_adj/方向(含消息)` 字段,须可空、旧记录兼容。

## 四、风险与退出判据

- **符号风险**:净情绪分历史 IC 反向——倾斜方向可能系统性错。**缓解**:k 允许为 0/负;分层验证符号一致性。
- **噪声风险**:顶层净情绪分常由舆情主导。**缓解**:倾斜信号收窄到根源层。
- **过拟合风险**:样本薄、k 易过拟合。**缓解**:预注册、时序 CV、聚类 t。
- **数据前提风险**:新鲜度字段当前全 None,降权逻辑空转。**缓解**:把"新鲜度真实回填"设为阶段 0 硬门槛。
- **前视泄漏风险**:历史回测/断点归因误用事后补采的消息。**缓解**:只用信号日当天已落盘的 sentiment/events,不触网、不二次补采。

**退出判据(写死,不美化)**:
> 若在预注册的最小样本量与窗口内,倾斜相对纯技术**无显著增量**(聚类 t 不达 2,或方向命中/Brier 无改善,或改善不能在 ≥2 regime 复现),则**激进版不上线**——保守版的"消息面提示"保持为唯一的消息面呈现方式。如实回填一份 `回测报告_激进版消息面倾斜_YYYYMMDD.md`,写明"当前口径/样本下消息倾斜无预测增量",不为交付美化。
