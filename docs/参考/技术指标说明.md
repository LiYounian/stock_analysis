# 技术指标说明

> 状态:**生效中** · 更新 2026-08-05
> 定位:给项目开发者和使用者的技术指标科普与口径参考。项目内各模块对指标的计算口径,原则上与本文对齐;与行情软件显示不一致时注明出处。
> 说明:文中默认参数与阈值为主流 A 股软件(通达信/同花顺/东财等)的常见约定,不同软件略有差异,标注"(常见约定,以实际为准)"处请以实际数据源为准。

---

## 总原则(先读)

- 一切技术指标都基于历史价量推导,**本质滞后**,只能提高概率,不能确定预测。
- **趋势市**用趋势类指标(MA/MACD/BOLL 开口),**震荡市**用摆动类指标(KDJ/RSI/BOLL 上下轨),用反了会频繁打脸。
- 任何指标都不能单独使用,必须结合量价、位置(低位/高位)、市场环境交叉验证。

---

## 1. 均线 MA

**定义** 最近 N 日收盘价的算术平均连成的线。常用 5/10/20/60:5 日=攻击线(超短),10 日=操盘线(短线),20 日=辅线(短中线),60 日=决策线(季线,常见约定)。
**计算** MA_N = 近 N 日收盘价之和 ÷ N,逐日滚动。
**信号怎么看**
- **多头排列**:5>10>20>60 自上而下排列 → 上升趋势;空头排列反之 → 下降趋势。
- **金叉**:短期均线上穿长期均线(如 5 日上穿 10 日)→ 看多;**死叉**反之 → 看空。交叉发生在 20/60 日线上方、且有放量配合时更可靠。

**关键参数** 5/10/20/60 最常用;120/250 作半年线/年线(常见约定)。
**实战用法** 趋势过滤:20 日线走平转上、价格站上 20 日线才考虑参与;回踩 10/20 日线缩量不破,可作为短线参考买点。
**局限** 滞后;震荡市金叉死叉频繁、假信号率高;参数越长越稳但越滞后。

## 2. MACD

**定义** 由快慢两条指数平均之差构成的趋势动量指标,含 DIF(快线)、DEA(慢线)、MACD 柱(红绿柱)。
**计算** DIF = EMA(12) − EMA(26);DEA = DIF 的 9 日 EMA;柱 = 2 × (DIF − DEA)(A 股软件普遍乘 2,常见约定,以实际为准)。
**信号怎么看**
- **金叉**:DIF 上穿 DEA → 看多,**零轴上方**的金叉强于零轴下方;死叉反之。
- **零轴**:DIF 在 0 上方为多头市场,下方为空头市场。
- 红柱渐长 = 多方动能增强;绿柱渐长 = 空方动能增强。
- **顶背离**:价格创新高而 DIF/红柱不创新高 → 见顶预警;**底背离**:价格创新低而 DIF 不创新低 → 见底参考。

**关键阈值** 零轴是多空分界,无固定超买超卖数值。
**实战用法** 趋势市靠零轴 + 金叉定方向;背离用于高位/低位提示动能衰竭,需 K 线形态与量能二次确认后再动作。
**局限** 双重平滑、滞后明显;震荡市金叉死叉基本不可用;背离可以"连续背离",不能用来精确抄底逃顶。

---

## 3. KDJ(随机指标)

**定义** 衡量当前收盘价在近 N 日价格区间中的相对位置,反映短线动能。
**计算** 默认参数 (9,3,3):RSV = (C − 9日最低) ÷ (9日最高 − 9日最低) × 100;K = 2/3 × 前K + 1/3 × RSV;D = 2/3 × 前D + 1/3 × K;J = 3K − 2D。
**信号怎么看** 金叉:K 上穿 D,发生在**超卖区**更可靠;死叉反之,发生在超买区更可靠。J 值最敏感,常率先拐头。
**关键阈值** K/D > 80 超买,< 20 超卖;J > 100 为超强势(也意味风险积聚),J < 0 为极端超卖(常见约定)。
**实战用法** 震荡市效果好:超卖区金叉参考买入、超买区死叉参考卖出;结合支撑/压力位使用胜率更高。
**局限** 单边行情中 K/D 会**钝化**(长期贴着超买/超卖区)而失效;J 值假信号最多;趋势市中应服从趋势指标。

---

## 4. RSI(相对强弱指标)

**定义** N 日内涨幅占全部波动的比例,衡量多空力量对比。
**计算** RSI_N = 100 − 100 ÷ (1 + RS),RS = N 日平均涨幅 ÷ N 日平均跌幅。常用 6/12/24:6 敏感(短线)、12 适中(中线)、24 平滑(长线)。
**信号怎么看** RSI 高位运行 = 强势;低位拐头向上 = 空方力竭。部分软件也用短期 RSI 上穿/下穿长期 RSI 作金叉死叉信号(常见约定)。
**关键阈值** > 80 超买、< 20 超卖;也有软件用 70/30(常见约定,以实际为准)。
**实战用法** 震荡市中 RSI6 跌破 20 后拐头,可作超跌反弹参考;配合背离(价格新低而 RSI 不新低)可靠性更高。
**局限** 趋势市同样钝化(主升浪中 RSI 可长期 >80);单指标假信号率高,需与量能、位置配合。

---

## 5. BOLL(布林带)

**定义** 由中轨 ± k 倍标准差构成的价格通道,刻画价格的波动范围。
**计算** 默认参数 (20,2):中轨 = MA20;上轨 = 中轨 + 2 × 标准差;下轨 = 中轨 − 2 × 标准差(常见约定)。
**信号怎么看**
- 触及上轨 → 相对超买(但也可能是强势);触及下轨 → 相对超卖。
- **收口**(三线靠拢)= 波动收敛到极致,常是变盘前兆;收口后**开口放大** = 可能启动趋势。
- **沿轨行走**:强趋势中价格沿上/下轨持续运行,此时触轨 ≠ 反转。

**实战用法** 震荡市:触下轨 + KDJ 超卖参考买、触上轨参考卖;趋势市:以中轨作持仓参考线(回踩不破中轨 = 趋势未坏)。
**局限** 基于历史标准差,突发消息会直接击穿轨道;收口只提示"将变盘",不指示方向;单边行情中"触轨即反"失效。

## 6. 成交量 / 量比 / 换手率

**定义** 成交量 = 成交股数(或金额);量比 = 当日每分钟均量 ÷ 近 5 日每分钟均量;换手率 = 当日成交股数 ÷ 流通股本。
**放量缩量的识别**
- **放量**:当日量明显大于近期均量(常用:≥ 5 日均量的 1.5~2 倍);缩量反之。
- **量比**:> 1 较前期活跃,2~5 明显放量,> 10 极端放量(常见约定)。
- **换手率**:< 3% 清淡,3%~7% 较活跃,> 10% 高度活跃(常见约定,大盘股整体偏低)。

**实战用法** 低位放量上涨 = 资金进场参考;高位放量滞涨 = 出货警戒;回调缩量 = 抛压减轻的健康整理;缩量上涨需警惕持续性不足。
**如何定位一只票近三次放量的位置**(本项目口径):
1. **找放量日**:从最近交易日向前回溯,取最近三个满足放量条件的交易日(如当日量 ≥ 5 日均量 × 2;或近 N 日成交量前三,N 常取 60,常见约定);
2. **定位置**:判断每个放量日处于近期区间的哪个位置——低位/整理区/高位/突破前高位置;
3. **判性质**:结合当日收阳/收阴、放量上涨还是放量下跌,区分更接近吸筹还是出货;
4. **验证有效性**:若此后股价始终未跌破该放量日低点,则该次放量更可能是有效承接。

**局限** 量能可被对倒制造假量;放量阈值各软件口径不一;量比是盘中动态值,收盘前后差异大。

## 7. 支撑位 / 压力位

**定义** 历史上多空力量集中交战的价位区域:跌到附近易获支撑,涨到附近易遇阻力。
**常见识别方法**
1. **前高前低**:前低 = 支撑,前高 = 压力;被多次触及未破的位置更有效。
2. **密集成交区**:历史大量堆积的价格区域,涨到该处有解套盘抛压,跌到该处有持仓成本支撑。
3. **均线支撑/压力**:20 日、60 日线等;上升趋势中回踩重要均线常获支撑,反之亦然。
4. **整数关口**:10 元、50 元、100 元等心理价位。
5. **斐波那契回撤**:一波涨幅的 38.2% / 50% / 61.8% 回撤位(常见约定)。

**实战用法** 先标位再谈交易:确定最近的支撑与压力,评估当前位置的上下空间比;多种方法在同一区域重叠(共振)时该区域更可靠。
**局限** 支撑压力是**区域**不是精确价;有效性是概率性的;被有效突破后角色互换(压力变支撑、支撑变压力);极端趋势中所有压力都可能被突破。

## 8. 资金流向

**定义** 按单笔成交金额把资金分档,统计各档净流入。常见分档:超大单(>100 万元或 >20 万股)、大单(20~100 万元)、中单(4~20 万元)、小单(<4 万元);**主力 = 超大单 + 大单**(各软件口径不一,常见约定,以实际为准)。
**计算** 某档净流入 = 该档主动买入额 − 该档主动卖出额(主动买/卖按逐笔成交的主动方向判定)。
**解读**
- 主力持续净流入 + 上涨:量价配合,趋势较健康。
- 主力净流入 + 价格横盘/小跌:可能低位吸筹。
- 高位主力净流出:出货警戒。
- 主力净流出 + 小单净流入:散户接盘迹象,谨慎。

**局限** 分单算法是各软件黑箱,主力可拆单伪装;主动买卖判定本身有噪声;只适合短线辅助参考,不能作为长线依据。

## 9. 量价关系与量价背离

**经典组合**

| 价 | 量 | 一般解读 |
|---|---|---|
| 涨 | 增 | 交投活跃,上涨较健康 |
| 涨 | 缩 | 跟风不足或高度锁仓,持续性存疑 |
| 跌 | 增 | 抛压放大,可能出货/恐慌 |
| 跌 | 缩 | 抛压衰减,可能接近止跌 |

**量价背离** 价创新高而量能明显萎缩 → 上攻动能不足,顶部预警;价持续下跌而量能萎缩到极致 → 抛压枯竭,可结合其他信号观察见底。
**实战用法** 量价必须结合**位置**解读:同样是"放量上涨",低位启动与高位末端的含义完全不同;一般量在价先,量能变化往往领先于价格。
**局限** 量能可被操纵;量价规律是经验而非定律;涨跌停板制度下量能会失真(缩量涨停反而可能很强)。

## 10. ATR(平均真实波幅)

**定义** N 日内真实波幅的均值,衡量价格波动幅度,**只反映波动大小,不指示方向**。
**计算** TR = max(当日最高−当日最低, |当日最高−昨收|, |当日最低−昨收|);ATR = TR 的 N 日均值,默认 N=14(常见约定)。
**实战用法(止损/止盈)**
- **止损**:止损价 = 买入价 − k × ATR,k 常取 2~3(常见约定),并随股价上移滚动上移(跟踪止损)。
- **止盈参考**:买入价 + m × ATR,或结合前高/压力位设定。
- **仓位管理**:ATR 越大(波动越剧烈),同等风险预算下仓位应越小。
- 优点:止损宽度自动适配个股波动特性,既不易被正常波动震出局,也不会对高波动票设得过松。

**局限** 不能判断方向;k 取小了易被震出、取大了亏损扩大;ATR 本身也滞后,波动骤变时反应慢。

## 11. 超买超卖的综合判定(多指标共振)

**动机** 单一指标都会钝化或误报;多个**相互独立维度**的指标同时给出极端信号时,均值回归的概率显著提高。
**四个共振维度**
1. **动能(KDJ)**:K/D < 20 超卖区出现金叉,J 值 < 0 后拐头向上;
2. **强弱(RSI)**:RSI6 < 20 后拐头向上;
3. **乖离(BIAS)**:BIAS_N = (C − MA_N) ÷ MA_N × 100 负乖离达到极端(如 6 日 BIAS ≤ −3% ~ −5%;阈值随市场阶段和个股波动差异很大,常见约定,以实际为准);
4. **量能**:成交量萎缩到极致(抛压枯竭)→ 再温和放大(资金开始承接)。

**用法** 同时满足的维度越多,超跌反弹信号越强;若再叠加支撑位(前低/密集区/斐波那契位)则更佳;稳健做法是等共振出现后,由第一根放量阳线或收盘拐头作确认,而不是左侧直接接。
**局限** 共振提高的是概率而非确定性;系统性下跌中所有指标集体钝化,"底下面还有底";"极端值"的判断本身依赖历史分布,换个市场环境阈值就要重新校准。

## 12. 两大场景下的指标用法

### (a)选股筛选阶段

目标:**批量、快速过滤**。指标必须阈值明确、可程序化计算、误杀率可控。侧重:
- **趋势过滤**:20 日线向上、均线多头排列(5>10>20)、收盘价站上 20 日线;
- **动能过滤**:MACD 的 DIF > 0 或近期金叉;RSI 处于 50~80(强势但未超买);
- **量能过滤**:量比 ≥ 1.5(交投开始活跃)、换手率落在合理区间(如 3%~10%);
- **位置过滤**:距 20 日线乖离不过大(防追高)、BOLL 收口后向上开口。

原则:筛选阶段只做**硬阈值初筛**,不做精确择时;宁可放过,控制入选数量,把精细判断留给下一阶段。

### (b)选定个股后的深度评估阶段

目标:**择时、定风险、定止损止盈**。侧重:
- **位置与结构**:支撑/压力识别(前高前低、密集成交区、均线、斐波那契),评估当前位置的上下空间比;
- **量价深挖**:定位近三次放量位置并判断性质(吸筹/出货),检查量价配合与量价背离;
- **择时共振**:KDJ + RSI + 乖离率 + 量能超跌共振找介入点;MACD 顶/底背离提示趋势衰竭风险;
- **资金确认**:主力净流入的方向与持续性;
- **风险管理**:用 ATR 定止损/止盈宽度与仓位大小。

原则:深度评估讲究**交叉验证**——趋势(MA/MACD)、动能(KDJ/RSI)、量能(量价/资金流向)、波动(ATR/BOLL)四个维度互相印证;任一维度出现矛盾(如价涨量缩、主力流出),应下调该票的评估等级而不是视而不见。

## 附:口径速查表

| 指标 | 默认参数 | 超买/超卖或关键阈值 | 主要用途 |
|---|---|---|---|
| MA | 5/10/20/60 | — | 趋势、排列、金叉死叉 |
| MACD | (12,26,9) | 零轴 | 趋势 + 顶底背离 |
| KDJ | (9,3,3) | 80 / 20 | 短线动能、震荡市择时 |
| RSI | 6/12/24 | 80 / 20(或 70/30) | 强弱、超买超卖 |
| BOLL | (20,2) | 上/下轨、收口开口 | 波动通道、变盘提示 |
| 量比 | 对近 5 日均量 | > 2 明显放量 | 交投活跃度 |
| ATR | 14 | — | 波动幅度、止损宽度 |
