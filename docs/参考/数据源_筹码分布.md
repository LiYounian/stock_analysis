# 数据源 · 筹码分布(本地推演)

> 新增日期：2026-08（借鉴 a-stock-data §4.6 CYQ）
> 采集器：`tools/collectors/chip.py`　落盘 kind=`chip`
> 一句话：**不拉任何新接口**，纯用已有主档 K线的 OHLC + 换手率推演每日「持仓成本分布」，派生获利比例/平均成本/成本区间/集中度四类因子。

---

## 1. 为什么做

项目现有资金流(`fundflow`)是「分钟/日级净流入」，反映**当下**买卖强度；但缺一个刻画**存量套牢/浮盈结构**的维度。筹码分布回答的是「现在这个价位，多少人赚着、多少人套着、平均成本在哪、筹码锁不锁」——是择时(压力/支撑位)与选股(低位放量突破成本密集区)的经典信号，且**零额外数据源成本**。

## 2. 数据源与前提

- **无独立行情源**：价格输入就是 `market.load_kline(code)` 的主档 K线。
- **关键前提**：需要每日**换手率** `turnover` 列。
  - 主档由 baostock 回补时**含** `turn`（已归一为 `turnover`，单位 %）。
  - 若主档只有腾讯裸 K线（`turnover` 全空）：`fetch_chip` 对 A股**自动用一次 baostock 会话补换手率**
    （换手率与复权口径无关，按交易日 map 即可，仅取尾部窗口减小拉取量），使筹码不依赖主档来源。
  - 港股无换手口径 → 跳过，**不伪造分布**。
- 说明：兜底是**运行期临时**补换手率，不回写主档；若希望常驻，可在 master_sync 用 baostock 源回补主档。

## 3. 算法(三角分布 + 换手衰减)

业内通行的「衰减型」筹码模型：

1. **离散化**：把近 `_WINDOW=250` 根 K线的 [最低价, 最高价] 切成 `_GRID=400` 个价格格点。
2. **首日播种**：以「全部流通盘」为初始存量(质量=1)，按首日价格三角分布铺开——**不能从零起步**，否则前段占比虚高(a-stock-data 明确注记)。
3. **逐日演进**，对每根 K线：
   - 当日均价 `peak` = 成交额/成交量(VWAP，落在 [low,high] 内才采信)，否则 (高+低+收)/3；
   - 当日新增筹码 = 换手率 `tr`(clip 到 [0,1])，按**三角形分布**(峰在 `peak`)铺在 [low,high]；
   - 历史筹码整体乘 `(1 - tr)` 衰减；
   - 叠加：`chips = chips*(1-tr) + 三角权重*tr`。
4. **归一化**：最终分布和≈1。

## 4. 派生因子(落盘字段)

`summarize(df)` 产出并落盘：

| 字段 | 含义 | 解读 |
|---|---|---|
| `获利比例` | 成本 ≤ 现价 的筹码占比(0~1) | 越高→浮盈盘越多→潜在抛压越大；低位由低转高常伴突破 |
| `平均成本` | 全体筹码加权平均成本(元) | 现价 vs 平均成本 = 市场整体盈亏线 |
| `成本区间下沿/上沿` | 90% 筹码所处价格上下沿(元) | 密集区即压力/支撑带 |
| `集中度90` | (上沿-下沿)/(上沿+下沿) | 越小→筹码越集中(锁仓)→变盘前兆 |
| `现价` | 最新收盘 | 供分析层对照 |

## 5. 更新逻辑(编排)

- **全量**：`run.collect_values` 在「主档 K线同步」之后调用 `chip.fetch_chip(codes)`——因筹码依赖当日 K线，必须排在 K线之后。纯本地、无网络、**不 sleep**。
- **补缺**：`run.collect_values_missing` 对无 `chip` 缓存的票补算(skip-if-cached)。
- **失败/降级**：单票 K线缺失 → `FileNotFoundError` 记 log 跳过；换手率半数以上缺失 → `summarize` 返回全 None，不写空快照。

## 6. 读取

```python
from tools.collectors import chip
rec = chip.load_chip("600000")     # {获利比例, 平均成本, 成本区间下沿/上沿, 集中度90, 现价}
```

分析层(factor.py)可直接取 `获利比例`/`集中度90` 作因子；预期 PEG 之类需现价的派生留分析层算。

## 7. 局限

- 窗口前的存量持仓被「一次性播种+持续衰减」近似，**非精确历史**(算法本性，非 bug)。
- 换手率口径依赖 baostock；港股无换手口径 → 不支持。
- 三角分布是对「当日成交价分布」的简化，极端一字板/停牌日会被 `h>=l` 守卫跳过。
