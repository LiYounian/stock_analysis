# 数据源 · 行业变迁史(消除回测前视偏差)

> 新增日期：2026-08（借鉴 a-stock-data §6.7）
> 采集器：`tools/collectors/industry_history.py`　落盘 kind=`industry_history`
> 一句话：现有 `board.membership` 只存**当前所属行业**，用它回测会引入**前视偏差**；本源拉历史行业变更、还原任一时点的所属行业。

---

## 1. 问题:前视偏差(look-ahead bias)

`board.py` 的 membership 是「个股 → 当前申万/证监会行业」的快照。回测时若用它判断三年前某票属于哪个板块，就默认了「它当年就在这个板块」——但股票会**借壳、转型、重分类**：今天在「机器人」的票，三年前可能还在「传统机械」。用现状回测历史 = 用未来信息，高估策略表现。

## 2. 解法

拉每只股票的**历史行业变更记录**，并提供 `industry_at(code, date)` 还原**当时**所属行业，供回测/归因按「当时」而非「现在」取板块。

- 与 `board.py` **互补**：board 给现状(供实时选股)，本模块给历史(供回测)。

## 3. 数据源

巨潮 `stock_industry_change_cninfo(symbol, start_date, end_date)`(akshare 封装)：给出每次变更的**变更日期 / 分类标准 / 前后行业**。

- 只保留主口径 `_PREFERRED_STD="证监会行业分类标准"`，避免多标准混淆时点(可按需放开)。
- 列名 `_pick()` **防御式取数**，容忍列名漂移。
- **港股无此数据 → 落空降级。**

## 4. 落盘字段

按变更日期**升序**的记录列表：`[{date, industry, std}, ...]`。

## 5. 核心 API

```python
from tools.collectors import industry_history as ih

hist = ih.load_industry_history("002594")      # 全部变更史(升序)
ind  = ih.industry_at("002594", "2022-06-30")  # 该时点当时的所属行业(变更日期 ≤ date 的最后一条)
```

`industry_at` 无历史/该时点前无生效记录 → 返回 `None`(advisory，不抛)；调用方可回退 `board.board_of` 现状或降级。

## 6. 更新逻辑(编排)

- 该数据**近乎静态**(多年一变)，编排上走 **skip-if-cached**：`run.collect_values` 只对**尚无缓存**的票补采(`need_ih`)，`run.collect_values_missing` 同理——不每日重复拉巨潮。
- 降级：单票失败记 log 跳过；港股落空(`source="none(hk)"`)。

## 7. 回测接入建议

回测的板块/RS 中间层(个股 vs 所属板块)，把「查现状 `board_of`」换成「查当时 `industry_at(code, 回测日)`」，即可消除该维度的前视偏差。对未收录历史的票，回退现状并在结果里标注(避免静默失真)。
