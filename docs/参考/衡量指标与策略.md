## 2. 可衡量指标全清单(值得衡量的"值")

### A. 技术面(已采集,`technical.compute`)
| 指标 | 含义 | 用途 |
|---|---|---|
| 收盘 / 涨跌幅 | 最新价与当日变动 | 基准 |
| MA5/10/20/60 + 排列 | 均线与多空排列 | 趋势 |
| MACD(DIF/DEA/柱/状态) | 动能与金叉死叉 | 趋势/拐点 |
| KDJ(K/D/J/状态) | 随机指标,超买超卖 | **超买超卖** |
| RSI6/12/24 | 相对强弱 | **超买超卖** |
| 量比 / 状态 | 放量缩量 | 资金活跃度 |
| 拐点信号(标签/评分/依据) | 超跌反弹:超跌/放量反包/低位金叉/底背离 | **超卖反弹** |
| **BIAS 乖离率(待补)** | (close−MA20)/MA20,偏离均线程度 | **超买超卖(建议新增,见§6)** |

### B. 基本面(已采集,`fundamental`)
营收 / 净利 / 营收增速 / 净利增速 / ROE / 毛利率 / 净利率 / 负债率 / PE(TTM) / PB / 总市值 / 报告期。
> 注意:ROE/增速为单季度值(随报告期),横向比较看趋势而非绝对。

### C. 公司行为(已采集,`announcement`,15类打标)
近期公告清单:类型(回购/增减持/业绩预告/合同/诉讼/激励/再融资…)+ 方向粗判(利好/利空/待判)。

### D. 消息面/新闻(本次 WebSearch 手动抽取,未来 L1 自动化)
个股新闻 / 行业主线 / 政策(国内外)。每条:日期 / 来源 / 要点 / 影响方向。

### E. 情绪面超买超卖(待 L2,本次留空标注)
舆情热度、多空情绪比 —— 需 LLM 情感打分,本轮不做,文档留位。

## 3. 超买超卖判定标准(本次核心分析点)

**技术面超买超卖(多指标交叉,本轮可算):**
| 指标 | 超买 | 超卖 |
|---|---|---|
| KDJ | K>80 或 J>100 | K<20 或 J<0 |
| RSI(12) | >70(>80 极端) | <30(<20 极端) |
| BIAS(20) | > +10%(强势股放宽) | < −10% |
| 量价 | 高位放量滞涨 | 低位缩量/放量反包 |

**综合结论口径**:≥2 个指标共振才下"超买/超卖"结论;单一指标只作提示。
拐点信号(§2A)是"超卖 + 反弹启动"的进阶判断。

**情绪面超买超卖**:待 L2(舆情过热=情绪超买,恐慌=情绪超卖)。本轮文档标"待情感打分"。

## 6. 灵感/待沉淀清单(持续迭代 —— 本项目的策略资产)

> 每轮分析发现的"值得纳入策略的衡量维度/规则"记这里,人审后决定是否落代码。

- **[待落地] BIAS 乖离率**:超买超卖的经典补充指标,当前 technical 未算。建议加入 `technical.compute`,纳入§3 超买超卖共振判定。
- **[已落地] 拐点信号独立成维**:趋势评级会掩盖超跌反弹,故拐点独立(P1.5)。
- **[观察] 回购集群信号**:同板块多股集中回购(如本池澜起/汇川/豪威/韶能)可能是板块底部信号,值得做"板块回购密度"指标。
- **[观察] 趋势—拐点背离**:趋势偏空但拐点"反弹启动"的票,是超跌反弹候选池(筛选阶段可作为一条规则)。
- **[待补] 情绪面超买超卖**:需 L2 情感打分,舆情过热/恐慌作为反向指标。

### 6.1 2026-08-05 并行分析(G1–G5)沉淀的灵感(人审后决定落地)

**指标类(建议落 `technical.compute` / 打分):**
- **[高优先] BIAS 乖离率**:5 组共同呼吁。(close−MA20)/MA20;分级 −10% 超卖 / −20% 极端,极端档 + 放量 = 强信号。
- **[高优先] KDJ 假信号过滤**:J=3K−2D 放大,单独极易误判(本轮 6 只 J>100 但不共振)。共振判定降 KDJ 单指标权重;增设 **J<10 次级超卖提示**(现 K<20/J<0 会漏判 J 濒临而 K>20 的情形)。
- **距 N 日高点回撤%**:急跌型超卖单看 BIAS 不足(江波龙 681→336 腰斩),建议独立维度。
- **缩量+超跌 加权**:地量(量比<0.7)+超跌 = 抛压衰竭前兆,反弹概率高于单纯超跌。
- **双拐点高置信**:①低位金叉 + MACD 底背离;②技术超卖 + 下季业绩预告拐点。权重高于单一拐点。

**估值/基本面类:**
- **PE 适用性开关**:亏损/周期底/微利标的禁用 PE → 切 PB/PS/在手订单/扭亏进度(芯原 PE 负、晶合 131 折旧、粤电力亏损)。
- **扣非 PE + 异常值告警**:一次性损益扭曲(东芯 PE1.65);重资产代工优先看毛利率趋势/稼动率。
- **成本加成/代工模式 = 低弹性折价标签**(太极实业,涨价周期别高估弹性)。
- **在手订单/年营收倍数**:周期主线确定性锚(烽火订单到 2028、亨通海洋 290 亿、绿的到 2027Q3)。
- **"越卖越亏"价值陷阱**:销量增速 vs 净利增速背离(机器人 300024)。

**事件/结构类:**
- **回购密度**:同板块多股集中回购(本池澜起/汇川/豪威/韶能)= 板块底部信号候选。
- **定增/限售解禁抛压标签**(麦格米特);回购用途细分(注销>激励)。
- **"业绩强/股价弱"背离池**:高增速+空头趋势+拐点反弹三重叠加 = 二次布局候选(沪电)。
- **子板块联动度**:同细分同步大涨(封测双雄)提示板块性行情。
- **题材 0→1 事件 + 券商预测兑现率标注**:防乐观外推(金力转子收入占比 1%、韶能券商测 2.58 亿 vs Q1 实际 0.11 亿)。
- **周期位置 vs 价格位置错配**:强周期股利好兑现期反而深跌(江波龙),识别"利好出尽 vs 错杀"。
- **算电协同**:公用事业因 AI 算力用电获估值重塑的次生题材(粤电力/韶能)。

> 落地优先级建议:BIAS + KDJ 假信号过滤 → 距高点回撤% + 缩量加权 → 回购密度/背离池(需公告+基本面联合)。情绪面相关待 L2。
