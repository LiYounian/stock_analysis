# 数据源 · 主力资金行为(龙虎榜 / 大宗交易 / 股东户数)

> 新增日期：2026-08（借鉴 a-stock-data §3.5 / 4.2 / 4.3）
> 采集器：`tools/collectors/smart_money.py`　落盘 kind=`lhb` / `block_trade` / `holder_num`
> 一句话：相比 `fundflow` 的分钟级净流入，这三类是**主力行为的直接痕迹**，解释力更强。

---

## 1. 三类数据与信号含义

| 类型 | kind | 信号 |
|---|---|---|
| **龙虎榜** | `lhb` | 个股上榜记录：净买额、买卖席位强度、上榜原因。游资/机构动向的直接曝光 |
| **大宗交易** | `block_trade` | 折溢价、成交额、买卖营业部。大额换手 = 机构接盘(折价)/出货 |
| **股东户数** | `holder_num` | 季度户数与环比。**持续减少 = 筹码集中(主力吸筹)**；激增 = 散户化 |

## 2. 数据源

东财 `datacenter-web`，经 **akshare** 封装(字段稳定、免自拼 RPT 表)：

| 类型 | akshare 接口 | 拉取方式 |
|---|---|---|
| 龙虎榜 | `stock_lhb_detail_em(start_date, end_date)` | **一次拉全市场区间明细** → 按代码切片 |
| 大宗交易 | `stock_dzjy_mrmx(symbol="A股", start_date, end_date)` | **一次拉全市场明细** → 按代码切片 |
| 股东户数 | `stock_zh_a_gdhs_detail_em(symbol=code)` | 逐票拉(无全市场快照接口) |

> 龙虎榜/大宗用「全市场一次拉 + 切片」，单请求覆盖整批，省网络；股东户数只能逐票。
> 列名一律 `_pick()` **防御式取数**：候选列名容错 akshare 列名漂移，取不到只降级该字段、不炸整批。

## 3. 落盘字段

- **lhb**：`[{date, reason, net_buy, buy, sell, turnover_rate, pct_chg}]`(按上榜日倒序)
- **block_trade**：`[{date, price, volume, amount, premium_rate, buyer, seller}]`(按交易日倒序)
- **holder_num**：`[{date, holders, holders_prev, change_ratio, avg_hold_value, pct_chg_range}]`(按截止日倒序)
  - meta 旁记派生摘要 `summarize_holder`：`最新股东户数` / `户数环比` / `连续减少期数`(连续负增长期数 = 吸筹强度)。

## 4. 更新逻辑(编排)

- **全量**：`run.collect_values` 调 `smart_money.fetch_smart_money(codes)`，默认回看 `days=90`(季度窗口，兼顾上榜稀疏)。走 `FETCH_TIMEOUT` 短超时快速失败。
- **补缺**：`run.collect_values_missing` 对无 `lhb` 缓存的票补采(以 lhb 缓存为存在性判据)。
- **降级策略**：
  - 龙虎榜/大宗**全市场拉取整体失败** → `_safe_market` 记 WARNING 返 None，该源整体降级为空，不阻断其余；
  - 股东户数**单票失败** → 只降级该项(该票 lhb/block 照常落盘)；
  - **港股** → 三类统一落空(`source="none(hk)"`)。

## 5. 读取

```python
from tools.collectors import smart_money as sm
lhb    = sm.load_lhb("600000")          # list[dict]
block  = sm.load_block_trade("600000")
holder = sm.load_holder_num("600000")
sm.summarize_holder(holder)             # {最新股东户数, 户数环比, 连续减少期数}
```
