## 0. 硬契约(防未来 / PIT)
- **一切值只用 ≤date 的数据**(因果滚动分位、动量因果、成分 as-of),**绝不含未来**。
- **入场语义**:信号在 T 生成(用≤T)→ 消费方 T+1 入场(与回测口径一致)。
- **口径**(两选一,消费方指定,默认 native):
  - `native`(**生产默认·干净**):申万一级行业指数 + 成分当日快照聚合,~1.5yr,无归属前视。
  - `deep`(**research·弱前视**):个股聚合等权指数重建 2018+,成分=当前快照倒填历史(弱前视),仅供研究/长样本核验,**不作生产消费**。
- code→行业:`tools/collectors/code_industry.load()`(申万一级);行业名规范 `industry_map.to_sw`。

## 1. 信号清单(每个带**诚实状态标签**)
| 信号 | 含义 | 状态(P-A 实测) | 消费建议 |
|---|---|---|---|
| **拥挤度** 拥挤分位 + A/B | 行业换手因果**时序**分位(vs自身历史);A=拥挤(过热侧),B=冷清(过冷侧) | ✅**截面前瞻IC有预测力**(深史8/9年负IC,p_boot0.003,拥挤行业前瞻跑输) | **过滤/降权辅助**:回避 A、倾向 B。⚠️见 §1b 组合级边界 |
| **动量冷热** 两种分位 + 档 | 行业指数 20 日动量;**时序分位**(vs自身历史,档 1/3,2/3)+ **截面分位**(当日vs其它~29行业,档 0.2/0.8) | 🟡**描述性**(单独对行业指数前瞻收益=真null,不作独立预测) | 作**条件过滤**(如 pattern:冷行业回踩逐笔α最优);不单独择时。⚠️见 §1b |
| **行业情绪** A/B | LLM 判投资者情绪/经济展望/风格/景气(只输出A/B) | 🔜**待建(P-B·live pilot,~6周文本不可历史validate)**,防偷看6条落地后;forward-shadow纯记录不gate | 未就绪=None;就绪后先当**观察信号**,攒够≥120独立样本再谈validate |

> **动量冷热两口径含义不同,别混用**:**时序**=该行业 vs 自己常态冷热;**截面**=当日该行业相对其它行业最强/最弱(pattern rotation 用这个)。`industry_heat` 的"冷热档"默认给**截面档**。native 用 **as-of 成分**(比 pattern 的当前映射套历史更干净,以本层为准)。

## 1b. ⚠️ 用法边界(组合级 ≠ 截面级,务必读)
- **截面前瞻 IC 有效 ≠ 组合可交易**。pattern 组合级回测(资金约束+每日限仓+MTM)显示:热优先年化223% > 随机184% > **冷优先163%/回撤−30%(最差)**——"冷/低拥挤"信号在时间上**扎堆弱市 = 集中度风险**,逐笔 α 高(+1.01)但组合层拖回报、放大回撤。**per-trade α ≠ portfolio 表现。**
- **结论**:拥挤度/动量冷热**只宜作选股前的过滤 / 降权辅助**;**别单据它做组合择时、别重仓冷行业、别把截面 IC 当组合优势**。截面预测力仍成立、仍是有用的板块过滤——但用法必须限定在"辅助过滤",不是"择时权重"。

## 2. API(消费方对齐这两个签名)

```python
# tools/analysis/industry_temp/thermometer.py  (待实现)

def get_industry_thermometer(date: str, *, 口径: str = "native") -> dict:
    """申万一级全行业在 date 的板块环境信号(因果 PIT)。
    返回 {行业名: {
        "拥挤分位": float|None,        # [0,1] 因果时序分位(vs自身历史)
        "拥挤": "A"|"B"|None,          # A=拥挤/过热, B=冷清/过冷
        "动量_时序分位": float|None,   # vs自身历史; 档 1/3,2/3
        "动量_时序档": "冷"|"温"|"热"|None,
        "动量_截面分位": float|None,   # 当日vs其它~29行业 rank pct; 档 0.2,0.8(pattern口径)
        "动量_截面档": "冷"|"温"|"热"|None,
        "情绪": "A"|"B"|None,          # P-B 未就绪=None
        "n_members": int,              # 当日有效成分数(<IET_MIN_MEMBERS 该行业弃权)
        "asof": str,                   # 实际取到的≤date最近交易日
    }}"""

def industry_heat(code: str, date: str, *, 口径: str = "native") -> dict | None:
    """个股 code 所属行业在 date 的冷热(pattern 最小接口)。因果 PIT。
    code→行业 via code_industry.load;无归属/无数据→None。冷热档默认给**截面档**(rotation语义)。
    返回 {"industry": str, "冷热档": "冷"|"温"|"热"|None,   # =截面档
          "动量_截面分位": float|None, "动量_时序分位": float|None,
          "拥挤": "A"|"B"|None, "asof": str}"""
```

- **确定性**:同 (code/date/口径) 多次调用结果一致;纯读、不触网、不写生产。
- **弃权**:数据不足(成分<阈值 / 分位样本<min_periods)→ 相关字段 None,消费方按"弃权不猜"处理。
