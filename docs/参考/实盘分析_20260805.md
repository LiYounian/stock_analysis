## 0. 一句话结论

**这不是一篮子孤立个股,而是一个被同一条行业 β 串起来的「存储超级周期 + AI 算力 + 国产替代」主题组合**;
8/5 的芯片产业 +6.3% 异动,驱动是**存储涨价确认(苹果压价失败)**,票池里 5 只存储链直接受益。
技术面几乎全票"偏空/中性",与当日暴涨强烈背离——**因为我的技术评级是趋势回看,踏空了超跌反弹的主升**(这是最大的实践教训,见第 6 节)。

## 3. 三个最有信号价值的发现

1. **回购潮 = 管理层信心信号**:全池 4 只集中回购(澜起、汇川、豪威、韶能)。澜起回购经 WebSearch 确认是董事长亲自提议 3-6 亿——**公司行为层的强利好,且与消息面完全对上**。回购潮值得在组合层单独聚合成一个信号。
2. **高估值高成长,但增速要拆穿**:净利增速动辄 +200%~+2644%(江波龙/埃斯顿),多是**低基数反弹**(去年同期近亏损),不是可持续成长;需结合毛利率/绝对利润看。真·景气是澜起(+61% 且高盛/国盛一致上修)、江波龙(涨价+算力双击)。
3. **预期差催化**:天孚 CPO 量产推迟一季度,是明确的短期利空催化;这类"进度不及预期"只有消息面能捕捉,数据层看不到。

## 4. 数据质量踩坑(实践中发现,已是待办)

- **东芯股份 PE=1.65 明显异常**(PB 却 12.5)——百度估值单点数据错,需加异常值校验(PE 为负或畸低时置信度标低)。
- **ROE 是单季度值**(Q1),看着都很低(0.2~8),不能与年化 PE 直接配对判断,需年化或标注。
- **净利增速未区分低基数**:+2644% 这种要标"低基数反弹",否则误导。

## 6. 实践反哺项目:P2-C/P3/P4 该怎么建(核心收获)

这次手动分析暴露了纯数据层的盲区,直接改写后续设计:

1. **技术模块要加「异动/超跌反弹」维度** ⭐最重要
   现在的综合评级是纯趋势跟随,8/5 这种"深跌后放量反包"被打成 -60,完全踏空主升。
   → P1 增强:加入"近 N 日反弹力度""放量突破""KDJ 底背离"等**拐点信号**,与趋势分开呈现,不要用一个分数掩盖异动。

2. **情绪三层里,「行业主线消息」权重应高于个股新闻** ⭐
   这个组合的涨跌 80% 由行业 β(存储涨价)决定。逐票抓个股新闻(L1)不如**先抓板块级主题事件**(存储涨价/算力扩产/出口管制)再映射到成分股。
   → P4 政策/舆情:先做"行业主题事件流",个股新闻为辅。event.py 的三层里,"政策/行业"层要能自动关联到受影响 sector。

3. **公司行为层:回购潮/减持潮要做「集群信号」**
   单只回购是弱信号,4 只同时回购是板块级管理层信心。
   → P3 组合聚合:announcement 按 type 跨票聚合(本周回购 N 家、减持 M 家),作为情绪温度的一个分项。

4. **基本面要做「信号净化」**:PE 异常值剔除、净利增速标低基数、ROE 年化。放进 fundamental 或 event 层。

5. **舆情热度应抓「主题词」而非只抓个股名**:"存储超级周期""缺货""涨价""HBM"这类主题词的热度,比单个股票名的讨论量更能预警板块启动。
   → P4 UGC:除个股讨论量,加主题词热度榜。

6. **重点票筛选(Q1 hybrid)得加"消息面催化"权重**:澜起这种"技术弱但消息面强+回购"的票,纯技术/涨幅筛会漏掉。hybrid 里消息面/公司行为应占一档。
