# 部署说明

本项目 = **离线数据管线**(定时刷新数据)+ **Web 服务**(只读展示)。两者解耦,分别部署。

## 数据流

```
run.py all (定时跑) ──► data/raw + data/analysis/*.json + screen.json/panel  ──►  Web 只读渲染
```

Web 不做计算,只读 `data/analysis`;所以**先跑数据管线,再起 Web**。

---

## 一、本地部署(开发)

环境:conda `stock_analysis`(Python 3.11,见 [环境说明.md](环境说明.md))。

```bash
PY=~/.conda/envs/stock_analysis/bin/python

# 1) 刷新数据(采集→分析→结构化→总表→选股→报告)。首次/每日盘后跑。
$PY -m tools.run all
#   分步:collect（采集,联网）/ serialize / panel / screen / report

# 2) 起 Web
$PY -m uvicorn web.app:app --port 8000
#   浏览器打开 http://localhost:8000
```

页面:`/` 概览 · `/screen` 选股 · `/news` 新闻 · `/stock/{code}` 个股。

## 二、服务器部署(生产)

1. **环境**:服务器建同名 conda 环境或 venv,`pip install -r requirements.txt`。
2. **数据定时刷新**:用 crontab 每交易日盘后(如 15:30)跑 `python -m tools.run all`。
   ```cron
   30 15 * * 1-5  cd /path/to/股票分析 && /path/to/python -m tools.run all >> logs/run.log 2>&1
   ```
3. **Web 常驻**:用 uvicorn(可加 gunicorn + uvicorn worker)后台运行,前面挂 Nginx 反代。
   ```bash
   python -m uvicorn web.app:app --host 0.0.0.0 --port 8000
   # 生产建议:gunicorn -k uvicorn.workers.UvicornWorker web.app:app -b 127.0.0.1:8000 -w 2
   ```
4. **Nginx** 反代到 127.0.0.1:8000,配 HTTPS。
5. **进程守护**:systemd 或 supervisor 保活 uvicorn/gunicorn。

## 三、注意事项

- **反爬稳定性**:资金流走 curl_cffi 伪装指纹;东财若升级反爬需关注(问题台账 R4/B2),失败降级为量价代理。
- **限频**:采集有 `FETCH_SLEEP_SEC` 间隔;整池约数分钟。东财偶发限频,少数票资金流可能缺,重跑补齐。
- **密钥**:LLM API key 走环境变量,不入库(见大模型调用设计)。
- **数据目录**:`data/raw`、`data/analysis` 不入库(gitignore);服务器首次需先跑 `run.py all` 生成。
- **票池**:改 `tools/config/stock_pool.py`;策略阈值改 `tools/config/strategy.py`。

## 四、验收自检

```bash
$PY -m pytest tests/ -q          # 单测全绿
$PY -m tools.run serialize        # 结构化 JSON 生成
$PY -m tools.run screen           # screen.json 生成
curl -s localhost:8000 | grep 今日概览   # Web 首页可访问
```
