## 0. 结论速览(先给要点)

1. **家数核实:提供者说的「~102-105 家」基本属实。** 权威口径是证监会/财政部的 **「从事证券服务业务会计师事务所备案名录」**,**截至 2025-12-16 为 105 家**(2023-04 曾为 115 家,近年小幅收缩)。数字随备案动态变化,以证监会最新名录为准。
2. **口径要点(重要):现在是「备案制」不是「资格审批制」。** 2020 年新《证券法》实施后,证券服务业务由**审批制改为备案制**(2020-08-24 起)。所以「证券资格所」这个旧说法已不精确——现在的权威口径叫**「从事证券服务业务备案」**。历史上审批制年代确实只有约 40 家「证券资格所」;备案制放开后名单扩大到 100+，所以「102-105」对应的是**现行备案制口径**,不是旧的 40 家口径。**二者不是一回事,不要混用。**
3. **分档:** 中注协每年发布 **「会计师事务所综合评价百家排名」**,是现成的、权威的分档锚。可据此搭三档框架(见 §2)。
4. **数据获取:** akshare **没有**发现干净的「审计机构 / 审计意见」专用接口(需人工核实);最可靠来源是**年报封面 / 审计报告(巨潮 cninfo 定期报告 PDF)**。闸门1 落地需要一个「审计机构字段」采集源,这是当前缺口(见 §3)。
5. **八大类造假:** 见 §4,每类给了「表现 / 财报可观测信号(科目·比率)/ 反查红旗指标」三件套,可让 Agent 逐条反向比对。

# 一、审计机构:权威名单口径 + 家数核实

## 1.1 权威口径是什么(先厘清概念)

策略提供者的表述是「有 A 股/IPO 证券业务资格的事务所约 102-105 家,不在名单内 → 判财报不可信」。这个直觉方向对,但**术语要更新**:

| 概念 | 年代 | 权威口径 | 家数量级 |
|---|---|---|---|
| **证券期货业务资格(审批制)** | 2020 年之前 | 证监会+财政部**审批**发「证券、期货相关业务许可证」 | 历史上约 **40 家**量级 |
| **从事证券服务业务备案(备案制)** | 2020-08-24 起至今 | 证监会+财政部**备案名录**(现行口径) | **约 100-115 家**,截至 2025-12-16 为 **105 家** |

- **转折点:2020 年 3 月新《证券法》** 取消了会计师事务所从事证券服务业务的**行政审批**,改为**备案管理**;2020-07 财政部+证监会发《会计师事务所从事证券服务业务备案管理办法》,2020-08-24 起施行。2025-04 又修订印发了该办法(强化质量/合规导向)。
- 因此:**「不在名单内 = 财报不可信」这条闸门规则,对应的「名单」应是「从事证券服务业务备案名录」**(现行 105 家口径),而不是旧的「证券资格所 40 家」。提供者说的 102-105 就是这个备案名录的量级,**核实通过**。

> 诚实提示:**「能审 A 股/IPO」≠「在备案名录里」的完全等价。** 备案名录是「从事证券服务业务」的准入门槛(审 A 股上市公司年报、IPO 审计都要求在此名录内),所以「不在名录 → 不能合法承接 A 股审计」这条逻辑成立;但名录内也有能力分化(见分档)。名录是**必要条件**,不是「保真」充分条件——提供者原话也强调「过闸 ≠ 保真」。

## 1.2 家数核实(是不是 102?)

| 截止日 | 备案名录家数 | 来源 |
|---|---|---|
| 2023-04-10 | **115 家** | 中注协「从事证券服务业务会计师事务所名单」 |
| 2025-10-21 | 名录已更新(具体家数以证监会页面为准,**需核实**) | 证监会备案名录页 |
| **2025-12-16** | **105 家** | 证监会发布(新浪财经转载) |

- **结论:现行约 105 家**,与「102-105」吻合。**不是精确的 102**,而是「100 出头、动态在 105 上下」。名录**逐月/逐季更新**(有新增备案、有主动注销/被处罚移出),所以**不要在代码里硬编码一个固定家数或固定名单**,应指向**证监会最新名录**作为单一真源。
- **名单获取入口(权威·单一真源):**
  - 证监会「从事证券服务业务会计师事务所备案名录」页:`https://www.csrc.gov.cn/csrc/c100102/...`(定期发布最新截止日名录)
  - 证监会「证券期货业务会计师事务所查询」在线服务:`http://app.gjzwfw.gov.cn/jmopen/webapp/html5/zjhzqqhywkjssws/index.html`
  - 中注协(cicpa.org.cn)「信息发布」栏目同步公示
  - 财政部「注册会计师行业统一监管平台」`https://acc.mof.gov.cn/`

## 1.3 三档分档框架(框架建议,具体归档待提供者确认)

**分档最好别自己拍脑袋——用中注协「综合评价百家排名」当锚**(每年 11 月左右发布,2024 年度百强合计业务收入 698.77 亿元;评价体系 2025 年新修订,把「处罚指标」权重提到 30%,更看重审计质量与合规)。据此给一个可落地的三档:

### 第一档:国际四大在华所 + 头部内资大所(综合能力最强)
- **国际四大在华所**:普华永道中天、安永华明、毕马威华振、德勤华永。
- **头部内资**:立信、天健、容诚、信永中和、天职国际 等(即中注协综合评价**前 10 名**梯队)。
- 2024 年度综合评价前 10(供参考锚):安永华明、毕马威华振、容诚、普华永道、立信、德勤华永、信永中和、天健、天职国际、中审众环。
- 特征:注册会计师人数多、审 A 股/港股/IPO 项目多、被处罚会显著影响排名。

### 第二档:行业公认综合能力强的中大型所(通常合称「本土八大」的其余成员 + 综合评价前 30~40)
- **「本土八大」传统口径**(具 A+H 审计资格的大型内资):立信、天健、信永中和、大华、大信、致同、天职国际、容诚(不同年份/口径成员略有出入,瑞华因事故退出后名单有调整)。
- 加上中注协综合评价**约 11~40 名**的所。
- 特征:全国性布局、有一定 IPO/大盘股审计经验,能力被市场认可但低于头部。

### 第三档:名录内的中小/尾部所
- 在备案名录内、但综合评价**排名靠后**、规模小、审 A 股项目少的所。
- 特征:提供者指出的风险点——**尾部所审计能力弱、易被钻空子造假**。

> ⚠️ **归档实现建议**:不要在代码里手工维护三档硬名单(会过时)。落地方式:
> ① 名录本身(是否在 105 家备案名录内)= 闸门1 的**硬门槛**(布尔);
> ② 分档 = 用中注协**综合评价百强排名的名次**做连续分档(如 top10 / top40 / 其余 / 榜外),排名每年更新一次,比手工三档稳。名次可从中注协年度公示抓取。

## 1.4 「更换审计机构」如何构成红旗(提供者强调)

- **轮换本身不是问题**:国家要求上市公司/事务所**定期轮换**(关键审计合伙人轮换、部分强制所轮换),这是合规要求。
- **红旗看两点**:
  1. **频率**:短期内(如 2-3 年内)**频繁更换**审计机构。
  2. **方向**:**从头部所换到尾部所**(如从「四大/八大」换到第三档小所)——尤其在被出具非标意见、或财务承压时更换,是**重红旗**(疑似「找愿意签字的所」)。
- **可量化红旗**(建议实现):记录每期审计机构 + 其分档名次,检测「近 N 年更换次数」「更换后档位是否下降」。档位下降的更换 = 高严重度红旗。

# 二、审计意见类型(闸门2 的判据,附带)

> §0.5 已定义闸门2,这里补一份枚举备查。审计意见分五类,**只有第一类通过**:

| 审计意见类型 | 含义 | 闸门2 处理 |
|---|---|---|
| **标准无保留意见** | 财报公允反映,无保留、无强调事项 | **✅ 通过** |
| 带强调事项段的无保留意见 | 意见本身无保留,但提示重大不确定性(如持续经营存疑) | ⚠️ 判有问题,不往下走 / 至少高度警惕 |
| 保留意见 | 除某些事项外公允 | ❌ 判财报有问题 |
| 无法表示意见 | 审计范围受限严重,无法发表意见 | ❌ 判财报有问题(重) |
| 否定意见 | 财报**未**公允反映 | ❌ 判财报有问题(最重) |

- 数据取用同 §3:审计意见类型也在**审计报告 / 年报**中,与审计机构字段同源。
- 注:「带强调事项段」严格说属于「无保留意见」,但强调事项常涉及持续经营/重大诉讼/大额减值,提供者口径是「非纯标准无保留一律不过」,建议**把它单列为「有条件通过 / 警示」而非直接放行**。

# 四、八大类财务造假清单(深度分析反查用)

> 目标:让 Agent **反向逐条比对**财报。每类给「① 表现特征 ② 财报可观测信号(哪些科目/比率异常)③ 可反查的红旗指标」。
> 说明:「八大类」是业界常用的**归纳框架**,不同资料切法略有出入(有的合并/拆分)。下面是覆盖 A 股常见手法的一套八分类,配可量化信号。**阈值均为占位建议,待提供者标定**。

## 类1:虚增收入 / 提前确认收入(最常见)
- **表现**:编造无真实交易背景的销售、提前确认未完成的收入、通过关联方或空壳客户「买卖」、放宽验收/完工标准提前确认。
- **可观测信号(科目/比率)**:
  - 营收大增但**经营性现金流(CFO)不增或背离**(收入进了应收,没进现金)。
  - **应收账款增速 >> 营收增速**;应收占营收比逐年抬升。
  - **合同负债/预收** 与收入趋势背离。
  - **毛利率异常偏高 / 突然跳升**、显著偏离同行。
- **反查红旗**:`营收增速 − CFO增速 > 阈值`;`应收增速 − 营收增速 > 20pct`;`(营收−销售商品收到现金)/营收` 持续为大正;毛利率 z-score 相对同业 > 2。

## 类2:虚减成本 / 费用(拉高利润)
- **表现**:少结转营业成本、费用跨期递延或资本化、把费用挂到在建工程/开发支出、隐瞒关联方代垫费用。
- **可观测信号**:
  - **毛利率无正当理由持续上升**、与同业背离。
  - **研发资本化率异常高**(开发支出/研发投入),把费用变资产。
  - 期间费用率(销售/管理)**异常低于同业**或逐年异常下降。
  - 存货与营业成本**勾稽异常**(存货高企但成本结转慢)。
- **反查红旗**:研发资本化率 > 同业分位;毛利率上升但同业下降;费用率 z-score 偏低。

## 类3:资产虚增 / 存货高估(虚构资产撑规模)
- **表现**:虚构存货/固定资产/在建工程、高估存货不计提跌价、虚构工程进度、评估增值注水。
- **可观测信号**:
  - **存货增速 >> 营收增速**,存货周转天数拉长。
  - **在建工程长期挂账不转固**(逃避折旧、藏亏损)。
  - **存货跌价准备计提比例畸低**(存货高企却几乎不减值)。
  - 固定资产/在建工程占总资产畸高、周转率下降。
- **反查红旗**:`存货增速 − 营收增速 > 20pct`;存货周转天数逐期上升;在建工程占比高且转固慢;跌价计提率显著低于同业。

## 类4:少计 / 表外负债(隐藏债务)
- **表现**:通过表外主体/关联方承担负债、明股实债、隐瞒担保与或有负债、少计应付。
- **可观测信号**:
  - 资产负债表看似健康但**利息支出与有息负债不匹配**(利息多、账面负债少 → 疑有表外债)。
  - **对外担保/关联方往来**规模大(附注)。
  - **筹资现金流(CFF)** 与账面负债变动背离。
  - **大存大贷**:高货币资金 + 高有息负债并存(资金可能受限/不真实)。
- **反查红旗**:`财务费用利息支出 / 有息负债` 隐含利率异常高;大存大贷标志(货币资金与有息负债同高);担保额/净资产 > 阈值。

## 类5:现金流操纵(伪造「钱」的真实性)
- **表现**:虚构货币资金余额(獐子岛/康得新式)、票据循环、期末冲时点、将筹资/投资现金伪装成经营现金流。
- **可观测信号**:
  - **货币资金巨额但利息收入极低**(钱是假的或被质押/受限)。
  - **大存大贷**同时存在(有钱还大额借款、付高利息,不合逻辑)。
  - **CFO 与净利润长期背离**(利润好、CFO 差或为负)。
  - 现金流量表**经营/投资/筹资分类异常**(经营现金流里混入非经营项)。
- **反查红旗**:`利息收入 / 平均货币资金` 远低于活期利率;大存大贷;`CFO/净利润 < 0.8`(连续 2 期);受限货币资金占比高(附注)。

## 类6:关联方交易 / 利益输送(体外循环)
- **表现**:通过关联方虚构购销、关联方代垫成本或注入利润、资金占用、体外资金循环制造「真实」现金流。
- **可观测信号**:
  - **前五大客户/供应商集中度畸高**且含关联方/新成立/异常小的主体。
  - 关联交易占营收/采购比例高且逐年上升(附注)。
  - **其他应收/其他应付款异常大**(资金占用的藏身处)。
  - 应收/预付集中在少数关联方。
- **反查红旗**:关联交易占比 > 阈值;其他应收款/总资产 > 阈值;大客户为关联方或成立时间短、注册资本小;资金占用披露。

## 类7:会计政策 / 会计估计变更操纵(合规外衣下调节)
- **表现**:变更折旧年限/减值假设/坏账计提比例/收入确认政策,择时释放或隐藏利润;频繁变更审计机构配合。
- **可观测信号**:
  - **折旧年限突然拉长、坏账计提比例突然下调**(附注「会计估计变更」)。
  - 变更**恰好使当期扭亏/达标**(保壳、达业绩承诺、避 ST)。
  - **频繁更换审计机构 / 会计政策**(见 §1.4)。
- **反查红旗**:检测附注「会计估计/政策变更」+ 变更方向对利润的影响符号(利好则警惕);变更年份与「扭亏/保壳/对赌到期」重合;审计机构近 N 年更换次数与档位下降。

## 类8:非经常性损益 / 减值·商誉操纵(粉饰利润质量)
- **表现**:靠政府补助/资产处置/公允价值变动/投资收益等一次性项目撑利润;或反向——「财务大洗澡」一次性巨额计提商誉/资产减值,为来年轻装。
- **可观测信号**:
  - **归母净利大增但扣非净利下滑/为负**(靠一次性项目)。
  - **非经常性损益占净利比过高**。
  - **商誉/净资产畸高**(并购后遗症),或当期**大额商誉/资产减值**。
  - 减值计提「择时」:业绩差的年份一次性巨额计提(洗大澡)。
- **反查红旗**:`扣非净利 / 归母净利 < 0.6`;非经常损益/净利 > 阈值;商誉/净资产 > 30%;当期减值损失/净利 > 阈值;减值年份与业绩低谷重合。

### 八大类 → 与 §方案 §1.3 数值红旗的映射(便于复用)

| 造假类 | 已在方案 §1.3 的对应数值红旗 |
|---|---|
| 类1 虚增收入 | 增收不增利、应收/存货激增、CFO<净利、毛利率异常 |
| 类2 虚减成本 | 毛利率异常、(研发资本化—新增) |
| 类3 存货高估 | 应收/存货激增、(在建工程挂账—新增) |
| 类4 表外负债 | 大存大贷、有息负债/短债覆盖不足 |
| 类5 现金流操纵 | CFO<净利、大存大贷、(货币资金利息收入异常—新增) |
| 类6 关联交易 | (关联交易占比、其他应收款—需附注/文本,新增) |
| 类7 政策变更 | (变更审计/会计政策—文本红旗,方案 §1.3-11) |
| 类8 非经常/减值 | 非经常损益撑利润、商誉高企/减值、扣非为负 |

> 标注「新增」的信号是当前方案 §1.3 未覆盖、建议补入规则引擎的指标(研发资本化率、在建工程转固、货币资金隐含利率、关联交易占比、其他应收款占比)。

# 五、给财报管线的落地建议

## 5.1 闸门1「审计机构过滤」怎么做
1. **数据源**:先核实 akshare 有无 F10 类「会计师事务所」字段;无则从巨潮年报「审计报告」段定向抽两个字段(审计机构名、审计意见类型),与 Q4 正文源合并做。
2. **硬门槛(布尔)**:审计机构名 **规范化后**比对**证监会最新备案名录(105 家口径)**。不在名录 → `audit_gate = FAIL`,标红旗「审计机构无证券服务备案资格」,**不再深查**。名录做成**外部可刷新的单一真源**(定期从证监会/中注协抓取),不硬编码。
3. **分档软信号**:命中名录后,用中注协综合评价名次给档位(top10/top40/其余/榜外),写入 record。
4. **更换红旗**:记录历年审计机构+档位,检测「频繁更换」「换向尾部」→ 高严重度红旗(§1.4)。
5. **降级**:审计机构字段暂不可得时,闸门1 **跳过不拦截**(记 `provenance.audit=false`),避免误杀。

## 5.2 深度红旗反查清单怎么做
1. 把 §4 八大类做成**规则引擎的 8 个红旗族**,每族挂 1~N 个可量化指标 + 占位阈值(阈值集中在一处配置,待提供者标定,复用「待策略端标定参数清单」流程)。
2. **多期 + 同行业**:每个指标按方案 §0.5 D 的原则——**前 3-4 年 + 今年**多期趋势,且**同行业相对**(个股独异才是红旗,行业普遍则大概率合理)。这要求红旗判定不用绝对阈值,而用「相对同业分位 / 相对自身历史 z-score」。
3. **文本类红旗(类6/7 及部分类5)** 需附注/MD&A 文本,归入方案 §2.1 B 层 LLM 抽取(schema_A 的「文本红旗」字段),与数值红旗在 C 层合并。
4. **输出**:每类给「命中/未命中 + 严重度 + 依据值」,汇总成「红旗强度 + 合理怀疑画像」(投资侧规避信号,**非审计定罪**,符合 §0.5 B 定位)。
5. **图表化**(§0.5 D-4):关键指标(存货周转、应收周转、毛利率、CFO/净利、商誉占比等)出多期趋势图 + 同业对比,供 Agent/详情页判断波动是否正常。

## 5.3 与现有方案的衔接
- 闸门1/2 放在管线**最前**(§0.5 管线图),命中即弃,最省 token。
- 审计机构/意见两个字段 + 名录比对,建议做成 `tools/financial_report/` 下的一个**独立轻量模块**(不依赖三大表数值),先于结构化采集跑。
- 名录、中注协排名做成**可刷新的参考数据**(如 `data/reference/` 下的 json + 定期更新脚本),代码只读不硬编码。
