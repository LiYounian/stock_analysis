# 数据源 · 通达信盘口微观结构(逐笔成交)

> 新增日期：2026-08（借鉴 a-stock-data 的 mootdx 源）
> 采集器：`tools/collectors/tdx_l2.py`　落盘 kind=`tick`(parquet)　入口：`python -m tools.run ticks`
> 一句话：补上项目此前完全缺失的**盘口微观结构**——逐笔成交（主动买卖方向），走通达信 TCP。

---

## 1. 为什么做 / 为什么是"盘后逐笔"

项目原本是**盘后 EOD 日线**体系，没有任何 tick/盘口数据。a-stock-data 用 `mootdx`(通达信 TCP 7709)
能拿逐笔/五档——**免费源里唯一的通道**。

**五档 vs 逐笔的关键差异**（决定了先做逐笔）：

| | 五档盘口 | 逐笔成交 |
|---|---|---|
| 性质 | 纯实时快照 | 当日累积 |
| 能否历史回补 | ❌ 不能 | ✅ 收盘后可整段拉全 |
| 适配采集模式 | 盘中定时快照 | **盘后归档(契合现有 EOD)** |

所以先做**盘后逐笔归档**：收盘后一次拉当日逐笔，契合现有 `run` 流水线，无需常开机器、数据可回测。
五档留待后续盘中定时任务（挂 `tools/scheduler.py`，仿 SEPA 监控的 CronTrigger）。

## 2. 数据源

`mootdx`（通达信 TCP，`requirements.txt` 已加），**惰性导入**（不装也能 import 本模块）：
- `Quotes.factory(market="std").transaction(symbol, start, offset)` — 当日分笔
- `.transactions(symbol, start, offset, date=YYYYMMDD)` — 历史某日分笔
- **分页**拉取（每页 `_PAGE=2000`）累积到全天，单票上限 `_MAX_TICKS=60000`（活跃票兜底）。
- 列名按 mootdx 各版本**防御式归一**（`vol`/`volume`、`buyorsell`/`nBuyOrSell` 都容忍）。

## 3. 落盘字段 + 派生摘要

**tick（parquet，逐笔明细）**：`[time, price, volume, num, direction]`，direction ∈ {买/卖/中性}（由 buyorsell 映射）。

meta 旁记 `summarize` 微观结构摘要（供盘口异动/打板策略消费）：

| 字段 | 含义 |
|---|---|
| `总笔数` / `总成交量` | 当日逐笔规模 |
| `主买占比` / `主卖占比` | 主动买/卖成交量占比 → 盘口买压 |
| `净主动买量` | 主买量 − 主卖量 |
| `大单笔数` | 单笔量 ≥ 当日单笔量 95 分位的笔数（相对口径，免绝对手数误判）|

## 4. 用法

```bash
python -m tools.run ticks              # 自选开发子集(默认)
python -m tools.run ticks --all        # 全票池(逐笔量大,慎用)
python -m tools.run ticks --date 20260827   # 回补历史某日(落该日分区)
```

读取：
```python
from tools.collectors import tdx_l2
df = tdx_l2.load_ticks("600519")               # 最新分区逐笔明细(大 parquet)
summ = tdx_l2.load_summary("600519")           # 轻量摘要(小 json,不载 parquet)
summ = tdx_l2.load_summary("600519", "2026-08-28")  # 按 as_of date-pin(≤该日,无未来函数)
```

## 前端展示

逐笔摘要已接入个股详情页(`serialize.build_record` → `record["tick"]` → `web/templates/stock.html`):

- **落盘**:`fetch_ticks` 同时写 `tick`(parquet 明细)+ `tick_summary`(小 json 摘要)。
- **装配**:`build_record` 用 `tdx_l2.load_summary(code, date=as_of)` 按 as_of **date-pin**(≤as_of 最近分区,
  绝不取未来分区;与 consensus/holder 同款 `store.get_raw_resolved` 语义)装进 `record["tick"]`。
- **展示**:个股页「盘口微观结构」卡片(主买/主卖占比、净主动买量、大单笔数、总笔数/量);
  **缺 tick 数据 → 卡片自动不显示**(`{% if r.tick and r.tick.总笔数 %}` 守卫)。

看效果:
```bash
python -m tools.run ticks --date 20260828   # 先归档某交易日逐笔
python -m tools.run all                       # (或 serialize)组装 record;tick 块 date-pin 回该日
uvicorn web.app:app --port 8801               # 个股页即见「盘口微观结构」卡片
```

## 5. 降级 / 注意

- **港股**：mootdx std 不支持 → 跳过。
- **失败降级**：未装 mootdx / 通达信服务器波动 / 非交易日空数据 → 单票 log 跳过，不中断整批。
- **数据量**：逐笔极大，**只对自选池/达标池跑，勿全A**。
- **服务器**：mootdx 走服务器池，盘中/波动时可能失败，可重试或切服务器。
