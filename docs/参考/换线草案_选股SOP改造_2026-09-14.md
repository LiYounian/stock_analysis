## §A canonical 子句 —— 超跌反抽触发闸门(①,H2 已验证)

> 供 selection SKILL ⑧ 与 noon 草案逐字复用。

```
超跌反抽候选(连续普跌重挫日底部选出、以超跌/超卖为主要理由的批次)的**首入场闸门 =
放量收阳(量比>1.5 且 收阳 close>open)**——回测 H2 坐实(24/24 零反例):它比"放量站上 MA5"
更早捕捉反抽首段、精确率≥MA5、α 更高。"站上前一日高/开盘价"作**更早辅助确认**(辅助档)。
**MA5 降为趋势确认/加仓档,不作首入场闸门**(MA5 首入场在超跌反抽里 α₅ 显著为负=买在首波顶)。
诚实边界:放量收阳精确率最优仍 <0.5(α 口径,正期望非高命中);"主买翻正"需 tick/fundflow、
项目无该源→不作硬闸、可人工旁证。见经验 #31(已验证)。
```

## §B canonical 子句 —— capitulation β 例外(②,H1-β 已验证;严守不越界)

> 供 selection SKILL 市场环境步 与 noon 草案逐字复用。

```
市场环境判断读 live capitulation 信号 `data/signals/capitulation/<今天>.json`:
若 `capitulation=true`(判据=破位广度+近端崩跌双极端,trailing-500 分位因果自标定),则**放松
"普跌日整体降级"、给市场 β 敞口**(经验 #10⑤,H1-β 回测 24/24)。**但绝不据此对个股加"超跌
选股 α 分"——H1-α 证不了,反抽是 β/市场级不是超跌属性的选股 α**(经验 #10 边界)。非 capitulation
的普通普跌日**维持整体降级**(#10③)。⚠️ 该信号是**收盘确定性信号,只用于次日(t+1)选股/环境判断**;
盘中场景只读**上一收盘**的信号作静态 β 背景,**绝不用盘中 breadth 重算门控**(经验 #17)。
```
