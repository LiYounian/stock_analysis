# 模型卡:Claude Opus 4.8

> 一句话:**会话驱动**的深度分析 / 复盘 / 多窗调度层,即席任务,**非程序化**、依赖 Claude Code。核实日 2026-09-13。

## 1. 标识
- **模型名 / ID**:Claude Opus 4.8(`claude-opus-4-8`)
- **kind**:LLM(**会话驱动、非程序化**)
- **用途**:深度选股分析 / 复盘 / 多窗调度编排;补选股、周末重选、本轮 chip/子窗口编排等即席任务
- **通道**:Claude Code(窗口),非无头 API
- **接线状态**:**会话驱动、非程序化**——依赖窗口活着 + Claude Code 模型,不进 launchd 定时管线

## 2. 数据源
- 输入 = 会话上下文 + 项目文件 + 工具产出(量化管线结果 / market_forecast.json / 各类 docs)。
- 不写死数据管道:即席按任务读取,产出为文档 / 决策 / 编排指令。

## 3. 输入特征(输入 / 输出)
- 输入:自然语言任务简报 + 工具调用返回;输出:分析文档、复盘、多窗任务派发与集成。
- 无固定 schema(会话驱动)。

## 4. 训练 / 加工方式
- **不微调**;prompt / 上下文工程 + 工具编排。

## 5. 关键参数现值(带出处)
- 无代码写死参数(会话驱动,不在 `settings.py` / `strategy.py` 中)。模型选择在 Claude Code 侧。

## 6. 效力 & 局限
