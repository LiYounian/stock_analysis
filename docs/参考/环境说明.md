# 环境说明

本项目用**独立 conda 环境** `stock_analysis`(Python 3.11)。所有运行/测试/部署都在此环境内。

## 环境信息

- 环境名:`stock_analysis`
- Python:3.11
- 路径:`~/.conda/envs/stock_analysis`
- 依赖:见 `requirements.txt`(范围)/ `requirements-lock.txt`(精确锁定)

## 常用命令

conda 的 shell 包装在非交互 shell 里可能失效,**直接用环境内的绝对路径**最稳:

```bash
PY=~/.conda/envs/stock_analysis/bin/python
PIP=~/.conda/envs/stock_analysis/bin/pip

# 跑测试
$PY -m pytest tests/ -q

# 跑主流程
$PY -m tools.run all

# 起 Web(P3 落地后)
$PY -m uvicorn web.app:app --reload --port 8000
```

交互式终端里可正常 `conda activate stock_analysis`。

## 重建环境

```bash
conda create -y -n stock_analysis python=3.11
~/.conda/envs/stock_analysis/bin/pip install -r requirements.txt \
  -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## macOS / Apple Silicon(M 系列)安装说明

> 背景:有合作者反馈 `baostock` 在 Apple Silicon Mac 上装不上,并归因于"老 C 扩展库无 arm64 预编译包"。**这个归因不准确**——实测 `baostock`(0.9.3)包内**零 C 扩展**(无 `.so/.pyd/.dylib`),是纯 Python 的 socket 客户端,唯一依赖 `pandas>=0.18`。装不上的真实原因通常是**原生 arm64 Python 下某个传递依赖(老版本 pandas/numpy)缺 arm64 wheel、退化成源码编译**而失败,锅不在 baostock 本身。

**本项目参考环境就是 x86_64 conda 跑在 Rosetta 2 下**(base 与 `stock_analysis` 环境的解释器均为 x86_64),所以 baostock/akshare 一律能拉到现成 wheel、从不缺包。两条可行路径:

**路径 A(推荐,与参考环境一致):建 x86_64 环境走 Rosetta**

```bash
# 在 Apple Silicon 上强制建 x86_64 环境(拉 osx-64 wheel,规避原生 arm64 缺包)
CONDA_SUBDIR=osx-64 conda create -y -n stock_analysis python=3.11
conda activate stock_analysis
conda config --env --set subdir osx-64          # 锁定该环境后续都装 x86_64 包
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**路径 B(原生 arm64 也可行):先备好 arm64 的 pandas,再装 baostock**

```bash
# baostock 是纯 Python,只要 pandas 先就位(现代版本有 arm64 wheel)即可成功
pip install --upgrade pip
pip install "pandas>=2.0" "numpy>=1.24"          # 这些才有 arm64 预编译 wheel
pip install baostock                             # 纯 Python,pandas 就位后秒装
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> 校验:`python -c "import baostock, akshare; print('ok')"`。若仍失败,请贴 `pip install baostock` 的完整报错(卡在哪个包、哪一步),对症一条命令通常即可解决,无需替换数据源。
> baostock 在本项目负责 K 线主档全量历史、证监会行业成分(membership)、benchmark 取数(6 个采集文件依赖);akshare 负责财报三大表/资金流/公告等——两者分工并存,不是二选一。

## 数据源与反爬要点

- 行情:腾讯/新浪(东财 `stock_zh_a_hist` 被 TLS 指纹墙)。
- 基本面:同花顺 `stock_financial_abstract` + 百度估值。
- 公告:巨潮 cninfo。
- **资金流 / 东财生态**:用 `curl_cffi` 伪装 chrome 指纹直连东财接口,绕过 JA3 反爬(见问题台账 B1/R4)。

## 部署(规划)

本地开发:`uvicorn --reload`。服务器部署:后续用 `uvicorn`(或 gunicorn+uvicorn worker)+ 反向代理,定时任务跑 `tools.run all` 刷新数据。详见 P3 计划。
