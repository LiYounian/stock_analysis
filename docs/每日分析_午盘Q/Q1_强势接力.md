# Q1 · 强势接力（追动量，赌尾盘不炸板）

> 类型：**信号型 · 看多 · 隔夜**。前置：[00_大盘闸门](00_大盘闸门.md)判定为「强势」或「震荡」。
> 逻辑：14:30 时段涨幅温和、量能延续、板块红盘领涨的强势股，14:50 复核仍稳，尾盘接力，赌次日情绪高开。

## 是什么

追**当日强势但没到极端**的股票——涨幅太低说明没启动，涨幅太高（尤其涨停）T+1 出货难。取"温和强势带"3%~6% 涨幅的票，配合量能/板块/K 线三重确认，尾盘买入。

**核心假设**：A 股散户为主，情绪有隔夜延续性；14:50 后仍强的股票，次日集合竞价大概率高开。历史研究里"次日高开率"这一维度在温和涨幅带最高（涨停组因为炸板/开板反而高开率低）。

## 信号（14:30 首判 + 14:50 复核，均只用当日 9:30-asof 数据 + T-1 日线）

**双点判定机制**：14:30 首判信号命中入候选池；14:50 复核时同一票仍命中（且大盘闸门未翻转）才买入。任一时点漏判即淘汰。

```
IntradayReturn(t, asof)  = P_asof / P_open - 1
                          ∈ [0.03, 0.06]                    # 温和强势带（asof ∈ {14:30, 14:50}）
AmPmRatio(t, asof)        = Vol_13:00_asof / Vol_10:00_11:00
                          ≥ 0.8                             # 下午量能不衰减
DistanceToDayHigh(t, asof)= 1 - P_asof / High_intraday_asof
                          ≤ 0.015                           # 距日内高点<1.5%
MA5, MA10, MA20 @ T-1     : P_open(t) > MA5(t-1) > MA10(t-1)  # 短均线多头站上
SectorRank @ asof         : 所属申万一级板块涨幅 前5           # 板块领涨
NotLimitUp                : P_asof < 涨停价 × 0.985            # 排除接近涨停（T+1 难卖）
NotSTNotNew               : 非 ST/*ST/退，上市 ≥60 交易日
LiquidityFilter           : Vol_9:30_asof × VWAP ≥ 5000万元     # 流动性下限

SELECT = 上述全部满足
RANK   = 综合分 = 0.4×IntradayReturn + 0.3×AmPmRatio + 0.2×(1-DistanceToDayHigh) + 0.1×SectorRank
TOP N  = 5
```

## 数据依赖

| 字段 | 用途 | 来源 | 频率 |
|---|---|---|---|
| 分时价 P(9:30..14:50) | 涨幅/量能/距日高 | akshare `stock_intraday_em` | 1min |
| 分时量 V(9:30..14:50) | AmPmRatio | 同上 | 1min |
| MA5/MA10/MA20 T-1 收盘 | 均线过滤 | `data/raw/kline/` | T-1 已就绪 |
| 涨停价 | NotLimitUp | 一般 ×1.1（主板）/×1.2（创板/科创） | 计算 |
| 板块归属 + 板块分时涨幅 | 板块排名 | akshare `stock_board_industry_name_em` + 分时 | 14:30/14:50 |
| 上市日/ST 标记 | 排除 | 中心记录 meta 块 | 静态 |

## 效果假设（未回测，仅推断）

- 期望胜率（次日高开且能以正收益卖出）：55%~62%
- 期望隔夜均值收益：+0.5%~+1.0%（扣 10bp 成本后）
- 最大回撤风险：单日 -5%~-8%（炸板 + 集体低开）
- 适用行情：结构性行情、消息面积极日、周五/月末不适用（隔周风险高）

**实际数值等 M3 回测后回填**。若均值收益扣成本后 ≤0 或最大单日回撤 >-10% → 丢弃。

## 反例（会导致翻车的情况）

1. **抱团核心资产集体跳水**：14:30 温和强势的白马，因为北向尾盘净流出集体砸盘 → G6 闸门 14:50 复核应能识别翻转。
2. **主题炒作末端**：连板高度板前一天，龙头炸板带下所有跟风票 → 需加"所在题材连板数 ≤3" 过滤（后续加）。
3. **周五+假期前**：隔夜风险 = 隔周风险，胜率下降明显 → 加日历闸门"周五及节前最后一日 14:30 起自动停用 Q1"。

## 实现骨架（`tools/strategy/midday_q1_momentum/`）

```
midday_q1_momentum/
├── __init__.py
├── signals.py        # 上述 6 个信号函数
├── screener.py       # @strategy 注册 "Q1_强势接力"
└── tests/
    ├── test_signals_no_lookahead.py    # 断言只读 asof（14:30 或 14:50）前数据
    ├── test_limit_up_excluded.py       # 断言涨停票被排除
    └── test_top5_ordering.py           # 断言 rank 稳定
```

入口：
- 首判：`python -m tools.pipeline.screen_midday_q1 --as-of 14:30 --top 5`
- 复核：`python -m tools.pipeline.screen_midday_q1 --as-of 14:50 --top 5 --confirm-from data/analysis/midday_q/q1_{date}_1430.json`

`--confirm-from` 只在首判入选票里做复核，命中即最终下单。
