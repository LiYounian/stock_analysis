# 数据源实测（2026-09-07）

> 定位：**采集器动手前的可用性实测记录**。M1 采集器实现依赖本文档结论。所有测试脚本已用完删除，结论落文档。

## 一、测试目的

原方案假设走 akshare 分时接口（README 已拍板）。M1 采集器动手前先跑连通性实测，避免踩项目已知的墙（问题台账 B2 · 东财 TLS 指纹墙）。

## 二、实测结果（本机 macOS，普通家用宽带）

### 通道 1｜akshare 分时接口 — ❌ 全挂

| 接口 | 结果 | 备注 |
|---|:-:|---|
| `stock_zh_a_hist_min_em`（个股/指数 1min） | ❌ RemoteDisconnected | akshare 走东财 push2，普通 requests 被 TLS 指纹墙 |
| `stock_individual_fund_flow`（个股分时资金流） | ❌ | 同源被墙 |
| `stock_individual_fund_flow_rank`（全 A 排名） | ❌ | 同源被墙 |
| `stock_intraday_em`（分笔） | ❌ | 同源被墙 |
| `stock_hsgt_hist_em`（北向历史） | ✅ 连通 | **但 2024-08-16 起停披露、近端恒 NaN，不作生产因子**（沿用 `market_fundflow.py` 结论） |

### 通道 2｜curl_cffi 直连东财 push2 — ⚠️ 按业务线分墙

复用项目 `fundflow.py` 已验证的 `impersonate="chrome"` 反墙套路。

| 端点 | 结果 | 备注 |
|---|:-:|---|
| `push2his/stock/fflow/kline/get`（**分时资金流**） | ✅ **通** | Q3 主力/大单/超大单核心数据源 |
| `push2his/stock/fflow/daykline/get`（日线资金流） | ✅ 通（项目 `fundflow.py` 在用） | |
| `push2his/stock/kline/get`（K 线：分时/日线价格） | ❌ curl(56) | **价格家族全被墙** |
| `push2his/stock/trends2/get`（分时 tick） | ❌ curl(56) | |
| `push2/clist/get`（个股列表/排名） | ❌ curl(56) | 全 A 快照/排名家族被墙 |
| `push2/stock/get`（单票快照） | ❌ curl(56) | |
| 换 `impersonate=chrome110/safari15_5` | ❌ | 非版本问题，是端点级封锁 |

**关键洞见**：东财这一波按 endpoint 家族分墙——**资金流通、价格/列表/快照全墙**。

### 通道 3｜mootdx（通达信 TCP 7709） — ❌ 本机全挂

15 台服务器实测，两种失败模式：

- **能建 TCP 会话（4/15）**：`TdxFunctionCallError: calling function error` —— 协议解析炸（`struct.unpack requires 4 bytes`），可能是本机 IP 被识别为异常/境外，服务器返回不完整报文
- **建不上会话（11/15）**：`TdxConnectionError: connection timeout error` —— 8s TCP 握手都完不成，运营商 QoS 或 IP 黑洞

**结论**：本机无法用 mootdx 拿分钟 K 或历史逐笔。（`tdx_l2.py` 保留在仓，未来换网络环境可能可用；本次午盘 Q 不依赖）

## 四、方案 A（用户拍板 2026-09-07）

**核心决策**：生产日内先跑起来，回测走"未来采样"路径。

### 生产日内（M1-M2 立即做）

1. 复用 `gtimg_quote.py` + `intraday_snapshot.py`，新增 **14:30 / 14:50 两个 slot**
2. 新建 `fundflow_intraday.py` 采集器 —— curl_cffi 直连东财 `fflow/kline`，只对候选池拉（≤50 只）
3. 大盘广度复用现有 `market_breadth` 的 `cross_section_stats`（单一真源，不重造）

### 回测（M3 阶段）

**不做"历史分时回填"**（数据不可得）。改用"未来采样"：

- 从 M1 上线之日起，**每天 14:30 / 14:50 落快照** → `data/intraday/<date>/T1430.json` + `T1450.json`
- 累积到 **60 交易日** 后（约 3 个月），再做完整分时回测
- 中间阶段用**降级回测**：仅用 T-1 收盘 + T 日开高低收 + 日线资金流，跑粗回测辨方向
- 若"未来采样"期间发现新的历史分时通道（付费/换网/新库），随时补历史

### 里程碑修订

- M3 拆成 **M3.a（降级回测，日线口径）** + **M3.b（分时回测，未来 60 日采样后）**
- M4 上线判定：M3.a 就足以做 alpha 方向判断；M3.b 再做精调
