## 四、口径与已知限制(诚实标注)

**相比 M3.a 修好的**:

1. **真 14:30/14:50 价** —— 不再用日线收盘代理。(09-17 实测该代理偏差其实很小:信号侧均值 +0.033pp、|偏差|>1pp 仅 6%,故 M3.a 的方向性结论并非降级造成的假象。)
2. **成交可行性** —— 买入日涨停一字剔除;T+1 卖出触及一字/跌停按评估口径 §八.2 **强制顺延持有并累计双边成本**(M3.a 直接按收盘价成交,Q3 的正收益曾全靠 3 笔一字板撑着)。
3. **组合口径回撤** —— 修 M3.a 逐笔累加的错口径。

**仍存在的限制**:

1. **Q3 无法回测** —— 东财 `fflow/kline` 只返当天分时资金流(`lmt` 给多大都拿不到历史),Q3 核心信号缺历史。仍须靠定时任务未来采样。
2. **bar 是抽样时刻,非全量** —— 只存 7 个时刻。故 `DistanceToDayHigh`/`IntradayLow` 用的是"采样点极值"而非真实日内极值 → **分母偏小,条件偏松**,真实入选会比这里更严。
3. **买卖价用 14:50 bar 收盘代替 VWAP** —— 方案设计是14:50-15:00 / 次日14:30-14:50 的 VWAP;5min bar 拿不到 tick 级 VWAP。
4. **一字板判据基于抽样点** —— `high==low` 只能证明这几个时刻无波动,比全量 bar 宽松;倾向**多判几笔不可成交**(保守,不高估收益)。
5. **闸门用焦点池广度代理全A** —— 同 M3.a,非真全A广度。

## 五、结论与解读(2026-09-18 补写)

### Q1 强势接力 → 🔴 **建议丢弃**

四项全败,没有可挽救的迹象:

| 指标 | 值 | 说明 |
|---|---|---|
| 均值/笔 | **-0.54%** | 扣成本后净亏 |
| 中位/笔 | -0.63% | **比均值还低** → 亏损是普遍的,不是被极端值拖累 |
| 日均 α | **-0.410%** | **不如等权持有整个票池** |
| 最大回撤 | -22.2% | 远超 -10% 红线 |

M3.a 里 Q1 曾是 **+0.86%**,真分时口径下变成 **-0.54%** —— 这是本轮最重要的
发现:它印证了 M3.a"用收盘价代替 14:30 现价"给了策略**看到收盘再决定**的
先知优势,而 Q1 恰恰对"何时看到价格"极度敏感。

### Q2 弱转强反抽 → 🔴 红灯,但**不该直接丢,值得改造**

本轮唯一有信号的策略,但**现在这个形态不能上生产**。

**亮点**:均值 +0.69%、胜率 52.5%、日均 α **+0.737%**(真跑赢基准)、
夏普 2.48、261 笔样本够。震荡日更好(+0.96%,胜率 56.9%)。

**致命伤**(三条,任一条都不该放行):

1. **回撤 -12.8% 触红线** —— 评估口径 §五「≤-10% 直接淘汰」是硬杠杠。
2. **统计上不显著** —— bootstrap 95% CI = **[-0.08%, +1.43%]**,下界跨 0。
   即"这 261 笔的正收益纯属运气"**无法被排除**。
3. **均值 +0.69% 但中位数仅 +0.22%** —— 偏度大、靠少数大赢家撑着,
   典型赔率型而非胜率型。

**建议方向**(都要再验证,别直接拍参数):
- **先做止损实验** —— 回撤 -12.8% 与"无止损"设计直接相关;
  评估口径 §八.3 本就预留了"观察后再决定是否加止损",现在有数据了。
- **再看闸门收窄** —— 弱势日 (+0.36%) 明显弱于震荡日 (+0.96%),
  只在震荡日跑可能同时提均值、降回撤。
- **扩样本** —— 167 个交易日偏短,跨市场环境的稳健性未知。

### Q3 资金流前瞻 → ⏸ **本轮无法评价**

东财 `fflow/kline` 只返当天分时资金流,核心信号缺历史 → 没有回测。
须靠定时任务每日累积(8 条 plist 已建并登记 SSOT,**待人工 launchctl 装载**)。

### 与 M3.a 的对比

| | M3.a(日线代理) | M3.b(真分时) |
|---|---|---|
| Q1 均值 | +0.86% | **-0.54%** ← 翻转 |
| Q2 均值 | +0.60% | +0.69% |
| Q1 回撤 | -49%(逐笔累加·口径错) | -22.2%(组合口径) |
| Q2 回撤 | -62%(同上) | -12.8% |

- **Q1 翻转**:对先知优势极敏感,日线代理足以把亏损策略粉饰成盈利。
- **Q2 稳健**:两版口径下均值都为正且接近 → 信号不依赖先知优势。
- 回撤数字变小主要是**口径修正**(M3.a 把逐笔收益累加当组合回撤),
  **不是策略变好了**。
