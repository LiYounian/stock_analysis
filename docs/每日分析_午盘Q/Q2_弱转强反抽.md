# Q2 · 弱转强反抽（超跌回血，赌次日惯性冲高）

> 类型：**信号型 · 看多 · 隔夜 · 逆向**。前置：[00_大盘闸门](00_大盘闸门.md)判定为「弱势」「震荡」或「崩盘后修复日」。
> 逻辑：早盘急跌、午后止跌企稳、14:30 已放量翻红或缩量止跌、14:50 复核仍稳，赌次日惯性冲高。

## 是什么

**挖坑反抽**型。早盘超跌是"筹码换手"，午后有资金介入是"接力信号"。核心是**日内 V 型反转**——低点在上午、14:30 已明显反弹到接近平盘或翻红。

**核心假设**：A 股情绪化下跌容易过度，午后接力资金往往看到"止跌+微反弹"信号入场，次日集合竞价通常延续这个反弹。历史统计里，跌破 3% 后当日修复到 -1% 以内的股票，次日高开率显著高于平均。

## 信号（14:30 首判 + 14:50 复核）

**双点判定机制**：14:30 首判命中入候选；14:50 复核同一票仍满足 `CurrentReturn`、`Rebound`、`AfternoonVolExpand` 三条（且大盘闸门未翻转）才买入。此双点对 Q2 尤其关键——防"14:30 反弹好看，14:50 又跳水"这个 Q2 最典型的翻车场景。

```
asof ∈ {14:30, 14:50}
IntradayLow(t)            = min(P_9:30..P_asof) / P_open - 1
                          ≤ -0.03                              # 早盘急跌 ≥3%
Rebound(t, asof)          = P_asof / IntradayLowPrice(t) - 1
                          ≥ 0.02                                # 从低点反弹≥2%
CurrentReturn(t, asof)    = P_asof / P_open - 1
                          ∈ [-0.01, 0.02]                       # 已修复到平盘附近
LowTimeInMorning          : argmin(P) 时点 ≤ 11:30              # 低点在上午（早跌）
AfternoonVolExpand        = Vol_13:00_asof / Vol_11:00_11:30
                          ≥ 1.2                                 # 下午放量（有资金介入）
NotDownLimit              : P_asof > 跌停价 × 1.015               # 排除跌停附近
NotSTNotNew               : 非 ST/*ST/退，上市 ≥60 交易日
LiquidityFilter           : Vol_9:30_asof × VWAP ≥ 5000万元       # 流动性下限
NotLongTermDowntrend      : P_open(t) > MA60(t-1) × 0.9           # 排除长期熊股（避免接飞刀）

SELECT = 全部满足
RANK   = 0.4×Rebound + 0.3×AfternoonVolExpand + 0.2×|IntradayLow| + 0.1×(-CurrentReturn)
TOP N  = 5
```

**RANK 里 `-CurrentReturn` 权重是刻意的**——已经翻红太多的票反弹空间小，越贴近平盘反抽空间越大。

## 数据依赖

| 字段 | 用途 | 来源 | 频率 |
|---|---|---|---|
| 分时价 P(9:30..14:50) | IntradayLow / Rebound / CurrentReturn | akshare `stock_intraday_em` | 1min |
| 分时量 V(9:30..14:50) | AfternoonVolExpand | 同上 | 1min |
| MA60 T-1 | 长期趋势过滤 | `data/raw/kline/` | T-1 已就绪 |
| 跌停价 | NotDownLimit | 一般 ×0.9（主板）/×0.8（创板/科创） | 计算 |
| 上市日/ST | 排除 | 中心记录 meta | 静态 |

## 效果假设（未回测）

- 期望胜率：50%~55%（低于 Q1，因为逆向策略胜率天然低）
- 期望隔夜均值收益：+0.8%~+1.5%（**赔率高**，回补空间大）
- 最大回撤风险：单日 -6%~-10%（"抄底抄在半山腰"典型场景）
- 适用行情：情绪修复日、恐慌盘后一天；不适合流动性危机日

**Q2 是三条路里赔率最高、胜率最低的一条**。回测阶段重点看夏普比率而非胜率。

## 反例

1. **假止跌真跳水**：14:30 反弹好看、14:50 再次破位——由双点判定机制在 14:50 复核环节剔除。
2. **退市/ST 反抽**：这类票 T+1 有 5% 涨跌幅限制且成交极差 → 已在 NotSTNotNew 过滤
3. **业绩雷跌停**：跌停开板反抽陷阱——加"当日无重大公告"过滤（读中心记录 `events` 块）
4. **单一板块崩塌**：整个板块跌 5%+ 的日子里的反抽多为诱多——加"所属板块日内涨幅 > -3%" 过滤
