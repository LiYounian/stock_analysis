## 三、信号函数 · midday_q_signals.py

按方案文档 Q1/Q2/Q3 §信号 列出的每条,做成纯函数,**输入一个快照 dict + T-1 上下文**,输出 bool 或 float。

```python
# 通用 helpers
def intraday_return(quote: dict) -> float | None
    """(price / open - 1),现价/开盘缺失 → None。"""

def distance_to_day_high(quote: dict) -> float | None
    """1 - price / high。"""

def rebound_from_low(quote: dict) -> float | None
    """price / low - 1(V 型反抽幅度)。"""

def not_limit_up(quote: dict, board: str) -> bool
    """price < 涨停价 × 0.985。涨停价按板块规则(主板×1.1,创/科×1.2,ST/*ST×1.05)。"""

def not_down_limit(quote: dict, board: str) -> bool
    """price > 跌停价 × 1.015。"""

def liquidity_ok(quote: dict, min_amount_wan: float = 5000) -> bool
    """amount_wan >= min_amount_wan(默认 5000 万成交额下限)。"""

def not_st_not_new(record_meta: dict, listing_days: int = 60) -> bool
    """meta.is_st / meta.days_since_listing 综合判定。"""

# ── Q1 强势接力(am/pm 量差需要两个快照) ──
def am_pm_vol_ratio(pm_quote: dict, am_quote: dict) -> float | None
    """(pm.volume - am.volume) 差分 / am.volume。要求 pm 是 T1400/T1430,am 是 T1030。
    实际返回 = (14:30 累计量 - 10:30 累计量) / (10:30 累计量的下午基准估计) ≈ 下午量/上午量。
    简化实现:直接 pm.volume / am.volume(累计量之比,值越大表示下午来量越多)。
    """

def ma_stacked(t1_close: pd.Series, current_price: float) -> bool
    """MA5 > MA10 > MA20 且当前价站在 MA5 之上(短均线多头)。"""

def sector_rank_top(code: str, sector_ranks: dict[str, int], top_n: int = 5) -> bool
    """所属申万一级板块日内涨幅排名前 top_n。sector_ranks 由 pipeline 层预计算。"""

# ── Q2 弱转强反抽 ──
def intraday_low_pct(quote: dict) -> float | None
    """(low / open - 1),负值代表跌破开盘幅度。"""

def current_return_in_range(quote: dict, low: float = -0.01, high: float = 0.02) -> bool
    """(price/open - 1) ∈ [low, high](已修复到平盘附近)。"""

def not_long_term_downtrend(t1_kline: pd.DataFrame, current_open: float, ma_col: str = "MA60") -> bool
    """current_open > MA60 × 0.9(排除长期熊股)。"""

# ── Q3 资金流前瞻(读 M1 fundflow_intraday) ──
def main_net_pm(ffdf: pd.DataFrame, since_hhmm: str = "13:00") -> float | None
    """>= since_hhmm 的所有 5min 主力净流入求和。"""

def large_order_pct(ffdf: pd.DataFrame) -> float | None
    """(大单+超大单) 累计净流入 / 总成交额估计。
    fundflow 只给净流入(不给成交额)→ 用 (大单+超大单)/(全五单总额)近似。"""
```

## 六、简化决策(直接锁定,不再对齐)

- **Q1/Q2 上下午量差**:用 `T1400`(现有 slot)代替"下午累计量"起点,`T1430` 减 `T1400` = 14:00-14:30 半小时增量;若 T1400 缺 → 用 `T1030` 兜底
- **申万板块归属**:M2 阶段用 `board_membership/{code}.json`(项目现有,`analysis.market_forecast.breadth.board_of` 里在用);若无 → 跳过 SectorRank 项(权重转到其他因子)
- **rank_score 权重**:先按方案文档 Q1/Q2/Q3 里的公式(hardcode 在 signals 模块顶部常量),M3.a 回测后再调
- **candidate universe(候选池)**:三策略共用一个初筛全 A → 从 `intraday_snapshot` 里的 `codes` 字典拿所有票 → 过 not_st_not_new + liquidity_ok 得初筛池 → 再各自跑本策略特定信号
- **测试策略**:不 mock 网络(fundflow_intraday 在 M1 有单测),M2 只测**给定假快照 → 预期入选**
