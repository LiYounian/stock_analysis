# Q3 · 资金流前瞻（跟主力，赌次日发酵）

> 类型：**信号型 · 看多 · 隔夜 · 资金面**。前置：[00_大盘闸门](00_大盘闸门.md)不限（只要不是「崩盘」都可跑）。
> 逻辑：14:30 时资金流/大单/北向明显偏正、14:50 复核仍稳，前瞻埋伏"当日或次日可能登龙虎榜/次日主力延续入场"的票。

## 是什么

不看 K 线形态、只看**钱在往哪流**。A 股游资/机构行为惯性较强，午后主力净流入排前的票，尾盘往往被抬价、次日惯性延续。这条路对**数据实时性**要求最高。

**核心假设**：分时主力净流入（大单+特大单）在午后仍持续为正的股票，反映主力当日已在建仓、次日大概率继续护盘/推升。北向资金午后净买入是外资信号，独立于内资，双确认时胜率显著提升。

## 信号（14:30 首判 + 14:50 复核）

**双点判定机制**：14:30 首判入候选；14:50 复核时 `MainNetInflow_PM`（口径改为 13:00-14:50）、`LargeOrderPct` 仍达标（且大盘闸门未翻转）才买入。资金流反转是 Q3 的主要杀手，双点尤其对识别"日内 T+0 出货"有效。

```
asof ∈ {14:30, 14:50}
MainNetInflow_AM          = 上午 9:30-11:30 主力净流入(万元)
MainNetInflow_PM          = 下午 13:00-asof 主力净流入(万元)
                          ≥ 0                                    # 下午净流入不为负
MainNetInflow_Ratio       = MainNetInflow_PM / max(|MainNetInflow_AM|, 1000万)
                          ≥ 0.5                                  # 下午/上午 净流入不衰减
LargeOrderPct(t, asof)    = 大单+特大单 / 总成交额
                          ≥ 0.30                                 # 大单占比≥30%
NorthboundNet_intraday    = 沪深港通该股当日净买入（若为陆股通标的）
                          ≥ 0                                    # 北向不流出（非陆股通标的跳过此条）
IntradayReturn(t, asof)   ∈ [-0.02, 0.05]                          # 温和区间（避免涨停/暴跌）
NotSTNotNew               : 非 ST/*ST/退，上市 ≥60 交易日
LiquidityFilter           : Vol × VWAP ≥ 8000万元                  # 大单策略要求流动性更高
LHBThresholdProxy         : 振幅≥5% ∨ 总成交额 板块前10%             # 有登龙虎榜潜力

SELECT = 全部满足
RANK   = 0.4×MainNetInflow_PM(标准化) + 0.3×LargeOrderPct
       + 0.2×NorthboundNet(标准化) + 0.1×LHBThresholdProxy(0/1)
TOP N  = 5
```

**标准化说明**：分市值分档做百分位（防大盘股淹没小盘），或用 z-score。

## 数据依赖

| 字段 | 用途 | 来源 | 频率 |
|---|---|---|---|
| 分时主力净流入（大单+特大单） | MainNetInflow_AM/PM | akshare `stock_individual_fund_flow_rank` 或 `stock_fund_flow_individual` | 1min~5min |
| 大单/特大单占比 | LargeOrderPct | 同上或推算 | 5min |
| 北向当日个股净买入 | NorthboundNet_intraday | akshare `stock_hsgt_stock_statistics_em` | 日频（可能延迟） |
| 振幅、成交额 | LHB 门槛代理 | 分时快照 | 14:30/14:50 |
| 板块归属 | 排名归一化 | 同 Q1 | 静态+分时 |

**⚠️ 北向个股数据的延迟问题**：北向个股明细通常次日才出，日内只有总量。日内可用「北向净买入总量」+「该股是否陆股通标的」+「所在板块 ETF 是否有北向增持」间接推断。这一条准确性打折，回测时要模拟当时的数据延迟。

## 效果假设（未回测）

- 期望胜率：52%~58%
- 期望隔夜均值收益：+0.6%~+1.2%
- 最大回撤风险：单日 -5%~-8%
- 适用行情：**震荡市里最稳**——大盘方向不明时，资金面是最可信信号；牛熊单边行情里 alpha 被大盘噪声淹没

## 反例

1. **主力吸筹诱多**：14:30 净流入好看、14:50 尾盘对倒出货 → 由双点判定机制在 14:50 复核环节剔除。
2. **龙虎榜"卖出"上榜**：振幅够但都是机构卖出席位 → 上龙虎榜不等于利好，Q3 只做前瞻埋伏、次日出货完全交给早盘价格判断，不看 T+1 龙虎榜内容
3. **北向数据延迟**：早盘北向大买后午后已经出货 → 用**日内累计净买入的动量**（△北向 1300-1400 / △北向 0930-1000）而非绝对值可缓解

## 待定

1. **主力净流入的数据源**：akshare 有两个接口口径不一致（`stock_individual_fund_flow_rank` vs 东财原始接口），需先做**双源对齐**测试再选定。
2. **大单阈值 30%** 是拍脑袋，需回测校准。可能不同市值段最优阈值不同。
3. **龙虎榜是否作为强信号**：如果 14:50 就能预判"今日必上榜"（振幅+成交额已达标），rank 里权重应加大——但要小心"上榜=卖飞"的反例。
4. **是否与 Q1 合并**：Q3 和 Q1 有一定重叠（强势股常伴主力净流入）。回测阶段看**Q3 独立于 Q1 的边际胜率**——如果重叠 >70% 就合并。
