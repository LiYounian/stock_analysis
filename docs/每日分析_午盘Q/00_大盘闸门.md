# 00 · 大盘闸门（14:30 首判 + 14:50 复核，三策略共享）

> 定位：**不是选股信号，是仓位/开关闸门**。14:30 首判、14:50 复核，四挡输出（强/弱/震荡/崩），决定 Q1/Q2/Q3 是否出手 + 仓位比例。
> 数据切片：**14:30 首判只用 9:30-14:30 分时**、**14:50 复核只用 9:30-14:50 分时**（无未来函数）。
> **翻转规则**：14:30 判「强势/震荡」但 14:50 恶化到「弱势/崩盘」 → 全策略撤单空仓过夜。反向（14:30 弱→14:50 强）**不追**，本策略族只保守。

## 为什么先做大盘闸门

尾盘接力策略最大的死因是**大盘转弱时接跳水**。历史上绝大多数隔夜策略在震荡市/牛市 alpha 明显、熊市/崩盘日一次性回吐一年利润。所以三个子策略共用**同一把闸门**——闸门关了就空仓过夜，闸门开了才允许 screener 出票。

## 闸门指标（6 项，14:30/14:50 各计算一次）

| 指标 | 计算口径 | 数据源 | 状态阈值 |
|---|---|---|---|
| **G1 沪深300 分时涨跌** | `(price_asof / open) - 1` | akshare 指数分时 | 强≥+0.5%，弱≤-0.5% |
| **G2 中证1000 分时涨跌** | 同上 | 同上 | 同上（小盘代理） |
| **G3 涨跌家数比** | `涨家数 / 跌家数` @ asof | 分时快照聚合 | 强≥1.5，弱≤0.67 |
| **G4 涨停/跌停比** | `涨停数 / max(跌停数,1)` | 分时快照聚合 | 强≥5，弱≤1 |
| **G5 赚钱效应** | 涨幅≥3% 家数 - 跌幅≥3% 家数 | 分时快照 | 强≥200，弱≤-200 |
| **G6 北向净买入** | 沪深港通累计净买入 @ asof | akshare `stock_hsgt_hist_em` | 强≥+30亿，弱≤-30亿 |

`asof ∈ {"14:30", "14:50"}`——两个时点用同一套指标口径、同一套阈值。

## 状态判定（简单规则，可后续加权重）

```python
def market_gate(g1, g2, g3, g4, g5, g6) -> str:
    strong = sum([g1 >= 0.005, g2 >= 0.005, g3 >= 1.5, g4 >= 5, g5 >= 200, g6 >= 30e8])
    weak   = sum([g1 <= -0.005, g2 <= -0.005, g3 <= 0.67, g4 <= 1, g5 <= -200, g6 <= -30e8])
    if strong >= 4: return "强势"
    if weak >= 4:   return "弱势"
    if g4 <= 0.5 and g5 <= -500:  # 跌停潮 + 大面积下跌
        return "崩盘"
    return "震荡"
```

**门槛可调**——阈值是初始假设，回测阶段用历史 60 日样本做敏感度分析后再定稿。

## 实现要点

- **单一职责**：闸门只做判定，不出选股。选股走 Q1/Q2/Q3 各自的 screener。
- **可复用**：`tools/analysis/midday_q/gate.py::compute_gate(as_of)`，`as_of ∈ {"14:30","14:50"}`，接口对齐 [_数据与信号清单.md](_数据与信号清单.md)。
- **可回测**：`compute_gate` 接受历史日期参数，读历史分时 + 历史涨跌家数快照重放。
- **失败降级**：G6 北向数据偶尔延迟，任一指标缺失→整个闸门产出 `"状态": "未知"`，全策略**默认不出手**（不静默用旧值）。
