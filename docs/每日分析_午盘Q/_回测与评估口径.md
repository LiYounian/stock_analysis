# 回测与评估口径（Q1/Q2/Q3 共用）

> 定位：**评估宪法**。三条策略共用同一套口径，才能公平比较。参照现有 [docs/策略/回测策略.md](../策略/回测策略.md) 的防未来函数原则。

## 一、回测口径

```
walk-forward:  逐日双点判定：
                14:30 首判 → 只用 T 日 9:30-14:30 分时 + T-1 及以前日线
                14:50 复核 → 只用 T 日 9:30-14:50 分时 + T-1 及以前日线
                严禁使用 T 日 14:50 后任何数据（含收盘价、成交量、次日数据）
                最终入选 = 首判命中 ∧ 复核命中 ∧ 大盘闸门未翻转
成交假设:      买入 = T 日 14:50-15:00 分时 VWAP（用 14:55 分时价代理）
                卖出 = T+1 日 9:35-10:00 分时 VWAP（无止损，用户拍板 2026-09-07）
成本:          买入 5bp（手续费+滑点）+ 卖出 10bp（手续费+滑点+印花税1‰）= 15bp/次
基准:          等权买入次日开盘 + 卖出次日收盘（"隔夜 buy&hold"）
样本期:        60 交易日（用户拍板 2026-09-07），效果 OK 后续再扩
样本空间:      沪深两市全 A（剔除 ST/*ST/退/次新<60日），~4500 只
```

**关键约束**：所有信号函数必须接受 `as_of` 参数（∈ {"14:30", "14:50"}），断言只读 `as_of` 及以前数据——单元测试锁死。回测时对每只票每日跑两遍，两遍都命中才算入选。

## 二、产出指标

对每条策略、每个大盘状态挡分别输出：

| 指标 | 说明 | 判定标准 |
|---|---|---|
| **胜率** | 隔夜收益 > 0 的比例 | Q1 ≥55%，Q2 ≥50%，Q3 ≥52% |
| **均值收益（扣成本）** | 隔夜均值 - 10bp | > 0 才算及格 |
| **中位数收益** | 抗极端值 | 与均值方向一致 |
| **夏普比率** | 均值/std（日频年化 244） | > 0.8 优秀，> 0.5 及格 |
| **最大单日回撤** | 组合口径 | > -10% 直接淘汰 |
| **最大连续亏损日数** | 组合口径 | > 5 天亮黄灯 |
| **超额收益** | 相对隔夜 buy&hold 基准 | > 0 才有 alpha |
| **入选票数分布** | 日均入选 N、方差 | 稳定性观察 |
| **入选行业集中度** | HHI | > 0.4 加"分散度"过滤 |

分组产出（同表分别看）：

- 按**大盘状态**分组：强势/弱势/震荡/崩盘 各挡效果
- 按**市值分档**分组：大盘/中盘/小盘 各挡效果
- 按**信号强度**分组：TOP5 内 rank 1 vs rank 5 效果差
- 按**日历因子**分组：周一~周五、月初/月末、节前节后

## 三、防未来函数（命门测试）

沿用现有防未来函数测试模式（详见 `docs/策略/回测策略.md`）：

```python
# tests/test_no_lookahead_midday_q.py
def test_signals_only_read_before_asof():
    """篡改 asof 后的分时数据为极端值，断言 signals 输出不变"""
    for asof in ("14:30", "14:50"):
        fake_data = load_intraday("2026-08-01")
        fake_data.loc[fake_data["time"] > asof, "price"] *= 100  # 未来数据篡改
        for strat in ["Q1", "Q2", "Q3"]:
            real    = compute_signals(strat, "2026-08-01", as_of=asof)
            tainted = compute_signals(strat, "2026-08-01", as_of=asof, _override=fake_data)
            assert real == tainted, f"{strat}@{asof} 有未来函数泄漏"
```

**这是回测最容易翻车的地方**，单独测试防回归。

## 四、成本模型

- **手续费**：万三双边 = 3bp × 2 = 6bp
- **滑点**：尾盘/早盘各 2bp（VWAP 假设已缓解，仍留 buffer）
- **印花税**：卖出 10bp（1‰，2023 年后口径）

**单次隔夜总成本 ≈ 15bp**（买 5bp + 卖 10bp）——这是隔夜策略的**主要杀手**，均值收益必须显著 > 15bp 才有 alpha。

回测代码里 `TOTAL_COST_BPS = 15`。

## 五、达标裁决

回测跑完出**红黄绿灯**：

- 🟢 **绿灯上生产**：均值收益扣成本后 ≥ 0.3%（30bp），夏普 ≥ 0.8，最大单日回撤 > -8%
- 🟡 **黄灯观察**：均值收益 0~30bp 或夏普 0.5~0.8——继续调参 or 收窄适用场景
- 🔴 **红灯丢弃**：均值收益 ≤ 0 或最大单日回撤 ≤ -10%——直接淘汰

**丢弃是常态**。三条策略中若只有 1 条绿灯很正常，全绿反而要警惕过拟合。

## 六、样本外验证

- 参数在**样本内**（前 40 交易日）调
- 样本外（后 20 交易日）**只跑不调**验证
- 样本外表现衰减超过 30%（相对样本内）→ 判定过拟合，丢弃

**注**：60 日按 40/20 是默认，可根据回测时点选择调整比例；见 README §阶段性问题。

## 八、决策记录 & 待定

- ✅ **卖出规则**：**次日 9:35-10:00 分时 VWAP 无脑卖，无止损**（用户拍板 2026-09-07）
- ✅ **回测样本**：60 交易日（用户拍板 2026-09-07）

待定：

1. **VWAP 估算**：无法精确复现 14:50-15:00 VWAP（历史分时数据不足以逐 tick 重放），先用 **14:55 分时价代替 VWAP**——高估精度，需在报告里注明。
2. **停牌/涨跌停无法成交的处理**：
   - 买入价触及涨停 → 剔除该票（已由 `NotLimitUp` 过滤覆盖）
   - 卖出价触及跌停 → **强制持有到下一日再卖，累计双边成本**（需与用户对齐这个口径）
   - T+1 停牌 → 持有到复牌，按复牌首日 VWAP 卖
3. **止损**：首版无止损，观察 60 日样本回测里"次日开盘 -3% 以上"事件的比例和成本，再决定是否加
