# 午盘 Q 策略（14:30 首判 + 14:50 确认 → 尾盘买 → 次日早盘卖）

> 状态：**方案已定稿，M1 未启动** · v0.2 · 起草 2026-09-07，用户拍板 2026-09-07
> 定位：**T+1 隔夜策略族**。每日 **14:30 首判出候选**，**14:50 二次确认后下单**，次日 9:35-10:00 分时 VWAP 卖出。
> ⚠️ **非投资建议**。所有信号/阈值均为方案假设，未上线前不喂生产。

## 是什么
A 股 T+1 制度下的短线接力策略。三条子路并行探索，用同一套「14:30 首判 + 14:50 复核」大盘闸门控风险，用同一套「隔夜前瞻收益」口径回测。

| 子策略 | 逻辑 | 侧重 | 适合行情 |
|---|---|---|---|
| **Q1 强势接力** | 追当日强势不炸板股，赌尾盘量能延续 → 次日高开 | 胜率 | 结构性/牛市 |
| **Q2 弱转强反抽** | 早盘急跌午后回血，赌次日惯性冲高 | 赔率 | 挖坑日/情绪修复 |
| **Q3 资金流前瞻** | 龙虎榜/主力资金/北向净买信号前瞻布局 | 资金面确认 | 主力主导日 |

三条路可**同时跑**，用共同的大盘闸门做仓位分配（见 [00_大盘闸门.md](00_大盘闸门.md)）。也可做成"大盘风格分派器"——根据 14:30 首判大盘状态自动切换 Q1/Q2 主导权、14:50 复核确认（详见 §派单器·候选设计）。

## 关键约束（写在最前面，避免翻车）

1. **T+1 制度**：当日买入次日才能卖，涨停板 T+1 出货难度大 → Q1/Q3 都要**避开当日涨停票**（或严格限制"未开板一字/T字板"）。
2. **未来函数红线**：14:30 首判只能用**当日 9:30-14:30 分时** + **T-1 及以前的日线/基本面**；14:50 复核只能用**当日 9:30-14:50 分时** + T-1。**不得**使用 14:50 后的收盘价、成交量、次日数据。回测时同样按此口径切片。
3. **成交口径**：
   - 买入：假设 T 日 14:50 分时均价（或 14:55-15:00 集合竞价前 5min VWAP）。
   - 卖出：假设 T+1 日 9:35-10:00 分时均价（避免开盘 1min 极值失真）。
   - 成本：单边 5bp（同项目其他回测口径）× 2 = 10bp/次。
4. **停牌/ST/次新**：一律剔除。次新按上市 ≥60 交易日过滤。
5. **样本量**：单日入选数量硬上限，先按 **≤5 只**试跑（避免过拟合 + 隔夜风险分散）。

## 派单器·候选设计（三策略如何协同）

14:30 首判读大盘闸门（[00_大盘闸门.md](00_大盘闸门.md)）后，按如下规则分配（14:50 复核时若状态翻转到「弱势/崩盘」→ 全策略撤单空仓）：

```
大盘状态         主导策略          备选/仓位
─────────────────────────────────────────────
强势（红盘+扩涨） Q1 强势接力     Q3 加权，Q2 停用
弱势（绿盘+缩跌） Q2 弱转强反抽   Q3 加权，Q1 停用
震荡（涨跌平衡）  Q3 资金流前瞻   Q1/Q2 各半仓
崩盘（跌停潮）    全策略停用      空仓过夜
```

派单器是**上层编排**，不算独立策略；三个子策略各自独立可跑。派单器代码在编排层实现，不侵入策略层。
