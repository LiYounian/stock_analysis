## 分类维度

| theme | 含义 |
|---|---|
| **CPO/光模块** | 硅光/光模块龙头（本策略核心） |
| **光通信设备** | 光通信整机/网络设备 |
| **PCB** | 高多层板/CCL/覆铜板 |
| **半导体设备** | 前道/后道设备 |
| **半导体材料** | 硅片/光刻胶/靶材/电子特气/CMP |
| **芯片制造** | Foundry/IDM |
| **芯片设计-模拟** | 模拟/电源/射频 |
| **芯片设计-数字** | MCU/SoC/GPU/存储控制 |
| **存储** | DRAM/NAND/NOR |
| **封测** | 封装测试 |
| **光学元件** | 激光/光学器件 |
| **服务器/算力** | AI 服务器/液冷/交换机 |

| tier | 含义 |
|---|---|
| **龙头** | 板块内公认第一梯队（对应指数权重前列） |
| **二线** | 有独立业务但市值/份额次之 |
| **弹性** | 中小市值/题材股，波动大适合日内策略 |

## 我对这个草案的诚实自评

**问题很大，你务必审仔细**：

1. **我不敢保证每个代码都对**：几个高置信度的（旭创 300308、新易盛 300502、中芯 688981、北方华创 002371 等）是常识，但一些中小盘的**代码可能张冠李戴**。我强烈建议：**你审的时候重点看名字对不对**，代码错的话很危险。
2. **有明显分类错误**：
   - "300046 台基股份" 被我塞到了 PCB、模拟设计、数字设计三个 theme 里（实际是**功率半导体**）
   - "300783 三只松鼠" 被我错标成 PCB（它是**食品**）
   - "300570 太辰光"、"300597 吉大通信"、"002190 成飞集成" 分类可能不准
   - "300085 银之杰"、"300229 拓尔思" 不是纯算力标的
3. **重复出现**：有些票在两个 theme 里同时出现（002049 紫光国微、002156 通富微电、002185 华天科技、300223 北京君正、300458 全志科技、300474 景嘉微、300604 长川科技、600584 长电科技、688521 芯原股份、688981 中芯国际、300046 台基股份）——**去重后实际不到 100 只**
4. **一些票的 tier 判断偏主观**：龙头/二线/弹性 是我按印象拍的，不一定准
