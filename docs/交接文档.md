## 0. 项目一句话

A 股**策略辅助工具**(非投资建议):技术面 + 情绪面分析,评估**超买超卖**,给**买卖倾向 + 各持有期(1/5/10日)止盈止损% + 情景概率**。两阶段主流程:**选股筛选 Screener → 个股评估 Evaluator**。方向=方案2(先组合共性,再重点票深挖)。

---

## 1. 当前工作的步骤(怎么一步步做到现在)

按阶段推进,每阶段"写计划→(审)→实现→测试→分步 commit→维护文档"。核心工程步骤:

1. **P0 框架** —— 32 只票池(东财自选截图去重)+ 分层骨架(config/collectors/analysis/report)+ 开发规范 + LLM 调用设计。
2. **数据采集层(避开东财 TLS 指纹墙)**:
   - 行情 `market.py` —— 腾讯/新浪/东财多源 fallback(踩坑 B1)。
   - 基本面 `fundamental.py` —— 同花顺财务摘要 + 百度估值。
   - 公告 `announcement.py` —— 巨潮 cninfo + 标题规则打标 15 类。
   - 资金流 `fundflow.py` —— curl_cffi 伪装 chrome 指纹直连东财 fflow(突破 B2)。
3. **分析层**:
   - 技术 `technical.py` —— MA/MACD/KDJ/RSI/量比 + **趋势评级** + **拐点信号(P1.5,独立成维)** + **BIAS + 超买超卖 verdict(P1.6,≥2 共振,KDJ 假信号过滤)**。
   - 估值 `valuation.py` —— PE 适用性开关(亏损/高PE折旧/低PE一次性)。
   - 预测 `predict.py` —— 近三次放量/支撑压力/止盈止损%/情景概率/买卖倾向(全百分比,不需资金额)。
   - 组合 `portfolio.py` —— 板块强弱/市场宽度/情绪温度/主线。
   - 选股 `screener/` —— 预设规则筛选(N1 待细化)。
4. **结构化产出(P1.6 关键升级)**:公式+阈值数据化 `config/strategy.py`→`strategy.json`;每票 `data/analysis/{code}.json`;横向总表 `panel.csv/json`;选股结果 `screen.json`。
5. **报告层**:组合技术概览 + 单票卡(markdown,`docs/报告/`,gitignore)。
6. **Web(P3.4/3.5)**:FastAPI+Jinja2+Chart.js,Dashboard + 个股页 + 选股页 + 新闻页。
7. **分析实践**:并行 5 Agent 对 32 只逐票分析 → `docs/个股分析/`(32份)+ `docs/汇总/`,灵感沉淀进 [衡量指标与策略.md](衡量指标与策略.md)。
8. **编排** `run.py`:`collect / analyze / serialize / panel / screen / report / all` 子命令。

## 4. 快速上手

```bash
PY=~/.conda/envs/stock_analysis/bin/python
$PY -m tools.run all       # 采集→分析→结构化JSON→总表→选股→报告
$PY -m tools.run panel     # 只出横向总表
$PY -m pytest tests/ -q    # 55 单测
$PY -m uvicorn web.app:app --port 8000   # Web
```
数据产出:`data/analysis/{code}.json`(每票)、`panel.csv/json`(总表)、`screen.json`(选股)、`config/strategy.json`(公式+阈值)。
