# 一致性校验机制（超级模型 vs 中小模型）

> 状态：**框架桩（v2026-09-01）**，待落地。这是本机制的**最终交付物**——让中小模型按同一套经验/提示词分析，与超级模型（我）比对一致性，据此打磨经验文档，直到中小模型能高度复现。
> ⚠️ 非投资建议：校验的是"分析方法的一致性"，非收益。

---

## 1. 目标

同一批股票、同一份最新经验（`经验沉淀/` 最新版）+ `提示词/分析师提示词.md`，让：
- **超级模型（我）** 产出分析 A
- **中小模型** 产出分析 B

比对 A、B 的一致性；**不一致处定位是"经验文档没讲清"还是"中小模型能力不足"**，前者→回去把经验条目写得更可操作，后者→记录为模型能力边界。最终目标：经验文档打磨到 B 与 A 高度一致。

## 2. 校验维度与口径（建议）

对每只票，逐维打"一致/部分一致/不一致"：

| 维度 | 权重 | 一致判定 |
|---|---|---|
| **定性分票** | 高 | 是否归入同一类型（游资情绪/趋势成长/高位妖股/超卖反弹） |
| **方向预测** | 高 | 明日1日 + 5日方向是否同向（游资票"不给方向"也算一种，需同为"不给"） |
| **关键判据** | 高 | 支撑结论的 top-3 理由是否重叠（数据+消息面） |
| **消息面覆盖** | 中 | 是否都抓到了核心催化、是否都识别了关键利空 |
| **操作倾向** | 中 | 参与/观望/规避是否一致 |
| **我vs系统的出入** | 低 | 是否都识别了系统加工分的问题 |

一致率 = 加权一致维度占比。设阈值（如 ≥80% 视为"可复现"）。

## 3. 落地步骤（后续实现）

1. **固定输入**：选定当日 3~5 票 + 冻结经验版本号，保证 A/B 读同一份。
2. **产出 A**：超级模型按 SOP 分析（即每日复盘里的分析）。
3. **产出 B**：中小模型喂 `分析师提示词.md` + 同批票的 `data/analysis/日期/<code>.json` + 消息面 → 产出分析。
4. **比对**：按 §2 维度逐条打分，记 `校验/YYYY-MM-DD_对比.md`。
5. **归因不一致**：
   - 若因经验文档模糊 → 修经验条目（给可量化判据），记入下一版 changelog。
   - 若因模型能力 → 记为能力边界，考虑提示词降复杂度/给更多示例。
6. **迭代**：每交易日重复，跟踪一致率趋势。
