# 每日选股分析

> 本项目"每日选股分析→经验沉淀→反哺策略"机制的工作区。架构与流程见 [../计划/每日选股分析机制.md](../计划/每日选股分析机制.md)。
> ⚠️ 非投资建议：所有内容为测试环境研究模拟，用于迭代分析思路与策略数值。

## 怎么用（每天开工）

1. **先读最新经验**：`经验沉淀/` 里日期最大的那一版（`vYYYY-MM-DD.md`）——那是当前在用的 SOP + 提示词 + 经验条目。
2. 按 SOP 选股 3~5 只（写 `选股/今天.md`）→ 逐票"数据×消息面"分析。
3. 次日盘中核实、盘尾复盘（写 `复盘/次日.md`）。
4. 把当日教训并进 `经验沉淀/` 新版（changelog 写清改了什么、为什么）。

## 目录

- `经验沉淀/vYYYY-MM-DD.md` — 分析 SOP + 经验条目，**每交易日一版、只增不删、用最新版**，可回退。
- `复盘/YYYY-MM-DD.md` — 当日预测 vs 实际 vs 错因。
- `选股/YYYY-MM-DD.md` — 当日选出的 3~5 只 + 理由 + 分析产出。
- `提示词/分析师提示词.md` — 给中小模型的稳定说明书。
- `校验/一致性校验说明.md` — 超级模型 vs 中小模型 分析一致性对比机制。

## 铁律

- **防未来函数**（硬红线）：只用分析时点及之前的信息。
- **数据×消息面结合**：不能只看数据/系统加工分，必须看原始消息面。
- **游资情绪票不赌方向**，只判风险；**高位巨量不默认偏多**。
