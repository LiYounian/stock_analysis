# 每日选股分析

> 本项目"每日选股分析→经验沉淀→反哺策略"机制的工作区。架构见 [../计划/每日选股分析机制.md](../计划/每日选股分析机制.md)。
> ⚠️ **非投资建议**：所有内容为测试环境研究模拟，用于迭代分析思路与策略数值，不构成任何真实交易推荐。
> 目标：把"每天实盘选股+分析+复盘+沉淀"变成可迭代、可版本回退、**可让合作者及其 agent 一起参与**的标准流程，并用分析反哺策略。

---

## 一、目录结构

```
docs/每日分析/
├─ README.md              # 本文件：工作流 + 协作指南
├─ 经验沉淀/vYYYY-MM-DD.md  # 分析SOP+经验条目，每交易日一版、只增不删、用最新版、可回退
├─ 选股/YYYY-MM-DD.md      # 当日选出的票+选股理由(命中策略/维度)+深度预测+买入排序
├─ 复盘/YYYY-MM-DD.md      # 次日：预测vs实际vs错因+盘中核实
├─ 策略建议/               # 每日分析发现的策略修改建议(topic命名)+状态跟踪
├─ 提示词/分析师提示词.md   # 给中小模型/合作者agent的说明书(可直接喂)
└─ 校验/一致性校验说明.md   # 我(超级模型) vs 中小模型/合作者 分析一致性对比机制
```

## 二、每日工作流（一个交易日的闭环）

> 触发：收盘闭环 `com.stock.pullrefresh`(工作日15:40起)跑完、**当天全部策略视图生成后**。已配 3 个定时任务自动执行（见下），合作者也可手动做。

```
① 读最新经验   读 经验沉淀/ 最新版，加载 SOP+经验条目+已知陷阱
② 选股(盘尾)   等当天全部策略跑完 → 从全部策略视图多维度选3~5只(见SOP"选股阶段")
                 → 每只标类型(买入候选/检验样本)+写选股理由 → 逐票深度分析(数据×消息面)
                 → 明确买入排序(不对冲) → 写 选股/今天.md
③ 盘中核实(次日) 拉实时快照，核实早盘是否偏离预测 → 写入 复盘/次日.md
④ 盘尾复盘(次日) 预测vs实际、错因 → 写 复盘/次日.md
⑤ 沉淀经验      把当日教训并进 经验沉淀 新版(changelog写清改了什么)
⑥ 策略建议      发现策略误导/缺陷 → 在 策略建议/ 新增或更新一份建议(只提议)
```

**已配定时任务**（本机，工作日；`app 开着才跑`）：
| 任务 | 时间 | 做什么 |
|---|---|---|
| daily-stock-selection | 18:36 | 收盘后：等全部策略跑完→多维度选股→深度分析+买入排序 |
| daily-stock-intraday-check | 10:33 | 盘中核实前一日选票 |
| daily-stock-eod-review | 15:10 | 盘尾复盘+沉淀经验 |

## 四、协作指南（合作者 & 其 agent 一起参与）

> 目标：让合作者(如 jzq950305)及其 agent 也能选股、分析、迭代策略，形成多方参与的日更。

### 参与者怎么上手（人或 agent，按序读）
1. 读本 README（工作流+铁律）。
2. 读 [经验沉淀/](经验沉淀/) **最新版**（当前 SOP+经验条目）。
3. 读 [提示词/分析师提示词.md](提示词/分析师提示词.md)——**给 agent 的可直接喂的系统提示词**，按它执行即与主分析师同一套方法。
4. 按"每日工作流"产出，写进对应目录。

### 分工与防冲突（避免多人/多 agent 撞车）
- **按交易日或按票分工**：一天的 `选股/YYYY-MM-DD.md` 原则上一个作者；若多方同日参与，**按股票拆分**（各写各的票，文件内分节署名），或约定谁主笔。
- **策略建议按 topic 分工**：一个策略问题一份文档，避免多人同改一份；新问题新建，已有问题在原文档追加(记 changelog)。
- **git 纪律**：在自己的 `feat/analysis-*` 分支上写，**只写 `docs/每日分析/`**；**绝不直接改策略代码**（策略改动走 策略建议→统筹审→实现窗→回测 流程，达标才接生产）。合并 main 由统筹集成。
- **署名**：合作者产出可在文件内注明作者，便于追溯；但 commit 不加 AI 联名（项目约定）。

### 一致性校验（超级模型 vs 合作者/中小模型）
- 同一批票，不同参与者各按同一份经验/提示词分析，用 [校验/一致性校验说明.md](校验/一致性校验说明.md) 的维度比对（定性/方向/关键判据/买入表态是否一致）。
- 不一致处 → 定位是"经验文档没讲清"(回去补经验条目) 还是"能力差异"(记录)。**这是最终要打磨的交付物**：把经验文档做到"照着做就能与主分析师高度一致"。

### 策略反哺是共同产出
- 任何参与者在分析中发现策略缺陷 → 写进 [策略建议/](策略建议/)（诊断+提议+回测口径）。统筹汇总排期，多方一起迭代策略。

## 五、铁律（所有参与者/agent 必须遵守）
- **防未来函数**（硬红线）：只用分析时点及之前的信息。
- **数据×消息面结合**：不能只看数据/系统加工分，必须看原始消息面。
- **选股等全部策略跑完**、**从全部策略多维度挖**（不只看策略0合议）、每只写选股理由。
- **明确买入表态、别对冲**：给买入排序，观望/规避只用在真该观望的票；保证有真买入候选。
- **游资情绪票不赌方向**（只判风险）；**高位巨量区分主力vs融资盘**；**超卖看市场广度**。
- **不直接改策略代码**：策略改动只在 策略建议/ 提议，走正式实现窗+回测，达标才接生产。
- **非投资建议**：测试环境研究模拟。
