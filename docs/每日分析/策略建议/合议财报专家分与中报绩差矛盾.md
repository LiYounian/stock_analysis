# 策略建议 · 合议"财报专家"评分与中报绩差严重矛盾

> 记录日：2026-09-07（每日选股分析发现）。仅提议，非投资建议。

## 现象

2026-09-07 策略0合议给 **001223 欧克科技** 排第 6（综合分 0.7169），其中**财报专家判"财报评级=优、quality_score=100.0、审计闸门通过、flags 空"**，方向看多、强度 0.9、置信 0.8，贡献 0.72（与板块轮动并列为两大加分项）。

但同日 baidu_news + 中报原始数据显示该股基本面实为**绩差**：
- 2026 中报：营收 4.56 亿（+0.26%）、归母净利 1754 万（**−74.60%**）、扣非 1506 万（−76.04%）、经营现金流净额 295 万（**−91.91%**）。
- Q2 单季倒推归母约 −1322 万（**同比约 −146%，单季转亏**）。
- 应收账款体量大（占最新年报归母净利约 1282%）、中报计提资产/信用减值、主营从高毛利生活用纸装备（毛利 46%、营收 −65.79%）切换到低毛利薄膜材料（毛利 10.7%）。

即：**合议财报专家的"优/100"与实际"增收不增利、单季转亏、现金流枯竭、计提减值"方向完全相反。**

## 疑似根因（待核查）

1. **报告期对齐错误**：财报专家可能取了更早的报告期（如去年年报/一季报）或"优"来自旧口径，未对齐 2026-06-30 半年报。
2. **盈利质量维度缺权重**：quality_score=100 可能主要由营收规模/资产/审计意见等驱动，**漏掉了净利增速、扣非、经营现金流、应收账款质量**这些盈利质量维度——导致"增收不增利"被判为"优"。
3. **five_dims 未参与或映射反了**：需核查财报专家如何把 five_dims/利润表摘要聚合成 quality_score。

## 影响

- 该矛盾直接抬高了 001223 的合议排名（进 Top10），若不做 #4（原始消息对账）会被误当"合议∩资金放量的多维确认买入"。本次已按经验 #4/陷阱3 以原始消息为准，降级为"检验样本·观望"。
- 属经验 #4"系统 events/sentiment/加工分可能建立在残缺/错位数据上"在**财报专家维度**的又一实例。

## 建议

1. 核查财报专家（`tools/analysis/experts.py` 或 `financial/` 下评级逻辑）对 001223 实际取用的**报告期**与 quality_score 的**因子构成**，确认是否报告期滞后或盈利质量维度缺失。
2. 若确为盈利质量缺权重，建议在 quality_score 中显式纳入**扣非净利增速 + 经营现金流/净利 + 应收账款周转/占比**的惩罚项，使"增收不增利、单季转亏"无法拿高分。
3. 与已有《财报路由验证.md》合并核查（可能同源）。
