## 1. 动机（实盘暴露的缺陷）

2026-09-01 分析新易盛300502，把"巨量资金流入"当主力看多判"偏多"，实际冲高回吐收平。消息面显示：那更可能是**融资盘买入（单日融资买入16~17亿），主力口径反而净流出**（板块120亿撤离）。

## 2. 诊断（现状口径 + 缺陷根因，附证据）

**唯一数据源**：东财 `push2his.eastmoney.com/api/qt/stock/fflow/daykline/get`（[fundflow.py:20-28](../../../tools/collectors/fundflow.py)）。
- 东财"主力净流入" = **超大单净额 + 大单净额**，是按**单笔成交金额/手数大小**对**已成交逐笔**分类反推的，**不是账户身份数据**。
- **关键盲区**：融资盘买入 = 投资者用融资额度下的普通买单；一旦金额够大达到大单/超大单阈值，成交后即被东财**分类进"超大单/大单买入"→计入"主力净流入"**。系统拿到的是分类结果，**无法区分**这笔大买单背后是机构、游资、还是融资加杠杆的散户/大户。

**信号逻辑过粗**（三处同构，纯看符号）：
- `expert_资金流`（[experts.py:108-128](../../../tools/analysis/experts.py)）：主力净流入>0→看多(强度0.5)，连续≥2天→强度顶格**1.0**；<0→看空。
- `council.py:143-152`、`predict.py:189-199`：净流入>0记+1，连续≥2再+1。
- **只看正负号+连续天数，不看量级、不看价格位置、不甄别来源**。

**结论**：系统**没有采集任何两融数据**（全仓 grep `两融/rzrq/融资买入/margin` 零命中），所以不是"字段接错"的低级 bug；而是**东财主力口径的固有盲区**（无法剔除融资盘）+ **系统在其上又叠了只看符号、还随连续天数自我放大的粗糙信号**。两者叠加，使高两融题材票的"巨量流入"极易被误读为主力吸筹。新易盛"20亿"对应的正是 `fundflow.今日主力净流入` 字段被 16-17亿融资买入撑起。

## 3. 改进提议（按投入产出排序，只提议）

1. **【治本】引入两融数据做背离甄别**：新增 collector 采个股**融资买入额/融资余额/融资占成交额比**（akshare `stock_margin_detail_*` 或东财两融明细）。构造**背离风险标**：当"主力净流入"为大额正值、但当日融资买入能解释掉大部分该"流入"时，判"主力流入疑似融资盘驱动"→资金流看多信号降权或翻风险提示，纳入 `risk_veto.py`。
2. **【治标·可先上】高两融占比票整体降权**：以"融资余额/流通市值"或"融资买入/成交额"分档，高档位票 `expert_资金流` 权重打折甚至弃权；缺两融数据时用换手率+波动率+是否热门题材做代理。
3. **【结构】资金流信号去符号化+加约束**：用主力净占比/净额相对成交额标准化，设死区阈值（小额不表态）；**高位巨量流入降权/反向**（阶段高位+单日净流入分位极高更可能是出货对倒/融资追高，不应顶格看多）；重审 `streak≥2→强度1.0` 的放大逻辑在追涨末端的危险性。
4. **【最小】背离作为独立风险标**：即使不动资金流因子，也把"主力净流入 vs 融资买入背离"作为 `risk_veto` 的降级项，报告显式标"本次流入疑似杠杆资金，非主力吸筹"。

## 4. 回测口径（A/B，达标才接生产）

- **样本**：全A（或自选池）近3~5年、有东财资金流+可获两融数据的观测；重点分层出**高两融占比子样本**（融资余额/流通市值前20% 或热门题材票）作主检验层。
- **A/B**：A=现状纯符号信号；B=叠加"两融背离降权/高两融降权/去符号化+高位约束"。
- **对比指标**：
  - 判别力：资金流看多信号后 T+1~T+5 前瞻收益（IC/分组多空/命中率），全样本 vs 高两融子样本分看；
  - **误判率（核心）**：定义"高位巨量主力净流入→判偏多→T+3内收平/回吐"为误判事件，比 A/B 误判占比是否下降；
  - **不伤害正常样本**：低两融正常建仓样本上 B 判别力不显著低于 A；
  - 与 `eval_v3` 多维评测对齐（alpha/命中率/名义E 综合判定，别只用单指标）。
- **达标标准**：高两融子样本误判率相对 A 显著下降（如≥20%相对降幅且显著）；全样本判别力 B 不劣于 A；带 kill-switch 可回退（沿用自适应RR 的 A/B 落地范式）。
