# 策略建议 · "多策略命中"选股维度需加"同源信号"与"游资票"两道闸

> 来源：2026-09-02 选股分析——002084 海鸥住工以 **3 个策略同时命中**（最大范围选股 + 动量组合 + 反转低换手）成为当日命中数最高的票，但它是**复牌后7连板、累计+95.54%、当日一字板开板天量派发**的游资情绪票，基本面空心（净利增速-271%、ROE-1.72、PE-16.71）。
> 状态：**已实现**（见 §6/§7；分支 `worktree-agent-a5ac0883c2eed2a43`，软默认 + kill-switch，待统筹把关接生产）。这不是某个策略的 bug，是**选股维度（经验#8）本身的方法论缺口**。
> 优先级：中（不改策略代码也可先落在经验沉淀/选股SOP里，属"低成本高收益"）。
> ⚠️ 非投资建议。§1-5 为原始提议；§6-7 为实现与验收记录。

---

## 1. 动机

经验 #8 把"**多策略命中**：一只票被 ≥2 个策略同时选中——信号强"列为第一选股维度。本轮实测这个维度会**系统性地把连板妖股排到最前面**：

| 命中策略 | 命中原因（该策略实际在看什么） |
|---|---|
| 最大范围选股(S03) | `C/HHV(C,250) ≥ 0.82` → 002084 **距250日高点 100%** |
| 动量组合(S04·A腿) | 加权对数动量打分 → 002084 **动量分 2753.65、年化3981**（7连板堆出来的斜率） |
| 反转低换手(S10) | 5日反转因子极端 → 002084 `rev = -0.4864`、`rev_z = -1.75`（连板导致的极端5日涨幅） |

**三个"独立策略"命中的其实是同一件事——"它涨得多"。** 距250日高点100%、动量分极高、5日反转极端，三者都是"近期涨幅"的不同变换，相关系数极高。
→ **同源命中 ≠ 多维确认**。经验#8 说的"信号强"暗含了"多个独立视角互相印证"，但当所有命中都来自价格涨幅这一个源头时，命中数越多只说明**涨得越猛**，不代表证据越强，反而是"过热"的度量。

**唯一救回来的是否决层**：反转策略的否决层判「事件博弈（龙虎榜 2026-09-01 净买上榜，占比7.70%，距今1日）→ 否决入选」，罚分1.5、调整后分 -2.4134、打标"高风险博弈，不作反转买入候选"；per-stock `lhb_veto.triggered = True` 同步命中。**这是 [反转策略否决层](反转策略否决层.md) 接生产后的一次样本外正面验证，应记一笔。** 但它只保护了反转策略这一条通道——动量组合和最大范围选股仍把它选了进来，且**"多策略命中"这个维度是在策略之上的选股环节，任何单策略的否决层都管不到它**。

## 2. 诊断

1. **命中口径独立性未被度量**：现有选股维度只数"命中几个策略"，不看"这几个策略的信号是否来自同一口径"。当前策略池里，S03(距高点)、S04(动量)、S10 的 rev 腿(5日反转) **都是价格涨幅族**；真正口径独立的是：半导体多因子(基本面/研发)、放量后缩量回踩(跨周量能形态)、S10 的 turn 腿(换手/冷门度)、策略0合议的财报质地专家。
2. **游资情绪票没有前置闸**：经验 #1/#6/#7 已经说清"游资连板票不赌方向、催化已price-in只标风险"，但那是**逐票分析阶段**的约束；**选股阶段**没有对应闸门，导致这类票每天都会挤进候选、消耗分析预算（本轮它占了 5 个名额之一）。
3. **风控 veto 未上升到选股层**：`lhb_veto` / 财报红旗在 per-stock 和反转策略里都有，但"多策略命中"排序时没有统一消费它们。策略0合议已经做了"统一风控 veto 汇聚接入排序"（当日 `命中高危红旗 98`、`命中龙虎榜否决 28`），**这个已有能力没有被"多策略命中"维度复用**。

## 3. 改进提议（只提议）

**A. 给"多策略命中"改计分口径（核心提议）**
把"命中数"换成**"独立口径命中数"**：先给每个策略打一个**口径标签**（价格动量族 / 形态族 / 基本面族 / 资金族 / 情绪事件族 / 换手冷门族），同族命中**只计 1 次**。
- 002084 按新口径：最大范围 + 动量 + 反转rev腿 = **价格动量族 ×3 → 独立口径命中数 = 1**（而非 3）。
- 002811 郑中设计按新口径：量价放量(形态/量能族) + 最大范围(价格动量族) = **独立口径命中数 = 2**，真正的双维确认。
→ 这一条不需要改任何策略代码，只需要一张"策略 → 口径族"映射表 + 选股环节改用新计数。**成本极低、立即可用。**

**B. 加"游资情绪票"前置闸（描述性判据，不写死具体案例）**
选股阶段对候选先算一个"情绪过热"裁决，命中则**不进买入候选池，只能作为检验样本/风险观察**，判据用一般性约束：
- 近期连续涨停/极端累计涨幅（价格严重偏离中期均线，bias20 极端）；
- 换手率处于极端分位（筹码一日内大规模换手）；
- 获利盘比例接近饱和（上方无套牢支撑、全员浮盈）；
- 龙虎榜/事件博弈类 veto 命中；
- 基本面空心（扣非为负 / 净利大幅负增长 / 高危红旗）。
**多轴同时命中才裁决**（对齐 [动量策略高位超买抑制层](动量策略高位超买抑制层.md) 已验证有效的"双轴命中才抑制"范式，避免误杀正常强势股）。默认**软降级**（保留展示 + ⚠ 标签 + 沉排序），不硬剔除。

**C. 把统一风控 veto 汇聚复用到选股层**
选股环节直接消费策略0合议已经在用的那套 veto 汇聚（财报红旗 + 龙虎榜否决正交 OR 合成），对"多策略命中"排序做同样的降权/沉底。避免同一份风控信息在合议里生效、在选股维度里失效。

## 4. 回测/验收口径

- **A（口径族计数）验收**：属排序口径调整，用**历史选股名单重放**验收——取过去 N 个交易日，对比"原命中数 TopK"与"独立口径命中数 TopK"两个名单的 **T+1/T+5/T+10 前瞻收益与踩雷率（maxDD ≤ -12%）**。达标标准：**踩雷率下降**且前瞻收益不劣化。
- **B（情绪过热闸）验收**：沿用动量抑制层那套三条标准——①全样本不劣化 ②判别力（被裁决子样本的踩雷率显著高于基率）③不误杀（被挤出票的前瞻收益显著差于保留票）。默认软降级 + kill-switch 一键回退。
- **C（veto 复用）验收**：一致性断言——同一票在"策略0合议排序"与"多策略命中排序"里得到**同向的风控处置**，不再出现"合议已否决、选股仍推荐"。
- **诚实定位**：A/B/C 都是**减损层**（降踩雷、省分析预算），**不制造 alpha**。

## 6. 实现（已落地）

> 状态：**已实现**（分支 `worktree-agent-a5ac0883c2eed2a43`）。软默认 + kill-switch，不破坏正常多维命中票。

三道闸统一落在**选股汇总层一处**（不在各策略内重复），复用现有已验证机制、不重造轮子：

- **A 口径族计数**（核心）：策略 → 口径族映射表落 `tools/config/strategy.py` 的 `STRATEGY_FAMILY`
  （THRESHOLDS 同级，单一真源；新增策略必须在此登记口径族）。族划分：价格动量族（动量组合 /
  最大范围选股 / 反转低换手组合 / 最强选股）、形态量能族（放量后缩量回踩 / 量价放量）、基本面族
  （半导体多因子）、合议综合族（策略0合议）、状态参考族（指标条件化状态排序，列入"非确认族"不计入
  确认）。纯函数 `multi_strategy_gate.independent_hit_count(labels)` 把命中策略归族，数**独立口径命中数**
  替代命中数；**未登记策略按"独立族"保守计**（不误合并）。
- **B 游资情绪过热前置闸**：`multi_strategy_gate.overheat_verdict`（纯函数）+ `extract_gate_features`
  （IO 层），五轴——超买共振 / 涨幅透支（复用 `momentum_overheat.extract_features`）、换手极端
  （kline `turnover` 列）、事件博弈龙虎榜 / 基本面空心（复用 `reversal_veto._lhb_feature` /
  `_fund_features`）。**多轴同时命中才裁决**（默认最少命中轴数 = 2，对齐动量抑制层"双轴命中才抑制"，
  避免误杀正常强势股）；默认**软降级**（保留展示 + ⚠ + 沉排序）。
- **C 统一风控 veto 汇聚复用**：`multi_strategy_gate.veto_verdict` 薄封装 `config.risk_veto_adjust`
  （财报红旗 + 龙虎榜否决 OR 合成），选股层同向消费——避免"合议已否决、选股仍推荐"。
- **排序分层**：`sort_key` = `(tier, -独立口径命中数, -原始命中数)`；tier 优先于命中数、
  **magnitude-robust**——clean 多维确认票 > 过热软降级(1) > 沉底(2) > 剔除/否决(3)。
- **接线**：`run.py::run_screen_all` 在 `run_screen` 后调 `run_multi_gate(picks_by_view, as_of)`，
  结果落 view `多策略命中闸门`（随当日 analysis 产物 upload 到远端，供选股页 / SOP 消费）；
  `_safe` 隔离，失败降级不中止闭环。
- **kill-switch**：`THRESHOLDS['多策略命中闸门']['启用']=False` → 退回**原命中数排序**（不归族、
  不过 B/C 闸、不读盘），现状不回归；过热闸另有独立子开关 `过热闸.启用` 与分轴开关。

改动文件：`tools/config/strategy.py`（映射表 + THRESHOLDS 段 + `family_of`/`multi_gate_cfg`）、
`tools/analysis/multi_strategy_gate.py`（新模块）、`tools/run.py`（`run_multi_gate` + 接线）、
`config/strategy.json`（dump 同步）、`tests/test_multi_strategy_gate.py`（语义锁 22 例）。

## 7. 验收结果

以 §1 的 002084 / 002811 为口径构造选股层重放（`test_evaluate_主验收_*`）：

- **主验收（达标）**：002084（最大范围 + 动量 + 反转，同源均价格动量族）→ **独立口径命中数 = 1**
  （而非 3），叠加超买/涨幅/换手过热 + 龙虎榜命中 → **过热闸触发软降级**，排序**不再居首**；
  002811（量价放量[形态量能族] + 最大范围[价格动量族]，独立口径命中数 = 2 的**真·双维确认**）
  **居首**；正常单族 clean 票（600000）也排在过热票之前。
- **不劣化（达标）**：正常多维命中票（两个双族 clean 票）过热闸不触发、tier 均为 0、独立口径
  命中数保留，排序不被误降级。
- **kill-switch（达标）**：关闸退回原命中数排序（002084 命中 3 仍居首、独立数 = 原始数不归族），
  且**关闸时完全不调用特征抽取**（no-op、不读盘，测试用会抛异常的 provider 反证)。
- **交叉验证**：§1 记录的"反转否决层在 002084 上龙虎榜正确否决"与本层 C（veto 汇聚复用）同源——
  同一份龙虎榜风控信息现在在选股汇总层也被消费（`风控汇聚.龙虎榜` 当前为降权模式；改否决模式即在
  选股层强制沉底）。
- 测试：`tests/test_multi_strategy_gate.py` 22 例全绿；`config/strategy.json` 同步测试绿；
  相关回归（momentum_overheat / reversal_veto / risk_veto）61 例全绿。全量套件除 3 例**与本改动无关**
  的既有环境失败（akshare 财联社接口属性缺失 / HS300 ZIP 下载 / 一处 redflag 打分断言）外全绿。

**建议接生产**：软默认（过热软降级不硬剔除）+ 完整 kill-switch + 纯复用已验证机制，风险低；
诚实定位为**减损层**（降踩雷 / 省分析预算，不制造 alpha）。上生产后建议按 §4 口径做历史选股名单
重放（踩雷率 / 前瞻收益 A/B）持续观测，再决定是否把过热闸从"软降级"上调为"沉底/剔除"。

## 样本外验证 · 2026-09-03（盘尾复盘补记）

本闸门已于 09-02 接生产（`d194e42`），09-03 拿到**第一个样本外正面证据**：

- **002084 海鸥住工**（09-02 以 3 策略命中排全批最高，三者命中原因同源="涨得多"；闸门把它的独立口径数降到 1、不再居首，反转否决层同时判"事件博弈"降级）：
  09-03 收 **6.91，-2.95%**，日内 **高 7.24 → 低 6.50（振幅 10.4%）**、**换手 24.56%**、量比 2.46，7连板开板后延续派发。
- **002811 郑中设计**（闸门认定的真双族命中，改判后居首）：09-03 收 **15.68，+7.84%**（α vs 全A等权 **+8.15pp**），当日全批最强之一。

→ **闸门的排序改判方向与次日实际收益方向一致**（被降级的跌、被上提的涨）。单日单样本，不构成统计结论，但是第一条"改判有效"的实盘证据。建议按本文 §4 口径继续累积，满 20 个交易日再做踩雷率/前瞻收益的 A/B 统计。
