## 1. 动机：一个我们完全抓不到的高手打法

某高手近期10笔买入（白银有色/江西铜业/英特科技/上海谊众/中欣氟材/国芳集团/中文在线/亿田智能/花溪科技/康农种业），**上车价=当日开盘价（8/8主板精确吻合）**，**平开→当日盘中放量拉至涨停**（放量1.6~6.4倍），买入前多为安静横盘。

**我们的策略覆盖**：
- **前一日闭环（为买入日选股）：0/10 命中**——完全没预判到。
- **买入日闭环（收盘后·马后炮）：仅3/10** 事后出现（江西铜业/英特科技/中文在线，均在其涨停之后）。

→ 我们的技术/量价/多因子/合议策略都是**盘后日线截面**，抓不到"安静票次日放量涨停"，因为**信号不在收盘K线里，在盘前题材/事件/竞价/龙虎榜**。

## 2. 逆向出的策略（他在做什么）

**核心 = 题材/业绩共振的"低吸接力打板"**，两条隔夜可量化的主线：
1. **中报业绩爆发事件**（8-25中报密集披露夜后连买）：江西铜业净利+106%、国芳集团+214%、上海谊众稳健——**专挑当晚出高增长中报的票、次日开盘买**。
2. **板块题材发酵补涨**：每天押1~2个当天最强发酵方向的**尚未大涨的补涨/接力龙头**——有色/贵金属(8-26两笔同题材)、液冷算力散热、创新药、氟化工/制冷剂、AI微短剧出海、北交所农业(9-01两笔同题材)。
辅线：**龙虎榜游资接力**（花溪8-31上榜→9-01续买，可验证样本成立）。
特征：**不看情绪、不惧利空基本面**（中文在线情绪负、中欣/亿田中报亏损照买）——主导变量是题材资金+催化。异类：亿田智能无业绩无题材，属纯低位超跌游资反包。

## 3. 提议：新增"事件/题材驱动候选池"（盘后可量化的部分）

我们缺一整类"**盘后事件+题材+资金**"选股，建议新增一个候选池策略，因子（全部收盘后可得）：
- **事件因子**：T-1晚披露的中报/预告，净利/营收增速超阈值（项目已有 event_yjkb/yjyg + announcement 采集，可直接用）。
- **板块题材动量**：所属题材当日**涨停家数**、板块指数动量、"板块内已有龙头封板"→ 圈定**补涨候选**（需板块聚类+涨停统计——注意这依赖已修好的行业映射，见 [合议专家覆盖补全](合议专家覆盖补全.md)）。
- **量价异动形态**：前期缩量横盘后**首日放量**（中欣/国芳形态）、超跌反包（亿田）——panel 里量比/BIAS/放量标记可捕捉。
- **龙虎榜接力因子**：T-1游资/机构净买上榜→T日跟随（项目已有LHB采集+lhb_forward_scorecard，但历史深度不足，需积累）。
- 候选池 = 上述因子的并集/加权，产出"次日高弹性/打板候选"。

## 4. 硬限制：选股可量化，打板择时必须盘中（诚实说明）

**决定"当天必封板"的胜负手，EOD收盘数据给不出**：
- **开盘竞价强度/盘口**：他"平开低吸→日内封板"依赖集合竞价量能、盘口挂单、分时资金——日线策略拿不到。
- **题材当天是否引爆**：需盘前实时新闻+竞价判断，EOD静态因子只能给"概率/候选"，给不出"今天就这只"。
→ **结论：我们能复现他的"选股池"（命中率会不错），但复现不了"开盘买且当日封板"的执行**——那需要接入**集合竞价+分时盘口+实时龙虎榜/新闻**（盘前/盘中数据层，是另一个工程）。**先做可量化的候选池，把它当"次日高弹性观察池"用，不追求打板择时。**

## 5. 回测口径（A/B）
- **样本**：历史闭环日，构建"事件+题材+龙虎榜+量价形态"候选池，逐票算 T+1 开盘买入→当日/T+1收益、**次日涨停命中率**、T+1~T+3前瞻收益（复用 forward_scorecard 基建）。
- **对比基准**：现有策略（动量/量价/合议）的次日涨停命中率与前瞻收益。
- **达标**：候选池的**次日涨停命中率 / T+1收益 显著高于**现有策略基准；用本案10笔做样本外抽查（看新池能否把这10只在前一日纳入）。带 kill-switch。
- **注意**：不承诺复现"当日封板"，只验证"候选池是否显著富集次日高弹性/涨停票"。
