# 策略建议 · S03/S04 缺"筹码·减持"否决层，且阻力位不含可转债强赎线

> 来源：2026-09-03 每日选股。两个独立发现，共同点是 **S03最大范围 / S04量价放量 / S02回踩 三个策略只读量价，读不到"供给侧"信息**：
> ① **603333 福华尚纬** 被 S03+S02 双双选中（距250日高 98.93%、标准缩量回踩），但它同时满足：获利盘 **99.78%**、股东户数环比 **+7.16%**、大股东连续减持、龙虎榜机构净卖出 2139万、净利率 **0.835%**、PE_TTM 为负。
> ② **300866 安克创新** 被 S03 判为"距250日高 96.37% = 强势"，但其**存续可转债的强赎触发带 138.7~143.8 与 250日高 142.32 几乎重合**，上行空间被结构性压缩到约 5% 以内。
> 状态：**提议（只诊断+提改进+回测口径，未改代码）**。
> 优先级：**P1**。
> ⚠️ 非投资建议。本文档只提议，**不改代码、不改任何定时任务配置**。

## 第一部分 · S02/S03/S04 缺"筹码·减持"否决层

### 1.1 现象

`反转低换手组合(策略10)` **已经有**专属否决/降级层，2026-09-03 当日还命中了「事件博弈 1 + 治理风险 1」共 2 只降级：

```
"否决层": {"启用": true, "模式": "降级",
           "命中数": {"降级": 2, "否决": 0, "剔除": 0},
           "分轴命中": {"事件博弈": 1, "治理风险": 1},
           "有风险特征票数": 60}
```

但 **`最大范围选股(S03)`（256只）、`量价放量(S04)`（94只）、`放量后缩量回踩(S02)`（169只）三个策略的视图里没有任何否决层字段**——它们的 `规则` 全是纯量价条件。

### 1.2 603333 的五条负面证据，三个策略一条都读不到

| 证据 | 数值 | 来源 |
|---|---|---|
| 获利比例 | **99.78%** | `chip`（09-02口径）——SOP 明确"获利盘~100%=高抛压无支撑" |
| 股东户数环比 | **+7.16%** | `holder`（09-02口径）——明显散户化，筹码松动 |
| 大股东连续减持 | 李广元 08-10~08-17 减持 **621.52万股（1%）**，区间 8.90~9.69元，持股降至 7.98% 且**全部自由流通**；2025-09/2026-01/2026-04 均披露过减持计划 | 正式公告 |
| 龙虎榜结构（08-21涨停日） | **机构净卖出 2139.42万，营业部净买入 2742.59万** = 机构出、游资接 | 交易所数据 |
| 盈利质量 | 营收增速 +71.7% 但 **净利率 0.835%、ROE 0.03、PE_TTM -183.27（失效）** | `fundamental`/`valuation`（09-02口径） |

→ 五条**独立**证据同向指向"筹码由机构/大股东流向散户与游资"，而策略给出的信号是"距250日高98.93% + 标准缩量回踩 = 双策略命中"。**这正是经验 #15 说的"同源命中≠多维确认"的极端案例**：两个策略命中的**都是量价形态口径**，而基本面与筹码两个口径都在反对。

### 1.3 建议改动

**复用反转否决层的现成四轴**（基本面空心 / 事件博弈 / 治理风险 / 重组未完成），接到 S02/S03/S04 的排序/入选层，**并新增一条"筹码轴"**：

```
筹码轴命中（建议初值）：
  · 获利比例 > 0.95        （几乎无解套盘承托）
  · 或 股东户数环比 > +5%   （明显散户化）
  · 或 近90日内存在"大股东减持进展/结果公告"且减持均价 < 当前价
→ 模式：降级（× 系数沉排名），不直接剔除
kill-switch：关闭即回到纯量价现状
```

**设计要点**
- **降级而非剔除**：与反转否决层保持一致的保守模式，避免误伤（获利盘高本身也是强势特征，需靠回测定系数）。
- **数据可得性护栏**：`chip`/`holder` 依赖 per-stock record，而**全A口径下这两个字段大面积缺失**（2026-09-03 当日 record 数为 0）。因此建议：**仅对已有 record 的票施加降级，缺数据的票不降也不奖**，并在视图里输出 `筹码轴覆盖率`，防止"因为缺数据所以看起来没风险"。

### 1.4 建议回测口径

- **样本**：S02/S03/S04 的历史每日入选快照。
- **对照**：A = 现状；B = 加筹码/减持降级层后。
- **指标**：H1/H5/H10 均值收益、胜率、IC；**α 基准用全A等权 mean_pct + 中位数对照（经验 #11，不用指数）**。
- **达标判据**：B 的 H5/H10 **均值收益与胜率不劣于** A，且**被降级子集**的前瞻收益显著低于未降级子集（证明闸门抓的是真风险，而不是随机剔票）。
- **分层**：按"是否有 record（筹码轴是否可算）"分层报告，避免覆盖率偏差把结论带偏。

## 第二部分 · 阻力位不含可转债强赎线

### 2.1 现象

`最大范围选股(S03)` 的 `明细` 只输出 `距250日高点%` / `HHV250` / `MA10/MA20/MA50`：

```json
{"code": "300866", "明细": {"距250日高点%": 96.37, "HHV250": 142.3241,
  "close": 137.16, "MA10": 125.155, "MA20": 121.656, "MA50": 116.3788}}
```

策略据此判定"距250日高 96.37% = 强势、可入选"。但**同一个项目里 `equity_financing` 已经能算出**：

```
安克转债 123257 | 规模 11.0482亿 | 已进入转股期(2025-12-22起)
转股价 106.72 | 强赎触发价 138.74 | 回售触发价 74.7
债现价 160.36 | 转股溢价率 24.77% | 转股潜在股数 1035万股
约束提示: ["已进入转股期,转股价106.72,摊薄可随时发生",
          "强赎触发价138.74(正股价触及即可能促转股)"]
```

**250日高 142.32 与强赎触发价 138.74 相距仅 2.6%** —— 两层阻力叠在同一区域，而**策略完全不知道第二层存在**。

### 2.2 为什么强赎线是真阻力（不是主观判断）

- 强赎条件 = 30 个交易日中 15 日收盘价 ≥ 转股价 130%。
- **转股溢价率 24.77%** 意味着债主**当前不愿主动转股**（债价 160.36 vs 转股价值约 128.5）；**强赎是逼其转股的唯一工具**。
- 一旦计数走完，11.05亿转债对应约 **1035万股** 需转股，按现价约 **14.2亿元** 的潜在股票供给 ≈ 本票近20日均额（4.01亿）的 **3.5 倍**。
- → 形成"**越涨越重**"的负反馈：股价上行推进强赎计数，计数推进供给预期。**这是可从条款直接算出的结构性阻力。**

### 2.3 建议改动

在 S03/S04（以及任何输出"距高点/阻力位"的策略）的明细里**增加一个可选阻力项**：

```
若 该票存在存续可转债 且 已进入转股期：
    输出 强赎触发价、距强赎触发价%、潜在转股股数/近20日均额（倍数）
    若 现价 ∈ [强赎触发价 × 0.95, 强赎触发价 × 1.05]：
        标记 "转债强赎带" 并对入选做降权（建议初值 ×0.8）
kill-switch：关闭即只输出信息、不降权
```

**先只做"输出信息"、后做"降权"**——分两步接生产，第一步零风险（纯增字段），第二步再靠回测定系数。

### 2.4 建议回测口径

- **样本**：历史上"存续可转债 且 已进入转股期"的票，按 `现价 / 强赎触发价` 分桶（<0.9 / 0.9~0.95 / **0.95~1.05** / >1.05）。
- **对照组**：同期无可转债、但技术状态相近（距250日高分位相近、bias20 相近）的票。
- **指标**：H5/H10 均值收益、**最大上行幅度**（这条比均值更能体现"天花板"效应）、胜率。
- **达标判据**：若 `0.95~1.05` 桶的 H5/H10 收益与最大上行幅度**显著低于**对照组，则支持降权；否则只保留信息字段、不降权。

### 2.5 ⚠️ 附带的数据质量问题：转股价两源冲突

| 源 | 转股价 | 推出的强赎线(×1.30) |
|---|---|---|
| 项目采集器 `equity_financing`（`详情已取=true`） | **106.72**（另记初始转股价 111.94） | **138.74** |
| 外部核验（集思录 / 巨潮中报） | **110.58** | **≈143.75** |

差 3.6%，推出的强赎线差 **5.0 元**；而 09-03 最高价 139.17 恰好落在两者之间——**按采集器口径今日最高已越线，按外部口径还差 4.8%**。

**建议**：核对 `equity_financing` 的 `转股价` 字段是否随**分红除权/向下修正**同步刷新，并加断言：
- `转股价 ≤ 初始转股价`（下修与分红只会调低，不会调高）；
- `转股价` 与最近一次「转股价格调整公告」一致；
- `强赎触发价 == round(转股价 × 1.30, 2)`（内部一致性）。

**在修好之前，下游使用应按"强赎触发带 = [min(两源), max(两源)]" 的保守区间处理**，这也是 2026-09-03 选股时的现场处置方式。

### 2.6 ⚠️ 附带的第二个数据质量问题：解禁块 `_pct` 字段存的是**比率**（差 100 倍）

`equity_financing` 解禁明细返回（688612，2026-09-03 实采）：

```json
{"解禁日": "2027-01-25", "解禁数量_股": 162047094.0, "解禁市值_亿_sina": 55.015,
 "占流通市值_pct": 0.631271902543, "占总市值_pct": 0.386577932832,
 "限售股类型": "追加承诺限售股份上市流通"}
```

**按字段名直读** → "占流通 0.63%、占总市值 0.39%"，结论=**可忽略**。
**核验** → 688612 市值 144.95亿 / 价 33.70（09-02口径）→ 隐含总股本 **4.301 亿股**；`162,047,094 / 4.301亿 = 37.7%`，与 `占总市值_pct = 0.3866` **吻合**。旁证：`解禁市值_亿_sina = 55.015亿` 对 144.95亿市值本身就是 38%。
→ **这两个字段存的是比率（0.3866 = 38.66%），不是百分数。**

**风险方向**：**系统性低估解禁压力 100 倍**。本次分析初稿即按字面写成"占流通 0.63%"，核验后订正为"≈流通盘 63.1% / 总股本 37.7%"——**一个会把"解禁三分之一总股本"读成"解禁千分之四"的误读**。

**建议**
- 字段改名 `占流通市值_ratio` / `占总市值_ratio`，或把值 ×100 与名字对齐（**二选一，但必须与 `固定一问.有临近解禁_90日` 的阈值判断口径同步改**，否则会引入新的不一致）。
- 加内部一致性断言：`解禁数量_股 / 总股本 ≈ 占总市值_ratio`（容差 5%）；`解禁市值_亿 / 总市值_亿 ≈ 占总市值_ratio`。
- 同一块内 `潜在摊薄_pct` 当前为 `null`（安克转债那条也是 null），一并核对是否同类口径问题或未实现。
- 该块已随 commit `0ffb483` 进 `record` 的 `financing` 顶层块并作为"固定一问"进入每日 SOP，**下游会长期读它**，建议优先修。
