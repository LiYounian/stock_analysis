### 2.1 `行业=None` 根因（最关键，牵连板块轮动 + 财报路由）
- 三条行业来源对 000712 恰好都失灵：①人工池 `stock_pool.industry`=None；②`board.board_of()`=None(**文件不存在**)；③`industry_history.industry_at()`="金融业"✅有值**但板块轮动专家根本不读它**。
- 钉死根因：`board.fetch_membership_baostock()`(`board.py:132-159`，落 `board_membership/all.json`)**从没跑过** → `board.load_membership()` 直接 `FileNotFoundError` → `board_of()` 恒 None。
- **数据其实齐活**：申万板块指数 `board_kline` 在盘(1323文件，RRG能算)、`industry_history` 在盘(所以 industry_asof 有值)，唯独这份"个股→行业"映射没采。
- 连带影响：财报专家的行业路由(`analyzer.py:64,105` 用 board_of 兜底命中电子/半导体)也失效——fabless 半导体从不命中电子专家(代码注释 `analyzer.py:76-97` 已自认此坑)。

## 3. 改进提议（只提议；按成本排序）

### B. 修行业映射（近零成本、收益最大、**优先单独做**）
1. 跑一次 `board.fetch_membership_baostock()` 落 `board_membership/all.json`（baostock 自有协议，**不受东财墙影响**，一次全A查询）。
2. `build_min_record` 的 `meta.industry` 回退链补 point-in-time 源：`stock_pool → board_of → industry_history.industry_at(code, as_of)`（去前视，富集侧已有 industry_asof，全A 直接复用）。
3. 板块轮动专家在 `meta.industry/sector` 皆空时，除 board_of 外**也读 `meta.industry_asof`**（`experts.py:216-227` 回退加一档）。
4. `industry_map` 补"证监会门类→申万一级"细化（**实测坑**：门类名 `to_sw("金融业")=None` 太粗对不齐，需补"金融业→银行/非银金融"等；细分名如"证券""C39"能对齐）。
> 收益：板块轮动从~100%弃权→大面积激活，财报行业路由同时修好。成本≈零（本地/baostock，不烧东财额度）。

### A. 补齐资金流/情绪/事件覆盖（**分层补采，不做全A**）
- **两阶段**：先用现有4专家跑出候选 top_k(200~300)，**只为候选票**补采 fundflow/sentiment/events + 跑 factor precompute，重组8专家合议二次排序取 Top N。全A 全量补采太贵、不可行。
- **多因子最便宜**：全A扫描前**先跑一次 `factor.score.precompute`**（纯本地横截面），多因子即可在全A发声，无需补采。
- ⚠️ **诚实说明**：**东财 fflow 接口本机被墙(curl 56)**，资金流即使补采也大概率继续缺失——需先解决数据供给（换源 baostock/THS 资金流，或接受资金流长期弃权）。**别指望补采能救活资金流**。这与 [资金流融资盘甄别](资金流融资盘甄别.md) 的两融数据供给是同一个"资金数据基建"问题，建议一并规划数据源。

## 4. 回测口径（A/B 验证"专家补全后合议判别力是否提升"）
- **样本**：已闭环历史交易日(现有 `data/analysis/2026-08-*` 约15+日)，每日全A逐票合议取 Top N；对每票算 as_of 后 T+5/T+10 前瞻收益(**复用现有 `forward_scorecard.csv`/`predict_lines_*` 前瞻记分卡基建**)。
- **A/B 两臂**：
  - A(现状)：4专家合议(技术三件套+财报)。
  - **B1=A+板块轮动**(仅补 board_membership，**零采集成本、纯修bug、最干净的对照**，**建议先只测这个**——最能回答"板块轮动到底有没有判别力")。
  - B2=B1+多因子(补 precompute)；B3=+资金流/情绪(数据供给受限，单独评估、备选)。
- **对比指标**(补全前vs后，同批日期同 Top N)：①Top N 组合 T+5/T+10 平均前瞻收益+胜率；②综合分对前瞻收益的 Rank IC / IC_IR；③相对全A基准超额收益；④Top N 成分变化率(板块轮动是改排序还是仅改边角)。
- **达标标准**：B 相对 A，IC/命中率/超额收益**至少一项显著提升、其余不劣化**(与 eval_v3 多维综合判定一致，别只用单指标)；且弃权率明显下降才算"名副其实的合议"。
- **kill-switch**：B 若核心指标劣化超阈值，`config`(`tools/config/strategy.py THRESHOLDS['合议']`)一键切回现状专家组，无需改代码路径。

## 5. 待统筹决策
- **建议排期**：先做 **B（修行业映射）**——零成本、纯修bug、收益最大，单独一个实现窗 + B1 回测即可验证板块轮动价值。
- A（分层补采）依赖"资金数据基建"（换源解东财墙），与 fundflow 两融提议合并规划数据源后再做。
