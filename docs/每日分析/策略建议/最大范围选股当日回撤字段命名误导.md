# 策略建议 · 「最大范围选股」`当日回撤%` 字段命名误导（符号与语义相反）

> 状态：**提议**（只提议、不改代码）。来源：2026-09-04 盘后选股，读该视图时被此字段直接带偏。⚠️ 非投资建议。

## 问题

`data/analysis/<日>/最大范围选股.json` 的入选明细里有一个字段叫 **`当日回撤%`**，实际存的是规则 C 项 `(REF(C,1)/C − 1) × 100`，即**"昨收相对今收的偏离"**。

于是它的符号与字面语义**完全相反**：

| 该字段值 | 字面读作 | 实际含义 |
|---|---|---|
| `-9.08%` | 今天跌了 9% | 今天**涨了 9.99%**（603162 海通发展涨停） |
| `-9.92%` | 今天跌了 9.9% | 今天**涨了 11.02%**（688061 灿瑞科技） |
| `+1.57%` | 今天涨了 1.6% | 今天**跌了** 1.5% 左右 |

证据（2026-09-04 实测，与 `data/master/kline/` 日线对账）：
- 603162：`当日回撤% = -9.08`，实际 `pct_chg = +9.99%`（prev_close 13.31 / close 14.64 − 1 = −9.08%）。
- 688061：`当日回撤% = -9.92`，实际 `pct_chg = +11.02%`。
- 605296：`当日回撤% = -6.11`，实际 `pct_chg = +6.51%`。

**实际造成的误判**：本次选股第一遍读该视图时，把 8 只"三口径命中"的票读成了"今天全部大幅回撤 −4% ~ −10%"，据此差点判定为"放量突破后当日崩塌、属经验 #18 的危险形态"。回原始日线对账后才发现事实**完全相反**——它们是在全A等权 −0.298% 的普跌日里**逆势大涨 4%~11%** 的强势股。一个字段名把结论推向了 180° 的反面。

## 建议

1. **改名**：`当日回撤%` → `昨收较今收偏离%`（或直接 `REF1_over_C_minus1_pct`），字段名与公式一致。
2. **或改符号**：既然规则本意是"今日不能是大阴线"（`(REF(C,1)/C−1) ≤ 0.04` 等价于今日跌幅不过大），那就直接存 `当日涨跌幅% = pct_chg`，语义最直白，阈值改写成 `pct_chg ≥ −3.85%` 的等价形式。
3. **过渡期兼容**：若不便改名，至少在该视图的 `规则` 字符串里显式写一句"**`当日回撤%` 为负 = 当日上涨**"，避免下游（人或模型）按字面读。
4. 同类自检：其它视图里凡是形如 `REF(C,1)/C − 1` 的派生量，都应统一为"以今日为基准的涨跌幅"口径，不要混用两种基准方向。

## 对应经验

对应经验 #16（产出必须自证口径/时点）的延伸：**字段名本身就是一种口径声明，命名与公式不一致等于向下游发假口径**。建议在经验沉淀里补一条"读策略视图的派生字段必须与原始日线对账一次"。
