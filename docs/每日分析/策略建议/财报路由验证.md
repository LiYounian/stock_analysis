## 0. 一句话结论

**财报路由可以干净地从被证伪的板块轮动里摘出来单独复活，且几乎零成本。**
核心修复只需两样东西：**（a）跑一次 `board.fetch_membership_baostock()` 落 `board_membership/all.json` 数据文件；（b）`industry_map` 补粗口径行业名映射（存档分支 commit `b310458`）**。这两样都**不触碰**板块轮动专家（被证伪的那条链是另一个 commit `cf643c9`）。验证口径**不用合议 IC**（那衡量不了路由对错），改用**路由命中率 + 误路由率 + 金融业特判触发率**这类"数据质量/正确性"指标，可在标注集上离线判定，不需要跑大回测。

## 2. 财报路由 vs 板块轮动：耦合关系 + 如何摘出

### 2.1 两者的消费路径其实独立

- **财报路由**（`tools/analysis/financial/analyzer.py`）：`_industry_key(code, industry)` / `_is_financial(code, industry)` 先用传入的 `industry`，**否则自己内部回退 `board.board_of(code)`**（`analyzer.py:64,105`），再经 `industry_map.to_sw()` 对齐申万一级，路由到对应行业财报专家；半导体另有 `_in_semi_universe()`→电子 兜底（`analyzer.py:73-110`，已在主仓）。
- **板块轮动**（`tools/analysis/experts.py:250` `expert_板块轮动`）：读 `meta.industry` → `board_of` → 送 `rrg` 算 RRG 象限。

**关键洞察**：财报专家**不依赖** `build_min_record` 把 `meta.industry` 塞进来——它内部就会 `board_of(code)` 兜底。所以只要 `board_membership/all.json` 存在，`board_of()` 返回真实行业名，财报路由**自动修好**，完全不需要动 `screen_council.py`，也就完全不碰板块轮动。

### 2.2 唯一的耦合点，以及为什么必须避开它

存档分支的 `fc815c1` 把 `meta.industry` 用回退链填满（原本 board_of=None 时保持 None）。但 `meta.industry` 是**板块轮动专家和财报专家共读的字段**——一旦填满，主仓那个"`meta.industry` 有值就发声"的板块轮动专家（`experts.py:259`）会被**顺带激活**，而这正是 17 日回测证伪的东西（IC 翻负、10 日收益 +0.88%→-1.78%）。

**结论：`fc815c1` 是财报路由与板块轮动的耦合源，复活财报路由时应当跳过它。** 财报路由不需要 `fc815c1`（理由见 2.1）。

### 2.3 干净摘出方案（推荐）

复活财报路由 = 只取 **数据文件 + `b310458`**，不取 `fc815c1`、不取 `cf643c9`：

1. 跑一次 `board.fetch_membership_baostock()` 落 `board_membership/all.json`（baostock 自有协议，**不受东财墙影响**，一次全 A 查询，约 94% 覆盖）。
2. cherry-pick / 重放 `b310458`（`industry_map` 补粗口径映射）——纯映射表，无副作用，`to_sw()` 对 baostock 返回的证监会行业名对齐更稳。
3. **不动** `screen_council.build_min_record`、**不动** `expert_板块轮动`。板块轮动专家继续维持主仓的"~100% 弃权"证伪-安全态。

> 若将来出于别的原因确实要在 `build_min_record` 填 `meta.industry`（`fc815c1`），必须**同时**用 config kill-switch（`tools/config/strategy.py THRESHOLDS['合议']`）关掉板块轮动专家，否则会重新激活被证伪的链。但复活财报路由**不需要**走到这一步。

## 3. 值不值得复活

**值得，优先级中。** 理由：

- 成本≈零：一次 baostock 查询 + 一张纯映射表，不烧东财额度、不触网重复。
- 修的是真 bug：主仓合议全 A 路径上，**除半导体外所有行业的财报专家都拿不到行业**（board_of 恒 None），银行/非银被通用红旗逻辑误伤（如对银行套用"高负债红旗"这种对金融业无意义甚至错误的判定，`analyzer._is_financial` 的金融业特判**从来没触发过**）。
- 风险可控：财报路由只改"财报专家用哪套行业口径判红旗/给分"，不改综合分权重结构，且能干净地不碰已证伪的板块轮动。

**但要诚实标注两点局限**：
- baostock 的 `industry` 是**证监会行业口径**，与申万一级不完全对齐；粗桶（制造业/金融业等）经 `to_sw` 会返 None → 那部分票财报路由仍走通用兜底（不会误路由，但也没修好）。真实修复率取决于 baostock 口径能对齐到申万一级的比例。
- 半导体已有 `semi_universe` 兜底，复活的增量主要在**非半导体行业**（银行/非银/医药/食品饮料/地产等有专门行业财报专家的板块）。

## 4. 针对性验证口径（A/B，**不跑大回测**）

财报路由的价值**不能用合议 IC / 前瞻收益衡量**（路由对错是数据正确性问题，不是选股 alpha 问题）。改用离线、可判定的"路由质量"口径：

**两臂**：
- **A（现状/主仓）**：无 `board_membership` 数据 → `board_of` 恒 None → 财报路由仅半导体走 semi_universe 兜底，其余行业无路由。
- **B（复活）**：有 `board_membership/all.json` + `b310458` 粗口径映射。

**标注集**（ground truth，一次性构造，不触网）：取有明确申万一级归属的样本——① `semi_universe` 178 只半导体（→电子）；② 指数成分/已知名单里的银行、非银金融、医药生物、食品饮料各一批（可用现有 `stock_pool` 里已标行业的票，或申万一级成分快照）。

**指标 + 达标标准**：
| 指标 | 口径 | 达标标准 |
|---|---|---|
| **① 路由命中率** | 标注集里 `_industry_key(code)` 返回值 == 真实申万一级 的比例 | A≈0%（半导体除外）；**B 在"可对齐"子集上 ≥ 85%** |
| **② 误路由率（精度）** | 路由到**错误**行业专家的比例（粗桶应返 None/弃权，而非乱指一个行业） | **B = 0**（宁可弃权不可错路由；粗桶 to_sw 返 None 即合格） |
| **③ 金融业特判触发率** | 标注集里银行/非银样本，`_is_financial()` 返 True 的比例 | A≈0% → **B ≈100%**（这是"银行不再被通用红旗误伤"的直接证据） |
| **④ 覆盖率** | 全 A 里 `board_of()` 非 None 的比例 | 报告即可（预期 ~94%，baostock 口径上限） |

**判定**：B 相对 A，①③显著提升、②=0，即判"财报路由修复成立、可接生产"。**全程不需要前瞻收益**。

**可选的二级监控（非门槛）**：接生产后，观察合议 top-N 的 T+5/T+10 前瞻收益有无异常劣化（复用 `forward_scorecard.csv` 基建）——只作 kill-switch 触发监控，不作达标依据（因为财报路由主要影响判别质量而非直接 alpha，且样本区间短）。

**kill-switch**：财报路由若上线后发现误路由，删/重命名 `board_membership/all.json` 即回退到 semi_universe-only 态（`board_of` FileNotFoundError → None，优雅降级），无需改代码。

## 7. 实现 + 验证结果（2026-09-02 落地，分支 `worktree-agent-a61a2c768eb4ff1b1`）

### 7.1 改了什么（严格按 §2.3 干净摘出方案）

1. **落 board_membership 数据**：跑 `board.fetch_membership_baostock()` 生成
   `data/raw/<日期>/board_membership/all.json`（baostock 证监会行业，**5212 只**，全A 约 94%；
   空的多为退市/僵尸股）。**数据产物、gitignore、不入库**。
2. **重放 `b310458` 纯映射表**：cherry-pick `industry_map.CSRC_CATEGORY_TO_SW`（证监会门类大类/
   GICS 粗名→申万一级，无歧义者；跨多申万的粗桶如 制造业/金融业/采矿业 故意返 None）。
   纯数据无副作用，**不取** `fc815c1`（build_min_record 填 meta.industry）/`cf643c9`（板块轮动读 asof）。
3. **修半导体池优先级 bug（数据落地暴露的连带问题）**：board_membership 落地后 `board_of` 不再恒
   None——而证监会门类把 **60/178** 只 fabless 芯片设计/半导体设备票误分到 软件(I64/I65)/机械(C35)。
   原 `_industry_key` 把半导体池成分兜底排在 `board_of` 之后，导致这些票落到 计算机/机械设备 专家。
   修：申万二级 801081 半导体池对「电子」是权威口径，**提前到 board_of 之前**命中（仍让上游显式
   industry 最优先）。这是"复活财报路由"必需的正确性修复，不触碰板块轮动。

1. **未触碰任何板块轮动代码/配置**：改动仅 `industry_map.py`（纯映射）、`analyzer._industry_key`
