# 策略建议 · 高波动票入场闸门加"开盘跳空作废"保护（两侧对称：高开作废 + 低开作废）

> 状态：**提议**（只提议、不改代码）。来源：2026-09-04 盘尾复盘 300857 协创数据（高开侧）；**2026-09-17 盘尾复盘 301183 东田微补低开侧**。⚠️ 非投资建议。

## 问题
入场闸门形如"放量站上 X 价（且量比≥Y）"，对**高波动票**会退化成"买在开盘最高点的触发器"。
- 证据（一行）：300857（ATR14 5.21%、年化波动 86.2%）09-04 开盘 269.98 直接跨过 269.15 闸门、最高仅 269.99，随后单边下杀 5.5%、收盘失守 MA20，α −4.58pp。
- 与 09-03 002811"闸门太严→从不触发→踏空"（催生经验 #13）**完全对称的另一种失败**：一个太松、一个太紧，都是纯价格阈值闸门在极端波动下的缺陷。

## 建议
1. 对 `ATR14 > 5%`（或年化波动显著偏高）的票，入场闸门增加一条硬约束：**"若以跳空方式在闸门价上方开盘（open ≥ 闸门价），则当日闸门作废、改判次日"**。
2. 或把闸门语义从"站上某价"改为**"回踩不破 + 再次放量上攻"的二次确认**（避免开盘一跳即触发）。
3. 产出层面：高波动票的入场条件必须**显式标注 ATR/波动分位**，让下游知道该票适用跳空保护。

## 补充（2026-09-17）：回踩限价闸门的**低开阴跌**对称漏洞

上面 #20 治的是"站上某价"闸门的**跳空高开**退化；**回踩限价闸门有对称的另一侧漏洞——低开阴跌接飞刀**。

- 问题：入场闸门形如"挂 A~B 回踩限价、**跳空高开>N%作废**"，只防了高开，没防**低开**。当票**低开且落在限价区间**时，回踩限价照常成交，但若股价**低开一路走弱**（不企稳、不反弹），就等于"买在下跌途中"——"等回踩"退化成"接下跌"。
- 证据（一行）：301183 东田微（极端超买 bias20 +27.7 的 gap-fade 票）09-17 在高低切/回吐日**平开 300.98 落 300.6~303.7 区间→回踩限价成交**，随后低开走弱收 −1.76%（低 −3.8%）、绝对 −2.17%，为当日唯一实亏单（β +0.12% 微正未拖累、纯个票 α 负）。
- 建议（与高开侧对称）：
  1. 回踩限价加**低开保护**：**"若低开且不企稳（低开且跌破当日均价/前一日低点、或未放量收回），则回踩限价当日作废、不接"**；把"开盘价落区间即成交"升级为"回踩后需有企稳/回升的二次确认再入"。
  2. **触发类型优先级**：优先"量能自证型触发（放量收阳/主买翻正）"而非"价格假设型触发（等回踩反弹）"——前者用当日可观测量能证实启动，后者押注未必成立的价格路径。同日对照：秋田微"需放量收阳"闸门 firing→+18.92%，东田微"回踩限价"接飞刀→−2.17%。
  3. 极端超买 gap-fade 票在高低切/回吐日**两侧都要防**（高开回落 #20 + 低开阴跌本条），宜要求"低开企稳 + 再放量上攻"的二次确认。
