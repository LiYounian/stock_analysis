# 策略建议 · 策略0合议：专家"弃权"未在分值/置信度上体现，导致纯技术分被当成多专家共识

> 来源：2026-09-02 选股分析——301246 宏源药业以 **综合分 0.725 排全A第一**入选策略0合议，但当天公司自己公告"Q2 经营业绩环比阶段性下滑"、主力资金净流出1589万（占比-12.71%）、所属锂电板块领跌。我判"观望"，与系统分歧最大。
> 状态：**待统筹排期**。
> 优先级：中。
> ⚠️ 非投资建议。本文档只提议，不改代码。

---

## 1. 动机

`data/analysis/2026-09-02/策略0合议.json` 的 Top1/Top2（301246 宏源药业、603557 *ST起步）综合分均为 **0.725**，`council.experts` 里实际发声的只有两个：

- 「超买超卖」专家：方向看多，**强度 1.0、置信度 1.0**，依据"超卖·共振3"
- 「拐点」专家：方向看多，强度 0.45、置信度 1.0，依据"拐点超跌待反弹·评分45"

而视图自己的口径说明写明：「**资金流/多因子/情绪/事件因无全A数据自然弃权**」。
→ **0.725 实质是"两个纯技术方向专家的一致意见"，不是"多专家合议"。** 但分值形式上与"六个专家一致看多"无法区分，`综合分` / `排序分` 里没有任何字段告诉下游"这次只有2个专家投票、且都属同一类（技术方向）"。

**后果**：301246 的 0.725（全A第一）会被"单策略极值(高)"这个选股维度直接采信（经验#8），而它的技术超卖恰恰是被**当天的业绩降温公告解释**的——"跌多了"和"该跌"在纯技术口径下长得一样。
**同一系统内部还自相矛盾**：per-stock 的综合 `prediction.买卖倾向` 对同一只票给的是 **"观望"**（超跌+1、趋势偏空-1、**主力净流出-1**，净 -1），因为它读到了 `fundflow`（今日主力净流入 -1589万）。**per-stock 口径是对的，全A合议口径是错的**，差别就在"能不能拿到资金/事件数据"——而这个差别没有反映在合议分的置信度里。

这与经验 #4（"系统 events/sentiment 是加工分，可能建立在残缺新闻上，要存疑"）同源，但暴露的是**更上游的问题：合议机制不区分"专家看了数据后保持中性"与"专家没数据所以弃权"**。

## 2. 诊断

1. **弃权与中性未区分**：一个专家"有数据、判中性"（真实信息：无方向）与"无数据、弃权"（无信息）在加权合议里若都按缺席处理，剩余专家的权重会被**隐式放大到 100%**。本轮 2/6 个专家发声 → 这两个技术专家实际拿到了全部权重。
2. **置信度只在专家级、没有合议级**：单个专家有 `置信度`（本例都是 1.0），但合议输出只有 `综合分`/`排序分`/`综合方向`，**没有"参与专家数 / 覆盖的能力类型数 / 口径多样性"这类合议级置信度**。
3. **全A口径的数据可得性天然不均**：视图已如实标注 `财报覆盖 398`（5196 有效样本里只有 398 有财报块）——即 **92% 的票在合议时连财报质地专家都不发声**。所以"全A合议"事实上在绝大多数票上退化为纯技术合议，但排序时与那 398 只"有财报背书"的票**混在同一张榜里直接比大小**。
4. **与已知问题的关系**：[合议专家覆盖补全](合议专家覆盖补全.md) 关注的是"如何让更多专家有数据发声"（治本、成本高、依赖数据落地）；本条关注的是"**在专家仍然弃权的现实下，如何不让分值撒谎**"（治标、成本低、可立即做），两者互补而非重复。

## 3. 改进提议（只提议）

1. **合议输出增加"参与度"字段（核心提议，改动小）**：在每条 top 记录里加
   - `参与专家数` / `弃权专家数`（及弃权原因：无数据 / 数据不足）
   - `覆盖能力类型`（方向 / 质地 / 资金 / 事件 …）与 `口径多样性`（发声专家覆盖了几类）
   - `合议置信度` = 由上述派生（描述性：**发声专家越少、覆盖口径越单一 → 合议置信度越低**）
   这样 301246 的 0.725 会带上"参与2/6、口径单一(全为技术方向)、合议置信度低"的标签，下游与分析师一眼可辨。
2. **排序上分层，而不是同榜比大小**：按 `合议置信度` 分层排序（高置信层在前，低置信层在后），或对低置信条目做**软降级沉底**（保留展示 + ⚠），避免"纯技术超卖分"与"技术+财报+资金多口径一致"的票在同一张榜上直接竞争 Top1。
3. **弃权 ≠ 中性，显式建模**：合议加权时把"无数据弃权"从分母里剔除的同时，**对剩余权重的放大设上限**（描述性：发声专家数低于门槛时，综合分整体收缩向中性），防止 2 个专家拿满权重直接给出 0.725 这种高分。
4. **同系统对账（低成本、高价值）**：对同一只票，若 **per-stock `买卖倾向` 与 策略0合议 `综合方向` 相反**，在视图里打一个"内部分歧"标记。本轮 301246 就是这种情况（合议看多 vs per-stock 观望且含主力净流出-1），有这个标记分析师会立刻去查原因。**这条建议独立于其他三条，可单独先做。**

## 4. 回测/验收口径

- **主验收（分层排序有效性）**：历史重放，比较"原综合分 TopK"与"按合议置信度分层后的 TopK"的 **T+1/T+5/T+10 前瞻收益与踩雷率（maxDD ≤ -12%）**。达标：**高置信层的前瞻表现应显著优于低置信层**——若两层无差异，说明"合议置信度"这个构造没有信息量，应放弃该提议（这是本提议的**可证伪点**）。
- **一致性验收**：`参与专家数 + 弃权专家数 == 专家总数`；`财报覆盖` 与"财报质地专家发声数"一致。
- **不劣化验收**：对那 398 只有财报块的票（多口径发声），分层前后排序**基本不变**——证明改动只惩罚低置信条目，不打乱高置信条目。
- **对账标记验收**：构造/挑选"合议看多 + per-stock 买卖倾向偏空"的样本（301246 即是），断言"内部分歧"标记命中；反之一致的票不误标。
- **kill-switch**：分层排序与权重收缩上限都应可配置、可一键关回原纯综合分排序。
- **诚实定位**：本条是**置信度校准 / 减损层**，不制造 alpha；预期收益体现在"少把纯技术极值当强信号"，与 [多策略命中同源信号闸门](多策略命中同源信号闸门.md) 是同一思路（**要求证据来自独立口径**）在不同环节的落地。

## 5. 待决（需统筹拍板）

- "合议置信度"是新增字段还是直接改 `排序分`？建议**先只加字段 + 打标签（观察期）**，确认它与前瞻表现相关后再动排序，避免一次性改动排序口径造成断层。
- 与 [合议专家覆盖补全](合议专家覆盖补全.md) / [财报路由验证](财报路由验证.md) 的排期关系：后两者是"让专家有数据"，本条是"没数据时别撒谎"。**建议本条先做**（成本低、独立、且能直接量化出"覆盖补全"到底改善了多少）。
- 弃权时的权重收缩函数形式与门槛（发声专家数 < 多少开始收缩）需实现窗给具体口径。
