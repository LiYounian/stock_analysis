# 策略建议：financing 采集对个别票失效 → 固定一问漏报关键供给面（转债强赎/减持）

> 提出日：2026-09-14（每日选股分析发现）。**只提议，不改代码**。⚠️ 非投资建议。

## 现象（2026-09-14 逐票发现）

**603730 岱美股份**：per-stock record 的 `financing` 段返回 **None**（采集失效/缺口），导致"固定一问"（有无存续可转债/推进中定增/临近解禁）**没有被数据回答**。但经 baidu_news 原始消息面发现：
- **09-10「岱美转债预计满足赎回条件」提示性公告** → 存在存续可转债、强赎将触发转股摊薄（供给面利空）；
- **09-02 姜银台、姜明减持计划届满，分别减持 1250.48 万股 / 758.5 万股** → 大股东减持兑现（供给面利空）。

即：**financing 段为 None 时，逐票若只信数据层就会把一只有"转债强赎摊薄 + 大股东减持"的票当成供给面干净**，而供给面恰是该票（今日 −3.81% 破位）的核心变量（#22）。

对照：688262 国芯科技 financing 段"定增"源标注"qbzf+公告检索不可得"（源状态降级但结构存在）；603730 是整段 None。

## 风险

固定一问（转债/定增/解禁）是经验里的**硬性一问**，靠它兜住"存量融资与解禁是中期变量、不能靠临场想起"。若 financing 采集对某票静默失效（返回 None 而非显式"数据不可得"标记），逐票分析容易默认"无 → 供给面干净"，与真实相反。

## 建议（供统筹/策略维护者评估）

1. **financing 段区分"确认无(false)"与"数据不可得(None/降级)"**：None 时逐票模板应强制走消息面/公告兜底核验，不得默认"供给面干净"。可在 record 里对 financing=None 的票打显式 `financing_unavailable=true` 告警，逐票 SOP 见此标记即触发 baidu_news/announcement 补采转债赎回/减持公告。
2. **排查 603730 financing 采集失效根因**：是接口对该票 code 失败、还是聚合阶段异常吞掉。若是个别票偶发，加入重试/降级留痕；若是系统性（如可转债源对某类 code 覆盖不全），补源。
3. **反转低换手组合（策略10）叠加供给面否决/降级**：603730 被反转低换手选为 top1，但策略只看量价反转 + 低换手，未计入转债强赎/大股东减持 → 误导性入选。可在该策略入选后过一道"临近转债强赎 / 近期大额减持"软降级闸（类比反转否决层对事件博弈的降级）。

## 关联经验/建议
