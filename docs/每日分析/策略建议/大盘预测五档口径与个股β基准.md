# 策略建议 · 大盘预测：五档标签在普跌日给出"大涨"，且选股环节的个股β基准选错了标的

> **状态更新（2026-09-03 实现）**：提议 1（重命名五档为概率口径）、2（显式声明 β 基准，默认 proxy）、3（风格背离标记）**已实现并接生产**；实现与验收见文末「6. 实现与验收结果」。可选项 4（幅度分档解耦）/5（价格-舆情背离入档）暂未做。

> 来源：2026-09-02 选股分析——`market_forecast.json` 给沪深300 T+1 `p_up = 0.6697` 并映射到五档最高档 **"大涨"**，而当日实况是**沪深300 -1.38%、个股中位数 -1.02%、涨1156/跌3537、近3900只飘绿**；同一份产出里"全A等权代理"只有 0.5477（震荡）、T+5 更是 **0.4869（<0.5）**。
> 状态：**待统筹排期**。
> 优先级：中（大盘预测v0.5 已接生产并被选股/复盘每日消费，标签口径直接影响每日买入表态）。
> ⚠️ 非投资建议。本文档只提议，不改代码。

## 1. 动机（两个独立问题）

### 问题A · 五档标签把"概率"当成了"幅度"
当日 `targets.hs300.horizons`：

| 期限 | p_up | direction | bucket | bucket_idx |
|---|---|---|---|---|
| T+1 | 0.6697 | 偏多 | **大涨** | 4 |
| T+5 | 0.6659 | 偏多 | **大涨** | 4 |

`p_up = 0.67` 表达的是"**上涨的概率**"，而"大涨"这个词在使用者读起来是"**上涨的幅度**"。0.67 的上涨概率完全可以对应"小涨0.3%"，两者是不同维度。经验沉淀已明确 v0.5 方向命中率约 55%，**在这个命中率下把最高档命名为"大涨"，与模型的真实分辨力不匹配**，容易让下游（尤其中小模型分析师）在普跌日给出过于激进的买入表态。这与经验 #10 刚刚吸取的教训（09-01 选的5只在09-02普跌日全绿，因为选股时没做β判断）方向相反——**标签本身在鼓励高估β**。

### 问题B · 选股用的个股β基准选错了标的
同一份产出里两个标的给出的结论几乎相反：

| 标的 | T+1 p_up | T+5 p_up | T+5 技术/广度贡献 |
|---|---|---|---|
| 沪深300 | 0.6697（偏多） | 0.6659（偏多） | 技术 +0.3475 / 广度 +0.0015 |
| **全A等权代理** | 0.5477（震荡） | **0.4869（<0.5，偏弱）** | 技术 **-0.1227** / 广度 **-0.1207** |

而本轮选出的 5 只票市值 20~230 亿，**全部是中小盘**——它们承担的β显然更接近"全A等权"，而不是权重股主导的沪深300。
当日实况也印证了这一点：沪深300 -1.38%，但**深成指 -1.88%、创业板指 -2.39%、个股中位数 -1.02%**，越小盘越弱。
但机制文档与定时任务的措辞是"优先读 market_forecast.json 作量化β背景"，**没有指定用哪个 target 作个股β基准**。分析师若默认读第一个（hs300）就会系统性高估中小盘的β，正好踩进 #10 想避免的坑。

## 2. 诊断

1. **档位映射是概率→标签的单调映射，未引入幅度信息**：`bucket/bucket_idx` 由 `p_up` 单调映射而来（0.67 → idx 4 → "大涨"），但产出里其实已有 `factor_contrib` 与广度快照，**具备区分"高概率小幅"与"高概率大幅"的原料**，只是没用。
2. **两个 target 的适用范围未声明**：`notes` 里只对全A等权代理标了"含幸存者偏差，方向研究用，绝对收益勿当真"，**没说"个股β应以哪个为基准"**；反过来 hs300 也没标"仅代表权重股，不代表个股中位数"。
3. **资金流维当日为 0 贡献**：两个 target 的 `factor_contrib.资金流` 均为 **0.0**，`fundflow_snapshot` 显示 `margin_date = 2026-09-01`（SSE市场级两融，盘后披露、已按防未来函数滞后一日）。属设计内降级（`notes` 已说明"历史未采到的日子该维降级中性"），**不是 bug**，但意味着 T+1 的 0.6697 实际只由 技术(+0.3168) + 广度(+0.3132) + 消息面(+0.1062) 三维支撑，**其中广度贡献是把"今天跌得多、破位广"读成超跌修复**——这个逻辑本身合理，但它使"高 p_up"与"刚刚普跌"必然同时出现，从而使"大涨"标签在普跌日**必然**被触发。这是标签命名与模型机理的结构性冲突，不是偶发。
4. **广度背离未被表达**：当日 `net_adv = -0.4967`、`median_pct = -1.0244`，而 `sentiment_snapshot.se_ratio = 0.878`（38利好/2利空）——**价格与舆情严重背离**。这类背离对"反弹能否成立"很有信息量，但没有进入任何输出标签。

## 3. 改进提议（只提议）

1. **重命名五档（最低成本、建议立即做）**：把幅度类词（大涨/大跌）改成**概率类**表述（如"上行概率高/偏高/中性/偏低/低"），或直接保留 `p_up` 数值 + `direction` 三档（偏多/震荡/偏空）而**取消五档**。理由：模型输出的是概率，标签就该说概率；命中率~55% 撑不起"大涨"这种确定性措辞。
2. **产出里显式声明β基准（核心提议）**：在 `targets` 每个标的下加 `适用范围` 字段——
   - `hs300`：`"权重股/大盘β；不代表个股中位数"`
   - `proxy`：`"个股/中小盘β基准（含幸存者偏差，方向用）"`
   并在 `notes` 或新增 `选股用β基准` 字段里**指定默认基准 = proxy**（个股选股场景），hs300 作背景。同步修订 [每日选股分析机制](../../计划/每日选股分析机制.md) 与经验沉淀 #10 的措辞，从"读 market_forecast 定β"细化为"**个股β读全A等权代理，权重股背景读沪深300，两者分歧时以等权为准并标注分歧**"。
3. **增加"分歧标记"**：当 `hs300.p_up` 与 `proxy.p_up` 跨越 0.5 两侧、或差值超过阈值时，输出 `二八分化` 标记。本轮 0.6697 vs 0.5477（T+1）、0.6659 vs 0.4869（T+5）就该被标出来——这正是分析师最需要知道的一句话。
4. **（可选，成本较高）幅度分档与概率分档解耦**：若确实需要幅度标签，应由**条件分位数**（类似 per-stock `情景预测` 的 q7/q50/q93 口径）给出，而不是从 p_up 单调映射。
5. **（可选）价格-舆情背离入档**：把 `net_adv`/`median_pct` 与 `se_ratio` 的背离做成一个标记项，供"反弹成立与否"的定性参考。

## 4. 回测/验收口径

- **1（重命名）**：纯措辞，无需回测；验收=下游文档/定时任务措辞同步更新，且历史 JSON 兼容（旧字段保留或给映射）。
- **2（β基准）主验收（可量化，最关键）**：取历史 N 个交易日，分别用 hs300 与 proxy 的 T+1/T+5 方向作基准，计算**每日选股名单的 α 记分**；断言"**用 proxy 作基准时，α 与个股实际相对表现的相关性更高、残差更小**"。若不成立则本提议应放弃——这是可证伪点。
- **2 辅助验收**：按市值分层（小盘/中盘/大盘）分别算两个基准的解释力，确认"中小盘更贴 proxy"这个假设在数据上成立。
- **3（分歧标记）验收**：历史回放统计"二八分化"标记命中的日子，检验**这些日子里"按 hs300 定β"的选股 α 记分误差是否显著更大**——若是，标记有价值。
- **不劣化验收**：改动不触碰 `p_up` 的计算，A/B 回测（`tools.backtest.market_forecast_backtest`）结果应**逐位一致**（纯标签/字段层改动）。
- **kill-switch**：字段层新增，天然可回退；若做第4条（幅度解耦），需带开关。

## 5. 待决（需统筹拍板）

- 五档是"重命名"还是"取消"？倾向**取消五档、只留 p_up + 三档 direction**——五档在 55% 命中率下提供的增量信息很可能是噪声。
- `proxy`（全A等权代理）自带幸存者偏差，作为个股β基准是否需要先做一次偏差量化（如与中证2000/中证1000对比）？或者直接**改用真实小盘指数**（中证1000/中证2000）替代等权代理作为个股β基准？——这可能是更干净的方案，但需评估采集成本。
- 本条与经验沉淀 #10 的关系：#10 已确立"选股必做β判断、拆α/β、普跌日降档"，本条是**把 #10 落地时"读哪个数"这一步补明确**。建议下一版经验沉淀 #10 的"怎么用"第①条直接改成"读 `targets.proxy`（个股β），`targets.hs300` 仅作权重股背景，两者分歧时标注"。

## 6. 实现与验收结果（2026-09-03）

### 6.1 做了什么（对应提议 1/2/3）

- **提议 1 · 五档口径修正（概率≠幅度）**：新增独立的**概率档**标签集，与**幅度档**彻底解耦。
  - `tools/config/strategy.py`：`大盘预测` 下新增 `概率分档 = ["上行概率低","上行概率偏低","方向中性","上行概率偏高","上行概率高"]`；原 `分档`（大跌..大涨）保留，注释改为**只用于已实现 fwd 收益→幅度档（训练标签/回测）**。
  - `predictor.py`：新增 `_PROB_LABELS` 与 `prob_bucket_label(idx)`（概率口径）；`bucket_label` 明确为幅度口径；`prob_to_bucket` 文档标注返回的是"上行概率分位"。
  - `forecast.py` 每个 horizon 输出：`bucket`/`bucket_idx` 值改为概率口径（不再出现"大涨/大跌"），新增 `prob_bucket`/`prob_bucket_idx`、`bucket_kind="上行概率分位(方向,非涨跌幅)"`、`amplitude_forecast=null`、`amplitude_note`。**`p_up` 计算一字未动**。

- **提议 2 · 个股 β 基准明确化**：
  - `strategy.py` 新增 `个股β基准="proxy"`、`β背景标的="hs300"`。
  - `forecast.py` 每个 target 增 `适用范围`（hs300=「权重股/大盘β；不代表个股中位数」，proxy=「个股/中小盘β基准（含幸存者偏差，方向用）」）；顶层新增 `选股用β基准`（默认 proxy、背景 hs300）。

- **提议 3 · 风格背离（二八分化）标记**：`forecast.py` 新增 `_style_divergence()`，顶层输出 `分歧标记`。逐 horizon 触发条件（任一）：方向档背离 / p_up 跨越 0.5 / |hs300−proxy| ≥ `风格背离差值阈值`(0.10)。触发按方向给类型：背景更强→「权重搭台中小盘偏弱」，基准更强→「中小盘领跑权重滞后」。

### 6.2 验收结果（2026-09-02 重跑 `forecast`）

| 验收口径 | 结果 |
|---|---|
| ①普跌日不再给"大涨" | ✅ hs300 T+1/T+5 由 `大涨` → `上行概率高`（概率口径），`p_up` 仍 0.6697/0.6659（未变） |
| ②proxy 标为个股β基准、hs300 为背景 | ✅ `选股用β基准.默认=proxy`；两 target `适用范围` 已标 |
| ③当日 hs300 偏多 / proxy 偏弱被打"风格背离" | ✅ `分歧标记.触发=True`；T+1「权重搭台中小盘偏弱」(diff 0.122,方向背离)、T+5 同类型(diff 0.179,跨越0.5) |
| 防未来函数 | ✅ 未触碰 `p_up`/训练路径；`prob_to_bucket` idx 逻辑不变 |
| schema/闭环 | ✅ `--as-of --write-analysis` 不崩，正常落盘 |
| 不劣化 A/B | ✅ 纯标签/字段层改动，`p_up` 逐位不变→回测逐位一致（`test_walk_forward_no_future_leak` 保留字节级断言） |

### 6.3 测试（`tests/test_market_forecast_predictor.py`，11 passed）

新增 5 条锁语义：概率档无幅度词且与幅度档解耦、概率档单调五档互异、β基准默认 proxy、09-02 风格背离触发且类型正确（含跨0.5 识别）、反向/一致场景。

### 6.4 是否接生产 & kill-switch

字段/标签层改动，`p_up` 与回测口径零改动，**建议接生产**。回退：`strategy.py` 删 `概率分档`（`prob_bucket_label` 自动回落 `分档`）即恢复旧标签；`适用范围`/`选股用β基准`/`分歧标记` 为纯新增字段，下游不读即无副作用。可选项 4（幅度分档由条件分位数解耦）/5（价格-舆情背离入档）与 §5 待决（是否改用真实小盘指数替代 proxy）留后续。
