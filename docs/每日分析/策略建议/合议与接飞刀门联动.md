## 2. 根因（两层）

### 2.1 合议内部：口径塌缩到 2 维，且拐点专家主导
Top20 每一只的 `参与专家数` 只有 **3~4**、`口径多样性` 只有 **2**（`覆盖口径=["技术","质地"]`）。视图自身的 `口径` 字段已说明原因：

> 「资金流/多因子/情绪/事件因无全A数据自然弃权」

于是"多专家合议"实质是 **技术专家（含拐点） + 财报质地专家** 的两口径合成。而**拐点专家**在这些票上给出「拐点反弹启动·评分80」（000157 的依据是"超跌区(KDJ/RSI/近低点)+25、MACD底背离+20"），**没有任何资金或情绪口径来制衡它**。

**关键的反证据**：000157 在 09-02 **主力资金净流出 1.17 亿元、主力净占比 -34.18%、超大单 -1.13 亿**，成交量 5 日内从 96.8 万手萎缩到 34.8 万手。**资金口径完全反对"反弹启动"，但资金专家弃权了。**

### 2.2 跨策略：广度信息存在，但合议读不到
策略11 同日产出（`指标条件化状态排序.json`）：

```
"市场广度": {"破下轨占比": 0.0148, "接飞刀门槛": 0.02,
             "接飞刀门生效": true, "降权pp": 20.0}
```

策略11 **自己会**对破位候选降权 20pp 并标"接飞刀风险"，但**这个市场级判断没有被任何其他策略消费**。经验 #5 的实证是：

- 孤立破位（平静日）H5 均值 **-0.54%** = 接飞刀
- 全市场恐慌（capitulation）H5 均值 **+3.3%** = 真反弹

→ 同一个"超卖看多"信号，**在两种广度状态下的期望收益差约 3.8pp**。合议对此完全无感。

## 3. 建议改动

在合议排序层（**不改专家本身**）加一个**广度条件化的降权闸**，与现有 veto 汇聚（财报红旗 + 龙虎榜否决）同一位置、同一纯函数风格：

```
若 接飞刀门生效(破下轨广度 < 门槛)：
    对满足以下全部条件的票降权/沉底：
      · council 拐点专家方向 = 看多 且 标签 ∈ {反弹启动, 超跌待反弹}
      · 均线排列 = 空头排列
      · 未站上 MA60
    → 综合分 × 系数（建议初值 0.5，沉排名）或直接沉底
kill-switch：关闭即回到纯合议现状
```

**设计要点**
- **只在接飞刀门生效日生效**——广度确认日（capitulation）反而应该**保留甚至加权**这些票，因为那才是 #5 说的真反弹环境。这是一个**条件化**闸门，不是一刀切压制超卖票。
- 复用策略11 已有的 `市场广度.破下轨占比` 与 `接飞刀门槛`，**不新增数据依赖**（同日截面，无未来函数）。
- 与"低合议置信度"标记正交：本闸看的是**方向来源与趋势状态**，不是置信度高低。

## 4. 建议回测口径

- **样本**：历史上所有交易日的合议 Top20 快照，按 `破下轨占比 < 0.02`（接飞刀门生效）vs `≥ 0.02` 分层。
- **对照**：A = 现状合议 Top20；B = 加降权闸后的 Top20。
- **指标**：H1/H5/H10 的**均值收益、胜率、IC**；**α 基准用全A等权 mean_pct + 中位数对照**（经验 #11，**不用指数**）。
- **达标判据**（建议）：在"接飞刀门生效日"子样本上，B 的 H5 均值收益与胜率**显著优于** A；同时在"广度确认日"子样本上 B **不显著劣于** A（证明闸门是条件化而非普遍压制）。
- **样本量护栏**：接飞刀门生效日若不足 ~20 个交易日，只报方向性结论、不下定论（参照 `合议专家覆盖补全.md` 里 17 日样本的教训）。
