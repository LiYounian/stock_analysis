## 2. 诊断
动量组合（`tools/pipeline/screen_momentum.py` 及动量算子）为**纯动量打分**（涨速/量能/趋势强度），**无高位超买/涨幅透支的抑制项**——动量越强分越高，但动量最强处常是超买见顶区。与"游资情绪票不赌方向""高位巨量区分主力vs融资盘"同源：**强信号在高位可能反转，需位置约束。**（待实现窗核对动量算子具体口径。）

## 3. 改进提议（只提议）
给动量策略加**高位超买抑制层**：动量高分票若同时命中——
- 超买共振（bias20/RSI/KDJ 多指标超买，复用 `technical.compute` 的 `ob_os` verdict）；
- 涨幅透支（近N日累计涨幅/距MA20乖离 超阈值）；
- 利好出尽特征（可选：事件/消息面近期利好已price-in）；
→ 对动量分**降级/沉底或剔除**（软降级优先，带kill-switch）。复用现成 `technical.ob_os`，不重复造轮子。

- 达标：高位超买子样本前瞻收益/踩雷率 B 显著优于 A，全样本不劣化（对齐eval_v3多维）；带kill-switch。
