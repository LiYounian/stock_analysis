# 策略改进提议 · 消息面回灌的事件「时效过滤 + 方向映射 + 同名归属」三缺陷

> 来源：2026-09-08 补做选股 §6 首次提出，2026-09-09 收盘复盘收口验证。
> 状态：**提议（诊断 + 修复方向 + 验证口径，未改代码/配置）**。⚠️ 非投资建议。
> 与已有 [事件专家方式字段重采.md](事件专家方式字段重采.md) 的关系：那份解决"减持**性质**（协议转让 vs 二级抛售）无数据"；
> 本份解决更前置的三类**方向/时效/归属**错误——即便性质字段补齐，这三类仍会污染消息面分。

---

## 0. 一句话结论

消息面回灌（数据面综合分 + 0.3×消息面分）在 09-08 批次暴露**三类独立缺陷**，2026-09-09 收盘复盘证明"单日结果侥幸兑现不注销缺陷"：

1. **时效缺失**：把 5–8 年前的历史增减持事件当作当日利空喂给情绪模型 → 误压。
2. **方向映射错**：把"减持"事件计入**正分**，或旧事件盖过近期反向新事件 → 误判加分。
3. **同名归属错**：疑似把同名/关联代码（000027 深圳能源）的减持张冠李戴到 000019 深粮控股。

---

## 1. 证据（09-08 批次 · 双向都出错）

**关键护栏（经验 #28）**：000019 涨停 **不是**回灌评分的胜利——方向侥幸对、依据（减持误判/张冠李戴）仍错、防的尾部风险（解禁）未落地。**不得因单日侥幸结果下调本项修复优先级。**

## 2. 修复方向（提议，未改代码）

1. **事件时效过滤**：情绪/事件管线对增减持事件加时间窗（如仅取近 ≤6 个月），旧事件不进当日消息面分。
2. **方向映射校验**：减持 = 负向、增持 = 正向的符号映射加断言；**事件方向与净情绪方向冲突时降权或标"冲突"、不直接取情绪正分覆盖**。
3. **近期优先加权**：同一标的多条方向相反事件，按时间加权（近期 > 半年前），近期反向事件不被旧事件淹没。
4. **同名/关联代码归属校验**：抓取减持事件时校验代码归属，防 000019↔000027 一类张冠李戴。
5. **重组承诺文本排除**："承诺不减持/锁定/转让限制"等条款文本不计为减持利空。
6. **断言测试锁语义**（经验第 6 条）：新增测试断言"纯减持样本（近期仅减持、无增持）消息面分 ≤ 0"、"全历史陈旧事件（最近一条 > N 月）不进当日分"、"同名代码事件不串号"。

## 3. 验证口径

- 回归验证：对 600356/000019/000035 重放修复后管线，期望 600356 消息面分由 −0.71 上修至 0~+0.3、000019 由 +0.53 翻负或中性、000035 依据切到近期增持。
- 前瞻验证：后续交易日继续记"纯减持样本消息面分是否 ≤0""陈旧事件是否被过滤"，并入盘尾复盘的回灌专项台账。
- **不以单日个股涨跌判修复对错**（#28）：600356/688262 走平、000019 涨停均不改上述断言语义。
