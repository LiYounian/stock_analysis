# 策略建议：扣非质量策略前置"审计意见 / 存货减值"红旗闸门

> 提出日 2026-09-09（选股复盘）。仅提议，不改代码。⚠️ 非投资建议。

## 现象
2026-09-09 选股中，**晶华微 688130** 在「扣非质量」策略排 **#1（综合分 1.5183）**，同时命中半导体多因子#3。但其半年报 financial 块 flags 明确含 **「非标审计」+「存货减值高企」+「成长期未盈利」**，财务评级为 **"风险"**。

## 问题
扣非质量策略的综合分被 **"扣非缩亏增速（+74.2%）+ 高毛利率（49.7%）"** 拉到榜首，但**"缩亏增速高"不等于"盈利质量高"**（仍未盈利），且**非标审计意见 + 存货减值**是财务可信度的硬红旗——一个"质量"策略把带非标审计的未盈利股排到质量#1，属**策略口径自相矛盾**，会误导分析师把红旗票当质量首选（本次靠人工纪律 #4 拦下，降为"不建仓·检验"）。

## 建议
1. 在扣非质量策略入选前置一道**红旗闸门**：命中 `financial.flags` 中的「非标审计 / 保留意见 / 无法表示意见」或「存货减值高企 / 商誉减值」时，**降级或剔除**（与合议侧统一风控 veto 汇聚口径对齐）。
2. **未盈利股**（归母/扣非为负）参与"扣非质量"排名时，"缩亏增速"因子应设**盈利门槛**或单独标注，避免"缩亏快"污染"质量高"。
3. 与既有《多策略命中同源信号闸门》(#15) 协同：审计红旗票即使多策略命中，也应先过红旗闸再计命中数。

## 回测口径建议
- A/B：现状 vs 加红旗闸门后，对比"扣非质量 TopN"次日/5日 α 与最大回撤；重点看被剔除的红旗票（如非标审计股）事后收益是否系统性更差。
- 达标标准：加闸门后 TopN 的 5 日 α 不降、且尾部回撤（P10）改善，则接生产。
