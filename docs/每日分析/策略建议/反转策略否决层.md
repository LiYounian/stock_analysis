# 策略建议 · 反转低换手策略加"基本面/消息面否决层"

> 来源：2026-09-01 每日选股——刻意选反转策略的极高分(中南文化002445=0.83)与极低分(湖南黄金002155=-0.95)做检验，发现**高分假阳性、低分反而准**。
> 状态：**建议（诊断+提议+回测口径，未改代码）**。走 统筹审→实现窗→回测评测，达标才接生产，带 kill-switch。
> ⚠️ 非投资建议。

---

## 1. 动机（实盘检验暴露）

反转低换手策略捕捉"超跌+低换手"反转候选。2026-09-01 用两个极值样本检验：
- **极高分 002445 中南文化(0.83)**：技术面确像超跌企稳(缩量+KDJ低位)，**但消息面=主业空心化(扣非-80%)+2018-19约137亿资金占用治理黑历史+江阴国资注入火电的重组停复牌游资博弈**。→ **假阳性**：不是困境反转真逻辑，是高风险壳股炒作。只信技术信号会踩雷。
- **极低分 002155 湖南黄金(-0.95)**：策略判"非反转"，实为**金价趋势强势股**(金价4600美元+43亿金矿注入+复牌一字板)。→ **判对了**（它本就不是超跌反转标的）。

**结论**：反转策略只有**技术层**（超跌/低换手打分），**缺基本面/消息面否决层**——会把"复牌重组壳股的技术超跌形态"当反转强推。技术信号是必要非充分条件。

## 2. 诊断

- 反转低换手打分（`tools/strategy/` 下反转算子 + `tools/pipeline/screen_conditional_rank.py` / `screen_*` 相关）为**纯量价因子**（反转 rev + 换手 turn + 成交额），无基本面/事件否决。
- 高分票若同时是"主业空心化 / 停复牌重组 / 龙虎榜游资 / ST风险"，技术超跌形态与"高风险博弈"重叠，策略无法区分。
- （待实现窗核对具体算子文件与打分口径，本建议给方向。）

## 3. 改进提议（只提议）

给反转低换手策略叠加**否决/降级层**：当技术超跌高分票**命中以下任一风险特征**时，**否决或大幅降级**其反转推荐：
1. **基本面空心**：最近报告期扣非净利大幅下滑/为负、主业萎缩（用已有 financial 块）。
2. **事件博弈特征**：近期停复牌重组、登龙虎榜、股票交易异常波动公告（用 events / 公告采集）。
3. **治理风险**：ST/*ST、历史重大违规（资金占用/违规担保/造假）、退市风险。
4. **重组未完成**：重组预期驱动但方案未过会/未完成（存终止风险）。
- 命中 → 反转信号降级为"高风险博弈，不作反转买入候选"，或直接从反转榜单剔除。
- 与「合议专家覆盖补全」「事件专家」复用同一批基本面/事件数据，不重复造轮子。

## 4. 回测口径（A/B）

- **样本**：历史闭环日的反转低换手榜单（高分票），逐票算 as_of 后 T+5/T+10 前瞻收益（复用 forward_scorecard 基建）。
- **A/B**：A=现状纯量价反转；B=A+否决层。
- **对比指标**：
  1. 反转高分票的 **T+5/T+10 胜率与前瞻收益**（B vs A）；
  2. **踩雷率**：定义"高分票 T+10 内最大回撤超阈值(如-15%)或后续ST/停牌"为踩雷事件，比 B/A 踩雷占比是否下降；
  3. **不误杀**：真困境反转/超跌优质票（有基本面支撑的）在 B 下不被否决层错杀（保留率）。
- **达标**：B 相对 A，反转高分票**踩雷率显著下降**且**胜率/前瞻收益不劣化**（与 eval_v3 多维判定一致）；带 kill-switch 可回退。

否决层对 **002084 海鸥住工** 的判定（反转综合 -0.9134 → **-2.4134**，罚 1.5；`LHB否决=True`，定性"事件博弈"）在 09-03 得到验证：该票收 **6.91，-2.95%**（α vs 全A等权 **-2.64pp**），日内振幅 **10.4%**、换手 **24.56%**，7连板开板后延续派发，全程双向巨震。
