## 3. 金字塔选股是什么（速览）
每天从全A独立召回候选池 → 五基石加权打分骨架（量价自证0.30/板块角色0.25/策略共识0.20/排雷0.15/宏观0.10）+ 排雷一票否决 → 决策包（市场定调 + 全板块概览 + 骨架 topN×各工具浓缩块）→ **你的 Claude Code 作为合成层**，读决策包按你被分配的风格做**受限调整**（只调序/否决/选定/写纪律，**不产数字、不加池外票、不无证据加塞**），出 2~3 买 + 2~3 避。价位由程序 `entry_price` 工具回填。

## 4. 怎么跑金字塔（命令）
```bash
PY=~/.conda/envs/stock_analysis/bin/python
# 列工具
$PY -m tools.pyramid list
# 单票查某工具（as_of=分析交易日，防未来）
$PY -m tools.pyramid tool <工具名> --as-of 2026-09-18 --code 000725 --data-root .
# 生成决策包（自动落盘 data/analysis/<as_of>/金字塔决策包_top8.md）
$PY -m tools.pyramid.d2_package --as-of 2026-09-18 --data-root . --top-n 8
```
决策包就是你（Claude Code 合成层）的输入。10 个工具：entry_price / price_volume / gate / shared_pool / sector_context / experience_rules / fake_good_news / financial_redflag / unlock_risk / insider_reduction。机制细节见 `docs/计划/2026-09-18_D2_流程设计_打分骨架加浓缩块合成.md`。

## 5. 统一输出格式（必须一致，否则无法横评/记分）
**① 选股推荐** —— markdown，文件首部必须带机器可读标记（供程序横评/D3记分解析）：
```
<!-- PICKS_BUY: 代码1,代码2,代码3 -->
<!-- PICKS_AVOID: 代码1,代码2,代码3 -->
```
正文每只买入票写：名称+代码 / 骨架分与理由 / 买点（entry_price 回填的挂单/加仓/止损/红线）/ 纪律。规避票写理由。**每处调整引用决策包里的浓缩块证据，不得编造数字或股票名（名称以 config/code_name.json 为准）。**
**② 每日复盘** —— 昨日/近日选股的 D+1/D+3 表现、命中与否、经验教训（文档）。
**③ 经验沉淀** —— 这次分析中沉淀的可复用规则/陷阱（文档，只增不删）。
