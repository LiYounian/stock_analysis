# 协作者文件夹模板

认领风格后，把本 `_模板/` 复制成 `实验选股/<你的名字>/`，按下列结构产出（详见 `../../金字塔选股_协作者交接.md` §5/§6/§7）：

```
实验选股/<你的名字>/
  选股/       每交易日一份  2026-09-18_金字塔_<你的名字>.md   （首部带 <!-- PICKS_BUY/AVOID --> 标记）
  复盘/       每交易日一份  2026-09-18_复盘_<你的名字>.md
  经验沉淀/   只增不删      v2026-09-18_<你的名字>.md
  优化建议/   发现问题时    2026-09-18_优化建议_<你的名字>.md （文档形式提交，统筹审批是否采纳，你不改代码）
```

硬性规定（摘自交接文档 §7，不可违反）：
1. 产出只放本文件夹；报告/复盘一律文档；**你不改代码**。
2. 优化建议/代码修改想法 → **文档形式**放 `优化建议/`，由统筹审批与实施，你不自行改。
3. 你只负责产出：选股推荐 / 每日复盘 / 经验沉淀。
4. 每次操作前先 `git pull`；只 push 本文件夹文档。
