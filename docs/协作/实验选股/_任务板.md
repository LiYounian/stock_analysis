# 实验选股 · 任务板

> 协作者在此**自由领取**任务。先读 `../金字塔选股_协作者交接.md`。统筹维护本板。
> ⚠️ 研究模拟、非投资建议。

## 怎么领取
1. 在下方"可领取任务"里挑一个**空闲风格**，把该行"认领人"改成你的名字（一次一人一风格），commit 本文件。
2. 到 `实验选股/<你的名字>/` 下按交接文档 §5/§6 产出三件套。
3. 冲突处理：若 push 时发现该风格已被人抢先认领，换一个空闲风格。

## 三种风格定义（认领时按此执行）
| 风格 | 偏好 | 入场 | 回避 | 适配场（假设·待验证） |
|---|---|---|---|---|
| **趋势突破** | 放量创新高、突破形态的强势右侧股 | 突破确认 / 回踩不破 | 弱势、缩量 | 强势普涨、主线发酵 |
| **低吸回踩** | 回调到均线/支撑、缩量企稳、趋势未破 | 回踩企稳（MA5/MA20） | 追高、破位 | 震荡、轮动 |
| **事件催化** | 有明确催化（业绩超预期/政策/订单） | 催化确认+未充分定价 | 无催化纯技术票 | 消息驱动、财报季 |

> 风格是**选股倾向**：同一份决策包，不同风格会挑出不同的票。目的——攒够 forward 后按"板块×行情×风格"分层记分，看哪种风格在什么场里更赚，最终沉淀成发现。

## 每日任务（认领后每交易日重复）
1. `git pull` 同步代码 + 本板 + 交接文档。
2. 跑金字塔决策包（交接文档 §4）。
3. 你的 Claude Code 按你认领的风格做受限调整，产出选股推荐 + 每日复盘 + 经验沉淀（交接文档 §5/§6）。
4. 只提交你自己文件夹下的文档。
