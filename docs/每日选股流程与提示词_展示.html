1流程全景（从新闻/盘面到每日选股产出）

选股每天分两条线跑：机器先在收盘后完成「数据采集 → 大盘研判 → 板块冷热 → 全A多策略候选 → 策略0合议」的闭环，把结果落到 data/analysis/<当日>/；然后 LLM「分析师」按 SKILL 提示词读这些产物做综合研判，选出 3–5 只并逐票深度分析。触发链：收盘闭环 com.stock.pullrefresh（工作日 15:40 起）跑完 → 晚间选股定时任务 daily-stock-selection（18:36）开工；次日午休有 daily-stock-noon-analysis（11:45）盯盘。

2提示词模块说明来源：daily-stock-selection / daily-stock-noon-analysis SKILL.md

选股主体是一个 LLM「分析师」角色，其行为由定时任务 SKILL（提示词）逐段约束。下面把主提示词 daily-stock-selection/SKILL.md（收盘 18:36 晚间选股）拆成模块，每块给：角色/任务 · 输入→输出 · 这段干嘛 · 涉及变量；末尾附午盘 SKILL。

角色总纲SKILL 头
角色/任务：stock_analysis 每日选股分析师（定时任务·收盘后选股 + 深度预测）。目标是从全部策略多维度挖 3–5 只、逐票深度研判并给明确买入排序。
输入→输出：输入=当日闭环全部产物 + 最新经验沉淀；输出=选股/<当日>.md + 每日选股.json。
作用：确立「测试环境·非投资建议·防未来函数·不改代码·绝不反问」的总铁律，并绑定工作目录与 conda python。
变量：工作目录python 环境
开工护栏 + 漂移检测task_guard begin
任务：跑 task_guard.sh begin，算「预期触发时刻 vs 实际执行时刻」的漂移。
输入→输出：输入=cron 时刻/系统时钟；输出=DRIFT_FLAG（ok / late）+ DRIFT_NOTE。
作用：后台会话在桌面 App 非活动时会被挂起数小时，实际执行常远晚于 cron。漂移>30min 时要把说明写进产出，并点出哪个维度因漂移未能检验，绝不把「实际采到的数据」当成「预期时点数据」陈述。
变量：DRIFT_FLAGDRIFT_NOTE
闭环就绪门控（硬）前置检查
任务：确认当日为 A 股交易日，且盘后闭环已完成后才开工。
输入→输出：输入=data/sync_receipts/<当日>.json + 策略视图齐全度；输出=开工 / 有界轮询等待 / 跳过留痕。
作用：防时序竞态。判据两条都要满足：① 存在当日 sync 收据；② 策略视图齐全（动量组合/半导体多因子/反转低换手/放量后缩量回踩/最大范围/最强/策略0合议/量价放量/指标条件化 等）。未就绪→每 2 分钟重查、最多等 90 分钟；仍不就绪才跳过（写 <!-- PICKS: none -->）。另有「盘尾复盘互斥门控」task_guard.sh wait daily-stock-eod-review 30，避免两个定时会话撞车。
变量：sync_receipts策略视图齐全度EOD 复盘锁
市场环境判断（β 背景）第二步
任务：读 market_forecast.json 给市场环境定性（偏多/偏空/震荡），作量化 β 背景。
输入→输出：输入=大盘预测 v0.5（沪深300 + 全A等权 proxy）；输出=市场环境一句话定性 + β 风险标注。
作用：选股 β 以 proxy（全A等权=个股β基准）为准，权重股偏多≠个股偏多。预测命中率约 55%，作背景、非硬门控；大盘偏空时买入表态更谨慎并标 β 风险。capitulation β 例外：读 data/signals/capitulation/<当日>.json，若 capitulation=true（破位广度+近端崩跌双极端）则放松「普跌整体降级」、给 β 敞口，但绝不据此给个股加「超跌 α 分」。
变量：p_up(T+1/T+5)方向/五档三维贡献(技术/广度/消息面)分歧标记capitulation
选股：从全部策略多维度挖 3–5 只选股
任务：读全部策略视图，按 ①多策略命中 ②单策略极值 ③多样化，选 3–5 只，每只写清命中哪些策略+分值、标类型。
输入→输出：输入=各策略视图 + 策略0合议；输出=候选清单（含「买入候选/检验样本」类型，必须有真买入候选）。
作用：目标挖 3–5 只可买入候选；弱市优质不足时诚实说「只有 N 只够格」、绝不降标准硬塞满（硬凑=把 β 风险伪装成 α 机会）。
变量：命中策略集综合分合议置信度口径多样性
2B · 选股权重微调（已验证证据）相对权重·非硬门控
作用：按回测已验证的证据调相对权重与标注（不改主流程、不新增硬门控）：
  • 普跌日不反动量：绝不因「超买/高 winner_rate/获利盘高」系统性否决或降权动量票——回测证伪「弱市避高 β」，弱市高 β 票次日胜率反而更高；动量票在普跌日仍是首选 α 候选，用回踩限价入场。
  • 半导体多因子命中降权：该策略被诊断跨口径拖累次日 α（约 −1.26%），top 命中降权、不单独据它进候选。
  • winner_rate 分档：wr 80~95 中段是真拖累段→命中该段降权；wr>99 强势票不降权——回测坐实「回踩限价入场正期望、追高开负期望」，故对 wr>99 标 gap-fade：照常入选、挂昨收~昨收−1% 回踩限价、不追高开、D+1 了结不持 D+2。
变量：winner_rate 分档次日高开回落风险gap-fade 标记
2C · 板块预测系统消费（P-a）分析师参考·non-gating
作用：若当日 sector_focus.json 存在，读作分析参考（不覆盖逐票研判）：
  • ① regime→战略切换：读顶层 风险偏好{进攻/中性/防守} + 宏观情景{加息紧缩/降息宽松/关税冲击/中性}→按预案表调动量口径/规避口径/板块偏好/仓位表态。催化优先：有硬催化的强势票任何 regime 都可进候选。
  • ② 消息面综合：读 market_daily.md（宏观+大盘档+重点/规避板块）补个股级新闻之外的板块/宏观面。
  • ③ 占优板块 roster：重点板块池→各板块角色表（龙头/中军/补涨先锋/弹性股）作研判战场背景。被证伪的只是「机械把 roster 无脑覆盖式补入候选」，板块分析作研判背景的价值照常用。
变量：风险偏好宏观情景focus_score角色表
逐票深度分析 SOP核心
任务：对每只候选走「定性分票→数据层→消息面（强制 baidu_news + 必要 WebSearch）→数据×消息面交叉→深度结论」。
输入→输出：输入=per-stock JSON + 原始新闻/公告/舆情；输出=每票深度预测（明日情景 + 1日/5日方向置信 + 区分 α/β + 我 vs 系统 + 盯点）。
作用：明确表态不对冲（买入/可参与/观望/规避 + 理由）；游资情绪票只标风险不给方向；高位巨量区分主力 vs 融资盘；情绪质量必标，质量∈{unknown,missing} 的票是消息面盲区、不得给「买入·首选」最强表态。
变量：量价形态财报五维资金流(主力/融资)情绪三层质量α/β 归因
判对之后：三条必填（硬）⑦⑧⑨
  • ⑦退出/止盈纪律（买入候选必填）：什么条件减仓/清仓（价格位/形态破坏/时间止损/催化落空）；若次日涨停封板卖不出，预先写明处理；不许只写「只做短线」这种无触发条件的话。
  • ⑧方向前提=触发信号：方向若依赖尚未出现的触发（放量收阳/主买翻正/行业催化），只能给「低波动待动」，不得给方向。超跌反抽首入场闸门=放量收阳（量比>1.5 且收阳），MA5 降为趋势确认/加仓档。
  • ⑨盯点单问化：每条盯点是可独立判定的单一问题（能用 是/否/无数据 回答）。估值/筹码环节固定加一问：有无存续可转债/推进中定增/临近解禁。
产出 + 机读锚点 + 结构化 JSON产出
作用：写 选股/<当日>.md——文件第一行必须是 <!-- PICKS: 代码1,代码2,... -->（午盘/盯盘识别「昨日选股」的权威源）；正文含逐票分析 + 「买入建议排序」表。之后调 tools.analysis.write_picks 生成 每日选股.json，名称/收盘价/命中分值由工具从 record 回填（不手打），并过 枚举/必填/情绪质量/防未来/PICKS一致性 校验，不过则改正重跑、绝不带错落盘。
变量：PICKS 锚点买入建议排序表market-regime

午盘提示词 · daily-stock-noon-analysis（11:45）

午盘超短线分析师盯盘集~19只·非全A
角色/任务：交易日午休（约 11:45，11:30 已收市）对盯盘集（前日选股 ∪ 自选池）做午盘研判，给尾盘买/持/卖倾向。
输入→输出：输入=午盘快照 data/intraday/<当日>/T1145.json（11:31 冻结价）+ 前日选股结论；输出=日内_<当日>.md（第一行同样带 PICKS 锚点）。
作用：逐票给午盘状态（vs 昨收/早盘、量能异动）+ 大盘 β（普涨/普跌/高低切）+ 结合触发闸门给尾盘倾向 + 关键价位。与晚间一致「不反动量」：强势放量票给「回踩限价可参与」而非一刀切放弃。防未来硬红线：只用 ≤11:31 冻结快照的信息。范围只覆盖盯盘集~19只、非全A重筛。
变量：T1145 午盘价vs 昨收/早盘量比/异动触发闸门是否触发

3策略清单（候选怎么来 + 打分）来源：tools/pipeline/screen_*.py · config/strategy.py

策略0 · 合议怎么产综合分

8 专家=超买超卖拐点资金流情绪三层多因子事件驱动板块轮动财报。每专家给 方向/强度/置信度/默认权重/依据，加权汇总为综合方向 + 综合分；合议置信度=专家一致度，参与专家数 / 口径多样性 / 覆盖口径=有多少独立视角发声。注意（诚实边界）：全A逐票时，资金流/多因子/情绪/事件因无全A数据自然弃权，只有技术类 + 有财报 raw 的票财报专家发声——所以全A口径下实际参与专家常常有限，综合分主要由技术+财报(+板块)驱动。

4.3 策略命中（哪些策略选中了某票、各数值含义）

变量含义
命中策略集该票被哪些策略选中（如「最强选股 + 量价放量 + 最大范围选股」）。多策略命中≠多维确认：需前置闸门，同源命中要打折。
综合分策略0合议加权后的方向强度分（越高越偏多）。
合议置信度专家意见一致程度（1.0=高度一致）。
参与专家数 / 口径多样性 / 覆盖口径有多少独立视角发声、覆盖了哪几类口径（技术/板块/质地…）。多样性高=多维印证。
winner_rate 分档获利盘比例分档（>99 / 95-99 / 80-95）。80~95 中段降权；>99 不降权但标 gap-fade。
次日高开回落风险由 S05 输出，标记高位强势票的 gap-fade 风险（回踩限价买、不追高开）。
财报风险 / 龙虎榜否决策略0 风控 veto：财报红旗、龙虎榜 entry_veto（近端净买上榜方向）触发则降权/沉底。

每票一份 data/analysis/<当日>/<code>.json，含以下块（每块带 口径日期 / 新鲜度，标注该字段是否当日新鲜）。

块关键字段代表什么 · 说明什么
snapshot 量价形态close / pct_chg / ma(5/10/20/60,排列) / macd(状态) / kdj / rsi / bias20 / vol_ratio / vol_state当日量价与均线结构。bias20=对 20 日均线乖离（极端乖离=透支），vol_ratio/vol_state=放量/缩量。
valuation 估值pe_ttm / pb / mktcap_yi / mode（PE适用/PEG）/ pe_valid估值贵贱、结合增速看 PEG。样例口径日期常滞后 as_of（陈旧）。
fundamental 基本面营收 / 净利 / 营收增速 / 净利增速 / ROE / 毛利率 / 净利率 / 负债率 / 每股股利成长性与盈利能力速览。
financial 财报五维five_dims：成长 / 质量 / 健康 / 运营 / 回报；quality_score + 评级；扣非/现金含量/审计意见+机构档位；合同负债/在手订单；qualitative 文本红旗财报质地打分（五维雷达）。审计意见/机构档位作硬闸；扣非占归母、现金含量 CFO/净利 判断利润成色。
signals 信号trend（评级/得分）、reversal（超跌/放量反包/低位金叉/底背离/拐点评分）、ob_os（超买超卖 verdict/resonance）趋势/反转/超买超卖三类技术信号，合议专家的原料。
prediction 预测atr / atr_pct / 支撑位 / 压力位 / 情景预测(1日/5日/10日) / 买卖倾向 / 指标条件化预测 / 结构位波动幅度、支撑压力、概率化情景。诚实标注「概率基于历史频率、非未来保证」。

5待确认 / 可调整清单

读代码/产物时发现的、当前实现与「理想」有差距或含糊之处，列给用户探讨（不改动任何生产代码/SKILL）。

  1. 国际新闻 / 关税 / 地缘覆盖度不均。利率、汇率有结构化字段；国际龙头（英伟达/台积电）专用海外 feed「待接」，现经国内财经媒体间接覆盖；关税/地缘无独立采集器，仅经 sentiment_policy/news 文本间接进入「宏观情景」。任务书要求呈现的「加息/降息/汇率/关税/地缘」中，后两者目前是弱覆盖——是否需补专用源？
  2. 北向 raw 本地缺、待接；大宗金额聚合口径待细化。（market_daily.md 诚实边界原文）当前北向变量存在但底层 raw 未到位。
  3. 板块系统尚未真正闭环进选股。sector_focus.json 为 non-gating/forward-shadow，口径注明「不进生产选股（P3 gated 才接）」，当前只是分析师参考锚。是否推进到 gating？
  4. 部分个股字段「陈旧」。样例中估值/基本面（口径 09-08）、盘口 tick（09-11）、股东户数（09-04）滞后于 as_of（09-16）。选股用到的部分变量并非当日新鲜——是否需要提升刷新频率或在选股时对陈旧字段降权？
  5. 全A 逐票时消息面/情绪多为盲区。样例个股 sentiment 新闻/舆情样本数 0、质量 missing；策略0里资金流/多因子/情绪/事件对全A自然弃权。消息面只对「策略选中集∪自选池」采集——分析师需对候选补采，但候选之外的全A票消息面缺失。
  6. 已下线策略仍在代码库。S01（趋势深跌反包）、箱体（策略3）经诊断显著负、仅存档不接生产。建议确认前端选股页/编排/回放确已摘除、无误用。
  7. 大盘预测是弱信号。market_forecast 整体方向命中约 55%（较纯惯性约 +4pt），SKILL 明确「作背景、非硬门控」。使用者需理解其定位，不宜当强前瞻依据。
  8. 编排无单一 DAG。pipeline.py 是骨架（NotImplementedError），真实编排分散在 launchd（pullrefresh/screenall/commitdocs）+ 各 screener CLI + 分析师 SKILL。流程「真源」不集中，转交时需同时看这几处。
  9. 策略0「多专家合议」在全A口径下参与专家有限。综合分主要由技术 +（有 raw 时）财报 + 板块驱动，资金流/情绪/多因子/事件多弃权。「多专家」名义与全A实际参与度之间有落差，评估综合分权重时需知晓。
  10. 选股主体是 LLM 人工研判、非算法 top。最终 3–5 只由分析师按 SKILL 主观从策略视图挑选并深度研判，可复现性依赖「经验沉淀」文档版本（v<日期>.md，累积 33 条经验/纪律）。若追求确定性/可回测，需明确「哪些是硬规则、哪些是分析师自由裁量」。
