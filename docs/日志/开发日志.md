## 2026-08-30 · 统一风控 veto 汇聚器:财报红旗 + 龙虎榜否决 收进同一否决/降权出口(`feat/risk-veto-aggregator`)

> 背景:两个风险否决/降权信号各接各的出口——**财报红旗**(质量轴,`config.redflag_adjust`,已上线降权/否决)与**龙虎榜否决**(微结构轴,`backtest.lhb_veto`,评测坐实净买上榜见光死 H5 −1.68% p=0,但**尚未接入任何选股排序**)。本轮建统一汇聚器,把两轴正交 OR 合成到同一出口,并把龙虎榜正式接入选股闭环。⚠️ 非投资建议。

### 设计(分两层,镜像红旗现有分层,守 §9.3 依赖方向)
- **纯映射层**(`tools/config/strategy.py`,零依赖、web 可 import):新增 `THRESHOLDS['风控汇聚']`(龙虎榜轴总开关/模式降权\|否决/触发罚分/按条数加权/否决沉底保留展示/窗口天数/最小净买占比 + 两轴合成罚分上限)+ 纯函数 `risk_veto_adjust(base, high_flag_count, lhb_verdict=None, cfg=None)`。
  - **动作语义统一**:两轴都映射到 `降权=排序分−Σ罚分` / `否决=沉底标记(不改分)` / `剔除=否决且不保留展示`;OR 合成(任一轴否决→否决;任一轴剔除→剔除;降权罚分求和后封顶)。
  - **向后兼容红线**:**财报轴独立于汇聚总开关**(始终读 `财报.红旗接入`);`lhb_verdict=None`/未触发/总开关关停 → 排序结果与 `redflag_adjust` **完全一致**(无回归)。保留 `redflag_adjust/redflag_penalty` 不动。
- **数据生产层**(`tools/analysis/risk_veto.py`,新,可 import backtest):`lhb_verdict_asof(code, as_of)` 走 `lhb_veto.entry_veto_asof` 取 as-of 裁决(`.to_dict()`),缺快照/异常→None。

### 诊断(先诊断再动手)
- **为何只 175 票**:`run_financial_collect` 只对 `news_subset`(自选 ∪ 每策略 topN)采财报(`tools/run.py`),刻意的 token/资源纪律,从不对全A 5000+。采集器 `collectors.financial.fetch_financial(codes)` 本身**对任意 code 列表通用**(akshare 东财 per-stock by_report,自带披露日 NOTICE_DATE)。

## 2026-08-30 · 财报高危红旗**接入选股逻辑**(从"仅展示"→"进排序/入选":降权沉底)

> 分支 `feat/redflag-veto`(独立开发线)。承接 WI-6 验值结论(见下条 2026-08-30 finval:红旗=风险/降权层、**非 alpha**)。**未动**财报数据采集、未动 `financial/industry/` 行业专家阈值;只加 config(additive)+ 纯函数 + web 排序接入。⚠️ 非投资建议。

### 一、诊断
- 面向用户的选股页最终排序在 `web/data_access.py::selection_page` 组装:自选股/策略0 按 `council_score` 降序、综合选股 combined 按并集插入序(无打分)。此前 `financial_risk()` 命中的高危红旗**仅展示⚠、不进排序**。
- 实测暴雷票入选:2026-08-28 **002129(评级=风险·扣非为负)在自选股排第 3**(council_score 为正);高危红旗票约 19~24 只/日,**约 17 只落进 combined 并集**。
- council 默认组虽已含"财报专家"(按评级投方向 + 审计闸门一票否决),但**无基于红旗严重度的风险覆盖层**,且离线 `screen_council` 用最小记录(无 financial)→ 财报专家恒弃权。

### 二、方案(降权 vs 否决 → 选**降权**)
- **降权**(默认):候选**排序分扣分**(dose 单调、封顶),高危票沉底但保留展示+⚠;**否决**(可配):强制沉底或剔除。

## 2026-08-30 · 行业财报信号验值:避暴雷 **达标**(风险侧)/ 选 alpha **不达标**

### 一、方法(防未来函数为红线)
- **信号 as-of**:`analyze(code, as_of=None)` 逐报告期取 {quality_score, 评级, 红旗(严重度), 五维},**信号内在于该报告期**(每期 flags/score 仅用该期+去年同期,与 as_of 无关);锚定该期 `disclosure_date`。**入场=严格晚于披露日的首个交易日**(跳过披露日跳空),前向收益/回撤只取入场之后。

### 二、结论(两类价值分离评估,预注册判据)
- **价值A · 避暴雷(风险侧)= 达标,但只在回撤/暴跌维度**。高危红旗组 vs 无红旗组:**60 日最大回撤显著更深**,三样本一致——全样本 −22.1% vs −17.6%(差 −4.5%,月聚类 **p=0.003**)、专家子集 −22.0% vs −17.7%(**p=0.007**)、年报半年报 −21.0% vs −17.4%(**p=0.004**);20 日回撤同向(p 0.04~0.075)。**暴跌率约 2 倍**:min60<−20% ≈ 25~27% vs 14~15%,min60<−30% ≈ 9~10% vs 3~6%。**剂量反应单调**:高危红旗数 0/1/2 → mdd60 −18.7%/−23.4%/−31.7%,crash20 18.9%/30.0%/46.7%。
- **⚠️ 诚实反证**:红旗组**平均收益并不更低,反而略高**(fwd/exc 差为正但不显著)。即红旗票=高波动/肥左尾,但 2023–2026 A股里这些高杠杆/困境小票同时吃了垃圾股/低价反弹的肥右尾。**故红旗的价值是"降回撤/避崩盘/减仓位",不是"否决=提均值收益"**;纯做 veto 会同步砍掉上行,均值净效应本窗口≈中性。
- **价值B · 选 alpha = 不达标**。quality_score 对超额收益 **rank-IC 近 0 且从不显著**(全样本 t 0.02~0.70;年报样本 t≤1.50),五分位在全样本/年报样本**非单调**,多空 Q5−Q1 扣成本后 ≤0。唯一微弱亮点在**专家子集**:exc60 Q1 −2.1%→Q5 +1.1% 近单调、rank-IC60 +0.081(t=1.25,命中 75%)、Q5−Q1 扣成本 +2.5%——**提示行业化打分或比通用打分略带 alpha,但 t<1.3 不显著、20 日无、样本薄,不足以进生产**,仅作扩样后复验的假设。
