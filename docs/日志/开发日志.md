## 2026-08-05 · 32 只票并行分析实践(5 Agent + 汇总)

**做了什么**
- 按用户要求做真刀真枪的股票分析(不写代码,用已建工具产出文档供人审):抽数据→分类→找共性→超买超卖判断→新闻抽取→逐票成文→并行 Agent→汇总。
- 固化三层数据 `data/raw/analysis_input.json`(32 只×技术/基本面/公告)。
- 写 [衡量指标与策略.md](../衡量指标与策略.md):可衡量指标全清单 + 超买超卖判定口径(≥2 共振)+ 每票文档模板 + 灵感库。
- **并行起 5 个 Agent(G1–G5,按板块分组)**,逐票产出 `docs/个股分析/{code}_{name}.md`(32 份)+ 5 份组共性,各回传结构化摘要。
- 二次汇总 → [汇总报告_20260805.md](../汇总/汇总报告_20260805.md):分类 + 跨组共性(7 条)+ 超买超卖全景(明确超卖 10 只)+ 筛选三候选池(A超跌反弹/B质地优/C透支回避)+ 灵感沉淀。
- 各 Agent 灵感汇入策略库 §6.1(BIAS/KDJ 假信号过滤/距高点回撤/回购密度/PE 开关等)。

**关键发现(实践出真知)**
- 全池被"AI 算力+半导体+机器人"一条主线串起;8/5 异动=存储超级涨价周期+HBM 缺口。
- **趋势—拐点背离**是核心现象:多数趋势偏空但拐点超跌待反弹 → 印证 P1.5 拐点独立成维。
- **KDJ 假信号频发**(6 只 J>100 不共振)→ 印证"≥2 共振"口径;催生"BIAS 落地+KDJ 降权"最高优先灵感。
- PE 大面积失效(亏损/折旧/周期底)→ 需按标的性质切 PB/PS/订单/扭亏进度。

**方法论验证**:并行 Agent 分组分析 + 主控汇总,是处理"多标的同型深度分析"的有效路径(5×~70K token 并行,总 wall-clock≈单组耗时)。

**产出**:`docs/个股分析/`(37 文件)+ `docs/汇总/汇总报告_20260805.md` + 策略库更新,均 markdown 供人审,入库保留。

**遗留 / 下一步**:灵感 §6.1 待人审 → 择优落 P1.6(BIAS+KDJ 过滤)。情绪面超买超卖待 L2。
