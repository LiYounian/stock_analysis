# 策略0 多专家合议:逐专家准确率 + 权重建议 + 策略0×11 合并方案

> 内容窗口·线B 产出(feat/council-vs-cond)。**分析+建议,供合作者共评;不改生产权重、不删专家、不实施合并。**
> 数据·非投资建议。历史观测≠未来保证。

---

## 一、多专家合议:有哪些专家、当前怎么加权

配置真源 `tools/config/strategy.py` → `THRESHOLDS["合议"]`。

- **默认专家组(9 个)**:技术趋势 / 超买超卖 / 拐点 / 资金流 / 情绪三层 / 多因子 / 事件驱动 / 板块轮动 / 财报。
- **默认权重**:全部 `1.0`(等权起步,D2)。
- **合成口径**(`council.convene`):`S = Σ(强度×置信度×权重) / Σ(权重×置信度)`(置信度加权分母),`τ=0.2`:S≥+0.2 看多、≤−0.2 看空、其间中性。冲突仅标注不改判。

### 关键事实:全A合议里实际只有 3 个专家在场

`screen_council.build_min_record` 的最小记录**只填 `signals`(trend/reversal/ob_os)**,行业多为 None。因此:

| 专家 | 全A合议中状态 | 原因 |
|---|---|---|
| **技术趋势 / 超买超卖 / 拐点** | **在场发声** | 由 `technical.compute(kdf)` 现算 |
| 板块轮动 | 几乎恒弃权 | 最小记录 industry=None / 无 RRG |
| 资金流 / 情绪三层 / 多因子 / 事件驱动 / 财报 | 恒弃权(置信度0) | 最小记录无对应数据 |

置信度加权分母下,弃权专家分子分母都为 0、自动退出。**所以策略0全A的"综合方向"完全由技术趋势/超买超卖/拐点三个技术专家的加权决定**——这也是既有回测判"策略0 无 edge(可带 alpha 的资金流/情绪/基本面维度全弃权)"的结构性根源。

## 二、逐专家预测准确率(工具:`tools/backtest/expert_scorecard.py`)

两条口径交叉验证。**方向命中** = sign(前向收益)==sign(专家方向);**超额** = 命中率 − 同(日,期限)抽样宇宙方向基线正确率(看多样本基线=P(涨)、看空=P(跌))。防未来函数:信号日前算方向、之后取收益,h 仅当 idx+h<len 才计。

### 口径B:历史全A回测(主结论,样本大、无选择偏差)

主跑 seed=7 · 464 票 · 59,610 信号点:

| 专家 | 1日命中% | 1日超额% | 5日命中% | 5日超额% | 样本 | 方向构成 |
|---|---|---|---|---|---|---|
| **超买超卖** | 55.5 | **+2.2** | 56.4 | **+2.0** | 7,505 | 多4091/空3414 |
| 拐点 | 51.3 | +0.5 | 48.5 | −0.6 | 24,250 | 全看多 |
| **技术趋势** | 45.6 | **−3.4** | 48.4 | **−1.1** | 38,689 | 多18521/空20168 |

复跑 seed=11 · 236 票 · 30,548 点(独立随机种子)结论一致:超买超卖 +1.3/+0.8、拐点 +0.5/−0.3、技术趋势 −3.2/−0.9。

**准确率排名:超买超卖 > 拐点 > 技术趋势。**

要点:
1. **技术趋势是拖后腿的**:两个期限、两个种子都是负超额,且它**发声最多(样本最大)、强度可达 0.75/0.8**,在等权合议里贡献占比最高 → 主导 `综合分`、把 S 拉偏。这正是 A股"短期动量弱、反转强"铁律的体现(追趋势=追高)。
2. **超买超卖最准**:mean-reversion 型(超卖→看多/超买→看空),两期限稳定正超额,但发声最少(7,505)→ 好信号被等权稀释。
3. **拐点边际**:只出看多(超跌反弹/反弹启动),1日微正、5日微负,近噪声。
4. **技术趋势强度未校准**:5日命中按 |强度| 分档 无单调性(0.3→49.7%、0.6→47.3%、0.8→47.9%),强度越大不代表越准 —— 强度用作合议贡献权重反而放大了错误方向。

### 口径A:观测口径(历史 策略0合议 top20 清单,16 个预测日)

三专家均呈强负超额(技术趋势 5日 −12~13%、拐点 −15~16%)。**这不是专家本身更差,而是选择偏差 + 窗口偏差**:top20 按综合分选出 = 系统性偏向"强技术趋势看多"的高位股(恰是负 edge 信号),又逢 2026-08 中旬一段普跌窗口、样本仅十几日。**故 per-expert 准确率归因以口径B为准,口径A只作"等权合议选出来的票确实偏弱"的佐证。**

## 三、权重调整建议(有 A/B 数据支撑)

方向:**降技术趋势、升超买超卖、拐点持平**。用 `expert_scorecard.py` 内置的合议综合方向 A/B 直接评估(seed=11 独立样本,30,548 点,tau=0.2 同口径):

| 权重方案(技术趋势/超买超卖/拐点) | 1日命中% | 1日超额% | 5日命中% | 5日超额% | 综合样本 |
|---|---|---|---|---|---|
| 等权 1.0 / 1.0 / 1.0(现状) | 47.9 | −2.0 | 49.4 | −0.3 | 7,843 |
| **建议 0.5 / 1.5 / 1.0** | 50.8 | −1.0 | 51.3 | **+0.4** | 5,338 |
| 反转倾斜 0.3 / 2.0 / 1.2 | 50.8 | −0.5 | 51.1 | +0.4 | 7,321 |

**效果**:等权合议 5日超额 −0.3%(印证"IC 微负/无 edge");降趋势升超卖后 **5日超额翻正到 +0.4%、1日超额改善 ~1~1.5pp**。

**诚实定位**:边际 ~0.5~1pp,是把"系统性小亏"的合议**扭到大致打平/微正**,**不是造出强 alpha**。建议:
- **首选「建议 0.5/1.5/1.0」**:改动温和、可解释(超卖信号加权、追趋势减半),5日已翻正。
- 「反转倾斜」更激进、样本更多(降趋势会让更多点落入中性、样本缩水,倾斜方案靠抬超卖/拐点把样本找回),超额相近,可作次选。
- **配套**:技术趋势的**强度**因未校准、放大错误方向,建议 council 里对技术趋势改为**方向定性、强度封顶**(如 |强度|≤0.3)或改用固定小强度,而非现在的 得分/100(可达 0.75/0.8)。这条与降权是同一诉求的两条实现路径,二选一或叠加。
- 以上仅建议,**不在本轮改 `strategy.json`**;落地前建议再拉长样本(全 5550 票 × 更密日期)与分市场态(牛/熊/震荡)复核稳健性。

## 四、策略0(合议)× 策略11(指标条件化状态排序)技术口径对比与合并方案

### 4.1 技术指标口径:底层 100% 重合,映射层完全不同

两者**都只吃 `tools/analysis/technical.compute(kdf)`**,原始指标层(MA/MACD/RSI/KDJ/BOLL/BIAS)是**同一份实现、同一份阈值**(`THRESHOLDS`)。差异全在"指标→结论"的映射:

| 维度 | 策略0 合议 | 策略11 指标条件化 |
|---|---|---|
| 输入指标 | signal(均线排列+DIF/DEA+价vsMA20)、ob_os(KDJ/RSI/BIAS 共振)、reversal(超跌/放量反包/低位金叉/底背离) | 3 主维度状态格:趋势方向(MA排列)×动量(MACD+RSI12)×BOLL位置(%B分档);二级维度作过滤/佐证 |
| 映射方式 | **人工规则 + 手设方向/强度** → 加权求和 → 综合方向 | **经验条件分布**:全A历史里"同状态格"样本的前瞻收益 → 上涨概率% → 排序 |
| 输出 | 综合方向(看多/看空/中性)+ 综合分 | 每持有期 上涨概率% + 方向 + 置信度(匹配质量)+ Top-K 排行 |
| 个股区分度 | 逐票不同(强度连续) | **状态格级**(同格同概率),真正 tiebreak 靠流动性 |
| 自评 | 无 edge(IC 微负) | 无显著超额(1日弱区分/5-10日近噪声) |

**重合点**:①原始指标计算层(technical);②趋势(MA排列)、动量(MACD+RSI)两个维度在两侧都用,只是策略0拆进"技术趋势专家"、策略11拧进"状态格"。**互补点**:策略0是**先验规则**(缺经验校准,故追趋势追高吃亏);策略11是**后验经验分布**(数据驱动、天然规避"看着强其实要反转"的格,但粒度粗、个股无区分)。

### 4.2 合并方案(3 选 1,列优劣供共评;本轮不实现)

**方案A(推荐)— 用策略11的经验分布给策略0的技术专家"校准方向/强度"。**
把"技术趋势/动量"专家的输出**不再用手设 ±1 强度**,而是查该票当前状态格的历史上涨概率 p:方向由 p 相对 50% 定,强度由 |p−50|/归一定,置信度用匹配质量(精确/放宽1/放宽2)。这直接治本第二/三节发现的病(技术趋势方向系统性偏错、强度未校准),把先验规则换成经验校准。
- 优:根因对症;复用策略11 已有的 state_pool + conditional_scenarios;合议框架不变,只换"技术趋势/动量"这一路专家的适配器。
- 劣:依赖 state_pool 建池(数据线,全A ~3-4min/日);增加一个"条件化专家"的 IO;需回测确认校准后 IC 转正。

**方案B — 双层门:策略11 状态格上涨概率做策略0 的前置闸门/后置过滤。**
合议出看多后,再要求该票状态格 p≥某阈(如 ≥52%)才入选;或把 p 作为一个新专家(等权或按第三节权重)并进合议。
- 优:改动最小(加一个专家或一个过滤),两策略保持独立可回退。
- 劣:治标不治本(技术趋势那一路仍在拖);策略11 自身无超额,做硬门可能过度收缩样本。

**方案C — 合并成一个"技术合议"策略,砍掉重复扫描。**
策略0 与策略11 都全A逐票跑 technical.compute(策略11 更贵,单票 ~105ms、全A ~12min)。合成一条管线:一次 compute → 同时产 3 专家信封 + 状态格查询 → 合议(专家含"条件化"一维)→ 输出综合方向 + 上涨概率 + Top。
- 优:省一遍全A扫描;口径统一、前端一个入口;把方案A的校准 + 方案B的门都收进来。
- 劣:工程量最大;两策略当前各有独立 view/前端/回测,合并需重接 run_screen_all + 前端 + 记分卡登记;策略11 尚未接入每日跑(代码注释明确"待用户点头"),合并会牵动上线节奏。

**共评建议**:先做**方案A 的离线回测验证**(校准后技术专家的 per-expert 超额是否转正、合议 IC 是否转正),验证 OK 再决定是否上升到方案C 的工程合并;方案B 作为"低成本立即可试"的过渡。

## 五、自审

1. **防未来函数**:观测口径只读信号日 T 落盘的 view、收益取 T 之后价;历史回测信号日前算专家方向、之后取前向收益,h 仅当 idx+h<len 才计(未到期排除);市场基线同样只用已到期。A/B 合议模拟同一口径。无未到期收益泄漏。
2. **per-expert 归因有据/样本量**:口径B 样本充足(技术趋势 3.8万、超买超卖 7.5千、拐点 2.4万),双种子(464票/236票)结论一致 → 归因稳。口径A 样本薄(top20×16日)且有选择偏差,已明确降级为"佐证",不作主判据。拐点全看多、无看空样本,其"超额"只反映看多侧。
3. **权重建议有数据支撑**:有——直接用合议综合方向 A/B(30,548 点)证明降趋势升超卖使 5日超额 −0.3%→+0.4%;并诚实标注 edge 仅 ~0.5~1pp、非强 alpha、需拉长样本与分市场态复核。
4. **合并方案可评**:3 方案各给优劣 + 依赖 + 推荐验证路径(方案A 离线回测→C 工程合并,B 作过渡),可直接进入共评/立项。

### 假设与未决
- 假设 master 前复权 K 线(2018-2026、5550 票)口径与线上一致;抽样宇宙(random 子集)的方向基线近似全市场涨跌面。
- 未做:分市场态(牛/熊/震荡)分层、全量票池(仅抽样 236~464 票)、方案A 的实际校准回测(需 state_pool)。这些是落地前建议补的。
- 数值随抽样种子有 ~0.5~1pp 抖动;结论方向(排名、reweight 改善符号)在双种子下稳健。
