## 1. 策略 0 · 全A 多专家合议

**是什么**:不新增算法,把技术指标交给 8 位"专家"各自投票,加权合成一个 −1~1 的**综合分**,全A 按综合分降序取 Top20。是"谁更强"的**排序/打分**,不是"买不买"的信号。

**怎么算(公式)**:每位专家 v 给出 方向、强度 `stg∈[-1,1]`、置信度 `conf∈[0,1]`;综合分
```
S = Σ(强度ᵥ × 置信度ᵥ × 权重ᵥ) / Σ(权重ᵥ × 置信度ᵥ)
综合方向 = 看多(S≥τ) / 看空(S≤−τ) / 中性        # τ=0.15
```
弃权专家 `conf=0`,不入分母不稀释。全A 最小记录下,资金流/情绪/多因子/事件维度**无数据→自动弃权**,实际只有技术趋势/超买超卖/拐点/板块轮动在场(故是"**技术面合议**")。

**怎么回测**:排序型 → `backtest_rank.py`。逐历史日 t 用 `kdf.iloc[:t+1]` 算综合分(无未来函数),横截面对齐(真实日期)算:① **IC**=每日 Spearman(综合分, 前瞻 N 日收益) 的时序均值/ICIR/t;② **分层**十档均收益;③ **TopK** 超额。

**回测效果**(随机 299 只 · 1.6万观测 · IC 有效 98 日):IC 5日 −0.011(t=−0.55)/ 10日 −0.025(t=−1.13)/ 20日 −0.031(t=−1.31),**均不显著、微负**;TopK 超额 −0.05~−0.58%。→ **无 edge**。关键局限:能带 alpha 的资金流/情绪/基本面维度全弃权(无历史快照)。

## 2. 策略 1 · 趋势深跌反包(S01)

**是什么**:强势(贴 52 周高、均线多头)个股盘中深跌但收阳,抢反包。**单日触发买入信号**。

**怎么算(公式)**:C1..C4 全真即 SELECT(`screen_s01.signal_at`):
```
C1 均线完整多头:MA5>MA10>MA20>MA30>MA60>MA200 且 收盘≥MA5
C2 贴近52周高:  0.9×H52 ≤ 收盘 ≤ 1.2×H52     (H52=前250日最高,不含当日)
C3 近10日偏强:  近10根 收阳数 > 收阴数
C4 当日深跌收阳:(最低−前收)/前收 ≤ −4%  且  收盘>开盘
SELECT = C1 ∧ C2 ∧ C3 ∧ C4
```
离场(状态机,`THRESHOLDS['趋势深跌反包']['离场']`):硬止损 0.97 / 跌破 MA13 / 加速止盈(3日≥25%)/ 放量滞涨 / 时间成本(>10日且收益<5%)。

**怎么回测**:信号型 → `position_backtest.simulate_position`。全A 前复权 raw,信号日收盘 P0 建仓 → 逐日 5 条离场状态机;一字板不可成交顺延;防未来函数;相对沪深300 算同持有期 Alpha。

**回测效果**(全A 5124 只 → 出信号 670 只 · N=1405 笔):胜率 **12.6%**、中位 **−3.0%**(=硬止损)、均 **−0.34%**、盈亏比 6.04、Alpha **−0.14%**、**硬止损即死 86.5%**、平均持有 2.2 天;**t=−1.42, p=0.15 → 不显著**。参数敏感性(放宽止损/深跌阈值)结论:**救不活**。→ 🔴 不支持有正超额。

## 3. 策略 2 · 放量后缩量回踩(S02)

**是什么**:先放量拉升、随后缩量回踩到均线附近的低吸信号。**单日触发**。

**怎么算(公式)**(`screen_s02.signal_at`,`THRESHOLDS['放量后缩量回踩']`):
```
C1 周线近期放量:REF(周量,1) > MA(周量,8)×1.6  OR  REF(周量,2) > MA(周量,8)×1.6  (当周在途不计)
C2 短均多头:    MA5 > MA10
C3 收阴且收跌:  收盘<开盘  且  收盘<前收
C4 地量:        当日量 ≤ MA(量,10)×0.70
C5 贴线:        |收盘−MA10|/MA10 ≤ 0.03
SELECT = C1 ∧ C2 ∧ C3 ∧ C4 ∧ C5
```
离场沿用 S01 状态机(机械基线,便于横比)。

**怎么回测**:同 S01 持仓回测器,信号源换 S02。**注意口径**:子集回测(全A 等距抽样 427 只)+ 信号日收盘机械买入,**非最终买法、非全A 定论**。

**回测效果**(子集 427 只 · N=1162 笔):胜率 **31.6%**、中位 −1.07%、均 **+0.33%**、盈亏比 2.64、Alpha **+0.14%**、平均持有 3.5 天。→ 🟡 略正,但子集 + 机械基线,**不足定论**。

## 4. 策略 3 · 箱体形态

**是什么**:一段窄幅横盘(箱体)后,放量向上突破箱顶。**单日触发买入信号**。

**怎么算(公式)**(`screen_box`→`detect_box`,`THRESHOLDS['形态选股']['箱体']`,窗口=30):
```
窄幅:不含末根的 30 根箱体 (箱顶−箱底)/箱底 × 100 ≤ 12%
突破:收盘 > 箱顶 × (1 + 3%)
放量:末根量 > 前 30 根均量 × 1.5
SELECT = 窄幅 ∧ 突破 ∧ 放量
```
`detect_box` 只看"不含末根的箱体 + 末根突破",截 [0,t] 识别,无未来函数。离场沿用 S01 状态机。

**怎么回测**:信号型 → `backtest_box.py`(克隆 `backtest_s02` 骨架,信号源换 `screen_box`,离场同口径)。全A 5208 只、相对沪深300 Alpha。

**回测效果**(全A · N=1415 笔):胜率 **31.2%**、中位 −3.0%、均 **+0.74%**、盈亏比 3.03、**Alpha +0.32%**、**硬止损即死 61%**、平均持有 4.2 天。→ 🟡 弱正(≈S02 档次),Alpha 经济上极小、大概率不显著,即死率仍高。

## 5. 策略 4 · 动量组合(A 腿)

**是什么**:按"加权对数动量"给全A 打分,取最强的 TopK。**排序型选股**(B 腿需基本面,全A 不跑,仅 web 自选池)。

**怎么算(公式)**(`momentum.weighted_log_momentum`,回看 25 日):
```
对最近 26 根 log(close) 做**权重递增**加权最小二乘:权重 = linspace(1,2,n)²
score = (exp(斜率 × 250) − 1) × R²        # 年化对数收益 × 拟合优度,越大越强势
```
R² 闸门滤掉"伪趋势",低通信号过滤噪声,按 score 降序取 TopK。

**怎么回测**:排序型 → `backtest_rank.py`(打分=`weighted_log_momentum`),IC/分层/TopK,同策略0 口径。

**回测效果**(随机 499 只 · 4.5万观测 · 273 日):**IC 5日 −0.048(t=−2.91)/ 10日 −0.067(t=−3.87)/ 20日 −0.069(t=−4.04),显著为负**;TopK(实际选股口径)超额 −0.03~−0.13%、Top−Bottom 全负。→ 🔴 **A股短期是反转市,选强动量票反跑输均值,不建议现状上线**。

> 追加验证(反转因子):反做动量/纯 N 日反转虽 IC 显著正(rev_mom IC +0.05~0.07,t 2.9~4.0),但**多空净成本后≈0**、且**流动性前50%里 edge 归零**——反转是"账面异象、不可交易"。详见 [策略0_3_4_回测方案与预注册预期.md](../计划/策略0_3_4_回测方案与预注册预期.md) §6。

## 6. 预测引擎 · 止跌线 / 止盈线(两条线)

**是什么**:给选出的票,从技术面估**该跌到哪止损、涨到哪止盈**,以及历史收益区间/上涨概率。是**风控刻度**,不预测方向。`tools/analysis/predict.py`。

**怎么算(公式)**:
```
【波动率括号】ATR% = ATR(14)/现价×100;band_N = ATR%×√N
   止损位 = 现价×(1 − 1.2×band_N/100)   止盈位 = 现价×(1 + 1.6×band_N/100)   (倍数经回测调参)
【历史频率】 对历史每日 r=close[t+N]/close[t]−1 → 上涨概率、悲观/中位/乐观 = q7/q50/q93 分位
【L3 结构锚定】支撑/压力=swing pivot(左右各8根);放量突破/箱体/回踩 分情景锚定
   止损=支撑×(1−buffer),止盈=压力×(1−小缓冲);buffer=max(1%, 1.0×ATR%)   (经回测调参)
```

**怎么回测**:5 指标事件研究(`backtest_predict.py`,逐日切片喂真 predict,无未来函数,随机全A 29 万观测):止损触发率 / 止盈先于止损命中率(带真实盈亏比算 E)/ 区间覆盖校准 / 上涨概率校准 / 叠加方向信号后期望。

**回测效果 + 调参**:①波动率括号 ~80% 到期未触,是外层包络;②L3 锚定调参后止损误扫 10日 32%→24%;③区间覆盖调参(分位[10,90]→[7,93])72%→**80%**;④**上涨概率是纯噪声**(Brier≈0.25、各分箱都塌到50%基础率)→ 不当胜率;⑤偏买入择时全A 无 edge。详见 [预期价位预测.md](预期价位预测.md) §回测验证结论。

## 7. 回测方法学(统一,防未来函数是命门)

- **无未来函数**:逐历史日 t **只用 `kdf.iloc[:t+1]`** 算信号/打分/预测;进场锚 t+1;前瞻收益只取 t+1 及之后。红线由单测锁死(构造未来极端数据不得改变 t 时刻信号)。
- **两类口径**:信号型看胜率/盈亏比/Alpha/即死率(持仓状态机);排序型看 IC(预测力)/分层/TopK(横截面,真实日期对齐)。**不可混用**。
- **样本**:随机全A 抽样(破自选池"偏成长"偏差);基准沪深300;窗口约 1.5 年(偏多,须声明)。
- **诚实**:带样本量与显著性,不足标"待观察",绝不编准确率;信号型机械基线明确标"非最终买法"。

## 8. 总结论(2026-08-13)

**纯量价·日频这口井挖到底:没有一个策略或预测项跑出统计显著的正 alpha。** 箱体/S02 弱正但不显著,S01 显著平庸,动量显著为负,合议持平,反转账面真但不可交易;预测两条线是调好的风控工具、不是赚钱工具,上涨概率无效。

**这不是白干**——用数据挡下了几个"看着专业、上线会亏"的策略,并沉淀了回测 harness(信号型 `backtest_box`/`position_backtest`、排序型 `backtest_rank`、预测 `backtest_predict`)+ 预注册纪律。

**数据指向的下一步**(非纯量价日频):①补**数据维度历史快照**(资金流/情绪/基本面)让合议有料;②"强而不极端"动量(需独立预注册再测);③箱体调参(放量倍数/回踩确认)看能否抬到显著。
