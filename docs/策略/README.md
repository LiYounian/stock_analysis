# 策略文档索引

> 本文件夹收纳项目**目前已实现的所有策略**,一策略一文档。本 README 是索引:标注每份文档**是什么策略、应用到哪、在什么模块、起什么作用**。
> **权威口径**:阈值/公式的单一真源是 [`tools/config/strategy.py`](../../tools/config/strategy.py);各文档是它的人读版。
> ⚠️ **免责**:所有信号/预测基于历史统计与波动率,是概率非预言,**非投资建议,风险自负**。

## 策略如何串起来(端到端)

```
① 采集   数值面(K线/基本面/公告/资金流)+ 消息面(新闻/股吧/政策),按日期落盘
                    │
② 技术判定 technical.py ── 趋势评级 / 拐点 / 超买超卖 …………………… 技术判定策略.md
                    │
③ 情绪    event.py ── 三层 LLM 打分 → 加权净情绪分 ………………………… 情绪三层策略.md
                    │
④ 预测    predict.py ┌─ 支撑/压力位 ┐
                     ├─ 止盈止损位  ├─ 涨到/跌到多少、概率多大 ………… 预期价位预测.md
                     ├─ 情景预测   ┘
                     └─ 买卖倾向(多因子打分,含情绪)………………………… 买卖倾向决策.md
                    │
⑤ 组装   serialize.py ── 汇成中心记录(过契约校验)→ 按日期存储
                    │
⑥ 选股/回测 screener/strategy/backtest ……………………………… 选股策略.md / 回测策略.md
                    │
⑦ 展示   Web 个股页:K线+止盈止损线 / 情景表 / 三层情绪 / 买卖倾向
```

## 阅读建议
- 只想知道**"预期涨到多少、跌到多少"** → 直接看 [预期价位预测.md](预期价位预测.md)。
- 看不懂某个指标/参数 → 查 [术语与参数速查.md](术语与参数速查.md)。
- 想改阈值 → 改 [`tools/config/strategy.py`](../../tools/config/strategy.py) 的 `THRESHOLDS`(唯一真源),各文档同步说明。
