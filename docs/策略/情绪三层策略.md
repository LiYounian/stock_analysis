# 情绪三层策略(新闻 / 舆情 / 政策 加权)

> - **是什么策略**:把消息面拆成新闻/舆情/政策三层,各自 LLM 打分,再按信源可靠性加权成一个净情绪分。
> - **应用到哪**:作为一维输入并入[买卖倾向决策](买卖倾向决策.md);个股页"情绪面"三层展示。
> - **应用在什么模块**:`tools/analysis/event.py`(采集在 `collectors/news.py`·`ugc.py`·`policy.py`)。
> - **起什么作用**:把非结构化的消息量化成可比较、可并入决策的分数。
> 名词见 [术语与参数速查.md](术语与参数速查.md)。

## 三层与加权
```
每层净情绪 = Σ(方向 × 强度) 归一到 [−1, 1]     # 方向:利好+1 / 利空−1 / 中性0,强度由 LLM 给
总净情绪分 = 0.5×新闻 + 0.3×政策 + 0.2×舆情
           (缺某层则丢弃该层,对存在层重新归一 → 天然向后兼容)
```
- **权重依据(信源可靠性)**:新闻(事实)> 政策(方向)> 舆情/股吧(散户噪声,权重最低)。
- **来源**:新闻 = 东财个股新闻(备源财联社电报);舆情 = 东财股吧帖子;政策 = 东财按行业关键词检索(备源新闻联播)。
- 打分走 LLM,结果按内容 hash 缓存(改下游免重复烧钱)。

## 并入决策
总净情绪分按阈值并入买卖倾向:`≥ +0.2 → +2`、`≤ −0.2 → −2`(样本数为 0 不计)。**非决定项**,只是一维。

## 实例(688521)
新闻 **+0.6**(偏多)、舆情 **−0.5**(偏空)、政策 **+0.619**(偏多)→ 加权净 **+0.386** → 触发"情绪偏多 +2"。
> 三层可以互相矛盾(这里舆情偏空但新闻/政策偏多),加权后由可靠性更高的层主导。

## 局限
情绪依赖 LLM 打分;缺层降级重归一(不崩但信息变少);股吧信噪比低,故权重最低。
