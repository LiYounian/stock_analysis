# 预期价位预测(支撑压力 / 止盈止损 / 情景预测)⭐

> - **是什么策略**:回答"这票**预期涨到多少、跌到多少价钱、概率多大**"。
> - **应用到哪**:个股页的"止盈止损表""情景预测表""K线上的支撑/压力/止盈止损线"。
> - **应用在什么模块**:`tools/analysis/predict.py`(参数在 `tools/config/strategy.py['预测']`)。
> - **起什么作用**:给出可操作的目标价/止损价,以及基于历史的收益区间与胜率。
> 名词见 [术语与参数速查.md](术语与参数速查.md)。全程用**百分比**,与买几手、投多少钱无关(故不需要总资金)。

对每只票、每个**持有期 N**(默认 1 / 5 / 10 交易日),从**两条独立路径 + 一条辅助**给预期,互相印证。

## 路径一 · 波动率法 → 止损价 / 止盈价(该跌到哪止损、涨到哪止盈)
**思路**:能涨跌多少取决于票**自身波动(ATR%)**,持有越久波动越大(按 √N 放大——N 日累计波动 ≈ 单日 × √N)。
```
ATR%     = ATR(14日真实波幅均值) / 现价 × 100
band_N   = ATR% × √N                     # 持有 N 日的预期波动幅度(%)
最大亏损% = 止损倍数(1.0) × band_N
目标盈利% = 止盈倍数(1.6) × band_N
止损位   = 现价 × (1 − 最大亏损%/100)     ← 跌到这个价止损
止盈位   = 现价 × (1 + 目标盈利%/100)     ← 涨到这个价止盈
风险收益比 = 止盈倍数 / 止损倍数 = 1.6      # 赚的空间是亏的 1.6 倍
```
> 止损设得比止盈近(1.0 vs 1.6)= "亏损截断、利润奔跑"。

## 路径二 · 历史频率法 → 概率化收益区间(历史上大概涨跌多少、上涨概率多大)
**思路**:统计这票**历史上**每次持有 N 天的真实收益,汇成分布。
```
对历史每个交易日 t:  r = close[t+N] / close[t] − 1     # N 日前瞻收益
上涨概率 = P(r > 0)
悲观收益 = r 的 q10(只有 10% 历史比这更差)
中位收益 = r 的 q50
乐观收益 = r 的 q90(只有 10% 历史比这更好)
```
样本 < 20 判数据不足、不给分位(诚实拒绝)。

## 辅助 · 结构法 → 支撑位 / 压力位(关键价位)
```
压力枢纽:high[i] == max(high[i-window : i+window])    # window 默认 5
支撑枢纽:low[i]  == min(low[i-window : i+window])
支撑位 = 现价下方最近 2 个枢纽低点;压力位 = 现价上方最近 2 个枢纽高点
```
> 历史多次触碰后反转的价位,往往再次形成阻力/支撑。

## 完整实例(真实数据:芯原股份 688521,2026-08-06)
现价 **217.17**,ATR% = **10.38**(波动很大)。

**止盈止损位**:

| N | band=ATR%×√N | 止损位(最大亏损%) | 止盈位(目标盈利%) | 盈亏比 |
|---|---|---|---|---|
| 1日 | 10.38 | 194.63(−10.38%) | 253.22(+16.60%) | 1.6 |
| 5日 | 23.21 | 166.79(−23.20%) | 297.78(+37.12%) | 1.6 |
| 10日 | 32.81 | 145.92(−32.81%) | 331.18(+52.50%) | 1.6 |

验算(5日):band=10.38×√5=23.2 → 止损=217.17×(1−0.232)=166.79,止盈=217.17×1.371=297.78 ✅

**情景预测**:

| N | 上涨概率 | 悲观 q10 | 中位 q50 | 乐观 q90 | 样本 |
|---|---|---|---|---|---|
| 1日 | 49.4% | −6.11% | −0.02% | +6.38% | 324 |
| 5日 | 50.0% | −10.61% | +0.07% | +15.74% | 320 |
| 10日 | 52.7% | −15.30% | +0.90% | +27.19% | 315 |

**支撑/压力**:支撑 [208.0, 203.67],压力 [237.79, 258.65]。

**怎么读**:持有 5 日,操作上"跌到 166.79 止损、涨到 297.78 止盈";但历史频率看 5 日上涨概率仅 50%、乐观也就 +15.74% → **止盈目标 +37% 偏激进、历史很少达到**。这正是两条路径互相印证的价值:**波动率法给纪律,历史频率法给现实预期**。

## ⭐ 回测验证结论(2026-08-12,随机全A 29 万观测 · 严格无未来函数)

> 首次对这两条线做量化验证。harness:`tools/backtest/backtest_predict.py`;全过程见 [计划文档](../计划/预测两条线_回测验证与调参_计划.md)。⚠️ 结论为"历史统计",非未来保证。

**一句话:这两条线是站得住的「风控刻度」,但不产生 alpha;其中「上涨概率」在代表性全A上近乎无效,不应当胜率用。**

| 验证项 | 结论 | 处置 |
|---|---|---|
| **上涨概率校准** | ❌ 全A 上各预测分箱实际上涨率都塌到 ~50% 基础率,Brier≈0.25(≈掷硬币)。无条件历史频率,信息量极弱 | **不当胜率呈现**;`scenarios` docstring 已标注;页面待弱化 |
| **区间覆盖** | 原 [q10,q90] 只覆盖 ~72%(应 80%),低估肥尾 | 情景分位 **[10,90]→[7,93]**,全A 覆盖回到 ~80% |
| **止损触发率(L3)** | 原参数下 10 日达 32% 被扫 | swing窗口 **5→8** + 止损缓冲 **0.5→1.0**,10 日降到 ~24%,实测不降 |
| **止损触发率(括号)** | 原 11% | 止损_ATR倍数 **1.0→1.2**,降到 ~6%,EV 不降 |
| **叠加方向信号(偏买入)** | 全A 上无可测 edge(实测≈0)→ 这套括号本身不赚钱,需真有 edge 的方向信号才有意义 | 诚实标注;不宣称预测能力 |

**定稿参数(已写回 `strategy.py['预测']`,provenance 在注释)**:止损_ATR倍数 1.2 · 止盈_ATR倍数 1.6 · 情景分位 [7,50,93] · swing窗口 8 · 止损缓冲ATR倍数 1.0。
**样本**:随机全A 300~700 只(破自选池"偏成长"偏差),自选池调、全A验,换种子防偷看。复现:`python -m tools.backtest.backtest_predict --sample 700 --seed 42 --step 2`。
