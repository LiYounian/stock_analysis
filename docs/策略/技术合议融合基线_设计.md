# 技术合议「融合基线」· 设计与预注册判据(Phase A)

> 分析·非投资建议。分支 `feat/council11-fusion-baseline`。本文=融合分设计口径 + **预注册达标判据**。
> 回测结论见同目录《技术合议融合基线_回测结论.md》(回测跑完后写)。
> 工具:`tools/backtest/fusion_lab.py`。数据产物:`data/analysis/backtest/{fusion_panel.parquet,fusion_lab.json}`。

## 背景

策略0 合议专家拆分已证(见《策略0合议_专家拆分重建_回测结论.md》):全A 只 3 个技术专家在场——
**超买超卖**(rank-IC +0.040 稳定为正,但稀疏,仅约半数日发声)、**拐点**(温和良性,Top10 超额显著)、
**技术趋势**(rank-IC **−0.046 显著反向**,是现状等权综合分的拖累根因)。现状 council 等权(V0)综合分
rank-IC=−0.0105 几乎无选择性。删趋势(V2)可把 rank-IC 翻正到 +0.041。

本轮不再停留在"删/降权某专家",而是**洗牌重建**一条独立的"技术融合分":把经过验证的技术信号
在**横截面 zscore** 空间里重新线性复合,吸收三条改进线索:① 超买超卖作核心正因子;② 技术趋势
**反用**(负权重反转因子);③ 补一层**稠密的结构化均值回归指标**(策略11 的状态条件指标之连续形态)
填平超买超卖专家的稀疏缺口。

## 融合分口径

逐信号先做**逐日横截面 zscore**(去量纲,防单信号尺度主导),再按符号/权重线性复合:

```
fuse(票, 日) = Σ_k  sign_k · w_k · z_day( signal_k )
```

| key | 原始信号(列) | sign | 角色 | 依据 |
|---|---|---|---|---|
| os | `str_超买超卖`(signed:超卖→+) | +1 | 核心正 | 合议好专家,solo IC +0.040 |
| rev | `str_拐点`(≥0 看多) | +1 | 次级正 | 温和良性,Top10 超额显著 |
| trend | `str_技术趋势`(signed) | **−1** | 反转候选(负权重) | solo IC −0.046 显著负 → 反用 |
| bias | `bias20`(乖离率) | −1 | 结构化状态 | 越低越超跌→均值回归看多(稠密) |
| pctb | `boll percent_b` | −1 | 结构化状态 | 越低越贴/破下轨→超跌看多(稠密) |

- **动量不并入**:动量 edge 仅在 1 日,并入 5 日尺度会周期错配;动量保持独立策略。
- **策略11 用其指标不用其离散排序**:只取 `bias20 / percent_b` 连续值(technical.compute 纯 K 线算出,
  无数据文件依赖、防未来函数),不用其"离散状态格 → TopK 排序"(已证离散状态格无区分度)。

## 权重两版(都回测报)

1. **等权 zscore 复合(基线)**:各参与信号 w_k=1。
2. **IC 加权**:w_k ∝ |该信号有符号 z 的历史 rank-IC|(符号仍由上表 sign 固定)。
   注:IC 权重在**同一面板**上估(in-sample),存在轻度乐观偏差,结论以"是否稳健优于 council 基线"为准,
   不追求 IC 权重的绝对最优。

## 配置矩阵(回答"技术趋势反用引不引入")

| 配置 | 参与信号 | 用途 |
|---|---|---|
| F0 核心正 | os + rev | 不含趋势的融合基线 |
| F1 核心正+反用趋势 | os + rev + trend(−) | 检验反用趋势是否带来正增量 |
| F2 核心正+结构态 | os + rev + bias(−) + pctb(−) | 检验结构化态是否补稀疏 |
| F3 全量 | os + rev + trend(−) + bias(−) + pctb(−) | 全叠加 |

**技术趋势反用判定**:比较 F1 vs F0(及 F3 vs F2)。仅当**加入反用趋势后 rank-IC 与 Top-N 扣成本超额
同向改善**才把 trend 纳入负权重;否则不引入(别硬塞)。

## 选股与评测

- 选股:**主榜 Top10 + 精选 Top5** 两档并列。
- 评测(复用 `eval_v3.stats`,深历史 + 防未来函数):
  - rank-IC / ICIR(逐日截面 Spearman,跨日 t/p);
  - Top5/Top10 **gross** 超额 + **net**(扣往返成本 0.1% / 0.2%)超额,均按**日聚类** bootstrap p;
  - 全宇宙基线 = 当日面板内全票 5 日等权(与融合分同口径);
  - **同一面板**复算 council V0(等权)/V2(删趋势),做 apples-to-apples 相对增量对比。

## 预注册达标判据(Phase A → 进 Phase B 的闸门)

融合分需**同时**满足:

1. rank-IC **显著正**(p<0.05,方向与幅度稳定,ICIR 为正);
2. Top-N(至少 Top5)**扣成本后**(net,0.2%/往返)超额**显著正**(聚类 p<0.05);
3. **明显优于 council 等权基线(V0)**,且不劣于删趋势基线(V2)。

**达标** → 进 Phase B(接入生产 + 下线策略11 + 修齐全度)。
**不达标** → 停在 Phase A,如实报告"融合基线未达标,建议不上线 / 换配方",不硬接生产。

## 防未来函数自证

- 信号 as-of:`sub = df.iloc[:idx+1]`,technical.compute 只取最后一根及之前;
- 前向收益:`fwd_h = close[idx+h]/close[idx]−1`,只用 idx 之后价;
- 横截面按**真实交易日日期字符串**对齐;基线与融合分同口径(同日同全宇宙)。
