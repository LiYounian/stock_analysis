# 多因子截面打分选股(F6)

> **应用到哪**:全 A 票池横截面打分排序,产出"多因子"专家结论,供多策略合议勾选。
> **应用在什么模块**:`tools/analysis/factor/`(计算)+ `tools/analysis/experts.py`(专家适配)+ 合议 `council.py`(消费)。
> **起什么作用**:把零散财务/估值/量价规则升级为**低换手多因子横截面排序**,给合议提供一维稳健、与技术/情绪互补的"质地+估值+资金"综合判断。

## 一、为什么这样设计(A 股铁律)

A 股**动量弱、反转强**,单纯"追涨最强"长期不赚钱(见 [调研](../参考/选股与收益支点策略_网络调研.md) §类别1)。故:
- **规避纯价格动量**:动量不进正向合成;如启用仅作反向护栏,绝不裸用。
- **优先低换手因子**:质量/价值/低波/成长/股息 + 资金流(北向),换手低、成本拖累小,贴合离线批量架构。

## 二、因子清单与数据可得性(本机实测)

| 因子 | 子指标(方向) | 数据源 | 可得性 |
|---|---|---|---|
| 质量 | ROE(+)· 毛利率(+)· 负债率(−) | 同花顺财务摘要 | ✅ |
| 价值 | PE_TTM(−)· PB(−) | 百度估值 | ✅ |
| 低波 | 年化波动率(−,60日日收益 std×√244) | K线(腾讯) | ✅ |
| 成长 | 净利增速(+) | 同花顺 | ✅ |
| 股息 | 股息率(+) | 记录暂无 | ⚠️ 降级缺失(不改采集) |
| 资金流 | 北向净流入趋势(+,D8,5–10日) | 东财北向个股明细 | ⚠️ 本机不可用→I4 降级缺失,接口在 `collectors/northbound.py` 留好 |

> 方向:+1 越大越好 / −1 越小越好;截面分位标准化后据此定向,使"高分=好"。
> 缺因子按 I4 降级:该维度不参与,其余因子照算,**置信度 = 因子齐全度**随之下降。

## 三、算法(公式)

1. **截面标准化**(I3 默认**分位**,对 A 股肥尾稳健;可 zscore):每个子指标在全票池内取中位秩分位 ∈ (0,1),按方向定向(越小越好则 1−分位)。
2. **子指标 → 因子**:因子分 = 其子指标定向分位的均值(跳过缺失)。
3. **因子 → 综合分**(I2 默认**等权**,权重落 config):综合分 = Σ(因子分 × 权重)/Σ权重(跳过缺失因子)。
4. **综合分 → 强度/方向**:综合分的截面分位 p → 强度 = clamp((p−0.5)×2, −1, 1);方向 = 强度符号(看多/看空/中性)。
5. **置信度** = 因子齐全度(有数据因子数 / 6);数据充分度:全 = 充分、部分 = 部分降级、无 = 缺失。

参数单一真源:`THRESHOLDS["合议"]["多因子"]`。

## 四、专家信封(过 F1 契约)

`ExpertVerdict(专家="多因子", 能力类型="评级", 方向, 强度, 置信度=因子齐全度, 依据=各因子分位, 数据充分度, 原始=综合分/分位/各因子分位)`。

## 五、落库 / 注册 / 消费(三对齐)

- **实现**:`factor.raw_factors`(单票原始)+ `score.cross_section`(截面合成)+ `score.precompute`(全票池→落 code_view `factor`)。入口 `python -m tools.analysis.factor.score --universe N`。
- **注册**:`experts.BUILTIN["多因子"]`(遵 D4:先适配器、不动 registry 地基);默认权重 `config 合议.默认权重.多因子=1.0`。
- **消费**:合议 `council.convene` 勾选"多因子"即纳入加权;综合分/分位/各因子分位存 code_view `factor`(横截面产物),专家读之(因子分无法由单票现算)。
- **验证**:`score.monotonicity` 分层单调性(高分组前瞻收益应 ≥ 低分组);真回测扣成本在批次C/BT.1。
