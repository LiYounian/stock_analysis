# 选股策略(预设筛选 + 可注册策略)

> - **是什么策略**:按规则从票池里筛出候选股;并提供可插拔的三类策略注册框架。
> - **应用到哪**:选股页的预设分组;回测层的信号来源。
> - **应用在什么模块**:`tools/screener/screen.py`(预设)、`tools/strategy/registry.py`(注册框架)。
> - **起什么作用**:把判定/预测结果落成"挑哪些票",并支持未来扩展新策略。
> 名词见 [术语与参数速查.md](术语与参数速查.md)。⚠️ 预设阈值为**合理默认,待用户按实际口径细化(N1)**;票池目前固定(开发期用随机 10 只)。

## 1. 预设选股(`screener/screen.py`)
读中心记录逐票过滤,命中即入选(多条件取 AND):

| 预设名 | 命中条件 | 用意 |
|---|---|---|
| 超跌反弹候选 | 有拐点标签 且 拐点评分 ≥ 25 | 抓超跌反弹机会 |
| 主力吸筹 | 主力连续净流入 ≥ 2 天 且 今日净流入 > 0 | 跟资金 |
| 趋势强势 | 趋势评级得分 ≥ 30 | 顺势 |
| 质地优不高估 | ROE 达标 且 PE 有效 | 基本面过滤 |
| 反弹+资金共振 | 「超跌反弹候选」且「主力吸筹」 | 技术+资金双确认 |

结果按趋势得分降序。

## 2. 可注册策略框架(`strategy/registry.py`,`@strategy` 装饰器)
三类标准签名,登记进注册表后按名调用(可插拔/可独测/可并行):

| 类型 | 签名 | 已实现示例 |
|---|---|---|
| **信号 Signal** | `fn(kline_df) -> list["买/卖/持"]` | **均线金叉**:短均线(5)上穿长均线(20)→买,下穿→卖,其余持;逐日输出喂回测 |
| **评分 Score** | `fn(record) -> {score, 依据}` | **买卖倾向评分**:只读汇总记录里已算好的买卖倾向 |
| **选股 Screen** | `fn(records) -> [code...]` | 上面 5 个预设自动注册进来 |

> **为什么要注册框架**:让新策略只需写一个标准函数 + 加装饰器即可接入,不改调用方;也为未来"Agent 自动发现调用"留口。
