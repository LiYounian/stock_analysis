# 策略 S04 · 量价放量(3 可勾选子信号)

> 来源:外部 PR#15 提取重做(原为独立 screen 脚本 + 独立页)。按用户裁决做成**一个 screener + 3 个可勾选布尔子信号**,复用 /selection「勾选并集」面板(combined-section 模式,**非 council 投票**)。
> 类型:**信号型 · 看多**。参数真源:[`tools/config/strategy.py`](../../tools/config/strategy.py) `THRESHOLDS["量价放量"]`。
> ⚠️ **非投资建议**。

## 是什么
"**放量突破/上涨**"型筛选,与 S02「放量后缩量回踩」**互补**(S02 买放量*之后*的缩量回踩;S04 买放量突破/上涨*本身*),故并存不去重。3 个子信号共享指标计算,命中任一即入选;`入选清单[].组合` 记命中哪几个。面板 3 个子信号勾选框按**命中形态并集**实时过滤。定位=过滤器/观察池。

## 怎么算(公式,均前复权,当日=第 t 根)
```
单日放量:turnover(t) > 1.7×turnover(t-1) ∧ C(t) > C(t-1)×1.03 ∧ MA200(t)>MA200(t-1) ∧ MA50>MA200
         # 换手 turnover 读 master 列(免费源 baostock/akshare-spot);该列 NA → 本子信号跳过该票
低位放量:C > MA5/10/20/30/200(全) ∧ 上穿30周线 ∧ V(t)=近10根最大量
         # 上穿30周线:C(t)>WMA30(t) 且 C(t-1)≤WMA30(t-1);周线按 ISO 自然周、当周用今收(无未来函数)
连续放量:C>REF(C,1)且C>REF(C,2) ∧ (C/REF(C,1)-1)>0.04 且 (C/REF(C,2)-1)>0.04 ∧ V(t)>V(t-1)
         ∧ C>MA20/50/200 ∧ MA5>MA20 且 MA10>MA20
SELECT = 命中任一子信号
```
复用 `indicators.ma` + 本模块 `_weekly_ma`(30 周线动态、无未来函数)。历史 < 201 根不选。

## 怎么回测
同 S03 前瞻收益法,**按 3 子信号分桶**。详见 [S04回测报告_20260821.md](../计划/S04回测报告_20260821.md)。

## 效果(诚实,样本级)
- 250 只分层样本 / 27 测试日:整体命中组 **T+10 均值 +1.40% > baseline +0.36%**(方向符合看多),胜率 45.4% 偏低(右偏/动量)。
- 分子信号:**单日放量** T+10 +2.64% / T+20 +1.92%(方向最明显,收益延后 1-2 周);**连续放量** T+10 +1.88%(温和正向);**低位放量 样本内无 edge**(T+5 −0.67% / T+10 −0.14%)——面板可勾但标注"未验出 edge",待全A 复验/调参(周线周期、加量能确认)。
- **样本级方向性 sanity,非全A alpha**。
