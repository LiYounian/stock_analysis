# 策略0 合议 · 专家拆分 + 权重组合重建 · 横截面回测结论

> 分析·非投资建议。分支 `feat/council-expert-split`。**本文只给回测结论+改进方案(供共评),不真改 strategy.json / 专家默认权重 / 策略逻辑。**
> 数据产物:`data/analysis/backtest/council_weight_lab.json`(横截面 rank-IC + Top-N)、`data/analysis/backtest/expert_scorecard_split.json`(逐专家方向命中,交叉验证)。
> 工具:`tools/backtest/council_weight_lab.py`(新增,横截面实验室,不改策略)。

## 背景与动机

策略0 合议(全A)实际只有 3 个技术专家在场:**超买超卖 / 拐点 / 技术趋势**(新闻/情绪/资金流/多因子/事件/板块因全A无对应数据天然弃权)。
前序 `expert_scorecard.py` 只测**单专家方向命中率 + 合议综合方向的超额**,未测**综合分作为横截面排序器**的选择性。
用户指出"卡死单权重不严谨,应拆开重建组合再回测"。本轮把三专家信封(有符号强度/置信度)采到**同一横截面面板**,
按多套权重重算合议综合分 `S=Σ(强度×置信度×w)/Σ(w×置信度)`(与 `council.convene` 完全同口径),做横截面评测。

**样本(防未来函数,信号日前算方向/之后取收益,与 expert_scorecard 同口径):**
739 只(master 抽样)× step15 → **面板 76017 行,覆盖 1618 个交易日**。基线=当日面板内全票 5 日收益等权。

## 三、结论

1. **技术趋势是拖后腿的根因,且是"显著反向",不是单纯权重过重。** 单独当排序器 rank-IC=−0.046(t=−4.5,p<0.001),方向命中超额 −1.6%。5日尺度上它的技术趋势评级与未来收益**显著负相关**(强趋势票 5 日跑输)。
2. **现状等权综合分几乎没有选择性:** rank-IC=−0.0105(不显著)、Top-N 超额≈0。好的超买超卖信号被有害的趋势信号稀释/淹没。
3. **超买超卖是唯一可靠为正的专家**(IC+0.040 p=0.018,方向超额+2.0%),但**稀疏**——只在真有超买超卖共振时发声(约半数交易日),单独无法给全宇宙排序。
4. **拐点温和且良性:** 单独 IC 不显著(+0.011 p=0.28),但 Top-10 超额 +0.105(p=0.028),适合当"榜首多头过滤器"、补齐覆盖度。

### 推荐配置(供共评)——**删除技术趋势,保留超买超卖+拐点(0/1/1)**

- **最优且最显著:** V2/V5 使 rank-IC 从 −0.0105 **翻正为 +0.041(t=4.16,p<0.001)——选择性恢复**;Top5 超额 +0.331%(p<0.001)、Top10 +0.147%(p=0.001)均显著;覆盖 1328 日(比纯超买超卖的 831 日密,靠拐点补齐)。
- **降权 vs 删除:** 降权(V4 趋势0.25)也改善(IC+0.024 p=0.015),但删除(V2/V5)在 IC 幅度、IC t 值、Top-N 超额上全面占优。**既然趋势 IC 显著为负,任何正权重都只拖累 → 删除是原则性选择。**
- **"按历史准确率反推的最优权重"≈删除趋势:** 权重 ∝ max(0, 单专家IC) = 超买超卖0.040/拐点0.011/趋势0,本质就是 V2/V5(略偏超买超卖)。V2/V5(两存活专家等权)已捕获几乎全部增益且最简。

### 重建后综合分选择性是否恢复:**是。**
rank-IC 由**负转正且显著**(−0.0105 → +0.041,t=4.16,p<0.001),Top5/Top10 超额显著为正。

### 诚实边界(扣成本)
Top-N 超额幅度小(0.15~0.33%/5日),A股单边往返成本约 0.1~0.2%。V2/V5 的 **Top5(+0.331%/5日,p<0.001)扣成本后薄有余量,Top10(+0.147%)约打平,Top20 任何方案都不显著**。edge 只集中在**榜首前 5~10 只**。定位为"止血 + 小幅正偏",非高收益策略。

## 四、可抽取供后续技术面融合的专家信号(仅记录,不实现)

1. **超买超卖(共振型 OB/OS)= 最值得抽取的单一技术信号**:方向超额最高最稳(+2.0%/5日)、rank-IC 正。宜作**条件触发器**(约半数日发声),不宜作全宇宙排序器。
2. **技术趋势作"反向/contrarian"因子**:其 rank-IC 显著为负(−0.046,t=−4.5)——**反用**(淡化强趋势、偏好弱趋势)可能是真实的 5日空头/反转因子,值得在融合层作**负权重输入**测试(本轮不实现)。这是最有意思的融合线索:"最差专家"携带真实的**反向**信息。
3. **拐点**:作榜首多头过滤器(Top10 超额 +0.105 p=0.028),非全宇宙排序器。
