# 回测策略(信号回测,walk-forward)

> - **是什么策略**:用历史数据回放一个信号策略,算出它的收益/回撤/胜率,并和买入持有对比。
> - **应用到哪**:验证[选股策略](选股策略.md)里的信号策略(如均线金叉)历史上到底赚不赚。
> - **应用在什么模块**:`tools/backtest/engine.py` + `metrics.py`(参数在 `strategy.py['回测']`)。
> - **起什么作用**:**防未来函数**地评估策略,拦住"看着好、实则偷价"的伪策略。
> 名词见 [术语与参数速查.md](术语与参数速查.md)。

## 回测口径(BT.1 信号回测,已实现)
```
walk-forward:逐日只用"当日及以前"的数据产生信号(严禁未来函数)
t+1 成交:  信号当天出、次日按收盘价成交(execution_lag=1)
单边成本:  5bp(手续费+滑点),买卖各扣一次
基准:     买入持有(buy & hold),算"超额收益"
年化口径:  每年 244 交易日
```

## 产出指标(`metrics.py`)
累计收益、年化收益、最大回撤、夏普比率、胜率、超额收益(相对买入持有)。

## 防未来函数(命门测试)
有专门测试锁死:用"非因果探针策略" + 篡改未来极端值,断言**更早的收益不变** → 证明策略只用了 t 及以前的数据。这是回测最容易翻车的地方,单独测试防回归。

## 实例
均线金叉 @ 000021 回测:**超额收益 −28%**——诚实拦截了一个"跑不赢买入持有"的差策略。
> 回测的价值不是证明策略好,而是**如实告诉你它到底行不行**。
