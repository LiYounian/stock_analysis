# 技术合议「融合基线」· Phase A 回测结论(预注册判据:**未达标**)

> 分析·非投资建议。分支 `feat/council11-fusion-baseline`。设计与预注册判据见同目录《技术合议融合基线_设计.md》。
> 工具 `tools/backtest/fusion_lab.py`;产物 `data/analysis/backtest/{fusion_panel.parquet,fusion_lab.json}`;运行日志 `run_fusion.log`。
> 面板:抽样 800 票 / 可用 739 / **面板行 76017 / 覆盖 1618 交易日**(与 council_weight_lab 同口径同规模,防未来函数)。

## 结论先行:**融合基线未达预注册标准 → 停在 Phase A,不接入生产、不下线策略11、不动齐全度。**

预注册三条(须**同时**成立):① rank-IC 显著正 ② Top-N **扣成本后**超额显著正 ③ 明显优于 council 等权(V0)。

- ① **达标**:融合分 rank-IC 显著正,且是所有排序器里最强(最优 F2 IC=**+0.065**,ICIR 0.17,t=6.3,p≈0)。
- ③ **达标(对 V0)**:远优于 council 等权 V0(IC −0.0105 无选择性、净 Top5 显著为负)。
- ② **不达标(致命)**:在预注册的 **0.2%/往返** 成本下,**所有**融合配置的 Top5/Top10 净超额**均不显著**
  (最好 F0 净 Top5 +0.05,p=0.47)。**扣成本后 edge 被交易成本吃掉。**
- 附加发现:在**净 Top-N 这一"可交易"维度上,已有的简单基线 V2(council 删趋势)反而优于新融合**
  (V2 净 Top5:0.1%→+0.231 p≈0、0.2%→+0.131 p=0.056;融合净 Top5 仅 +0.03~0.05 且不显著)。
  融合的优势**只集中在全宇宙 rank-IC(学术排序)**,**未转化为 Top-N 选股的扣成本净收益(可部署)**。

- **rank-IC 维度**:F2(os+rev+bias+pctb,**不含趋势**)最优(+0.065),IC 加权再微升到 +0.067。全面碾压 V0、优于 V2。
- **净 Top-N 维度**:0.1% 成本下 F0/F1 的 Top5 尚显著(p≈0.03–0.05);**0.2% 成本下全部失守**(p 0.44–0.98)。Top10 净超额一律不显著/转负。

  **rank-IC 选 IC加权、Top-N 选股选等权**;但两者**都过不了 0.2% 净 Top-N 的闸门**。

## 三、预注册问答

**技术趋势"反用"引不引入?** —— **验证为真的反转因子,但被结构化指标支配,最终不引入。**
- 反用趋势(−z(trend))单独 rank-IC 显著负复现(−0.046);叠到裸 os+rev 上**确有 rank-IC 增量**(F1>F0:+0.032→+0.046)。
- **但**一旦加入稠密结构化均值回归指标(bias20/percent_b),反用趋势**变冗余甚至微害**(F3<F2:+0.065→+0.063)——
  bias20/percent_b 已捕获了"弱趋势/超跌反转"的同一信息。**结论:反用趋势是真信号,但不独立;有结构化指标时不需引入。**

**等权 vs IC加权:** 见上,rank-IC 略偏好 IC 加权、净 Top-N 略偏好等权;差异不改变"未达标"结论。

**vs council 等权(V0)的增量:** 真实且显著(IC −0.011→+0.065;V0 净 Top5 显著负→融合 gross 显著正)。但**净额度不足以覆盖成本**。

## 四、为什么"rank-IC 大涨"却"不达标"

rank-IC 奖励**整条截面单调性**;Top-N 净超额奖励**极端头部 5~10 只、且要跑赢成本**。融合分把"稠密均值回归"
铺满全宇宙 → 整体排序对(IC 高),但**头部锐度不如** council 的"稀疏×置信度乘性"综合分(只在强共振时才给高分,头部更纯)。
5日 Top5 gross 增益(~0.2–0.25%)**本就薄于 A股往返成本(0.15–0.2%)**,扣完即淹没。

## 五、建议(不上线融合基线;后续换配方方向,供共评)

1. **不接 Phase B**:融合基线未过预注册净 Top-N 闸门,**不接入生产、不下线策略11、不动齐全度**(避免用未证增益的策略替换/删除现有链路)。
2. 若继续攻"技术面选股":edge 的天花板受制于 **5日 Top-N 净超额 < 成本**。可换的方向:
   - **拉长持有期 / 降换手**(摊薄往返成本),或**只在强信号日出手**(条件触发而非每日全宇宙选),对齐 V2 的"稀疏锐利"特性;
   - **头部锐化**:用 council 乘性综合分(稀疏但头部纯)做**最终 Top 选择器**,融合分做**粗筛/覆盖**的两段式;
   - **叠加正交增量层**(消息面 / 资金流,已在 fusion_lab 线性预留挂点)——技术面单口径已近饱和。
3. 现有可部署结论仍以 **V2(council 删趋势)** 为准:其净 Top5(0.1%)+0.231(p≈0)是目前扣成本后最实的技术面 edge。

## 自审

- **防未来函数**:信号 as-of(`sub=df.iloc[:idx+1]`)、前向取 idx 之后价、基准与融合分同日同全宇宙同口径;单测锁 `_fwd_ret` 越界返 None。
- **增量真实性**:融合 vs V0 增量真实显著;IC 加权为 in-sample(轻度乐观),但结论"未达 0.2% 净 Top-N"对权重方案稳健(等权同样不达标)。
- **反用趋势**:按数据决定——有结构化指标时不引入(F3<F2),不硬塞。
- **成本口径**:net 只对策略腿扣往返成本(市场腿买入持有不计),0.1%/0.2% 双档均报;0.2% 为 A股现实-保守值。
- **未做 Phase B**:因 Phase A 未达标,严格按预注册停下,未接生产 / 未下线策略11 / 未改齐全度。
