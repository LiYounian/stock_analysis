# 技术判定策略(趋势评级 / 拐点识别 / 超买超卖共振)

> - **是什么策略**:读 K 线技术指标,给当前盘面贴三个标签——趋势方向、是否处拐点、是否超买超卖。
> - **应用到哪**:作为[买卖倾向决策](买卖倾向决策.md)的核心输入;也是[选股](选股策略.md)"趋势强势/超跌反弹"预设的判据。
> - **应用在什么模块**:`tools/analysis/technical.py`(阈值在 `tools/config/strategy.py`)。
> - **起什么作用**:把连续的价量数据压成"这票现在是什么状态"的可读结论 + 得分。
> 名词见 [术语与参数速查.md](术语与参数速查.md)。

## 1. 趋势评级 → 偏多 / 偏空 / 中性
四项加权打分,clamp 到 −100~100:
```
均线排列:多头 +30 / 空头 −30
MACD:   金叉 +25 / 死叉 −25;DIF 在 0 轴上方 +10 / 下方 −10
价对 MA20:收盘 > MA20 +10 / < MA20 −10
RSI12 档位:偏强 +10 / 偏弱 −10
合计 ≥ +30 → 偏多;≤ −30 → 偏空;其间 → 中性
```
> 直觉:趋势由"均线结构 + 动能 + 价位 + 强弱"共同决定,单看一项易误判。

## 2. 拐点识别 → 反弹启动 / 超跌待反弹 / 无
专为"超跌反弹"场景,四个触发项按权重加总,clamp 0~100:
```
超跌      +25:KDJ超卖 或 RSI6<20 或 距20日低点≤3% 其一
放量反包  +30:量比>1.5 且 当日涨 且 站上 MA5
低位金叉  +25:KDJ 的 K 上穿 D 且 K<50
底背离    +20:价创新低但 MACD 未创新低
合计 ≥50 → 反弹启动;≥25 → 超跌待反弹;否则 无
```

## 3. 超买超卖(共振制,防假信号)→ 超买 / 超卖 / 中性
对 **KDJ / RSI12 / BIAS20** 各自判超买或超卖,统计**同向命中个数(共振数)**:
```
共振数 ≥ 2 才下"超买"/"超卖"结论,否则中性
```
- 单指标不单独定论——尤其 KDJ 的 `J = 3K − 2D` 放大波动、易假信号。
- 阈值:KDJ(超买 K>80 / J>100,超卖 K<20 / J<0)、RSI12(>70 / <30)、BIAS20(>10% / <−10%)。

> **为什么要共振**:任一超买超卖指标单独看噪声都大;要求两个以上同时告警,能显著降低假信号。
