# 策略 S05 · 最强选股(Tushare-only)

> 来源:外部 PR#15 提取重做。类型:**信号型 · 看多**。**硬依赖 Tushare 筹码获利比例(`cyq_perf`),免费源拿不到** → **仅 Tushare 可用时才出**,未配 `TUSHARE_TOKEN` / 取不到筹码则不产出 + 面板提示"需 Tushare"(非报错,不用免费源硬凑)。
> 参数真源:[`tools/config/strategy.py`](../../tools/config/strategy.py) `THRESHOLDS["最强选股"]`。⚠️ **非投资建议**。

## 是什么
在强势形态基础上叠加**筹码高度获利**过滤:六均线多头 + 近期连续大涨 + 高位区间 + 大部分持仓者获利。筹码获利比例是 Tushare `cyq_perf` 独有字段(`winner_rate` = 获利盘占比%,`cost_95pct` = 95 分位成本价),免费源无法计算,故本策略作 Tushare 环境专属增强。

## 怎么算(公式,当日=第 t 根)
```
① 六均线多头:MA5>MA10>MA20>MA30>MA60>MA200
② 近期连续大涨:近 11 日内单日涨≥5% 的天数 ≥ 2
③ 高位区间:0.9·H52 < C < 1.2·H52        # H52=近250日最高价(含当日)
④ 筹码高度获利:winner_rate > 95(%)  或  HIGH ≥ cost_95pct
SELECT = ①∧②∧③∧④    （chip 缺失 → ④False → 不选）
```
复用 `indicators.ma`/`highest_high`;筹码走 `tools/collectors/tushare_daily.fetch_chip(as_of)`(全市场当日 `cyq_perf`)。历史 < 250 根不选。

## 门控与回退
- `run_strong_screen` 自门控:`tushare_daily.is_configured()` 为假 / 筹码取不到 → 写 `present=False` + 提示的占位 view,**不产出选股**。
- /selection 面板「S05 · 最强选股」区块显示"需 Tushare"提示;综合选股「策略9」勾选框置灰(unavailable)。
- **绝不用免费源近似筹码**(维持"仅 Tushare 可用时出"的口径)。

## 怎么回测 / 效果
- **本环境未配 Tushare token → 无法取 `cyq_perf` 历史 → 暂无历史回测**(诚实标注,不用免费源伪造)。
- 回测口径与 S03/S04 一致(方向感知 + T+1/5/10/20 + HS300 基准);待在配有 `TUSHARE_TOKEN` 且能拉 `cyq_perf` 历史的环境按 F10 口径补跑。单测已用 mock 筹码锁住四条规则语义 + Tushare 门控(`tests/test_screen_strong.py`)。

## 运行
```
export TUSHARE_TOKEN=<你的token>
python -m tools.pipeline.screen_strong --universe 500
```
落 view「最强选股」→ /selection「S05」区块 + 综合选股「策略9」。未配 token 时该命令写"需 Tushare"占位 view。
