# 策略 S03 · 最大范围选股

> 来源:外部 PR#15 提取重做(原为独立 screen 脚本 + 独立页,已按本项目 screener→view→/selection 约定重实现)。
> 类型:**信号型 · 看多**(单日触发筛选,非买入指令)。参数真源:[`tools/config/strategy.py`](../../tools/config/strategy.py) `THRESHOLDS["最大范围选股"]`。
> ⚠️ **非投资建议**;信号是概率非预言。

## 是什么
把"**高位强势 + 均线多头 + 近期有过大阳 + 当日未大跌**"的强势股筛出来。纯 OHLC(不依赖 Tushare),当日盘后逐票判最新一根 K 线,全条件 AND 命中即入选。定位=**过滤器/观察池**,喂人工复核或合议,不作单独买点。

## 怎么算(公式,均前复权,当日=第 t 根)
```
① 距高点:C/HHV(C,250) ≥ 0.82  且  C ≤ HHV(C,250)×1.10        # HHV 含当日
② 均线多头:C > MA10 且 C > MA20 且 C > MA50
③ 近期大阳:COUNT(C > REF(C,1)×1.06, 32) ≥ 1                  # 32 日内至少一次单日涨>6%
④ 当日回撤:(REF(C,1)/C − 1) ≤ 0.04                          # 当日相对昨收跌幅上限
⑤ 非北交所:code 前缀 ∉ {8, 4}(等价 TDX FINANCE(3)!=2;保留 002)
⑥ C > LOW                                                    # 非最低收盘
SELECT = ①∧②∧③∧④∧⑤∧⑥
```
复用 `tools/analysis/trend_template/indicators.py` 的 `highest_high` / `ma`(t 索引、无未来函数、不足返 None)。历史 < 250 根不选。

## 怎么回测
前瞻收益法(无未来函数):逐历史测试日用 `signal_at(kdf, i)` 判定,命中记 T+1/5/10/20 前瞻收益,对照 baseline 全样本 + HS300。详见 [S03回测报告_20260821.md](../计划/S03回测报告_20260821.md)。

## 效果(诚实,样本级)
- 250 只分层样本 / 27 测试日:命中组 **T+10 均值 +1.13% > baseline +0.36% / HS300 +0.50%**(方向符合看多);但**胜率 44.7% 低于 baseline**——**右偏/动量**(少数大涨拉动),非机械买点。
- A/B:去掉③(32日大阳)门槛样本翻倍、收益不增 → 该门槛主要收紧选择性,保留用于画像一致性。
- **样本级方向性 sanity,非全A alpha**;定位过滤器。
