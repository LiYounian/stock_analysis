## 策略 0 · 全A 多专家合议
**①基本信息**:编号0。多专家(技术趋势/超买超卖/拐点/资金流/情绪三层/多因子/事件/板块轮动/财报)各出方向票,加权合成综合方向。**做什么**:给每只票一个"综合偏多/偏空"的可追溯结论。**期待**:多维度互相印证、降单因子噪声。**能干什么**:全A/自选池打分排序 + 冲突标注。**操作**:盘后跑,页面可勾选专家实时重合成。
**②回测**:有。排序型 `backtest_rank`,逐日切片算 IC/分层/TopK。**结果**:随机299只·1.6万观测,IC 5/10/20日 −0.011/−0.025/−0.031 均不显著微负,TopK超额 −0.05~−0.58% → **无 edge**。**讲解**:能带 Alpha 的资金流/情绪/基本面维度在历史回测里因无快照全弃权,只剩技术面 → 技术面横截面无超额(与"日频量价无 alpha"一致)。
**③待确认**:(a) 合议目标是"排序选股"还是"单票辅助定性"?若后者则 IC 不达标不算否决。(b) 专家权重要不要人工经验值(现等权)?

## 策略 1 · 趋势深跌反包(S01)
**①基本信息**:编号1。选"暴力洗盘(深跌)后强势反包"的强势股(均线完整多头 MA5>…>MA200 + 贴近52周高)。**期待**:抓强势股回踩后的反包续涨。**操作**:盘后出信号。
**②回测**:有。信号型持仓回测。**结果**:全A 5124→670只·N=1405,胜率12.6%、均−0.34%、Alpha−0.14%、即死86.5%、t=−1.42 p=0.15 **不显著**;参数敏感性:救不活。**⚠️讲解(重要)**:该回测测的是"**信号日收盘买**"——**这是提供者从没指定的买法**,所以"救不活"是**测错了买法**,不等于筛选器(选强势股)本身无效。筛选器选出的强势股集合未被证伪。
**③待确认**:⭐ **S01 的买点到底是什么?**(信号日收盘?次日竞价?回踩后?)——买法定了才能重测。

## 策略 2 · 放量后缩量回踩(S02)
**①基本信息**:编号2。放量突破后缩量回踩到支撑/均线的低吸点。**期待**:低吸强势股回踩、低即死。**操作**:盘后出信号,次日介入。
**②回测**:有,且最充分。子集427只基线 胜率31.6%/Alpha+0.14%;**深历史8.4年全A**:即死**34.8%**、Alpha **+0.40% 显著**(但很薄)。叠加趋势模板过滤 A/B:**p=0.87 不改善**。**讲解**:S02 是现有最优——低即死+右偏(低胜率高盈亏比);但 Alpha 经济上薄,趋势过滤无用,改进点更可能在**离场器**。
**③待确认**:⭐ 即死↔Alpha 二选一(见待确认总清单);RS 口径;是否从离场规则入手。

## 策略 3 · 箱体形态
**①基本信息**:编号3。识别横盘矩形箱体 → 放量突破上沿。**期待**:抓箱体突破的启动。**操作**:盘后出信号。v1 生产、v2(振幅带放宽)待命。
**②回测**:有。信号型 `backtest_box`。**结果**:全A·N=1415,胜率31.2%、均+0.74%、Alpha+0.32%、即死61%,弱正不显著;v2 Alpha+0.69%/即死67%/仍无显著。**讲解**:弱正≈S02 档次但即死更高;追突破=即死高的固有代价。
**③待确认**:⭐ 箱体前提(20-60天真横盘 vs 抛物线加速,300209 之争);买点时序;是否只做 20cm 板;是否接受"高即死高盈亏比"。

## 策略 4 · 动量组合
**①基本信息**:编号4。加权对数动量 + R² 过滤选"走势最强"的票。**期待**:强者恒强。**操作**:盘后排序取 TopK。
**②回测**:有。排序型。**结果**:动量 A 腿 IC **显著为负**(t −2.9~−4.0)→ **A 股是反转市、动量是反指**。**讲解**:A股短中期动量效应为负,纯动量选强=选到即将回落的。
**③待确认**:动量是否只作"避免追高"的反向过滤(而非正向选股)?

## 策略 5 · SEPA + VCP(拟新增,来自提供者需求书)
**①基本信息**:编号5(拟)。Minervini 第二阶段强趋势(趋势模板 MA50/150/200)+ 波动收缩(VCP)+ 量能 + 基本面门槛 → 观察池;同行业≥2 标星(板块共振);趋势保护线 TSL。**期待**:把全A缩小到"强势+波动收缩+主题共振"的强候选,人工看突破点介入。**能干什么**:盘后选股+标星+保护线字段。**操作**:盘后出观察池,人工拍板。**(注:原需求含"盘中实时突破预警"——已与用户确认我们不做实时,降级为盘后突破检测+标记。)**
**②回测**:待做(实现后)。**但已有强相关结论**:我们**早前独立测过"趋势模板过滤",A股深历史 Alpha p=0.87 不显著**(见策略2)——即 **Minervini 趋势模板在 A 股不一定有自身超额**。
**③待确认**:⭐⭐ **既然趋势模板 A股已被我们回测证明不显著,SEPA 是否仍定位为"追求策略自身 Alpha",还是纯"缩小候选面的过滤器+人工拍板"?**(我方推荐后者,与"信号+人工拍板"精髓一致)。其余:MA 口径(50/150/200 vs 我们全序)、要不要加 RS、VCP 4.5% 阈值 A股是否调、验收股(中际旭创等)回测。

## 财报分析(M1+M2,已上线)
**①基本信息**:数值层(三大表→五维评分+9条红旗)+ 双前置闸门(审计意见=标准无保留 / 审计机构∈证监会备案名录105家)+ LLM 文本定性/综合归纳 + 资金来源(现金流三段→造血模式)。**期待**:投资侧"合理怀疑即避"排雷。**能干什么**:每票财报质地评级+红旗+审计闸门+AI归纳,web 有榜单+详情页。**操作**:盘后对 news_subset(自选∪每策略前5)采+分析。
**②回测/标定**:无独立 Alpha 回测(评级是质地画像非选股信号)。**2026-08-16 已补 AI 建议默认标定,评级正常化**:红旗重新分级(现金含量不足等降为"中",只有 扣非为负/非标意见/审计机构未备案 高危封顶)+ 区间放宽 → 31 只分布 优2/良5/中7/差8/风险9(新易盛/中际旭创→优、行云科技非标→风险)。金融业五维不适配致银行偏低(待行业相对)。`forward_scorecard` 累积前瞻收益中。
**③待确认**:⭐ **M3 评级标定**(五维权重/标准化区间/红旗阈值/一票否决/评级映射/审计档位/行业相对——见 [M3 清单](../计划/财报评级标定_待提供者清单_M3.md))。

## 消息面 / 情绪三层
**①基本信息**:新闻/舆情(股吧)/政策三层 LLM 情绪打分 → 净情绪分;PEAD/持续性分类(结构性 vs 短暂)。**期待**:识别"结构性持续增长 vs 短暂好消息",防见光死。**操作**:盘后对 news_subset 采+打分。
**②回测**:有(部分)。**结果**:PEAD 见光死无漂移;持续性 60日 短暂事件−3.65%/结构性持平,**方向与机制对上但样本薄(n28)不显著**——第一个"有希望"的信号。`forward_scorecard` 每日滚存持续性标签累积复验。
**③待确认**:⭐ "结构性 vs 短暂"判据经验清单;跨源印证定义;消息面结合技术面的优先级(过滤/择时/加权)。

## 价位预测(止盈止损 / 情景)
**①基本信息**:支撑压力位 + 情景锚定 + 按持有期的止盈止损线 + 历史频率情景。**期待**:给人工参考的点位/盈亏比。**操作**:盘后随记录产出,页面展示。
**②回测**:有。5指标事件研究,随机全A 29万观测。**结果**:**"上涨概率"无区分力(Brier≈0.25,已弱化)**;区间校准到80%;止损/ATR 倍数调参定稿。
**③待确认**:止盈止损的持有期/ATR 倍数默认值认不认?

## 反转 / 创百日新高(已否决,留档)
**回测**:反转 rev5/10/rev_mom 账面 IC 正,但**净成本后≈0、流动性前50%里 edge 归零 → 不可交易**;创百日新高追高(均线多头+追高)**−1.06%**(见光死)。**结论**:均不部署,留作"不要做什么"的证据。
