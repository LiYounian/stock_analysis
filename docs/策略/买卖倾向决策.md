# 买卖倾向决策(多因子打分)

> - **是什么策略**:把技术判定 + 资金流 + 情绪**打分求和**,给一个偏买入/偏卖出/观望的倾向。
> - **应用到哪**:个股页顶部结论徽章、横向总表、选股页的"买卖倾向"列。
> - **应用在什么模块**:`tools/analysis/predict.py` 的 `bias_recommendation()`。
> - **起什么作用**:把多个分散信号合成一个**可追溯**的结论(每分都留依据),避免单因子拍板。
> 名词见 [术语与参数速查.md](术语与参数速查.md)。

## 打分表(每因子只是一维输入,不单独决定结果)

| 因子 | 来源 | 加/减分 |
|---|---|---|
| 超买超卖 | [技术判定](技术判定策略.md) | 超卖 **+2** / 超买 **−2** |
| 拐点 | [技术判定](技术判定策略.md) | 反弹启动 **+2** / 超跌待反弹 **+1** |
| 趋势评级 | [技术判定](技术判定策略.md) | 偏多 **+1** / 偏空 **−1** |
| 资金流 | 采集(东财) | 主力净流入 **+1**;连续≥2天再 **+1**;净流出 **−1** |
| 情绪 | [情绪三层](情绪三层策略.md) | 净情绪分 ≥ +0.2 → **+2**;≤ −0.2 → **−2**(样本数为0不计) |

```
总分 ≥ +2 → 偏买入;≤ −2 → 偏卖出;其间 → 观望
```

## 实例(688521)
各技术项中性、资金流缺失,仅**情绪偏多 +2** → 总分 2 → **偏买入**,依据 `["情绪偏多+2"]`。
> 说明情绪真正参与了决策,且结论可回溯到具体依据——不是黑箱。

## 设计要点
- **可追溯**:输出含 `得分` 和 `依据`(每条加分的原因),便于人工复核。
- **权重量级**:超买超卖/拐点反弹/情绪都是 ±2(强信号),趋势/单日资金流是 ±1(辅助)——强弱分明。
- **向后兼容**:情绪块缺失或样本数为 0 时该因子不计分,不影响其余打分。
