## 1. 当前工作与结果

### 1.1 已有的消息面架构
- **情绪三层**:`新闻` / `舆情`(股吧等 UGC/大V)/ `政策`,各出净情绪分,合成 `净情绪分`(−1~1)。
- **事件/公告**:业绩预告(yjyg)/快报/增减持/公司行为 + 巨潮公告。
- **新闻采集**:东财∪新浪∪财联社 + 按行业主题"扩召回"(补挂不到个股的行业/管制类消息)+ LLM 相关性初筛。
- **LLM**:逐条抽取利好/利空 + 情绪打分。

### 1.2 做了哪些回测(严格无未来函数)
| 研究 | 做法 | 结果 |
|---|---|---|
| **A 归因** | 失败信号 ∩ 有无消息 | 舆情采集把"有消息率"顶到 **84%** → "有无消息"几乎零区分度;**根源口径(公告+政策)收窄到 58%**,舆情命中 73.7% 是噪声放大器 |
| **B 事件类型** | 命中消息分预定型/突发型 | **突发型(不可提前)是预定型(可提前)的 ~2 倍**;能提前捕获的预定型仅 ~12% |
| **C 情绪信号** | 净情绪分 IC vs 前瞻收益 | 弱、且方向**逆向**(正情绪反而略跌 = 见光死);但点位数据仅 7 天,统计力≈0 |
| **PEAD 业绩预告** | 超预期→前瞻漂移(6516 事件) | **见光死**:超预期披露当天定价完(正+0.57%/负−1.29%),**进场后无漂移**;看似 +3% 的 20 日 Alpha 是"发预告票整体跑赢大盘"的 beta+幸存者,不是超预期 edge |
| **持续性分类** | LLM 判 结构性/短暂,再看前瞻 | ⭐ **60 日:短暂事件显著反转 −3.65%,结构性持平 ~0**——方向符合"短暂见光死、结构性拿得住";但结构性 60 日样本仅 28,**不显著** |

### 1.3 整体结果分析(诚实)
1. **A 股短周期是"见光死 / 反转"市**:利好(超预期、正情绪、创新高、强动量)倾向被**提前定价或反转**,而非延续。这在动量(显著负)、PEAD(见光死)、情绪 IC(逆向)、创新高(追高负)多处一致——**量化印证了"一切利好皆为利空"**。
2. **消息面当前的价值 = 解释 / 风控 > 预测**:泛情绪/"有无消息"是噪声,单纯情绪极性无领先预测力。
3. **唯一有希望的方向 = 消息的"持续性"**:结构性利好(慢兑现)可能拿得住、短暂利好见光死——方向对上了,但**样本太薄(点位情绪仅 7 天、结构性 60 日 28 例)尚不能证明**。

## 2. 后续规划(要做什么 + 重点关注)

### 2.1 治本:前向累积(已上线,正在攒)
- `forward_scorecard`(已接入每日盘后闭环):每天存"**当日 picks + 预测方向 + 净情绪分 + 持续性标签**"配上到期后的**前瞻收益**,滚动累积。
- **为什么必须累积**:回测消息信号要"每个历史日**当时**的判断(只用当日及之前消息)配上未来收益",而点位情绪只从近期才开始落库、新闻 API 无长历史 → 现在样本太短。**攒 4~8 周后**才有统计力下"能不能预测/赚钱"的结论。

### 2.2 重点关注(排序)
1. **持续性分类的 60 日"结构性 − 短暂"差**是否随样本增大转显著(当前方向对、量薄)。
2. **只看根源消息(公司公告 + 国家政策),弃舆情/大V**(已验证舆情是数量噪声)。
3. **预定型事件(业绩预告等,有日历、可提前)** vs 突发型(不可提前)——可交易 edge 只可能在预定型。
4. **与技术面结合**(见 §3):消息面单独选股 IC 弱,价值在叠加技术信号做**过滤/择时/风控**。

## 3. 优化方案(怎么做得更好 + 与技术面结合)

### 3.1 信号定义升级:从"极性/数量"到"根源 + 持续性 + 印证"
- **弃数量、看根源**:只用公司公告 + 国家政策(原发、权威),舆情/新闻转载当噪声。
- **从极性到持续性**:LLM 不只判好坏,判**结构性持续(长期订单/产能/政策长期扶持/主营实质改善)** vs **短暂事件(单季波动/一次性/蹭概念)**——结构性才可能有慢兑现的 edge。
- **跨源印证**:公告 + 政策 + 基本面互相印证 = 更可信的结构性利好。

### 3.2 事件驱动细分
- **预定型**(业绩预告/财报/解禁,有日历)→ 可提前布局;但 PEAD 已证"披露即定价",edge 若有,更可能在**披露前的预期差**或**结构性预告的中长窗持续**,而非披露后追。
- **突发型**(重组/监管/突发)→ 多数不可提前,只能事后风控。

### 3.3 ⭐ 与技术面结合的方式(用户明确要的方向)
消息面**不单独选股**(IC 弱),而是与技术信号交叉:
- **双确认过滤**:技术面选出的票,叠加"结构性根源利好"才进、遇"短暂利好/见光死特征"则规避 → 用消息面**降假信号**。
- **风控/择时层**:结构性利空 → 收紧止损/回避;政策管制类 → 规避主营受冲击票(扩召回已能抓)。
- **持续性加权**:给技术信号的仓位/优先级按"消息持续性"加权(结构性加、短暂减)。
- **可验证的假设**:用 forward_scorecard 交叉"**技术信号 × 消息持续性**",看结构性消息是否让技术信号的前瞻收益**更持续**(20/60 日)——这是"结合是否有效"的直接检验。

### 3.4 数据
- 点位情绪/持续性标签:持续累积(治本)。
- 公告/政策历史:可回补(有历史),先在这个 slice 上验持续性。

## 附:关键结论一句话
**消息面目前的价值在"解释/风控"强于"预测";唯一有希望的可交易方向是"根源消息的持续性(结构性慢兑现 vs 短暂见光死)",但要靠 forward_scorecard 累积几周样本才能证明;与技术面结合应走"过滤/择时/加权",而非让消息面独立选股。**
