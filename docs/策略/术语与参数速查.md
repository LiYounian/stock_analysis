# 术语与参数速查

> 读其它策略文档前的字典:名词/指标解释 + 全部可调参数。参数**单一真源**是 [`tools/config/strategy.py`](../../tools/config/strategy.py) 的 `THRESHOLDS`。

## 名词 / 指标

| 名词 | 含义 | 作用 |
|---|---|---|
| **K线 / OHLC** | 每日 开/高/低/收 盘价 + 成交量 | 一切计算的原始输入 |
| **MA(均线)** | N 日收盘均值(MA5/MA20/MA60) | 判趋势方向与多空排列 |
| **均线排列** | 多头(MA5>MA20>MA60)/ 空头 / 纠缠 | 趋势强弱骨架 |
| **MACD** | 快慢 EMA 之差(DIF)与其均线(DEA);DIF 上穿 DEA = 金叉 | 中期动能、拐点 |
| **KDJ** | 随机指标 K/D/J(通达信 SMA 递推口径);J = 3K − 2D | 短期超买超卖 |
| **RSI** | 相对强弱 0~100(RSI6/12/24);>70 热、<30 冷 | 超买超卖 |
| **BIAS20** | 乖离率 =(收盘 − MA20)/ MA20 × 100 | 价格偏离均线多远 |
| **量比** | 当日量 / 过去5日均量;>1.5 放量、<0.7 缩量 | 量能是否配合 |
| **ATR** | 真实波幅均值(14日):每天大约波动多少钱 | **止盈止损的标尺** |
| **ATR%** | ATR / 现价 × 100 | 跨票可比的波动幅度 |
| **Swing pivot** | 前后各 window 根内的局部最高/最低点 | **支撑/压力位**来源 |
| **分位数** | 一组数里第 X% 小的值;q10/q50/q90 = 悲观/中位/乐观 | **情景预测**收益 |
| **净情绪分** | 三层情绪加权值,范围 −1~1 | 消息面并入决策 |
| **walk-forward** | 逐日只用"当日及以前"数据回测 | 防未来函数 |
| **t+1 成交** | 信号当天出、次日才成交 | 贴近真实、避免偷价 |

## 参数总表(可调,改这里即改策略)

| 类别 | 参数 | 默认值 | 用在 |
|---|---|---|---|
| 预测 | ATR周期 / 止损倍数 / 止盈倍数 | 14 / 1.0 / 1.6 | 止盈止损位 |
| 预测 | 持有期 / 情景分位 | [1,5,10]日 / [10,50,90] | 情景预测 |
| 预测 | swing窗口 / 支撑压力取几档 | 5 / 2 | 支撑压力位 |
| 情绪 | 偏多阈值 / 偏空阈值 / 权重 | +0.2 / −0.2 / 2 | 买卖倾向并入 |
| 情绪 | 三层权重(新闻/政策/舆情) | 0.5 / 0.3 / 0.2 | 净情绪加权 |
| 超买超卖 | 共振数阈值 | 2 | 超买超卖判定 |
| 趋势 | 偏多 / 偏空 标签阈值 | +30 / −30 | 趋势评级 |
| 拐点 | 反弹启动 / 超跌待反弹 阈值 | 50 / 25 | 拐点识别 |
| 量价 | 放量 / 缩量 量比 | 1.5 / 0.7 | 量能判定 |
| 选股 | 主力连续天数 / ROE下限 / 趋势最低分 / 拐点最低分 | 2 / 1.0 / 30 / 25 | 预设选股 |
| 回测 | 单边成本 / 执行滞后 / 年化交易日 | 5bp / t+1 / 244 | 回测引擎 |
