## (a) 详细介绍
- **是什么**:盘后/午间**监控**。Minervini SEPA 均线硬条件筛出技术合格池(≈200~400)，再在池内盯 VCP **波段轮次收缩**（相邻轮振幅↓ + higher low），把「值得看的那几只」摊在表2。
- **做什么**:让人只翻重点观察池，而不是翻完 400 张图。星标（基本面/板块）只展示、不排序、不挡入池。
- **期待**:过滤器 + 人工拍板。不自动下单、不给精确买点、不追策略自身 Alpha。
- **操作讲解**:全A → SEPA 三条均线入池 → 合格池上切波段轮次 → ≥2 轮收缩进观察池；盘中刺破前低收盘拉回=洗盘算活；收盘跌破>1.5%才失效。主图只标「收缩结构参考」，不自动叫「VCP 完成」。
- **现状**:🟢 本机可跑（分支 `feat/sepa-vcp-monitor`）。看 [本地部署与监控手册](../../参考/本地部署与监控手册.md)；页面 `/sepa`。占位阈值待肉眼标定。

## (e) 变量说明(落 `THRESHOLDS['SEPA_VCP']`)
- **SEPA**:股价 > MA50 > MA150 > MA200；MA200 当前 > 20 日前；股价在 MA50 与 MA200 上方。
- **VCP 一轮**:波段高→波段低，≥3 交易日；回撤% = (高−低)/高；只比当前轮 vs 上一轮。
- **失效**:收盘较前轮低点跌破 >1.5% 且收不回；盘中刺破收回=洗盘。
- **星标**:基本面 / 板块，仅展示。
