# 消息面 / 情绪三层

> ⚠️ 非投资建议 · [← 返回主看板](../策略看板_与提供者沟通.md) · 详见 [消息面策略](../消息面分析策略_现状规划与优化.md)

## (a) 详细介绍
- **是什么**:排雷/择时辅助。新闻/舆情(股吧)/政策**三层 LLM 情绪打分** → 净情绪分;PEAD(业绩公告后漂移)+ 持续性分类(结构性 vs 短暂)。
- **做什么**:盘后对 news_subset 采集+LLM 打分,产净情绪分 + 新闻AI视图,接入合议情绪专家。
- **期待**:识别"结构性持续增长 vs 短暂好消息",防**见光死**。
- **操作讲解**:三层按信源可靠性加权(新闻0.5/政策0.3/舆情0.2,缺层重归一),达±0.2 阈值以权重2并入买卖倾向(非决定项)。
- **现状**:生产(辅助)。

## (b) 回测记录
- **PEAD**:业绩公告后**见光死、无正向漂移**。
- **持续性分类**(2026-08-13,399抽样/364可用):60日 短暂事件 **−3.65%(反转)** / 结构性 **持平**,结构−短暂差 +4.16pp——**方向与机制对上(短暂利好褪色、结构性拿得住),但样本薄(结构性 n28)聚类t不显著**。第一个"有希望"的信号。
- `forward_scorecard` 每日滚存持续性标签,累积几周 + 下报告期到期补 60 日窗再复验。

## (c) 修改记录

## (e) 变量说明
- **三层权重**:新闻0.5/政策0.3/舆情0.2(信源可靠性,缺层重归一)。
- **净情绪阈值** `±0.2`:达阈以权重2并入买卖倾向。
- **NEWS_LOOKBACK_DAYS** `7`:新闻/公告回看窗口。
- **持续性分类**:结构性/短暂/中性 三类(LLM 判 + 事件属性)。
