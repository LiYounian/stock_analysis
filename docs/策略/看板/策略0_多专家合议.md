# 策略0 · 全A 多专家合议

> ⚠️ 非投资建议 · [← 返回主看板](../策略看板_与提供者沟通.md) · 参数真源 `tools/config/strategy.py['合议']`

## (a) 详细介绍
- **是什么**:排序型元策略。多专家(技术趋势/超买超卖/拐点/资金流/情绪三层/多因子/事件驱动/板块轮动/财报)各出方向票,加权合成综合方向。
- **做什么**:给每票一个"综合偏多/偏空"的**可追溯**结论(含逐专家归因、冲突标注)。
- **期待**:多维互相印证、降单因子噪声。
- **操作讲解**:盘后对 llm_subset 跑,页面可勾选参与专家、按落库权重前端实时重合成(不触发后端重算)。
- **现状**:生产(辅助定性),非独立选股信号。

## (e) 变量说明(config `THRESHOLDS['合议']`)
- **tau**:综合方向阈值,S≥+τ看多 / ≤−τ看空 / 其间中性(默认 0.2)。
- **conflict_epsilon**:冲突判据,正反两方各自 |Σ贡献|≥ε 才算冲突(仅标注,默认 0.05)。
- **分母模式**:`置信度加权`(默认,弃权专家不稀释)/ `等权`(旧,会稀释)。
- **默认权重**:各专家权重(现等权 1.0)。
- **默认专家组**:参与综合结论的专家名单(现 9 个,含财报)。
- **置信度映射**:数据充分度(充分1.0/部分降级0.5/缺失0.0)× 共振/样本数 → [0,1]。
