# 财报分析(主要模块)

> ⚠️ 非投资建议 · [← 返回主看板](../策略看板_与提供者沟通.md) · 参数真源 `tools/config/strategy.py['财报']` · 详见 [M3标定清单](../../计划/财报评级标定_待提供者清单_M3.md)、[行业专家框架](../../财报分析专家/README_框架总纲.md)

## (a) 详细介绍
- **是什么**:排雷/质地评估模块(非选股信号)。数值层(三大表→五维评分+红旗)+ 双前置闸门(审计意见=标准无保留 / 审计机构∈证监会备案名录105家)+ LLM 文本定性/综合归纳 + 资金来源(现金流三段→造血模式)。
- **做什么**:每票给财报质地评级(优/良/中/差/风险)+ 红旗 + 审计双闸门 + AI 综合归纳;web 有财报榜 `/financial` + 单票详情页 `/financial/{code}`(七模块)。
- **期待**:投资侧"**合理怀疑即避**"排雷,给人工/合议一个质地维度。
- **操作讲解**:盘后对 news_subset(自选∪每策略前5)采三大表+年报PDF+LLM;数值全走代码,LLM 只碰文本。
- **现状**:M1+M2 已上线;M3 评级标定已补 AI 默认(评级正常化);**行业专属专家研发中**(银行/电子/通信…,见框架总纲)。

## (b) 回测记录
- **无独立 Alpha 回测**(评级是质地画像,非横截面选股信号)。
- 2026-08-16 补 AI 建议默认标定后,31 只分布回到 **优2/良5/中7/差8/风险9**(新易盛/中际旭创→优、行云科技非标→风险)。
- `forward_scorecard` 每日滚存前瞻收益,累积后可验"质地好的票是否前瞻更优"。

## (e) 变量说明(config `THRESHOLDS['财报']`)
- **红旗**:现金含量_CFO比净利_下限0.8 / 应收存货增速超营收_pct20 / 商誉占净资产_上限30 / 资产负债率_上限70 / 扣非占归母_下限0.6 / 毛利率跳升_pct10 / 短债覆盖_下限1.0 / 应收存货最小基数占营收0.05(低基数护栏)。
- **严重度**:各红旗 高/中(高=一票封顶降"风险";现真高危仅 扣非为负/非标审计意见/审计机构未备案)。
- **审计意见_通过**:`[标准无保留意见, 无保留意见]`(闸门2)。
- **金融业申万/金融业跳过红旗**:银行/非银豁免高负债等不适用红旗。
- **评分.五维权重**:成长/质量/健康/运营/回报 权重(现等权)。
- **评分.红旗扣分**:高12/中5/低2。**高危封顶分**:35。**评级映射**:优80/良65/中50/差35。
- **评分.五维区间**:各维子指标的标准化区间(0分端→100分端,M3 可标定;现毛利率[0,50]、ROE[0,12] 等)。
