# A 股策略辅助工具 · 项目方案总览

> 对外分享版(供同事/合作伙伴对齐)。一份看懂项目在做什么、怎么设计、进展如何。
> 详细文档见各专项(链接在文末)。更新 2026-08-05。

---

## 1. 一句话定位

**一个 A 股行情的「策略辅助工具」**:融合技术面 + 情绪面,评估个股**超买超卖**,给出**买卖倾向**、
**不同持有期(1/5/10 日)的止盈止损位与预期收益(百分比)**,并支持**选股筛选**。

- **辅助而非代替**:系统出分析与推荐,买不买、怎么操作由用户自己决定。
- **诚实边界**:股价不可被可靠预言。系统只做**基于历史数据的概率化推算**(上涨概率、波动区间)+ **规则化止盈止损**,全站标注**非投资建议**。
- **形态**:可本地/服务器部署的 Web + 一套离线数据/分析管线。

---

## 2. 解决什么问题

散户/研究员盯盘时,信息散落在多个 App、口径不一、无法批量比较:
- 技术指标要逐只翻看,超买超卖靠感觉;
- 消息面(政策/公司公告/舆情)与行情割裂;
- 缺乏一致的止盈止损/风险收益参考。

本工具把这些**汇成一张结构化数据 + 一个 Web 看板**:全池一览筛选,单票一页看全(K线+指标+基本面+资金流+公告+预测)。

---

## 3. 产品主流程:两阶段

```
┌──────────────────┐        ┌────────────────────────────┐        ┌──────────────────────┐
│ 阶段一 选股筛选    │  ───►  │ 阶段二 个股评估              │  ───►  │ 买卖推荐 + 止盈止损     │
│ Screener          │        │ Evaluator                  │        │ + 预期收益(百分比)    │
│ 从票池/全市场筛候选│        │ 超买超卖 = 情绪面 + 数据面   │        │ 1/5/10 日情景 + 概率   │
│ (规则可插拔,留口子)│       │ 放量/支撑压力/K线/指标/资金流│       │ 全部百分比,非投资建议 │
└──────────────────┘        └────────────────────────────┘        └──────────────────────┘
```

- **阶段一(筛选)**:接口已就位,**具体规则留口子**(与业务方共同定义,见"待定决策 N1")。
- **阶段二(评估)**:核心是**超买超卖双维判定**——数据指标面(KDJ/RSI/BIAS 多指标共振,≥2 才定论,过滤 KDJ 假信号)+ 情绪面(政策/公司行为/舆情,部分依赖大模型)。
- **推荐**:买卖倾向 + 各持有期止盈止损%/预期收益%。

## 4. 分析维度(评估一只票时看什么)

| 维度 | 内容 | 数据/方法 |
|---|---|---|
| 趋势 | 均线排列、MACD、综合趋势评级 | 通达信口径自算 |
| 动能/超买超卖 | KDJ、RSI、BIAS 乖离,多指标共振判定 | 阈值可配,≥2 共振 |
| 拐点 | 超跌反弹(超跌+放量反包+低位金叉+底背离) | 独立成维,不与趋势混淆 |
| 量价 | 量比、放量/缩量、近三次放量定位 | K线+成交量 |
| 支撑压力 | swing 高低点结构性支撑/压力位 | 统计法 |
| 资金流 | 主力/超大/大/中/小单净流入、连续净流入 | 东财(curl_cffi 绕反爬) |
| 基本面 | 营收/净利/增速/ROE/毛利/负债 + PE/PB/市值 | 同花顺+百度;PE 适用性开关 |
| 情绪·公司行为 | 公告(增减持/回购/业绩预告/合同/诉讼…) | 巨潮,规则打标 15 类 |
| 情绪·政策/舆情 | 政策、研报、大V/股吧 | 大模型抽取与情感(待接入) |
| 预测 | 1/5/10 日上涨概率 + 收益分位 + 止盈止损% | 历史频率 + ATR,概率化非预言 |

## 5. 系统架构(分层)

```
┌───────────────────────────────────────────────────────────────┐
│ 展示层  web/           FastAPI + Jinja2 + Chart.js:Dashboard/个股/选股/新闻 │
├───────────────────────────────────────────────────────────────┤
│ 数据服务 analysis/serialize + panel   每票结构化 JSON + 全池横向总表(Web/DB 可消费) │
├───────────────────────────────────────────────────────────────┤
│ 分析层  analysis/      technical(指标/拐点/超买超卖) · predict(止盈止损/情景/买卖倾向) │
│                        valuation(PE开关) · portfolio(聚合/选股) · sentiment/event(情绪,LLM) │
│ 专项    screener/(选股·留口子)   financial_report/(财报深挖·留口子) │
├───────────────────────────────────────────────────────────────┤
│ 采集层  collectors/    market(行情) fundamental(基本面) announcement(公告) │
│                        fundflow(资金流) news/ugc/policy(情绪源,部分待接) │
├───────────────────────────────────────────────────────────────┤
│ LLM 层  llm/           统一客户端(用户 API / qwen 可插拔),用于文本/情绪侧 │
├───────────────────────────────────────────────────────────────┤
│ 配置    config/        stock_pool(票池) settings(参数) strategy(阈值/公式单一真源) │
├───────────────────────────────────────────────────────────────┤
│ 存储    data/raw(采集缓存 parquet/json) · data/analysis(结构化产出) │
└───────────────────────────────────────────────────────────────┘
```

**核心设计原则**
1. **采集与分析解耦**:采集只落盘,分析只读缓存;Web 只读产出、不算。可分别调试、易部署。
2. **策略配置数据化**:所有阈值/公式集中在 `config/strategy.py`(单一真源),导出 JSON 供程序/DB/人读、可审可调。
3. **结构化优先**:每票产出 schema 化 JSON + 全池总表,一条 `df.query` 即可筛选比较。
4. **诚实性内建**:预测=概率/波动,非点位保证;输出带免责,全站标非投资建议。
5. **留口子**:选股规则、财报框架、情绪 LLM 均以接口/契约先行,业务确定后填。

## 6. 技术选型与数据源

| 层 | 选型 |
|---|---|
| 语言/环境 | Python 3.11(独立 conda 环境 `stock_analysis`) |
| 数据 | akshare 为基座 + curl_cffi(绕东财 TLS 指纹反爬) |
| 行情 | 腾讯/新浪(东财被指纹墙) | 基本面 | 同花顺 + 百度 |
| 公告 | 巨潮 cninfo | 资金流 | 东财(curl_cffi) |
| 情绪/新闻 | 大模型抽取(用户 API / qwen)+ WebSearch | Web | FastAPI+Jinja2+Chart.js |
| 预测 | 统计(历史频率+ATR)先行,ML+回测为第二阶段 |
