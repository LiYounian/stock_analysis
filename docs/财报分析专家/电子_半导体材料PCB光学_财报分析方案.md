## ① 行业商业模式与财报特点

电子/科技制造是**技术密集 + 资本密集 + 强周期**三重叠加的制造业,与消费(白酒)、金融(银行)的财报画像差异极大:

1. **技术密集 → 研发是护城河**。产品(晶体、陶瓷粉体、HDI/高多层 PCB、大硅片)靠**持续研发迭代**维持代际领先与溢价;研发投入占营收比(研发费用率)是核心质地指标,远比消费行业重要。研发停滞 = 被下一代产品替代 = 毛利率崩塌。
2. **资本密集 → 重资产、扩产大**。产能靠大额资本开支(在建工程/固定资产)堆出来;扩产周期长(1-3 年),扩产节奏与下游景气**错配**是最大风险(扩产投产恰逢下行 → 产能利用率跌 → 折旧吃利润)。现金流量表的"购建固定资产"科目常年为大额流出。
3. **强周期 → 毛利率与存货大起大落**。终端需求(手机/PC/AI服务器/光伏装机/汽车电子)波动直接传导到价格与开工率;**存货易减值**(技术迭代 + 价格下行双杀),存货跌价准备是周期拐点的先行信号。
4. **产品结构决定毛利率中枢差异极大**——这是电子专家**不能用单一毛利率区间**的根本原因:
   - 光学元件/激光晶体(福晶):高精度、小批量、定制,毛利率 **40%~55%**;
   - 电子陶瓷/新材料(国瓷):配方/粉体壁垒,毛利率 **35%~45%**;
   - PCB(胜宏):中高多层/HDI 毛利率 **20%~35%**,普通板 **10%~18%**;AI/高阶板拉动时可跳升(胜宏 2024 年报毛利率约 17.9% → 2025 年报约 31.9%);
   - 半导体材料/硅片(TCL中环):光伏硅片强周期 **5%~20%**(下行期可为负),半导体级大硅片 **25%~40%**。
5. **客户集中 + 账期长**。下游多为品牌大厂(果链、AI 服务器 ODM、光伏组件厂),前五大客户占比常 40%~70%;应收账款账期长、余额大,应收周转与放账质量是运营维重点。

## ② 关键指标(看什么 · 多少算好/差)

> 下列指标除注明外,均可由现有采集层三大表算出(见 §⑤)。"季报未年化"的比率只做趋势/同业相对比较。

### 2.1 研发投入占营收比(研发费用率)【技术密集核心】
- **看什么**:`研发费用 / 营业总收入 × 100%`。衡量技术投入强度、代际领先可持续性。
- **好/差**:电子制造**健康区间 5%~10%**;半导体设计/设备可 >15%(本池无);
  - **< 3%** = 技术密集行业里明显偏低,失去领先风险 → 红旗;
  - 4 家自选标的均属材料/元件/PCB,合理中枢 **4%~8%**;胜宏 PCB 约 3%(制造属性重、偏低但正常),福晶/国瓷偏高(材料研发)。
- 注:关注**绝对额趋势**——营收快增时研发费率可能被动下降,应看研发绝对额是否同步增长。

### 2.2 毛利率及其趋势【产品迭代 / 涨价 / 价格战】
- **看什么**:`(营收 − 营业成本) / 营收 × 100%` 及其**同比/环比趋势**(趋势比绝对值更重要)。
- **好/差**:按细分给区间(见 §① 第4点、§④ 毛利率子指标)。**趋势**判定:
  - 毛利率**持续上行** = 产品升级/涨价/规模效应 → 好;
  - **连续 2~3 期下滑 > 3~5pct** = 价格战/产品老化/成本上行 → 红旗。
- 可用 `stock_zygc_em`(主营构成)拆**分产品/分行业毛利率**,识别高毛利业务占比变化(见 §⑤)。

### 2.3 存货与存货周转【易减值 · 周期先行信号】
- **看什么**:存货余额、存货增速、存货周转天数(`存货 × 期间天数 / 营业成本`),以及**存货跌价准备/资产减值损失**。
- **好/差**:周转天数按细分,PCB/材料 **60~150 天**属正常;**存货增速持续 > 营收增速 15pct 以上**且叠加毛利率下行 → 减值风险积聚(红旗)。周转天数拉长 = 出货不畅/需求走弱。

### 2.4 应收账款与周转【客户账期 · 放账冲收入】
- **看什么**:应收账款余额、应收增速、应收周转天数(`应收 × 期间天数 / 营收`)。
- **好/差**:电子对大客户账期长,应收周转 **60~120 天**常见;**应收增速显著超营收增速(> 15pct)** = 靠放宽账期冲收入,回款质量恶化 → 红旗。结合 CFO/净利 交叉验证。

### 2.5 客户集中度【大客户依赖】
- **看什么**:前五大客户销售占比(定性)。
- **好/差**:< 30% 分散,30%~50% 中等,**> 60% 高度依赖**(单一大客户砍单/压价即重创)。
- **数据**:三大表**取不到**,需年报正文"前五名客户"表 → 现采集层 `annual_report.py` 已抓年报 PDF 全文(MD&A/风险段),可扩展解析或交 LLM 文本层(见 §⑤)。**当前建议:定性标注,暂不入数值评分**。

### 2.6 产能利用率与扩产【资本开支大 · 错配风险】
- **看什么**:在建工程(CIP)、固定资产增速、`购建固定资产支付现金 / 营收`(资本开支强度)。产能利用率年报有披露(定性)。
- **好/差**:扩产本身中性;**风险在"扩产 + 景气下行"错配**——在建工程/固定资产大增、但营收/毛利率同步走弱 = 投产即过剩,折旧压制未来利润(红旗)。胜宏当前在建工程 51.7 亿(vs 固定资产 104.7 亿),扩产激进,需盯下游 AI 板需求能否消化。
- **数据**:CIP/固定资产/资本开支现成;产能利用率率**需年报正文**(定性)。

### 2.7 营收增速与订单能见度
- **看什么**:营收/扣非增速(累计同比)、单季环比、合同负债(预收类,订单先行)。
- **好/差**:合同负债/预收上行 = 在手订单充足(订单能见度好)。注:电子多为下单-出货短周期,合同负债信号弱于设备/军工;本池以增速趋势为主。

### 2.8 经营现金流质量
- **看什么**:`CFO / 归母净利`(现金含量)、自由现金流(CFO − 资本开支)。
- **好/差**:CFO/净利 **持续 > 0.8** 为健康;重资产扩产期**自由现金流常为负**(资本开支大),属阶段性正常,不等同于质地差——需区分"扩产性负 FCF"与"造血不足性负 FCF"(看 CFO 本身是否为正)。

## ③ 电子专属红旗

在通用红旗(增收不增利/现金含量不足/应收存货激增/高负债/扣非为负等)基础上,**新增/强化**以下电子专属项:

| 红旗 | 触发条件(建议阈值,占位) | 严重度 | 数据可得性 |
|---|---|---|---|
| **存货减值高企** | 资产减值损失/营收 > 2%,或存货跌价准备同比大增 | 高 | 部分(减值损失见 §⑤,存货跌价准备明细为年报附注) |
| **存货激增+毛利率下滑** | 存货增速 − 营收增速 > 15pct **且** 毛利率同比下滑 > 3pct | 高 | ✅ 现成 |
| **毛利率持续下滑** | 毛利率连续 ≥2 期同比下滑,累计降幅 > 5pct | 中 | ✅ 现成 |
| **研发占比过低** | 研发费用率 < 3%(制造)/ 研发绝对额同比下滑 | 中 | ✅ 现成 |
| **客户集中度过高** | 前五大客户占比 > 60% | 中 | ⚠️ 年报正文(定性) |
| **扩产后产能利用率下滑** | 在建工程+固定资产大增 **且** 营收/毛利率走弱 | 中 | ✅ CIP/固定资产现成;产能利用率定性 |
| **应收激增(放账冲收入)** | 应收增速 − 营收增速 > 15pct(通用"应收存货激增"已覆盖,电子加权关注) | 中 | ✅ 现成 |

> 复用通用红旗即可的项:增收不增利、现金含量不足、扣非为负、高负债、短债覆盖不足。电子**不需要**金融业那种大规模跳过(高负债/存货对制造业适用)。

## ④ 电子版五维方案(子指标 + 标准化区间 + 权重)

设计原则:通用五维骨架**大体适用**,做三处强化——**质量维加"研发费用率"**、**运营维强化"存货减值/存货趋势"**、**成长维/健康维沿用**、**毛利率区间按电子中枢上移并放宽**。

### 4.1 各维是否够用

| 维度 | 通用是否够用 | 电子调整 |
|---|---|---|
| 成长 | ✅ 够用 | 沿用营收/扣非增速;区间可略放宽(电子波动大) |
| 质量 | ⚠️ 需强化 | **加"研发费用率"子指标**;毛利率区间上移(电子中枢高于全市场) |
| 健康 | ✅ 够用 | 沿用资产负债率/短债覆盖/商誉;重资产行业负债率区间可略放宽 |
| 运营 | ⚠️ 需强化 | 存货周转 + 应收周转沿用;红旗层加"存货减值/激增+毛利率下滑"联动 |
| 回报 | ✅ 够用 | ROE 沿用(季报未年化,做趋势/相对) |

### 4.2 电子版五维区间建议(0分端 → 100分端;反向指标 lo>hi)

> 格式对齐 `config/strategy.py` → `THRESHOLDS['财报']['评分']['五维区间']`;实现时挂到 `THRESHOLDS['财报']['行业专家']['电子']` 覆写。derived 键名沿用 `metrics.compute_derived` 已有输出。

```python
"电子": {
  "五维区间": {
    "成长": [["营收增速%", "营收增速", -25, 45],           # 电子波动大,放宽两端
             ["扣非净利增速%", "扣非净利增速", -30, 50]],
    "质量": [["现金含量 CFO/归母净利", "现金含量_CFO比净利", 0, 1.2],
             ["扣非占归母", "扣非占归母", 0, 1.0],
             ["毛利率%", "毛利率", 10, 55],                # 电子中枢上移(10→55,跨半导材料~光学)
             ["研发费用率%", "研发费用率", 1, 8]],          # 新增:1%差 → 8%优(制造密集口径)
    "健康": [["资产负债率%(反向)", "资产负债率", 75, 30],  # 重资产,负债率区间略放宽
             ["短债覆盖", "短债覆盖", 0, 2],
             ["商誉占净资产%(反向)", "商誉占净资产", 50, 0]],
    "运营": [["应收周转天数(反向)", "应收周转天数", 180, 45],
             ["存货周转天数(反向)", "存货周转天数", 240, 60]],  # 电子存货周转比通用略快
    "回报": [["ROE%", "ROE", 0, 12]],
  },
  "五维权重": {"成长": 1.0, "质量": 1.2, "健康": 1.0, "运营": 1.1, "回报": 1.0},
  # 质量维(含研发)与运营维(含存货)加权 —— 技术密集 + 存货减值是电子的两个关键区分点。
}
```

**权重理由**:电子的核心区分度在"技术领先(研发/毛利率)"与"存货周期(减值/周转)",故 **质量维 1.2、运营维 1.1** 略加权,其余等权。提供者可按风格覆盖。

**毛利率区间说明**:因四个细分毛利率跨度 10%~55%,单一线性区间是折中。若后续细分标定,建议**按细分再拆**(光学/陶瓷用 30→60,PCB/硅片用 5→35),或引入同业相对分位(P2 增强,对应总纲 Q6)。当前先用统一 `10→55` 保证不失真过重。

**研发费用率区间说明**:取 `1%→8%`(制造密集口径)。若把半导体设计/设备纳入同一专家需上调 100 分端至 15%~20%;本池 4 家均为材料/元件/PCB,`1→8` 合理。

### 5.2 需修正 / 需扩展

- **资产减值损失 / 信用减值损失(存货、应收减值)**:
  - ⚠️ **重要修正**:现 collector 映射的列 `ASSET_IMPAIRMENT_LOSS` / `CREDIT_IMPAIRMENT_LOSS` 在东财 by_report 接口**恒为 NaN**(取不到)。实际有值的列是 **`ASSET_IMPAIRMENT_INCOME` / `CREDIT_IMPAIRMENT_INCOME`**(新准则口径:作为损益行列示,**负值=减值损失**)。
  - 验证(胜宏 2024 年报):`ASSET_IMPAIRMENT_INCOME = -2361 万`(资产减值损失)、`CREDIT_IMPAIRMENT_INCOME = +859 万`。**建议实现电子专家时把 collector 的减值科目改映射到 `*_INCOME` 列**,即可取到减值(用于"存货减值高企"红旗)。
  - 注意:减值科目**仅年报/半年报有值,一季报/三季报为 NaN**(季报不披露减值明细),红旗判定应限定在年报/半报期。
- **存货跌价准备"余额"(而非当期损失)**:属资产负债表**附注**明细,by_report 接口无此列(`CREDITOR_IMPAIRMENT_RESERVE` 恒 NaN)→ **未找到,建议**用利润表当期"资产减值损失"(`ASSET_IMPAIRMENT_INCOME` 负值)作为代理,或解析年报 PDF 附注。
- **分产品/分行业毛利率(产品结构)**:`ak.stock_zygc_em(symbol)` **可取**——返回按行业/产品/地区的主营收入、收入比例、毛利率。验证:胜宏 2025 年报 PCB 制造收入 180.8 亿(占 93.7%)、毛利率 31.9%(vs 2024 年 17.9%,印证 AI 板拉动)。**建议新增采集**,用于识别高毛利业务占比与结构升级。
- **客户集中度(前五大客户占比)**:三大表与 by_report **取不到**;`stock_zygc_em` 是产品/地区维度、非客户维度;akshare 无专门"前五大客户"结构化接口(dir 扫描无 customer/supplier 接口)。→ **未找到结构化源,建议**由 `annual_report.py`(已抓年报 PDF 全文)扩展正则/交 LLM 文本层解析"前五名客户"表;当前定性标注、不入数值评分。
- **产能利用率**:同上,年报正文披露、无结构化接口 → **未找到,建议**年报 PDF 文本解析或定性标注。

| 变量 | 定义 / 公式 | 口径备注 |
|---|---|---|
| 研发费用率 | 研发费用 / 营业总收入 × 100% | 已在 `metrics.compute_derived` 输出;季报累计口径 |
| 毛利率 | (营业总收入 − 营业成本) / 营业总收入 × 100% | 趋势看同比/环比;可用 `stock_zygc_em` 拆分产品 |
| 存货周转天数 | 存货 × 期间天数 / 营业成本 | 季报未年化,做趋势/同业相对;期间天数 90/180/270/360 |
| 应收周转天数 | 应收账款 × 期间天数 / 营业总收入 | 同上口径 |
| 存货增速 / 应收增速 | 同比(与去年同报告期比,以 \|prev\| 为分母) | 与营收增速差值 > 15pct 触发激增红旗 |
| 资本开支强度 | 购建固定资产支付现金 / 营业总收入 | 扩产强度;重资产扩产期偏高属正常 |
| 扩产错配 | (在建工程+固定资产)增速 vs 营收/毛利率趋势 | 扩产升 + 景气降 = 红旗 |
| 资产减值损失 | `ASSET_IMPAIRMENT_INCOME`(负值=损失) | ⚠️ 非现映射列;仅年报/半报有值 |
| 现金含量 | 经营活动现金流量净额 / 归母净利润 | 持续 > 0.8 健康 |
| 自由现金流 | CFO − 购建固定资产支付现金 | 扩产期常为负,需区分扩产性/造血性 |
| 客户集中度 | 前五大客户销售额 / 营业收入 | 年报正文,定性;> 60% 高依赖 |
| ROE | 归母净利润 / 归母股东权益 × 100% | 当期未年化,趋势/相对用 |

> 五维评分沿用 `scoring.py` 的线性映射 `_score_linear`(val≤lo→0, ≥hi→100)与加权均值 − 红旗扣分逻辑,电子专家只覆写 §④ 的区间/权重 + §③ 的专属红旗。挂接点:`config/strategy.py` → `THRESHOLDS['财报']['行业专家']['电子']`;路由由 `analysis/industry_map.py` 将票映射到申万一级"电子"(半导体/PCB/光学/电子陶瓷别名已在 `_ALIAS` 表内)。

### 关键假设与占位说明(信息不全处按方案 doc 自定)
1. **毛利率同比升**:非单期 derived,依赖 analyzer 按上期注入 `derived['毛利率同比升']`(见 `flags.py` L137 同款约定)。缺失时"毛利率持续下滑"不判、"存货高企"不叠加升级——降级而非误杀。
2. **资产减值损失口径**:方案 §5.2 指出 by_report 接口减值实际值在 `*_INCOME` 列(负值=损失)。本模块对 `structured.利润表.资产减值损失` 取**绝对值**作损失额代理,兼容"负值=损失"(新准则)与"正值=损失"(旧口径)两种存法。减值仅年报/半报有值,故 `report_type ∈ {年报,半年报,中报}` 或缺失时才判(季报跳过)。
3. **扩产错配用单期比值代理**:纯函数不碰前期数据(无未来函数、无跨期状态),故用 `在建工程/固定资产 > 0.35` 作"扩产激进"代理,而非方案 §③ 建议的"在建+固定资产增速"(需前期,单期不可得)。营收走弱以 `营收增速 < 0` 判定。
4. **未纳入数值层**:客户集中度、产能利用率(无结构化源,方案 §5 定性标注)、分产品毛利率(需新增采集 `stock_zygc_em`)—— 均属 P1/P2 增强,本轮不实现。
5. 全部阈值(15pct/-5pct/3%/2%/0.35 等)为工程占位,集中在模块顶部 `_xxx` 常量,待 M3 标定后可外迁至 `config/strategy.py` → `THRESHOLDS['财报']['行业专家']['电子']`。
