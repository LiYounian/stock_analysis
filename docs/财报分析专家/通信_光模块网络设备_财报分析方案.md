# 通信 · 光模块 / 网络设备 · 财报分析方案

> ⚠️ 非投资建议。本文仅为财报分析口径设计,不构成任何买卖建议。
> 申万一级:通信 · 细分:光模块(中际旭创 300308 / 新易盛 300502)、ICT 网络设备(紫光股份 000938 / 新华三)
> 日期:2026-08-16

---

## ① 行业商业模式与财报特点

**光模块**:AI 算力(GPU 集群)的"神经"——服务器/交换机之间的高速光电转换。商业模式=**卖硬件盒子**,但技术迭代极快(100G→200G→400G→800G→1.6T),**产品代际=毛利率分水岭**。需求由**北美云厂(Nvidia/Google/Amazon/Meta/微软)资本开支**驱动,是典型的"卖铲子"标的。

财报特点:
- **成长弹性极大**:AI 周期里营收/利润可同比翻倍甚至数倍;但一旦云厂 capex 转向,回落也快。
- **毛利率是核心变量**:低阶产品(100G/200G)毛利率个位到 20%,高阶(800G/1.6T)可到 35%+。毛利率走向反映**产品结构升级 vs 价格战**。
- **备货重**:芯片(尤其光芯片/EML、DSP)交期长,旺季前大幅备货 → **存货高企是常态,但要区分"良性备货"还是"滞销"**。
- **客户高度集中**:前五大客户常占营收 70%+,单一北美云厂可能占 30%+ → 大客户 capex 波动直接决定业绩。
- **现金流常滞后**:高增长期应收随收入同步膨胀,CFO 往往跑不赢利润。

**ICT 网络设备**(交换机/路由器/服务器,如新华三):偏**系统集成+软硬件**,毛利率低于光模块(交换机 30% 左右,服务器薄),但客户更分散(运营商/政企/云),业绩更稳、弹性小,应收账款和政企回款周期是关注点。

## ② 关键指标(讲解 + 好坏标准)

| 指标 | 讲解 | 好 | 警惕 |
|---|---|---|---|
| **营收同比增速** | AI 周期直接体现 | 光模块 >50%(旺周期可 >100%) | <20% 或环比转负=周期见顶信号 |
| **单季营收环比** | 比同比更早反映拐点 | 持续环比正增 | 连续两季环比负增 |
| **毛利率(及趋势)** | 产品结构/议价的综合体现 | 光模块 >30% 且**升**;设备 >25% | **环比连续下滑**(价格战/低阶占比升) |
| **研发费用率** | 押注下一代(1.6T/CPO/硅光)的强度 | 5%~10%,绝对额随收入增 | 收入涨但研发绝对额停滞=后劲存疑 |
| **存货 & 存货增速** | 备货前瞻性 | 存货增速≈或略快于营收增速(为下季备货) | 存货增速**远超**营收增速且毛利率同时降=滞销风险 |
| **应收 & 应收增速** | 回款质量 | 应收增速 ≤ 营收增速 | 应收增速远超营收=靠赊销冲收入 |
| **CFO / 归母净利(现金含量)** | 利润含金量 | >0.7(高增长期 0.5+ 可接受) | 持续 <0.3 或为负 |
| **客户集中度**(需正文) | 单一云厂依赖度 | 有意识分散、前五占比下降 | 单客户 >40% 且在扩大 |

## ③ 行业专属红旗

1. **毛利率连续下滑**(高:结构恶化/价格战。判据:毛利率环比连续 2 季下降且累计降幅 >3pct)。
2. **存货减值 / 存货畸高**(中→高:`资产减值损失` 明显扩大,或存货增速 > 营收增速 30pct 以上且毛利率同步走弱)。
3. **客户过度集中且恶化**(中:单一大客户占比 >40% 并上升;需正文披露)。
4. **应收暴增于营收**(中:应收增速 − 营收增速 > 20pct)。
5. **增收不增利**(中:营收高增但扣非增速显著落后,常因价格战或费用失控)。
6. **研发绝对额停滞**(低:营收增长而研发费用绝对额不增,下一代掉队风险)。

## ④ 五维调整方案(子指标 + 建议区间)

区间格式沿用 `scoring.py::dimension_specs`:`(显示名, derived键, 0分端, 100分端)`,反向指标 0分端>100分端。相对通用口径,**上调成长/质量弹性区间,弱化健康权重(轻资产、负债本就低)**。

| 维度 | 建议子指标 | 建议区间(0→100) | 相对通用的调整 |
|---|---|---|---|
| **成长** | 营收增速 | -10 → 80 | **拉高上限**(通用 40),AI 周期高增不该早早顶格 |
| | 扣非净利增速 | -10 → 100 | 利润弹性 > 营收弹性 |
| **质量** | 毛利率 | 10 → 40 | 光模块口径(高阶产品带高毛利) |
| | 现金含量 CFO/归母 | 0 → 1.0 | 高增期现金滞后,略降上限 |
| | 扣非占归母 | 0.6 → 1.0 | 剔除投资收益/补助水分 |
| **健康** | 资产负债率(反向) | 70 → 20 | 轻资产,负债本低 |
| | 短债覆盖 | 0 → 3 | 现金充裕更该给分 |
| **运营** | 存货周转天数(反向) | 200 → 60 | 备货重,放宽反向区间 |
| | 应收周转天数(反向) | 150 → 40 | |
| | **应收增速−营收增速差(新增,反向)** | 30 → -10 | 捕捉赊销冲收入,需在 metrics 增派生 |
| **回报** | ROE | 5 → 25 | AI 周期 ROE 可很高 |

**权重建议**:成长 0.30 / 质量 0.25 / 健康 0.10 / 运营 0.20 / 回报 0.15(成长+运营为主,健康减配)。

## ⑥ 变量说明

- **CPO**:Co-Packaged Optics,光电共封装,下一代形态。**硅光**:硅基光子集成,降本路线。**EML/DSP**:光模块核心芯片。这些只在正文出现,财务表不体现,作为"研发方向"定性参考。
- **产品代际(100G/400G/800G/1.6T)**:数字越大速率越高、单价与毛利越高,是判断毛利率趋势的定性抓手。
- 反向指标:数值越大越差(如存货周转天数、资产负债率),区间写成"0分端 > 100分端"。
- 所有"需正文"项当季报缺失时,页面标注"该项需年报正文,季报暂缺",不用 0 冒充。

## 实现状态

> 落地:`tools/analysis/financial/industry/通信.py` + `tests/test_industry_telecom.py`(14 passed)。
> ⚠️ 非投资建议;下列阈值/区间/权重全部为**工程占位,待策略提供者标定**。

- **KEY** = `"通信"`(申万一级规范名,路由键)。
- **覆写维度数**:5 维全覆写(成长/质量/健康/运营/回报),区间取方案 ④。
  - 新增子指标 `应收营收增速差`(反向 30→-10)已在 metrics 现成派生,无需改 metrics。
- **weights**:成长 0.30 / 质量 0.25 / 健康 0.10 / 运营 0.20 / 回报 0.15(归一,弱化健康)。
- **SKIP_FLAGS**(1 条):`应收存货激增`——光模块备货重,存货增速略快于营收是良性常态,通用红旗仅看增速差会误杀,改由本模块更精细的「存货畸高滞销」(叠加毛利率走弱)与「应收暴增于营收」接管。
- **专属红旗**(6 条,全用 derived/structured 自算,缺值不命中、不抛异常):
  1. `毛利率下滑`(高)—— `毛利率同比升 ≤ -3pct`。
  2. `存货畸高滞销`(中)—— `存货增速−营收增速 > 30pct` 且 `毛利率同比升 < 0`(区分良性备货)。
  3. `应收暴增于营收`(中)—— `应收营收增速差 > 20pct`(缺现成差值时退回 应收增速−营收增速)。
  4. `合同负债转弱`(中)—— `合同负债环比 ≤ -10pct`(订单/景气见顶前瞻)。
  5. `研发投入偏弱`(低)—— `营收增速 > 20pct` 且 `研发费用率 < 3%`。
  6. `增收利润背离`(中)—— `营收增速 > 20pct` 且 `营收增速−扣非净利增速 > 40pct`(补通用「增收不增利」仅利润负增才命中之不足)。
- **用到的 derived 键**:营收增速、扣非净利增速、毛利率、现金含量_CFO比净利、扣非占归母、资产负债率、短债覆盖、存货周转天数、应收周转天数、应收营收增速差、ROE、存货增速、应收增速、合同负债环比、研发费用率、毛利率同比升(由 analyzer 注入,缺则相关红旗不命中)。

### 关键假设(信息不全时按方案自定的默认)
- **「毛利率连续下滑」→ 用同比降幅代理**:季报单期 derived 无多期毛利率历史,方案 ③#1 的"环比连续 2 季"无法在纯函数内实现,故以 `毛利率同比升 ≤ -3pct` 作代理;`毛利率同比升` 由 analyzer 注入,未注入时该红旗不命中(不误杀)。
- **「研发绝对额停滞」→ 用高增期研发费用率下限代理**:相邻期研发费用绝对额不可从单期 structured 取得,故以"营收高增但研发费用率 < 3%"捕捉"下一代后劲存疑"之意。
- **客户集中度(单一云厂占比)/ 产品代际结构占比 / 在手订单**:财务三大表无此数据,需年报正文,季报暂缺——不做红旗,页面按方案 ⑤ 标注"需年报正文,季报暂缺",不以 0 冒充。
- **阈值方向而非数值经测试锁定**:单测只断言"越界命中、界内不命中"的语义方向,阈值本身待标定后可安全调整。
