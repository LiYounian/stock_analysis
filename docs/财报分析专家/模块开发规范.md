# 行业财报专家模块 · 开发规范(共读契约)

> ⚠️ 非投资建议。阈值/区间/权重一律为**工程占位**,注释里注明"待策略提供者标定"。
> 本规范供各行业专家模块开发者共读;地基已建好(注册表自动发现、scoring/flags 覆写钩子、analyzer 路由)。

## 1. 你要交付什么(每个行业 3 个产物,互不与他人共享写)

1. `tools/analysis/financial/industry/<行业>.py` —— 专家模块(**新文件**)
2. `tests/test_industry_<行业拼音或英文>.py` —— 该模块单测(**新文件**,不要碰 `tests/test_financial.py`)
3. 在你那份 `docs/财报分析专家/<行业>_..._财报分析方案.md` 末尾**追加**一节「## 实现状态」(写清 KEY / 覆写了哪些维度 / 专属红旗 / 用到的 derived 键 / 占位阈值待标定)

**严禁**改这些共享文件:`industry/__init__.py`(自动发现,无需注册)、`metrics.py`、`scoring.py`、`flags.py`、`analyzer.py`、`tests/test_financial.py`。如你发现确实缺一个通用 derived 指标,**不要改 metrics**——在 `extra_flags` 里用 `structured` 原始科目自己算。

## 4. 通用红旗名清单(SKIP_FLAGS 只能从这里选要跳过的)
```
增收不增利, 现金含量不足, 应收存货激增, 商誉高企, 高负债, 扣非占比低, 短债覆盖不足, 扣非为负, 非标审计意见, 毛利率异常跳升
```
> 例:银行/金融跳 高负债/现金含量不足/短债覆盖不足/应收存货激增(不适用);重资产行业可保留高负债但放宽区间。

## 5. 红线与约束
- **纯函数、无网络、无状态、不 import 其他行业模块**;一切除法/取值缺失 → 该项 None / 不命中,绝不抛异常。
- **无未来函数**:你不碰 as_of(analyzer 已按披露日过滤),只管单期 derived/structured。
- 阈值/区间/权重工程占位,注释注明"待标定";严重度用 高/中/低。
- 代码风格、注释密度对齐现有 `scoring.py`/`flags.py`;中文注释。

## 6. 测试(必须跑通)
`tests/test_industry_<x>.py` 至少覆盖:
- `dimension_specs()` 结构正确(每维是 [(名,键,lo,hi)] 元组列表,键为字符串)、KEY 是规范名;
- `weights()` 返回 dict 或 None;
- `extra_flags` 的**每条专属红旗**至少一个"命中/不命中"边界断言(锁住语义);
- `extra_flags({}, {})` 与 `extra_flags(derived, {"利润表":{},"资产负债表":{},"现金流量表":{}})` 不抛异常、返回 list。
- 跑 `python3 -m pytest tests/test_industry_<x>.py -q` 全绿再算完成。
