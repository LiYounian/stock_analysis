# 财报行业专家 · 程序架构设计

> 日期:2026-08-16 · ⚠️ 非投资建议 · 目标:通用专家兜底 + 行业专家可插拔覆写;**地基串行建一次,各行业专家互相独立可并行**。

## 1. 分层与依赖(单向)
```
采集层 collectors/financial.py         # 三大表(+修2bug +补银行科目)——共享地基
   → 分析层 metrics.py                 # 派生指标(+银行比率 +2个通用减法派生)——共享地基
   → 分析层 financial/industry/         # ★行业专家注册表 + 各行业模块(互相独立·可并行)
       __init__.py  registry           # key(申万一级)→ 专家模块;缺→None(用通用)
       银行.py / 电子.py / 通信.py …     # 各自:dimension_specs/weights/skip_flags/extra_flags/note
   → 分析层 scoring.py / flags.py       # 通用兜底 + 接受行业覆写(specs/weights/skip/extra)——共享地基
   → 分析层 analyzer.py                 # 路由:_industry_key(code)→专家→喂给 scoring/flags——共享地基
   → 决策/展示                          # record.financial 块带 行业专家/口径说明
```

## 2. 行业专家接口(每个行业一个模块,统一契约)
`tools/analysis/financial/industry/<key>.py` 导出:
```python
KEY = "银行"                       # 申万一级
NOTE = "银行专属口径;不良/拨备/资本充足 akshare 缺采,当前用代理指标"   # 页面标注
def dimension_specs() -> dict: ...  # 覆写五维子指标+区间(格式同通用 [(显示名,derived键,lo,hi)])
def weights() -> dict | None: ...   # 覆写五维权重(可 None=用通用)
SKIP_FLAGS = ["高负债", ...]        # 该行业不适用的通用红旗(不判)
def extra_flags(derived, structured) -> list[dict]: ...  # 行业专属红旗(如银行拨备不足)
```
**互相独立**:各模块只读 derived/structured + 自己的常量,不互相 import、不改共享文件 → **可并行开发**(不同文件、无共享写)。

## 3. 注册表 + 路由
- `industry/__init__.py`:`EXPERTS = {m.KEY: m for m in [银行, 电子, ...]}`;`get_expert(key)`。
- `analyzer._industry_key(code, industry)`:industry_map 对齐申万一级(复用现 `_is_financial` 口径)。
- `analyze()`:`exp = get_expert(key)`;有 → 用 `exp.dimension_specs()/weights()/SKIP_FLAGS/extra_flags`;无 → 通用。
- 复用现成:`_is_financial`(已识别银行)、`flags` 的金融业跳过(将泛化为 `SKIP_FLAGS`)。

## 4. scoring/flags 改造(接受覆写,向后兼容)
- `scoring.five_dims(derived, specs=None)`:specs 给则用行业区间,否则 `dimension_specs()`(通用)。
- `scoring.quality_score(derived, flags, weights=None)`:weights 给则用行业权重。
- `flags.evaluate_flags(derived, structured, skip=None, extra=None)`:skip=行业不适用红旗;extra=行业专属红旗清单。

## 5. 共享地基(必须先建·串行)
- **A. collector 修 2 bug + 补银行科目**:①银行营收 `TOTAL_OPERATE_INCOME`(空)→ 补采 `OPERATE_INCOME`;②减值列 `_LOSS`(恒NaN)→ `_INCOME`;③补银行科目(利息净收入/发放贷款/吸收存款/信用减值/业务管理费)。
- **B. metrics 补派生**:银行比率(存贷比/成本收入比/非息占比/PPOP/ROA/营收增速用银行口径)+ 通用 2 个(应收增速−营收增速差、合同负债环比)。
- **C. registry + 路由 + scoring/flags 覆写钩子**(上面 §2-4)。
- **D. web**:详情页展示 `行业专家/口径说明`(NOTE)。

## 6. 并行计划
1. **先串行建地基 A+B+C+D**(改共享文件 collector/metrics/scoring/flags/analyzer)。
2. 地基好后 → **并行建 7 个行业模块**(`industry/<key>.py` 各自独立文件 + 各自测试):银行/电子/通信/汽车/传媒/交运/计算机。用 isolation=worktree 的 subagent 并行,互不冲突(不同文件)。
3. 每个:实现模块 + 单测(区间/专属红旗/无未来函数)+ 回填该行业方案文档"实现状态"。
