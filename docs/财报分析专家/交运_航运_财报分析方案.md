# 交通运输 · 航运(油运) · 财报分析方案

> ⚠️ 非投资建议。本文仅为财报分析口径设计,不构成任何买卖建议。
> 申万一级:交通运输 · 细分:航运/油运(招商南油 601975 · 成品油运)
> 日期:2026-08-16

---

## ① 行业商业模式与财报特点

航运=**强周期 + 重资产 + 高经营杠杆**。收入=运力(船队)× 运价(TCE),成本大头是**折旧、燃油、船员**,其中折旧是刚性固定成本 → **运价一涨,增量几乎全部落到利润(经营杠杆极高)**;运价一跌,固定成本吞噬利润甚至亏损。

关键特征:
- **业绩由运价决定,运价在财报外**:油运看 **BDTI/TCE**(如 VLCC、MR 型日收益),这是外部市场数据,是理解单季盈利暴涨暴跌的**真正驱动**,财报只是结果。
- **单季波动剧烈**:运价旺季/淡季、地缘事件(如绕行好望角拉长航距抬升运价)导致单季利润大起大落。**不能用单季 PE 判断贵贱**(高点低 PE 是陷阱,低点高 PE 是常态)。
- **重资产、折旧大**:船舶为主要资产,折旧金额大且刚性,**EBITDA / CFO 比净利更能反映真实赚钱能力**。
- **杠杆高**:造船/买船靠借款,资产负债率天然偏高;运价下行 + 高杠杆 = 戴维斯双杀。
- **现金流通常好于利润**:折旧是非付现成本,景气期 CFO 显著高于净利。

## ② 关键指标(讲解 + 好坏标准)

| 指标 | 讲解 | 好 | 警惕 |
|---|---|---|---|
| **单季营收 / 单季归母(及环比)** | 捕捉运价周期 | 环比上行 | 环比连续下滑=周期见顶 |
| **毛利率 / 营业利润率** | 运价对固定成本的杠杆效应 | 景气期可 30%+ | 快速收窄=运价回落 |
| **CFO / 归母净利** | 折旧非付现,现金含量应高 | >1.2(景气期) | <1 需查应收/一次性 |
| **EBITDA(近似:营业利润+折旧摊销)** | 剔除折旧看真实盈利 | 稳健为正 | 转负=经营性亏损 |
| **资产负债率** | 高杠杆风险 | <55% 较稳健 | >65% 且运价下行=高危 |
| **短债覆盖 / 有息负债** | 偿债与利息压力 | 货币资金能覆盖短期有息 | 覆盖 <1 且高杠杆 |
| **折旧占营收比** | 重资产刚性成本 | 稳定 | 骤升(新船交付)而营收不跟 |
| **船队规模/运力**(需正文) | 供给端 | 与运价周期匹配扩张 | 高点大举订船=周期错配 |
| **TCE / BDTI**(外部) | 业绩的真正先行指标 | 上行 | 暴跌 |

## ③ 行业专属红旗

1. **周期高点追高扩张**(高:运价高位时大举订船/加杠杆,交付即遇周期下行)。
2. **运价暴跌致单季盈利崩塌**(高:单季归母环比/同比大幅转负,营业利润率快速收窄)。
3. **高杠杆 + 运价下行**(高:资产负债率 >65% 且单季利润下滑,戴维斯双杀)。
4. **短债覆盖不足**(中:货币资金 < 短期有息负债,重资产偿债压力)。
5. **仅凭单季高盈利/低 PE 追高**(方法论红旗:周期股禁用单季 PE,须用**穿越周期的均值/重置成本**;本项在展示层提示,非财务判据)。
6. **折旧激增而营收不跟**(中:新船交付推高折旧,运价未同步,利润被摊薄)。

## ④ 五维调整方案(子指标 + 建议区间)

> **核心原则**:周期股的"成长/回报"单季值极不稳定,评分应**弱化单季成长、强化现金流与偿债安全边际**,并在展示层强制标注"强周期,单季分数仅供参考,须结合运价周期位置"。

| 维度 | 建议子指标 | 建议区间(0→100) | 相对通用的调整 |
|---|---|---|---|
| **成长** | 营收增速 | -30 → 60 | **放宽双向**(周期波动大);权重**调低** |
| | 单季营收环比 | -30 → 30 | 加入,捕捉拐点 |
| **质量** | 毛利率 | 0 → 40 | 景气期高毛利 |
| | 现金含量 CFO/归母 | 0.5 → 1.5 | **提权重+上移**(折旧非付现,现金应强于利润) |
| **健康** | 资产负债率(反向) | 70 → 35 | **提权重**,高杠杆是周期股命门 |
| | 短债覆盖 | 0 → 2 | |
| **运营** | 应收周转天数(反向) | 90 → 20 | 航运应收账期短 |
| **回报** | ROE | -10 → 25 | **放宽下限**(周期低谷可为负) |

**权重建议**:成长 0.10(减配)/ 质量 0.25 / 健康 0.30(高杠杆重配)/ 运营 0.10 / 回报 0.25。**健康+回报+质量为主,成长维度对周期股意义弱**。

## ⑤ 数据可得性

| 指标 | 状态 | 说明 |
|---|---|---|
| 营收增速、单季营收/单季归母、单季环比、毛利率、CFO 现金含量、资产负债率、短债覆盖、有息负债、应收周转、ROE | **akshare 现成** | metrics.py 已派生(单季拆分已实现) |
| 折旧摊销 | **akshare 现成** | 现金流量表 `FA_IR_DEPR`(固定资产折旧)/`IA_AMORTIZE` 已采 |
| EBITDA(营业利润+折旧+摊销) | **可算(需新增派生)** | 原子已有:营业利润(利润表)+ 折旧+摊销(现金流量表),做加法即可 |
| 折旧占营收比 | **可算(需新增派生)** | 折旧 / 营业总收入 |
| 船队规模 / 运力(DWT)/ 船龄 | **需正文** | 年报"主要资产"及经营讨论;财务表无 |
| **TCE / BDTI / VLCC-MR 日收益** | **算不出(外部)** | 波罗的海交易所等市场数据,须外部行情源;是业绩先行指标 |
| 重置成本 / 二手船价 | **算不出(外部)** | 用于穿越周期估值,需 Clarksons 等外部数据 |

> 关键提示:招商南油为**成品油运(MR 型)**,应看 **BCTI/MR TCE** 而非原油 VLCC 的 BDTI——两者虽相关但不完全同步,标注时须区分成品油 vs 原油运价。

## ⑥ 变量说明

- **TCE(Time Charter Equivalent)**:等价期租租金,航运业最通用的运价口径(日收益),航运公司盈利的**真正驱动变量**,来自外部行情。
- **BDTI / BCTI**:波罗的海原油/成品油运价指数;招商南油(成品油)看 **BCTI/MR**,原油油轮看 BDTI/VLCC。
- **经营杠杆**:固定成本(折旧)占比高,运价小幅变动被放大到利润的大幅波动——航运暴涨暴跌的根源。
- **EBITDA**:税息折旧摊销前利润,剔除刚性折旧看真实经营现金创造力,航运优先于净利。
- **单季 PE 陷阱**:周期高点利润最高、PE 最低(看着最便宜),恰是最危险时点;必须用跨周期均值/重置成本。
- 反向指标(资产负债率、应收周转天数)区间"0分端 > 100分端"。
