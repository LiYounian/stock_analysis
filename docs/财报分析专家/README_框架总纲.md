# 财报分析专家 · 框架总纲

> 日期:2026-08-16 · ⚠️ 非投资建议 · 财报分析是主要模块,持续深做。
> 缘起:通用五维(成长/质量/健康/运营/回报)对**不同行业失真**——银行无毛利率/存货周转、五维压低;
> 半导体/光模块看研发/产能/客户集中;航运看运价周期。**不同行业需不同分析方法与衡量标准**。

## 1. 设计:通用专家 + 行业专家(可插拔覆写)
- **通用专家**(现五维,`scoring.py`)= **兜底**:任何行业无专属专家时用它。
- **行业专家** = 对某申万一级/细分,**覆写**通用口径 + 加行业专属指标/红旗:
  - 覆写五维**子指标/区间/权重**(如银行:去毛利率/存货周转,换 ROE/资产质量);
  - 加**行业专属红旗**(如银行:不良率↑/拨备↓/资本充足↓;半导体:存货减值/客户集中);
  - 给 verdict/展示补**行业上下文**。
- **挂接**:`analyzer` 按 `industry_map` 把票映射到专家 key;有专属→用之,无→通用。config 挂 `THRESHOLDS['财报']['行业专家'][<key>]`。
- **数据**:多数行业现有三大表科目够;**银行/非银需专属科目**(拨备/不良/资本充足/净息差)——若采集层暂缺,先用可得指标(ROE/资产负债结构)+ **页面标注"通用五维不适用,行业专属指标待补采"**,后续补采集。

## 3. 每个行业一个方案文档(本文件夹内)
命名 `<申万一级>_<细分>_财报分析方案.md`,含:①行业商业模式与财报特点 ②关键指标(替代/补充五维哪些)③行业专属红旗 ④评分口径建议(区间/权重)⑤所需数据科目 + 现采集层是否已有 ⑥变量说明。**调研好一个 → 落一个方案文档 → 实现一个专家**。

## 4. 落地顺序(调研好一个做一个)
1. 先出各行业**方案文档**(subagent 调研 + 我审定)。
2. 按"数据现成度 + 失真严重度"排序实现:**银行(最失真)→ 电子/通信(自选占比最高)→ 其余**。
3. 每实现一个:config 挂行业专家 + analyzer 路由 + 测试 + 页面标注 + 回填本总纲状态表。
