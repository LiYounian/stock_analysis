# 半导体(fabless / 科创未盈利成长期)财报分析要点 + 评分豁免

> 分支 `feat/semi-financial`。背景:策略5/6·半导体多因子选出的科创板 fabless 芯片设计票,
> 财报被通用高危红旗(尤其「扣非为负」=高危封顶35分)一律打成「差/风险」。本文档记录
> ① 联网调研得到的半导体财报分析要点(改代码依据)② 据此做的路由修复 + 成长期豁免。
> ⚠️ 非投资建议;阈值为工程占位,可由策略提供者标定。

## 一、调研结论:哪些通用红旗对半导体是误伤 / 行业常态

| 通用红旗 | 为何对成长期/ fabless 半导体是常态 | 分析师改看什么 |
|---|---|---|
| **扣非净利为负 / 当期亏损** | 科创板第五套上市标准对营收/CFO/净利均不设门槛,专为「高研发、长期亏损但技术领先」硬科技设计;54 家未盈利企业营收复合增速 26%、合计减亏。寒武纪(688256)累亏>50亿仍成科创板首个万亿市值股 | 营收增速/减亏趋势/研发/里程碑,**不看当期利润** |
| **研发费用率高(15%–30%+)** | fabless/设计研发强度典型 10%–25%,越高越体现竞争壁垒;**研发不足(<8%)才是负面** | 研发强度当**正向因子** |
| **经营现金流(CFO)弱/为负** | 成长期「以现金换增长」(扩客户/扩产/备晶圆)的正常形态 | **cash runway 月数**(现金÷月净烧钱),>3–5 年即安心 |
| **应收/存货高企** | 扩产期、上行周期主动囤晶圆/备货是常态;存货是周期领先指标而非孤立红旗 | 存货天数×毛利率方向:毛利升+存货天数降=上行(健康);毛利降+存货天数升=下行(才警惕);DOI<90 紧、90–120 正常、>120 才提示 |
| **高 SG&A / 上市初期费用率高** | 营收基数小、固定/中介/股权激励费摊薄 | 看费用率随营收放量的下降趋势(行业常识) |

## 二、半导体真正该重点看的维度

研发强度(R&D/营收 10–25%,设计最高)· 毛利率(按环节:fabless 50–70% / foundry 40–50% /
封测 20–25% / 设备 40–60% / EDA 57–89%)· 存货结构与 DOI×毛利率方向 · **cash runway 月数** ·
营收 YoY/复合增速与在手订单(book-to-bill>1)· capex 强度(fabless<5%,foundry/memory 20–30%)·
ROA/ROIC(fabless 轻资产高 ROA)· 客户集中度 · 流片/掩膜(NRE)一次性研发支出。

**核心:先按产业链环节(设计/制造/封测/设备材料)选基准区间,再判红旗**,否则跨环节误判。

## 三、未盈利科创板(第五套)特殊性 + U 标识

- 评估锚定营收增长/研发/市占率/技术里程碑而非当期利润;监管取向「产品技术领先」。
- 上市未盈利股带 **"U"**;首次盈利即摘U。摘U量化门槛:①近两年净利均正且累计≥5000万;或
  ②近一年净利为正且营收≥1亿。**监管对盈利质量本就宽容,评分框架不应比监管更苛刻。**

## 四、据此做的代码改动

### 4.1 路由修复(让半导体票命中「电子」专家)
根因:①`screen_semi_factor` 调 `build_financial_block` 未传 industry;②`board.board_of` 因
board_membership 成分数据本机不可用恒 None;③证监会门类把 fabless 判成「计算机/软件」。

- `tools/pipeline/screen_semi_factor.py`:`build_financial_block(..., industry="电子")`
  (本 screener 只扫申万二级 801081 半导体池,全部对齐电子)。
- `tools/analysis/financial/analyzer.py`:`_industry_key` 增**半导体池成分兜底**——industry/board
  都解析不到时,若 code ∈ `config/semi_universe.json`(801081)→ 返回「电子」。修所有调用点
  (serialize 生产闭环、council、semi screen)的半导体路由,不依赖缺失的 board 数据。

### 4.2 成长期未盈利半导体豁免(不再一刀切高危封顶)
- `tools/analysis/financial/industry/电子.py`:
  - `_is_growth_semi(derived, structured)` 画像判定——**三条同时**:研发费用率≥15% + 营收增速≥20% +
    当期扣非为负(严格圈定 fabless 成长期,避免误伤衰退/低研发的普通电子亏损票)。
  - `dynamic_skip()`(analyzer 每报告期调用的新可选钩子):画像成立 → 豁免通用红旗
    「扣非为负」「现金含量不足」(去掉高危封顶);否则返回 `[]`(普通电子票行为不变)。
  - `extra_flags()` 承接:画像成立时加 **`成长期未盈利_研发驱动`(严重度=提示,0扣分)** 透明化标注
    + `现金runway承压`(中,runway<12 个月)。
- `tools/analysis/financial/metrics.py`:新增衍生指标 **`现金runway月数`**(货币资金÷月净经营烧钱率;
  CFO≥0 不烧钱→None)。
- `tools/analysis/financial/analyzer.py`:接 `dynamic_skip` 钩子(与静态 SKIP_FLAGS 并集,每报告期算)。
- `tools/config/strategy.py`:红旗扣分新增 **`提示: 0`** 档(纯信息标注不压分);登记两条新信号严重度。

### 4.3 兼容与边界
- 「提示」严重度不计入高危计数(`high_flag_count` 只数「高」),不封顶、0扣分。
- 非半导体、非成长画像的电子票:`dynamic_skip` 返回 `[]`,行为与改前逐字节一致。
- 真有问题的半导体票仍标:豁免只去掉「扣非为负」一刀切封顶,电子专家自身的周期红旗
  (存货高企叠加毛利下滑→高、runway<1年→中)照常升起,高负债/商誉/非标审计等高危照旧封顶。

## 六、遗留 / 后续
- 产业链**环节细分**(设计/制造/封测/设备材料各自毛利率/capex 基准)尚未落地——当前统一走「电子」
  区间。可后续按环节子标签细化(需环节成分数据)。
- U 标识 / 第五套上市标准识别未接(当前用「高研发+高增+扣非为负」财务画像代理,跨科创/创业板通用)。
- runway 用累计 CFO 折月估算(季报会低估烧钱、runway 偏乐观),仅作辅助提示,不作硬门槛。
- 阈值(研发15%/增速20%/runway12月)为调研锚定的工程占位,待策略提供者标定。
