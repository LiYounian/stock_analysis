# 传媒 · AI应用 / 游戏 · 财报分析方案

> ⚠️ 非投资建议。本文仅为财报分析口径设计,不构成任何买卖建议。
> 申万一级:传媒 · 细分:AI 应用 / 游戏(昆仑万维 300418)
> 日期:2026-08-16

---

## ① 行业商业模式与财报特点

**游戏/AI 应用=轻资产、高毛利、内容驱动**。收入来自玩家充值(游戏)、订阅/广告/API 调用(AI 应用)。几乎无生产成本,毛利率天然高(游戏可达 80%+,AI 应用受算力成本拖累略低)。

核心财报特征:
- **高毛利、重费用**:毛利率高,但**销售费用(买量/推广)和研发/内容投入巨大**,净利率取决于费用管控。买量占比过高=增长不可持续。
- **递延收入(合同负债)**:游戏充值先收钱后确认,**合同负债/预收款 = 未来收入蓄水池**,是流水的财务映射,领先营收。
- **商誉高企**:传媒公司靠并购工作室/IP 扩张,**商誉减值是最大杀手**(历史上传媒板块商誉暴雷频发)。
- **一次性收益扰动**:投资收益(所投项目退出/公允价值变动,尤其昆仑万维有大量对外投资)常大幅扰动归母净利 → **扣非才是主业**。
- **关键运营指标在财报外**:流水、MAU/DAU、付费率、留存、ARPU——财务表看不到,需正文/运营数据。AI 应用还要看 token 消耗/算力成本占比。

## ② 关键指标(讲解 + 好坏标准)

| 指标 | 讲解 | 好 | 警惕 |
|---|---|---|---|
| **营收增速** | 新品/新应用放量 | 稳健正增 | 老产品流水衰退致负增 |
| **毛利率** | 轻资产本色 | 游戏 >70%、AI 应用 >50% | 明显下滑(算力成本吞噬/分成上升) |
| **合同负债 / 预收款(及环比)** | 流水蓄水池、领先指标 | 环比增 = 新游/买量见效 | 环比连降 = 流水下滑前兆 |
| **销售费用率** | 买量强度 | 稳定;收入增速 > 费用增速 | 费用暴增而收入不跟=买量失效 |
| **研发费用率** | 内容/大模型投入 | 8%~20%,持续 | 骤降=内容后继乏力 |
| **扣非占归母** | 剔除投资收益水分 | >0.7 | 归母增而扣非降=靠投资收益 |
| **商誉 / 净资产** | 并购雷区 | <20% 且无减值迹象 | >40% 或已现减值 |
| **CFO / 归母净利** | 现金真实性(游戏应很好) | >1.0(先收钱模式,CFO 常好于利润) | 显著 <1=充值确认或回款异常 |
| 流水 / MAU / ARPU(需正文) | 运营健康度 | 增长、留存稳 | 下滑 |

## ③ 行业专属红旗

1. **商誉高企 / 减值**(高:商誉/净资产 >40%,或当期 `资产减值损失` 中含商誉减值)。
2. **靠一次性/投资收益撑利润**(高:扣非占归母 <0.6,或归母正而扣非大幅下滑;昆仑万维尤需盯投资收益)。
3. **流水下滑**(中→高:合同负债/预收款环比连续 2 季下降,营收随后大概率走弱)。
4. **买量失效**(中:销售费用增速 > 营收增速 20pct 以上,净利率被侵蚀)。
5. **毛利率异常下滑**(中:AI 应用算力成本上升吞噬毛利,或游戏渠道分成上升)。
6. **研发/内容投入骤降**(低:研发费用率明显下台阶,产品管线后劲存疑)。

## ④ 五维调整方案(子指标 + 建议区间)

| 维度 | 建议子指标 | 建议区间(0→100) | 相对通用的调整 |
|---|---|---|---|
| **成长** | 营收增速 | -20 → 50 | 保留弹性 |
| | 扣非净利增速 | -20 → 60 | 用扣非,剔投资收益 |
| **质量** | 毛利率 | 40 → 85 | **大幅上移**(轻资产高毛利,通用 0→50 会顶格失真) |
| | 扣非占归母 | 0.5 → 1.0 | **提权重**,识别投资收益依赖 |
| | 现金含量 CFO/归母 | 0.3 → 1.5 | 先收钱模式,CFO 应偏高 |
| **健康** | 商誉占净资产(反向) | 50 → 0 | **提权重**,传媒头号雷 |
| | 资产负债率(反向) | 60 → 15 | 轻资产,负债本低 |
| **运营** | 合同负债环比(新增,正向) | -30 → 30 | **替代**存货/应收周转(游戏无存货、应收意义弱) |
| **回报** | ROE | 0 → 20 | |

**权重建议**:成长 0.20 / 质量 0.30 / 健康 0.20(商誉重配)/ 运营 0.10 / 回报 0.20。**质量+健康(商誉)最重**。运营维度传统周转指标基本失效,改用合同负债动量。

## ⑥ 变量说明

- **合同负债 / 预收账款**:玩家已充值但未消耗的部分,先收钱后确认收入,是**未来营收的领先蓄水池**,环比变化比营收更早反映流水拐点。
- **流水 vs 营收确认**:流水=玩家实际充值,营收=按消耗节奏确认;流水领先营收 1~2 季。
- **扣非净利**:剔除投资收益、公允价值变动等;昆仑万维对外投资多,**必须以扣非看主业**。
- **商誉减值**:并购标的业绩不达预期时一次性计提,直接砸归母净利,传媒最大暴雷源。
- 反向指标(商誉占净资产、资产负债率)区间"0分端 > 100分端"。
