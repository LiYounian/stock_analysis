# 计算机 · 云计算 / 算力服务 · 财报分析方案

> ⚠️ 非投资建议。本文仅为财报分析口径设计,不构成任何买卖建议。
> 申万一级:计算机 · 细分:云计算 / 算力服务 / IDC(行云科技 为典型样本)
> 日期:2026-08-16

---

## ① 行业商业模式与财报特点

"算力服务"是个**外表高成长、内里盈利质量高度存疑**的赛道,细分差异极大:
- **算力租赁 / IDC**:采购 GPU 服务器/建数据中心,再对外出租算力。**重资产、重资本开支、盈利质量存疑**——收入可爆发式增长,但净利率极薄,现金流被 capex 和应收吞噬。这是**行云科技类**标的的核心画像:营收暴增,但利润含金量差。
- **云计算/SaaS(软件)**:轻资产、订阅制、高毛利,盈利质量好于算力租赁,但早期常亏损换增长。

**本方案重点针对"算力服务/算力租赁"这类"营收暴增但质量存疑"的形态**,核心矛盾是:

- **营收爆发 vs 盈利极薄**:转售算力/贸易属性重,毛利率个位数,营收翻倍但净利率可能 <2%。
- **应收激增**:大客户/关联方赊账,应收随收入暴涨甚至更快,回款存疑。
- **现金流为负**:重资产(买 GPU/建 IDC)导致 capex 巨大,CFO 常年为负,靠融资输血。
- **毛利率异常跳升**:若某季毛利率无业务逻辑地大幅跳升,警惕**激进确认收入 / 关联交易做高毛利**。
- **扣非质量差**:政府补助、税收优惠可能占利润大头。

## ② 关键指标(讲解 + 好坏标准)

| 指标 | 讲解 | 好 | 警惕(算力服务尤其) |
|---|---|---|---|
| **营收增速** | 表面最亮 | 高增且伴随利润/现金同步 | **暴增但净利率极低/现金为负=空心增长** |
| **净利率** | 盈利质量核心 | 软件 >15%;算力租赁 >8% 算不错 | 长期 <3% = 只走量不赚钱(贸易化) |
| **毛利率(及趋势)** | 业务含金量 | 稳定、有业务逻辑支撑 | **异常跳升**(无解释的大幅上台阶)=激进确认收入嫌疑 |
| **应收 & 应收增速** | 回款质量,头号风险 | 应收增速 ≤ 营收增速 | **应收增速远超营收**=赊销撑收入 |
| **CFO / 归母净利** | 利润是否变现 | >0.5(重资产早期可略低) | 长期为负 = 利润是纸面的 |
| **自由现金流(CFO−capex)** | 重资产真实造血 | 转正或收窄 | 持续大额为负,靠融资续命 |
| **扣非占归母** | 剔除补助 | >0.7 | <0.5 = 靠补助/优惠 |
| **资产负债率 / 有息负债** | 扩张融资压力 | 可控 | 高杠杆 + 现金为负 |
| **在建工程/固定资产增速** | IDC/算力扩张 | 与收入匹配 | 大幅超前于收入放量 |
| 存货增速 | 硬件囤货 | ≤营收 | 远超营收=囤货/滞销 |

---

## ③ 行业专属红旗

1. **营收暴增但净利率极低**(高:营收增速 >50% 而净利率 <3%,典型空心增长/贸易化。此为行云科技类核心红旗)。
2. **应收激增于营收**(高:应收增速 − 营收增速 > 30pct,回款质量存疑)。
3. **现金流长期为负**(高:CFO 连续为负,或自由现金流大额为负且靠筹资净流入补窟窿)。
4. **毛利率异常跳升**(高:毛利率单季大幅上台阶且无业务解释,激进确认收入 / 关联交易嫌疑)。
5. **存货激增**(中:GPU/服务器囤货,存货增速远超营收)。
6. **扣非质量差**(中:扣非占归母 <0.5,靠补助/税收优惠)。
7. **在建工程超前收入**(中:大额 capex/在建工程但收入未兑现,产能空转风险)。

## ④ 五维调整方案(子指标 + 建议区间)

> **核心原则**:算力服务最大陷阱是"用营收增速骗高分"。评分须**压低成长权重、强化质量(现金/应收/毛利真实性)权重**,让"暴增但空心"的票拿不到高分。

| 维度 | 建议子指标 | 建议区间(0→100) | 相对通用的调整 |
|---|---|---|---|
| **成长** | 营收增速 | -20 → 60 | 保留弹性但**权重大幅调低** |
| | 扣非净利增速 | -20 → 60 | 用扣非 |
| **质量** | 净利率(新增) | 0 → 15 | **新增为核心子指标**(算力服务生死线) |
| | 现金含量 CFO/归母 | -0.5 → 1.2 | **提权重**,下限设负捕捉现金为负 |
| | 毛利率 | 0 → 40 | |
| | 扣非占归母 | 0.5 → 1.0 | |
| **健康** | 自由现金流(新增,正向标准化) | — | 用是否持续为负作红旗;评分可取 CFO−capex 占营收比 |
| | 资产负债率(反向) | 75 → 30 | |
| **运营** | 应收周转天数(反向) | 180 → 30 | **提权重**,应收是头号雷 |
| | 应收增速−营收增速差(新增,反向) | 30 → -10 | 直击赊销冲收入 |
| **回报** | ROE | -5 → 15 | 放宽下限(早期可负) |

**权重建议**:成长 0.15(减配)/ 质量 0.35(重配:现金+净利率+毛利真实性)/ 健康 0.15 / 运营 0.20(应收重配)/ 回报 0.15。**质量+运营为核心防线**,专治"空心高增"。

## ⑥ 变量说明

- **算力租赁 vs 软件/SaaS**:前者重资产、薄利、现金差、盈利质量存疑;后者轻资产、高毛利、盈利质量好。同属"计算机·云计算"但风控口径迥异,须先按资产结构(固定资产/在建工程占比高 → 算力租赁)分流。
- **空心增长**:营收暴增但净利率极低、现金流为负、应收激增——收入"看着增,钱没进",本行业头号陷阱。
- **激进确认收入**:提前/虚增确认(总额法转售、关联交易做高),表现为毛利率无逻辑跳升 + 应收暴增,须结合两者交叉验证。
- **自由现金流(FCF = CFO − capex)**:重资产行业真实造血能力,持续大额为负=靠融资续命。
- **扣非净利**:剔除政府补助、税收优惠等;算力服务补助占比常偏高。
- 反向指标(周转天数、资产负债率、应收−营收增速差)区间"0分端 > 100分端"。

  2. 应收激增超营收(高):应收营收增速差 > 30pct(赊销撑收入)。
  3. 经营现金流为负(高):CFO<0 且 归母净利润>0(纸面利润)。
