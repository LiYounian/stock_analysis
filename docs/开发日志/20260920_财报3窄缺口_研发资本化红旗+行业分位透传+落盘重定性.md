## 缺口一:研发费用化 vs 资本化「注水」红旗

### 现状核实
- 表内只有 `研发费用`(利润表·费用化)+ `开发支出`(资产负债表·资本化研发**存量**);**无现金流"本期资本化研发"流量科目**(核 300750 等样本)。故只能用 `开发支出/研发费用` 作**粗代理**——与 `医药生物.py` 已成熟的「研发过度资本化」旗、`_calibration.py` 已登记的 `开发支出比研发费用` 度量同源。
- 医药已有(高);**汽车已有**(`研发资本化激进`,占位阈值 1.0);其余研发密集行业无。

### 实现
- 电子/计算机/通信/机械设备/国防军工/电力设备 各加 `研发资本化激进` 红旗(**严重度中**);汽车阈值由占位 1.0 上调到 p90=4.7 并补诚实 NOTE。
- 医药保持 `研发过度资本化`(高)+ 阈值 3.0 **不动**(防回归,约法6)。
- **文案诚实(统筹要求)**:值 NOTE = "开发支出/研发费用 粗代理,偏高=注水嫌疑非确认,精确资本化率待正文核"——是"离群嫌疑"非"确认注水"。

## 缺口二:塔身工具层档位透行业分位

### 关键辨析(避免夸大精度)
引擎**已算**的是「行业化**评分区间**」(dimension_specs 的 [0分端,100分端]),**不是**"同行业经验百分位"。故:
- growth_quality 的毛利率/负债率 → 透传"本行业评分档";净利率仅计算机/非银的 specs 有;银行 specs 三者皆无(用 ROA/存贷比)。
- valuation 的 PE/PB → 引擎没算行业区间,要做=当日全行业横截面新管线(B 期),**本轮不做,只加口径注**。

### 实现
- `analyzer._industry_score_band`:有行业专家时,把毛利率/资产负债率(/净利率)在本行业 dimension_specs 区间的 `_score_linear` 定位(score)固化进 `financial.行业评分档`;无专家→None。**引擎侧一次算好,不重算**。
- `growth_quality`:有 `行业评分档`→"本行业X评分档优/良/中/弱"(score 经统一 `_QUALITY档`,与 five_dims 同口径);无→回退跨行业粗档并明标"跨行业";金融业负债率仍走金融例外不透。
- `valuation`:PE/PB 口径标"跨市场粗档",意味加"行业分位属 B 期横截面管线,暂未接入"。
- **文案诚实(统筹)**:写"本行业评分档"非"经验百分位"。**going-forward 每日 analyze 自动填,不回灌历史存量**(同补落盘惯例)。

## 缺口三:扩财报覆盖 → **重定性**为专家覆盖缺口 + 一处路由 bug

### 排查事实(最新 data/analysis/2026-09-18,558 只真个股)
- **落盘 0 缺口**:558/558 都有非空 `financial` 块;raw 全在;无管线漏、无 raw 缺。任务书"扩落盘"措辞被此纠正。
- 真正缺口在块内深度:命中 16 专家=419(75.1%);`行业专家=null` 走通用兜底=139(24.9%),全部落在 16 专家覆盖外的 13 个申万一级(公用事业22/综合20/社服18/建筑建材各14 等)。
- **000504「显糙」根因=通用兜底口径,非缺数据**。
- **路由 bug**:CXO 医药票(300725/301230/688710/301060)`code_industry` 挂"综合/商贸零售"(无专家),而 `industry_history`(严格 as_of)=医药卫生→医药生物(有专家),主路由 `_industry_key` 不消费 formal 源 → 漏路由。

### 本轮实现(③加轻量专家留后续轮次)
- **① 通用兜底展示明标**:`行业专家=null` 但有 quality/five_dims 的票,财报质量汇总打标"通用口径(无行业专属专家)"+"五维为通用测算,非数据缺失"。改展示不改模型。fields 增 `行业专家/通用兜底/行业评分档`。
- **② 路由回退救援**:`_industry_key` 在当前落点**无专家**且时变正式行业(industry_history,严格 as_of,防未来)**有专家**时,救援到时变正式;board 已命中专家(300504→电子)或 formal 亦无专家(000504→综合)时行为不变——不引入全域路由重排。真实数据端到端验证 4 只票救援到医药生物成功。
