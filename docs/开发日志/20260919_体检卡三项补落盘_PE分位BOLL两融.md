## 背景
体检卡 Wave2 工具会"读到就用、没有标待补落盘"。三项数据算了/采了却没进 per-stock json
（`data/analysis/<date>/<code>.json`），导致工具恒标"待补落盘"。本轮把它们补进序列化器
（`tools/analysis/serialize.py` 的 `build_record`）与对应工具读取处，让工具自动读到真值。

## 三项现状核实（调研纠偏）
- **PE历史分位 = 算了没拷**：`tools/collectors/fundamental.py:_valuation_scalars` 已算
  `fund["PE分位"]`（0~1，现值 PE(TTM) 在自身历史 PE 序列中的 ≤x 占比）+ `PE分位窗口`，
  现成于 `load_fundamental()` 返回的 fund dict，只是构造 `valuation_block` 时漏挑。
  （首轮调研误判"根本没算"，经直读 `load_fundamental('000026')→PE分位=0.6795` 确认为漏拷。）
- **BOLL = 算了没拷**：`tools/analysis/technical.py:_boll_state` 产出
  `tech["boll"]={上轨/中轨/下轨/带宽/percent_b/位置/挤压}`，`_build_snapshot` 漏挑。
- **两融 = 采了没进 record**：`collectors.margin` 已按 code 落库（store raw kind=margin，
  带日期路径 `data/raw/<date>/margin/<code>.json`）。**无需扩采集**。`serialize.py` 原注明写
  "有意不进 record，若挂进按 consensus 同款处理"。

## 落盘位置 + 键名对齐（补落盘键名必须与工具读取键名一致）
| 项 | json 段/键 | 工具读取处 | 备注 |
|---|---|---|---|
| PE历史分位 | `valuation.pe_percentile`(0~1) + `pe_percentile_window` | valuation_tool | snake_case 对齐 pe_ttm/pb |
| BOLL | `snapshot.boll`（透传 tech["boll"] + 加 `状态` 别名=位置值） | technical_detail_tool（已有读取） | 工具读 `状态`、源产 `位置`，序列化侧加同值别名，不动 technical.py |
| 两融 | **顶层 `margin` 块**（非 financing.margin） | fund_flow_tool 改读 `d.get("margin")` | financing 是自证块，嵌入会破坏一致性；顶层块+_stamp 正是 consensus 同款 |

## 关键决策
- **两融落顶层 margin 块**（不塞 financing.margin）：financing 块内自带 as_of/源状态/降级
  （自证块），塞进去破坏自证一致性、也拿不到 consensus 式口径戳与 VINTAGE_BLOCKS 校验。
  顶层块 + `_stamp` 严格照 serialize 原注"按 consensus 同款处理"。
- **BOLL 状态别名**：`_boll_state` 只产 `位置`（破上轨/触上轨/中性/触下轨/破下轨），工具读
  `状态`。序列化侧 `{**tech["boll"], "状态": 位置值}` 加同值别名，不改 technical.py（避免动
  其他消费方语义）。
- **两融不套涨跌档**：margin 块无历史/截面基线，如实报融资余额/融资买入/融券余量规模 + 口径
  日期（融资盘后 T+1 可用），不编造 高/低 档（守则：缺基线不空编）。
- **防未来函数**：两融 `summarize_asof` 取 ≤as_of 最新一日、剔除 date>as_of；口径日期 = 记录
  自带 date（非分区日），as_of 更晚则 `_stamp` 标"陈旧"。

## 改动清单
- `tools/analysis/serialize.py`：valuation_block 加 pe_percentile/窗口；snapshot 加 boll(+状态别名)；
  顶层加 margin 块（load_margin+summarize_asof）+ consensus 同款 _stamp + provenance 布尔/口径。
- `tools/pyramid/tools/valuation_tool.py`：新增 `_PE分位档`，占位分支改读 pe_percentile 出真档。
- `tools/pyramid/tools/fund_flow_tool.py`：`_f_两融(margin)` 改读顶层 margin 块出真值 + 机读 fields。
- `tools/contracts/record.py`：RECORD_SCHEMA 加 snapshot.boll / valuation.pe_percentile / margin 段；
  margin 进 VINTAGE_BLOCKS/OPTIONAL_TOP；provenance 维列表加 margin。
