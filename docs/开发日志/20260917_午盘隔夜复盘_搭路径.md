## 本轮做了什么（第一步：搭路径 + 测试）
定义并实现「隔夜口径」午盘复盘：**当天收盘买入（D 收盘价）→ 次日 11:30 全A午休冻结快照卖出
（代理"次日午盘前~11:00"）→ 隔夜绝对收益 r_overnight + α + 规则归因**。与尾盘大复盘彻底解耦、
复用不重写。

## 关键决策（与统筹对齐）
- **卖出价真源**：`data/intraday/<D+1>/noon_screen_snapshot.json`（全A 11:30 冻结，实测 5564 只
  全覆盖，09-11 起每日有）——比日线 open 近似强、比 T1145 定向 18 只全。分级
  noon_screen→T1145→open 降级→None，**绝不用 D+1 收盘顶替**（破坏"早盘卖"语义）。
- **买入价**：master 日线 close@D（与尾盘 Model-A / Agent 实验窗买入口径同源、跨版可比）。
- **α 基准洞察**：D+1 noon 快照每只 `pct_chg` 恰是「gtimg D收盘→D+1 11:30」隔夜收益 →
  全A等权隔夜基准 = `breadth.equal_weight_mean_pct([pct_chg...])`，零额外 IO、唯一真源、全覆盖。
- **复用**：`Pick`/`loaders.load_picks`/`load_market_context`/`attribution.classify`（经 `_AttrShim`
  适配：untriggered=False、r_exit=r_overnight）/`breadth` 基准，全直接复用；**绝不改** model_a /
  尾盘 types / 尾盘测试。
