# A股股票分析系统 · 数据源调研报告

> 调研日期：2026-08（信息以调研时公开资料为准）
> 目标：为"基本面 / 技术面 / 消息面（舆情）"三类数据找出可落地的获取路径，比较"浏览器抓取"与"公开 API/库"两条路线。
> 一句话结论（详见文末）：**基本面 + 技术面用 AKShare 打底（缺口用 Tushare/BaoStock 补），舆情用"AKShare 新闻/研报接口 + WebSearch/RSS + 巨潮公告"三路混采。**

---

## 0. 结论速览（TL;DR）

- **别一上来就写爬虫。** 90% 的行情、财报、估值、公告、研报、新闻标题，AKShare 一个免费库就能覆盖，它本质上是把东财/新浪/同花顺/巨潮的隐藏 JSON 接口封装好了，比自己抓 HTML 稳得多。
- **浏览器抓取只在两种场景才值得做**：(1) AKShare/Tushare 没有封装的、需要登录态的深度内容（如雪球个股讨论流、东财股吧长贴正文）；(2) 需要"实时增量监控"某只票的舆情。其余一律走库。
- **最难的是"市场舆情/大V观点"这类非结构化数据**，没有任何一个源能一站式拿全，必须混采 + 自己做 NLP 情感分析，详见第 4 节。

## 1. 数据类型 × 推荐数据源 对照表

| 数据类型 | 首选 | 备选 | 为什么这么选 |
|---|---|---|---|
| **日/周/月 K线、成交量** | AKShare `stock_zh_a_hist` | BaoStock（`query_history_k_data_plus`）/ 东财 kline 原生接口 | AKShare 直连东财，含前复权/后复权/不复权；BaoStock 历史数据干净、免注册，适合批量回补 |
| **分钟级/实时行情** | AKShare `stock_zh_a_hist_min_em` / `stock_zh_a_spot_em` | 东财 push2 实时接口 | 免费源里分钟数据 AKShare 最全；真高频要上付费源 |
| **技术指标 MACD/KDJ/RSI/均线** | 本地用 `pandas-ta` / `TA-Lib` 自算 | 东财 F10 已算好的指标接口 | 指标是纯计算，**不建议依赖数据源**，自己算可控、可回测、无频率限制 |
| **财报（营收/净利/负债/现金流）** | AKShare `stock_financial_abstract`（新浪）/ `stock_financial_report_sina`（三大报表） | Tushare `income`/`balancesheet`/`cashflow`（需积分）；巨潮原文 | AKShare 免费够用；要标准化字段、批量全市场，Tushare 更规整但要积分 |
| **估值 PE/PB/PS/股息率/市值** | AKShare `stock_a_indicator_lg`（乐咕，历史 PE/PB）/ `stock_individual_info_em` | 东财 F10 主要指标；理杏仁（付费） | 乐咕的历史估值分位数很适合做估值判断 |
| **ROE/毛利率等财务比率** | AKShare `stock_financial_analysis_indicator`（新浪） | Tushare `fina_indicator` | 免费，历年比率一次取全 |
| **行业对比 / 板块** | AKShare `stock_board_industry_*`、`stock_sector_spot` | 东财板块接口；申万行业分类 | 东财行业/概念板块最活跃 |
| **业绩预告/快报** | AKShare `stock_yjyg_em`（预告）/ `stock_yjkb_em`（快报） | 巨潮 | 事件驱动的关键前瞻信号 |
| **公司公告（增减持/回购/诉讼）** | 巨潮 `stock_zh_a_disclosure_report_cninfo` / 东财 `stock_notice_report` | 交易所官网、`stock_ggcg_em`（高管增减持） | 巨潮是法定信息披露平台，最权威 |
| **龙虎榜/资金流/北向** | AKShare `stock_lhb_detail_em`、`stock_individual_fund_flow`、`stock_hsgt_*` | 东财原生 | 资金面信号，AKShare 覆盖好 |
| **个股新闻** | AKShare `stock_news_em`（个股最近新闻） | WebSearch + 财经媒体 RSS | 见第 4 节，新闻要混采 |
| **研报** | AKShare `stock_research_report_em` | 东财研报中心、慧博 | 拿到评级/目标价/机构，正文一般拿不到全 |
| **股吧/雪球评论（散户情绪）** | 浏览器抓取（雪球/东财股吧） | 无好的免费库 | **最难，见第 4 节**，多数库不封装 UGC 正文 |
| **宏观/政策（央行/证监会/美联储/关税）** | WebSearch + 官网 RSS | AKShare 宏观接口（`macro_china_*`、`macro_usa_*`） | 政策文本用搜索，宏观指标用 AKShare |

## 2. AKShare 重点评估（覆盖度最高，作为系统基座）

**定位**：免费、开源（`pip install akshare`）、无需 token、无需注册，聚合了东财/新浪/同花顺/巨潮/乐咕/雪球等公开接口。对个人/小团队的 A股分析，它能一站覆盖"基本面+技术面"约 80–90% 的需求。

### 2.1 常用接口函数清单（按数据类型）

**行情/技术面**
- `ak.stock_zh_a_hist(symbol="600519", period="daily", start_date="20240101", end_date="20241231", adjust="qfq")` — 日/周/月 K线，含前后复权（数据源：东财）
- `ak.stock_zh_a_hist_min_em(symbol=..., period="5")` — 分钟级 K线
- `ak.stock_zh_a_spot_em()` — 全 A股实时快照（涨跌幅、量、市值等）
- `ak.stock_individual_fund_flow(stock="600519", market="sh")` — 个股资金流
- `ak.stock_hsgt_hist_em(...)` — 沪深港通/北向资金

**基本面/财报/估值**
- `ak.stock_financial_abstract(symbol="600519")` — 关键财务指标摘要（新浪，历年一次取全）
- `ak.stock_financial_report_sina(stock="sh600519", symbol="资产负债表")` — 三大报表（资产负债表/利润表/现金流量表）
- `ak.stock_financial_analysis_indicator(symbol="600519")` — 财务分析指标（ROE、毛利率、负债率等）
- `ak.stock_a_indicator_lg(symbol="600519")` — 历史 PE/PB/股息率/市值（乐咕，带估值分位）
- `ak.stock_individual_info_em(symbol="600519")` — 个股基本信息（总市值、流通市值、行业、上市日期、股本）
- `ak.stock_zh_a_gdhs(...)` — 股东户数

**事件/公告/情绪**
- `ak.stock_yjyg_em(date="20240930")` — 业绩预告
- `ak.stock_yjkb_em(date="20240930")` — 业绩快报
- `ak.stock_zh_a_disclosure_report_cninfo(symbol="600519", ...)` — 巨潮信息披露公告列表
- `ak.stock_notice_report(...)` — 东财公告
- `ak.stock_ggcg_em()` — 高管增减持
- `ak.stock_lhb_detail_em(start_date=..., end_date=...)` — 龙虎榜
- `ak.stock_news_em(symbol="600519")` — 个股最近约 20 条新闻（标题+链接+时间+摘要）
- `ak.stock_research_report_em(symbol="600519")` — 个股研报（评级、目标价、机构、日期）

**行业/板块/宏观**
- `ak.stock_board_industry_name_em()` / `ak.stock_board_industry_hist_em(...)` — 行业板块
- `ak.stock_board_concept_name_em()` — 概念板块
- `ak.macro_china_cpi()` / `ak.macro_china_pmi()` / `ak.macro_usa_interest_rate()` 等 — 宏观（政策量化指标）

> 注：AKShare 版本迭代快，个别函数名/参数会调整（上面标注了数据源以便交叉验证）。**用前务必以官方文档为准**：https://akshare.akfamily.xyz/data/stock/stock.html 。函数名不确定时在文档站内搜中文关键词（如"业绩预告""研报"）最快。

### 2.2 稳定性与坑

- **优点**：免费、无 token、覆盖广、社区活跃、中文文档全。
- **风险点**：
  1. **它是二手封装** — 上游东财/新浪一旦改接口，对应函数就会报错，需等作者/社区修（GitHub issue 里常年有"接口失效"报告，通常几天内修复）。**生产系统要对每个函数做 try/except + 降级**。
  2. **无官方 SLA、无频率保证** — 上游是公开网页接口，高频批量拉容易被限流，建议加随机 sleep（0.2–1s）+ 重试 + 本地缓存。
  3. **实时性**：行情有秒级到分钟级延迟，非交易级；财报/公告更新依赖上游披露。
  4. **AKTools**：官方提供 `aktools`（把 AKShare 封成 HTTP API），适合非 Python 服务调用。

**结论：AKShare 作为"基本面+技术面"的默认基座，缺口再用下面的源补。**

## 3. 其他库 / 官方源评估（补 AKShare 的缺口）

| 方案 | 覆盖 | 接入门槛 | 数据质量/频率 | 定位 |
|---|---|---|---|---|
| **Tushare Pro** | 行情+财报+财务指标+资金面，字段标准化、全市场批量友好 | **需注册 + 积分**（`tushare` 库，`ts.set_token`）。多数接口要 120–2000 积分，靠充值/贡献攒；有调用频率限制 | 质量高、字段规范，适合量化生产 | AKShare 缺标准化/批量时的首选补充。⚠️ 注意：Tushare 曾发生过突发停运事件，**不宜单点依赖**，要做多源冗余 |
| **BaoStock** | A股历史日/周/月 K线、复权因子、财报、财务指标、估值 | **完全免费、免注册**（`baostock` 库，`bs.login()`） | 历史数据干净、缺失少、稳定性高；**但无实时、更新偏慢** | 历史行情批量回补的最佳免费源，和 AKShare 交叉校验 |
| **efinance** | 东财行情/资金流/基金，接口简洁 | 免费、免 token | 直连东财，和 AKShare 同源 | AKShare 某些东财接口失效时的平替 |
| **adata** | A股行情/资金/情绪/概念，多源聚合 | 免费、免 token | 覆盖国内多源，含部分情绪数据 | 舆情/情绪维度的补充候选 |
| **pywencai（问财）** | 自然语言选股（"市盈率<20 且 ROE>15%"直接出票池） | 免费，但依赖同花顺问财网页，**反爬较强、易失效**（常需更新 cookie/JS 逆向） | 选股筛选强，非稳定数据管道 | 做 selection/初筛好用，不适合当稳定数据源 |
| **巨潮资讯网 (cninfo)** | 全市场法定公告 PDF/公告列表 | 免费，有公开查询接口（AKShare 已封装部分） | 最权威的公告源 | 公告/披露的权威出处 |
| **交易所官网（上交所/深交所）** | 公告、交易数据、规则 | 免费，部分需抓 HTML | 权威但接口零散 | 兜底核对 |
| **东方财富 Choice / Wind** | 全维度专业数据 | **付费、贵** | 机构级质量 | 预算充足才考虑，个人项目略过 |

## 4. 路径A：浏览器抓取 —— 各站点评估（重点看隐藏 JSON 接口）

原则：**能用隐藏 JSON 接口就绝不抓 HTML。** 下面按站点给出能拿的数据、隐藏接口、反爬难度。

### 4.1 东方财富 eastmoney（★首选抓取目标，接口最开放）

覆盖：行情+财报(F10)+资金流+公告+研报+个股新闻，几乎全维度。**AKShare 大量接口就是封装它**，所以能用 AKShare 就别自己抓。

关键隐藏 JSON 接口（无需登录、无签名，最稳）：
- **历史 K线**：`https://push2his.eastmoney.com/api/qt/stock/kline/get`
  参数：`secid`（`1.600519`=沪 / `0.000001`=深）、`klt`（101=日,102=周,103=月,5=5分钟）、`fqt`（0不复权/1前复权/2后复权）、`fields1`、`fields2`、`beg`、`end`、`lmt`。返回 JSON，K线在 `data.klines` 数组（逗号分隔字符串）。
- **实时快照/列表**：`https://push2.eastmoney.com/api/qt/stock/get`（单只）、`https://push2.eastmoney.com/api/qt/clist/get`（列表/板块，带 `fs` 筛选、`fields` 选列）。
- **F10 财报/资料**：`https://emweb.securities.eastmoney.com/PC_HSF10/...` 及 `https://datacenter-web.eastmoney.com/api/data/v1/get`（datacenter 系列，业绩预告、龙虎榜、研报、资金流都走这个，用 `reportName` 指定表名）。

反爬难度：**低**。多数行情/datacenter 接口无需登录、无验证码、无签名，只需带常规 `Referer`/`User-Agent`。限制主要是**频率限流**（高频会 429/空返回），加 sleep+重试即可。JSONP 接口需处理 `cb` 回调包裹。

### 4.2 新浪财经 sina（★财报三张表首选）

覆盖：实时行情、历史财报三大报表、财务指标。AKShare 的 `stock_financial_report_sina` / `stock_financial_analysis_indicator` 即封装它。
隐藏接口：
- 实时行情：`https://hq.sinajs.cn/list=sh600519`（返回一行文本，需带 `Referer: https://finance.sina.com.cn`，否则 403）。
- 财报：`https://money.finance.sina.com.cn/corp/go.php/...`（HTML 表格为主）。
反爬难度：**低–中**。行情接口需正确 Referer；无验证码。文本/HTML 格式老旧但稳定。

### 4.3 同花顺 10jqka / 问财（★反爬最强，慎抓）

覆盖：行情、F10、问财自然语言选股、资讯。
反爬难度：**高**。问财（`www.iwencai.com`）有 **JS 加密的动态参数（如 hexin-v token）+ 频繁改版**，需要 JS 逆向或用 `pywencai` 这类维护逆向逻辑的库（仍易失效）。普通行情页也有 cookie 校验。
建议：**除非要用问财的自然语言选股，否则跳过同花顺**，行情财报用东财/新浪即可。

### 4.4 雪球 xueqiu（★散户情绪/大V观点的主要来源，但需登录态）

覆盖：**个股讨论流、大V专栏、用户情绪**（这是别处拿不到的 UGC），也有行情/财报接口。
隐藏接口：`https://stock.xueqiu.com/v5/stock/...`（行情、财务）；讨论流 `https://xueqiu.com/statuses/...`。
反爬难度：**中–高**。**几乎所有接口都要先带 cookie（`xq_a_token`）**，该 token 需先访问首页/登录获取，且有有效期；高频访问会被封 IP/要求验证码。AKShare 有少量雪球封装（如 `stock_individual_basic_info_xq`），但**讨论流/评论正文一般得自己带 cookie 抓**。
建议：舆情要用雪球时，走浏览器自动化（本仓库已有 chrome-devtools-mcp / claude-in-chrome 能力）拿登录态，再调其 v5 JSON 接口；控制频率，只抓目标票池，别全市场爬。

### 4.5 东财股吧 guba.eastmoney.com（散户情绪补充）

覆盖：散户帖子/回帖/阅读量（情绪热度信号）。
反爬：中。列表页可抓 HTML/接口，长贴正文需翻页。适合做"讨论热度/发帖量"这类量化情绪指标，而非逐条读正文。

### 4.6 抓取路线的合规与稳定性提示

- **合规**：仅抓公开、不需破解登录的数据；遵守 robots 与频率礼貌；数据仅供自用分析，**不转售、不二次公开发布原文**（尤其研报正文、UGC 有版权/平台协议约束）。绕过验证码/登录风控属高风险，避免。
- **稳定性**：自建爬虫维护成本高（上游改版就挂），**能落到 AKShare 就落到 AKShare**，把自建爬虫的范围收敛到"库不封装的 UGC 舆情"这一小块。

## 5. 舆情 / 新闻数据的获取难点与建议方案（本项目最难的一块）

### 5.1 为什么难

1. **非结构化**：新闻/评论/研报是自由文本，拿到只是第一步，要做**情感分析、事件抽取、相关性打分**才有用。
2. **没有一站式源**：政策在官网、新闻在媒体、研报在东财/慧博、散户情绪在雪球/股吧、大V在雪球/公众号/微博——**每类都在不同平台，且格式各异**。
3. **UGC 要登录 + 强反爬**：雪球/股吧/微博的评论流几乎都要登录态，且反爬升级快。
4. **信噪比低 + 时效性强**：股市舆情大量噪声、水军、标题党，且价值随时间快速衰减，需近实时采集 + 去噪。
5. **正文常拿不全**：研报/新闻多数只能拿到标题+摘要+链接，全文受版权/付费墙限制。

### 5.2 分块建议方案

| 舆情子类 | 建议采集方式 | 说明 |
|---|---|---|
| **政策（国内央行/证监会/发改委/行业部委）** | 官网栏目页 + RSS + **WebSearch 定向查**（`allowed_domains` 限定 gov.cn / csrc.gov.cn / pbc.gov.cn） | 政策文本权威、更新有规律，抓栏目页或搜索最省事 |
| **国外（美联储/关税/海外宏观）** | **WebSearch**（限定 reuters / bloomberg / 财联社 / 华尔街见闻）+ 财经媒体 RSS | 海外源直接搜，配合 AKShare `macro_usa_*` 拿量化指标 |
| **财经新闻（个股/行业事件）** | AKShare `stock_news_em`（个股）+ 财联社/东财/新浪财经 RSS + WebSearch 补 | 标题+摘要+链接足够做事件识别；全文按需再抓单页 |
| **研报（机构评级/目标价）** | AKShare `stock_research_report_em`（评级/目标价/机构结构化字段） | 结构化字段最有用；正文一般拿不全，靠标题+评级+目标价即可建情绪信号 |
| **公司公告/内部行为（增减持/回购/预告/诉讼）** | 巨潮 `stock_zh_a_disclosure_report_cninfo` + `stock_ggcg_em` + `stock_yjyg_em` | **结构化程度最高、最权威**，是舆情里最好做的一块，优先做 |
| **散户情绪（雪球/股吧热度）** | 浏览器自动化带登录态抓 v5 接口 / 股吧发帖量 → 自算"讨论热度、多空比" | 最难、最脏；建议只抓**目标票池**、只做**量化热度指标**，不逐条精读 |
| **大V/博主观点** | 雪球专栏 + 精选公众号（人工/半自动）→ 摘要入库 | 覆盖成本高，建议小范围精选源，别追求全量 |

### 5.3 落地建议（务实版）

1. **分层**：结构化舆情（公告、研报评级、业绩预告）优先做——权威、好解析、信号强；非结构化 UGC 后做。
2. **情感分析**：中文金融情感可用 **FinBERT-中文 / 通用中文情感模型**，或直接调 LLM（对少量高价值文本做事件抽取+多空判断，成本可控）。本仓库已有 qwen 网关，**批量情感打分/摘要可外包给 qwen**（走 内部网关不烧额度）。
3. **去噪与聚合**：按票池过滤、去重（同新闻多源转载）、按时间衰减加权，产出"个股舆情分/热度分"而非堆原文。
4. **采集频率**：政策/公告日级即可；新闻/UGC 想做盘中信号则分钟级轮询目标票池。
5. **兜底**：任一源失效不影响整体——多源冗余 + 缺失时降级到 WebSearch。

---

## 6. 最终推荐架构（一句话结论）

> **基本面 → AKShare（`stock_financial_abstract`/`stock_financial_report_sina`/`stock_a_indicator_lg` 等），缺标准化/批量时用 Tushare 补、历史用 BaoStock 校验；
> 技术面 → AKShare `stock_zh_a_hist` 拉 K线+量，技术指标（MACD/KDJ/RSI/均线）本地用 pandas-ta/TA-Lib 自算；
> 舆情 → 三路混采：结构化(巨潮公告 + AKShare 研报/业绩预告 + `stock_news_em`) + 搜索(WebSearch 定向查政策/海外) + UGC(浏览器带登录态抓雪球/股吧热度)，再用中文金融情感模型/LLM 做打分聚合。**

配套原则：
- **AKShare 做基座**，自建爬虫只补它不封装的 UGC 舆情；
- **每个数据函数都要 try/except + 多源降级 + 本地缓存**（免费源无 SLA）；
- **合规红线**：只取公开数据、控频率、不转售不二次公开原文、不破解登录风控；
- **高耗 token 的批量情感/摘要外包给 qwen**，主对话留决策。
