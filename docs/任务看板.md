## 使用规矩(对齐 [开发规范.md](开发规范.md) 第六章 Git 铁律)

1. **开工前**:把要做的任务从「待做」挪到「进行中」,填**窗口/负责人、worktree 路径、分支名、开始时间**。→ 别人看到就不碰同一分支/文件。
2. **并行开发用 git worktree**(开发规范 §六 规则 0):新任务在 `claude_dir/worktree/<任务名>` 开独立 worktree + 分支,各窗口 HEAD 独立、不互相打断;主窗口(主仓)只在 main 做集成。
3. **完成后**:从「进行中」挪到「已完成(近期)」,并在 [开发日志](日志/开发日志.md) 写详情、合并 main、删分支。
4. **阻塞/待用户拍板**的进「阻塞区」,注明卡在什么。
5. **本文本身也是共享文件**:更新时小步、及时提交,避免与他人同时改(纯追加/改自己那行最安全)。
