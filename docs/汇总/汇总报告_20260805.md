## 二、跨组共性(本池全景结论)

1. **一条主线串起全池:AI 算力 + 半导体 + 机器人硬科技**。8/5 芯片异动的核心驱动 = **2026 存储超级涨价周期**(DRAM Q2 +58~63% / NAND +70~75%,近 15 年最严重短缺)+ HBM 缺口,外溢到先进封装、内存接口、算力/光模块/液冷。
2. **技术面高度同步于"跌深反弹初期"**:约 20/32 趋势"偏空",大面积 MACD 底背离 + 超跌,当日集体收红/多股大涨——**板块级超跌修复窗口**。但量能多为平量/缩量,右侧反弹**未被成交量确认**。
3. **"趋势—拐点背离"是本轮核心现象**:多数票趋势评级偏空,同时拐点信号"超跌待反弹/反弹启动"——**验证 P1.5 让拐点独立成维的价值**(否则趋势分会一律打成偏空、踏空反弹)。
4. **估值极致分化 + PE 大面积失效**:高 PE 多因周期底利润被折旧/低毛利/亏损压制(芯原 PE 负、晶合 131、绿的 437、麦格 407)。**须按标的性质切换 PB / PS / 在手订单 / 扭亏进度**。
5. **公告面回购集群护盘**:澜起、汇川、豪威、韶能近期集中回购——**可能是板块底部信号**(见灵感"回购密度")。
6. **政策双刃**:2026-08 前后日本/美对华先进封装设备逐案审批(HBM/Chiplet 驳回率高)+ 25% 关税——短期压制设备/高端产能,**长期强化国产替代逻辑**。
7. **KDJ 假信号频发**:绿的/机器人/柯力/风华/当升/金力 6 只 J 值 >100 冲入超买区,但 RSI 与 BIAS 均不共振——**实证"≥2 指标共振才下结论"口径的必要性**。

## 五、本轮沉淀的新指标/策略灵感

已汇入 [衡量指标与策略.md §6](../衡量指标与策略.md)。最高优先级:
1. **BIAS 乖离率落入 `technical.compute`**(5 组共同呼吁;−10% 超卖/−20% 极端档,极端+放量为强信号)。

3. **PE 适用性开关**:亏损/周期底/微利标的禁用 PE,切 PB/PS/在手订单/扭亏进度。
4. **双拐点高置信**:低位金叉 + MACD 底背离,或 技术超卖 + 下季业绩预告拐点。
5. **距 N 日高点回撤% 独立维度**(急跌型超卖,如江波龙 681→336)。
6. **"业绩强/股价弱"背离池**(沪电)、**回购密度**(板块底部)、**定增解禁抛压标签**(麦格)、**在手订单/年营收倍数**(周期确定性锚)。
